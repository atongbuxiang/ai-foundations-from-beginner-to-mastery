# 多层感知机与逐层前向计算

> [!abstract] 本章主问题
> 多层感知机不是“把很多神经元画成网状”这么简单，而是形状严格匹配的函数复合。每一层先做 affine map，再做逐元素或门控非线性；前向传播按计算依赖顺序产生 hidden representations 与最终输出。只要逐层保存对象、形状和语义，参数计数、手算、实现和后续反向传播都能统一。

## 一、学习目标

完成本章后，应能：

1. 从层宽写出完整 MLP 的参数与 activation 形状；
2. 区分 pre-activation $Z^{(\ell)}$ 与 activation $H^{(\ell)}$；
3. 将网络写为函数复合而不是含混“层列表”；
4. 手算一个 $2\to2\to1$ 网络的前向输出；
5. 推导批量和序列输入下的 shape ledger；
6. 计算参数数、MACs 与 activation storage；
7. 证明全 identity MLP 会坍缩成单个 affine map；
8. 区分 hidden activation 与 output parameterization；
9. 解释 depth、width、bottleneck 与表示维数的作用；
10. 建立后续 backprop 所需的 cache 与计算图接口。

## 二、第一性定义：有向无环的函数复合

令输入层宽为 $d_0$，第 $\ell$ 层宽为 $d_\ell$。采用“样本在行”的约定，对单样本定义

$$
\boldsymbol h^{(0)}=\boldsymbol x\in\mathbb R^{1\times d_0},
$$

并对 $\ell=1,\ldots,L$ 递推

$$
\boxed{
\begin{aligned}
\boldsymbol z^{(\ell)}
&=\boldsymbol h^{(\ell-1)}W^{(\ell)}+\boldsymbol b^{(\ell)},\\
\boldsymbol h^{(\ell)}
&=\phi_\ell\!\left(\boldsymbol z^{(\ell)}\right).
\end{aligned}}
$$

形状为

$$
W^{(\ell)}\in\mathbb R^{d_{\ell-1}\times d_\ell},
\qquad
\boldsymbol b^{(\ell)}\in\mathbb R^{1\times d_\ell}.
$$

整个网络是

$$
f_\theta
=f_L\circ f_{L-1}\circ\cdots\circ f_1,
\qquad
\theta=\{W^{(\ell)},\boldsymbol b^{(\ell)}\}_{\ell=1}^L.
$$

“前馈”表示依赖图中没有从后层返回前层的有向环；不是说训练时没有反向梯度。

## 三、Pre-activation 与 Activation 必须分账

$\boldsymbol z^{(\ell)}$ 是第 $\ell$ 层 affine score，$\boldsymbol h^{(\ell)}$ 是经过非线性后的表示。两者的 shape 通常相同，但数值语义不同：

- ReLU 时，$h_j^{(\ell)}=\max(0,z_j^{(\ell)})$；
- sigmoid 时，$h_j^{(\ell)}\in(0,1)$；
- identity 时，$h^{(\ell)}=z^{(\ell)}$；
- normalization、gating 或 residual block 中，两者之间还可能有更多算子。

反向传播需要知道 activation 的局部导数，故只缓存一个没有名字的 `layer_output` 很容易在复杂网络中接错。

## 四、一个两层 MLP 的完整手算

考虑 $2\to2\to1$ 网络，hidden 用 ReLU，output 用 identity：

$$
\boldsymbol x=\begin{bmatrix}1&-2\end{bmatrix},
\quad
W^{(1)}=\begin{bmatrix}1&-1\\2&1\end{bmatrix},
\quad
\boldsymbol b^{(1)}=\begin{bmatrix}1&0\end{bmatrix}.
$$

第一层 pre-activation 为

$$
\begin{aligned}
\boldsymbol z^{(1)}
&=\boldsymbol xW^{(1)}+\boldsymbol b^{(1)}\\
&=\begin{bmatrix}1&-2\end{bmatrix}
\begin{bmatrix}1&-1\\2&1\end{bmatrix}
+\begin{bmatrix}1&0\end{bmatrix}\\
&=\begin{bmatrix}-2&-3\end{bmatrix}.
\end{aligned}
$$

因此

$$
\boldsymbol h^{(1)}=\operatorname{ReLU}(\boldsymbol z^{(1)})
=\begin{bmatrix}0&0\end{bmatrix}.
$$

再取

$$
W^{(2)}=\begin{bmatrix}3\\-2\end{bmatrix},
\qquad b^{(2)}=0.5.
$$

输出为

$$
z^{(2)}=\boldsymbol h^{(1)}W^{(2)}+b^{(2)}=0.5,
\qquad
h^{(2)}=0.5.
$$

这个例子也暴露“dead path”：本样本上两个 hidden ReLU 都关闭，输出只剩 bias。它不意味着这些神经元对其他输入也永久死亡。

## 五、批量前向与形状账本

对 batch size $B$：

$$
H^{(0)}=X\in\mathbb R^{B\times d_0},
$$

$$
Z^{(\ell)}
=H^{(\ell-1)}W^{(\ell)}
+\boldsymbol1_B\boldsymbol b^{(\ell)},
\qquad
H^{(\ell)}=\phi_\ell(Z^{(\ell)}).
$$

一个可靠 ledger 是：

| 对象 | 形状 | 轴语义 |
|---|---|---|
| $H^{(\ell-1)}$ | $[B,d_{\ell-1}]$ | sample × input feature |
| $W^{(\ell)}$ | $[d_{\ell-1},d_\ell]$ | input feature × output feature |
| $b^{(\ell)}$ | $[d_\ell]$ | output feature |
| $Z^{(\ell)},H^{(\ell)}$ | $[B,d_\ell]$ | sample × output feature |

检查顺序是：先让 contracted dimension $d_{\ell-1}$ 匹配，再检查 bias 对最后一轴广播，最后确认 batch 轴被保留。

## 六、序列输入怎样经过 MLP

若输入是

$$
H^{(0)}\in\mathbb R^{B\times T\times d_0},
$$

普通 position-wise MLP 对每个 $(b,t)$ 使用同一参数：

$$
Z^{(\ell)}_{b,t,j}
=\sum_{k=1}^{d_{\ell-1}}
H^{(\ell-1)}_{b,t,k}W^{(\ell)}_{k,j}
+b_j^{(\ell)}.
$$

因此输出 shape 是 $[B,T,d_\ell]$；该 MLP 混合 feature，却不混合不同 token 位置。Transformer FFN 的 position-wise 性质正来自这一参数共享方式。

## 七、参数计数与前向成本

第 $\ell$ 层参数数为

$$
P_\ell=d_{\ell-1}d_\ell+d_\ell.
$$

总参数数

$$
\boxed{
P=\sum_{\ell=1}^L(d_{\ell-1}+1)d_\ell.
}
$$

批量前向的主要 MACs 为

$$
\boxed{
\operatorname{MACs}
\approx B\sum_{\ell=1}^L d_{\ell-1}d_\ell,
}
$$

序列输入则再乘 $T$。训练时还要保存或重算部分 $Z^{(\ell)},H^{(\ell)}$；activation memory 大致随 $B\sum_\ell d_\ell$（序列时再乘 $T$）增长。参数量、计算量和 activation memory 是三本不同的账。

## 八、为什么没有非线性就没有多层表达增益

若所有 $\phi_\ell$ 都是 identity，以两层为例：

$$
\begin{aligned}
f(\boldsymbol x)
&=(\boldsymbol xW^{(1)}+\boldsymbol b^{(1)})W^{(2)}
+\boldsymbol b^{(2)}\\
&=\boldsymbol x\underbrace{(W^{(1)}W^{(2)})}_{W_{\rm eff}}
+\underbrace{(\boldsymbol b^{(1)}W^{(2)}+\boldsymbol b^{(2)})}_{\boldsymbol b_{\rm eff}}.
\end{aligned}
$$

仍是单个 affine map。归纳可知任意有限层 affine map 的复合仍是 affine。因而 hidden nonlinearity 是改变函数类的必要条件；但“有非线性”不等于任意结构都容易训练或高效表达。

## 九、隐藏层是在学表示

第一层把输入映为

$$
\boldsymbol h^{(1)}=\phi_1(\boldsymbol xW^{(1)}+\boldsymbol b^{(1)}).
$$

第二层不再直接看原始 $\boldsymbol x$，而是在 $\boldsymbol h^{(1)}$ 空间中做新的 affine decision。于是一个在输入空间不可被单超平面分开的任务，可能在 learned representation 中变得线性可分。

“表示”并不必然可逆或保留所有信息。若某层宽度很小、activation 饱和或 ReLU 大量为零，多个输入可能映到同一点；这既可能压缩 nuisance，也可能丢失任务信号。

## 十、Depth 与 Width 的最小区分

- **width** $d_\ell$：某层可同时维护多少 coordinate/features；
- **depth** $L$：允许多少次交替的 affine transform 与 nonlinear re-partition；
- **bottleneck**：某层宽度显著低于相邻层，限制中间表示维数；
- **overparameterization**：参数表示可能高度冗余，不等于函数空间维数同样大。

深度可以复用中间计算并形成组合结构，宽度可以并行覆盖更多局部特征。更深是否更高效是需要函数族、误差与资源共同量化的定理问题，详见[[深度分离、线性区域与表达效率]]。

## 十一、输出层不是固定模板

最后一层的 activation 与 loss 必须配套：

| 任务 | 最后输出 | 常见损失 | 边界 |
|---|---|---|---|
| 实值回归 | identity scalar/vector | squared/robust loss | 输出不自动有范围约束 |
| 二分类 | one logit | sigmoid-cross-entropy | 训练宜使用 fused logits 形式 |
| $K$ 分类 | $K$ logits | softmax-cross-entropy | logits 有共同平移不变性 |
| 多标签 | $K$ independent logits | per-label BCE | 不要求概率和为 1 |
| 正值参数 | softplus/exp | likelihood-specific | 数值范围与 conditioning 不同 |

hidden ReLU 的选择不能机械复制到 output；输出必须先声明 action/parameter space。

## 十二、逐层前向算法

```text
H = X
cache = []
for layer l = 1,...,L:
    Z = H @ W[l] + b[l]
    H_new = phi[l](Z)
    cache.append((H, Z, H_new))
    H = H_new
return H, cache
```

这个伪代码强调：

1. 当前层输入是上一层 activation；
2. affine 与 activation 分成两个算子；
3. cache 是为了后续 VJP/backprop，不是数学输出本身；
4. inference 可丢弃大部分 cache，training 通常不能；
5. dropout、normalization 等会给 cache 加入 mask 或统计量。

## 十三、计算图视角

MLP 的前向是一个有向无环图：参数和输入为 source nodes，matmul、broadcast add、activation 是 operation nodes，loss 是 sink。链式网络只是最简单的图；残差、门控和共享参数会出现分支与汇合。

前向的拓扑序保证每个算子执行时输入已就绪。反向则按逆拓扑序传播 cotangent。此处只建立接口，完整语义见[[计算图、拓扑序与前向执行]]。

## 十四、数值与实现审计

即使公式正确，实现仍可能错在：

- 把 `[B,d]` 与 `[d,B]` convention 混用；
- bias 在 batch/time 轴而非 feature 轴广播；
- 原地修改 activation，破坏 autograd 所需缓存；
- 大 logit 先显式 sigmoid/softmax，再取 log 造成 overflow/underflow；
- mixed precision 中 accumulator 太窄；
- 忘记 train/eval mode 会改变 dropout/normalization；
- 把参数 storage layout 当数学 layout。

单元测试至少应检查 shape、dtype/device、finite values、small hand calculation 和 gradient check。

## 十六、AI 中的对象映射

- Transformer FFN：每个 token 独立经过 $d_{model}\to d_{ff}\to d_{model}$ 的 MLP；
- vision MLP/head：对 patch/pooled representation 做 feature mixing 与分类；
- adapter：在主干内插入小 bottleneck MLP；
- gating：把一个线性分支的输出乘到另一个分支，超出纯逐元素 activation；
- implicit/deep equilibrium models：层可重复共享参数并通过 fixed point 定义输出，已不再是普通有限链；
- mixture-of-experts：router 决定不同 token 调用哪些 MLP experts，参数数与 active compute 分离。

这些结构复用本章的 affine—activation 基元，但还需各自的 routing、sharing、normalization 或 fixed-point 合同。

## 十七、常见错误

1. 不标层号，混淆 $W^{(\ell)}$ 的输入/输出维；
2. 把 $Z^{(\ell)}$ 和 $H^{(\ell)}$ 当成同一个变量；
3. 以为叠加多个 identity layer 会产生非线性；
4. 参数计数遗漏 bias，或把 batch size 算进参数；
5. 把 output activation 机械设成 hidden activation；
6. 只画神经元连线，不给 tensor shape 与 axis semantics；
7. 把更宽、更深直接等同于更容易训练或更会泛化；
8. inference memory、training cache 和 parameter memory 混成一个数字。

## 十八、本节回顾与掌握标准

> [!summary]
> - MLP 是 $H^{(\ell)}=\phi_\ell(H^{(\ell-1)}W^{(\ell)}+b^{(\ell)})$ 的复合；
> - $W^{(\ell)}:[d_{\ell-1},d_\ell]$，batch/time 轴保持；
> - pre-activation、activation 与 output parameterization 必须分开；
> - 全 identity 网络严格坍缩为单个 affine map；
> - 总参数为 $\sum_\ell(d_{\ell-1}+1)d_\ell$；
> - forward cache 是 backprop 的输入合同，表达能力与训练保证仍需另论。

能读写 shape ledger（A）、手算完整前向（B）、证明 affine collapse 并推导成本（C）、诊断广播/输出/缓存错误（D），并把 Transformer FFN 或 adapter 翻译成本章对象（E）。
