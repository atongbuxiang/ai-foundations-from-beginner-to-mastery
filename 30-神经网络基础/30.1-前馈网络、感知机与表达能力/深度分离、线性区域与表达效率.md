# 深度分离、线性区域与表达效率

> [!abstract] 本章主问题
> 万能逼近只说浅网最终“能够”，深度分离问的是“要花多少资源”。深层网络通过函数复合重复折叠输入空间，能用少量重复模块产生大量振荡或线性区域；对特定目标族，浅层网络若保持较小误差就必须指数增宽。但这是带明确目标分布、activation、深度与误差的资源定理，不是“越深永远越好”。

## 课程位置与两遍学习路线

- **承接什么：** NN-06 只保证在允许网络规模随精度增长时存在近似，没有回答浅网和深网各要付出多少资源；
- **本页解决什么：** 用 NN-05 的 triangular hat 构成 tent map，展示复合如何复用一个局部模块并增加线性 pieces；
- **后续为何需要：** NN-08 会说明资源计数必须先处理等价参数，下一卷则转向计算图、梯度与“表达得到但能否训练”。

**第一遍只数折线。** 从一个 tent 开始画 $T,T^{\circ2},T^{\circ3}$，数单调段和 breakpoint；先建立“串行复合”与“浅层枚举”的资源差异直觉。

**第二遍再读 lower-bound 合同。** 写清 target family、deep class、shallow class、size/depth measure、error norm/distribution 和量词，确认结论没有越界到所有函数、训练或泛化。

### 问题链

1. UAT 已说浅网也 universal，为什么还需要研究 depth？
2. ReLU 每个区域内仍是 affine，全局复杂性从哪里出现？
3. 一个 tent module 被复合 $L$ 次时，哪些计算被复用？
4. “区域数指数增长”在什么条件下才能升级为 approximation lower bound？
5. 参数量相近时，顺序延迟、activation memory 与硬件并行度怎样改变实际选择？

> [!check] 第一遍停靠线
> 若你能从 $T$ 手算 $T^{\circ2}$ 的四个单调段，并解释浅层 $m$ 个一维 ReLU 至多给 $m$ 个 breakpoint，就可以进入参数对称性；严格分离量词和系统成本留到第二遍。

## 符号与对象账本

| 对象 | 身份 | 计数方式 | 不能替代 |
|---|---|---|---|
| $T:[0,1]\to[0,1]$ | 两折 tent module | 常数个 ReLU units | 任意真实目标函数 |
| $T^{\circ L}$ | 深度 $L$ 的函数复合 | executed depth 与线性 pieces | $T(x)^L$ |
| breakpoint/region | 局部 affine 公式改变处/区间 | 输入空间几何 | VC 维或风险 |
| size/depth | 架构资源 | 必须声明 units、parameters 或 gates | FLOPs、latency、memory 的全部 |
| approximation error | lower bound 的判据 | norm 或数据分布 | optimization/generalization error |

### 贯穿算例：把 XOR 三角帽缩放成可复用模块

沿用 NN-05 的 $X_\oplus$ 与三角帽 $q$，并定义

$$
T(u)=q(2u)
=2\operatorname{ReLU}(u)-4\operatorname{ReLU}(u-\tfrac12)+2\operatorname{ReLU}(u-1).
$$

$T$ 在 $[0,1/2]$ 斜率为 $2$，在 $[1/2,1]$ 斜率为 $-2$。每次复合都把上一层每个单调区间再次折成两段；在非退化构造中，$T^{\circ L}$ 有 $2^L$ 个单调 pieces。这里的指数来自**函数复合的层级复用**，不是凭空增加信息，也不说明 SGD 会发现这些精确权重。

## 核心公式七问：$T^{\circ L}=\underbrace{T\circ\cdots\circ T}_{L\text{ 次}}$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 用固定局部折叠模块生成随执行深度增长的振荡结构 |
| 对象 | $T$ 是函数，$L$ 是复合次数，$T^{\circ L}$ 不是点乘或幂 |
| 来路 | 每层把前层表示重新映回 $[0,1]$，使下一层可重复同一两折操作 |
| 步骤 | 必须先算最内层；每个旧单调段的值域覆盖 $[0,1]$ 时才会完整再分裂 |
| 读法 | depth 存储的是可复用计算顺序，shallow width 倾向并行列举局部 pieces |
| 检查 | $L=1$ 有 $2$ 段，$L=2$ 有 $4$ 段；权重退化或值域不足时计数可下降 |
| 去路 | circuit depth、hierarchical features、weight tying、compression，以及表达—优化—硬件三本账 |

## 一、学习目标

完成本章后，应能：

1. 定义 depth、width、size 与 parameter sharing；
2. 解释 ReLU 网络为何是 continuous piecewise affine；
3. 计算一维浅层 ReLU 网络的 breakpoints 上界；
4. 构造 tent map 并分析复合后的振荡数；
5. 陈述 depth separation 的量词结构；
6. 区分 region count、可逼近函数数与统计容量；
7. 解释 compositional target 为何适合 deep architecture；
8. 比较宽浅与窄深的参数、计算和并行代价；
9. 识别无效/不可达线性区域；
10. 审计“深度带来指数表达力”的适用边界。

## 二、先固定资源单位

不同论文的 depth 定义可能把 output layer 算入或排除。本章约定：每次 affine + nonlinear hidden transform 计一层，output affine 单独报告。width 是最大 hidden units 数，size 是所有 computational units 或 nonzero parameters 总数。

若参数跨层共享，distinct parameters 与 executed units 不同。例如重复调用同一 tent module $L$ 次，depth 随 $L$ 增长，但 distinct parameter values 可以保持常数。

## 三、ReLU 网络是 Piecewise Affine

在一个固定 activation pattern 中，每个 ReLU 等于乘一个固定 $0/1$ diagonal mask $D_\ell$：

$$
h^{(\ell)}=D_\ell(W_\ell h^{(\ell-1)}+b_\ell).
$$

把所有层展开，网络在该区域内是 affine。不同 pattern 对应不同局部公式，边界由某些 pre-activation 等于零组成。因此 ReLU 网络全局上 continuous、piecewise affine。

## 四、一维浅网的 Breakpoint 上界

一个含 $m$ 个 hidden ReLU 的一维单隐藏层网络可写成

$$
g(x)=c+ax+\sum_{j=1}^m\alpha_j\operatorname{ReLU}(w_jx+b_j).
$$

每个 $w_jx+b_j$ 最多在一个位置变号，所以 breakpoint 至多 $m$ 个，线性区间至多 $m+1$ 个。不同神经元的 breakpoint 可重合或落在 domain 外，因此这是上界，不保证达到。

## 五、Tent Map：一个可重复折叠的模块

在 $[0,1]$ 上定义

$$
T(x)=2\operatorname{ReLU}(x)
-4\operatorname{ReLU}(x-\tfrac12)
+2\operatorname{ReLU}(x-1).
$$

则

$$
T(x)=
\begin{cases}
2x,&0\le x\le1/2,\\
2-2x,&1/2<x\le1.
\end{cases}
$$

它把区间先上升再下降，形成一个 tent。这个模块只需常数个 ReLU units。

## 六、复合怎样指数增加振荡

考虑 $T^{\circ L}=T\circ\cdots\circ T$。每次复合都把现有每个单调区间再折成两段，因此第 $L$ 次复合有 $2^L$ 个主要线性 pieces，并在相邻区间交替上升/下降。

深网按层复用“折叠”操作，而不是把全部 $2^L$ 段逐一列成并行 hidden units。这是 compositional reuse 的核心直觉。

## 七、为什么浅网需要很多单元

若目标在 $[0,1]$ 上有大量交替峰谷，而浅层 ReLU 函数只有 $m+1$ 个线性 pieces，则当 $m\ll2^L$ 时，它无法在每个相邻区间跟随正确振荡。

严格 separation proof 还要指定误差 measure（如某分布下 classification error 或 $L^1$ error），并证明缺少 crossings 会造成非小误差。仅比较图中“波峰数”是 proof intuition，不是完整 lower bound。

## 八、一个代表性的 Depth Separation 结论

Telgarsky 2016 构造了一族由 semi-algebraic gates 表示的目标：某些深度和 size 为 polynomial 的深网，若由深度显著更小的网络在指定误差下逼近，则浅网 size 必须 exponential 增长。

其量词形式是：

$$
\exists\{f_k\},\quad
\exists\text{ small deep nets representing }f_k,
$$

而对满足指定 depth/size 限制的 shallow class，误差不能同时小。它不是“对所有函数，深网都指数优于浅网”。

## 九、高维 Linear Region 计数

一层 $m$ 个 generic hyperplanes 在 $d$ 维最多把空间分成

$$
\sum_{j=0}^d\binom mj
$$

个区域。深层网络在前层表示空间中继续切分和折叠，可使可达区域数随 depth 快速增长。Montúfar 等给出了多层 piecewise-linear 网络的 region-count lower bounds，揭示 depth 的组合增益。

但 region 数只是 expressivity proxy：不同区域可能用同一 affine map、可能几乎没有输入概率质量，也可能因权重退化而不可达。

## 十、Region Count 不等于 VC 维或泛化

- linear regions：单个参数实例把 input domain 切成多少局部 affine pieces；
- VC/pseudodimension：整个函数类在有限样本上能实现多少标记/数值模式；
- norm/Lipschitz：函数敏感性或复杂度控制；
- generalization：算法、数据分布和 sample size 共同决定的风险性质。

它们可能相关，但任何一个数都不能无条件替代另一个。

## 十一、Compositional Structure

若目标本身有层次结构，例如

$$
f(x_1,\ldots,x_8)
=h_3(h_2(h_1(x_1,x_2),h_1(x_3,x_4)),
      h_2(h_1(x_5,x_6),h_1(x_7,x_8))),
$$

树形网络可复用低元函数并匹配 dependency graph。一个完全浅层的展开可能重复描述许多组合。深度优势因此常来自 architecture 与 target composition 对齐，而非 depth 的抽象数字。

## 十二、Width、Depth 与系统成本

深网通常增加 sequential latency 和 activation/checkpointing burden；宽网提供更多并行 GEMM，但参数和通信可能增加。相同 parameter count 不代表相同 FLOPs、critical path 或 hardware utilization。

表达效率定理通常只计 units/parameters；部署选择还需加入 memory、parallelism、numerical stability 和 optimization。

## 十三、表达存在不等于可训练

tent-map 构造需要精确参数排列；随机初始化与 gradient descent 不一定发现它。深度还会引入 Jacobian products、conditioning 和 signal propagation 问题。后续初始化、归一化和残差卷正是处理“可表达但难训练”的缺口。

## 十五、AI 中的接口

- hierarchical vision/language features 可能与 compositional depth 对齐；
- recurrent/weight-tied modules 用执行深度换 distinct parameters；
- circuit depth 与 chain-of-thought steps 也涉及 sequential composition，但对象和定理不同；
- mixture-of-experts 主要增加 conditional width，不自动获得同样的 depth separation；
- model compression 若减层，需检查 target 是否依赖高频/组合结构。

## 十六、常见错误

1. 从一个构造族推出所有函数都偏好深网；
2. 不声明 shallow/deep 的 depth、size 与 activation；
3. 只数理论 activation patterns，不检查可达区域；
4. 把 region count 当 generalization guarantee；
5. 忽略 approximation norm/distribution；
6. 把存在性构造当训练动力学；
7. 只计参数，不计 sequential latency 和 cache；
8. 把共享参数的执行单元数和 distinct parameters 混为一谈。

## 十七、本节回顾与掌握标准

> [!summary]
> - ReLU 网络在固定 activation pattern 内是 affine；
> - 一维浅网 $m$ 个 ReLU 至多产生 $m$ 个 breakpoint；
> - tent map 的 $L$ 次复合可产生 $2^L$ 级 pieces；
> - depth separation 是特定目标族、误差和资源下的 lower bound；
> - expressivity、optimization、generalization 与 hardware efficiency 必须分层。

能计算区域（A/B）、推导 tent composition（C）、纠正指数优势误读（D），并分析真实 architecture 的 composition—resource 对齐（E）。
