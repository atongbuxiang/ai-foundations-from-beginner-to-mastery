# 参数对称性、等价表示与可辨识边界

> [!abstract] 本章主问题
> 神经网络参数不是函数的唯一身份证。隐藏单元可以置换，ReLU 入边和出边可以正向反向缩放，冗余单元还会产生连续等价族。因而“参数不同”“距离很远”“Hessian 很平”都不能直接翻译成“函数不同”或“泛化更好”；正确对象往往是参数空间按函数保持变换取商后的等价类。

## 课程位置与两遍学习路线

- **承接什么：** NN-05—07 一直在比较网络表示的函数，但还默认一组参数像是函数的唯一坐标；
- **本页解决什么：** 用同一个 triangular-hat 网络证明 parameter-to-function map 多对一，并建立离散置换、连续正缩放与冗余退化三类边界；
- **后续为何需要：** 反向传播、初始化、sharpness、model merging 与 mechanistic interpretability 都必须知道哪些变化只是 gauge、哪些真的改变函数。

**第一遍只验证两种保持变换。** 对三个 hidden units 先交换列与对应输出行，再把某单元 incoming 参数乘 $c>0$、outgoing 权重除以 $c$；逐矩阵确认输出不变。

**第二遍再进入 quotient 视角。** 区分 orbit、fiber、stabilizer 与 singular degeneracy，审计 raw norm、Euclidean distance、Hessian 和 posterior mode 是否具有函数不变性。

### 问题链

1. 两组相距很远的参数能否对所有输入实现同一函数？
2. hidden unit 重命名时，为什么 incoming 与 outgoing 必须成对变换？
3. ReLU 的正齐次性怎样产生连续等价轨道，为什么 $c<0$ 不合法？
4. dead/duplicate units 为什么比普通置换带来更强的不可辨识性？
5. AI 系统比较 checkpoint、平均权重或解释 neuron 时，应在参数空间还是函数空间工作？

> [!check] 第一遍停靠线
> 若你能在 NN-05 的三单元网络上任取一个 permutation 和一个 $c>0$，写出补偿后的参数并证明 $q$ 不变，就完成本卷第一遍；quotient 奇异性、Bayesian 与 merging 后果留到第二遍。

## 符号与对象账本

| 对象 | 类型 | 语义 | 审计问题 |
|---|---|---|---|
| $\theta\in\Theta$ | 参数坐标 | 一份 checkpoint | 是否只是等价类的代表元？ |
| $\Phi(\theta)=f_\theta$ | parameter-to-function map | 模型实际 predictor | 是否在声明域上比较？ |
| $P$ | permutation matrix | hidden-unit 重命名 | outgoing 是否做逆置换？ |
| $D\succ0$ | positive diagonal matrix | ReLU 单元缩放 gauge | activation 是否正齐次？ |
| $[\theta]$ | equivalence class/fiber | 同一函数的全部表示 | 是否含 dead/duplicate degeneracy？ |

### 贯穿算例：同一个三角帽的许多参数坐标

沿用 NN-05 的 $X_\oplus$。其 $q$ 可写成一隐藏层网络：三个 hidden columns 都读取 $s=x_1+x_2$，bias 为 $(0,-1,-2)$，output weights 为 $(1,-2,1)^\top$。若 $P$ 置换三个单元，或 $D=\operatorname{diag}(c_1,c_2,c_3)$ 且 $c_j>0$，令

$$
W_1'=W_1PD,\qquad b_1'=b_1PD,\qquad
W_2'=D^{-1}P^{-1}W_2,
$$

则由逐坐标 ReLU 与置换可交换、并满足 $\operatorname{ReLU}(zD)=\operatorname{ReLU}(z)D$，得到 $f_{\theta'}=f_\theta=q$。参数 norm、坐标距离甚至局部曲率都可以改变，但 XOR 四点和整个声明域上的函数均不变。

## 核心公式七问：$\theta\sim\theta'\Longleftrightarrow f_\theta(x)=f_{\theta'}(x)\;\forall x\in\mathcal X$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 把“同一个模型”从参数相等提升为声明域上的函数相等 |
| 对象 | $\theta,\theta'$ 是坐标；$f_\theta,f_{\theta'}$ 是函数；$\mathcal X$ 必须明确 |
| 来路 | parameter-to-function map 的 fibers 自然诱导等价关系 |
| 步骤 | 先证明 reflexive、symmetric、transitive，再识别保持 $\Phi$ 的 group action 与额外 degeneracy |
| 读法 | quotient $\Theta/{\sim}$ 中，同一 fiber 的所有参数代表同一点 |
| 检查 | 只在有限校准集输出相等不能证明全域等价；activation/architecture 改变时 symmetry 也会变 |
| 去路 | symmetry-aware merging、gauge-invariant capacity、function-space posterior 与可辨识性定理 |

## 一、学习目标

完成本章后，应能：

1. 定义 parameter-to-function map 与等价关系；
2. 推导隐藏单元 permutation symmetry；
3. 推导 ReLU positive-scaling symmetry；
4. 区分离散 symmetry 与连续 symmetry；
5. 解释 dead、duplicate 和 split neurons 带来的非唯一性；
6. 说明 identifiability 必须是 modulo symmetries；
7. 分析 symmetry 对 loss landscape、Hessian 和 Bayesian posterior 的影响；
8. 解释为何 naive weight averaging/model merging 会失败；
9. 区分输入置换等变性与参数置换对称性；
10. 选择 function-space 或 symmetry-aligned 比较方法。

## 二、参数到函数通常是多对一映射

设架构固定，参数空间为 $\Theta$，实现映射

$$
\Phi:\Theta\to\mathcal F,
\qquad
\Phi(\theta)=f_\theta.
$$

定义

$$
\theta\sim\theta'
\quad\Longleftrightarrow\quad
f_\theta(x)=f_{\theta'}(x)
\ \text{对声明域中所有 }x.
$$

这是等价关系。一个函数对应 fiber/orbit-like set

$$
[\theta]=\{\theta':\theta'\sim\theta\}.
$$

若 $\Phi$ 不是 injective，仅从完整输入输出函数也不能唯一恢复 raw parameters。

## 三、隐藏单元置换对称性

考虑一隐藏层 row-vector 网络

$$
f(X)=\sigma(XW_1+b_1)W_2+b_2,
$$

hidden width 为 $m$。令 $P\in\mathbb R^{m\times m}$ 为 permutation matrix，定义

$$
W_1'=W_1P,
\qquad
b_1'=b_1P,
\qquad
W_2'=P^{-1}W_2.
$$

逐元素 activation 与置换可交换：

$$
\sigma((XW_1+b_1)P)=\sigma(XW_1+b_1)P.
$$

所以

$$
f_{\theta'}(X)=\sigma(XW_1+b_1)PP^{-1}W_2+b_2=f_\theta(X).
$$

若各 hidden widths 为 $m_1,\ldots,m_{L-1}$，generic 参数至少产生 $\prod_\ell m_\ell!$ 个置换相关表示。

## 四、ReLU 的正缩放对称性

ReLU 是正一阶齐次：对 $c>0$，

$$
\operatorname{ReLU}(cz)=c\operatorname{ReLU}(z).
$$

令 $D$ 为正 diagonal matrix，变换

$$
W_1'=W_1D,
\qquad b_1'=b_1D,
\qquad W_2'=D^{-1}W_2.
$$

则

$$
\operatorname{ReLU}((XW_1+b_1)D)D^{-1}W_2
=\operatorname{ReLU}(XW_1+b_1)W_2.
$$

这是连续 symmetry；沿 $D(t)$ 改变参数 norm，函数保持不变。$c<0$ 不成立，因为 ReLU 不是 odd function。

## 五、不同 Activation 有不同 Symmetry

- tanh 是 odd：翻转某 hidden unit 的 incoming weight/bias 符号，同时翻转 outgoing weight，可保持函数；
- sigmoid 不具正齐次，不能使用任意正 rescaling；
- normalization 可能引入额外 scale invariance；
- bias、gating、weight tying 和 skip connection 会改变 symmetry group。

因此不能把某一架构的等价变换当成所有神经网络的普遍完整列表。

## 六、冗余单元带来更多非唯一性

若某 hidden unit 的 outgoing weight 为零，它的 incoming parameters 可任意变化而不改变输出。若两个 units 计算同一个 feature $h(x)$，outgoing weights $a_1,a_2$ 只通过和 $a_1+a_2$ 进入函数；可以连续重新分配。

对 ReLU 还可把一个 unit 拆成两个相同 incoming parameters、outgoing weights 相加等于原值。这些 degeneracy 在过宽网络中形成更高维的等价最优集合。

## 七、Identifiability 必须加限定语

参数可辨识通常应表述为：若 $f_\theta=f_{\theta'}$，则 $\theta'$ 只能由已知 symmetry 从 $\theta$ 得到。要成立常需 minimal/irreducible、非退化权重、足够输入域和架构宽度等条件。

Sussmann 对特定单隐藏层 tanh 网络给出了在 irreducibility 条件下、模置换与符号变化的唯一性；Phuong–Lampert 对某些非增宽 ReLU 架构研究了模置换与正缩放的功能—参数等价。结论都有明确架构条件。

## 八、Quotient Space 视角

理想对象是

$$
\Theta/{\sim},
$$

即把所有实现同一函数的参数视为同一点。实际 quotient 可能有 singular strata：generic 参数的 orbit 维数稳定，但 dead/duplicate neurons 的 stabilizer 更大，局部几何改变。

因此全局选择唯一 canonical representative 往往不连续或不容易；“把每层神经元排序”在权重接近相等时也可能突然跳变。

## 九、Loss Landscape 的后果

若 empirical loss 只依赖 $f_\theta$，则等价参数具有相同 loss。离散 permutation 产生多个相同值的 modes；连续 scaling/duplication 可产生平坦方向或相连 minima manifolds。

沿精确连续 symmetry 的切向量 $v$，函数和 loss 不变，故在光滑点 directional derivative 为零，局部 Hessian 可能有零特征值。这种平坦来自 parameterization gauge，不应直接解释为对输入扰动鲁棒或泛化好。

## 十、初始化中的“打破对称”

若同一层两个 units 以完全相同 incoming/outgoing parameters 初始化，并在相同数据上接受相同 gradient，它们会保持相同，等效为一个重复 unit。随机初始化让它们从不同点出发，从而有机会学习不同 features。

这与模型函数的 permutation symmetry 不矛盾：目标和架构仍对置换不变，只是一次随机 realization 选中了 orbit 中的一个非对称坐标表示。

## 十一、Weight Distance 与 Model Merging

两网功能相近但 hidden units 顺序不同，逐坐标平均可能把不对应的 features 混合，产生很差函数。反之，沿 ReLU scaling orbit 参数欧氏距离可以很大，函数距离仍为零。

合并前常需 unit matching、permutation alignment、activation correspondence 或直接在 function/output space 蒸馏。parameter cosine 也不是 symmetry-invariant metric。

## 十二、Bayesian 与 Ensemble 边界

参数 posterior 会在置换相关 modes 上重复质量；未经对齐的 mean 可能落在低概率且功能差的区域。MCMC/variational approximation 若只覆盖一个 mode，并不一定漏掉不同 functions，也可能只是漏掉同一函数的复制表示。

预测 posterior 应推前到 function space：

$$
p(f\mid D)=\Phi_\#p(\theta\mid D).
$$

参数不确定性与预测不确定性不能直接等同。

## 十三、不要混淆两种“置换”

- 参数置换 symmetry：重命名 hidden units，输入输出函数不变；
- 输入 permutation invariance/equivariance：交换 set elements/tokens/nodes 后，模型输出按任务规则不变或相应交换。

前者是 parameterization redundancy，后者是 architecture 对数据群作用的归纳偏置。

## 十五、AI 中的接口

- checkpoint matching/merging 必须先处理 hidden permutation；
- LoRA/adapter 还有矩阵因子 $AB=(AQ)(Q^{-1}B)$ 的 gauge；
- mechanistic interpretability 比较 neuron 时需应对 permutation、scaling 与 distributed representation；
- federated averaging 在独立训练模型上可能遭遇 feature misalignment；
- parameter-space uncertainty、distance 和 flatness 应报告 symmetry-aware boundary。

## 十六、常见错误

1. 参数不同就断言函数不同；
2. 只置换 incoming weights，忘记逆置换 outgoing weights；
3. 对 ReLU 使用负 scaling；
4. 把 symmetry-induced flatness 当泛化证据；
5. 对未经对齐的独立模型直接逐参数平均；
6. 把 parameter permutation 与 input permutation equivariance 混淆；
7. 宣称“只有置换和缩放”却不写架构与非退化条件；
8. 用 raw weight norm/Euclidean distance 比较功能而不审计 gauge。

## 十七、本节回顾与掌握标准

> [!summary]
> - $\Phi:\Theta\to\mathcal F$ 通常多对一；
> - hidden permutation 需 incoming 置换与 outgoing 逆置换配对；
> - ReLU positive homogeneity 产生连续 rescaling orbit；
> - dead/duplicate units 造成额外 non-identifiability；
> - loss flatness、posterior modes、weight averaging 都受 symmetry 影响；
> - 可辨识结论必须写成 modulo symmetry 且声明条件。

能推导两类 symmetry（A/C）、手算参数变换（B）、构造不可辨识反例（D），并设计 symmetry-aware merging/interpretability audit（E）。
