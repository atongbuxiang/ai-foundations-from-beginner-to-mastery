# 激活、分支、广播与梯度累加

> [!abstract] 本章主问题
> 真实网络的反向不只是一条链：激活用逐元导数门控 upstream cotangent，fan-out 将多条路径贡献相加，broadcast 的伴随沿复制轴求和，gather 的伴随是 scatter-add。这些规则都来自局部线性映射的转置，不是框架的零散特例。

## 课程位置与两遍学习路线

- **承接什么：** NN-09—12 已完成 affine 图的一条纯矩阵反向，但真实网络还包含 nonlinear gate、residual fan-out 与 broadcast parameter；
- **本页解决什么：** 把三者接到同一个 $Z$ 上，逐项区分 mask、path sum 和 sum-to-shape 各自为何出现；
- **后续为何需要：** NN-14 将把得到的 $Q$ 当作 logits，NN-15/16 再对同一 loss 选择 AD mode 并做独立验证。

**第一遍只开三本账。** activation 账记录哪些位置开门，branch 账记录每条 path 的贡献，broadcast 账记录 forward 复制了哪些轴；最后才把结果相加。

**第二遍再统一为伴随。** 从局部 differential 推出 elementwise mask、fan-out sum、broadcast reduction 与 gather scatter-add，并审计 kink/tie、alias 和并行归约边界。

### 问题链

1. ReLU backward 为什么只做逐位置门控，不混合特征？
2. residual 中同一个 $Z$ 走 direct 与 nonlinear 两路，如何避免漏项？
3. 长度为 2 的阈值 $c$ 广播到两行后，反向为何必须沿 batch 轴求和？
4. 零点处框架返回的数值究竟是 classical derivative 还是约定？
5. graph accumulation、microbatch accumulation 与 Adam state 有何本质区别？

> [!check] 第一遍停靠线
> 若你能由 mask 写出 $\bar Z=\left[\begin{smallmatrix}2&-1\\2&2\end{smallmatrix}\right]$ 与 $\bar c=(-1,-1)$，并指出二者分别用了 path sum 与 batch reduction，就可以进入 fused loss；不可微点和 storage alias 留到第二遍。

## 符号与对象账本

| 对象 | shape | 在 AI 计算图中的身份 | reverse 动作 |
|---|---|---|---|
| $Z$ | $2\times2$ | NN-12 的 pre-activation/logit precursor | 汇总 direct 与 ReLU 两路 |
| $c$ | $1\times2$ | 跨 batch 共享的 threshold/bias | 沿复制的 batch 轴求和 |
| $A=Z-\mathbf1c$ | $2\times2$ | shifted pre-activation | 保存 sign mask |
| $H=\operatorname{ReLU}(A)$ | $2\times2$ | nonlinear residual feature | upstream 乘局部 mask |
| $Q=Z+H$ | $2\times2$ | 下一页分类 logits | cotangent 同时发往两支 |

### 贯穿算例：ReLU 残差、零点约定与广播阈值

沿用 $X_\diamond$ 图产生的

$$
Z=\begin{bmatrix}5&2\\1&3\end{bmatrix},\qquad
c=\begin{bmatrix}2&2\end{bmatrix}.
$$

取 ReLU 在零点的程序导数为 $0$，则

$$
A=Z-\mathbf1c=\begin{bmatrix}3&0\\-1&1\end{bmatrix},\quad
H=\operatorname{ReLU}(A)=\begin{bmatrix}3&0\\0&1\end{bmatrix},\quad
Q=Z+H=\begin{bmatrix}8&2\\1&4\end{bmatrix}.
$$

为单独检查本节点，给定 $\bar Q=U=\left[\begin{smallmatrix}1&-1\\2&1\end{smallmatrix}\right]$。mask 为 $M=\left[\begin{smallmatrix}1&0\\0&1\end{smallmatrix}\right]$，所以

$$
\bar Z=U+U\odot M=\begin{bmatrix}2&-1\\2&2\end{bmatrix},\qquad
\bar c=-\mathbf1^T(U\odot M)=\begin{bmatrix}-1&-1\end{bmatrix}.
$$

## 核心公式七问：$\bar Z=\bar Q+\bar Q\odot\mathbf1_{A>0},\;\bar c=-\mathbf1^T(\bar Q\odot\mathbf1_{A>0})$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 同时闭合 residual fan-out、ReLU gate 和 broadcast threshold 的 VJP |
| 对象 | $\bar Q$ 与 $Q$ 同形，mask 与 $A$ 同形，$\bar c$ 必须回到 $1\times2$ |
| 来路 | $dQ=dZ+M\odot(dZ-\mathbf1dc)$ 与 Frobenius pairing |
| 步骤 | direct path 给一份 $\bar Q$，ReLU path 给 $\bar Q\odot M$，对 $c$ 再沿 batch 归约并带负号 |
| 读法 | identity 支路永远回传，nonlinear 支路只在 active positions 回传 |
| 检查 | $M=0$ 时 $\bar Z=\bar Q,\bar c=0$；shape 和复制轴必须闭合 |
| 去路 | residual network、gated MLP、shared bias、embedding scatter-add 与 fused classification head |

## 一、学习目标

1. 从 $H=\phi(Z)$ 推导 elementwise activation VJP；
2. 手算 ReLU、sigmoid、tanh 的局部反向；
3. 区分 kink 处的 classical derivative 与框架 convention；
4. 用一般 DAG 递推解释 branch accumulation；
5. 从 broadcast map 的伴随推出 sum-to-shape；
6. 推出 sum/mean/max reduction 的 VJP；
7. 理解 reshape、transpose、slice、gather 的反向轴语义；
8. 区分 graph accumulation、microbatch accumulation 与 optimizer state；
9. 审计 residual、weight sharing、mask 和 in-place mutation。

## 二、逐元激活的统一 VJP

若 $H=\phi(Z)$ 且 $\phi$ 逐元作用，给定 $\bar H=G$，微分是

$$
dH=\phi'(Z)\odot dZ.
$$

与 $G$ 配对：

$$
dL=\langle G,dH\rangle
=\langle G\odot\phi'(Z),dZ\rangle,
$$

所以

$$
\boxed{\bar Z=G\odot\phi'(Z).}
$$

Hadamard product 表明每个位置的 upstream signal 被本地斜率独立门控；没有特征轴混合。

## 三、三个基本激活

| forward | derivative | backward 解释 |
|---|---|---|
| $\operatorname{ReLU}(z)=\max(0,z)$ | $1$ if $z>0$，$0$ if $z<0$ | active positions 通过，inactive positions 归零 |
| $\sigma(z)=1/(1+e^{-z})$ | $\sigma(z)(1-\sigma(z))$ | 可用 forward output 作 cache |
| $\tanh z$ | $1-\tanh^2z$ | 两端饱和时斜率趋 0 |

sigmoid 导数最大为 $1/4$，tanh 导数最大为 $1$。这只是单节点局部上界；深网络还要乘权重 Jacobian，不能由此单独断言整体梯度。

## 四、不可微点的语义

ReLU 在 $z=0$ 左导数为 0、右导数为 1，无唯一 classical derivative。AD primitive 必须选一个规则，常见选择是 0。max 在 tie 处也需决定把 cotangent 给第一个 winner、平分，还是按别的 convention。

因此必须分清：

- 数学函数在该点是否可微；
- primitive 在该点定义了哪个 backward；
- optimization 是否接受这个 surrogate/subgradient convention。

## 五、分支为何必须累加

若同一 $x$ 进入 $a=f(x)$ 和 $b=g(x)$，后续 $L=q(a,b)$，则

$$
\bar x=J_f(x)^T\bar a+J_g(x)^T\bar b.
$$

这是 total differential 对 $dx$ 的系数。residual block $y=x+F(x)$ 也是两分支：

$$
\bar x=\bar y+J_F(x)^T\bar y.
$$

直接支路传回 $\bar y$，但这并不保证 $I+J_F$ 在任意深度下条件良好。

## 六、Broadcast 的伴随是 Sum-to-Shape

设 $b:[d]$ 在 forward 中广播为 $B(b):[B,T,d]$，

$$
B(b)_{itj}=b_j.
$$

对任意 upstream $G$，

$$
\langle G,B(db)\rangle
=\sum_{i,t,j}G_{itj}db_j
=\sum_j\left(\sum_{i,t}G_{itj}\right)db_j.
$$

所以

$$
\boxed{B^*(G)_j=\sum_{i,t}G_{itj}.}
$$

算法上是把 upstream 沿 forward 中被复制的轴求和，直到形状回到原 tensor。如果原形状是 `[1,T,1]`，只对 batch 和 feature 轴求和，不能“一律对所有轴求和”。

## 七、Reduction 的反向

- $s=\sum_i x_i$：$\bar x_i{+}=\bar s$，即把 cotangent 广播回去；
- $m=n^{-1}\sum_i x_i$：$\bar x_i{+}=\bar m/n$；
- $y_j=\sum_iX_{ij}$：沿被约去的轴恢复 singleton dimension 后 broadcast；
- $m=\max_i x_i$：非 tie 时只给 winner，tie 处依 primitive convention。

forward broadcast 与 forward sum 是一对伴随操作；一边的复制在反向变成另一边的聚合。

## 八、布局算子也有 VJP

| forward | reverse |
|---|---|
| reshape | reshape 回输入 shape |
| transpose/permute | inverse permutation |
| slice | 把 cotangent scatter 回原位置，其余填 0 |
| concatenate | 按原边界 split |
| split | 按原轴 concatenate |
| gather by index | scatter-add to source indices |

gather 的索引若重复，scatter 必须使用 add，不是 assignment。embedding lookup 中同一 token 出现多次，对应 row gradient 正是多处贡献之和。

## 九、完整手算：激活分支加标量广播

定义

$$
h_i=\operatorname{ReLU}(x_i)+bx_i,
\qquad L=\sum_i h_i.
$$

取 $x=(-1,2)$、$b=3$，则

$$
h=(-3,8),\qquad L=5.
$$

从 $\bar h=(1,1)$ 回传：ReLU 支路对 $x$ 贡献 $(0,1)$，product 支路贡献 $(3,3)$，因而

$$
\bar x=(3,4).
$$

$b$ 被广播到两个位置，所以

$$
\bar b=\sum_i\bar h_i x_i=-1+2=1.
$$

这一例同时出现 activation mask、fan-out sum 和 broadcast reduction。

## 十、三种“梯度累加”不要混用

1. **图内累加**：同一 value 的多条 downstream paths 在一次 backward 中相加；
2. **microbatch accumulation**：多次 backward 的 parameter gradients 在 optimizer step 前累加；
3. **optimizer state accumulation**：Adam 的一阶/二阶 moving averages 是跨 step 的状态。

前两者的 sum/mean scale 必须与目标 loss 对齐；第三种已是 optimization algorithm，不是链式法则。

## 十一、Mask、Dropout 与离散决定

对 fixed mask $m$，$y=m\odot x$的 VJP 是 $\bar x=m\odot\bar y$。dropout train mode 还包含存活率缩放；eval mode 通常是 identity。mask 的随机采样通常不对 probability parameter 直接可微；把 mask 当 constant 求导和对采样分布求导是两个问题。

## 十二、Alias 与 In-place 的系统边界

若两个 views 共享 storage，对其中一个 in-place 写可同时改变另一个的 primal。若 backward 需原值构造 activation mask 或局部系数，就会产生错误。可靠系统使用 version counter、functionalization 或显式 copy，并在 custom VJP 中记录 alias contract。

## 十三、验证协议

1. 对每个 primitive 做 shape/type check；
2. 对非 kink 点做 directional finite difference；
3. 对 broadcast 列出原 shape 与被复制轴；
4. 对 branch 分别记录每条贡献，再核对和；
5. 对 repeated indices 测 gather/scatter-add；
6. 对 microbatch 测 sum-loss 加倍与 mean-loss 不变性；
7. 在 kink/tie 处只验证文档化 convention，不声称 classical derivative。

## 十五、常见错误

1. 在 fan-out 处用 assignment 覆盖前一支贡献；
2. 对 broadcast tensor 在错误轴求和；
3. mean backward 忘记或重复除 element count；
4. gather 有重复 index 时使用 scatter assignment；
5. 把 ReLU zero convention 当作可微性定理；
6. 把 microbatch accumulation 与 Adam moving average 混为一件事；
7. 忽略 views 的 storage alias。

## 十六、回顾与练习

> [!summary]
> 反向规则可统一为“对 forward 局部线性化取伴随”：逐元映射乘 slope，分支贡献求和，broadcast 沿复制轴归约，gather 用 scatter-add。
