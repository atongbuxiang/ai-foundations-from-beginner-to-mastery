# 线性层与仿射层的反向传播

> [!abstract] 本章主问题
> 对 row-batch affine layer $Z=XW+\mathbf1b$，给定 upstream cotangent $G=\partial L/\partial Z$，三个 VJP 是 $\bar X=GW^T$、$\bar W=X^TG$、$\bar b=\mathbf1^TG$。公式来自同一个微分与 Frobenius 配对；transpose 和 reduction 都由形状与线性算子伴随强制决定。

## 一、前向与形状
$$X:[B,d_{in}],\quad W:[d_{in},d_{out}],\quad b:[d_{out}],$$
$$Z=XW+\mathbf1_Bb:[B,d_{out}].$$
令 upstream $G=\bar Z$ 与 $Z$ 同形。

## 二、微分一次写全
$$dZ=dXW+XdW+\mathbf1_Bdb.$$
标量 loss 的 differential 为
$$dL=\langle G,dZ\rangle_F=\operatorname{tr}(G^TdZ).$$
分别隔离 $dX,dW,db$ 即可读取 gradients。

## 三、输入梯度
$$\operatorname{tr}(G^TdXW)=\operatorname{tr}((GW^T)^TdX),$$
所以
$$\boxed{\bar X=GW^T:[B,d_{in}].}$$
它把 output-feature cotangent 经 weight transpose 拉回 input-feature space。

## 四、权重梯度
$$\operatorname{tr}(G^TXdW)=\operatorname{tr}((X^TG)^TdW),$$
所以
$$\boxed{\bar W=X^TG:[d_{in},d_{out}].}$$
分量式
$$\bar W_{kj}=\sum_{i=1}^BX_{ik}G_{ij}$$
表明每个样本贡献 input activation 与 output error signal 的 outer product，batch 上求和。

## 五、Bias 梯度
$$\boxed{\bar b=\mathbf1_B^TG=\sum_{i=1}^BG_{i,:}:[d_{out}].}$$
forward broadcasting 的 transpose 是沿广播轴 reduction。若输入还有 time/spatial axes，共享 bias gradient 对所有这些位置求和。

## 六、完整数值手算
取
$$X=\begin{bmatrix}1&2\\-1&3\end{bmatrix},\quad
W=\begin{bmatrix}2&0\\1&-1\end{bmatrix},\quad
G=\begin{bmatrix}1&-2\\3&1\end{bmatrix}.$$
则
$$\bar X=GW^T=\begin{bmatrix}2&3\\6&2\end{bmatrix},$$
$$\bar W=X^TG=\begin{bmatrix}-2&-3\\11&-1\end{bmatrix},$$
$$\bar b=(4,-1).$$
三者分别与 $X,W,b$ 同形。

## 七、逐样本 Outer Product 解释
单样本 $x_i:[1,d_{in}]$、$g_i:[1,d_{out}]$ 的 weight contribution 是
$$x_i^Tg_i:[d_{in},d_{out}].$$
batch gradient为 $\sum_i x_i^Tg_i$。这解释了 microbatch accumulation、data parallel all-reduce 和 per-example gradient 的关系。

## 八、Sum 与 Mean Loss
若 $L_{mean}=B^{-1}\sum_i\ell_i$，则 $G$ 已包含 $1/B$，上述公式不再额外除一次。若 framework loss 使用 sum，gradient 会大 $B$ 倍。gradient accumulation 跨 microbatches 时必须先确定要复现 global sum 还是 global mean。

## 九、序列/空间张量
对 $X:[B,T,d_{in}]$，可把前两轴展平为 $N=BT$：
$$\bar W=\sum_{b,t}X_{bt,:}^TG_{bt,:},\qquad \bar b=\sum_{b,t}G_{bt,:}.$$
$\bar X_{bt,:}=G_{bt,:}W^T$，不会跨 token 混合；参数共享只在 parameter gradients 中聚合。

## 十、接 Activation
若 $H=\phi(Z)$，先由上游 $\bar H$ 得
$$G=\bar Z=\bar H\odot\phi'(Z),$$
再代入 affine backward。必须区分 upstream 对 $H$ 的 gradient 与经过 activation VJP 后对 $Z$ 的 gradient。

## 十一、Column-vector Convention
若单样本写 $z=Wx+b$，则 $W:[d_{out},d_{in}]$，公式形式相应为 $\bar x=W^T\bar z$、$\bar W=\bar z x^T$。它与 row convention 等价，但不可在一次推导中混用。

## 十二、框架 Storage
PyTorch `Linear` 常存 weight `[out,in]`，其 forward 相当于 $XW_{store}^T+b$。autograd 返回与 storage 同形的 gradient。比较数学公式前必须先转成共同 layout。

## 十三、数值与系统边界
- low-precision $X^TG$ reduction 可能积累误差；
- large $BT$ 使 bias/weight gradient overflow；
- fused kernels 可能改变加法顺序；
- sparse/quantized forward 的 backward 可能使用 surrogate 或 higher precision；
- distributed all-reduce 的 scale 必须与 loss reduction 一致。

## 十四、验证协议
1. small integer hand case；
2. shape equality；
3. finite difference 对 $X,W,b$ 各随机方向；
4. dot test 比较 forward linearization 与 VJP；
5. batch duplication test：sum loss 应倍增 gradient，mean loss 应保持；
6. broadcast axes test。

## 十六、回顾与练习
> [!summary]
> $dZ=dXW+XdW+1db$；$\bar X=GW^T$，$\bar W=X^TG$，$\bar b=\sum G$。transpose 与 sum 都由伴随和 shape 强制决定。
