# 标量链式法则与反向传播递推

> [!abstract] 本章主问题
> 对标量损失 $L$，反向传播把输出 cotangent $\bar L=1$ 作为种子，沿计算图逆拓扑序调用每个节点的局部 VJP。若一个值通向多条支路，其 adjoint 是所有子节点贡献之和。它是链式法则的动态规划，不是求逆、不是 gradient descent，也不是只适用于神经网络的生物启发规则。

## 课程位置与两遍学习路线

- **承接什么：** NN-10 已能为单个 primitive 做 VJP，但尚未说明怎样在带分支的整张图中完整、无重复地组合贡献；
- **本页解决什么：** 从 scalar seed 出发建立逆拓扑递推，并证明 fan-out 节点的 adjoint 必须对所有 children 求和；
- **后续为何需要：** NN-12 会把贯穿图中的 affine VJP 展开成 $GW^T,X^TG,\sum G$，NN-13 再处理 activation、broadcast 与更多分支。

**第一遍只做一趟 reverse trace。** 在 forward 数值旁另开 adjoint 账本，从 $\bar L=1$ 开始逆序移动；每条边只产生局部贡献，共享节点只在所有 child 都处理后读取总和。

**第二遍再证明递推。** 从总微分线性性得到 children-sum，展开为 path-sum，再说明动态规划为何复用共同后缀而不用指数枚举路径。

### 问题链

1. 为什么 scalar loss 的 reverse seed 必须是 $1$？
2. 为什么 forward 用拓扑序，reverse 恰好用逆拓扑序？
3. 同一参数走两条 loss paths 时，gradient 为什么是和而不是任选一路？
4. path-sum 看似可能指数大，反向传播怎样共享中间 adjoint？
5. backprop、autodiff、gradient 与 optimizer 分别是什么对象？

> [!check] 第一遍停靠线
> 若你能从 $L=5.25$ 的贯穿图反算出 $\bar Z=R$、正则分支贡献 $\lambda W_\diamond$，并明确 $\bar W$ 要用 `+=` 合并两路，就可以进入 affine backward；一般 DAG 证明留到第二遍。

## 符号与对象账本

| 对象 | 在 AI 训练图中的身份 | 何时就绪 | 易混淆项 |
|---|---|---|---|
| $\bar v=\partial L/\partial v$ | 与 $v$ 同形的 cotangent | 所有 children 已回传后 | primal value $v$ |
| $\bar L=1$ | scalar output seed | reverse 起点 | loss 数值 $L$ |
| local VJP | 一条 operation 的 pullback | 其输出 cotangent 就绪后 | optimizer update |
| edge contribution | 一条 child path 的局部项 | 处理该 edge 时 | 完整 node adjoint |
| `+=` accumulator | fan-out/shared parameter 的总和 | 全部贡献累加后 | loss mean 的缩放规则 |

### 贯穿算例：共享权重必须合并两条路径

沿用 $X_\diamond$ 任务。data branch 给 $\bar R=R$、$\bar Z=R$；regularization branch 给

$$
\bar W_{\rm reg}=\lambda W_\diamond
=\begin{bmatrix}0.5&-0.5\\1&0.5\end{bmatrix}.
$$

prediction branch 经 affine 节点给

$$
\bar W_{\rm data}=X_\diamond^TR
=\begin{bmatrix}2&-1\\1&4\end{bmatrix}.
$$

因此共享参数的总 adjoint 是

$$
\bar W=\bar W_{\rm data}+\bar W_{\rm reg}
=\begin{bmatrix}2.5&-1.5\\2&4.5\end{bmatrix}.
$$

只回传 data branch 会漏掉 weight decay；把两个 $W$ 当成独立参数则会破坏原始程序语义。

## 核心公式七问：$\bar v=\sum_{c\in\operatorname{Ch}(v)}(\partial c/\partial v)^T\bar c$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 汇总一个值经所有下游路径对 scalar loss 的一阶影响 |
| 对象 | $v$ 是 parent value，$c$ 遍历直接 children，$\bar c$ 已在逆序中就绪 |
| 来路 | $dc$ 对 $dv$ 的各局部线性作用进入 $dL$ 后，由线性性按路径相加 |
| 步骤 | 逆拓扑访问 child，调用局部 VJP，把 contribution 用 `+=` 写入 parent accumulator |
| 读法 | 每条 outgoing edge 都投一票，node adjoint 是全部票的总和 |
| 检查 | chain 只有一项；fan-out 有多项；无 loss path 的节点 adjoint 为零 |
| 去路 | 参数共享、残差连接、RNN/BPTT、multi-task loss 与 distributed gradient accumulation |

## 一、符号合同
对图中任意中间值 $v$，定义 adjoint/cotangent
$$
\bar v:=\frac{\partial L}{\partial v}
$$
（向量时理解为 VJP 返回的同形数组）。标量输出 seed 为
$$\bar L=\frac{\partial L}{\partial L}=1.$$

## 二、标量链式法则
若 $z=f(x)$、$L=g(z)$，则
$$\frac{dL}{dx}=\frac{dL}{dz}\frac{dz}{dx}.$$
多层链 $x_0\to x_1\to\cdots\to x_L$ 有
$$\bar x_{l-1}=J_{f_l}(x_{l-1})^T\bar x_l.$$
右端正是局部 VJP。

## 三、一般 DAG 递推
若节点 $v$ 的 children 为 $c\in\operatorname{Ch}(v)$，则
$$
\boxed{
\bar v=\sum_{c\in\operatorname{Ch}(v)}
\left(\frac{\partial c}{\partial v}\right)^T\bar c.
}
$$
每条 outgoing edge 产生一份贡献；sum 来自总微分的线性性，而不是框架的经验约定。

## 四、为何按逆拓扑序
计算 $\bar v$ 前必须先得到所有 children 的 adjoints。forward 拓扑序让 parents 先就绪；reverse 拓扑序恰让 children 先就绪。若过早回传一条支路而未累加另一条，gradient 会缺项。

## 五、完整分支手算
定义
$$a=xy,\qquad b=x+y,\qquad c=a+b,\qquad L=\tfrac12c^2.$$
在 $x=2,y=3$，forward 为 $a=6,b=5,c=11,L=60.5$。

reverse：
$$\bar L=1,\qquad \bar c=c=11,$$
$$\bar a=11,\qquad\bar b=11.$$
$x$ 有两条路径：
$$
\bar x=\bar a\frac{\partial a}{\partial x}+
\bar b\frac{\partial b}{\partial x}
=11\cdot3+11\cdot1=44.
$$
同理
$$\bar y=11\cdot2+11=33.$$
直接展开 $L=\frac12(xy+x+y)^2$ 求导可验证。

## 六、Path-sum 解释
展开递推可得
$$
\frac{\partial L}{\partial v}
=\sum_{p:v\leadsto L}\prod_{e\in p}J_e^T
$$
作用于 output seed。反向动态规划共享重叠后缀，不逐路径枚举；否则分支图路径数可指数增长。

## 七、常用局部规则
| forward | 对输入的 reverse contribution |
|---|---|
| $z=x+y$ | $\bar x{+}=\bar z,\ \bar y{+}=\bar z$ |
| $z=xy$ | $\bar x{+}=y\bar z,\ \bar y{+}=x\bar z$ |
| $z=\phi(x)$ | $\bar x{+}=\phi'(x)\odot\bar z$ |
| $z=Ax$ | $\bar x{+}=A^T\bar z$ |
| $z=\sum_i x_i$ | $\bar x_i{+}=\bar z$ |

`+=` 强调一个变量可能收到多条贡献。

## 八、参数共享
若同一 $W$ 在 $T$ 个位置使用，
$$\bar W=\sum_{t=1}^T\bar W^{(t)}.$$
这适用于 convolution kernel、embedding row、RNN weight 和 tied input/output matrix。共享参数不是把每次调用的 gradient 求平均；sum/mean 由 loss reduction 决定。

## 九、Backprop 与 Gradient Descent 不同
backprop 计算给定 program 和 parameters 的 derivative；optimizer 使用 derivative 更新参数，例如 $\theta\leftarrow\theta-\eta\nabla L$。可以用 backprop 配 Adam、SGD 或不更新；也可用其他 derivative 方法配 gradient descent。

## 十、Backprop 与 Reverse-mode AD
backprop 常指神经网络上的 reverse accumulation；reverse-mode AD 是对一般 differentiable program 的更广框架。二者共享局部 VJP、tape 与逆拓扑递推。历史上反向累积思想早于 1986 神经网络论文；Rumelhart–Hinton–Williams 的重要作用包括展示 hidden representations 可由 error propagation 学得。

## 十一、向量输出需要 Seed
若最终输出 $y\in\mathbb R^m$ 而没有标量 loss，不存在唯一“gradient of vector”。给 seed $u$ 得 VJP $J_y^Tu$，等价于标量化 $u^Ty$ 的 gradient。形成 full Jacobian 需多个 independent seeds。

## 十二、停止梯度与截断
`stop_gradient(v)` forward 等于 $v$，但人为定义 VJP 为零；truncated BPTT 切断远期路径。它们改变求导程序，而不改变当前 forward 数值。报告结果时必须说明这种 surrogate gradient contract。

## 十三、数值与验证
深层 reverse 是 Jacobian-transpose products，可能消失、爆炸或在 mixed precision 下 overflow。正确局部公式也不保证数值稳定。验证使用直接展开小图、finite difference、JVP/VJP dot test、逐节点 hooks 与共享贡献计数。

## 十五、回顾与练习
> [!summary]
> reverse mode = scalar seed + reverse topological order + local VJP + fan-out sum；它高效复用路径后缀，但需要 forward cache 或重算。
