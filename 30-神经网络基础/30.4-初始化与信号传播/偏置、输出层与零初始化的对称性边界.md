# 偏置、输出层与零初始化的对称性边界

> [!abstract] 本章主问题
> “神经网络不能零初始化”说得太粗。真正危险的是：一组可置换 hidden units 的完整参数 bundle 被放在同一个对称点，而且前向、loss、optimizer 与状态更新都保持该对称性。Bias 通常可以为零；单层线性/逻辑模型可从零离开；输出头置零会暂时阻断上游梯度但未必永久退化；残差分支末层置零又有 skip path 保护。必须逐个计算第一步梯度。

## 课程位置与两遍学习路线

- **承接什么：** NN-30 检查线性映射与 derivative mask 的 rank；本页改问参数是否因为置换对称和零 Jacobian 而永远不能分工；
- **本页解决什么：** 不背“能/不能零初始化”口诀，而是对 hidden bundle、bias、single layer、zero head 和 residual zero-last 分别计算 step-0 gradient；
- **后续为何需要：** NN-32 的 Fixup 正是一种精心设计的 zero-last staged learning，只有 skip path 和完整 recipe 才使它不等于全零 MLP。

**第一遍只算第一步。** 从 loss adjoint 往前乘：哪个参数梯度非零，哪个 activation gradient 被零权重截断，skip path 是否另外传递了 1。

**第二遍再看对称群。** 判断完整 unit bundle 是否相同、loss 是否置换不变、optimizer state 是否也相同，以及 dropout/noise 是显式独立还是不可复现的偶然扰动。

### 问题链

1. 为什么要比较 $(w_j,b_j,v_j)$ 完整 bundle，而不能只看 incoming row？
2. deterministic SGD/Adam 为什么会保持两个完全相同 units 的差为零？
3. zero output head 为什么自己能在第一步学习，却让 encoder 首步冻结？
4. residual branch 末层为零时，主路梯度为什么仍能直通？
5. 随机噪声偶然打破对称，为什么不是一个可接受的初始化合同？

> [!check] 第一遍停靠线
> 若你能在 $\mathcal I_\square$ 的两维 head slice 中，用 $h=(1,-1)$、$w_{\mathrm{out}}=0$、$\delta=1$ 算出 $\nabla w_{\mathrm{out}}=(1,-1)$ 与 $\nabla h=(0,0)$，并解释 residual skip 为何仍返回 upstream $1$，就掌握了分类判据。

## 符号与对象账本

| 对象 | 定义 | AI 模型中的身份 | 零初始化时要问 |
|---|---|---|---|
| $\theta_j=(w_j,b_j,v_j)$ | hidden unit 完整 bundle | 可置换的 feature unit | bundle 是否全同 |
| $h$ | encoder/branch feature | zero head 的输入 | 是否非零且非同质 |
| $\delta$ | output cotangent | loss 传回的误差 | class/sample 方向是否有区分 |
| $W_{\mathrm{out}}$ | output head | 可 staged learning 的末层 | 是否暂时截断 encoder gradient |
| $I+J_F$ | residual block Jacobian | skip + branch 双路传播 | branch 为零时 identity 是否仍在 |

### 贯穿算例 $\mathcal I_\square$：zero head 与 zero-last 的第一步

从 $4\to8$ 层中取两个已有区分的 hidden features，简化为

$$
h=(1,-1)^T,qquad
w_{\mathrm{out}}=(0,0)^T,qquad
\delta=\frac{\partial L}{\partial \hat y}=1.
$$

对 $\hat y=w_{\mathrm{out}}^Th$，

$$
\nabla_{w_{\mathrm{out}}}L
=\delta h
=(1,-1)^T,
$$

$$
\nabla_hL
=w_{\mathrm{out}}\delta
=(0,0)^T.
$$

所以 head 第一步就能离开零；若学习率 $\eta=0.1$，则 gradient descent 后 $w_{新}=(-0.1,0.1)^T$。但 encoder 在 step 0 确实没有这条 head 的梯度。

对 residual block $y=x+w_{最后}^Th$，令 $w_{最后}=0$。末层仍收到 $(1,-1)$，branch 早期层首步仍收到 0，但 skip path 给

$$
\frac{\partial L}{\partial x}=\delta=1.
$$

这正是 zero-last residual 与全零串行 MLP 的结构差异：前者有 identity path 保护整网信号，后者可能连主路都被零权重截断。

## 核心公式七问：$\theta_1^{(0)}=\theta_2^{(0)}\Longrightarrow\theta_1^{(t)}=\theta_2^{(t)}$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 表达对称模型在置换等变 deterministic update 下的不变对角线 |
| 对象 | 两个可置换 hidden units 的完整 parameter + optimizer-state bundle |
| 来路 | loss 的 permutation invariance 使对称点上两组 gradients 相同 |
| 步骤 | 识别 symmetry→比较完整 bundle→算 step-0 gradient→检查 optimizer/noise 是否等变 |
| 读法 | 差值初始为 0 且每步更新差也为 0，units 就无法自发分工 |
| 检查 | incoming 相同但 outgoing 独立时不得误报完整 bundle 对称 |
| 去路 | Fixup/zero-last、ReZero、mixture expert symmetry 与 permutation quotient |

### AI / 系统对应

相同的判据会出现在 attention heads、MoE experts、ensemble members、class heads 与 adapter branches 中。审计时不只保存 parameter seed，还要保存 optimizer moments、dropout mask 语义和 distributed kernel 的确定性；否则“对称被打破”可能只是不可复现的系统噪声。

## 一、Hidden-Unit Permutation Symmetry

考虑一隐藏层标量输出网络

$$
f(x)=\sum_{j=1}^m v_j\phi(w_j^Tx+b_j)+c.
$$

任意 permutation $\pi$ 同时重排

$$
(w_j,b_j,v_j)\mapsto(w_{\pi(j)},b_{\pi(j)},v_{\pi(j)})
$$

都不改变函数。每个 hidden unit 的完整 bundle 是

$$
\theta_j=(w_j,b_j,v_j),
$$

而不只是 incoming weight $w_j$。

## 二、对称初始化为何被 Deterministic SGD 保持

若两个 units 从

$$
\theta_1^{(0)}=\theta_2^{(0)}
$$

开始，且 loss 对交换二者不变，那么在可微点

$$
\nabla_{\theta_1}\mathcal L
=\nabla_{\theta_2}\mathcal L.
$$

相同学习率的 SGD 更新给出

$$
\theta_1^{(1)}-\theta_2^{(1)}
=(\theta_1^{(0)}-\theta_2^{(0)})
-\eta(\nabla_{\theta_1}\mathcal L-\nabla_{\theta_2}\mathcal L)
=0.
$$

归纳可知它们永远相同。宽度 $m$ 的 layer 于是表现得像一个 unit 的复制，不能利用完整表达能力。

> [!warning] 对称 bundle 才是判据
> 只把两个 incoming rows 初始化成同一值、但让 outgoing weights 独立随机，完整 bundle 已不相同，反向信号可能不同。不能只看某一个矩阵就宣布对称一定保持。

## 三、全零 MLP 的第一步梯度

写成

$$
h=\phi(W_1x+b_1),
\qquad
\hat y=W_2h+b_2.
$$

令输出 adjoint 为 $\delta_2=\partial\mathcal L/\partial\hat y$。则

$$
\nabla_{W_2}\mathcal L=\delta_2h^T,
$$

$$
\delta_1=(W_2^T\delta_2)\odot\phi'(W_1x+b_1),
\qquad
\nabla_{W_1}\mathcal L=\delta_1x^T.
$$

若 $W_1=W_2=b_1=0$：

- 对 tanh 或常见 ReLU 约定，$h=0$，故 $\nabla W_2=0$；
- 因 $W_2=0$，必有 $\delta_1=0$，故 $\nabla W_1=0$；
- 通常只有 output bias $b_2$ 能先更新。

网络不只是“units 相同”，而是绝大多数权重根本没有第一步信号。

## 四、Sigmoid 为什么也没有真正解决

Sigmoid 满足 $\sigma(0)=1/2$，所以全零时

$$
h=\frac12\mathbf 1,
$$

输出权重可收到非零梯度。但每个 hidden coordinate 完全相同，$W_2$ 的对应 columns 在对称任务/更新下以相同方式演化；随后传回 $W_1$ 的信号仍保持 unit 对称。结果不是永久全零，却仍可能退化成一个复制单元。

## 五、为什么 Bias 通常可以初始化为零

若 $W_1$ 的 rows 已独立随机，则即使

$$
b_1=0,
$$

不同 units 的 preactivations $w_j^Tx$ 通常不同，permutation symmetry 已由 weights 打破。Bias 的主要作用是平移 activation threshold，不承担唯一的 symmetry breaking 责任。

但“bias 全零安全”也有边界：gate bias、forget gate、output prior、class imbalance 或 residual scale 可能需要任务/架构特定初值；这是工作点选择，不是 hidden-unit permutation 的问题。

## 六、单层线性与 Logistic 模型可从零离开

线性回归

$$
\hat y=Xw+b,
\qquad
\nabla_w\mathcal L=X^T(Xw+b-y)
$$

在 $w=b=0$ 时通常为 $-X^Ty\ne0$。Logistic regression 在 $w=b=0$ 时预测 $p_i=1/2$，梯度

$$
\nabla_w\mathcal L=X^T(p-y)
$$

也通常非零。这些模型没有一层多个 hidden units 的内部 permutation collapse；零初值是否慢或病态是优化问题，不是同一种对称性障碍。

## 七、Zero Output Head：可学，但第一步冻结 Encoder

设 encoder 已产生非零且非同质的 $h$，只令 output head

$$
W_{\mathrm{out}}=0.
$$

则

$$
\nabla_{W_{\mathrm{out}}}\mathcal L
=\delta_{\mathrm{out}}h^T
$$

通常非零，所以 head 会在第一步离开 0；但

$$
\nabla_h\mathcal L
=W_{\mathrm{out}}^T\delta_{\mathrm{out}}=0,
$$

所以 encoder 在第一步没有来自该 head 的梯度。第二步以后，随着 head 非零，上游梯度恢复。是否接受这一 one-step delay，取决于 optimizer、warmup、多任务 head 与训练协议。

对于 softmax classifier，虽然所有 class logits 初始相同，error $p-y$ 因 label coordinate 不同，通常会让不同 class rows 得到不同更新；不能把 class symmetry 与 hidden-unit symmetry混为一谈。

## 八、Residual Branch Last Layer Zero：Skip Path 改变结论

残差块

$$
y=x+F(x;\theta)
$$

若 $F$ 的最后一层权重置零，则初始化时 $F(x)=0$、$y=x$。主路径仍传递 activation 与 gradient：

$$
\frac{\partial y}{\partial x}
=I+\frac{\partial F}{\partial x}=I
$$

（若 branch Jacobian 因末层为零而为 0）。末层本身可从其输入 activation 与 upstream gradient 获得更新；branch 更早层通常第一步被零末层阻断，之后再逐渐获得梯度。这是受 identity skip 保护的 staged learning，不等于把普通串行 MLP 全部置零。

## 九、Optimizer、噪声与状态也必须纳入对称合同

若 Adam 的两个 units 从相同 parameter、相同 gradient 和相同 moment state 开始，其更新仍相同。Mini-batch SGD 本身不会自动打破精确 unit symmetry。Dropout、独立噪声或非确定性 kernel 可能扰动对称点，但：

- 依赖浮点噪声没有可复现保证；
- noise 很小可能只缓慢分离；
- 某些 shared mask 仍保持对称；
- symmetry broken 不等于尺度与优化良好。

正确做法是显式随机初始化需要区分的参数，而不是期待事故救场。

## 十、一个逐参数的判断表

| 对象 | 零初始化常见结论 | 必查条件 |
|---|---|---|
| hidden weights | 通常危险 | 完整 unit bundle 是否相同 |
| hidden bias | 通常可行 | weights 是否已打破对称；gate prior |
| 单层 linear/logistic | 可从零学习 | 初始 loss gradient 是否非零 |
| output head | head 可学，上游首步冻结 | hidden feature 是否非零；任务 error |
| residual branch last layer | 可作为近 identity 初值 | skip path、branch input、后续梯度 |
| padding embedding row | 可有意固定为零 | 是否设置 `padding_idx`/mask |

## 十二、可复现实验

用两隐藏单元 MLP 建立四组初值：全零、相同常数 bundle、incoming 相同但 outgoing 独立、完整随机。每步记录

$$
\|w_1-w_2\|,
\quad |b_1-b_2|,
\quad |v_1-v_2|,
\quad \|\nabla w_1-\nabla w_2\|.
$$

再比较 zero head、random head 与 residual zero-last-layer 的第一、第二步 gradient norm。固定数据、seed、optimizer state 和 ReLU-at-zero 约定，避免把实现差异误当理论反例。

> [!summary]
> 零初始化是否可用，取决于完整 symmetry orbit 与第一步计算图。Hidden bundle 全同会被等变的 deterministic optimizer 保持；bias、单层模型、输出头和 residual branch last layer 分别有不同的梯度合同，不能用一句口诀代替推导。
