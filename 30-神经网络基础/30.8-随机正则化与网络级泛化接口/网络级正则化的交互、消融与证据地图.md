# 网络级正则化的交互、消融与证据地图

> [!abstract] 本章主问题
> 现代网络很少只用一种正则化：augmentation、Mixup、Label Smoothing、Dropout、DropPath、weight decay、gradient penalty、early stopping 和 consistency loss 常同时存在。它们作用于 target、数据分布、随机函数、参数 update 或 function derivative，因而联合目标通常不是“几个独立好处相加”。要识别贡献，必须先写统一随机目标，再用 factorial design 估计 interaction；同时区分固定超参下的组件效应、各方法重新调参后的最佳可达效应，并分开记录 objective、optimization、generalization、calibration/uncertainty、robustness/shift 与 system 六本账。

## 课程位置与两遍学习路线

- **承接什么：** NN-57—63 已分别给出 activation/path 随机性、target replacement、vicinal interpolation 与 derivative control；
- **本页解决什么：** 把这些方法放入一张对象—机制—指标地图，并用 factorial design 识别条件效应和 interaction；
- **后续为何需要：** 本页是 30.8 与 64 节神经网络基础的卷终出口，为后续 cumulative evidence gate、架构审计和真实训练实验提供合同。

**第一遍只建立五位置地图与 $2\times2$ 表。** 先判断方法作用在 target、input/hidden、activation/path、parameter/update 还是 function，再计算 risk interaction。

**第二遍再做研究设计。** 区分 fixed-policy、retuned-policy、matched-budget，建立 exact—local—mechanism—benchmark—deployment 证据阶梯，并预注册随机种子与统计检验。

### 问题链

1. 两个 regularizers 分别直接改变哪个数学对象？
2. 它们在 target 层可交换，是否意味着训练 dynamics 与最终风险也相同？
3. 单独有效的两个组件联合时，风险改变量为什么不必相加？
4. one-at-a-time ablation 能估计哪个条件效应，又遗漏哪些 interaction？
5. 机制证据、benchmark gain 与部署改善之间还缺哪些独立证据？

## 符号与对象账本

| 干预位置 | 本卷共享对象 | 精确可验收量 | 仍需经验验收量 |
|---|---|---|---|
| activation/path | $q=1/2$ 的 masks | mean、covariance、active depth | 泛化、校准、延迟 |
| target | $t_{0.1}$ | simplex、CE gradient、finite margin | 原始概率校准、蒸馏质量 |
| input/hidden | $(\widetilde x,\widetilde y)$ | convexity、target affine identity | 语义有效性、shift risk |
| function | $J_f=W$ | operator/Frobenius norm、probe estimator | 全局鲁棒性、certificate tightness |
| parameter/update | $L_2$/AdamW 等 | objective 或 update equation | 最佳调参后的风险与成本 |

### 贯穿算例 $\mathcal D_\square$：从局部等式到因子实验

前七页已经给出同一对象族的四类事实：

1. Dropout 在 $x=(2,1)$、$q=1/2$ 下保持均值并产生 activation variance $(4,1)$；
2. Label Smoothing 把 target 变为 $(14/15,1/30,1/30)$，有限 margin 为 $\log28$；
3. Mixup 在 $\lambda=1/4$ 下产生 $\widetilde x=(-1,1)$ 与 $\widetilde y=(1/4,3/4,0)$；
4. 对 $f(x)=Wx$，$\|J_f\|_2^2=(7+\sqrt{13})/2$，Hutchinson 两类 probe 平均为 $7$。

这些都是**对象层的精确事实**，还没有一个等价于“测试风险下降”。现在把 $A$ 定义为 target/data intervention，把 $B$ 定义为 stochastic/function intervention，并在完全相同的 train/eval protocol 下得到一组**纯教学用的假想 expected risks**：

$$
\begin{array}{c|cc}
 & B=0 & B=1\\\hline
A=0 & Y_{00}=0.30 & Y_{01}=0.27\\
A=1 & Y_{10}=0.26 & Y_{11}=0.20
\end{array}
$$

于是 $B$ 在 $A=0$ 时的 effect 是 $-0.03$，在 $A=1$ 时是 $-0.06$，difference-in-differences 为

$$
\boxed{
\Delta_{AB}
=(Y_{11}-Y_{10})-(Y_{01}-Y_{00})
=-0.06-(-0.03)=-0.03
}.
$$

因为这里指标是 risk，负值表示当前 protocol 下的额外降险；若指标改成 accuracy，符号解释会反过来。四个数是演示 interaction 计算的假想数据，不是任何真实任务的 benchmark 断言。

## 核心公式七问：正则交互

$$
\boxed{
\Delta_{AB}
=(Y_{11}-Y_{10})-(Y_{01}-Y_{00})
}.
$$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 测量 $A$ 的 effect 随 $B$ 状态改变多少 |
| 对象 | 同一 protocol 下四个 cell 的 expected evaluation quantity |
| 来路 | 两个条件差再作差，即 difference-in-differences |
| 步骤 | 冻结协议→运行四 cell→估 expected metric→算条件效应→算 interaction |
| 读法 | $\Delta_{AB}=0$ 才与该尺度上的加法一致；非零表示条件依赖 |
| 检查 | 指标方向、seed 配对、调参预算、compute、置信区间与 multiplicity |
| 去路 | factorial/fractional factorial、机制消融、部署证据地图与架构选择 |

### AI / 系统对应

真实模型中，Mixup 可能增加数据流水线成本，R-Drop 增加 forward 次数，Jacobian penalty 增加 double backward，DropPath 改变有效计算而 AdamW 改 update。公平实验至少分别给 fixed-policy、retuned-policy 和 matched-budget 结果，并同时记录训练吞吐、峰值显存、收敛步数、推理延迟、NLL/ECE 与 shift/robustness，而不是只保留最佳 accuracy。

## 二、统一随机目标

令原始样本为 $Z=(X,Y)\sim P$。训练时可能采：

- augmentation randomness $a$；
- pairing 与 interpolation randomness $m$；
- dropout/path randomness $r$；
- stochastic estimator/probe $v$。

把所有训练随机变量记为

$$
\xi=(a,m,r,v).
$$

输入/hidden transformation 记为 $A_\xi(X)$，target transformation 记为 $T_\xi(Y)$，随机网络记为 $f_\theta(\cdot;r)$。一个广义目标是

$$
\boxed{
\mathcal J(\theta)
=\mathbb E_{Z,\xi}
\left[
\ell\big(f_\theta(A_\xi(X);r),T_\xi(Y)\big)
\right]
+\sum_j\lambda_jR_j(\theta;Z,\xi).
}
$$

这个公式仍不包含 optimizer update。实际学习算法是

$$
(\theta_{t+1},s_{t+1})
=U(\theta_t,s_t,\widehat\nabla\mathcal J_t;\eta_t,\text{decay},\text{clip},\text{precision}),
$$

其中 $s_t$ 是 momentum/adaptive state。Objective 与 update 必须分账。

## 三、五个干预位置

| 位置 | 代表方法 | 直接改变什么 | 首要验收量 |
|---|---|---|---|
| Target | Label Smoothing、distillation | conditional target / loss gradient | target entropy、population bias |
| Input / Hidden | augmentation、Mixup | training distribution / vicinity | distance、semantic validity、pairing |
| Activation / Path | Dropout、DropPath | sampled function 与梯度路径 | moments、mask covariance、active compute |
| Parameter / Update | $L_2$、AdamW、constraints | objective curvature 或 update map | norm、update ratio、optimizer state |
| Function | Jacobian、consistency、adversarial | local output sensitivity | output object、norm、points/directions |

同一个方法可能跨多层：例如 R-Drop 既需要 activation randomness，又加 function-output consistency。

## 四、为什么联合效果通常不是加法

若单独方法 $A,B$ 的风险改变量分别是 $\Delta_A,\Delta_B$，不能默认

$$
\Delta_{A+B}=\Delta_A+\Delta_B.
$$

原因包括：

1. 二者改变同一个 target entropy 或 margin；
2. 一个改变另一个 penalty 的采样分布；
3. normalization state 把样本耦合；
4. 一个改变另一个方法的有效尺度；
5. optimizer/learning-rate optimum 移动；
6. compute 增加导致训练步数或 batch size 改变；
7. 两个随机源相关而非独立。

## 五、一个精确可交换式：Mixup × Label Smoothing

固定同一个 prior $u$，定义

$$
S_\epsilon(y)=(1-\epsilon)y+\epsilon u.
$$

对 mixed target $M_\lambda(y_i,y_j)=\lambda y_i+(1-\lambda)y_j$，

$$
\begin{aligned}
S_\epsilon(M_\lambda(y_i,y_j))
&=(1-\epsilon)\{\lambda y_i+(1-\lambda)y_j\}+\epsilon u\\
&=\lambda\{(1-\epsilon)y_i+\epsilon u\}
+(1-\lambda)\{(1-\epsilon)y_j+\epsilon u\}\\
&=M_\lambda(S_\epsilon(y_i),S_\epsilon(y_j)).
\end{aligned}
$$

所以 target affine maps 可交换。

> [!warning] 这只是局部代数
> 完整 pipeline 仍可能不交换：Mixup 改 input/hidden distribution；class-dependent smoothing 的 prior 不同；augmentation、BatchNorm 与 pairing order 也不同。即使 target 相同，optimization trajectory 仍可不同。

## 六、R-Drop：两个部件形成新联合目标

对同一个 $(x,y)$，用独立 Dropout masks $r_1,r_2$ 得

$$
p_1=f_\theta(x;r_1),
\qquad
p_2=f_\theta(x;r_2).
$$

一种明确、对称的合同是

$$
\begin{aligned}
L_{\rm task}
&=\frac12\{H(y,p_1)+H(y,p_2)\},\\
L_{\rm cons}
&=\frac12\{\operatorname{KL}(p_1\|p_2)
+\operatorname{KL}(p_2\|p_1)\},\\
L_{\rm RDrop}
&=L_{\rm task}+\beta L_{\rm cons}.
\end{aligned}
$$

它不是“把 batch 复制两遍”这么简单：第二项把两个 sampled functions 耦合。实现必须声明：

- masks 是否独立；
- KL 在 probabilities/log-probabilities 上怎样稳定计算；
- 两个方向是否都回传梯度、是否 stop-gradient；
- temperature、padding mask 与 reduction；
- BatchNorm/running state 是否被两次 forward 改写；
- 两倍 forward 的 compute 如何计账。

R-Drop 是交互的典型：Dropout randomness 与 consistency penalty 的联合效果不能由任一单独组推断。

## 七、$L_2$ Penalty 与 Weight Decay 的 Optimizer 边界

考虑 loss-side $L_2$ objective

$$
\mathcal J(\theta)=L(\theta)+\frac\lambda2\|\theta\|_2^2.
$$

普通 SGD update：

$$
\begin{aligned}
\theta_{t+1}
&=\theta_t-\eta_t(\nabla L(\theta_t)+\lambda\theta_t)\\
&=(1-\eta_t\lambda)\theta_t-\eta_t\nabla L(\theta_t).
\end{aligned}
$$

这与同尺度的 multiplicative weight decay 条件等价。

若 optimizer 使用 coordinatewise preconditioner $P_t$：

$$
\theta_{t+1}
=\theta_t-\eta_tP_t(\nabla L+\lambda\theta_t),
$$

则 loss-side $L_2$ 的 shrink 是 $-\eta_t\lambda P_t\theta_t$。Decoupled decay 则形如

$$
\theta_{t+1}
=(1-\eta_t\lambda)\theta_t-\eta_tP_t\nabla L.
$$

一般不相等。`weight_decay` 参数名不能替代 update equation。

## 八、Normalization 与 Scale Symmetry 的交互

若某层后接 scale-invariant normalization，正比例缩放 weight 可能几乎不改变 forward function，却改变：

- parameter norm；
- raw gradient norm；
- effective angular update；
- optimizer moments 与 epsilon 相对尺度；
- decay 的 radial dynamics。

所以“weight norm 变小”不一定表示函数 Lipschitz 或容量按同比例变小。应同时记录 function output、direction/update ratio 和 normalized operator。

## 九、Derivative Penalty 的采样分布会被别的方法改变

若 Jacobian penalty 在 training inputs 上计算：

$$
R_J=\mathbb E_{x\sim Q}\|J_f(x)\|^2,
$$

加入 Mixup 后 $Q$ 可能变为 chord distribution；加入 augmentation 后 $Q$ 变为 transformed distribution；加入 adversarial sampling 后是 worst-case-like distribution。

于是即使 penalty 公式和 $\lambda_J$ 不变，控制的空间位置已改变。比较时必须区分：

- penalty 只在 clean $x$；
- 只在 mixed/augmented $x$；
- clean 与 transformed 都算；
- 用相同还是独立随机变换。

## 十、DropPath × Residual Scaling 的精确二阶接口

Residual branch 写成

$$
x_{l+1}=x_l+\frac{b_l}{q_l}\alpha_lF_l(x_l).
$$

固定 $x_l$ 后，branch covariance 是

$$
\operatorname{Cov}
\left(\frac{b_l}{q_l}\alpha_lF_l(x_l)\mid x_l\right)
=\frac{1-q_l}{q_l}\alpha_l^2F_lF_l^\mathsf T.
$$

因此 $q_l$ 与 $\alpha_l$ 对 noise scale 是乘性交互。已有 LayerScale/Fixup/ReZero/DeepNorm 类尺度时，复制另一个模型的 DropPath rate 没有匹配二阶强度。

## 十一、给每种正则建立“强度账本”

不同方法的 hyperparameter 单位不可直接相加，但可记录其可观察强度：

| 方法 | 名义参数 | 可观察强度 |
|---|---|---|
| Label Smoothing | $\epsilon$ | target entropy、optimal margin |
| Mixup | $\alpha$ | $\lambda(1-\lambda)$、mixed distance |
| Dropout | $p$ | activation variance multiplier $p/q$ |
| DropPath | $q_l$ | active-depth law、branch covariance |
| Weight decay | $\lambda$ | per-step radial shrink、update ratio |
| Jacobian penalty | $\lambda_J$ | held-out Jacobian norm distribution |
| R-Drop | $\beta$ | inter-mask KL、extra forward cost |

这些强度不在同一量纲，不能压成一个“总正则系数”；它们用于发现重复压缩、过强组合与 train/eval mismatch。

## 十二、$2\times2$ Factorial Design

对两个二元方法 $A,B\in\{0,1\}$，令 $Y_{ab}$ 是同一 protocol 下的 expected evaluation risk。条件 effect：

$$
\Delta_A(B=0)=Y_{10}-Y_{00},
$$

$$
\Delta_A(B=1)=Y_{11}-Y_{01}.
$$

Interaction 定义为 difference-in-differences：

$$
\boxed{
\Delta_{AB}
=(Y_{11}-Y_{10})-(Y_{01}-Y_{00}).
}
$$

等价地，$A$ 的 effect 随 $B$ 改变多少。

### 12.1 完整数值例

假设 risk：

$$
Y_{00}=0.30,
\quad Y_{10}=0.26,
\quad Y_{01}=0.27,
\quad Y_{11}=0.20.
$$

在 $A=0$ 时加 $B$：

$$
Y_{01}-Y_{00}=-0.03.
$$

在 $A=1$ 时加 $B$：

$$
Y_{11}-Y_{10}=-0.06.
$$

所以

$$
\Delta_{AB}=-0.06-(-0.03)=-0.03.
$$

在这个 protocol 和 risk 指标下，$A,B$ 有额外的协同降险。但它不是跨超参、跨数据、跨 compute 的普遍 synergy。

## 十三、为什么 One-at-a-Time Ablation 不够

若 full model 含 $A,B,C$，只删除一个组件得到：

- full；
- no $A$；
- no $B$；
- no $C$。

这只能估计“在其他组件开启时删除该组件”的局部 effect；它看不到 $A$ 与 $B$ 在 $C=0$ 时的 behavior，也不能识别三阶 interaction。

对 $k$ 个二元组件，full factorial 有 $2^k$ cells。资源不足时可：

1. 先用机制图选择最可能交互的 pairs；
2. 做分阶段 screening；
3. 使用明确 alias structure 的 fractional factorial；
4. 对关键 pair 完整 $2\times2$；
5. 不把未估 interaction 默认为 0。

## 十四、三种不同的消融问题

### 14.1 Fixed-Policy Effect

保持其余 hyperparameters 完全不变，只开/关组件。回答：“在当前训练政策下，这个组件的边际作用是什么？”

缺点：关闭正则后 optimal LR/steps 可能改变。

### 14.2 Retuned-Policy Effect

每个 cell 使用相同 tuning budget 分别优化。回答：“允许合理重调后，每种政策的最佳可达表现是什么？”

缺点：effect 同时包含组件和 tuning response，不能当作纯机制效应。

### 14.3 Matched-Budget Effect

匹配 train FLOP、wall time、memory 或 number of examples。回答：“同资源约束下收益如何？”

三种结果都应报告，不能互相替代。

## 十五、随机性与配对设计

每个 cell 至少控制：

- initialization seed；
- data order 与 augmentation seed；
- Dropout/DropPath/Mixup streams；
- distributed shard；
- evaluation sampling。

使用 paired seeds 可降低 difference estimator variance，但要避免把本应独立的训练随机源错误同步。报告 seed-level results 与 interval，不只报 mean。

## 十六、Hyperparameter Search 也是实验处理

如果方法组搜索 100 个配置、baseline 只试 3 个，最终 validation best 有 selection advantage。必须记录：

- search space 与 prior；
- trial 数和 early termination；
- validation reuse 次数；
- selection metric；
- test 是否只在冻结方案后评估。

多个 regularizers 还增加 multiple-comparison risk。应保留独立 test，或采用 nested/held-out selection protocol。

## 十七、六本账：不要只报 Accuracy

### Objective

Task loss、各 penalty、target entropy、consistency divergence。

### Optimization

Train loss、time-to-target、gradient/update ratio、clipping、nonfinite、optimizer state。

### Generalization

Train–validation gap、held-out risk、NLL/accuracy、sample efficiency。

### Calibration / Uncertainty

Brier、NLL、reliability、selective risk；不把 confidence 直接命名为 uncertainty。

### Robustness / Shift

预声明 corruption、adversarial threat model、OOD/shift severity 与 classwise effect。

### System

Train/inference FLOP、wall time、throughput、peak memory、communication、storage、actual branch execution。

最终应画 Pareto frontier，而不是把异质指标压成一个未经论证的总分。

## 十八、五级证据阶梯

### Level 1：Exact Object / Objective

例如：Label Smoothing 的 loss 分解、Mixup target linearity、Dropout condition moments、$L_2$-SGD update identity。

### Level 2：Local / Approximate

例如：small-noise Taylor、first-order adversarial bridge、finite MC estimate、layer-product upper bound。

### Level 3：Mechanism

需要 controlled mediator、counterfactual ablation 和替代解释。只看 final metric 不识别 mechanism。

### Level 4：Benchmark

多 seed、合理 tuning、held-out tasks 与 uncertainty interval。仍只支持测试范围。

### Level 5：Deployment

真实 shift、latency/memory、monitoring、failure recovery、feedback loop 和持续 calibration。

不得从 Level 1 的公式直接跳到 Level 5 的安全结论，也不得从单 benchmark 倒推唯一机制。

## 十九、与学习理论的接口

Regularization 可能通过多个理论通道影响 generalization：

- 缩小 hypothesis/parameter norm；
- 提高 algorithmic stability；
- 改变 margin；
- 改变 effective data distribution；
- 对 posterior/description length 施加结构；
- 改变 optimization selection among interpolating solutions。

但任何具体 bound 都需要把实际算法、loss、norm、data assumptions 和常数接上。最终 accuracy improvement 不证明某个 PAC-Bayes、stability 或 margin bound 是真实机制；bound 变小也不保证不 vacuous。

## 二十、一个可执行的施工与验收流程

### Step 1：列 Inventory

逐项列出 augmentation、target transform、activation/path randomness、parameter/update regularization、function penalty、early stopping。

### Step 2：写 Equations

把每项放入统一 $\mathcal J(\theta)$ 或 update $U$；不能只列配置名。

### Step 3：画 Interaction Graph

连边表示共同 target、共同 sampling distribution、scale/state coupling 或 compute coupling。

### Step 4：选 Estimands

明确 fixed-policy、retuned-policy、matched-budget，以及 evaluation distribution。

### Step 5：做 Factorial Core

对高风险 pair 做完整 $2\times2$，用 paired seeds 估 main effects 与 interaction。

### Step 6：记六本账

Objective、optimization、generalization、calibration、robustness、system。

### Step 7：按证据等级写结论

每条 claim 附对象、条件、反例、指标、source 与可迁移边界。

## 二十一、常见误区

1. **“每个方法单独有效，叠加一定更有效”**：可能重复 bias、过度正则或优化冲突；
2. **“删除一个组件就是其普遍贡献”**：这是 full context 下的条件 effect；
3. **“固定超参最公平”**：它回答 fixed-policy，不回答最佳可达；
4. **“每组各自调到最好就识别机制”**：retuning 混入 policy response；
5. **“`weight_decay` 就是 $L_2$ objective”**：adaptive optimizer 下一般不等价；
6. **“公式可交换，pipeline 就可交换”**：state、sampling 和 optimization 仍不同；
7. **“多 seed mean 足够”**：还需 interval、paired difference 与 selection audit；
8. **“accuracy 最高就是最佳正则”**：calibration、robustness 与 system Pareto 可能相反；
9. **“经验提升证明了某种泛化理论”**：需要单独接 theorem assumptions 与 nonvacuity。

## 二十三、第三章总出口

完成 NN-01—64 后，你应能对一个陌生 neural block 在 45 分钟内完成：

1. shape、parameter 与 state contract；
2. forward equation 与数值稳定实现；
3. local VJP/JVP 与分支累加；
4. initialization、normalization、residual 与 stochastic scale；
5. parameter symmetry、train/eval 与 distributed RNG；
6. regularization interaction 与 compute ledger；
7. exact/local/mechanism/benchmark/deployment 五级证据分级；
8. 反例、property test、factorial ablation 与可复现报告。

这才是“掌握神经网络基础”的材料出口；真实掌握状态仍需闭卷作答、间隔重做、代码复现与陌生结构迁移证据。
