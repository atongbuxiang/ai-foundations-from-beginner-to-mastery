# 激活函数的角色、选择准则与函数性质

> [!abstract] 本章主问题
> 激活函数不只是“给网络加非线性”的名字表。它同时决定局部 Jacobian、函数空间的分段/光滑结构、信号均值与方差、数值动态范围、硬件代价和输出语义。可靠选择必须写成“架构—初始化—归一化—损失—精度”联合合同，而不是脱离上下文宣布某个函数普遍最好。

## 一、学习目标

1. 严格证明没有非线性时多层仿射网络仍是一层仿射映射；
2. 区分 hidden activation、gate、output link 与 probability normalization；
3. 从 derivative、range、smoothness、homogeneity、mean shift 和 cost 比较函数；
4. 写出 elementwise activation 的 Jacobian、JVP 与 VJP；
5. 解释局部斜率如何与权重、初始化和深度共同决定梯度；
6. 区分表示能力、可优化性、数值稳定和经验性能四类证据；
7. 为新任务写出可复现的激活选择与消融协议。

## 二、为什么必须引入非线性

设两层都只有仿射映射：

$$
h=W_1x+b_1,
\qquad
y=W_2h+b_2.
$$

代入得

$$
y=(W_2W_1)x+(W_2b_1+b_2),
$$

仍是一层仿射映射。任意有限个仿射层都能如此折叠；深度没有产生弯曲的决策边界或新的函数复合层级。

插入非仿射 $\phi$ 后，

$$
h=\phi(W_1x+b_1)
$$

一般不能吸收到新的 $W,b$ 中。这说明“非线性是必要的”，但没有说明任意非线性都同样容易训练，也没有说明越强的弯曲越好。

## 三、对象合同：激活究竟作用在哪里

对 preactivation $Z\in\mathbb R^{B\times d}$，逐元 hidden activation 定义为

$$
H_{ij}=\phi(Z_{ij}).
$$

它保持 shape，不混合样本或特征。需要与下列对象分开：

- **gate**：$H=A\odot V$，其中 $A$ 可能由另一分支产生；
- **output link**：把 score 映射到观测模型参数，例如 Bernoulli probability；
- **softmax**：跨类别轴耦合，不是逐元 map；
- **normalization**：使用多个位置的统计量，会混合指定轴；
- **hard decision**：argmax/threshold 通常不用于训练图中的梯度传播。

## 四、局部线性化与反向传播

对逐元 $\phi$，Jacobian 是对角矩阵：

$$
J_\phi(z)=\operatorname{diag}\!\bigl(\phi'(z_1),\ldots,\phi'(z_d)\bigr).
$$

因此

$$
\operatorname{JVP}(v)=\phi'(z)\odot v,
\qquad
\operatorname{VJP}(u)=\phi'(z)\odot u.
$$

“JVP 与 VJP 公式相同”来自 diagonal Jacobian；若激活跨坐标耦合，这个结论不成立。

## 五、深层梯度不是只看一个导数上界

对

$$
h_\ell=\phi_\ell(W_\ell h_{\ell-1}+b_\ell),
$$

令 $D_\ell=\operatorname{diag}(\phi_\ell'(z_\ell))$，则输入到输出的 Jacobian 是

$$
J=D_LW_L\cdots D_1W_1.
$$

反向则按相反顺序作用 $W_\ell^TD_\ell$。若 $|\phi'|\le1$，只能约束 $D_\ell$；权重谱范数、方向对齐和 residual/normalization 都还会改变乘积。

> [!warning] 常见误判
> “导数不超过 1，所以不会梯度爆炸”是错的；若 $\|W_\ell\|_2>1$，整体仍可能放大。反过来，某些位置 $|\phi'|>1$ 也不自动推出爆炸。

## 六、比较激活的十个维度

| 维度 | 要问的问题 | 对 AI 的影响 |
|---|---|---|
| affine / non-affine | 是否真正打破仿射折叠？ | 表示能力的最低门槛 |
| range | 有界、半有界还是无界？ | 动态范围、输出语义、饱和 |
| derivative | 斜率在哪些区间接近 0 或大于 1？ | 梯度门控与局部条件性 |
| smoothness | 连续、$C^1$、$C^2$ 还是有 kink？ | 高阶优化、PDE/导数正则 |
| monotonicity | 是否单调，是否存在非单调门？ | 排序、信息保留与门控 |
| symmetry | odd、zero-centered 或带负饱和？ | 均值漂移与参数耦合 |
| homogeneity | 是否满足 $\phi(cx)=c\phi(x)$？ | 重缩放对称、范数与 sharpness |
| moment map | 输入均值/方差怎样变化？ | 初始化与深层信号传播 |
| numerical path | exp、erf、分支在低精度下怎样实现？ | overflow、underflow、吞吐 |
| evidence | 结论来自恒等式、假设定理还是特定 benchmark？ | 防止经验外推 |

## 七、四类性质不能互相替代

1. **表示性质**：函数类能否逼近目标；
2. **优化性质**：局部梯度是否提供有用方向；
3. **数值性质**：有限精度实现是否稳定、快速；
4. **统计性质**：给定数据与训练协议能否改善泛化。

万能逼近只回答第一类存在性问题，不会自动选择 ReLU、tanh 或 SELU，也不提供有限宽度、样本量、步数和浮点误差保证。

## 八、Range、中心与信息压缩

- bounded activation 会把极端输入压到有限区间，可能抑制异常值，也可能让导数趋零；
- one-sided unbounded activation 可保留正幅度，但输出均值通常不为零；
- zero-centered 指输出分布可能围绕 0，不等于每层实际均值必为 0；
- negative saturation 可产生稳定下界，但也会在极负区间丢失幅度信息。

这些性质都依赖输入分布。即使 $\phi$ 是 odd function，若 $Z$ 分布不关于 0 对称，$\mathbb E[\phi(Z)]$ 仍可能不为 0。

## 九、Smoothness 与高阶任务

ReLU 在 0 处不可微，却可用 primitive convention 做一阶训练；若任务显式惩罚 input Hessian、求解高阶 PDE 或使用高阶 optimization，则 kink 可能变成一等公民。相反，$C^\infty$ 并不保证深层 Jacobian 条件良好。

应声明需要的是：几乎处处一阶导、Lipschitz 连续、一阶连续、二阶连续，还是特定弱导数意义。不同任务不能共享一句“越平滑越好”。

## 十、隐藏层与输出层不要共用口诀

- binary Bernoulli likelihood 常以 sigmoid 参数化 probability；
- multiclass categorical likelihood 常用 softmax；
- unbounded regression 常保留 linear output；
- strictly positive scale 可用 softplus/exponential，但数值与 tail 行为不同；
- hidden layer 的目标是表示与训练，不必具有概率解释。

“hidden layers 默认 ReLU”不能推出“回归输出也用 ReLU”；输出支持集必须先由 likelihood/任务定义。

## 十一、一个最小手算：同样非线性，不同梯度

设 $x=2,w=3,b=-5$，则 $z=wx+b=1$。若 loss 为 $L=\tfrac12h^2$，$h=\phi(z)$，则

$$
\frac{dL}{dw}=h\phi'(z)x.
$$

- ReLU：$h=1,\phi'=1$，所以 $dL/dw=2$；
- sigmoid：$h\approx0.7311,\phi'\approx0.1966$，所以 $dL/dw\approx0.2875$；
- tanh：$h\approx0.7616,\phi'\approx0.4200$，所以 $dL/dw\approx0.6397$。

这只比较同一点的一步局部梯度；它不证明哪一个在完整训练中更好。

## 十二、激活选择合同

在实验前固定：

1. task 与 output support；
2. architecture、depth、width 与 residual/gating；
3. initialization 是否按激活的二阶矩校准；
4. normalization 位置与 train/eval 语义；
5. optimizer、learning-rate schedule、regularization；
6. dtype、kernel implementation 与 loss scaling；
7. 参数量/FLOPs 是否因 gated activation 改变；
8. seed、预算和选择指标；
9. activation/gradient moments、dead/saturated rate 与 finite-value rate；
10. 结论允许外推到哪些数据、深度和硬件。

## 十三、公平消融

只替换函数名通常不公平。至少同时报告：

- matched parameter/FLOP budget；
- activation-aware initialization 与共同初始化两条轨道；
- 有/无 normalization 两条轨道；
- learning-rate retuning 与固定超参数两条轨道；
- train loss、validation metric、wall-clock、memory 和数值异常；
- layerwise mean/variance、derivative histogram 与 Jacobian proxy。

如果一个函数只在重新调参后获益，应把结论写成“函数与调参协议的联合优势”。

## 十五、常见错误

1. 把非线性必要性误写成某个具体激活的必要性；
2. 只看 curve，不看 derivative 与输入分布；
3. 把局部导数上界当作深层 Jacobian 定理；
4. 混淆 hidden activation 与 output likelihood link；
5. 用 UAT 为有限网络和训练速度背书；
6. 比较 gated 与非 gated 模型却不匹配参数/FLOPs；
7. 把一次 benchmark 排名外推到所有 architecture 与 dtype。

## 十六、回顾与练习

> [!summary]
> 激活函数是一份联合设计合同：它提供非仿射复合与局部斜率，但深层行为由函数、权重、数据分布、初始化、归一化、损失和有限精度共同决定。
