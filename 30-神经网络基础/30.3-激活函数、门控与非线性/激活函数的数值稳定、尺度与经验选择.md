# 激活函数的数值稳定、尺度与经验选择

> [!abstract] 本章主问题
> 激活函数比较必须同时通过数学等价、浮点稳定、深层尺度、系统成本和统计实验五道门。单次 accuracy、漂亮曲线或博客直觉都不足以决定选择；真正可复用的产物是带边界的证据协议。

## 一、稳定公式清单

| 对象 | 不可靠路线 | 稳定路线 |
|---|---|---|
| sigmoid | $1/(1+e^{-x})$ 全域硬算 | 按符号分支或库 primitive |
| softplus | $\log(1+e^x)$ | $\max(x,0)+\log1p(e^{-|x|})$ |
| log-sigmoid | 先 sigmoid 再 log | $-\operatorname{softplus}(-x)$ |
| ELU | $e^x-1$ near 0 | `expm1(x)` |
| GELU | 不声明 exact/approx | 明确 erf/tanh/sigmoid 版本 |
| maxout | tie 时假装唯一导数 | 文档化 winner/tie convention |

数学等价只说明 real arithmetic；finite precision 还需 overflow、underflow、cancellation、rounding 与 branch audit。

## 二、尺度台账

对每层至少记录

$$
E[H],\quad E[H^2],\quad\operatorname{Var}(H),\quad
E[\phi'(Z)^2],\quad\|\bar H\|.
$$

前三者不可混用；导数二阶矩还需与 weight variance 结合。normalization 会重置部分统计量，residual 会相加相关分支，gating 会相乘两条相关支路。

## 三、五条比较轨道

1. **plug-in**：全部超参数固定，测替换鲁棒性；
2. **retuned**：每个激活独立调 learning rate/initialization；
3. **matched parameters**：尤其处理 gated/maxout hidden width；
4. **matched FLOPs/latency**：以真实 kernel 测量；
5. **matched quality**：达到同一 validation 阈值比较时间/能耗。

五条轨道回答不同问题，不能只展示对自己有利的一条。

## 四、统计与选择偏差

预注册主指标、训练预算、seed 数与 early-stopping rule。报告所有 failed/NaN runs、均值与不确定区间；若从许多 activations 中挑最优，validation selection 已产生 multiple-comparison optimism，最终 test 只能在选择完成后使用。

## 五、Kernel 与编译器现实

activation FLOPs 常不是瓶颈，但会影响 fusion、memory traffic、checkpoint residual、quantization 和 compiler lowering。GELU exact/approx、SwiGLU 三矩阵、Maxout candidate tensor 的成本必须以目标硬件实测；理论 operation count 不等于 latency。

## 六、来源证据分层

- 恒等式/证明：支持定义、导数、界与反例；
- 原始论文：支持明确 architecture/dataset/protocol 的经验；
- 官方实现文档：支持当前 API 与 kernel 语义；
- 科学空间/博客：提供推导视角与研究假说，需回查原论文；
- leaderboard/anecdote：只能作为待验证线索。

例如科学空间关于光滑近似、初始化和激活恒等式的文章适合生成问题与推导，但不自动升级为跨任务因果结论。

## 七、发布级验收矩阵

对每个候选检查：定义与极限、forward/grad/gradgrad reference、kink/tie、极端输入、dtype、shape/layout、fusion、determinism、moments、gradient、参数/FLOP/bytes、wall-clock、energy、train/validation/test、seeds 与 claim boundary。

## 九、决策规则与回顾

先用任务/输出支持排除不合法函数，再用数学与数值门排除不可靠实现；在 architecture-aware initialization 下做 matched-budget screening，最后小范围 retune。若差异落在 seed variance 与测量噪声内，优先选择更简单、稳定、已有融合支持的方案。

> [!summary]
> 激活选择不是函数名竞赛，而是数学—浮点—传播—系统—统计的联合审计。最可信的结论通常更窄，却更可迁移。
