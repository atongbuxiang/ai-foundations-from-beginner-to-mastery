# 人工智能基础从入门到精通

这是一个面向长期研究的 Obsidian 知识库，目标不是收集文章，而是建立一套可推导、可验证、可追溯的人工智能基础理论与模型体系。

知识库以苏剑林的[科学空间](https://spaces.ac.cn/)中与 AI 有关的内容作为重要导读来源，同时用教材、原论文和可复现实验交叉验证。与 AI 无关的站内内容不登记；博客原文也不会被整篇镜像到仓库。

## 目录角色

```text
00-知识库管理/
├── 00-总览/        知识地图、范围和当前路线
├── 01-规范/        工作流、写作、引用、图示和质量规范
├── _sources/       博客、论文和教材的来源笔记
├── _labs/          独立推导、数值实验、习题、解答和阶段测验
├── _assets/        合法使用的图片、SVG 和实验图
├── _inbox/         尚未分类的 AI 问题和待处理来源
└── _templates/     Obsidian 笔记模板
10-数学基础/        线性代数、概率、信息论、优化、数值方法
20-学习理论/        学习问题、统计学习、泛化、经典模型
30-神经网络基础/    反向传播、激活、初始化、归一化、残差
40-表示与模型架构/  CNN、RNN、Attention、Transformer、MoE
50-生成模型/        自回归、VAE、GAN、Flow、能量与扩散模型
60-训练与优化/      SGD、Adam、Muon、正则化、尺度与稳定性
70-语言模型/        Tokenization、预训练、长上下文、微调与推理
80-强化学习与智能体/ MDP、价值学习、策略优化、对齐与规划
90-研究专题/        跨章节的深挖主题和科学空间系列
```

本仓库不要求第三方 Obsidian 插件。Mermaid、MathJax、属性和双向链接均可由 Obsidian 核心功能处理。
