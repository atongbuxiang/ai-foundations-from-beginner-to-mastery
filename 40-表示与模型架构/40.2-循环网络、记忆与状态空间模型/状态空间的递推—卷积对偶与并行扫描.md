# 状态空间的递推—卷积对偶与并行扫描

> [!abstract] 本节主问题
> 离散线性时不变 SSM 可逐步 recurrence，也可在零初态/固定初态条件下展开为一维 convolution；更一般的仿射 recurrence 还能编码为带结合律的 scan。三者描述相关 input-output map，却具有不同的训练、流式、工作量、并行 span 与 IO 合同。

## 导读：同一个模型，为什么可以有三种计算方式

ARCH-13 已经给出一个离散状态更新。最直接的算法当然是按时间从左到右递推：先算 $s_1$，再算 $s_2$，直到序列末尾。这种方式非常适合流式推理，因为每来一个新 token 只需保存当前状态；但整段训练时，它也让计算看起来必须严格串行。

线性时不变系统还有另一面。把 recurrence 反复代入后，每个早期输入前面都会出现一个 $\bar A$ 的幂；这些只依赖时间距离的系数可以预先排列成 impulse-response kernel，于是同一输入输出映射也可以写成因果卷积。卷积接口适合整段并行和频域算法，但它依赖固定参数、正确的初态项和严格的 index convention。

即使参数随时间变化，卷积核不再固定，一步更新仍可能是关于旧状态的仿射映射。把每一步编码成 $(A_t,b_t)$ 后，区间组合具有结合律，于是可以用 parallel prefix scan 改变括号结构而不改变时间顺序。请特别留意：scan 需要 associativity，不需要 commutativity；我们可以并行重新分组，却不能随意交换 token。

## 课程位置与两遍学习路线

- **承接什么：** ARCH-13 已从连续系统得到 $s_{k+1}=\bar A s_k+\bar B u_k$；本页不再更换模型，而是更换同一模型的计算接口；
- **本页解决什么：** 逐步展开 LTI recurrence，识别 impulse-response kernel 和非零初态自由响应，再把一般时变仿射更新编码成有序但可结合的 pair；
- **后续为何需要：** ARCH-15 借固定 LTI kernel 做结构化频域计算，ARCH-16 的输入依赖参数会破坏固定卷积，却仍保留仿射 scan。

**第一遍只证明同一串数能算两遍。** 用 recurrence 得到 $(2,3,3/2,-5/4)$，再用 kernel $(2,1,1/2,1/4)$ 做因果卷积，逐项核对完全一致。

**第二遍重建算法合同。** 加回非零初态和 direct term，证明仿射 pair 的结合律，区分 work、parallel span、IO、浮点顺序与真实墙钟。

### 问题链

1. 反复代入 recurrence 后，早期输入前面的矩阵幂从哪里出现？
2. 为什么零初态输入响应可以写成卷积，而非零初态还要加自由响应？
3. 固定 kernel $K_j=C\bar A^j\bar B$ 依赖哪些 LTI 条件？
4. causal linear convolution 与 FFT 的 circular convolution 怎样避免混淆？
5. 一步仿射映射怎样编码成 pair $(A_t,b_t)$？
6. parallel scan 为什么只需要 associativity，而不要求 commutativity？
7. $O(L)$ work、$O(\log L)$ span 与 GPU 更快为什么是三个不同主张？

> [!check] 第一遍停靠线
> 若你能用 kernel $(2,1,1/2,1/4)$ 从输入 $(1,1,0,-1)$ 复算输出 $(2,3,3/2,-5/4)$，再把四个仿射 pair 合成为 $(1/16,-5/4)$，就完成了本页第一遍。

## 符号与对象账本

| 对象 | 数学身份 | AI 中的身份 | 不能偷换成 |
|---|---|---|---|
| $s_{k+1}=\bar A s_k+\bar B u_k$ | 顺序状态递推 | streaming recurrent interface | 可并行 token 生成 |
| $K_j=C\bar A^j\bar B$ | LTI impulse response | training convolution kernel | 输入依赖 kernel |
| $C\bar A^ks_0$ | 非零初态自由响应 | chunk boundary state effect | 输入卷积的一部分 |
| $p_t=(A_t,b_t)$ | 一步仿射映射 | scan element | 可随意交换顺序的标量 |
| $\otimes$ | 函数组合诱导的结合运算 | prefix scan operator | 交换运算 |
| work | 总算术量 | 全设备总操作 | critical path |
| span | 无限并行资源下关键路径 | 理想并行深度 | 墙钟延迟 |

### 贯穿算例 $\mathcal S_\square$：递推、卷积与 scan 三次得到同一答案

沿用 ARCH-13 的精确 ZOH recurrence，并把读出定义为更新后的状态：

$$
s_{t+1}=\frac12s_t+2u_t,\qquad z_t=s_{t+1},\qquad s_0=0.
$$

对 $u=(1,1,0,-1)$，顺序递推给

$$
z=\left(2,3,\frac32,-\frac54\right).
$$

对应 impulse response 为

$$
K_j=2\left(\frac12\right)^j,
\qquad
(K_0,K_1,K_2,K_3)=\left(2,1,\frac12,\frac14\right).
$$

按 causal linear convolution 逐项计算：

$$
\begin{aligned}
z_0&=2\cdot1=2,\\
z_1&=1\cdot1+2\cdot1=3,\\
z_2&=\frac12\cdot1+1\cdot1+2\cdot0=\frac32,\\
z_3&=\frac14\cdot1+\frac12\cdot1+1\cdot0+2\cdot(-1)=-\frac54.
\end{aligned}
$$

再把每一步写成 pair

$$
p_t=\left(\frac12,2u_t\right),
$$

于是

$$
p_1\otimes p_0
=\left(\frac14,3\right),
$$

$$
p_2\otimes(p_1\otimes p_0)
=\left(\frac18,\frac32\right)
=(p_2\otimes p_1)\otimes p_0.
$$

继续合入 $p_3=(1/2,-2)$：

$$
p_3\otimes p_2\otimes p_1\otimes p_0
=\left(\frac1{16},-\frac54\right).
$$

第二个分量正是零初态下的最终状态；第一个分量说明若 $s_0\ne0$，还要额外加 $(1/16)s_0$。同一 pair 同时保存了输入响应和初态自由响应。

## 核心公式七问：仿射 pair 的结合组合

$$
\boxed{
(A_2,b_2)\otimes(A_1,b_1)
=\left(A_2A_1,\ A_2b_1+b_2\right).
}
$$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 把多步仿射 recurrence 压缩成可做 parallel prefix 的代数元素 |
| 对象 | $(A_1,b_1)$ 先作用，$(A_2,b_2)$ 后作用；顺序写在乘积中 |
| 来路 | 直接复合 $s\mapsto A_1s+b_1$ 与 $s\mapsto A_2s+b_2$ |
| 步骤 | 线性部分相乘，前一步偏置先被后一步 $A_2$ 传播，再加后一步偏置 |
| 读法 | 一个 pair 记录“这段区间把旧状态乘多少、额外写入多少” |
| 检查 | 单位元为 $(I,0)$；三元素两种括号必须相等；交换 $p_1,p_2$ 通常改变结果 |
| 去路 | LTI 时可进一步预生成固定卷积；输入依赖时固定卷积消失，但 pair scan 仍成立 |

因此，recurrence、convolution 和 scan 不是三个彼此竞争的模型名称，而是同一状态更新在不同条件下的计算接口。下面我们先从逐步代入开始，明确零初态、非零初态和 direct term 各自落在哪里，再讨论 work、span 与实际硬件时间为何不能混成一个复杂度数字。

## 一、从离散 LTI recurrence 出发

采用索引

$$
x_{k+1}=\bar Ax_k+\bar Bu_k,\qquad y_k=Cx_k+Du_k.
$$

为简洁先设 $x_0=0,D=0$。逐步展开：

$$
x_1=\bar Bu_0,
$$

$$
x_2=\bar A\bar Bu_0+\bar Bu_1,
$$

$$
x_k=\sum_{j=0}^{k-1}\bar A^{k-1-j}\bar Bu_j.
$$

因此

$$
y_k=\sum_{j=0}^{k-1}C\bar A^{k-1-j}\bar Bu_j.
$$

定义 impulse-response kernel

$$
K_n=C\bar A^n\bar B,\qquad n\ge0,
$$

则 $y_k=\sum_{j=0}^{k-1}K_{k-1-j}u_j$。具体是否写成 $y_k=(K*u)_k$ 取决于输出与状态的 index convention；实现前必须用 impulse test 对齐一格偏移。

## 二、非零初态是额外自由响应

一般情况

$$
x_k=\bar A^kx_0+\sum_{j=0}^{k-1}\bar A^{k-1-j}\bar Bu_j,
$$

$$
y_k=C\bar A^kx_0+\sum_{j=0}^{k-1}K_{k-1-j}u_j+Du_k.
$$

所以仅做 input convolution 会漏掉 $C\bar A^kx_0$。训练时常取零初态；流式承接上一个 chunk 时初态通常非零，需 state-passing 或显式加自由响应。

## 三、固定 convolution kernel 的条件

单一 $K_n=C\bar A^n\bar B$ 要求：

- transition 对 state 是线性的；
- $\bar A,\bar B,C$ 不随时间、输入或状态变化；
- boundary/initial-state 约定固定；
- 序列长度内参数共享；
- 不在 recurrence 中夹入任意非线性。

若 $\bar B_k,C_k,\Delta_k$ 依赖 $u_k$，仍可能是线性于 state 的 time-varying recurrence，却不能由一个预先固定的 convolution kernel 表示。这正是 selective SSM 的关键边界。

## 四、卷积接口为何适合整段训练

长度 $L$ 的 kernel 生成后，direct convolution 为 $O(L^2)$（标量/通道常数略去），FFT convolution 通常约 $O(L\log L)$，并可对所有位置并行。代价包括：

- 先生成 $K_0,\ldots,K_{L-1}$；
- padding 到线性卷积所需长度，避免 circular aliasing；
- FFT 的复数/实数变换与临时内存；
- kernel 参数化的数值条件。

短序列、很小状态或 streaming 时，逐步 recurrence 可能更合适。渐近复杂度不直接等于 wall-clock。

## 五、生成函数和 transfer function

形式生成函数

$$
K(z)=\sum_{n=0}^{\infty}K_nz^n
=\sum_{n=0}^{\infty}C(z\bar A)^n\bar B.
$$

在级数收敛或形式幂级数意义下，Neumann series 给

$$
\boxed{K(z)=C(I-z\bar A)^{-1}\bar B.}
$$

这是有理函数；其 poles 与 $\bar A$ eigenstructure 相关。[[S-2024-Su-10180-有理生成函数SSM]]用这一视角连接线性 RNN、resolvent 和 transfer-function parameterization。

需要区分：

- 形式幂级数恒等；
- 解析函数的收敛域；
- 单位圆上的频率响应；
- 有限长度 DFT samples。

它们相关但不完全相同。

## 六、仿射更新的结合律

时间变化的线性仿射 recurrence

$$
x_t=A_tx_{t-1}+b_t
$$

可把每一步编码为 pair $p_t=(A_t,b_t)$。定义“后做 $p_2$”的组合

$$
\boxed{p_2\otimes p_1=(A_2A_1,A_2b_1+b_2).}
$$

验证结合律：

$$
p_3\otimes(p_2\otimes p_1)
=(A_3A_2A_1,A_3A_2b_1+A_3b_2+b_3),
$$

$$
(p_3\otimes p_2)\otimes p_1
=(A_3A_2A_1,A_3A_2b_1+A_3b_2+b_3).
$$

因此可用 parallel prefix scan 同时得到所有 prefix compositions。注意 $\otimes$ 一般不交换；parallel scan 只需 associativity，不需 commutativity。

## 七、work、span 与 IO 分开

Sequential recurrence 的 work $O(L)$、span $O(L)$。理想树形 scan 仍有 $O(L)$ work，但 span 可为 $O(\log L)$，代价是并行调度、中间结果、矩阵/向量操作和内存访问。

对于 diagonal $A_t$，pair composition 可逐元素，成本远低于稠密 $N\times N$ 矩阵乘法。说“scan 是线性的”必须同时声明 state structure；稠密矩阵 pair 的常数和 $N$ 阶数可能巨大。

实际 GPU 性能还取决于：

- 是否把 parameter projection、scan 与 output 融合；
- 中间 state 是否写回 HBM；
- backward 重算还是保存；
- chunk 大小、batch、dtype 与 sequence length；
- 非结合的浮点舍入导致不同树顺序的微小差异。

## 八、训练、prefill 与 streaming

| 接口 | 合适形式 | 关键资源 |
|---|---|---|
| 整段训练 | FFT convolution 或 parallel scan | activation、kernel/scan IO |
| prefix prefill | scan/块递推 | prefix throughput、final state |
| 单步 streaming | recurrence | state bytes、step latency |
| chunked long stream | state passing + chunk kernel | boundary state、overlap |

同一参数化可以提供多个执行接口，但数值等价需测试 initial state、padding 和 precision。

## 十、浮点下“结合”要加注记

实数代数中 pair composition 严格结合；浮点加法和乘法不严格结合。不同 scan tree 可能产生舍入差异，长乘积还可能 underflow/overflow。工程验收应比较：

- sequential reference 与 scan 的相对/绝对误差；
- 不同长度、dtype 和状态尺度；
- forward 与 backward；
- deterministic setting 下重复性；
- stable parameterization 或 rescaling。

这不否定 scan 算法，只说明数学等价和 bitwise equality 是不同要求。

## 十一、常见错误

1. 忽略 initial-state 自由响应；
2. 用 circular FFT convolution 冒充 linear causal convolution；
3. 参数随输入变化仍写固定 $K$；
4. 把 associativity 误写为 commutativity；
5. 混淆 work、parallel span 和 wall-clock；
6. 忽略 dense state matrix 的 $N$ 成本；
7. 要求不同 scan tree 在浮点下 bitwise 相同；
8. 用整段训练并行性推断自回归 token 可并行生成。

## 十二、掌握标准

> [!summary]
> - 离散 LTI recurrence 展开为 impulse-response convolution；
> - 非零初态产生额外自由响应；
> - input-dependent/time-varying 参数破坏单一固定卷积核；
> - 仿射更新 pair 在正确顺序下满足结合律；
> - recurrence、convolution、scan 分别适合不同执行接口。

能展开前三步并对齐索引（A/B）、推导卷积与生成函数（C）、构造 non-LTI/initial-state 反例（D），并对 scan 做 work/span/IO/precision 审计（E）。
