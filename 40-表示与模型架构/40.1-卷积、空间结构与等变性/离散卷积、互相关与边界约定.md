# 离散卷积、互相关与边界约定

> [!abstract] 本节主问题
> 数学卷积会翻转 kernel，深度学习库中的 `conv` 通常计算不翻转的 cross-correlation。因为 kernel 是学习的，两者表示能力可通过参数重命名对应；但手算、信号解释、权重迁移和等变性证明必须固定索引、边界、stride 与 dilation，不能只说“做卷积”。

## 课程位置与两遍学习路线

- **承接什么：** ARCH-01 已说明结构偏置要落到具体的信息边与共享规则；你也已经会做有限维内积；
- **本页解决什么：** 把“卷积层在滑动”改写成唯一、可手算、可测试的索引公式，并把翻转、边界、stride 与 dilation 全部纳入合同；
- **后续为何需要：** ARCH-03 的等变性证明依赖这里的相对索引，ARCH-04 的多通道公式只是再增加 batch/channel 轴。

**第一遍先做窗口算术。** 固定 valid cross-correlation，只计算 $\mathcal C_\square$ 的三个窗口；能够指出数学 convolution 为什么要反转 $w$ 即可。

**第二遍再做算子审计。** 从“最后一个合法窗口”推出输出长度，把有限序列看成由 boundary extension 定义的线性算子，并用 impulse/constant input 检查实现。

### 问题链

1. 一个局部窗口怎样变成一个输出标量？
2. convolution 与 cross-correlation 的索引差在哪里？
3. 有限数组的区间外取值为何属于算子定义，而非装饰性实现细节？
4. stride、padding、dilation 怎样共同决定合法窗口数？
5. 局部与共享如何在 Toeplitz-like 矩阵中显现？
6. 何时可谈 FFT 的渐近优势，何时还必须看硬件与形状？

> [!check] 第一遍停靠线
> 若你能不看答案算出 $y_\square=(-1,-1,2)$，并能说出“DL conv 通常是不翻转 kernel 的相关”，即可进入 ARCH-03。输出长度证明、矩阵化和 FFT 成本留到第二遍。

## 符号与对象账本

| 对象 | 类型与范围 | AI 身份 | 易混对象 |
|---|---|---|---|
| $x[i]$ | 离散输入样本 | 一维 feature map 的位置值 | batch 中第 $i$ 条样本 |
| $w[j]$ | 长度 $K$ 的参数 | 可学习 kernel tap | 已翻转的 $\widetilde w[j]=w[-j]$ |
| $y[i]$ | 输出位置值 | 局部响应 | 分类概率 |
| $P_l,P_r$ | 非负整数 | 左右 padding | 实际数据点 |
| $S,D$ | 正整数 | stride 与 dilation | kernel 参数个数 |
| $K_{\mathrm{eff}}$ | 覆盖宽度 | 最左到最右 tap 的跨度 | 非零 tap 数 $K$ |
| $A_w$ | 结构化线性算子 | 理论上的卷积矩阵 | 实现中必须物化的矩阵 |

### 贯穿算例 $\mathcal C_\square$：三个窗口逐项合账

沿用 ARCH-01：

$$
x_\square=(2,-1,3,0,1),\qquad w_\square=(1,0,-1).
$$

采用 0-based、valid、stride $S=1$、dilation $D=1$ 的 cross-correlation。窗口—输出账为

| $i$ | 输入窗口 | 点积 | $y[i]$ |
|---:|---|---|---:|
| 0 | $(2,-1,3)$ | $2\cdot1+(-1)\cdot0+3\cdot(-1)$ | $-1$ |
| 1 | $(-1,3,0)$ | $(-1)\cdot1+3\cdot0+0\cdot(-1)$ | $-1$ |
| 2 | $(3,0,1)$ | $3\cdot1+0\cdot0+1\cdot(-1)$ | $2$ |

所以 $L_{\mathrm{out}}=5-3+1=3$ 且 $y_\square=(-1,-1,2)$。若改成数学 convolution，使用的 tap 顺序为 $(-1,0,1)$，第一项变成 $1$；这正是“约定不同，固定权重响应不同”的最小反例。

## 核心公式七问：统一索引与输出长度

$$
y[i]=\sum_{j=0}^{K-1}w[j]x[iS-P_l+jD],
\qquad
L_{\mathrm{out}}=\left\lfloor\frac{L+P_l+P_r-D(K-1)-1}{S}\right\rfloor+1.
$$

| 问题 | 本式的回答 |
|---|---|
| 目的 | 枚举每个输出所读取的输入索引，并计算共有多少个合法起点 |
| 对象 | $i$ 是输出位置，$j$ 是 kernel tap；$S,D\ge1$，$P_l,P_r\ge0$ |
| 来路 | 第 $i$ 个起点是 $iS-P_l$，最右 tap 再加 $D(K-1)$；要求它不越过补齐后的右边界 |
| 步骤 | 先得 $K_{\mathrm{eff}}=D(K-1)+1$，再解 $iS\le L+P_l+P_r-K_{\mathrm{eff}}$，最后对最大整数 $i$ 取 floor 并加 1 |
| 读法 | dilation 改覆盖，stride 改起点间隔，padding 改允许起点；三者共同决定输出个数 |
| 检查 | $S=D=1,P_l=P_r=0$ 时退化为 $L-K+1$；若分子为负则不存在合法窗口 |
| 去路 | ARCH-04 对高、宽两轴分别应用同一公式；ARCH-05 将 stride 解释成采样并分析混叠 |

## 一、阅读前只需知道

- [[线性映射]]：固定 kernel 时，输入到输出是线性映射；
- 有限序列索引：本节默认从 0 开始；
- dot product：每个局部窗口与 kernel 做一次内积。

## 二、从一个三点窗口手算

令

$$
x=[2,-1,3,0,1],\qquad w=[1,0,-1].
$$

第一个完整窗口为 $[2,-1,3]$。Cross-correlation 得

$$
y[0]=2\cdot1+(-1)\cdot0+3\cdot(-1)=-1.
$$

窗口右移一格：

$$
y[1]=(-1)\cdot1+3\cdot0+0\cdot(-1)=-1,
$$

再移一格得 $y[2]=3\cdot1+0\cdot0+1\cdot(-1)=2$。Valid 输出是 $[-1,-1,2]$。

## 三、两个容易混淆的定义

对双无限离散序列，一种标准数学卷积写作

$$
\boxed{(x*w)[i]=\sum_{j\in\mathbb Z}x[i-j]w[j].}
$$

Cross-correlation 可写作

$$
\boxed{(x\star w)[i]=\sum_{j\in\mathbb Z}x[i+j]w[j].}
$$

令 $\widetilde w[j]=w[-j]$，则 $x\star w=x*\widetilde w$。所以两者差一个 kernel reversal。对学习参数而言，网络可以把所需反转吸收到 $w$；对固定的边缘 detector 或信号响应而言，方向符号会改变。

## 四、有限序列必须先扩展

有限输入 $x[0],\ldots,x[L-1]$ 在区间外没有定义。要计算边缘位置，必须给 extension rule：

| 规则 | 区间外定义 | 语义 |
|---|---|---|
| zero padding | $x[i]=0$ | 图像外为空；边缘统计突变 |
| reflection | 镜像内部值 | 边缘较连续，但引入镜像先验 |
| replication | 使用最近边界值 | 常数延拓 |
| circular | $x[i]=x[i\bmod L]$ | 周期域；适合环形/FFT 模型 |
| valid | 不计算越界窗口 | 输出变短，不需要外推值 |

这些不是纯实现细节。它们定义了不同的线性算子，也改变边缘响应和严格平移等变的定义域。

## 五、Valid、Full 与 Same

kernel 长度 $K$、stride 1、dilation 1 时：

- `valid`：只放完整窗口，$L_{out}=L-K+1$；
- `full`：两侧各补 $K-1$ 个零，$L_{out}=L+K-1$；
- `same`：选择总 padding 使输出约等于输入长度。

对奇数 $K$、stride 1，左右各补 $(K-1)/2$ 可得到同长。对偶数 kernel 或 stride $S>1$，左右 padding 可能不对称；不同框架的 `same` 约定应查文档，不能凭名称猜。

## 六、Stride 与 Dilation 的统一索引

对左 padding $P_l$、stride $S$、dilation $D$ 的互相关，写

$$
y[i]=\sum_{j=0}^{K-1} w[j]\,x[iS-P_l+jD].
$$

有效 kernel 覆盖宽度为

$$
K_{eff}=D(K-1)+1.
$$

若输入长度为 $L$、总 padding $P_l+P_r$，输出长度

$$
\boxed{L_{out}=\left\lfloor\frac{L+P_l+P_r-K_{eff}}{S}\right\rfloor+1.}
$$

这个公式来自最后一个窗口起点不能超过 $L+P_l+P_r-K_{eff}$，不是要死记的咒语。

## 七、二维与多维只是索引增加

单通道二维互相关：

$$
y[p,q]=\sum_{a=0}^{K_h-1}\sum_{b=0}^{K_w-1}
w[a,b]x[pS_h-P_h+aD_h,\ qS_w-P_w+bD_w].
$$

每个 output location 对一个局部 patch 与 kernel 做 Frobenius inner product。多通道时还要沿 input-channel 轴求和，详见[[通道、卷积核、步幅、填充与膨胀的形状账本]]。

## 八、卷积是一个结构化矩阵

对有限 1D valid correlation，存在矩阵 $A_w$ 使 $y=A_wx$。例如 $L=5,K=3$：

$$
A_w=
\begin{bmatrix}
w_0&w_1&w_2&0&0\\
0&w_0&w_1&w_2&0\\
0&0&w_0&w_1&w_2
\end{bmatrix}.
$$

这是 banded Toeplitz-like matrix：局部性表现为带状稀疏，共享表现为每条对角线重复同一权重。实际实现不会通常物化它，而使用专用 convolution/GEMM kernel。

## 九、线性、双线性与偏置

固定 $w$ 时，$x\mapsto x\star w$ 线性；固定 $x$ 时，$w\mapsto x\star w$ 也线性；把 $x,w$ 同时作为变量则是双线性，而不是对 $(x,w)$ 联合线性。加 bias 后输入到输出变为 affine map。

卷积层后接 ReLU 等 activation，整体不再线性。不能用“卷积是线性的”推断 CNN 整体只是线性模型。

## 十、计算成本

1D single-channel valid direct correlation 有 $L-K+1$ 个输出，每个做 $K$ 次乘加：

$$
\text{MACs}=(L-K+1)K,\qquad \text{parameters}=K.
$$

FFT convolution 对很长序列和大 kernel 可达约 $O(L\log L)$，但还含变换、padding 和复数常数。小 kernel、batch/channel 较大时，direct/implicit-GEMM 通常更适合硬件。算法比较必须说明形状和设备。

## 十二、最小数值自检

对任意实现至少做四项：

1. impulse input：$x$ 只有一个 1，检查 kernel 是否翻转；
2. constant input：检查边界是否出现预期衰减；
3. hand case：用本节 $[2,-1,3,0,1]$ 复算；
4. shape case：随机取 $L,K,P,S,D$，用公式对输出长度。

这比仅看 API 名称可靠，尤其在跨 PyTorch/JAX/TensorFlow 或导出模型时。

## 十三、常见错误

1. 忽略 kernel 是否翻转；
2. 在有限数组上写双无限求和却不声明 extension；
3. 把 `same` 当成所有框架完全相同；
4. 忘记 dilation 改的是有效覆盖而不是参数数；
5. 忘记 floor，产生越界窗口；
6. 把相关的方向响应解释成卷积响应；
7. 将理论 $O(L\log L)$ 直接等同实际低 latency。

## 十四、与 AI 架构的连接

- CNN：小二维 kernel 学局部 pattern；
- temporal convolution：因果 padding 可做流式序列模型；
- depthwise convolution：每通道独立做空间/时间相关；
- SSM：线性 recurrence 可在条件成立时转成 long convolution；
- linear attention：短卷积常被用来补局部顺序 bias，但这属于后续经验机制；
- transposed convolution：是卷积线性算子的 adjoint-like 实现接口，不等于真正矩阵逆。

## 十五、回顾与掌握标准

> [!summary]
> - 数学 convolution 与 DL cross-correlation 相差 kernel reversal；
> - 有限输入必须声明 boundary extension；
> - stride/dilation/padding 共同决定索引和输出长度；
> - 卷积是局部、共享的结构化线性算子；
> - 参数、算术和实际延迟必须分开。

能复述约定（A）、完整手算（B）、推导输出长度和 Toeplitz 形式（C）、构造边界/翻转反例（D），并审计真实框架的 conv API（E）。
