# 相对位置表示、偏置与距离函数

> [!abstract] 本节主问题
> “相对位置编码”不是一个公式。位移 $i-j$ 可以进入 logits、keys、values 或更一般的结构 bias；距离还可被 clip、bucket、线性衰减或扩展为二维/图距离。注入点与距离函数共同决定表达、缓存、计算和外推边界。

## 一、先固定距离符号

对 query position $i$、key position $j$，本节定义

$$
\Delta=i-j.
$$

在 causal attention 中 $j\le i$，所以 $\Delta\ge0$。有些论文使用 $j-i$，公式符号会整体反转；实现前必须写 gold table，而不能靠“relative position”名称猜。

相对编码的核心先验是：pair $(i,j)$ 的位置作用主要由 $\Delta$ 或更一般的关系 $r(i,j)$ 决定，而不分别依赖绝对 $i,j$。

## 二、最简单：Logit Bias

$$
\ell_{ij}
=\frac{q_i^\top k_j}{\sqrt{d_k}}
+b_h(\Delta).
$$

$b_h$ 可：

- 查一张 learned table；
- 由小网络/函数生成；
- 按距离 bucket 查表；
- 设成固定线性/对数衰减；
- 依 head/layer 不同。

Bias 加在 mask 前后要遵守：非法 pair 最终必须为 $-\infty$；不能让有限 bias 把未来位置“救回来”。

## 三、Shaw：Relative Key 与 Relative Value

[[S-2018-Shaw-Relative-Position]] 的典型形式：

$$
\ell_{ij}
=\frac{q_i^\top(k_j+a^K_{\Delta})}{\sqrt{d_k}},
$$

$$
o_i=\sum_j\alpha_{ij}(v_j+a^V_{\Delta}).
$$

Relative key 使位置与 query content 发生双线性交互；纯 scalar bias 只给相同 $\Delta$ 一个 head-specific 常数。Relative value 又把位置信息直接写进输出，即使原 $v_j$ 相同也可能产生不同 $o_i$。

因此“都依相对距离”不表示表达或成本相同。

## 四、T5 的对数分桶

T5-style relative bias 把小距离保留较细 buckets，较远距离按对数尺度压缩，超过阈值后共享远端 buckets。抽象写成

$$
b_h(\Delta)=B_{h,\operatorname{bucket}(\Delta)}.
$$

这编码了先验：

- 近处顺序/距离需要精确；
- 远处只需粗粒度；
- 最大 bucket 外距离不可辨。

Bucket 数少能减参数并自然计算任意长度，却牺牲远距离分辨率。函数有定义不表示模型训练过这些 bucket 对应的候选数和内容分布。

## 五、ALiBi：固定线性衰减

[[S-2022-Press-ALiBi]] 对 causal head $h$ 使用

$$
\ell^{(h)}_{ij}
=\frac{q_i^\top k_j}{\sqrt{d_h}}
-m_h(i-j),
\qquad m_h>0.
$$

不同 heads 取不同 slopes，形成不同 recency scales。优点是无需 position table、任意距离都可直接计算；代价是显式偏向近处。

距离增加 $\delta$ 时，若 content logits不变，未归一化 odds 被乘

$$
\exp(-m_h\delta).
$$

这是 I；“因此长文本性能更好”只在论文任务/协议下为 E。足够远时强衰减会削弱直接远程读取。

## 六、Clip、Bucket 与连续函数的分辨率

### Clip

$$
\tilde\Delta=\min(\max(\Delta,-K),K).
$$

所有 $|\Delta|>K$ 共用参数；远距离完全碰撞。

### Bucket

多个距离映到离散组，分辨率随距离变化。

### 连续函数

例如 $b(\Delta)=-m|\Delta|$ 或小网络 $f(\Delta)$。它可对未见距离求值，但函数输入仍 OOD，输出尺度可能超出训练 logits。

距离压缩必须登记方向、最大范围、离散/连续、head sharing 及训练覆盖。

## 七、Toeplitz 与平移结构

若

$$
B_{ij}=b(i-j),
$$

则 $B$ 是 Toeplitz：沿每条对角线常数。对无限序列或同步平移且不越边界时，它表达 translation-invariant pair relation。

有限序列边界、padding、causal triangle、segment boundaries 会破坏完整平移对称。不能只看到 Toeplitz 公式就宣称模型全局平移等变。

## 八、科学空间的常量输入反例

[[S-2022-Su-9105-相对位置编码理论缺陷]] 考察：位置信息只改 softmax logits，输入 tokens 全同，因此

$$
v_j=v.
$$

无论各行 attention 权重怎样依位置变化，只要

$$
\sum_j\alpha_{ij}=1,
$$

就有

$$
o_i=\sum_j\alpha_{ij}v=v.
$$

所以这一层无法在没有其他非对称的情况下，把全同输入变成不同位置输出。

这是严格反例 I，但条件很重要。以下机制可打破：

- special/BOS/SEP tokens；
- padding/crop boundary；
- relative values $a^V_\Delta$；
- absolute position；
- 非 row-normalized attention；
- 内容/状态在更早层已经不同。

因此正确结论是“只在 logits 注入相对位置存在该盲区”，不是“所有相对位置编码都有理论缺陷”。

## 九、相对不等于自动外推

相对函数可能对所有 $\Delta$ 有定义，但测试更长时仍出现：

1. 训练未见过的大 $\Delta$；
2. 每行可见 keys 增多，softmax partition 改变；
3. bucket/clip 让更多 pairs 堆到同一远端参数；
4. 远程 decay 切弱全局依赖；
5. cache/kernel 处理的 position offset 错位；
6. 任务需要的依赖跨度超过训练。

[[S-2023-Su-9431-长度外推与局部注意力]] 将位置 OOD 与候选数 OOD 分账，是理解相对位置外推的重要接口。

## 十、二维、图与多模态关系

相对关系可从一维差扩展：

$$
r(i,j)=(\Delta row,\Delta col),
$$

或图上的 edge type、shortest-path distance、时间差、模态对、page/block relation。

若把多个轴压成单一 scalar distance，会丢方向；若每个轴独立查表相加，则假设轴效应可加。结构编码不是“越多越好”，要检查坐标碰撞、旋转/翻转等变目标及参数增长。

## 十一、缓存与实现账

- Scalar bias 可按 $(T_q,T_k)$ 动态生成，不进入 K/V cache；
- Relative key 通常需要 query—distance interaction，可能增加 score kernel复杂度；
- Relative value 在 aggregation 中多一项，不能只改 mask；
- Causal decode 要用 absolute query offset 与 cached key positions 计算正确 $\Delta$；
- Sliding window 丢弃旧 keys后，cache array index不可冒充绝对位置。

测试应手工构造 $(i,j,\Delta,bucket)$ gold table。

## 十三、常见错误与掌握标准

常见错误：$i-j$ 与 $j-i$ 混用；bias 加在 softmax 后；把 causal mask 当位置 bias；T5 bucket称精确距离；由函数可计算任意 $\Delta$ 推出模型会外推；把常量输入反例无条件扩到含special token/relative value的模型；忽略 relative value 的额外 kernel。

> [!summary]
> 相对位置可注入 logits、relative keys 或 relative values；clip、bucket 和连续 distance function 编码不同分辨率/局部性先验。只改 row-normalized logits 对全同 values 有严格盲区；相对函数有定义仍不等于长上下文可利用。

能重建三种公式与 bucket（A/B）、证明 Toeplitz/常量反例（C）、构造边界与远距碰撞（D），并为真实 kernel/cache写 distance gold test（E）。
