# 图级读出、异构图与任务接口

> [!abstract] 本节主问题
> 同一个 GNN encoder 可服务节点、边、链接和整图任务，但输出对象、对称性、decoder、split 与泄漏风险不同。Graph readout 必须对节点重排不变；异构图还要为节点/边类型、关系方向和参数共享建立明确合同。

## 一、先确定预测对象

给定节点状态 $H=[h_1;\ldots;h_n]$：

- 节点分类：$\hat y_i=c(h_i)$，输出随节点重排；
- 边分类：$\hat y_{ij}=d(h_i,h_j,e_{ij})$，对应已观测边；
- 链接预测：$s(i,j)=d(h_i,h_j,r)$，对候选 pair/relation 打分；
- 图预测：$\hat y_G=c(r(H))$，readout $r$ 对行置换不变。

任务名字相近不代表数据合同相同。Edge classification 可以使用该边属性；link prediction 若把目标边留在 encoder 中，模型直接看到了答案结构。

## 二、Graph readout 的三个典型选择

$$
r_{\text{sum}}=\sum_i h_i,\qquad
r_{\text{mean}}=\frac1n\sum_i h_i,\qquad
r_{\text{max},k}=\max_i h_{ik}.
$$

三者都 permutation invariant，但保留的信息不同：sum 保留 scale/count 线索，mean 对图大小归一化，max 只保留各维极值。可学习 Deep Sets 形式

$$
r(H)=\rho\!\left(\sum_i\phi(h_i)\right)
$$

更灵活；仍需定义域、容量和数值条件。Hierarchical pooling 或 attention readout 必须证明/构造为不变，不能依节点存储顺序。

## 三、Size signal 是特征还是混杂

某些分子性质随原子数增长，sum 合理；某些任务希望比较平均组成，mean 更合适。若 benchmark label 与图大小偶然相关，sum/readout 可能形成 shortcut。应报告仅用 $n,|E|,$ degree histogram 的弱基线，并按 size stratification 检查性能。

## 四、异构图的对象合同

异构图可包含 node type $\tau(v)$ 与 relation type $r(i,j)$。一个关系感知更新可写

$$
h_i'=\sigma\!\left(W_0h_i+
\sum_{r\in\mathcal R}\sum_{j\in\mathcal N_i^r}
\frac1{c_{i,r}}W_rh_j\right).
$$

[[S-2018-Schlichtkrull-RGCN]] 用 relation-specific $W_r$ 建模知识图谱。关系很多时参数量 $O(|\mathcal R|d^2)$，可用 basis/block decomposition 共享结构；这是容量—统计效率取舍，不是纯实现技巧。

## 五、方向、逆关系与 self-loop

事实 `(Paris, capital_of, France)` 有方向。常见做法添加 inverse relation `capital_of_inv`，让消息反向流动；再加 self-loop 保留自身。三类边应有独立或明确共享的参数。

链接预测时若删除正向目标边却保留其 inverse，仍然泄漏。对 temporal KG，还要避免训练 encoder 看见发生在 prediction time 之后的边。

## 六、Decoder 不是 encoder 的附属细节

对链接预测，常见 decoder 如

$$
s_r(i,j)=h_i^\top R_r h_j
$$

或 MLP/translation/bilinear 变体。某些 decoder 对交换 $i,j$ 对称，无法表示反对称关系；某些关系矩阵参数量很大。Encoder 表达结构上下文，decoder 定义候选 pair 如何相互作用，二者必须共同审计。

## 七、Transductive 与 inductive split

- **Transductive node split**：训练时整图结构常可见，只隐藏部分标签；测试节点的信息可在 message passing 中参与；
- **Inductive node split**：测试节点及其相关边不进入训练图；
- **Inductive graph split**：测试是未见整图；
- **Temporal split**：严格按时间截断结构与标签；
- **Link split**：目标边从 encoder graph 移除，并设计 negatives。

随机节点 split 上的高分不能直接归于“泛化到新图”。图依赖也使 i.i.d. 样本直觉失效，需记录 split unit。

## 八、Batching 与空图/孤立点

多张图可做 disjoint union，并用 batch index 指定每个节点所属图；message passing 不跨图，readout 按 batch 分组。实现必须覆盖空邻域、单节点图、不同大小图和 isolated node。若 normalization 对 degree 0 未定义，应在加 self-loop 或显式 convention 后处理。

## 九、Science Space 的经典任务参照

[[S-2019-Su-7006-InfoMap社区发现]]展示无需监督标签的社区发现目标。它提醒我们：一个 graph embedding/readout 是否好，取决于任务需要保留的结构统计；不能只因 embedding 可视化成团就宣称社区目标已优化，也不能把 cluster ID 当作有固定语义的类别编号。

## 十一、常见错误

1. 把 edge classification 与 link prediction 混用；
2. 图分类使用顺序相关 flatten；
3. 忽略 sum/mean 对图大小的不同偏置；
4. 删除目标边却保留 inverse；
5. 用 transductive split 声称 unseen-graph generalization；
6. decoder 对称性与关系语义冲突；
7. batching 时错误跨图连边或跨图 readout。

## 十二、掌握标准

> [!summary]
> - 节点/边/链接/图任务具有不同输出与可见性合同；
> - graph readout 必须不变，并审计 size shortcut；
> - 异构图需要 type/relation/direction/self-loop 参数化；
> - split 与 target-edge removal 是模型定义的一部分。

能为四类任务写形状与对称性（A/B）、证明 readout 不变（C）、发现 inverse-edge leakage（D），并设计 inductive/temporal benchmark（E）。
