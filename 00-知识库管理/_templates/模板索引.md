# 模板索引

创建任何正式节点前先阅读[[00-课程教学与研究总纲]]；模板只是结构提示，不能替代严谨性、证据、数值边界和 AI 接口检查。

| 场景 | 模板 |
|---|---|
| 整理稳定概念 | [[模板 - 概念笔记]] |
| 研读博客、论文或教材 | [[模板 - 来源笔记]] |
| 重建定理或公式链 | [[模板 - 推导与定理]] |
| 系统解释一个模型/模块 | [[模板 - 模型笔记]] |
| 运行数值或模型实验 | [[模板 - 实验笔记]] |
| 组织章节或研究路线 | [[模板 - MOC 与专题]] |
| 保存可证伪问题 | [[模板 - 问题笔记]] |
| 为一个节点建立分级练习 | [[模板 - 习题集]] |
| 保存不直接暴露给题目的完整解答 | [[模板 - 习题解答]] |
| 建立章节或阶段掌握检查 | [[模板 - 阶段测验]] |
| 设计一个图文单元 | [[模板 - 图示设计卡]] |

模板使用 Obsidian 核心 Templates 支持的 `{{title}}` 和 `{{date:YYYY-MM-DD}}`。没有启用核心模板功能时，也可以复制后手工替换。

创建后先填写属性和“一句话结论/研究问题”，再按[[01-研读与成稿工作流]]推进；视觉任务同时遵循[[06-图文编排与制图工作流]]。不要为了填满模板而保留无意义章节。
