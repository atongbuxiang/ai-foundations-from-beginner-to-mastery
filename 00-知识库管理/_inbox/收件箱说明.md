# 收件箱说明

收件箱用于暂存尚未判断归属的 AI URL、问题、公式和灵感，不在这里完成正式笔记。发现内容与 AI 没有直接关系时，不保留书签或摘要。

每条收件至少记录：

```markdown
## 标题

- URL：
- 发现日期：
- 它试图回答的问题：
- 可能关联：[[某节点]]
- 为什么值得处理：
- 范围角色：core / bridge / excluded
- 下一步：建来源笔记 / 补前置 / 放弃
```

每轮专题结束时清理收件箱：`core` 转成来源/问题节点，`bridge` 写明核心调用者，`excluded` 直接移除。不要让收件箱成为永久书签库。
