# 质量门槛与检查清单

本清单是[[00-课程教学与研究总纲]]的机械验收层。任何节点不能因篇幅长、公式多或来源多而自动升级。

## 状态升级规则

```mermaid
flowchart LR
    S["seed: 有问题和骨架"] --> D["draft: 主体成形"]
    D --> V["verified: 证据、推导、边界通过"]
    V --> M["mature: 跨节点贯通并复查"]
```

状态由证据和完成度决定，不由篇幅决定。

## 所有正式节点

- [ ] 标题只表达一个主要问题或对象。
- [ ] 开头说明本页承接的问题、中心问题与后续调用，不让读者猜测课程位置。
- [ ] 一句话结论能独立理解。
- [ ] 首次出现的术语和符号已定义。
- [ ] 属性中的 `type`、`status`、`area`、日期完整。
- [ ] 至少链接一个 MOC 和一个相关/应用节点。
- [ ] 活跃 wiki links 通过 `audit-markdown-wikilinks.mjs` 的对应章节扫描，不存在缺失或歧义解析。
- [ ] 结论区分定义、定理、推导、实验和猜测。
- [ ] 重要来源能追溯到原始页面、页码、公式或定理。
- [ ] 图、表和公式在正文中得到解释。
- [ ] 核心公式按“目的—对象—来路—步骤—读法—检查—去路”形成完整论证，而不是只陈列结果。
- [ ] 公式源码通过 `node 00-知识库管理/_labs/code/audit-markdown-math-source.mjs . --fail`，不存在控制字符、显示公式未闭合或高置信度 TeX 命令缺失。
- [ ] 一级小节之间有因果或问题过渡，每节只新增一个主要认知台阶。
- [ ] 图示先回答明确的视觉问题，并按[[06-图文编排与制图工作流]]完成页面、技术和来源验收。
- [ ] 有效图片嵌入具有根目录稳定路径与数值宽度，图文单元通过仓库级 `audit-markdown-image-embeds.mjs` 和 `audit-markdown-figure-units.mjs` 检查。
- [ ] 图内大标题、正文小节标题和图注没有重复承担同一信息；小图画廊每行不超过两张。
- [ ] 没有大段复制来源或无法确认许可的图片。
- [ ] 明确覆盖直觉、严谨理论、计算/数值和 AI/研究接口中与本节点相关的层次；缺失层次有合理说明。
- [ ] 前沿断言已标明经典定理、已建立方法、经验规律、假说或开放问题。

## 概念节点升级为 `verified`

- [ ] 开头列出最少前置知识，并为非当前章节概念提供回链。
- [ ] 正式定义前有普通语言问题和最小直觉例子。
- [ ] 定义包含定义域、量词和约定。
- [ ] 首次出现的公式解释了关键符号、维度以及公式怎样读。
- [ ] 至少有一个 A 级来源。
- [ ] 有直觉说明，但没有用直觉代替证明。
- [ ] 至少列出两个重要性质。
- [ ] 至少检查一个极端情况或反例。
- [ ] 有一个能够手算到底的最小例子和必要图示。
- [ ] 说明它在 AI 模型中的实际调用点。
- [ ] AI 调用点写明对象映射、关键形状、调用位置、适用条件和失败模式。
- [ ] 涉及计算时区分问题条件性、算法稳定性、浮点实现和资源成本。
- [ ] 相近术语已比较，避免概念混用。
- [ ] 结尾回顾了核心问题、必要条件、例子、误区与后继节点。
- [ ] 已链接一份覆盖 A–E 能力的习题集和独立完整解答。

## 定理/推导节点升级为 `verified`

- [ ] 先用普通语言和最小特例解释目标结论。
- [ ] 假设和目标在推导前完整列出。
- [ ] 每一步变换可以说明依据。
- [ ] 一个推导步若包含多个新操作，已经拆分或补出中间式。
- [ ] `=`、`≈`、`∝`、`≤`、分布等号使用正确。
- [ ] 张量维度和转置位置检查通过。
- [ ] 标量、单位阵、零值或秩一等特例检查通过。
- [ ] 如果省略步骤，明确说明省略内容和引用。
- [ ] 与来源符号不同之处有映射说明。
- [ ] 至少解释移除一个关键假设后会怎样失败。
- [ ] 已有至少一道无提示证明题和一道反例/纠错题。

## 习题集升级为 `verified`

- [ ] A–E 五类能力均有覆盖，题目 ID 唯一稳定。
- [ ] 题干明确对象、维度、条件和输出要求。
- [ ] 提示按方向、结构、计算分级，不直接泄露答案。
- [ ] 至少有一道可以手算到底的基础题。
- [ ] 至少有一道删除假设的反例或纠错题。
- [ ] AI 迁移题要求写出对象、形状和适用条件。
- [ ] 已链接独立解答节点。

## 习题解答升级为 `verified`

- [ ] 每题保留关键中间步骤和所用依据。
- [ ] 计算题包含维度、代回、残差或极端情况检查。
- [ ] 证明题指出最关键的一步和假设使用位置。
- [ ] 反例题验证对象确实满足其余条件。
- [ ] 数值题区分数学公式、算法和浮点实现。
- [ ] 常见错误回链到具体知识节点或小节。

## 阶段测验升级为 `verified`

- [ ] 覆盖表与课程路线一致，不遗漏计算、证明和边界。
- [ ] 题目与答案分离，建议时间和允许工具明确。
- [ ] 评分/自评规则能定位错误类型，而不只给总分。
- [ ] 错题复盘包含具体回链和无提示重做日期。
- [ ] 变式题检查的是迁移，而非记忆原答案。

## 模型节点升级为 `verified`

- [ ] 明确建模对象、输入、输出和目标分布/函数。
- [ ] 有架构图并标注关键张量形状。
- [ ] 训练目标有来源或推导。
- [ ] 训练与推理路径分别说明。
- [ ] 时间、空间或采样复杂度已分析。
- [ ] 关键归纳偏置和失败模式已解释。
- [ ] 与至少一个替代模型进行受控维度比较。
- [ ] 原论文结果没有被扩大到未验证场景。

## 来源节点升级为 `verified`

- [ ] 元数据、URL、版本、访问日期和来源等级完整。
- [ ] `scope_role`、`temporal_role`、官方分类和系列位置已经判断。
- [ ] `bridge` 来源明确链接到至少一个实际调用它的 `core` 节点。
- [ ] 摘要是自己的表达，不是逐段改写。
- [ ] 核心断言已分类并链接到知识节点。
- [ ] 作者的限制、保留意见和实验条件已保留。
- [ ] 原论文、前文、后文和勘误已尽可能找到。
- [ ] 评论区信息仅作为勘误或待验证线索。

## 实验节点升级为 `verified`

- [ ] 研究假设和判断标准预先写明。
- [ ] 环境、版本、数据、随机种子和硬件条件可追溯。
- [ ] 基线和控制变量合理。
- [ ] 结果图轴、单位、图例和误差范围完整。
- [ ] 失败运行和异常没有被选择性删除。
- [ ] 结论没有超出实验覆盖的范围。
- [ ] 代码或命令能重新生成图表。

## 升级为 `mature`

- [ ] 节点至少被两个专题或下游节点实际使用。
- [ ] 与相邻节点的符号和术语保持一致。
- [ ] 有相反观点、反例或后续工作的处理记录。
- [ ] 间隔一段时间重新阅读后仍能复现核心推导。
- [ ] 最近一次复查日期已更新。
