# 习题 - 预训练语料来源、许可、隐私与文档单位合同

## A. 识别与复述

### LM17-A01
区分 source asset、capture record、parsed document、selected example、token sequence 与 loss event。

### LM17-A02
为什么访问条款、robots、内容许可、隐私同意与用途审批不能合并成 `is_open`？

### LM17-A03
WARC 能提供哪些 provenance 字段，又不能证明什么？

## B. 手算与构造

### LM17-B01
为网页→WARC→正文→token shard 画 Entity–Activity 链，并给每层一个 hash/id。

### LM17-B02
论坛 thread 含 5 posts、2 位作者和引用。提出两种 document unit，并比较样本权重/删除粒度。

### LM17-B03
$P(U_1,U_2)=(0.7,0.3)$，crawl率 $(0.5,0.9)$、解析成功率 $(0.8,0.5)$、保留率 $(0.5,0.5)$；计算最终两类比例。

## C. 推导与证明

### LM17-C01
由 Bayes 推导 $Q(d)\propto P_U(u)c(u)r(d\mid u)s(d)$。

### LM17-C02
说明 document segmentation 改变 document-uniform sampling 的概率权重。

### LM17-C03
证明只保存最终 token shard 一般不能唯一恢复 raw asset 与 parser 版本。

## D. 边界、反例与纠错

### LM17-D01
反驳“Common Crawl 可下载，所以全部内容都有统一开放许可”。

### LM17-D02
反驳“公开网页不含隐私风险”。

### LM17-D03
指出“为 provenance 永久保存所有原文”与 data minimization 的冲突。

## E. AI 迁移

### LM17-E01
为一个 web pretraining corpus 写最小 manifest schema。

### LM17-E02
设计 20 样本 lineage 抽查与失败处理。

### LM17-E03
审计一个 dataset card 只给总 URL 数和顶层 `Apache-2.0` 的缺口。
