# 习题 - 计算图、拓扑序与前向执行
## A. 识别与复述
### NN-CG-A01
完整说明计算图的 vertex、edge、local operation 和 execution contract，并区分 architecture diagram。
### NN-CG-A02
区分 external input、parameter、constant、intermediate、random value 与 mutable state。
### NN-CG-A03
定义 topological order，说明它为何可能不唯一。
## B. 手算与建模
### NN-CG-B01
对 $a=x_1x_2, b=\sin x_1, c=a+b, L=c^2$，列出所有边、两个合法拓扑序，并在 $(x_1,x_2)=(2,3)$ 手算 forward。
### NN-CG-B02
对边集 $A\to C,B\to C,B\to D,C\to E,D\to E$，执行 Kahn 算法，每轮写出 ready set。
### NN-CG-B03
将 $Z=XW+b, H=\operatorname{ReLU}(Z), L=\operatorname{mean}(H^2)$ 拆成显式算子图，写出 shape 与 backward 所需缓存。
## C. 推导与证明
### NN-CG-C01
证明 Kahn 算法输出全部节点当且仅当图无环。
### NN-CG-C02
证明对纯函数 DAG，任意合法拓扑序在精确算术下给出同一输出。
### NN-CG-C03
对共享参数 $W$ 在 $T$ 个位置使用的图，证明它是一个 value node 的 fan-out，而不是 $T$ 个独立参数。
## D. 边界、反例与纠错
### NN-CG-D01
构造一个有 cycle 的图，说明为何它不是可直接拓扑执行的 DAG，以及 recurrent program 如何通过 time unrolling 处理。
### NN-CG-D02
反驳：“同一 DAG 的任意拓扑序在 GPU 上都会 bitwise 相同且同样快。”
### NN-CG-D03
给出 in-place mutation 破坏 backward 的最小例子，并说明 versioning 或 functionalization 的作用。
## E. AI 迁移
### NN-CG-E01
为 dropout 设计可复现的 graph record，明确 mode、mask、RNG 和 distributed order。
### NN-CG-E02
对 Transformer 中一个共享 embedding 同时用于 input lookup 与 output projection 的情形，设计 gradient-contribution 审计。
### NN-CG-E03
为 dynamic control flow 模型制定 forward 可复现与 derivative 语义验收清单。
