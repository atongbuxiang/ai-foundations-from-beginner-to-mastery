# 习题 - 通道、卷积核、步幅、填充与膨胀的形状账本

## A. 识别与复述

### ARCH-SHAPE-A01

在 NCHW 下写出 input、grouped weight、bias 与 output 的 shape。

### ARCH-SHAPE-A02

逐索引公式中哪些轴自由，哪些轴被缩并？

### ARCH-SHAPE-A03

区分 standard、grouped、depthwise 与 pointwise convolution。

## B. 手算与建模

### ARCH-SHAPE-B01

使用正文的两个 $2\times2$ patch/kernel，复算输出；若第二个 kernel 改为全 1，结果是多少？

### ARCH-SHAPE-B02

输入 `[4,16,32,32]`，conv 参数 $C_{out}=24,K=3,P=1,S=2,D=1,G=1$。求 output shape、含 bias 参数量和 MACs。

### ARCH-SHAPE-B03

输入 `[2,32,64,64]`，$C_{out}=64,K=3,P=2,S=1,D=2,G=4$。求 effective kernel、output shape、参数和 MACs。

## C. 推导与证明

### ARCH-SHAPE-C01

从最后合法窗口推导二维输出尺寸公式。

### ARCH-SHAPE-C02

推导 grouped convolution 的参数和 MAC 公式；检查 $G=1$ 与 $G=C_{in}$ 两个端点。

### ARCH-SHAPE-C03

推导 standard 与 depthwise+pointwise 参数比 $1/C_{out}+1/K^2$，说明忽略了哪些项。

## D. 边界、反例与纠错

### ARCH-SHAPE-D01

构造一个合法的 $C_{in},C_{out}$，使给定 groups 不合法，并解释原因。

### ARCH-SHAPE-D02

反驳：“dilation=2 等于把 3×3 kernel 变成 5×5 kernel，所以参数变为 25 倍。”

### ARCH-SHAPE-D03

给出一个 depthwise FLOPs 少很多但实际速度提升有限的硬件解释。

## E. AI 迁移

### ARCH-SHAPE-E01

为一个 CNN layer table 设计审计列，至少包含 12 项。

### ARCH-SHAPE-E02

设计把 $224\times224$ RGB 图像变成 $14\times14$、宽 768 tokens 的 patch embedding conv，写出全部超参数、weight shape、参数和 MACs（batch 1）。

### ARCH-SHAPE-E03

若要保持相近 MACs，把空间尺寸减半、通道数加倍是否足够？对 $3\times3$ standard conv 推导比例。
