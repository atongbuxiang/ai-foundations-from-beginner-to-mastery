# 习题 - 投影、约束与可行方向

> [!abstract] 训练目标
> 能从 tangent/normal geometry 推导 stationarity、projection 与 PGD，并在 simplex、PSD、adversarial/nonconvex 场景中识别理论边界。

## A. 识别与复述

### OPT-PROJ-A01

定义 feasible direction、Bouligand tangent cone、linearized cone 和 convex normal cone；说明 $T_C(x)\subseteq L_C(x)$ 为什么不总能取等。

### OPT-PROJ-A02

证明或解释约束一阶条件

$$
\nabla f(x^*)^Td\ge0\ (d\in T_C(x^*))
\Longleftrightarrow
-\nabla f(x^*)\in N_C(x^*).
$$

说明它何时也是 global sufficiency。

### OPT-PROJ-A03

写出 Euclidean projection、projected gradient 与 gradient mapping；说明 closed、convex、nonempty、exact projection、$L$-smooth 与 step size 分别用于哪条结论。

## B. 手算与构造

### OPT-PROJ-B01

分别计算 $z=(3,-1,2)$ 到 box $[0,1]^3$、半径 $2$ 的 $\ell_2$ ball、affine plane $x_1+x_2+x_3=1$ 的 projection。

### OPT-PROJ-B02

计算 $z=(0.8,-0.2,1.7,-0.1)$ 到 probability simplex 的 Euclidean projection。写出排序、$\rho$、threshold $\tau$，并与“截零后归一化”比较。

### OPT-PROJ-B03

令

$$
Z=\begin{bmatrix}1&2\\2&1\end{bmatrix}.
$$

计算到 PSD cone 的 Frobenius projection；报告原矩阵和投影矩阵的 eigenvalues、distance 与 rank。

## C. 推导与证明

### OPT-PROJ-C01

证明 nonempty closed convex set 的 projection 存在且唯一，并推导 projection variational inequality 与 Pythagorean inequality。指出 closed 和 convex 各在哪一步使用。

### OPT-PROJ-C02

由两个 projection variational inequalities 证明 firm nonexpansiveness，再推出 nonexpansiveness。说明为什么这不能直接推广到 nonconvex set。

### OPT-PROJ-C03

从 PGD subproblem 推导

$$
f(x^+)\le f(x)-\left(\frac1\eta-\frac L2\right)\|x^+-x\|^2,
$$

并证明 $G_\eta(x)=0$ 等价于 constrained stationarity。

## D. 反例与失败边界

### OPT-PROJ-D01

分别给出非 closed set 上 projection 不存在、nonconvex set 上 projection 多值、一次 alternating projection 不等于 intersection projection 的反例。

### OPT-PROJ-D02

构造一个约束 boundary optimum 满足 $\nabla f(x^*)\ne0$，并比较 raw gradient norm、projected step norm 和 gradient-mapping norm。解释为什么只看 gradient 会误判。

### OPT-PROJ-D03

反驳“softmax、截零归一化与 Euclidean simplex projection 是同一操作”，并说明三者的 boundary、metric、Jacobian 与数值稳定差异。

## E. AI 迁移

### OPT-PROJ-E01

为 $\ell_\infty$ 与 $\ell_2$ adversarial PGD 写完整 audit：projection、input-domain intersection、ascent sign、restarts、best iterate、inner stationarity 与 global-max 边界。

### OPT-PROJ-E02

设计 covariance/metric learning 的 PSD-constrained experiment：比较 eigenvalue clipping、factor parameterization $LL^T$ 与 barrier；记录 feasibility、rank、conditioning、stationarity 和成本。

### OPT-PROJ-E03

为 inexact projection 的大规模约束训练写误差预算：区分 projection distance、feasibility、subproblem gap、gradient-mapping error 和 outer objective，并给收紧 tolerance 的 schedule。
