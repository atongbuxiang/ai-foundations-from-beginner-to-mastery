# 习题 - 光滑性、强凸性与条件数

> [!abstract] 训练目标
> 能从函数、梯度、Hessian 和 norm 四层审计曲率常数；任何 $L,\mu,\kappa$ 都必须注明函数、区域、坐标和 reduction。

## A. 识别与复述

### OPT-CURV-A01

分别定义 $G$-Lipschitz function、$L$-Lipschitz gradient 和 $M$-Lipschitz Hessian。各给一个用途和一个不能互相替代的例子。

### OPT-CURV-A02

用 shifted function、chord、first-order 和 Hessian 四种语言陈述 $\mu$-strong convexity。比较 convex、strict convex、strong convex 与 PL condition 的逻辑关系。

### OPT-CURV-A03

定义 optimization condition number $\kappa=L/\mu$。解释它为何依赖 norm、coordinate、domain 与 parameterization，并与传统“输入扰动—输出扰动”的问题条件数区分。

## B. 手算与构造

### OPT-CURV-B01

对

$$
f(x)=\frac12x^TQx-b^Tx,
\qquad
Q=\begin{pmatrix}9&0\\0&1\end{pmatrix},
$$

求 Euclidean $L,\mu,\kappa$、minimizer、等高线 axis ratio，以及 $x=Sz$、$S=\operatorname{diag}(1/3,1)$ 后的新 Hessian 和条件数。

### OPT-CURV-B02

对 ridge least squares

$$
f(w)=\frac1{2n}\|Xw-y\|^2+\frac\lambda2\|w\|^2
$$

由 $X$ 的 singular values 求 tight $L,\mu$。分别讨论 rank deficient 且 $\lambda=0$、$\lambda>0$，以及把 mean loss 改成 sum loss 后常数如何变化。

### OPT-CURV-B03

对 binary logistic mean loss 加 ridge，推导 Hessian 并用 $p_i(1-p_i)\le1/4$ 给 $L$ 上界和 $\mu$ 下界。解释 linearly separable、unregularized 情形为何不能据此宣布 finite strongly-convex optimum。

## C. 推导与证明

### OPT-CURV-C01

从 gradient Lipschitz 和 line integral 推导双边 Taylor remainder bound与 descent lemma。明确使用 dual norm 的步骤；再在 $C^2$ Euclidean 情形推导 Hessian operator bound。

### OPT-CURV-C02

从 strong first-order inequality 推导：unique minimizer、quadratic growth、gradient strong monotonicity 和

$$
f(x)-f^*\le\frac1{2\mu}\|\nabla f(x)\|^2.
$$

指出 existence 在哪里需要额外条件。

### OPT-CURV-C03

证明 convex $L$-smooth function 的 cocoercivity，并建立

$$
\frac1{2L}\|\nabla f(x)\|^2
\le f(x)-f^*
\le\frac1{2\mu}\|\nabla f(x)\|^2
$$

以及 distance–gap–gradient 证书链。标出每一侧分别用了什么假设。

## D. 反例与失败边界

### OPT-CURV-D01

证明 $x^4$ strictly convex 但不 globally strongly convex。再给一个 smooth convex function，其 global gradient-Lipschitz constant 不存在，但某个 bounded sublevel set 上存在 finite regional $L$。

### OPT-CURV-D02

给一个满足 PL condition 但不 strongly convex、且 minimizer 不唯一的函数。计算 gradient、function gap、PL constant 和 minimizer set，说明论文中的 PL rate不能被改写成 strong-convex landscape。

### OPT-CURV-D03

设计一个反例/审计，说明单点 Hessian spectrum 或有限个 HVP probes 不能证明 global smoothness/strong convexity。明确什么观测可以否定某个声明，什么观测只能“未发现反例”。

## E. AI 迁移

### OPT-CURV-E01

对 temperature logsumexp 推导 gradient、Hessian、null direction 和 Euclidean smoothness bound。扫描 temperature 时同时设计 max-approximation、Hessian spectrum、overflow 与 precision 实验。

### OPT-CURV-E02

为一个神经网络 curvature report 写审计协议：区分 point/batch Hessian、trajectory region、global parameter space、logit space 与 quotient/restricted space；加入 HVP residual、seed、batch、precision 和 negative-curvature 检查。

### OPT-CURV-E03

比较 feature scaling、diagonal preconditioning、normalization 与 weight decay 对 empirical optimization condition number 的影响。说明为什么改善 Euclidean $\kappa$ 仍不能自动推出更好 validation/generalization。
