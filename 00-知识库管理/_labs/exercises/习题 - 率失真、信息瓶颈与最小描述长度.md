# 习题 - 率失真、信息瓶颈与最小描述长度

> [!abstract] 训练目标
> 从完整 lossy code 重建 $R(D)$、convexity 和 converse；能把 IB 写成 predictive rate–distortion，推导 VIB 两个 variational gaps，并把 negative ELBO、bits-back 与 MDL 放回各自协议。所有 AI 题必须同时报告 population object、estimator、training surrogate 和实际码长/风险。

## A. 识别与复述

### INFO-RDMDL-A01

逐项写出 block lossy source code 的 source law、encoder、message alphabet、decoder、reconstruction alphabet、single-letter/block distortion、rate 与 expected/excess-distortion criterion。解释 test channel $p(\widehat x\mid x)$ 与实际 encoder/decoder 的区别。

### INFO-RDMDL-A02

定义 $R(D)$、零速率阈值 $D_0$ 和 information bottleneck。说明 $R(D)$ 的 monotonicity、convexity、$R(0)$ 的适用条件，以及 IB 中 $I(X;Z)$、$I(Z;Y)$ 各自扮演什么角色。

### INFO-RDMDL-A03

区分以下六个“rate/complexity”：$I(X;\widehat X)$、$I(X;Z)$、entropy-model cross-entropy、实际 bitstream length、parameter count、MDL total length。哪些是 population quantity，哪些必须依赖 code/protocol，哪些不能直接用 bytes 比较？

## B. 手算与构造

### INFO-RDMDL-B01

$X\sim\operatorname{Ber}(1/2)$，Hamming distortion。计算 $D=0,0.1,0.25,0.5$ 时的 $R(D)$（bits/symbol）。对 $D=0.1$ 求 curve slope 与 Lagrange multiplier $\beta=-R'(D)$；构造 achieving binary-symmetric test channel。

### INFO-RDMDL-B02

$X\sim N(0,4)$，squared-error distortion。以 bits/symbol 计算 $D=4,1,0.25$ 时的 $R(D)$。对 $D=1$ 写出一个 achieving backward Gaussian channel，并核对 mutual information。

### INFO-RDMDL-B03

$Y,N\stackrel{\mathrm{ind}}{\sim}\operatorname{Ber}(1/2)$，$X=(Y,N)$。比较四个 encoders：

1. $Z=X$；
2. $Z=Y$；
3. $Z=Y\oplus E$，$E\sim\operatorname{Ber}(0.1)$ independent；
4. $Z$ 为常数。

计算各自的 $(I(X;Z),I(Z;Y))$，指出哪一项只是记住 nuisance，哪一项过度压缩，并计算 $\mathcal L_{IB}=I(X;Z)-2I(Z;Y)$。

## C. 推导与证明

### INFO-RDMDL-C01

用 time sharing 证明 $R(D)$ convex。再对任意 iid memoryless lossy code 推导

$$
nR\ge I(X^n;\widehat X^n)
\ge\sum_iI(X_i;\widehat X_i)
\ge nR(D),
$$

逐步说明 encoder determinism、DPI、memorylessness、$R(D)$ 定义、convexity 与 monotonicity 分别用于哪里。

### INFO-RDMDL-C02

从 $Y-X-Z$ 出发证明

$$
I(X;Y)-I(Z;Y)
=E_{x,z}D_{\rm KL}(p(y\mid x)\|p(y\mid z)).
$$

据此把 IB 写成 rate–distortion Lagrangian，并由 normalization multiplier 推导

$$
p(z\mid x)\propto p(z)
e^{-\beta D(p(y\mid x)\|p(y\mid z))}.
$$

### INFO-RDMDL-C03

推导 VIB 的两个 bounds：

$$
E_XD(q(z\mid X)\|r(z))\ge I_q(X;Z),
$$

$$
I(Z;Y)\ge H(Y)+E\log s(y\mid z).
$$

写出两个 gap。再证明 VAE average negative ELBO 等于 $D+R$，并说明 ideal bits-back net length 为何相同。

## D. 边界、反例与纠错

### INFO-RDMDL-D01

构造一个 distortion misspecification 例子：某重构在 MSE 下更好却在分类/语义任务下更差。说明 Shannon theorem 为什么没有失败；失败的是哪个建模对象？给出至少两种修复协议。

### INFO-RDMDL-D02

解释 continuous $X$、deterministic injective $Z=f(X)$ 时 $I(X;Z)$ 为什么可为 $+\infty$。再说明有限 empirical dataset、binning/noise 改变时 MI estimate 会如何改变，并给出一个可复核的 stochastic/quantized IB 定义。

### INFO-RDMDL-D03

反驳“MDL 就是 train NLL 加 $k\log n/2$，所以与 code、prior、parameterization、data order 无关”。分别用 two-part precision、Bayesian prior、NML normalizer 与 prequential ordering 指出边界；说明何时 BIC-like penalty 只能作为 asymptotic approximation。

## E. AI 迁移

### INFO-RDMDL-E01

设计 learned image codec 的 rate–distortion audit。必须包含 raw data/support、quantization、entropy model、hyperprior/side information、actual coder、header/termination、decoder cost、bpp denominator、至少三类 distortion、empirical frontier、held-out/shift 和 reproducibility。

### INFO-RDMDL-E02

为带 nuisance 的 classification representation 设计 VIB 实验。要求报告 rate upper bound、aggregate-prior gap 的估计、predictive relevance/risk、noise 与 $\beta$ grid、deterministic-MI 边界、calibration、OOD/shift、ablation 和“压缩改善泛化”的可证伪条件。

### INFO-RDMDL-E03

用 MDL 比较 full fine-tuning、LoRA 与 prompt adaptation。写出双方共享信息、model/update code、tokenizer/base model、label/data prequential code、parameter precision、ordering、optimizer randomness、compute 与 deployment risk。指出哪些 cost 可以换成 bits，哪些只能作为并列资源指标。

## 分级提示

- `B01`：$R(D)=1-h_2(D)$，$h_2(0.1)\approx0.468996$；
- `B02`：bits convention 下 $R(D)=\tfrac12\log_2(4/D)$；
- `B03`：$I(Y;Y\oplus E)=1-h_2(0.1)$；
- `C01`：用 $H(M)\le nR$，不要错误写成 equality；
- `C02`：先用 MI chain rule，再把 conditional MI 写成 expected KL；
- `C03`：两个 gap 分别是 aggregate-prior KL 与 predictor conditional KL；
- `D03`：先问是否真的定义了可归一化、可译码 probability/code。
