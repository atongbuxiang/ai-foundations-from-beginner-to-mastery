# 习题 - 预测器、假设空间与学习算法

> [!abstract] 训练目标
> 把 parameterization、function class 与 selection algorithm 分层；理解非可辨识参数、tie-breaking、随机算法和 data-dependent class。

## A. 识别与复述

### LT-HYP-A01

解释 $\Theta,\Phi,\mathcal H_\Phi,A_\Theta,A$ 的 domain/codomain，并画出组合关系。

### LT-HYP-A02

定义 proper/improper learner、deterministic/randomized learner。每类给出一个可能例子。

### LT-HYP-A03

分别说明 architecture、initialization、optimizer、regularizer、early stopping 主要进入函数类、参数化还是算法层；允许一个对象影响多层，但须解释。

## B. 手算与构造

### LT-HYP-B01

对 $h_{a,b}(x)=(a+b)x$，求 $h(x)=3x$ 的 fiber；计算其中最小二范数参数，并说明 gradient descent 从零初始化可能偏向哪个代表。

### LT-HYP-B02

对阈值类 $h_t(x)=\mathbf1\{x\ge t\}$ 和样本 $(-2,0),(-1,0),(1,1),(2,1)$，求所有零训练误差的 $t$；构造两个不同 tie-breaking learner。

### LT-HYP-B03

两层 ReLU 标量网络 $h_{u,v}(x)=v\operatorname{ReLU}(ux)$。取 $(u,v)=(2,3)$，写出一族表示同一函数的参数，并求 $u^2+v^2$ 在该 rescaling orbit 上的最小值。

## C. 推导与证明

### LT-HYP-C01

证明 $\Phi:\Theta\to\mathcal H$ 非单射时，参数空间上的量 $g(\theta)$ 能下降为函数空间量，当且仅当它在每个 fiber 上常数。

### LT-HYP-C02

对 `B01` 的参数化与平方经验损失，证明 Hessian 至少有一个零特征值；给出零方向。

### LT-HYP-C03

证明若 $A_\Theta$ 随机而 $\Phi(A_\Theta(S,U))$ 几乎处处不依赖 $U$，则 parameter learner 随机但 function learner 可视为确定性。解释这为何可能发生在对称参数化中。

## D. 边界、反例与纠错

### LT-HYP-D01

纠正：“参数更多，所以 VC 维必定严格更大。”至少讨论冗余参数、共享参数与无限精度实数参数的边界。

### LT-HYP-D02

纠正：“某架构能表示 Bayes predictor，所以 SGD 一定能学到它。”用量词列出 representation、optimization 与 finite-sample 三个鸿沟。

### LT-HYP-D03

某团队先用全部数据选出 100 个最相关特征，再在同一数据上对 100 维线性类套泛化界。指出 fixed-class assumption 如何被破坏，并给出三种修复方法。

## E. AI 迁移

### LT-HYP-E01

比较 frozen encoder + linear probe 与 full fine-tuning 的 $\Theta,\Phi,\mathcal H,A$；哪些性能差异不能只归因于“representation quality”？

### LT-HYP-E02

为一个含 dropout 与随机 mini-batch 的神经网络 learner 写清 $A(S,U)$。设计实验分离 data randomness 与 algorithm randomness。

### LT-HYP-E03

分析 weight decay 在正齐次网络中的 function/parameter ambiguity。提出一个更接近 function behavior 的复杂度或验收量，并说明它仍有什么限制。

## 分级提示

- `B01`：约束 $a+b=3$ 下最小化 $a^2+b^2$；
- `B03`：取 $u'=cu,v'=v/c$；
- `C02`：loss 只依赖 $a+b$；
- `C03`：参数可随 $U$ 沿 fiber 移动；
- `D03`：sample splitting、union over classes、把 selection 纳入 learner。
