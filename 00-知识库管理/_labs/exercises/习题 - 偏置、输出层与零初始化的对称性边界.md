## A

### NN-ZERO-A01
什么是 hidden unit 的完整 parameter bundle？为什么只比较 incoming rows 不足以判断 symmetry？

### NN-ZERO-A02
说明 deterministic SGD 为何保持两个完全相同 hidden units 的等式关系。

### NN-ZERO-A03
分别判断 hidden weights、hidden bias、单层 linear model、output head 与 residual branch last layer 的零初始化风险。

## B

### NN-ZERO-B01
对 $h=\phi(W_1x+b_1),\hat y=W_2h+b_2$ 写出 $\nabla W_2$ 与 $\nabla W_1$，并代入全零、tanh activation。

### NN-ZERO-B02
二分类 logistic regression 有 $X=\begin{bmatrix}1&0\\0&1\end{bmatrix}$、$y=(1,0)^T$。在 $w=b=0$ 时计算 prediction 与 gradient（loss 取样本和）。

### NN-ZERO-B03
令 encoder feature $h=(2,-1)^T$、zero-initialized scalar output head $w=0$，平方损失 $\frac12(w^Th-y)^2$、$y=3$。求第一步 $\nabla_wL$ 与 $\nabla_hL$。

## C

### NN-ZERO-C03
对 $y=x+W_2\phi(W_1x)$ 且 $W_2=0$，推导第一步 $\nabla W_2$、$\nabla W_1$ 与 $\partial y/\partial x$。

## D
