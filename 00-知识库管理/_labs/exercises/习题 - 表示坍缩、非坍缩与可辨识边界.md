# 习题 - 表示坍缩、非坍缩与可辨识边界

> [!abstract] 训练目标
> 能区分 collapse 层级，手算 covariance/effective rank/VICReg/Barlow 统计，解释 negatives 与 asymmetric teacher dynamics，并把 non-collapse、identifiability、sufficiency 和 transfer 分层验收。

## A. 识别与复述

### LT-COL-A01

定义 complete、dimensional、spectral 与 semantic collapse；coordinate non-identifiability 为什么不一定是 collapse？

### LT-COL-A02

列出 per-coordinate、spectrum、geometry、dynamics、task 与 shift 六层诊断，每层给出一个直接统计量。

### LT-COL-A03

比较 negatives、VICReg variance/covariance、Barlow cross-correlation 与 stop-gradient/EMA：它们直接改变的是 objective feasible set、batch statistic 还是 gradient dynamics？

## B. 手算与局部推导

### LT-COL-B01

对 $C=\operatorname{diag}(9,1,0)$ 计算 rank、stable rank、participation ratio 与 entropy effective rank，并解释为什么四个数给出不同“维度”。

### LT-COL-B02

VICReg 取 $d=2$、$\gamma=1$、$\varepsilon=0$。batch embeddings 全为 $(3,-2)$，两 views 相同。计算 invariance、variance 与 covariance 三项；指出哪项排除 constant solution。

### LT-COL-B03

给两视图标准化后的 cross-correlation
$C=\begin{pmatrix}0.9&0.2\\-0.1&0.8\end{pmatrix}$，$\lambda=0.5$。计算 Barlow Twins loss，并区分 diagonal 与 off-diagonal 贡献。

## C. 证明与反例

### LT-COL-C01

证明任意 positive-pair squared agreement-only objective 都有常数 global minimizer。为什么这不推出 SGD 必然坍缩？

### LT-COL-C02

证明 $B$ 个中心化样本的 $d\times d$ sample covariance rank 至多 $\min(d,B-1)$。这对 $d=2048,B=256$ 的 full-rank claim 意味着什么？

### LT-COL-C03

构造一个 covariance 为 identity、effective rank 为 $d$，但与下游 label 独立的表示；据此反驳“高 rank 即语义充分”。

## D. 审计与诊断

### LT-COL-D01

八卡分布式训练中，每卡 batch 32、embedding dim 512。比较 local covariance、all-gather global covariance 与 EMA covariance 三种目标；列出 rank、communication、staleness 与 BN 泄漏问题。

### LT-COL-D02

画出 SimSiam 的 forward/backward dependency graph，说明移除 stop-gradient 后为何 forward loss 可相同而 vector field 改变。需要监控哪些 gradient norms？

### LT-COL-D03

某报告只给训练 batch 的每维 std 均大于 0.5，便宣称“BYOL 已证明不会坍缩且学到语义”。逐层拆解该 claim，并给出最小补充实验。

## E. 研究与迁移

### LT-COL-E01

设计一个跨 layer、batch size、worker count、dtype 与 downstream task 的 collapse dashboard；规定 threshold、confidence interval 与 alarm priority。

### LT-COL-E02

若 $Z_2=AZ_1$ 且 $A$ 可逆，比较 linear probe、kNN、cosine retrieval、covariance spectrum 与 individual neurons 哪些不变；分别给出 $A$ 正交和一般可逆两种答案。

### LT-COL-E03

提出一种新的 non-contrastive 防坍缩方法，并给出四层证据计划：排除常数解、local dynamics、finite-batch robustness、task-family transfer。明确哪一层仍不能由实验普遍证明。
