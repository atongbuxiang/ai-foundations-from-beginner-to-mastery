# 习题 - 条件核、边缘一致性与统一离散扩散框架
## A. 识别与复述
### GEN47-A01
用测度形式和 density 形式分别写出 marginal-consistency 条件。
### GEN47-A02
区分训练时的 teacher kernel $r_t(x_{t-1}|x_t,x_0)$ 与部署时 reverse kernel 的条件信息。
### GEN47-A03
为什么“概率合法”“利用当前状态”“有限模型可学”是三道不同的门？
## B. 手算与建模
### GEN47-B01
验证正文 $R=\begin{pmatrix}0.8&0.7\\0.2&0.3\end{pmatrix}$ 将 $q_t=(1/2,1/2)^T$ 推送为 $(3/4,1/4)^T$。
### GEN47-B02
设二状态 kernel 的第一行是 $(a,b)$，$q_t=(1/2,1/2)$，目标第一分量为 $3/4$。求全部可行 $(a,b)$ 的范围，并给两个不同 coupling。
### GEN47-B03
给 $q_t=(0.6,0.4)$ 和 independent kernel 两列均为 $(0.2,0.8)^T$，计算输出并判断是否使用了 $x_t$。
## C. 推导与证明
### GEN47-C01
证明 independent kernel $r_t(\cdot|x_t,x_0)=q_{t-1}(\cdot|x_0)$ 必满足一致性。
### GEN47-C02
从全概率公式推出 $q(x_{t-1}|x_t)=\int r_t(x_{t-1}|x_t,x_0)q(x_0|x_t)dx_0$。
### GEN47-C03
若每个理想 Markov kernel 对 total variation 非扩张，证明替换一个近似 kernel 后的单步输入误差不会被该理想 kernel 放大；说明这为何还不是完整多步误差界。
## D. 边界、反例与纠错
### GEN47-D01
用 independent kernel 反驳“一致性推出 kernel 充分利用 $x_t$”。
### GEN47-D02
反驳“平方损失学到 conditional mean 就等于学到完整 reverse kernel”。
### GEN47-D03
纠正“每步 MSE 都小，所以最终生成分布误差至多是这些 MSE 的和”。
## E. AI 迁移

### GEN47-E02
设计有限状态 kernel 的自动一致性检查器及失败诊断。
### GEN47-E03
比较 Gaussian noise、blur 与 deletion 三种 corruption 时，哪些统一接口可以复用，哪些推导必须重做？
