# 习题 - 无损编码、典型集与渐近等分性

> [!abstract] 训练目标
> 从 Kraft–McMillan 与平均码长界理解 prefix coding；能手工构造 Huffman code，证明 AEP 和典型集大小界，并把 source coding theorem 的有限块边界迁移到语言模型、tokenizer 与 model mismatch 审计。

## A. 识别与复述

### INFO-CODE-A01

区分 nonsingular、uniquely decodable、instantaneous/prefix 与 fixed-length code，并给出严格蕴含关系及每个逆命题的反例或说明。解释 decoder 为什么关心整段可唯一解析而不只是单符号码字不同。

### INFO-CODE-A02

陈述 binary Kraft inequality、McMillan inequality、Shannon code average-length bound 与 Huffman optimality。指出哪些是存在性、哪些是必要性、哪些只在已知 finite alphabet distribution 和 binary prefix code 类内成立。

### INFO-CODE-A03

分别陈述 iid finite-alphabet AEP、weakly typical set 的三项性质、fixed-length lossless source coding theorem 与 entropy rate。区分 Shannon–McMillan–Breiman theorem 所需条件与 iid LLN 证明。

## B. 手算与构造

### INFO-CODE-B01

对 $p=(0.4,0.3,0.2,0.1)$ 构造一棵 binary Huffman tree，给出一组 codewords、lengths、平均码长 $L$ 与 $H_2(P)$。验证 $H_2(P)\le L<H_2(P)+1$ 和 Kraft equality。

### INFO-CODE-B02

$X_i\overset{iid}{\sim}\operatorname{Ber}(0.25)$，$n=8$。对任一恰含两个 1 的序列：求 probability、每符号 surprise、这种 type 的序列数与总 probability。比较每符号 surprise 和 $H_2(0.25)$；说明 $n=8$ 时为什么不能把 asymptotic 近似当等号。

### INFO-CODE-B03

对 block $X^n$ 使用 Shannon lengths $\ell(x^n)=\lceil-\log_2p(x^n)\rceil$。证明 $H(X^n)\le E\ell(X^n)<H(X^n)+1$，并在 iid 时除以 $n$。若 $H(X)=1.846$ bits、$n=100$，给出每符号 redundancy 的最坏上界。

## C. 推导与证明

### INFO-CODE-C01

使用 Kraft inequality 与 log-sum/Gibbs inequality 证明任意 binary uniquely decodable code 满足 $L\ge H_2(P)$。再解释为什么实数理想长度 $-\log_2p_i$ 不自动给出合法整数 code。

### INFO-CODE-C02

令

$$
A_\varepsilon^{(n)}=\left\{x^n:\left|-\frac1n\log_2p(x^n)-H_2(X)\right|<\varepsilon\right\}.
$$

由 weak law 证明 AEP，并推导 typical set 的 probability、单序列 probability 上下界以及 cardinality 上下界。明确下界为何含 $1-\delta$。

### INFO-CODE-C03

证明 iid finite-alphabet fixed-length source coding 的 achievability 与 converse：当 $R>H(X)$ 时构造 error $\to0$ 的 code；当 $R<H(X)$ 时证明任何至多 $2^{nR}$ 个 codewords 的 code 成功概率 $\to0$。说明这是块错误概率结论，不是有限 $n$ 的零错误结论。

## D. 边界、反例与纠错

### INFO-CODE-D01

公平 coin 的长度 $n$ 序列中，每个 sequence 同样可能；偏置 coin $p(1)=0.01$ 时，全零序列最可能。解释为什么“最可能序列”“众数附近的 type”“Shannon weakly typical set”不是同一概念，并分析全零序列的 per-symbol surprise 是否趋近 entropy。

### INFO-CODE-D02

真实 source 为 $P=\operatorname{Ber}(0.8)$，却用 $Q=\operatorname{Ber}(0.6)$ 的理想 code。计算 bits 下的 matched cost、mismatched cross-entropy 与 excess cost。若 $Q$ 由训练数据学得，还需报告哪些 model/data costs 才能把结果称作完整压缩方案？

### INFO-CODE-D03

构造非 ergodic source：先抽一次 $C\sim\operatorname{Ber}(1/2)$；若 $C=0$，以后全为 0；若 $C=1$，以后为 iid fair bits。求 entropy rate，并说明 $-n^{-1}\log P(X^n)$ 为什么不 almost surely 收敛到同一个常数。它揭示了把 iid AEP 任意推广到序列数据的什么问题？

## E. AI 迁移

### INFO-CODE-E01

一个 byte-level language model 在 held-out corpus 上 NLL 为 $0.9$ nats/byte，另一个 token model 为 $1.7$ nats/token、平均 $3.2$ bytes/token。换算二者的 bits/byte 并比较；列出把 NLL 变成实际 arithmetic-coded 文件大小还缺的 overhead 与 correctness 检查。

### INFO-CODE-E02

两个 tokenizer 在各自 token 上报告 perplexity 20 与 15。解释为什么不能直接判定后者压缩更好；设计一个公平 benchmark，至少统一原始 byte corpus、normalization、train/eval split、bits/byte、vocabulary/model cost、unknown handling 与 arithmetic coder overhead。

### INFO-CODE-E03

某生成模型只保留“概率最高的 $2^{nH}$ 个序列”，并把它称为“typical decoding”，声称因此无偏地代表 source。审计该论证：区分 top-probability set 与 typical set、coverage 与 per-sequence probability、finite-$n$、entropy estimate、mode collapse 和 sampling objective。

## 分级提示

- `B01`：依次合并 $0.1,0.2$，再合并 $0.3,0.3$；
- `B02`：单序列 probability 为 $0.25^2 0.75^6$，type size 为 $\binom82$；
- `C01`：令 $q_i=2^{-\ell_i}/K$，其中 $K=\sum_i2^{-\ell_i}\le1$；
- `C03`：converse 把成功集拆成 typical 与 atypical 部分；
- `D03`：两条 ergodic component 上的 surprise rate 不相同；
- `E01`：nats 转 bits 除以 $\ln2$。
