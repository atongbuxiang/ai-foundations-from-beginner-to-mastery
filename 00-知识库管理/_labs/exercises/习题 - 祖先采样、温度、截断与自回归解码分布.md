# 习题 - 祖先采样、温度、截断与自回归解码分布

## A. 识别与复述

### GEN07-A01
写出 temperature、top-$k$ 与 top-$p$ 后的条件核，并说明各自改变什么。

### GEN07-A02
区分 ancestral sampling、greedy 和 beam search 的输出对象。

### GEN07-A03
max length 为什么不是“原模型几乎必然终止”的证据？

## B. 手算与建模

### GEN07-B01
$p=(0.5,0.3,0.15,0.05)$。求 $\tau=1/2$、top-2 与 top-$p=0.8$ 分布（约定最小集合且含达到阈值项）。

### GEN07-B02
两个时间步的模型条件为 $p(x_1=A)=0.6$；若 $A$ 后 $p(EOS)=0.2$，$B$ 后为 0.9。求长度 2 内终止概率。

### GEN07-B03
给 3 个 token 的概率 $(0.7,0.2,0.1)$，比较“先 $\tau=0.5$ 后 top-$p=0.8$”与“先 top-$p=0.8$ 后温度”的候选集合和概率。

## C. 推导与证明

### GEN07-C01
证明 $q_\tau\propto p^{1/\tau}$，并求 $\tau\to0,\infty$ 极限（有限词表、唯一最大值）。

### GEN07-C02
若每个未终止前缀 EOS 概率至少 $\epsilon$，证明 $P(T_{EOS}>t)\le(1-\epsilon)^t$。

### GEN07-C03
证明任一前缀的 top-$k$ 截断与原分布 TV 恰等于被删除的总质量。

## D. 边界、反例与纠错

### GEN07-D01
构造 greedy 不是最高联合概率序列的两步反例。

### GEN07-D02
构造 top-$p$ 把 EOS 删掉而导致输出系统性变长的例子。

### GEN07-D03
解释为什么更大 beam 可能降低外部任务指标，即使找到更高模型 score。

## E. AI 迁移

### GEN07-E01
设计 decoding sweep，报告 quality、diversity、repetition、length、truncated mass 和 latency。

### GEN07-E02
为 JSON 约束生成写出 mask 后的 $q$，并说明死状态、归一化和有效性测试。

### GEN07-E03
审计某 API 只公开 temperature/top-p 参数却不说明顺序：提出最小黑盒实验推断其实现。
