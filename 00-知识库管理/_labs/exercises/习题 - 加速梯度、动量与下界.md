# 习题 - 加速梯度、动量与下界

> [!abstract] 训练目标
> 能把“动量更快”拆成 quadratic roots、general convex potential、oracle lower bound 与真实训练四类证据，并在每次迁移时保留函数类、metric、输出对象和预算。

## A. 识别与复述

### OPT-ACC-A01

写出 gradient descent、Polyak heavy-ball 和一种 Nesterov look-ahead 更新。逐项说明 gradient evaluation point、memory state 和常见实现约定为何可能不同。

### OPT-ACC-A02

分别陈述 smooth convex 与 smooth strongly convex 的 Nesterov accelerated rate，并与 gradient descent 比较。写明 function gap、初始距离、$L,\mu,\kappa$ 和 oracle-call complexity。

### OPT-ACC-A03

解释 first-order oracle lower bound 的四个组成：函数类、oracle information、误差准则与维度。为什么它既能说明 Nesterov 的最坏情形最优性，又不能说明每个具体模型都难？

## B. 手算与构造

### OPT-ACC-B01

对 $f(x)=\frac12\lambda x^2$，heavy-ball 使用 $\eta=0.2,\beta=0.64$。分别令 $\lambda=1,9,12$：

1. 写 characteristic polynomial；
2. 求 roots 或其模；
3. 分类为非振荡收敛、振荡收敛、边界或发散；
4. 从 $x_{-1}=x_0=1$ 计算前三步。

### OPT-ACC-B02

令 $Q=\operatorname{diag}(1,16)$。计算：

1. 最佳 constant-step GD 的 $\eta_*,\rho_*$；
2. quadratic-optimal heavy-ball 的 $\eta_{HB},\beta_{HB},\rho_{HB}$；
3. 把误差缩小到 $10^{-6}$ 所需的 asymptotic iteration estimates；
4. 解释 function gap factor 与 error-norm factor 的平方关系何时成立。

### OPT-ACC-B03

取 time-varying Nesterov sequence $t_1=1$，计算 $t_2,t_3,t_4$ 与 extrapolation coefficients $(t_k-1)/t_{k+1}$。验证 $t_{k+1}^2-t_{k+1}=t_k^2$，并检查 $t_k\ge(k+1)/2$。

## C. 推导与证明

### OPT-ACC-C01

从 quadratic error recurrence 推导 heavy-ball characteristic polynomial，并用 Jury 条件证明对 $0\le\beta<1$ 的单 mode 稳定性当且仅当 $0<\eta\lambda<2(1+\beta)$。

### OPT-ACC-C02

对 convex $L$-smooth $f$，令 $x^+=y-L^{-1}\nabla f(y)$。完整证明三点不等式

$$
f(x^+)-f(u)\le\frac L2(\|u-y\|^2-\|u-x^+\|^2).
$$

再说明它如何与 $t_{k+1}^2-t_{k+1}=t_k^2$ 结合成 accelerated potential。

### OPT-ACC-C03

假设 accelerated potential

$$
t_k^2(f(x_k)-f^*)+\frac L2\|z_k\|^2
\le\frac L2\|x_0-x^*\|^2.
$$

用 $t_k\ge(k+1)/2$ 推导 $O(1/k^2)$ bound 与达到 $\varepsilon$ 的复杂度。再写出 matching lower-bound statement 的所有限定。

## D. 反例与失败边界

### OPT-ACC-D01

构造一个 scalar quadratic，使 heavy-ball 的 objective 在若干步上升但最终收敛；再构造 $|r|=1$ 和 $|r|>1$ 的参数。说明“单步 loss 上升”“不收敛”“发散”不是同义词。

### OPT-ACC-D02

反驳：“quadratic-optimal heavy-ball 参数只由当前 Hessian 的最小/最大 eigenvalue 决定，因此对任意深网全程最优。”至少指出八个缺口，并给出可测诊断。

### OPT-ACC-D03

某报告声称：“NAG 在 1000 steps 达到更低 train loss，所以突破了一阶 oracle 下界，也必然有更好泛化。”逐层审计算法、预算、函数类、下界、统计与实现问题。

## E. AI 迁移

### OPT-ACC-E01

设计 $(\eta L,\beta)$ quadratic root map 实验：理论 roots、trajectory、objective、velocity、precision、overflow 和 restart 均需记录。给出预注册的稳定/振荡判定规则。

### OPT-ACC-E02

为 logistic/ridge regression 比较 GD、HB、NAG。要求相同 gradient-call 与 wall-clock 两种预算，包含 $L,\mu$ 的真值/误设、last/best iterate、restart 与统计不确定性。

### OPT-ACC-E03

为 Transformer 训练设计 momentum convention audit。要求解析 optimizer source/config，重建 effective step，控制 batch/accumulation/clipping/decay/scheduler/precision，并区分优化速度、稳定性与泛化。
