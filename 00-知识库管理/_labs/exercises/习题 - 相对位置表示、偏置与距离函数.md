# 习题 - 相对位置表示、偏置与距离函数

## A. 识别与复述

### ARCH-REL-A01
区分 relative logit bias、relative key 与 relative value 三种注入位置，并写出代表公式。

### ARCH-REL-A02
说明 clipping、线性距离、对数分桶和二维/图距离分别注入了什么先验。

### ARCH-REL-A03
ALiBi 的 head-specific slope 改变的是什么？它没有直接改变什么？

## B. 手算与建模

### ARCH-REL-B01
给定 logits $(0,0,0)$、相对偏置 $(0,-1,-2)$，计算 softmax 权重的精确式与近似值。

### ARCH-REL-B02
采用裁剪距离 $c(r)=\max(-2,\min(2,r))$，为长度 4 的双向序列写出完整 bucket 矩阵 $c(i-j)$。

### ARCH-REL-B03
在 causal attention 中使用偏置 $b(i-j)=-m(i-j)$，取 $m=0.5$。写出 query 位置 $i=3$ 对 keys $j=0,1,2,3$ 的偏置。

## C. 推导与证明

### ARCH-REL-C01
证明若所有 value 都等于同一向量 $v$，任何行归一化 attention 权重都给出相同输出 $v$。

### ARCH-REL-C02
说明 relative value 项 $a^V_{i-j}$ 如何打破上一题结论，并写出仍然失效的充分条件。

### ARCH-REL-C03
推导对数分桶在远距离区域为何用较少参数覆盖更大距离范围，并给出一个分段 bucket 函数。

## D. 边界、反例与纠错

### ARCH-REL-D01
反驳：“attention weights 随位置变化，因此输出一定编码了位置。”

### ARCH-REL-D02
构造 clipping 使两个远距离关系无法区分的例子；说明内容通道可能补偿但不推翻结构碰撞。

### ARCH-REL-D03
解释“距离越远偏置越负”为什么不等价于 attention 概率必随距离单调下降。

## E. AI 迁移

### ARCH-REL-E01
为相对位置模块设计 constant-value、bucket-boundary、causal sign 与 padding 四类单元测试。

### ARCH-REL-E02
比较相对 bias、relative K/V 与 RoPE 的缓存、参数、计算和表达接口。

### ARCH-REL-E03
设计一个实验，检验模型的长程表现提升来自距离先验、训练长度还是局部窗口。
