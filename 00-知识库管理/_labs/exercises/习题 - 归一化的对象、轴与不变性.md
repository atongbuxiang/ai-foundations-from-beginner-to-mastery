# 习题 - 归一化的对象、轴与不变性

## A

### NN-NAX-A01
写出一个 normalization 算子的四元组合同：统计组、affine sharing、state rule 与 $\varepsilon$ convention。分别说明每一项遗漏后有哪些不同算子会被混为一谈。

### NN-NAX-A02
对 $X\in\mathbb R^{B\times T\times D}$，写出 LayerNorm$(D)$ 的归约轴、保留轴、$\mu/q$ shape、$\gamma/\beta$ shape 与输出 shape。

### NN-NAX-A03
对 $X\in\mathbb R^{N\times C\times H\times W}$，写出 BatchNorm2d、InstanceNorm2d 与 GroupNorm$(G)$ 的统计组；不要只列模块名。

## B

### NN-NAX-B01
对
$$X=\begin{bmatrix}1&2&3\\10&20&30\end{bmatrix}$$
分别按行和按列做 $\varepsilon=0$、无 affine 的标准化，计算全部输出并检查每组均值与平方均值。

### NN-NAX-B02
一组输入为 $(2,2,2)$，$\gamma=(1,2,3)$、$\beta=(-1,0,1)$。分别在 $\varepsilon=0$ 的形式极限与 $\varepsilon=10^{-5}$ 下计算输出，解释为何“unit variance”失效。

### NN-NAX-B03
有效 mask 为 $M=(1,1,0,0)$，输入 $x=(1,3,100,100)$。计算 masked 与 unmasked mean/biased variance，说明 padding 怎样改变真实元素的标准化值。

## C

### NN-NAX-C01
证明 $P=I-\boldsymbol1\boldsymbol1^{\mathsf T}/m$ 是到 $\boldsymbol1^\perp$ 的正交投影，并说明 normalization 的 centering 删除了哪个自由度。

### NN-NAX-C02
对 $\boldsymbol x'=a\boldsymbol x+b\boldsymbol1$ 推导 $\widehat{\boldsymbol x'}$。精确分类 $a>0$、$a<0$、$\varepsilon=0$ 与 $\varepsilon>0$。

### NN-NAX-C03
证明 affine 前标准化组满足
$$\overline{\widehat x}=0,\qquad
\overline{\widehat x^2}=q/(q+\varepsilon),$$
并说明 affine 后这两个结论分别需要哪些额外条件才能继续成立。

## D

### NN-NAX-D01
反驳：“所有 normalization 都只是把数据换成标准正态分布，所以只需比较数值稳定性。”

### NN-NAX-D02
比较
$$\frac{x-\mu}{\sqrt{q+\varepsilon}}
\quad\text{与}\quad
\frac{x-\mu}{\sqrt q+\varepsilon}.$$
构造 $q=0$ 与 $q\ll\varepsilon$ 的例子，说明二者不可交换。

### NN-NAX-D03
某实现把 $(B,T,D)$ 的 normalized shape 从 $D$ 改成 $(T,D)$，单元测试只检查输出 shape 不变。指出至少四项语义变化，并给出一个因果模型中的风险。

## E

### NN-NAX-E01
为一个未知 normalization kernel 写十项审计表，必须覆盖 axis、estimator、epsilon、dtype、affine、state、mode、mask、distributed grouping 与退化输入。

### NN-NAX-E02
设计一个只用 $2\times3$ 或 $2\times2\times2$ 小张量的测试套件，能区分 BatchNorm、LayerNorm、InstanceNorm 与“全张量归一化”；说明每个测试判别哪条轴合同。

### NN-NAX-E03
条件归一化令 $\gamma=\gamma(c),\beta=\beta(c)$。写出前向对象与全部关键 shape，分析条件只进入 affine 与条件同时进入统计组的两种设计在依赖图和不变性上的区别。
