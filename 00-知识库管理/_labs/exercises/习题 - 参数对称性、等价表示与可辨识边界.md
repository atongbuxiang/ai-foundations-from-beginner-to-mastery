# 习题 - 参数对称性、等价表示与可辨识边界
## A. 识别与复述
### NN-SYM-A01
定义 $\Phi:\Theta\to\mathcal F$、parameter fiber、equivalence class 与 identifiability modulo symmetry。
### NN-SYM-A02
区分 hidden-unit parameter permutation 与 input permutation equivariance。
### NN-SYM-A03
列出 ReLU、tanh、sigmoid 各自允许或不允许的基本 sign/scale symmetry。
## B. 手算与建模
### NN-SYM-B01
给两 hidden units 的数值 $W_1,b_1,W_2$，用交换矩阵 $P$ 写出等价参数并验证一个输入。
### NN-SYM-B02
对 $f(x)=3\operatorname{ReLU}(2x+1)$，构造 $c=5$ 的正缩放等价参数；比较参数 norm。
### NN-SYM-B03
把一个 ReLU unit $a\operatorname{ReLU}(w^Tx+b)$ 拆成两个相同 incoming units，给出全部 outgoing weight 分配族。
## C. 推导与证明
### NN-SYM-C01
用矩阵公式证明多 hidden units 的 permutation symmetry。
### NN-SYM-C02
用 positive homogeneity 证明 diagonal scaling symmetry，并说明为什么 $D$ 必须正。
### NN-SYM-C03
证明沿光滑连续 symmetry orbit，function-only loss 的一阶方向导数为零；Hessian 零方向还需什么条件？
## D. 边界、反例与纠错
### NN-SYM-D01
构造参数欧氏距离任意大但函数完全相同的 ReLU 网络对。
### NN-SYM-D02
给出未经 hidden-unit alignment 直接平均两个等价网络而改变函数的例子。
### NN-SYM-D03
纠正：“置换和缩放是任意神经网络全部的 symmetry，所以参数始终不可恢复。”
## E. AI 迁移
### NN-SYM-E01
为 checkpoint merging 设计 symmetry-aware pipeline。
### NN-SYM-E02
解释 symmetry 对 Bayesian posterior mean、MCMC mode counting 与 predictive posterior 的不同影响。
### NN-SYM-E03
设计 mechanistic interpretability 中的 neuron matching 评估，避免 raw weight comparison。
