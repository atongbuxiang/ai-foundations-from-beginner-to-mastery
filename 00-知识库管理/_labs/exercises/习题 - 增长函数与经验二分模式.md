# 习题 - 增长函数与经验二分模式

> [!abstract] 训练目标
> 能从具体 class 枚举 restrictions，计算增长函数，并判断经验模式、最坏增长和随机样本之间的逻辑关系。

## A. 识别与复述

### LT-GROW-A01

分别定义 $\Pi_{\mathcal H}(C)$ 与 $\tau_{\mathcal H}(m)$。一个等式 $\tau_{\mathcal H}(m)=k$ 同时包含哪两个上下界断言？

### LT-GROW-A02

解释 $\tau_{\mathcal H}(m)\le\min\{|\mathcal H|,2^m\}$ 的两部分。若 $\mathcal H$ 不可数，哪一部分仍有信息？

### LT-GROW-A03

给定 labeled sample，证明 0–1 prediction patterns 与 error patterns 数量相同。该结论能否直接推广到 cross-entropy values？

## B. 手算与构造

### LT-GROW-B01

在四个有序点 $x_1<x_2<x_3<x_4$ 上，列出右阈值类全部 restrictions，验证 $\tau_{\mathrm{thr}}(4)=5$。

### LT-GROW-B02

计算 interval class 在四个有序点上的模式数；按非空连续 block 长度分别计数，并与 $2^4$ 比较。

### LT-GROW-B03

某 class 在三个输入上的 prediction patterns 是

$$
000,\ 011,\ 111.
$$

若真实标签是 $\boldsymbol y=010$，写出对应的全部 error patterns 及 empirical risks。

## C. 推导与证明

### LT-GROW-C01

在 domain 至少有 $m+1$ 个点时，证明 $\tau_{\mathcal H}(m+1)\ge\tau_{\mathcal H}(m)$。

### LT-GROW-C02

证明若 $d=\operatorname{VCdim}(\mathcal H)<\infty$，则 $\tau(m)=2^m$ 对所有 $m\le d$ 成立，而 $\tau(d+1)<2^{d+1}$。

### LT-GROW-C03

定义 complement class $1-\mathcal H=\{x\mapsto1-h(x):h\in\mathcal H\}$。证明它与 $\mathcal H$ 有相同的经验模式数、增长函数和 VC 维。

## D. 边界、反例与纠错

### LT-GROW-D01

纠正：“在当前训练输入上只有 20 种 patterns，所以可直接把 finite-class bound 中 $|\mathcal H|$ 换成 20。”指出总体风险比较中缺少了什么。

### LT-GROW-D02

构造一个参数值无穷多、但在任意 $m$ 个输入上增长函数只有 $m+1$ 的 class；解释为什么参数去重不是可选优化，而是定义的一部分。

### LT-GROW-D03

纠正：“$\tau(m)=100$ 意味着每个 $m$ 点数据集上都恰有 100 种 labeling。”给出一个同一 class 在不同点集上模式数不同的例子或机制。

## E. AI 迁移

### LT-GROW-E01

有一个可自动生成任意多 prompts 的系统。在固定 evaluation set 上只产生 37 个不同 pass/fail vectors。说明 37 能回答什么、不能回答什么，以及若 prompts 根据同一 set 反复生成，应怎样获得合法泛化证据。

### LT-GROW-E02

对 $X\in\mathbb R^{m\times d}$、单个 ReLU neuron $a=Xw+b\mathbf1$，把 sign pattern 定义为 $\mathbf1\{a\ge0\}$。解释它与 affine halfspace restrictions 的对应，并指出 hidden activation pattern 不等于最终 network prediction pattern的原因。

### LT-GROW-E03

两个冻结 encoders 都输出 512 维表示，但 encoder A 的 sample features 近似落在二维平面，encoder B 的 features 一般位置。仅从固定 linear-probe class 的最坏 VC 上界和经验模式角度，比较可以与不可以得出的结论。

## 分级提示

- `A03`：error vector 是 prediction vector 与固定 label vector 的 XOR；
- `B02`：长度为 $\ell$ 的连续 block 有 $4-\ell+1$ 个；
- `B03`：逐坐标 XOR，再除以 3；
- `C01`：给达到最大值的 $m$ 点集加一个新点；
- `C03`：逐坐标 bit flip 是 $\{0,1\}^m$ 上的双射；
- `D01`：训练点外两个同 pattern hypotheses 的总体风险仍可不同。
