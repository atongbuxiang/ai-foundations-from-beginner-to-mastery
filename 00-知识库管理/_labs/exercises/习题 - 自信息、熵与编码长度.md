# 习题 - 自信息、熵与编码长度

> [!abstract] 训练目标
> 从信息可加性重建负对数，完成 entropy 的边界与编码定理入口；能把 bits/nats、ideal/integer code length、token/byte reduction 和 discrete/differential entropy 严格分开。

## 使用方式

1. 每个 entropy 都写明随机变量、分布和对数底；
2. 编码题画码树或核对 Kraft sum，不只报平均长度；
3. 连续题禁止照搬离散 entropy 的非负性和单符号码长解释；
4. AI 题必须写 tokenizer、mask、归约单位和 probability object。

## A. 识别与复述

### INFO-ENT-A01

分别定义 outcome probability、self-information、entropy、cross-entropy 和实际 prefix-code length。说明哪些是 realization-level、哪些是 distribution-level；若底从 $e$ 改为 $2$，数值和单位怎样变化？

### INFO-ENT-A02

写出把事件信息量刻画为 $J(p)=-K\log p$ 所需的三项核心公理/正则条件。解释“独立事件信息可加”为什么不等于“任意相关事件信息相加”。

### INFO-ENT-A03

定义 prefix-free code 与 Kraft inequality。完整陈述离散 source symbol 的平均码长下界和 Shannon code 上界，并说明为什么 $H=1.5$ bits 不表示每个单独符号可用 1.5 个二进制位存储。

## B. 手算与构造

### INFO-ENT-B01

分布为

$$
p=(1/2,1/4,1/8,1/8).
$$

计算每个结果的 self-information、$H_2(P)$ 与 perplexity；构造达到 entropy 的二进制 prefix code，并验证 Kraft equality。

### INFO-ENT-B02

对 binary entropy

$$
h_2(p)=-p\log_2p-(1-p)\log_2(1-p),
$$

推导一、二阶导数，证明对称性、严格凹性和唯一最大值。计算 $h_2(0.1)$ 到三位小数，并解释它为何小于 $1$ bit。

### INFO-ENT-B03

某 prefix code 的长度为 $(1,2,3,3)$，真实分布为 $p=(0.4,0.3,0.2,0.1)$。

1. 验证 Kraft sum；
2. 计算平均长度 $L$ 与 $H_2(P)$；
3. 由 $q_i=2^{-\ell_i}/K$ 求码长诱导分布；
4. 核对 $L=H_2(P)+D_2(P\|Q)-\log_2K$。

## C. 推导与证明

### INFO-ENT-C01

设 $J:(0,1]\to\mathbb R$ 连续、严格递减，满足 $J(1)=0$ 与 $J(pq)=J(p)+J(q)$。从整数幂、有理幂和连续延拓三步证明 $J(p)=-K\log p$，并解释 $K>0$。

### INFO-ENT-C02

在固定 $m$ 元 alphabet 上，用 Lagrange multiplier 和 Hessian/严格凹性证明

$$
0\le H_b(P)\le\log_bm,
$$

写出两个等号的充要条件。说明为何这个证明不能推出实数轴上的“全域均匀分布最大 differential entropy”。

### INFO-ENT-C03

从 Kraft inequality 出发证明任意二进制 prefix code 满足 $L\ge H_2(P)$；再对 $\ell_i=\lceil-\log_2p_i\rceil$ 证明存在 prefix code 且 $L<H_2(P)+1$。最后对 $n$-symbol blocks 推出每符号冗余小于 $1/n$ bit。

## D. 边界、反例与纠错

### INFO-ENT-D01

令 $X\sim U(0,a)$。求 differential entropy $h(X)$；当 $a=1/4$ 时给出数值。再令 $Y=100X$，验证尺度变换式，并据此反驳“entropy 总非负且与测量单位无关”。

### INFO-ENT-D02

从公平 Bernoulli 分布抽取 $n=2$ 个 iid 样本，用经验频率构造 plug-in entropy（bits）。枚举四种有序样本，计算 $E[\widehat H_{\rm plug}]$，与真实 $H=1$ 比较并解释向下偏的来源。

### INFO-ENT-D03

两个语言模型分别使用 character tokenizer 和更细粒度的 sub-character tokenizer。研究者只报告 per-token PPL 并据此排名。构造一个极简序列和概率分配，使第二个模型 per-token PPL 更低、但 bits per character 与第一个相同；再说明若改用合并双字符的粗粒度 tokenizer，方向会怎样改变，并指出正确比较协议。

## E. AI 迁移

### INFO-ENT-E01

二分类 logits 为 $(a,0)$，temperature 为 $T>0$。写出 softmax probability 和 predictive entropy，证明固定 $a\ne0$ 时 $T\to0$ entropy 趋于 $0$、$T\to\infty$ 趋于 $\log2$，而 argmax 不变。它说明“低 entropy”为什么不是准确性证书？

### INFO-ENT-E02

某 LM evaluation 输出：总 natural-log NLL 为 $6900$，有效 token 数 $3000$，原始文本 $1500$ bytes，其中 padding 500 positions 已 mask。计算 per-token NLL、per-token PPL 和 bits per byte。若另一模型 tokenizer 不同，哪些量可以直接比较，哪些不能？

### INFO-ENT-E03

两个 PSD 矩阵的归一化谱分别为

$$
p=(1,0,0,0),
\qquad
q=(1/4,1/4,1/4,1/4).
$$

计算 spectral entropy 和 entropy effective rank。再说明 algebraic rank、stable rank 与 entropy effective rank 分别回答什么，为什么不能只凭 effective rank 断言表示质量更好？

## 分级提示

- `B03`：本题 $K=1$，所以最后一项消失；
- `C03`：把 $2^{-\ell_i}$ 归一化成 $Q$，再调用 Gibbs inequality；
- `D02`：样本 `00`、`11` 的经验 entropy 为 $0$，`01`、`10` 为 $1$；
- `D03`：让一个 token 恰好覆盖两个 characters，并保持整串概率相同；
- `E02`：bits per byte $=\mathrm{NLL}/(\ln2\times\text{bytes})$。
