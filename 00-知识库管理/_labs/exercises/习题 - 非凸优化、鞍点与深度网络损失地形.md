# 习题 - 非凸优化、鞍点与深度网络损失地形

> [!abstract] 训练目标
> 这组题不把“非凸”训练成一句悲观口号。A 层检查概念与定理条件；B 层完成可手算地形；C 层重建三条核心证明；D 层用反例阻止越界推断；E 层要求把 Hessian/HVP、对称性和 generalization 分账写成可执行研究协议。每道题都必须明确对象、条件、结论强度与不能推出什么。

## 使用规则

- 建议闭卷时间：A 20 分钟，B 35 分钟，C 60 分钟，D 45 分钟，E 75 分钟；
- 除 E 层允许查阅模型接口文档外，其余题先闭卷；
- 写“收敛”必须说明对象是 gradient norm、function value、iterate、local minimum 还是 global minimum；
- 写“flat/sharp”必须说明 parameterization、metric、normalization 与测量对象；
- 首次作答后再打开[[解答 - 非凸优化、鞍点与深度网络损失地形|独立详解]]。

## A 层：定义、边界与定理阅读

### OPT-NONCVX-A01｜三层驻点对象

对 twice-differentiable $f:\mathbb R^d\to\mathbb R$：

1. 写出 exact first-order stationary point、exact second-order stationary point 与 strict second-order sufficient condition；
2. 写出 $(\varepsilon_g,\varepsilon_H)$-approximate second-order stationary point；
3. 说明三者中哪些是 local minimum 的必要条件，哪个是充分条件；
4. 解释为什么 $\nabla^2 f(x)\succeq0$ 不能单独证明 $x$ 是 local minimum。

### OPT-NONCVX-A02｜严格鞍点避免定理的条件账本

某报告写道：“梯度下降不会收敛到鞍点。”请把它改写成 Lee et al. 风格的严谨命题，至少列出：

1. $f$ 的光滑条件；
2. 步长区间；
3. 鞍点类型；
4. 初始化分布；
5. 概率与时间语义；
6. 该命题仍不保证的三件事。

### OPT-NONCVX-A03｜结论阶梯与研究语言

把下列陈述按逻辑强度从弱到强排序，并为每个相邻跳跃写出至少一种可能需要的新增条件：

- 找到小 gradient；
- 达到 approximate second-order stationary point；
- 收敛到 local minimum；
- 所有 local minima 都 global；
- 找到 global empirical minimizer；
- population/deployment risk 小。

最后说明“mode connectivity”和“低训练 loss”分别最多直接支持阶梯中的哪类陈述。

## B 层：可手算地形与算法行为

### OPT-NONCVX-B01｜三个零 Hessian 现象

分别研究

$$
f_1(x,y)=x^2-y^2,
\qquad
f_2(x,y)=x^2-y^4,
\qquad
f_3(x)=x^4.
$$

1. 求原点处 gradient 与 Hessian；
2. 分类原点；
3. 对 $f_2,f_3$，说明 Hessian 为什么无法完成分类；
4. 给出一个 exact SOSP 但不是 local minimum 的最小反例。

### OPT-NONCVX-B02｜标量因子分解的完整地形

令

$$
f(a,b)=\frac12(ab-1)^2.
$$

1. 求 gradient、Hessian 和全部 stationary points；
2. 分类 $(0,0)$；
3. 证明集合 $\{(a,b):ab=1\}$ 是 global-minimum manifold；
4. 在 $(s,1/s)$ 求 Hessian eigenvalues 与 tangent null direction；
5. 说明这个例子为何同时展示 benign landscape、strict saddle 与 scale symmetry。

### OPT-NONCVX-B03｜一个非凸但满足 PL 的函数

取 $0<c<1$，令

$$
h(x)=x+c\sin x,
\qquad
f(x)=\frac12h(x)^2.
$$

1. 证明 $h$ strictly increasing，且 $f^*=0$ 的唯一实现点是 $x=0$；
2. 证明 $f$ 满足 PL inequality，并给出可取的 $\mu$；
3. 推导 $f''(x)$，说明为什么存在某些 $x$ 使其为负；
4. 解释 PL 为什么不自动给出可用于 GD 的 global smoothness constant $L$。

## C 层：证明骨架与复杂度

### OPT-NONCVX-C01｜GD 鞍点动力学与稳定流形

设 $x^*$ 是 critical point，$H^*=\nabla^2 f(x^*)$，GD map 为 $G(x)=x-\eta\nabla f(x)$。

1. 推导 $DG(x^*)$；
2. 若 $H^*v=\lambda v$，推导 $v$ 方向的小扰动递推；
3. 对 $f(x,y)=x^2-y^2$ 写出 exact GD recurrence，并找出收敛到原点的初始化集合；
4. 解释这个集合为何是 measure zero，却仍反驳“任意初始化都逃逸”；
5. 写出从局部不稳定方向到 almost-sure saddle avoidance 还需要的证明桥梁。

### OPT-NONCVX-C02｜negative curvature 的下降尺度

假设 $f$ 的 Hessian 为 $\rho$-Lipschitz，$\|v\|=1$，且

$$
v^T\nabla^2 f(x)v=-\gamma<0.
$$

1. 写出沿 $v$ 的三阶 Taylor upper bound；
2. 选择 $v$ 的 sign 消去一阶项的不利影响；
3. 证明 $0<t<3\gamma/\rho$ 时获得严格下降；
4. 取 $t=2\gamma/\rho$，给出只依赖 $\gamma,\rho$ 的下降量下界；
5. 若 $\gamma=\sqrt{\rho\varepsilon}$，说明下降量为何具有 $\varepsilon^{3/2}/\sqrt\rho$ 尺度，并解释这与 approximate SOSP 容差配对的关系。

### OPT-NONCVX-C03｜PL 下的全局线性函数值收敛

假设 $f$ 为 $L$-smooth、lower bounded，并满足

$$
\frac12\|\nabla f(x)\|^2\ge\mu(f(x)-f^*).
$$

对 $x_{k+1}=x_k-\frac1L\nabla f(x_k)$：

1. 从 descent lemma 推导一步下降；
2. 代入 PL inequality 得到 contraction；
3. 迭代得到达到 $f(x_k)-f^*\le\varepsilon$ 的复杂度；
4. 证明任一 stationary point 都是 global minimizer；
5. 列出该证明没有给出的三个结论。

## D 层：反例、越界推断与诊断

### OPT-NONCVX-D01｜SOSP 不是 minimum certificate

1. 用 $f(x,y)=x^2-y^4$ 反驳“$\nabla f=0,H\succeq0$ 足以局部极小”；
2. 构造一个一维 $C^2$ 函数，其原点为 stationary inflection point；
3. 说明 strict-saddle property 如何排除一部分失败，但为什么仍不能推出 global optimality；
4. 对 ReLU 网络说明 classical Hessian criterion 在 kink 处为何需要改写或限定到 smooth region。

### OPT-NONCVX-D02｜raw sharpness 的尺度反例

在 B02 的 minimum manifold 上取 $(a,b)=(s,1/s)$。

1. 证明 predictor 与 objective value 对所有 $s>0$ 不变；
2. 证明 Hessian 的非零 eigenvalue 是 $s^2+s^{-2}$；
3. 计算 $s=1,0.1,10$ 时的数值；
4. 反驳“更 sharp 必然 generalize 更差”；
5. 设计一个比 raw $\lambda_{\max}(H)$ 更可审计的比较协议，至少处理 scale、batch、loss reduction 与 function-space change。

### OPT-NONCVX-D03｜二维切片、mode connectivity 与 SGD 噪声审计

一个实验报告展示两幅平滑二维 loss surface、两个 minima 之间的低-loss 曲线，并观察 SGD 离开一个 saddle，随后断言：“整个深网 loss basin 连通，SGD 噪声会自动找到 flat 且 generalize 的全局最优。”

逐项拆解：

1. 二维 slice 隐藏了哪些方向与 normalization 选择？
2. 一条连接曲线能与不能说明什么？
3. 需要测量 noise covariance 的哪个投影，才能支持 saddle-escape 机制？
4. 如何把 optimization evidence 与 generalization evidence 分开？
5. 写出一个最小反例或替代解释，使原断言失效。

## E 层：AI 迁移与研究级验收

### OPT-NONCVX-E01｜HVP/Lanczos 驻点诊断协议

为一个含 $10^8$ 参数、不能显式形成 Hessian 的模型设计诊断协议。要求包含：

1. 在何时触发诊断，如何定义 small-gradient；
2. 如何用 Hessian-vector product 与 Lanczos 估计 $\lambda_{\min}$；
3. stochastic minibatch Hessian 的采样、重复与置信区间；
4. 如何区分 symmetry null direction、negative curvature 与 numerical error；
5. 若检测到 negative curvature，如何选方向、步长和验收阈值；
6. 哪些结论只能标为 heuristic，哪些可成为当前 run 的 empirical certificate。

### OPT-NONCVX-E02｜“没有坏局部极小”的定理迁移审计

选择以下任一命题作为原始材料：

- deep linear network 在特定宽度与 differentiable convex loss 下 local minima global；
- 某类 low-rank factorization 在 sampling/RIP/incoherence 等条件下无 spurious local minima。

写一份迁移审计：列出 theorem 的对象、量词、所有关键假设、结论、proof mechanism；然后逐项比较现实 Transformer/ReLU 项目。最终只能给出 `theorem applies`、`analogy only` 或 `contradicted assumptions` 三类标签之一，并说明原因。

### OPT-NONCVX-E03｜完整损失地形—泛化研究合同

为“优化器 A 比优化器 B 找到更平坦、泛化更好的解”设计一份可证伪研究合同，至少包含：

1. 固定 architecture/data split/augmentation/compute budget 的规则；
2. optimizer 的学习率、batch、weight decay、momentum/preconditioner 公平性；
3. training objective、gradient norm、Hessian extreme eigenvalues、function-space perturbation 与 mode-connectivity 测量；
4. permutation/scale/normalization 对齐；
5. 多 seed、置信区间、预注册 primary endpoint；
6. calibration、distribution shift 与 subgroup metric；
7. 至少三个可推翻原假设的结果模式；
8. 最终报告中 theorem、empirical result、mechanistic inference 与 speculation 的分层写法。
