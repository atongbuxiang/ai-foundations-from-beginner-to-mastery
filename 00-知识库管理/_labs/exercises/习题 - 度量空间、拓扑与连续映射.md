# 习题 - 度量空间、拓扑与连续映射

> [!abstract] 训练目标
> 从“知道距离和连续的直觉”升级为能独立审计一个空间：先声明 underlying set，再检查 metric axioms，继而分开 topology、scale、completeness、compactness 与 connectedness；最后把这些对象落实到表示学习、生成模型和有限样本实验中。

> [!warning] 作答合同
> 每次写“收敛”“连续”“紧致”“拓扑不变”时，都必须说明空间、metric/topology、映射的 domain/codomain，以及结论作用于 population object、finite sample 还是 numerical approximation。画图与有限样本只能提供证据，不能替代一般性证明。

## A. 定义、层级与最小条件

### GEO-MET-A01

建立以下对象的“类型表”，逐项写出定义、最小公理、典型例子、典型非例和它能诱导的结构：

1. metric、pseudometric、semimetric；
2. norm 与 norm-induced metric；
3. divergence、similarity 与 cost；
4. open ball、open set、closed set；
5. topology 与 metric-induced topology；
6. convergent sequence、Cauchy sequence 与 complete metric space。

特别解释：为什么“$D(x,y)$ 越小越相似”不能推出 $D$ 是 metric？为什么 completeness 不能只从 open sets 判断？

### GEO-MET-A02

设 $A\subseteq X$，在拓扑空间 $(X,\tau)$ 中定义并比较

$$
\operatorname{int}A,
\qquad \overline A,
\qquad \partial A,
\qquad A',
$$

其中 $A'$ 是 limit-point set。证明或反驳：

1. $A$ open 当且仅当 $A=\operatorname{int}A$；
2. $A$ closed 当且仅当 $A=\overline A$；
3. $\partial A=\overline A\setminus\operatorname{int}A$；
4. $\overline A=A\cup A'$；
5. $\partial(A\cup B)=\partial A\cup\partial B$；
6. 若 $Y\subseteq X$，则 $A\subseteq Y$ 在 subspace $Y$ 中的 closure 总等于 $\overline A^{,X}$。

对错误命题给出最小反例，并明确 ambient space。

### GEO-MET-A03

画出并解释以下映射层级：isometry、bi-Lipschitz map、topological embedding、homeomorphism、continuous bijection、continuous map。回答：

1. 哪些性质保持 exact distance、Cauchy/completeness、open sets、compactness、connectedness？
2. continuous、uniformly continuous、Hölder、Lipschitz 之间有哪些蕴含？
3. continuous bijection 还差什么条件才能推出 homeomorphism？
4. “两个 latent spaces 拓扑等价”与“两个 latent metrics 对训练等价”为什么是不同主张？

## B. 手算、构造与有限分辨率

### GEO-MET-B01

在指定集合上逐项检查下列函数是否为 metric；若不是，指出第一条失败的公理，并判断能否通过 quotient 或简单变换修复。

1. $d_w(x,y)=\sum_{i=1}^n w_i|x_i-y_i|$，$X=\mathbb R^n$，其中 $w_i>0$；
2. $d_2^2(x,y)=\|x-y\|_2^2$，$X=\mathbb R^n$；
3. $d_{\cos}(x,y)=1-\frac{x^\top y}{\|x\|\|y\|}$，$X=\mathbb R^n\setminus\{0\}$；
4. $d_f(x,y)=|f(x)-f(y)|$，其中 $f:X\to\mathbb R$；
5. $d_0(x,y)=\mathbf 1\{x\ne y\}$；
6. $D_{\mathrm{KL}}(P,Q)$，定义在具有正密度的概率分布上。

再说明 cosine angular distance

$$
d_\angle(x,y)=\arccos\frac{x^\top y}{\|x\|\|y\|}
$$

在哪个 quotient object 上自然成为 metric。

### GEO-MET-B02

令

$$
X=\{0\}\cup[1,2]\subset\mathbb R
$$

取 Euclidean subspace topology，并令

$$
A=\{0\}\cup(1,3/2),
\qquad
B=\{1+1/n:n\ge1\}.
$$

分别求 $A,B$ 在 $X$ 中的 interior、closure、boundary 与 limit points；判断它们在 $X$ 中是否 open/closed。再与 ambient $\mathbb R$ 中的答案比较，解释 isolated point $0$ 为什么在 $X$ 中是 open。

### GEO-MET-B03

考虑区间 $[0,1]$ 的 Euclidean metric。

1. 构造一个显式 $\varepsilon$-net，并给出 covering number $N([0,1],\varepsilon)$ 的上下界；
2. 构造一个 $2\varepsilon$-packing，并用它下界 covering number；
3. 对 $[0,1]^d$ 的 $\ell_\infty$ metric 给出网格上界的量级；
4. 解释为什么相同 topology 并不保证两个 metrics 的 covering number 在相同数值 $\varepsilon$ 下接近；
5. 若 $f$ 是 $L$-Lipschitz，证明

$$
N(f(X),\varepsilon)\le N(X,\varepsilon/L).
$$

说明该不等式对 representation compression 的含义及其不能推出的信息。

## C. 定理证明与结构联系

### GEO-MET-C01

设 $f:(X,d_X)\to(Y,d_Y)$。证明下列三者等价：

1. $f$ 在每一点满足 $\varepsilon$–$\delta$ 连续；
2. 对任意 open $V\subseteq Y$，$f^{-1}(V)$ 在 $X$ 中 open；
3. 对任意 $x_n\to x$，都有 $f(x_n)\to f(x)$。

必须指出第三个刻画为什么依赖 metric spaces 的 first-countability；然后证明连续函数把 compact set 映成 compact set、把 connected set 映成 connected set。

### GEO-MET-C02

证明 metric space $(X,d)$ compact 当且仅当它 complete 且 totally bounded。允许使用“metric space 中 compact 等价于 sequentially compact”，但必须把使用位置写出。

随后分别用反例说明：

1. complete 不推出 compact；
2. totally bounded 不推出 compact；
3. closed and bounded 在一般 metric space 中不推出 compact；
4. 为什么有限维 Euclidean space 的 Heine–Borel 不能原样搬到无限维 Hilbert space。

### GEO-MET-C03

设同一集合 $X$ 上两个 metrics 满足

$$
c,d_1(x,y)\le d_2(x,y)\le C,d_1(x,y),
\qquad 0<c\le C<\infty.
$$

证明：

1. $d_1,d_2$ 诱导相同 topology；
2. 它们有相同 convergent sequences 与 Cauchy sequences；
3. completeness 在二者之间等价；
4. compactness 与 total boundedness 在二者之间等价；
5. covering numbers 满足

$$
N_{d_1}(X,\varepsilon/c)
\le N_{d_2}(X,\varepsilon)
\le N_{d_1}(X,\varepsilon/C)
$$

还是相反？先独立推导 ball inclusion，再写出正确方向。

最后说明 finite-dimensional norm equivalence 给出什么，又为什么常数可能随维数恶化。

## D. 反例、边界与纠错

### GEO-MET-D01

在 $\mathbb R$ 上比较

$$
d_1(x,y)=|x-y|,
\qquad
d_2(x,y)=|\arctan x-\arctan y|.
$$

1. 证明 $d_2$ 是 metric；
2. 证明 $d_1,d_2$ 诱导相同 topology；
3. 证明 $(\mathbb R,d_1)$ complete；
4. 找出一个在 $d_2$ 下 Cauchy、却在 $\mathbb R$ 中没有 $d_2$-limit 的 sequence；
5. 识别 $(\mathbb R,d_2)$ 的 completion；
6. 解释该例为何同时否定“同 topology 必同 completeness”和“bounded metric space 必 compact”。

### GEO-MET-D02

令 $X=[0,2\pi)$ 带 Euclidean subspace topology，$Y=S^1\subset\mathbb R^2$，定义

$$
f(t)=(\cos t,\sin t).
$$

1. 证明 $f$ 是 continuous bijection；
2. 证明 $f^{-1}$ 不 continuous；
3. 找出 $X$ 不 compact 的具体 open cover 或 sequence 证据；
4. 证明一般定理：compact space 到 Hausdorff space 的 continuous bijection 是 homeomorphism；
5. 说明把 domain 改成哪种 quotient 后，圆参数化会成为 homeomorphism。

再给一个“连续但不 injective”的映射，并说明它如何粘合拓扑结构。

### GEO-MET-D03

审计下列研究表述。对每一条分别给出：判定、缺失假设、最小反例或修正版、可以计算的诊断量。

1. “t-SNE 图中出现三个岛，所以数据 support 恰有三个 connected components。”
2. “训练误差很小，故 encoder 在 data manifold 上近似 homeomorphism。”
3. “所有 finite datasets 都是 discrete topological spaces，因此拓扑方法对机器学习没有意义。”
4. “两个 metrics 产生相同 nearest-neighbor 排序，所以它们拓扑等价。”
5. “Neural ODE 的 vector field continuous，所以 time-$T$ map 必为全空间 homeomorphism。”
6. “augmentation 改变 topology，因此一定能学到任意目标分布。”

要求把 population、sample、graph-at-scale、exact flow 与 numerical solver 五个对象分开。

## E. AI 综合建模、实验设计与证据审计

### GEO-MET-E01

为一个图像 encoder $E:\mathcal X\to\mathbb R^k$ 写“metric–topology–sampling contract”。至少包括：

1. 原空间与 latent space 的集合、metrics 和选择理由；
2. augmentation 是否被视为同一点、pseudometric equivalence class 还是随机 transformation；
3. 希望保持的是 pairwise distance、local neighborhood、margin、connectedness 还是 class topology；
4. continuity/Lipschitz/bi-Lipschitz/injectivity 中真正需要哪一个；
5. population claim 如何由 finite noisy samples 估计；
6. covering radius、packing、neighbor overlap、round-trip 与 adversarial sensitivity 诊断；
7. train/validation distribution shift；
8. 失败判据和禁止声称的结论。

给出一个“metric preservation 与 task accuracy 冲突”的具体情形，并提出消融实验。

### GEO-MET-E02

设计一个二维生成建模实验，比较 ordinary Neural ODE/CNF 与 augmented Neural ODE：base distribution 为单连通 Gaussian，target samples 为 two moons 或 annulus-plus-island。

1. 写清 exact ODE flow 在何种条件下是 homeomorphism；
2. 预测 unaugmented flow 在 support geometry/topology 上的困难；
3. 解释 finite samples、positive-density Gaussian support 与“两个岛”说法之间的冲突；
4. 给出 augmentation、projection、density evaluation 三者的对象关系；
5. 规定 solver、tolerance、round-trip、Jacobian singular values、graph component curve 与 likelihood 的记录协议；
6. 区分 expressivity failure、optimization failure 与 numerical failure；
7. 写出什么结果能够支持、但不能证明 topology-related hypothesis。

### GEO-MET-E03

比较 total variation、KL、Jensen–Shannon、Wasserstein-1 与 MMD 作为分布差异量。选择

$$
P_n=\delta_{1/n},\qquad P=\delta_0
$$

以及一对 disjoint-support distributions，回答：

1. 哪些量是 metric，哪些是 divergence 或 kernel-dependent metric；
2. $P_n\Rightarrow P$ 时各差异量如何表现；
3. ground metric 如何进入 $W_1$，kernel 如何进入 MMD；
4. “loss 变小”究竟对应哪种 topology 或 convergence notion；
5. 为什么 WGAN 的价值不能简化成“用了一个更好的距离”；
6. 设计一个同时报告 statistical error、optimization error 与 metric-estimation error 的实验表。

最后写一段不超过 200 字的审稿意见，纠正“GAN loss 收敛所以生成分布已经在所有意义下收敛”的说法。
