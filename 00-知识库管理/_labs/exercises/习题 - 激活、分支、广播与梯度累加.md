# 习题 - 激活、分支、广播与梯度累加
## A. 识别与复述
### NN-SEM-A01
从 $H=\phi(Z)$ 写出 elementwise activation 的 differential 与 VJP。
### NN-SEM-A02
区分 graph fan-out accumulation、microbatch gradient accumulation 和 optimizer moving averages。
### NN-SEM-A03
说明 broadcast–sum 与 gather–scatter-add 为何是伴随配对。
## B. 手算与建模
### NN-SEM-B01
对 $h_i=\operatorname{ReLU}(x_i)+bx_i, L=\sum_i h_i$，在 $x=(-1,2),b=3$ 完成 forward 和 $\bar x,\bar b$。
### NN-SEM-B02
$b:[1,T,1]$ 广播与 $X:[B,T,D]$ 相加。给 $\bar Y=G$，写出 $\bar X,\bar b$ 的 shape 和 reduction axes。
### NN-SEM-B03
source $x=(x_1,x_2,x_3)$，indices $(2,2,1)$，$y=\operatorname{gather}(x)$，给 $\bar y=(a,b,c)$，手算 $\bar x$。
## C. 推导与证明
### NN-SEM-C01
从 total differential 推出 residual block $y=x+F(x)$ 的 $\bar x=\bar y+J_F(x)^T\bar y$。
### NN-SEM-C02
对 broadcast map $B(b)_{itj}=b_j$ 用内积恒等式推出 $B^*$。
### NN-SEM-C03
证明 unequal microbatch local means $g_r$ 复原 global mean gradient 时必须按 valid count 加权。
## D. 边界、反例与纠错
### NN-SEM-D01
反驳：“ReLU 在 0 处框架返回 0，所以 classical derivative 就是 0。”
### NN-SEM-D02
构造一个原 shape 为 `[1,T,1]` 却在 backward 对所有轴求和的错误，说明结果为何连 shape 合同都违反。
### NN-SEM-D03
给出 view alias 与 in-place 修改破坏 activation backward residual 的最小例子。
## E. AI 迁移

### NN-SEM-E02

### NN-SEM-E03
