# 习题 - 线性层、批量张量与参数计数

> [!abstract] 训练目标
> 把逐神经元公式可靠地提升为批量矩阵/高阶张量实现，并分清 shape、parameter、compute、memory 与 rank 五本账。

## A. 识别与复述

### NN-DEN-A01

在 row-batch 约定下，给出 $X,W,b,Z$ 的形状，并解释 $W$ 的第 $j$ 列代表什么。

### NN-DEN-A02

比较数学式 $Z=XW+b$ 与 PyTorch `Linear(in_features, out_features)` 常见参数 storage。为什么两者看似转置却并不矛盾？

### NN-DEN-A03

参数数、MACs、FLOPs、parameter memory、activation memory 分别衡量什么？哪些随 batch size 改变？

## B. 手算与建模

### NN-DEN-B01

令
$$
X=\begin{bmatrix}1&-1\\2&0\end{bmatrix},\quad
W=\begin{bmatrix}2&1&0\\-1&3&2\end{bmatrix},\quad
b=\begin{bmatrix}1&-2&0.5\end{bmatrix}.
$$
计算 $Z=XW+b$，并写出 shape ledger。

### NN-DEN-B02

一个 dense layer 为 $768\to3072$，带 bias，输入 shape `[32,128,768]`。求输出 shape、参数数与前向 MACs。

### NN-DEN-B03

FP16 参数的 $4096\to4096$ 带 bias 层仅存参数需要多少 MiB？若训练还存同 shape 的 FP16 gradient、两个 FP32 optimizer states 和一个 FP32 master weight，粗略总量是多少 MiB？

## C. 推导与证明

### NN-DEN-C01

从 $z_{ij}=\sum_kX_{ik}W_{kj}+b_j$ 推导 $Z=XW+\boldsymbol1b$，并指出每个自由指标和求和指标。

### NN-DEN-C02

证明 $\operatorname{rank}(XW)\le\min\{\operatorname{rank}(X),\operatorname{rank}(W)\}$。若 $d_{out}<d_{in}$，解释哪些输入差异可能无法由该层区分。

### NN-DEN-C03

对标量损失 $L(Z)$，设上游梯度 $G=\partial L/\partial Z$。用微分与 trace/Frobenius 内积推导 $\partial L/\partial X$、$\partial L/\partial W$、$\partial L/\partial b$。

## D. 边界、反例与纠错

### NN-DEN-D01

某实现令 `X.shape=[B,T,d]`、`b.shape=[T,1]`，广播后代码能运行。解释为什么“能广播”仍可能语义错误，并给出正确 bias shape。

### NN-DEN-D02

反驳：“两个 vectorized 实现数学上等价，所以浮点输出必然逐 bit 相同。”指出至少三个造成差异的机制。

### NN-DEN-D03

纠正：“低参数量就一定低延迟，低 FLOPs 就一定低显存。”分别给出一个反例机制。

## E. AI 迁移

### NN-DEN-E01

为 Transformer FFN 的两个 linear layers 建立参数与 MAC 账本：输入 `[B,T,d]`，中间宽 $4d$，忽略 bias。结果用 $B,T,d$ 表示。

### NN-DEN-E02

比较 dense layer、$1\times1$ convolution 与 embedding lookup：写出它们相同的参数矩阵视角，以及索引/共享/计算方式的差异。

### NN-DEN-E03

设计一个 shape-first code review checklist，要求它能发现 transpose、broadcast、flatten、layout 与 precision 五类问题。

## 分级提示

- `B02`：把前两轴视为 $4096$ 个位置；
- `B03`：$1\text{ MiB}=2^{20}$ bytes；
- `C03`：$dZ=dXW+XdW+\boldsymbol1,db$；
- `D01`：合法广播只检查尺寸规则，不理解轴语义；
- `E01`：两层 MACs 相同。
