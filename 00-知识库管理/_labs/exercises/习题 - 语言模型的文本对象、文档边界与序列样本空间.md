# 习题 - 语言模型的文本对象、文档边界与序列样本空间

> [!abstract] 训练目标
> 能从原始 bytes 恢复完整样本生成函数，区分文档/窗口/token/batch，并判断边界、归约和 packing 如何改变条件分布。

## A. 识别与复述

### LM01-A01
逐项解释 $\mathcal G=W\circ A_{tok}\circ S_{doc}\circ N\circ D_{enc}$ 的输入、输出与版本字段。

### LM01-A02
区分文档、token stream、训练窗口、batch 和有效 target token。

### LM01-A03
为什么 EOS 是否保留会改变长度模型？写出含 EOS 的序列概率。

## B. 手算与构造

### LM01-B01
两个文档 token 为 `[A,B]` 和 `[C]`。分别构造：每文档 BOS/EOS、直接拼接、长度 6 packing 三种 ID 序列，并写 loss mask。

### LM01-B02
文档有效 token 数为 2 和 6，token NLL 总和分别为 4 和 9。计算 token-mean 与 document-mean NLL。

### LM01-B03
写一个最小 data provenance manifest，至少含 raw hash、encoding、Unicode、parser、document boundary、tokenizer 与 packing。

## C. 推导与证明

### LM01-C01
证明 token-mean 风险可写成以文档长度成比例的 document loss 加权平均。

### LM01-C02
给出条件，证明两个 tokenizer/data pipeline 产生完全相同 ID/mask 时，对确定模型的一步 forward loss 相同。

### LM01-C03
形式化说明无边界拼接为何引入原文档分布中不存在的条件事件。

## D. 边界、反例与纠错

### LM01-D01
反驳“窗口数就是样本数”：构造同一文档产生大量重叠窗口的例子。

### LM01-D02
反驳“只要跨文档位置不计 loss，就没有泄漏”。

### LM01-D03
同一 URL 重抓后正文变化但文件名不变。指出版本与评估可能怎样失真。

## E. AI 迁移

### LM01-E01
为对话 SFT 写 messages→template→IDs→labels 的完整对象链。

### LM01-E02
设计 train/validation 文档级隔离协议，避免同一长文的相邻窗口跨 split。

### LM01-E03
审计“训练了 1T tokens”这一声明，列出至少八个需要追问的分母/版本字段。
