# 习题 - 自回归模型的表达、成本、失效模式与证据地图

## A. 识别与复述

### GEN08-A01
为什么 chain rule 的表达完备性不是固定有限网络的 universal approximation 保证？

### GEN08-A02
列出自回归系统六类失效层，并为每层给一个可观测症状。

### GEN08-A03
区分 NLL、sample precision、sample recall、conditional consistency 和 latency 回答的问题。

## B. 手算与建模

### GEN08-B01
从空序列生成长度 $T$：无 cache 每步重算 $t^2$ attention pairs，有 cache 每步只算 $t$。求两个累计和与主阶。

### GEN08-B02
两个模型 token 平均 NLL 分别 1.8、1.75 nat，平均长度 100。求平均序列 perplexity 的 token 口径，并解释不能直接推出 rollout 质量差多少。

### GEN08-B03
质量 precision=0.92、coverage recall=0.40 的系统与 precision=0.80、recall=0.78 的系统，分别适合什么结论？为什么不能用一个“更好”概括？

## C. 推导与证明

### GEN08-C01
在无限 conditional capacity 下，证明任意有限离散 joint 有一个 exact AR 表示；指出证明没有给什么复杂度保证。

### GEN08-C02
推导无 cache 与 KV cache attention pair 的精确求和公式，并加入 prompt 长度 $P$、输出长度 $S$。

### GEN08-C03
给出“观测重复 → 至少三种竞争解释 → 干预证据”的因果诊断结构，并说明为何相关日志不足。

## D. 边界、反例与纠错

### GEN08-D01
构造 exact likelihood 很好但因 top-$p$ 参数错误而样本覆盖差的系统。

### GEN08-D02
构造样本看起来清晰但模型遗漏一半模式的例子。

### GEN08-D03
反驳：“自回归采样串行，所以训练也必然逐 token 串行。”

## E. AI 迁移

### GEN08-E01
为文本、raw-pixel 图像、VQ 图像三类 AR 系统建立同一受控比较表。

### GEN08-E02
把科学空间五篇自回归文章按 `I/T/E/H/O` 分级，并为每个主要 claim 指定补证方式。

### GEN08-E03
对一个宣称“AR 被扩散淘汰”或相反的论断，写一份可证伪评测设计，覆盖训练预算、NLL、质量、覆盖、NFE/latency 与条件控制。
