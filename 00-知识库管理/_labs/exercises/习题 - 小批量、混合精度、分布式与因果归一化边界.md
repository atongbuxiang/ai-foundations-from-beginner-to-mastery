# 习题 - 小批量、混合精度、分布式与因果归一化边界

## A

### NN-NSC-A01
区分 optimizer batch、microbatch、normalization group 与 effective independent count。Gradient accumulation 默认改变哪些、不改变哪些？

### NN-NSC-A02
给出 prefix-causal normalization 的正式定义，并判断 LN$(D)$、LN$((T,D))$、BN1d$(B,D,T)$、IN1d 和 GN 是否由 norm 本身跨时间。

### NN-NSC-A03
列出 normalization 的五层 dtype ledger，并说明 GradScaler 作用于哪一层、不能修复哪两类 forward 错误。

## B

### NN-NSC-B01
rank A 有 $(0,2)$，rank B 有 $(10)$。手算正确 global mean、$M_2$、biased variance，并比较简单平均 local means/variances 的错误结果。

### NN-NSC-B02
对跨时间 centered normalization，分别计算序列 $(1,2,3)$ 与 $(1,2,10)$ 的第一个输出，证明 suffix 改变 prefix。

### NN-NSC-B03
fp16 最大有限值约 $65504$。估算先平方的安全 magnitude 阈值，并写出 max-scaled RMS 公式。

## C

### NN-NSC-C01
在等相关模型下推导 $\operatorname{Var}(\bar X)$ 与 $m_{\mathrm{eff}}$；检查 $\rho=0,1$ 两个极端。

### NN-NSC-C02
推导两个 shard 的 Chan 合并公式，或从总 centered sum 展开验证 cross term $\delta^2n_An_B/n$。

### NN-NSC-C03
证明 prefix Welford 的 $(\mu_t,M_{2,t})$ 只依赖 $x_{1:t}$，并列出把它用于流式模型仍需解决的 state/chunk/mask 问题。

## D

### NN-NSC-D01
反驳“梯度累积 8 个 microbatches 与一个 8 倍大 batch 的 BatchNorm 完全等价”。指出 forward、state 与 backward coupling 差异。

### NN-NSC-D02
反驳“有 causal attention mask，所以任何 normalization 都不会泄漏未来”，给出轴级反例。

### NN-NSC-D03
反驳“SyncBatchNorm 只同步 running buffers”。说明训练 forward、统计组、梯度依赖与通信怎样改变。

## E

### NN-NSC-E01
为多卡变长序列训练设计 mask-aware SyncBN sufficient-statistic 协议，处理 uneven count、count=0、dtype 和 process group。

### NN-NSC-E02
为自定义 fused norm 设计 mixed-precision 验收：输入家族、reference、误差、NaN/Inf、epsilon 与 backward 至少各一项。

### NN-NSC-E03
一个流式语言模型准备把 per-token RMSNorm 改成跨时间 normalization。给出因果安全设计、状态 reset/checkpoint/chunk 协议与 suffix-perturbation 测试。
