# 习题 - 多层感知机与逐层前向计算

> [!abstract] 训练目标
> 用函数复合和 shape ledger 精确读取 MLP，并把表达、参数、计算、缓存与输出语义分开。

## A. 识别与复述

### NN-MLP-A01

对层宽 $d_0,d_1,\ldots,d_L$，写出 $H^{(\ell-1)},W^{(\ell)},b^{(\ell)},Z^{(\ell)},H^{(\ell)}$ 在 batch 输入下的形状。

### NN-MLP-A02

区分 pre-activation、hidden activation、logit、probability 与 prediction。一个多分类网络怎样依次得到这些对象？

### NN-MLP-A03

解释 feedforward、forward pass、backpropagation 三个词。为什么“前馈网络”不表示训练时只向前计算？

## B. 手算与建模

### NN-MLP-B01

令 $x=(1,2)$，
$$
W^{(1)}=\begin{bmatrix}1&-1\\0.5&2\end{bmatrix},\quad
b^{(1)}=(0,-1),\quad
W^{(2)}=\begin{bmatrix}2\\-1\end{bmatrix},\quad b^{(2)}=0.5.
$$
hidden 用 ReLU、output 用 identity。手算 $z^{(1)},h^{(1)},z^{(2)}$。

### NN-MLP-B02

网络宽度为 $784\to256\to128\to10$，每层带 bias。计算总参数数，并对 batch 64 计算主要前向 MACs。

### NN-MLP-B03

输入 `[8,512,768]` 经过 position-wise $768\to3072\to768$ MLP。写出每个 $Z/H$ shape、总参数数与主要 MACs。

## C. 推导与证明

### NN-MLP-C01

证明任意有限个 affine layers 在所有 activation 为 identity 时可合并为一个 affine map，并给出两层的 effective weight/bias。

### NN-MLP-C02

从 index notation 推导三维输入 `[B,T,d_{in}]` 上 dense layer 只混合最后一轴。为什么这不提供 token mixing？

### NN-MLP-C03

对 $L$ 层 MLP 推导参数数与主要 MACs 公式。若训练保存所有 $Z^{(\ell)}$ 和 $H^{(\ell)}$，给出 activation 标量数量的量级。

## D. 边界、反例与纠错

### NN-MLP-D01

构造一个两层网络，第一层 shape 正确但 bias 沿 batch 轴广播，导致不同样本拥有不同 bias。解释它为何不再是标准 shared dense layer。

### NN-MLP-D02

反驳：“更深网络严格包含更浅网络，因此训练误差与测试误差都必然下降。”区分函数类包含、优化结果与泛化结果。

### NN-MLP-D03

纠正：“输出在 $[0,1]$ 就用 sigmoid；有十类就用十个独立 sigmoid。”分别说明单标签多分类与多标签任务的输出合同。

## E. AI 迁移

### NN-MLP-E01

把 Transformer FFN 翻译为本章 shape ledger，并说明 activation、residual、normalization 分别位于何处；不要把 attention 纳入 FFN 本身。

### NN-MLP-E02

设计一个用于二分类 tabular task 的 MLP architecture card：至少列输入处理、层宽、activation、output、loss、参数数、shape tests 和部署 threshold。

### NN-MLP-E03

给出一个 forward-pass debugging protocol，要求能定位 NaN、shape error、all-zero ReLU、错误 train/eval mode 与 output/loss mismatch。

## 分级提示

- `B02`：逐层使用 $(d_{in}+1)d_{out}$；
- `B03`：位置数为 $8\times512$；
- `C01`：仿射复合仍为仿射，用归纳法；
- `D02`：存在可表示参数不等于训练算法会找到它；
- `E03`：从输入到输出逐层记录 shape、range、finite ratio 与 activation statistics。
