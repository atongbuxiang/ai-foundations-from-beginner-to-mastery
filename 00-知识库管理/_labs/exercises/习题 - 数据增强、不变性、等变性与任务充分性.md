# 习题 - 数据增强、不变性、等变性与任务充分性

> [!abstract] 训练目标
> 能把 augmentation 写成随机核与依赖图，区分 invariance/equivariance/sufficiency，证明错误不变性的不可逆风险，计算 clustered-view 有效样本量，并设计任务合法性与迁移实验。

## A. 识别与复述

### LT-AUG-A01

写出 source unit $U$、clean observation $X$、augmentation kernel $A(dx'\mid x,u)$ 与 two-view positive joint。为什么 transform 名称列表不是完整合同？

### LT-AUG-A02

分别定义 invariance 与 $\rho$-equivariance。怎样从 equivariant feature 构造 invariant readout？

### LT-AUG-A03

区分 pointwise label preservation、conditional preservation 与 risk preservation，并各给一个可能只满足较弱条件的例子。

## B. 手算与局部推导

### LT-AUG-B01

$n=100$ 个独立 source units，每个生成 $m=8$ 个 views；同一 source 内统计量相关系数 $\rho=0.6$，边际方差为 1。计算平均量方差与 design-effect 有效样本量，并与错误的 $800$ iid 假设比较。

### LT-AUG-B02

令 $G=\{e,r,r^2,r^3\}$ 为四次旋转群，$\bar f(x)=|G|^{-1}\sum_{g\in G}f(gx)$。逐步证明 $\bar f(rx)=\bar f(x)$，并指出有限随机抽两个旋转时结论如何改变。

### LT-AUG-B03

$X=(S,N)$，$S,N\sim\operatorname{Bernoulli}(1/2)$ 独立，augmentation 翻转 $N$。分别对 $Y_1=S$ 与 $Y_2=N$ 求 invariant representation 的最小 0–1 Bayes risk。

## C. 证明与反例

### LT-AUG-C01

证明：若 $h(gx)=h(x)$，但 $P(Y\mid gx)\ne P(Y\mid x)$，则 $H=h(X)$ 不可能对 $Y$ 充分。写清 conditional-distribution 的矛盾步骤。

### LT-AUG-C02

对 $X'=X+\varepsilon$、$E\varepsilon=0$、$\operatorname{Cov}(\varepsilon)=\Sigma$ 推导二阶 augmentation 近似，并列出至少四个不能由该近似覆盖的实际增强。

### LT-AUG-C03

构造两个非交换增强 $a,b$，使 $a\circ b$ 与 $b\circ a$ 对标签合法性不同；说明 composition order 为什么必须进入配置与来源记录。

## D. 审计与诊断

### LT-AUG-D01

某医学影像分类项目使用随机水平翻转，并把同一患者的多个增强图随机分到 train/test。列出对象、标签、split、uncertainty 与 claim 五层错误，给出修订方案。

### LT-AUG-D02

机器人抓取任务把所有旋转后的图像 embedding 强制相同，但 action label 随旋转改变。判断应该使用 invariance 还是 equivariance，并写出输入群作用、feature 作用与 action head 合同。

### LT-AUG-D03

对 SimCLR 类训练，设计 no augmentation、单变换、composition、强度 sweep 与 alternative-task 五组实验。哪些统计量必须按 source unit 聚类估计？

## E. 研究与迁移

### LT-AUG-E01

为文本表示设计 span masking、paraphrase 与 entity replacement 的 augmentation card；至少覆盖 transform support、conditional-label audit、negation/number/entity stress 与 leakage。

### LT-AUG-E02

给定三个 downstream tasks：object identity、pose estimation、OCR，设计 shared encoder 的 invariant/equivariant/retained feature 分解，并说明冲突任务如何加权。

### LT-AUG-E03

提出一个可证伪研究，比较 hard-wired group equivariance、full group augmentation、partial random augmentation 与 test-time averaging。明确 estimand、样本单位、预算、公平对照和不能外推的结论。
