# 习题 - 自适应优化方法

> [!abstract] 训练目标
> 不靠背诵 optimizer 名称，而能从 variable metric、state recurrence、proof invariant、regularization 和数值实现完整重建 AdaGrad—Adam 家族。

## A. 识别与复述

### OPT-ADAPT-A01

从 variable quadratic model 推导 $x^+=x-\alpha H^{-1}g$。说明 SGD、diagonal AdaGrad、full AdaGrad 与 Newton 分别选择了什么 $H$，哪些只是算法 metric 而非 Hessian。

### OPT-ADAPT-A02

准确写出 diagonal AdaGrad、RMSProp、Adam、AMSGrad 和 AdamW 的 states 与 update；标明逐坐标运算、bias correction、epsilon 和 weight decay 的位置。

### OPT-ADAPT-A03

解释 diagonal adaptivity 的坐标依赖、对稀疏 features 的可能优势，以及它与 full-matrix geometry、natural gradient、Newton、Muon 的边界。

## B. 手算与构造

### OPT-ADAPT-B01

给定 scalar gradients $g_1=2,g_2=-1,g_3=3$，$x_1=0$，令 Adam 的 $\beta_1=1/2,\beta_2=3/4,\alpha=0.1,\epsilon=0$。逐步计算 $m_t,v_t,\hat m_t,\hat v_t,x_{t+1}$。

### OPT-ADAPT-B02

同一二维 gradients：$g_1=(4,0),g_2=(0,1),g_3=(0,1)$。计算 diagonal AdaGrad 的 cumulative states 和每步 normalized direction；与 scalar AdaGrad 比较，解释稀疏坐标效应。

### OPT-ADAPT-B03

在一步中取 $x=(10,1)$、data gradient $g=(1,1)$、diagonal preconditioner $D=\operatorname{diag}(100,1)$、$\alpha=0.01,\lambda=0.1$。分别计算 coupled L2-preconditioned update 与 AdamW-style decoupled update，证明不等价。

## C. 推导与证明

### OPT-ADAPT-C01

证明累积平方根引理

$$
\sum_{t=1}^T\frac{a_t}{\sqrt{\sum_{\tau\le t}a_\tau}}
\le2\sqrt{\sum_{t=1}^Ta_t},
$$

并用它重建 diagonal AdaGrad 的 coordinatewise regret bound，写明 diameter 与 projection 假设。

### OPT-ADAPT-C02

从 zero-initialized EMA 展开式证明 Adam 的 $1-\beta_1^t$、$1-\beta_2^t$ correction。说明 nonstationary gradients 下 correction 为什么不使 state 等于当前 moment。

### OPT-ADAPT-C03

证明 plain SGD 中 L2 penalty 与 multiplicative decay 的等价；再一般化到 $x^+=x-\alpha P(g+\lambda x)$，给出它与 $(1-\alpha\lambda)x-\alpha Pg$ 等价的充要矩阵条件。

## D. 反例与失败边界

### OPT-ADAPT-D01

解释 Adam nonconvergence counterexample 的核心：EMA denominator 下降使 effective step 增大。构造一个短的 gradient sequence 展示这一现象，并说明 AMSGrad 的逐坐标 max 如何阻止它。

### OPT-ADAPT-D02

反驳“$\sqrt{\operatorname{EMA}(g^2)}$ 就是 Hessian diagonal，因此 Adam 是 diagonal Newton”。逐条列出 local linearization、isotropy、PSD、diagonal alignment、sampling、stationarity 和 time-scale 等假设。

### OPT-ADAPT-D03

列出至少八种两个“AdamW”运行虽超参数标签相同却不等价的原因：epsilon placement、fused kernel、state dtype、bias correction、decay/scheduler、parameter groups、clipping、reduction 等；为每项给审计方法。

## E. AI 迁移

### OPT-ADAPT-E01

设计 sparse logistic-regression benchmark，比较 SGD、scalar AdaGrad、diagonal AdaGrad、Adam。记录 coordinate frequency、cumulative gradient norm、effective steps、objective/regret 和 held-out metric。

### OPT-ADAPT-E02

复现 Adam failure/AMSGrad safeguard：先做一维 online convex sequence，再做 stochastic quadratic。要求画 effective learning rate、denominator monotonicity、regret/noise floor，并审计 theorem assumptions。

### OPT-ADAPT-E03

为 Transformer optimizer comparison 写预注册协议：独立 tuning budget、tokens/FLOPs/wall-clock、公平 scheduler、decay exclusions、clipping、mixed precision、telemetry、多 seed 与选择偏差控制。
