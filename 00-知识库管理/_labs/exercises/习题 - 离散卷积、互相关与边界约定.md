# 习题 - 离散卷积、互相关与边界约定

## A. 识别与复述

### ARCH-CONV-A01

写出 1D convolution 与 cross-correlation 的一种索引定义，并指出 kernel reversal 关系。

### ARCH-CONV-A02

解释 valid、zero padding、reflection 与 circular extension 分别定义了什么。

### ARCH-CONV-A03

为什么“深度学习实现相关却称卷积”通常不减少可学习表示能力？什么场景仍必须区分？

## B. 手算与建模

### ARCH-CONV-B01

对 $x=[1,2,0,-1]$、$w=[2,-1]$，计算 valid cross-correlation 和 valid mathematical convolution。

### ARCH-CONV-B02

对同一 $x,w$，采用左右各补 1 个零的 cross-correlation，计算所有输出；说明偶数 kernel 下这个 padding 是否得到与输入同长。

### ARCH-CONV-B03

输入长度 $L=17$，$K=3,P_l=1,P_r=2,S=2,D=2$。计算 $K_{eff}$、输出长度，并列出最后一个输出使用的原始输入索引。

## C. 推导与证明

### ARCH-CONV-C01

推导 $L_{out}=\lfloor(L+P_l+P_r-D(K-1)-1)/S\rfloor+1$。

### ARCH-CONV-C02

为 $L=5,K=3$ 写出 valid correlation 的矩阵 $A_w$，并证明固定 $w$ 时它对 $x$ 线性。

### ARCH-CONV-C03

证明 circular convolution 在 DFT 基中对角化，并说明本题只需要陈述核心换元，不要求 FFT 实现。

## D. 边界、反例与纠错

### ARCH-CONV-D01

用 impulse input 构造一个能立即区分 convolution 与 correlation 的例子。

### ARCH-CONV-D02

给出 constant input 经 zero-padded averaging kernel 后边缘不再保持常数的例子。它说明了什么？

### ARCH-CONV-D03

反驳：“FFT 是 $O(L\log L)$，所以任何 CNN 卷积都应该用 FFT。”

## E. AI 迁移

### ARCH-CONV-E01

写一个框架无关的 conv1d 单元测试计划，覆盖值、shape、翻转、padding 和 dtype。

### ARCH-CONV-E02

为实时预测设计长度 5 的 causal convolution，写出 padding 和 $y[t]$ 可见的输入范围。为什么 symmetric same padding 会泄露未来？

### ARCH-CONV-E03

一篇论文把 recurrence 转成 convolution 并宣称“完全并行”。列出还要检查的四项条件。

## 分级提示

- `B01`：convolution 使用 $[-1,2]$；
- `B03`：最后窗口起点在 padded coordinates 中为 $(L+P_l+P_r-K_{eff})$ 以下最大的 stride 倍数；
- `C03`：周期移位矩阵由 Fourier vectors 对角化；
- `E02`：因果 padding 只在左侧补 $K-1$。
