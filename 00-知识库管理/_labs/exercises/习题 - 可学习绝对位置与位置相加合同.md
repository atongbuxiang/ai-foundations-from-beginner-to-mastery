# 习题 - 可学习绝对位置与位置相加合同

## A. 识别与复述

### ARCH-ABS-A01
写出 token embedding 与可学习绝对位置表相加的方程、shape 和索引范围。

### ARCH-ABS-A02
解释为什么 padding ID、sample packing、cropping 与 cached decoding 都属于位置编码合同，而不是数据管线细节。

### ARCH-ABS-A03
区分“模型能接收更长张量”“位置参数有定义”“模型能利用远程信息”三种主张。

## B. 手算与建模

### ARCH-ABS-B01
设词向量 $e=(3,4)$、位置向量 $p=(0.6,0.8)$。计算 $\|e\|,\|p\|,\|e+p\|$，并说明仅有相同维度为何不保证尺度平衡。

### ARCH-ABS-B02
批中有两个右侧 padding 的样本，真实长度分别为 3、5，张量长度为 6。写出 position IDs 与 padding mask 的两种合法约定，并说明各自要求。

### ARCH-ABS-B03
训练位置表 $P\in\mathbb R^{512\times768}$。计算参数量；若直接扩为 2048 行，新增参数量和 fp16 存储量是多少？

## C. 推导与证明

### ARCH-ABS-C01
证明当 token 与 position 只通过相加进入后续网络时，分解存在平移不可辨识性：$e_x\mapsto e_x+c, p_i\mapsto p_i-c$ 不改变输入和。

### ARCH-ABS-C02
把长度 $L_0$ 的一维位置表线性插值到 $L_1$，写出旧坐标、浮点索引、左右邻点与权重公式。

### ARCH-ABS-C03
推导逐 token cached decode 中第 $t$ 个新 token 的 position offset；证明若 offset 错一位，全量与缓存推理一般不等价。

## D. 边界、反例与纠错

### ARCH-ABS-D01
反驳：“绝对位置表有第 2048 行，因此模型已学习 2048 token 上下文。”

### ARCH-ABS-D02
构造 packing 后不 reset position IDs 会泄露样本边界统计、reset 却未隔离 attention 会发生跨样本信息泄露的例子。

### ARCH-ABS-D03
说明为什么把 ViT 的 $14\times14$ 位置表先拉平成 196 行再做任意一维插值，可能破坏二维邻接关系。

## E. AI 迁移

### ARCH-ABS-E01
为绝对位置模块设计覆盖 padding、left padding、packing、crop、cache offset 和越界行为的测试矩阵。

### ARCH-ABS-E02
设计一个绝对位置表 resize 实验，要求区分分辨率适配、长度适配与任务性能。

### ARCH-ABS-E03
为一个训练/Serving 共用的位置 ID 生成器写接口规范，列出最少输入、输出和不变量。
