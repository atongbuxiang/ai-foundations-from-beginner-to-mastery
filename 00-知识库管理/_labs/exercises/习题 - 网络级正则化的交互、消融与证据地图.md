# 习题 - 网络级正则化的交互、消融与证据地图

## A

### NN-REG-A01
把 Label Smoothing、Mixup、Dropout、DropPath、$L_2$/AdamW、Jacobian penalty、R-Drop 放入 target/input-hidden/activation-path/parameter-update/function 五类干预位置。

### NN-REG-A02
区分 objective regularization 与 optimizer update。为什么配置项名 `weight_decay` 不能确定数学对象？

### NN-REG-A03
写出 exact、local/approximate、mechanism、benchmark、deployment 五级证据各自所需材料。

## B

### NN-REG-B01
风险表为 $Y_{00}=0.30,Y_{10}=0.26,Y_{01}=0.27,Y_{11}=0.20$。计算 $A,B$ 的条件 effects 与 interaction，并解释符号。

### NN-REG-B02
DropPath block 的 $q=0.8$、residual scale $\alpha=0.25$、固定 branch vector $f=(2,-1)$。计算 branch mean 与 covariance；再把 $\alpha$ 加倍，说明 interaction。

### NN-REG-B03
写出两个独立 Dropout predictors $p_1,p_2$ 的 R-Drop objective。若 $p_1=(0.8,0.2),p_2=(0.6,0.4)$，计算 bidirectional KL 的对称平均。

## C

### NN-REG-C01
证明 fixed-prior Label Smoothing 与 target Mixup 可交换，并给出 class-dependent prior 使简单交换式失效的条件。

### NN-REG-C02
推导 SGD 中 loss-side $L_2$ 与 multiplicative decay 的系数等价；用 diagonal preconditioner 说明 Adam-like update 的断点。

### NN-REG-C03
推导 $2\times2$ difference-in-differences；说明它是哪个 protocol 下的 estimand，而不是方法的固有常数。

## D

### NN-REG-D01
反驳：“full model 删除某组件后性能下降，因此该组件在所有上下文中都有效且机制已被证明。”

### NN-REG-D02
比较 fixed-policy、retuned-policy 与 matched-budget ablation；为同一结果给出三种可能不同的解释。

### NN-REG-D03
构造一个正则化堆叠导致 underfitting 的案例：同时从 target entropy、activation/path noise、derivative penalty 与 training compute 解释。

## E

### NN-REG-E01
为四个二元 regularizers 设计资源受限的 factorial screening，声明 alias/未估 interaction 与关键 pair 复验。

### NN-REG-E02
写一份六本账的实验报告模板：objective、optimization、generalization、calibration、robustness、system，并给每本账至少三个字段。

### NN-REG-E03
选择一个陌生 Transformer/ResNet block，写出 45 分钟正则化审计：inventory、equations、interaction graph、estimands、factorial core、证据等级与停止条件。
