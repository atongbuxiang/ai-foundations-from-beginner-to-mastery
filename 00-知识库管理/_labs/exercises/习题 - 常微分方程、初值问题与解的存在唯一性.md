# 习题 - 常微分方程、初值问题与解的存在唯一性

> [!abstract] 训练目标
> 不把“写出 ODE”“存在解”“解唯一”“解能全局延拓”“求解器算得准”混成同一件事；能够从积分方程重建 Picard–Lindelöf，从 Gronwall 重建扰动账本，并把这些结论迁移到 Neural ODE。

> [!warning] 作答约定
> 每次调用定理都必须同时写出假设、时间区间和结论；每个数值量都区分 exact value $y(t_n)$ 与 computed value $y_n$。除非题目另有说明，范数均取有限维空间中的任意固定范数。

## A. 识别与复述

### DYN-IVP-A01

分别定义或解释：ODE、initial-value problem、boundary-value problem、classical solution、solution interval、maximal solution 与 numerical trajectory。指出哪些是连续对象、哪些是离散对象，并解释“方程相同”为什么不等于“问题相同”。

### DYN-IVP-A02

陈述一个精确的局部 Picard–Lindelöf 定理：给出 cylinder $R$、常数 $M,L$、时间半径 $h$ 的条件以及结论。逐项说明 continuity、state-Lipschitz、$Mh\le b$、$Lh<1$ 在证明中各负责什么。

### DYN-IVP-A03

建立以下四层 claim ladder：

1. local existence；
2. local uniqueness；
3. continuous dependence；
4. global continuation。

为每一层给出一个常用 sufficient condition，并说明该条件不是 necessary condition。再解释 Hadamard well-posedness 与 global-in-time well-posedness 的区别。

## B. 手算与构造

### DYN-IVP-B01

考虑二阶 IVP

$$
u''+3u'+2u=0,
\qquad
u(0)=1,
\qquad
u'(0)=0.
$$

1. 把它写成一阶向量系统 $x'=Ax$；
2. 求 classical solution；
3. 检验初值与微分方程；
4. 说明为什么“化为一阶系统”不是数值离散化。

### DYN-IVP-B02

在 $t\ge0$ 上考虑

$$
y'=\sqrt{|y|},
\qquad y(0)=0.
$$

对任意 $c\ge0$ 定义

$$
y_c(t)=
\begin{cases}
0,&0\le t\le c,\\
\dfrac{(t-c)^2}{4},&t>c.
\end{cases}
$$

逐点验证 $y_c$ 是 classical solution，尤其检查 $t=c$。由此说明 $f(y)=\sqrt{|y|}$ 的 continuity、local Lipschitz regularity 与 uniqueness 各自如何。不要只写“在零点不可导”。

### DYN-IVP-B03

求解

$$
y'=y^2,
\qquad y(t_0)=y_0,
$$

并对 $y_0>0$、$y_0=0$、$y_0<0$ 分别给出 maximal interval。证明 vector field 是 $C^1$ 且每个初值局部唯一，但非零解并不都在整个实轴存在。把它与 $z'=z$ 的解及最大区间比较。

## C. 推导与证明

### DYN-IVP-C01

从 Banach fixed-point theorem 完整证明局部 Picard–Lindelöf 定理。证明必须包含：

1. 轨迹空间 $X$ 及其完备性；
2. Volterra/Picard operator；
3. self-map estimate；
4. contraction estimate；
5. fixed point 与 classical solution 的等价；
6. uniqueness 的作用范围。

最后对 $y'=t+y, y(0)=0$，从 $y^{(0)}=0$ 出发计算前三个非平凡 Picard iterates，并识别极限解。

### DYN-IVP-C02

证明 integral Gronwall inequality：若连续非负函数 $u$ 满足

$$
u(t)\le A+B\int_{t_0}^{t}u(s)\,ds,
\qquad t\in[t_0,T],
$$

其中 $A,B\ge0$，则

$$
u(t)\le A e^{B(t-t_0)}.
$$

然后依次推出：

1. 同一 Lipschitz vector field、同一初值的 uniqueness；
2. 不同初值 $y_0,z_0$ 的 bound；
3. vector fields $f,g$ 满足 $\sup\|f-g\|\le\delta$ 时的 trajectory bound，并处理 $L=0$。

### DYN-IVP-C03

假设 $f$ 在 state 上 locally Lipschitz，且在任意有限时间区间 $[t_0,T]$ 上满足 linear-growth bound

$$
\|f(t,y)\|\le a(t)+b(t)\|y\|,
$$

其中 $a,b\ge0$ 且可积。

1. 用 Gronwall 推导 $\|y(t)\|$ 的显式 bound；
2. 结合 continuation criterion 证明 solution 不会在 $T$ 前因 norm blow-up 而终止；
3. 解释为什么若 domain $D$ 有边界，仅有 norm bound 仍未必足以延拓；
4. 给出一个 invariant compact set 可以替代全局 growth bound 的论证框架。

## D. 反例与失败边界

### DYN-IVP-D01

分别判断下列命题真伪；伪命题必须给出反例，真命题必须补齐缺失条件。

1. $f$ continuous，所以 IVP local unique；
2. $f$ locally Lipschitz，所以所有解 global；
3. 解 global，所以解 bounded；
4. $f$ 不 Lipschitz，所以 IVP 一定不唯一；
5. 某个初值的解唯一，所以 vector field 在其邻域 Lipschitz。

### DYN-IVP-D02

比较两个一维 vector fields：

$$
f(y)=\operatorname{ReLU}(y)=\max\{0,y\},
\qquad
g(y)=\mathbf 1_{\{y\ge0\}}.
$$

1. 证明 $f$ globally Lipschitz，求 $y'=f(y)$ 的 flow，并说明 $f$ 在零点不可微为何不妨碍标准 uniqueness theorem；
2. 说明 $g$ 在零点不 continuous，因此哪些标准定理不能直接调用；
3. 审计 neural vector field 中 hard threshold、argmax routing 与 event reset：它们分别可能破坏 continuity、Lipschitzness 或固定维连续流假设中的哪一项？

### DYN-IVP-D03

对 exact IVP

$$
y'=-3y,
\qquad y(0)=1,
$$

取 step size $h=1$ 做 forward Euler：$y_{n+1}=y_n+h(-3y_n)$。

1. 比较 exact $y(n)$ 与 computed $y_n$；
2. 解释 exact flow 稳定而 numerical trajectory 发散为何不矛盾；
3. 把 residual block $x_{k+1}=x_k+hF_k(x_k)$ 称为 Euler-like 时，至少列出四个必须声明的限定；
4. 设计一个 solver-refinement test，以区分 model failure 与 discretization failure。

## E. AI 迁移

### DYN-IVP-E01

设 Neural ODE

$$
\dot z=f_\theta(t,z),
\qquad z(0)=x,
\qquad \hat y=r_\phi(z(T)).
$$

为其建立一份 well-posedness contract：写出足以保证 $[0,T]$ 上唯一 forward trajectory 的可检查条件、初值敏感性 bound、vector-field 近似误差 bound，并区分模型层、求解器层、训练层和预测有效性层的证据。

### DYN-IVP-E02

证明：若一维 nonautonomous ODE 的 vector field 对 state 满足 uniqueness 条件，并且正反时间都可延拓，则 time-$T$ flow 对初值严格保序。因此 target map $F(x)=-x$ 不可能由这样的同维 flow 精确表示。再说明：

1. 高维中 injectivity/homeomorphism restriction 的对应含义；
2. state augmentation 如何绕开一部分表示障碍；
3. 为什么 augmentation 不自动解决 stiffness、solver cost 或 generalization。

### DYN-IVP-E03

设计一个可复现的 Neural ODE 实验协议，用于支持或否定“性能提升来自连续动力学，而非某个粗糙离散器/额外计算预算”这一主张。协议至少包含：

- 数据与时间外推切分；
- vector-field regularity audit；
- solver family、tolerance 与 step refinement；
- forward/backward consistency；
- NFE、wall-clock 与 memory；
- state norm、local error 与 failure logging；
- 离散 ResNet 和参数/算力匹配基线；
- 可以被反驳的 acceptance criteria。
