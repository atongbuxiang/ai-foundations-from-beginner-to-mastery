# 习题 - 二维、多轴与多模态位置编码

## A. 识别与复述

### ARCH-AXIS-A01
分别写出文本、图像、视频与图文混排 token 的最小坐标元组。

### ARCH-AXIS-A02
区分轴分块、轴相加、轴拼接后投影与多轴旋转四种组合方式。

### ARCH-AXIS-A03
为什么“把二维 patch 拉平成一维序列”不是无害的记号选择？

## B. 手算与建模

### ARCH-AXIS-B01
把 $2\times3$ patch 网格按 row-major 展平，列出 index 与 $(r,c)$ 的对应；计算一维差相同但二维位移不同的两对 token。

### ARCH-AXIS-B02
模型维度 $d=12$，对时间、行、列三轴等分 rotary channels。每轴得到多少维、多少二维旋转块？

### ARCH-AXIS-B03
一个图文序列含 4 个文本 token、$2\times2$ 图像 patch、3 个文本 token。设计 sequence、segment、row、column 四组 IDs，并为非适用坐标指定 sentinel/mask。

## C. 推导与证明

### ARCH-AXIS-C01
证明若行轴与列轴作用在互不相交的通道块，则多轴旋转的内积只依 $(\Delta r,\Delta c)$。

### ARCH-AXIS-C02
证明 row-major 标量位置差 $\Delta s=W\Delta r+\Delta c$ 不能在无附加信息时唯一恢复二维位移。

### ARCH-AXIS-C03
推导图像分辨率从 $H\times W$ 改为 $2H\times2W$ 时，直接沿用整数坐标与归一化坐标各保持和改变什么。

## D. 边界、反例与纠错

### ARCH-AXIS-D01
反驳：“2D RoPE 只要分别编码行列，就天然具有旋转、缩放和平移全部几何等变性。”

### ARCH-AXIS-D02
构造轴通道不足或分配不均导致某一轴分辨率过低的例子。

### ARCH-AXIS-D03
说明多模态 token 共用全局 sequence ID 为何仍可能缺少图像内部坐标或音视频时间对齐。

## E. AI 迁移

### ARCH-AXIS-E01
为图像位置编码设计 transpose、crop、resize 与 padding 的性质测试。

### ARCH-AXIS-E02
为视频模型设计长度×空间分辨率二维外推矩阵，并列出控制变量。

### ARCH-AXIS-E03
写一张多模态 position schema，明确 coordinate domain、axis allocation、special token、packing 与 cache 规则。
