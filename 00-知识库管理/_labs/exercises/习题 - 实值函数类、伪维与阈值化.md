# 习题 - 实值函数类、伪维与阈值化

> [!abstract] 训练目标
> 能用逐点阈值和 subgraph 两种语言计算伪维，区分 prediction/loss/decision class，并在实值 uniform convergence 中同时审计容量、范围、尾部与尺度。

## A. 识别与复述

### LT-PDIM-A01

写出 pseudo-shattering 的完整量词。阈值向量 $r$ 与函数 $f_b$ 谁先选择？

### LT-PDIM-A02

定义 subgraph set $G_f$，陈述 $\operatorname{Pdim}(\mathcal F)$ 与 $\operatorname{VCdim}(\{G_f\})$ 的关系。

### LT-PDIM-A03

区分 prediction class $\mathcal F$、固定阈值 decision class $\mathcal H_t$ 与 loss class $\ell\circ\mathcal F$。

## B. 手算与数值判断

### LT-PDIM-B01

证明所有常数函数 $f_c(x)=c$ 的类伪维为 1。必须同时给出下界和排除两个点的论证。

### LT-PDIM-B02

对 $f_{a,b}(x)=ax+b$，在 $x_1=0,x_2=1$、$r_1=r_2=0$ 上为四个 bit patterns 各给一组 $(a,b)$。

### LT-PDIM-B03

某 $[0,1]$ 值函数类 Pdim $d=10$，$m=10{,}000,\delta=0.05$。忽略 universal constants，计算

$$
\sqrt{\frac{d\log(em/d)+\log(1/\delta)}m}
$$

的数量级，并说明为何这不是精确置信半径。

## C. 推导与证明

### LT-PDIM-C01

双向证明 pseudo-shattering 与扩展点 $(x_i,r_i)$ 的 subgraph VC shattering 等价，处理 $=$ tie convention。

### LT-PDIM-C02

证明对任意固定 $t$，

$$
\operatorname{VCdim}(\{\mathbf1[f(\cdot)>t]:f\in\mathcal F\})
\le\operatorname{Pdim}(\mathcal F).
$$

### LT-PDIM-C03

对 singleton $\mathcal F=\{f(x)=x\}$ 构造正文中的两点重尾分布，证明 Pdim 为 0 却不存在 distribution-free bounded mean gap。把 $M$ 选成 $100m$ 并给出未见异常值概率下界。

## D. 边界、反例与纠错

### LT-PDIM-D01

反驳“函数类不可数，所以 Pdim 无限”，除常数类外再给一个有限参数例子。

### LT-PDIM-D02

预测 $f(X)$ 有界，但标签 $Y$ 重尾。说明平方损失为什么仍可无界，并给出三种修复路线。

### LT-PDIM-D03

说明 finite Pdim 与 finite $\operatorname{fat}_\gamma$ 的关系。构造一个直觉场景说明类在粗尺度简单、细尺度复杂。

## E. AI 迁移

### LT-PDIM-E01

对 reward model 分别列出 raw score class、pairwise preference decision、training loss 与 policy-induced query distribution。说明伪维能直接描述哪部分，哪些需要额外工具。

### LT-PDIM-E02

对 softmax 分类，区分 logits 的平移不变性、argmax class 和 cross-entropy loss。为什么参数维数不能直接当作 loss-class Pdim 证书？

### LT-PDIM-E03

设计一个回归 generalization report 的最小检查表，至少包含 range/tail、capacity、loss composition、sampling、numerical nonvacuity 与 shift 六项。
