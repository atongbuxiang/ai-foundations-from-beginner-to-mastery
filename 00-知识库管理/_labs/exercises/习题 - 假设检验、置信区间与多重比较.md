# 习题 - 假设检验、置信区间与多重比较

> [!abstract] 训练目标
> 能从 repeated-sampling 程序定义错误率与覆盖，推导经典检验/区间，识别 p 值误读、低 power、optional stopping 与 selection，并为多指标 AI 评价选择合适 multiplicity control。

## A. 识别与复述

### PROB-TEST-A01

定义 null/alternative、statistic、rejection region、size、level、Type I/II error 和 power。为什么 fail to reject 不等于接受 null？

### PROB-TEST-A02

给出 valid p-value 的数学定义，并逐条纠正：“p 是 null 为真的概率”“p 是随机性造成结果的概率”“p 越小 effect 越大”。

### PROB-TEST-A03

区分 confidence interval、credible interval、prediction interval、simultaneous interval、FWER、FDR 与 realized FDP。

## B. 手算与构造

### PROB-TEST-B01

$X_i\sim N(\mu,4)$，$n=25,\bar x=0.8$。检验 $H_0:\mu=0$。求双侧 z statistic、p-value、95% CI；再求右侧检验的 p-value，并解释为何不能看到符号后才选择右侧。

### PROB-TEST-B02

设计右尾 z-test，$\alpha=0.05$，$\sigma=3$，希望对 $\Delta=1$ 有 80% power。求所需近似样本量；若实际只收一半样本，求在 $\Delta=1$ 处的 power。

### PROB-TEST-B03

有 8 个 p-values：

$$
(0.001,0.008,0.012,0.020,0.031,0.049,0.20,0.70).
$$

在 $\alpha=0.05$ 下执行 Bonferroni 与 Holm，在 $q=0.05$ 下执行 BH。列出各自拒绝集合，并说明控制目标不同。

## C. 推导与证明

### PROB-TEST-C01

证明若 $p(X)$ valid，则规则 $p\le\alpha$ 是 level-$\alpha$。对连续 null statistic $T$ 推导右尾 probability-integral-transform p-value 的 uniform 性。

### PROB-TEST-C02

证明 simple-vs-simple Neyman–Pearson lemma 的核心不等式，并指出 randomized boundary 在离散样本空间中的作用。

### PROB-TEST-C03

用 test inversion 推导 known-variance normal mean CI，并证明 coverage。随后用 union bound 证明 Bonferroni FWER 控制。

## D. 边界、反例与纠错

### PROB-TEST-D01

构造或计算反复查看 fixed-horizon p-value 直到显著的 Type I error 膨胀。说明 group-sequential/always-valid 方法为什么必须改变 reference process。

### PROB-TEST-D02

给出“不显著但不能判等价”的数值例子，并用预设 equivalence margin 与 TOST/CI 给出正确结论。

### PROB-TEST-D03

团队在 20 datasets、10 metrics、30 prompts、5 seeds 上挑最高提升，只对最终一个结果做普通 paired t-test。枚举 selection family，解释 standard error/p-value 为何无效，并提出设计修复。

## E. AI 迁移

### PROB-TEST-E01

设计两个模型在同一用户集合上的 paired evaluation。处理 user cluster、多个 outcomes、多个 seeds、effect/CI、practical margin 与 independent test set。

### PROB-TEST-E02

为在线 A/B test 制定 protocol：randomization unit、primary/guardrail metrics、sample size、interim looks、SRM、attrition、interference、heterogeneity 和 rollout rule。

### PROB-TEST-E03

在 100 个子群中筛查 calibration failure。比较 Bonferroni/Holm 与 BH 的目标，说明 dependence、minimum group size、selection 后 effect estimate shrinkage 与复验方案。

## 提示

- B01：standard error $=2/5=0.4$；
- B02：$n=[\sigma(z_{.95}+z_{.8})/\Delta]^2$；
- B03：Holm 逐步阈值为 $.05/(8-k+1)$；
- D01：即使只做两个独立 looks，至少一次假阳性的概率也超过 0.05；
- D02：区间包含 0 与区间完全落在 equivalence band 是不同条件。
