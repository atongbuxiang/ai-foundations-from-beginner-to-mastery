# 习题 - 凸集、凸组合与分离超平面

> [!abstract] 训练目标
> 从线段定义证明集合凸性，能用 closed-convex projection 推出 separation，并把 simplex、norm ball、PSD cone 与 AI parameterization 分开。

## A. 识别与复述

### OPT-SET-A01

分别定义 affine、convex、conic combination，以及 affine/convex/conic hull。对两个点 $(1,0),(0,1)$ 描述三种 hull。

### OPT-SET-A02

区分 convex、closed、bounded、compact、affine、cone、convex cone、strictly convex set。给出至少四个例子说明这些性质不能互相替代。

### OPT-SET-A03

陈述 point–closed-convex-set separation、weak separation 与 strong separation。每种结论需要哪些 closedness、compactness 或 positive-distance 条件？

## B. 手算与构造

### OPT-SET-B01

令 $S=\{(1,0),(0,1),(1,1)\}$。

1. 写出 $\operatorname{aff}S$；
2. 用 inequalities 描述 $\operatorname{conv}S$；
3. 判断 $(3/4,3/4)$、$(1/4,1/4)$ 是否在 convex hull，并给 coefficients 或 separation argument；
4. 描述 $\operatorname{cone}S$。

### OPT-SET-B02

逐个证明或否定 convexity：

1. $\{x:Ax=b\}$；
2. $\{x:\|Ax-b\|_2\le r\}$；
3. $\{x:\|x\|_2=1\}$；
4. $\{X=X^T:X\succeq0,\operatorname{tr}X=1\}$；
5. $\{X:\operatorname{rank}X\le1\}$；
6. probability simplex。

### OPT-SET-B03

令

$$
C=\{x\in\mathbb R^2:x_1+x_2\le1\},
\qquad y=(2,1).
$$

求 $x^*=\Pi_C(y)$，验证 projection variational inequality，并用 $a=y-x^*$ 写出严格分离 $y$ 与 $C$ 的一个 hyperplane。

## C. 推导与证明

### OPT-SET-C01

证明任意 convex sets 的 intersection convex；证明 affine image 与 affine preimage 保持 convexity。解释为什么这些规则足以证明 polyhedron、spectrahedron 和 coordinate projection 的 convexity。

### OPT-SET-C02

完整证明：nonempty closed convex $C\subset\mathbb R^n$ 上 Euclidean projection 存在且唯一，并推出

$$
(y-x^*)^T(x-x^*)\le0,
\qquad\forall x\in C.
$$

必须分别标出 closedness 与 convexity 用在何处。

### OPT-SET-C03

从 C02 出发证明 point–closed-convex-set strict separation theorem。明确 separator normal、threshold interval 和 margin $\|y-x^*\|$ 的关系。

## D. 反例与失败边界

### OPT-SET-D01

各给一个二维反例说明：union 不保凸；convex set 的 nonlinear image 不保凸；convex function 的 equality level set 不必凸；coordinate projection 虽保凸但可能丢失 closedness。

### OPT-SET-D02

给出：

1. 非 closed convex set，使某外部点没有 nearest point；
2. closed nonconvex set，使某点有两个 nearest points。

解释 projection theorem 的两个假设分别负责什么。

### OPT-SET-D03

构造一个 prediction/output set convex、但 parameter-space objective nonconvex 的最小神经网络例子。可使用输出 $w_1w_2$ 与 squared loss。算出 Hessian 或给 line restriction 反例。

## E. AI 迁移

### OPT-SET-E01

分析 attention：softmax weights 位于 simplex，因此 output 是 values 的 convex combination。列出至少五个不能由此推出的结论，并设计检查 mask、finite logits、value hull 与 parameter optimization 的实验。

### OPT-SET-E02

比较直接优化 covariance $X\succeq0$ 与 factorization $X=LL^T$。说明 feasible geometry、gauge nonuniqueness、rank restriction、convexity 和 numerical cost 的差异，并给一个可复现的验证表。

### OPT-SET-E03

为 $k$-sparse 或 rank-$r$ 模型设计 convex relaxation 审计：原集合、convex surrogate、relaxed lower bound、rounding/recovery、feasibility、integrality/relaxation gap 与 held-out risk 必须分别记录。
