# 习题 - 光滑流形、切空间与余切空间

> [!abstract] 训练目标
> 从“曲面附近像平面”的图片直觉升级为可审计的一阶微分几何：能声明 manifold 的拓扑与 smooth structure，能在换 chart 后追踪 tangent/cotangent components，能用 image/kernel/rank 计算切空间，并能判断 neural decoder、local PCA 与 autoencoder 到底提供了何种强度的 manifold 证据。

> [!warning] 作答合同
> 每次写 tangent、gradient、rank、embedding 或 manifold，都必须声明基点、domain/codomain、intrinsic/ambient dimension、chart 或 embedding，以及结论是一般 theorem、population assumption、finite-sample estimate 还是 numerical observation。未给 metric 时不得把 covector $df$ 无条件写成 tangent gradient。

## A. 定义、对象与层级

### GEO-MAN-A01

建立以下对象的“类型—条件—反例”表：

1. $d$-dimensional topological manifold；
2. chart、coordinate neighborhood、coordinate functions；
3. compatible charts、smooth atlas 与 maximal atlas；
4. smooth manifold with/without boundary；
5. abstract manifold、immersed submanifold、embedded submanifold；
6. intrinsic dimension、ambient dimension 与 latent dimension。

逐项解释 Hausdorff、second-countable、locally Euclidean 和 smooth transition 各负责什么。判断以下对象属于哪一类：$\mathbb R^d$、$S^1$、$[0,1]$、两条相交直线、有限点集、torus、figure-eight parametrized image。

### GEO-MAN-A02

为以下对象建立 domain/codomain、维数和坐标表达表：

1. tangent vector $v\in T_pM$；
2. cotangent vector $\alpha\in T_p^*M$；
3. smooth map differential $dF_p$；
4. scalar differential $df_p$；
5. tangent bundle $TM$ 与 cotangent bundle $T^*M$；
6. vector field、1-form、pushforward 与 pullback。

证明或反驳：

1. $T_pM$ 与 $T_qM$ 自动是同一个向量空间；
2. $df_p$ 是 $T_pM$ 中的向量；
3. $dF_p$ 的 Jacobian matrix 不依赖 charts；
4. $\alpha(v)$ 不依赖 coordinates；
5. 每个 1-form 都等于某个 global function 的 differential。

### GEO-MAN-A03

比较 immersion、submersion、local diffeomorphism、embedding、diffeomorphism 与 isometry。对每个概念写出 differential rank 条件、global condition、保持的结构和不能推出的结论。

再为 neural decoder $g:\mathbb R^d\to\mathbb R^D$ 建立声明阶梯：

$$
\text{sampled full rank}
\to
\text{local immersion evidence}
\to
\text{embedding}
\to
\text{population manifold model}.
$$

指出每个箭头还缺哪些假设或实验。

## B. Charts、切空间与 Jacobian 手算

### GEO-MAN-B01

在 circle

$$
S^1=\{(x,y):x^2+y^2=1\}
$$

上取北/南 stereographic coordinates

$$
u_N(x,y)=\frac{x}{1-y},
\qquad
u_S(x,y)=\frac{x}{1+y}.
$$

1. 推导两张 charts 的 inverse；
2. 求 overlap 上 transition map 及其 derivative；
3. 对点 $p=(1,0)$，分别求两 charts 中的 coordinates；
4. 若 tangent vector 在 $u_N$ coordinate 中 component 为 $a$，求其 $u_S$ component；
5. 若 covector 在 $u_N$ 中 component 为 $b$，求其 $u_S$ component；
6. 验证 pairing 在换坐标前后相同；
7. 解释为何 angle $\theta$ 不能成为整个 $S^1$ 的单张 chart。

### GEO-MAN-B02

分别用 parametrization image 与 constraint kernel 计算：

1. $S^2$ 在 $p=(1,2,2)/3$ 的 tangent space；
2. paraboloid $g(u,v)=(u,v,u^2+v^2)$ 在 $g(1,-1)$ 的 tangent basis；
3. matrix sphere $\{W:\|W\|_F=1\}$ 在 $W$ 的 tangent space；
4. Stiefel set

$$
\mathrm{St}(n,r)=\{Y\in\mathbb R^{n\times r}:Y^\top Y=I_r\}
$$

在 $Y$ 的 linearized tangent condition；
5. 计算 $\dim\mathrm{St}(n,r)$，并说明 constraints 为什么只有 $r(r+1)/2$ 个独立标量条件，而不是 $r^2$。

### GEO-MAN-B03

令 decoder 与 encoder 为

$$
g(u,v)=(u,v,u^2+v^2),
\qquad
E(x,y,z)=(x,y).
$$

1. 求 $J_g(u,v)$ 与 $J_E$ 的 shapes、ranks 和 singular-value 下界；
2. 验证 $E\circ g=\operatorname{id}_{\mathbb R^2}$ 及 $J_EJ_g=I_2$；
3. 计算 $P=J_gJ_E$，验证 $P^2=P$；
4. 判断 $P$ 是否为 Euclidean orthogonal projector；
5. 求真正 orthogonal tangent projector

$$
P_\perp=J_g(J_g^\top J_g)^{-1}J_g^\top;
$$

6. 解释 $P$ 与 $P_\perp$ 差异对应 encoder 选择的什么几何含义；
7. 若把 decoder 改成 $\tilde g(u,v)=(u^2,v,u^2+v^2)$，找出 rank-collapse locus。

## C. 定理、等价定义与证明链

### GEO-MAN-C01

证明 smooth map 的定义不依赖 source/target charts，并证明 differential 的 coordinate matrices满足

$$
[dF_p]_{\tilde y\leftarrow\tilde x}
=J_{\tilde y\leftarrow y}
[dF_p]_{y\leftarrow x}
J_{x\leftarrow\tilde x}.
$$

从 curve definition 与 derivation definition 各证明一次 manifold chain rule

$$
d(G\circ F)_p=dG_{F(p)}\circ dF_p.
$$

最后证明 rank $dF_p$ 是 coordinate-independent quantity。

### GEO-MAN-C02

设 $F:U\subseteq\mathbb R^D\to\mathbb R^k$ smooth，$c$ 是 regular value，$M=F^{-1}(c)$。

1. 用 implicit function theorem 给出 $M$ 局部是 graph 的证明路线；
2. 证明 $\dim M=D-k$；
3. 证明 $T_xM=\ker DF(x)$；
4. 证明 $dc_1|_x,\ldots,dc_k|_x$ span tangent annihilator；
5. 在 Euclidean inner product 下连接 normal space 与 constraint gradients；
6. 删除 regular-value 条件，用 $F(x,y)=x^2-y^2$ 说明证明在哪一步断裂。

### GEO-MAN-C03

完整证明 tangent space 的 curve-equivalence 与 derivation definitions 等价：

1. curve velocity 怎样产生 derivation；
2. 等价 curves 为什么产生同一 derivation；
3. 任意 derivation 怎样由 coordinate components $v[x^i]$ 唯一表示；
4. 怎样构造一条 curve 实现任意 coordinate vector；
5. 为什么这给 $\dim T_pM=d$。

再推导 vector/covector components 的相反变换律，并证明 $df_p(v)$ 与一般 pairing $\alpha(v)$ coordinate invariant。

## D. 反例、条件删除与错误研究声明

### GEO-MAN-D01

逐一分析以下空间在哪些点失败、失败的是哪条 manifold condition，以及它是否可改成 manifold with boundary、immersed object 或 stratified object：

1. $X=\{(x,y):xy=0\}$；
2. $[0,1]$；
3. cone $z^2=x^2+y^2$ 的顶点；
4. two spheres tangent at one point；
5. line with two origins；
6. uncountable discrete space。

不得只凭图形作答；至少使用 deleted-neighborhood component count、Hausdorff、second-countable 或 regular-level rank 中的一种正式诊断。

### GEO-MAN-D02

构造并分析三个独立反例：

1. immersion 但不是 embedding；
2. everywhere local diffeomorphism 但不是 global diffeomorphism；
3. finite training set 上 reconstruction loss 为零，但 encoder/decoder 不在 population support 上形成 homeomorphism。

对每个反例明确指出 local derivative 告诉了什么、global topology 又缺什么。再解释为什么“$J_g$ 在 1000 个 sampled latent points 上 full rank”仍不能证明 global embedding。

### GEO-MAN-D03

审计以下声明，每条给出判定、缺失假设、最小反例/修正版与可计算诊断：

1. “Local PCA 前两特征值很大，所以数据严格位于二维 smooth manifold。”
2. “Decoder 最小奇异值为正，所以 latent interpolation 永远有效。”
3. “Autoencoder reconstruction 很小，所以 latent 与 data topology 相同。”
4. “Tangent space 是平的，所以 manifold curvature 为零。”
5. “$df$ 和 gradient 只是 row/column 记号差别。”
6. “有限数据本身是 0-manifold，所以 intrinsic dimension estimator 都没有意义。”

要求把 population、finite sample、neighborhood scale、network map、autodiff computation 与 theorem 分成六本账。

## E. AI 综合建模与研究设计

### GEO-MAN-E01

为 circle/torus 数据设计一个 atlas autoencoder。必须写出：

1. chart index、local coordinate、encoder 与 decoders 的对象和 shapes；
2. chart domains、overlaps 与 coverage mechanism；
3. transition maps、inverse consistency 与 triple-overlap cycle；
4. reconstruction、routing、rank、overlap 与 topology losses；
5. 如何防止 chart collapse、duplicate coverage 和 uncovered region；
6. single Euclidean latent baseline 为什么必有 seam、duplication或distortion；
7. train/validation sampling 与 population claim 的边界；
8. 哪些结果支持 atlas hypothesis，哪些仍不能证明 mathematical atlas。

### GEO-MAN-E02

设计一个 noisy embedded manifold 的 tangent-estimation benchmark，比较 analytic tangent、decoder Jacobian 与 local PCA：

1. 选择 circle、sphere、paraboloid 或 Swiss roll，并写出 ground-truth tangent；
2. 扫描 sample size、noise、radius、curvature位置与 boundary；
3. 使用 projector/principal-angle error，不逐列比较 bases；
4. 同时记录 PCA eigengap、neighbor count 与 decoder singular values；
5. 分离 curvature bias、sampling variance、noise floor 与 model bias；
6. 规定 deterministic artifact、seed、assertions 与失败门；
7. 说明实验怎样支持 local linearization，又不能证明真实数据 manifold hypothesis。

### GEO-MAN-E03

为 $d$-dimensional data manifold $M\subset\mathbb R^D$ 上的生成模型写 object–measure–chart contract：

1. base space、manifold、ambient space 与 dimensions；
2. decoder/flow 是 immersion、embedding、diffeomorphism 还是 projection；
3. density 相对于 latent Lebesgue、intrinsic volume 还是 ambient Lebesgue；
4. non-square Jacobian 的 volume factor 与 chart overlap；
5. singular ambient law、added noise/dequantization 与 observed likelihood；
6. topology mismatch、rank collapse、self-intersection 与 boundary；
7. sampling、density evaluation 和 training objectives 分账；
8. 何时需要多 charts、structured latent 或 augmented ambient variables。

最后写一段审稿意见，纠正“模型在 ambient space 给出了高 likelihood，所以已经恢复真实低维数据流形及其 topology”的说法。
