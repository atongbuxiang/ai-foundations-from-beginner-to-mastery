# 习题 - 样本压缩方案与泛化

> [!abstract] 训练目标
> 能定义 compressor–message–reconstructor 合同，重建 description-count × missed-check 概率证明，并区分 sample、bit、parameter 与 lossy compression。

## A. 识别与复述

### LT-COMP-A01

定义 exact-size-$k$ sample compression scheme $(\kappa,q,\rho)$，并写出 full-sample consistency 条件。

### LT-COMP-A02

解释 unordered subset、ordered tuple、side-message set $Q$ 分别怎样改变 description count。

### LT-COMP-A03

区分 sample compression size、bit-code length、parameter sparsity 与 PAC-Bayes KL；各自压缩的对象是什么？

## B. 手算与数值判断

### LT-COMP-B01

$m=200,k=3,b=4,\delta=0.05$。用 exact formula
$$
[\log{m\choose k}+b\log2+\log(1/\delta)]/(m-k)
$$
计算风险上界。

### LT-COMP-B02

$m=1000,k=20,b=0,\delta=0.01$。用 $\log{m\choose k}\le k\log(em/k)$ 给一个数值上界。

### LT-COMP-B03

一个 at-most-2 scheme 的 message set 大小为 3。写出完整 description count，并在 $m=10$ 时算出数值。

## C. 推导与证明

### LT-COMP-C01

对固定 subset $I$ 和 message $q$，证明 risk $>\varepsilon$ 的 reconstructed hypothesis 与其余 $m-k$ 个样本全一致的概率至多 $(1-\varepsilon)^{m-k}$。

### LT-COMP-C02

对所有 $(I,q)$ 做 union bound，并用 $1-\varepsilon\le e^{-\varepsilon}$ 解出 high-probability risk bound。

### LT-COMP-C03

为一维 interval concepts 构造 at-most-2 compression scheme，包括“无 positive sample”的 side message，并证明重构与全样本一致。

## D. 边界、反例与纠错

### LT-COMP-D01

解释为什么“一个实数 threshold point 的 sample compression size 为 1”不代表 hypothesis 只需 1 bit。

### LT-COMP-D02

反驳：“soft-margin SVM 只保存 support vectors，所以可直接使用 realizable exact-size-$k$ bound。”列出至少四个缺口。

### LT-COMP-D03

给出一个只拟合 retained $k$ 个点、却在其余训练点全部出错的 decoder；说明为什么 full-sample consistency 不能删除。

## E. AI 迁移

### LT-COMP-E01

审计一个 pruned/quantized neural network：它更接近 sample compression 还是 bit/Occam compression？要形成有效 description certificate 还需计入什么？

### LT-COMP-E02

dataset distillation 产生 $k$ 个 synthetic examples。解释它为何通常不属于本章 sample compression，并提出一个可审计的替代 description contract。

### LT-COMP-E03

一个 prototype classifier 保留 $k$ 个原始样本，但 representation encoder 由全训练集学习。说明只数 prototypes 为什么不够，并给出两种修复方案。
