# 习题 - 残差学习、恒等捷径与退化问题

## A

### NN-RID-A01
对 $X\in\mathbb R^{B\times T\times D}$，分别写出 identity residual block 与 projection residual block 的前向公式、两条加法输入的 shape 和必要的 dtype/device 合同。

### NN-RID-A02
把下列问题分类为 representation、optimization 或 generalization：存在零训练误差参数；SGD 在预算内找不到；训练误差低但测试误差高；更深模型可嵌入浅模型函数。

### NN-RID-A03
为什么“更深 plain net 的训练误差更高”叫 degradation，而不能直接叫 overfitting？这个观察能否单独证明 residual shortcut 是唯一原因？

## B

### NN-RID-B01
目标映射为 $H(x)=1.21x$。用两层共享标量分别写成 plain $w^2x$ 与 residual $(1+a)^2x$，求正根参数，并说明 identity 在两种坐标中的位置。

### NN-RID-B02
对 $x_{\ell+1}=x_\ell+F_\ell(x_\ell)$ 展开 $x_3$。为什么这个求和式不等于三个 branch 独立并行地只读取 $x_0$？

### NN-RID-B03
输入 $X\in\mathbb R^{B\times64\times32\times32}$，主 branch 输出 $B\times128\times16\times16$。设计一个可相加 shortcut，写出 projection kernel/stride 的一种选择及输出 shape，并解释它为何不是 identity。

## C

### NN-RID-C01
给出 $\mathcal H_L\subseteq\mathcal H_{L+1}$ 的一个充分条件证明，再用 $x^+=\operatorname{ReLU}(x+F(x))$ 在 $F=0$ 时构造全空间反例。

### NN-RID-C02
比较深线性 plain map $W_{L-1}\cdots W_0$ 与 residual map $\prod_{\ell}(I+A_\ell)$。若所有 $A_\ell=0$，各自输出什么？若目标远离 $I$，为什么不能从 near-identity 参数化推出优化必优？

### NN-RID-C03
令 $F(x)=W_2\phi(W_1x)$。初始化 $W_2=0$、$W_1$ 随机。对单样本损失推导第一步 $\nabla_{W_2}\mathcal L$ 与 $\nabla_{W_1}\mathcal L$，说明 zero-last 的收益与“第一步内部层不更新”边界。

## D

### NN-RID-D01
为 identity shortcut、$1\times1$ projection shortcut 与带下采样 shortcut 分别列参数、FLOPs、activation memory、memory traffic 和信息损失风险。哪些成本不能从“加法无参数”推出？

### NN-RID-D02
IEEE FP16 在 $x=1024$ 附近相邻数间距为 1。讨论 round-to-nearest 下把 residual $0.25$、$0.5$、$0.75$ 加到 1024 的结果边界；这对极小 residual scale 有何警告？

### NN-RID-D03
设计 plain/residual 深网的公平 degradation 实验。至少固定 width、参数量或 FLOPs、初始化、normalization、optimizer、训练预算和调参预算，并分别报告训练与测试响应。

## E

### NN-RID-E01
反驳：“只要模型有 skip connection，加深后的函数类就必然包含原函数类。”至少给出 projection、post-add transform 和 stochastic/stateful 三类失败方式。

### NN-RID-E02
设 $P_\ell=\frac12I,F_\ell=0$。求 $L$ 层后输出与 shortcut Jacobian。这个网络有 skip，为什么没有 identity rail 的深度保持性质？

### NN-RID-E03
提出一个区分三种机制的实验：identity baseline、Jacobian propagation、增量/参数更新尺度。写出每种机制的干预变量、诊断量和不能由结果推出的更强结论。
