# 习题 - 概率语言模型、链式法则与自回归因子化

## A. 识别与复述

### LM09-A01
概率语言模型的样本空间为什么必须包含 tokenizer、边界和 EOS 合同？

### LM09-A02
区分链式法则、自回归参数化与 token 独立假设。

### LM09-A03
EOS 在可变长度模型中承担哪两个概率角色？

## B. 手算与构造

### LM09-B01
给定 $p(A)=0.6,p(B)=0.3,p(EOS)=0.1$，$p(B\mid A)=0.5,p(EOS\mid AB)=0.8$，算 $p(ABEOS)$ 与 NLL（nats）。

### LM09-B02
二元长度 2 联合表 $p(00)=0.2,p(01)=0.3,p(10)=0.1,p(11)=0.4$，还原 $p(x_1)$ 与 $p(x_2\mid x_1)$。

### LM09-B03
构造一个最大长度 2、词表 `{a, EOS}` 的概率树，并验证所有终止叶概率和为 1。

## C. 推导与证明

### LM09-C01
从条件概率定义归纳证明 $p(x_{1:T})=\prod_t p(x_t\mid x_{<t})$。

### LM09-C02
证明期望 log loss 等于熵加 KL，并说明最优解何时唯一。

### LM09-C03
证明完整序列 NLL 等于各 token NLL 之和；平均 NLL 为什么不是该序列的负对数概率？

## D. 边界、反例与纠错

### LM09-D01
反驳“自回归模型假设各 token 独立”。

### LM09-D02
给出每个有限前缀条件分布都归一化、却有正概率永不发 EOS 的模型。

### LM09-D03
指出“验证 NLL 更低，所以事实性一定更好”的证据缺口。
