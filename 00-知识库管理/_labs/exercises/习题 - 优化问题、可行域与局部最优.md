# 习题 - 优化问题、可行域与局部最优

> [!abstract] 训练目标
> 先把 problem contract 和状态语义写对，再讨论算法。每道 AI 题都必须区分 objective、feasibility、stationarity、population 与 deployment evidence。

## A. 识别与复述

### OPT-PROB-A01

写出一般 inequality/equality constrained minimization 的标准形式，并逐项定义 decision variable、effective domain、feasible set、optimal value 和 solution set。解释 data、hyperparameter 与 random seed 在一次固定 problem instance 中通常是什么角色。

### OPT-PROB-A02

区分：feasible、infeasible、bounded below、unbounded below、infimum、minimum、global minimizer、local minimizer、strict local minimizer、stationary point。哪些概念描述问题，哪些描述点？

### OPT-PROB-A03

说明 objective gap、distance to solution set、stationarity residual 和 feasibility residual 分别测量什么。为什么它们不能在任意问题中由一个小量推出另一个小量？

## B. 手算与构造

### OPT-PROB-B01

逐个分类下列问题：feasible/infeasible、optimal value、是否 attained、是否 unbounded，并给 solution set。

1. $\min_{x>0}x$；
2. $\min_{x\in\mathbb R}-x$；
3. $\min_{0\le x\le1}(x-2)^2$；
4. $\min_x x^2$ subject to $x\ge1,x\le0$；
5. $\min_{x\in\mathbb R}e^x$；
6. $\min_{x\ne0}x^2$。

### OPT-PROB-B02

对

$$
f(x)=x^4-2x^2
$$

求所有 stationary points 并分类为 local min/max。再求 constrained problem

$$
\min_{x\ge0}(x+1)^2
$$

的解，说明为什么最优点 ordinary gradient 不为零。

### OPT-PROB-B03

原问题为

$$
\min_x(x-1)^2
\quad\text{s.t.}\quad x=0.
$$

求 exact solution。再求 quadratic-penalty problem

$$
\min_x(x-1)^2+\rho x^2,
\qquad\rho>0,
$$

的解、constraint residual 和 objective at solution。解释有限 $\rho$ 是否与 hard constraint 等价。

## C. 推导与证明

### OPT-PROB-C01

证明：若 $\mathcal F\subset\mathbb R^n$ nonempty compact，$f$ continuous，则 $f$ 在 $\mathcal F$ 上取得 minimum。必须从 minimizing sequence、收敛子列和 continuity 三步写出，并说明每个假设若删除会怎样失败。

### OPT-PROB-C02

若 $\phi$ strictly increasing，证明

$$
\arg\min_{x\in\mathcal F}f(x)
=\arg\min_{x\in\mathcal F}\phi(f(x)).
$$

再以 $f(x)>0$ 与 $\log f(x)$ 为例，说明 exact minimizer 相同为什么 gradient descent trajectory 和 gradient threshold 仍不同。

### OPT-PROB-C03

假设 $f$ 满足 quadratic growth

$$
f(x)-f^*
\ge\frac\mu2\operatorname{dist}(x,\mathcal X^*)^2,
\qquad\mu>0.
$$

从 objective gap $f(x)-f^*\le\varepsilon$ 推出 distance certificate。再用 $f_\delta(x)=\delta x^2$ 说明没有统一 $\mu$ 时，小 gap/小 gradient 可以与远离解并存。

## D. 反例与失败边界

### OPT-PROB-D01

各给一个显式函数，证明：

1. stationary point 可以是 maximum；
2. stationary point 可以既非 minimum 也非 maximum；
3. nonsmooth global minimizer 可以没有 ordinary derivative；
4. constrained global minimizer 可以有非零 gradient。

### OPT-PROB-D02

构造一族函数，使某固定点到 solution set 的距离恒为 1，但 objective gap 和 gradient norm 都趋于 0。解释这否定了怎样的跨问题 stopping rule。

### OPT-PROB-D03

某求解器在三个 run 中分别返回：`diverged`、`infeasible_or_unbounded`、`gradient_norm < 10^-6`。逐项说明这些状态不能单独推出什么，并给出区分建模、算法、数值与最优性原因的最小诊断集合。

## E. AI 迁移

### OPT-PROB-E01

为一个带 class imbalance、$\ell_2$ regularization、latency budget 和 subgroup calibration constraint 的分类器写完整 problem contract。必须包含变量、empirical objective、constraint estimator、domain、solution concept、residual、split 与不能推出的部署结论。

### OPT-PROB-E02

审计 adversarial training：

$$
\min_\theta E\left[\max_{\|\delta\|_\infty\le\varepsilon}
\ell(f_\theta(X+\delta),Y)\right].
$$

若实现只用 5-step PGD 和 minibatch SGD，写出实际优化对象与理想对象之间至少四层 gap，并设计可证伪的验收协议。

### OPT-PROB-E03

设计 LoRA rank/weight-decay 的 bilevel selection protocol：inner train、outer validation、final test。说明 inner solution 非唯一、有限步训练、hyperparameter search、multiple seeds 和 base-model sharing 怎样进入问题定义；不得把最佳 validation run 当作无偏 test evidence。
