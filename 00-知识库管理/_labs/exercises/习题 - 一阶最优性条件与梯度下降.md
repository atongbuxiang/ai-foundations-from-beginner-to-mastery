# 习题 - 一阶最优性条件与梯度下降

> [!abstract] 训练目标
> 能从假设逐行推出“下降—telescoping—rate—停止证书”，并始终说明结论是 stationarity、function gap、distance 还是统计表现。

## A. 识别与复述

### OPT-GD-A01

陈述 unconstrained differentiable local optimum 的必要条件、differentiable convex problem 的充要条件，以及 convex constrained problem 的 variational inequality。解释边界 optimum 为什么 gradient 不必为零。

### OPT-GD-A02

从 Euclidean steepest descent 和 regularized linear model 两个视角解释 gradient step。若换成 $P$-norm，更新方向如何变化？为什么 negative gradient 不是 coordinate invariant？

### OPT-GD-A03

分别陈述 smooth nonconvex、smooth convex、smooth strongly convex 的 gradient-descent guarantee；写明步长、metric、rate 和不能推出的结论。

## B. 手算与构造

### OPT-GD-B01

对 $f(x)=\frac12ax^2$，$a>0$：

1. 写 gradient descent recurrence；
2. 求收敛的精确步长区间；
3. 区分 monotone、oscillatory-convergent 与 divergent 区间；
4. 给定 $x_0$ 写 closed form；
5. 比较 $\eta=1/a,,1/(2a),,2/a$。

### OPT-GD-B02

对 $Q=\operatorname{diag}(1,9)$ 的 quadratic，令 $b=0$：

1. 分解两个 eigenmodes；
2. 分别计算 $\eta=1/9$ 与 $\eta_*=2/10$ 的 contraction factors；
3. 从给定 $x_0=(1,1)$ 写前三步；
4. 解释 zig-zag 和 condition number。

### OPT-GD-B03

实现纸面 backtracking：给 $f(x)=e^x-x$、起点 $x_0=2$、direction $-f'(x_0)$、$c=1/4$、$\beta=1/2$、初始步长 1。逐次检查 Armijo，找到首个接受步长，并说明 domain/overflow 应如何处理。

## C. 推导与证明

### OPT-GD-C01

用 descent lemma 推导

$$
f(x_{k+1})
\le f(x_k)-\eta(1-L\eta/2)\|\nabla f(x_k)\|^2.
$$

证明 $0<\eta<2/L$ 的下降结论，并推导 smooth lower-bounded nonconvex objective 的 $O(1/T)$ minimum squared-gradient bound。

### OPT-GD-C02

用 distance potential 完整推导 convex $L$-smooth、$\eta=1/L$ 时

$$
f(x_T)-f^*
\le\frac{L\|x_0-x^*\|^2}{2T}.
$$

说明为何可从 average bound 转为 last-iterate bound。

### OPT-GD-C03

用 PL/strong-convex gradient bound 推导 geometric function-gap rate。再对 SPD quadratic 最小化

$$
\max_{\lambda\in[\mu,L]}|1-\eta\lambda|
$$

得到 $\eta_*=2/(L+\mu)$ 和 $\rho_*=(\kappa-1)/(\kappa+1)$，区分 error-norm 与 function-gap factor。

## D. 反例与失败边界

### OPT-GD-D01

分别构造：gradient 为零但为 local maximum；gradient 为零但为 saddle；function values 收敛而 iterates 不收敛或不唯一。说明每个例子缺少哪个假设。

### OPT-GD-D02

构造 smooth convex quadratic，使 $\eta=2/L$ 不收敛、$\eta>2/L$ 发散。再说明若只知道 local Hessian estimate，为什么使用 $2/\widehat L$ 仍无 global safety certificate。

### OPT-GD-D03

审计以下声明：“训练 loss 连续下降、step norm 已很小、mini-batch gradient 也接近零，因此到达了全局最优并会泛化。”至少指出八个逻辑或测量缺口，并给出修复证据。

## E. AI 迁移

### OPT-GD-E01

设计 quadratic learning-rate stability map：控制 spectrum、扫描 $\eta L$、记录 eigenmode/objective/gradient/overflow，并验证理论在 float32、float16/bfloat16 下的偏离。

### OPT-GD-E02

为 logistic regression 比较 fixed $1/L$、exact line search 与 Armijo backtracking。纳入 sum/mean reduction、ridge、analytic/local $L$、function/gradient cost、stopping certificate 与 held-out metric。

### OPT-GD-E03

围绕“有限学习率可能隐式正则”设计多 seed 受控实验。固定数据顺序、batch、scheduler、precision 和 clipping，比较 gradient-flow近似、小/中/大步长，并区分 optimization、discretization、noise 与 generalization effect。
