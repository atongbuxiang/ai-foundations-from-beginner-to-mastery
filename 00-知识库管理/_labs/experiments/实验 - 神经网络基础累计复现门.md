# 实验 - 神经网络基础累计复现门

> [!abstract] 实验定位
> 这是 `NN-CUM-01` 的计算复现门。A 轨检查一个真实 composite graph 的 forward/reverse 对账；B 轨把单层方差、深层乘积、残差缩放和 LayerNorm 不变量分开；C 轨检查 tied parameter 的多路径 gradient、target affine identity、Dropout covariance 与 factorial interaction。脚本通过只说明这些有限合同实现一致，不等于闭卷通过、陌生 block 迁移或真实任务泛化。

## 一、预注册问题与可证伪预期

### A 轨：Forward / Reverse 与 Finite Difference

固定两层网络

$$
a=W_1x+b_1,
\quad h=\operatorname{ReLU}(a),
\quad z=W_2h+b_2,
$$

使用[[阶段测验 - 神经网络基础（第三章）#第 5 题：两层 MLP 的完整 Forward / Reverse（8 分）|累计测验第 5 题]]的参数和第三类 fused softmax cross-entropy。脚本独立实现 analytic reverse，并对 15 个 scalar parameters 做中心差分：

$$
g_j^{\rm num}(\delta)
=\frac{L(\theta+\delta e_j)-L(\theta-\delta e_j)}{2\delta}.
$$

> [!hypothesis]
> 当 $\delta$ 从 $10^{-1}$ 降到约 $10^{-5}$，max absolute error 应按 truncation error 下降；再继续减小会受 floating-point cancellation 影响而回升。本参数邻域的两个 ReLU preactivations 为 3 和 0.5，足以在所用步长内保持 activation pattern。若曲线不先降后升，需检查 forward、reverse、parameter flattening 或差分公式。

### B 轨：Plain Product、Residual Scale 与 LayerNorm

固定深度 $L=64$ 与 scalar coefficients

$$
w_l=0.15+0.05\sin(0.7l),
\qquad l=1,\ldots,64.
$$

比较三种 end-to-end Jacobian gain：

$$
J_{\rm plain}=\prod_lw_l,
$$

$$
J_{\rm res,1}=\prod_l(1+w_l),
\qquad
J_{\rm res,scaled}=\prod_l\left(1+\frac{w_l}{\sqrt L}\right).
$$

另对 $x=(1,2,3)$、$\epsilon=0$、无 affine 的 LayerNorm 检查

$$
\operatorname{LN}(2x+5\mathbf1)=\operatorname{LN}(x).
$$

> [!hypothesis]
> 在这组固定 coefficients 上，plain product 应降到 $10^{-40}$ 以下，未缩放 residual product 应超过 $10^3$，$1/\sqrt L$ 缩放应保持在 2—4；LayerNorm affine-invariance error 应在浮点容差内为 0。这只检查一个 scalar construction，不证明 $1/\sqrt L$ 对任意 nonlinear residual network 最优。

### C 轨：Tied Gradient、目标变换与随机 Moments

令

$$
E=
\begin{bmatrix}
1&0\\0&2\\1&1\\0&0
\end{bmatrix},
\qquad
\mathrm{ids}=(3,2,3),
$$

hidden 为三行 lookup 的 mean，logits 为 $Eh$。Target 先以 $\lambda=0.3$ 混合 $e_1,e_3$，再以 $\epsilon=0.2$ 做 inclusive uniform smoothing：

$$
t=(0.29,0.05,0.61,0.05).
$$

同一个 $E$ 同时出现在 lookup 与 output projection 中，所以 analytic gradient 必须是

$$
\nabla_EL
=\nabla_E^{\rm output}+\nabla_E^{\rm lookup}.
$$

同时核对：fixed-prior smoothing 与 target Mixup 的 commutation；$x=(2,-1),q=0.75$ 的逐坐标 independent inverted Dropout covariance；给定 $2\times2$ risk table 的 interaction。

> [!hypothesis]
> 两路合并后的 tied gradient 与 central difference max error 应小于 $10^{-8}$；漏掉 lookup path 的 error 应大于 0.5。Target commutation difference 应为 0（浮点容差），Dropout covariance diagonal 应为 $(4/3,1/3)$，interaction 应为 $-0.03$。

## 二、对象—证据—不可推出结论

| 轨道 | 直接计算对象 | 可以支持 | 不能推出 |
|---|---|---|---|
| A | 固定 ReLU region 中 analytic VJP 与 central difference | 当前 forward/reverse、shape 和 parameter ordering 对齐 | kink convention 普遍正确；高阶导、AMP、真实模型都正确 |
| B | 一个 scalar 64 层 product 与一个 LN 不变量 | 深度 product 可与单层平均尺度严重不同；当前 scale 实现正确 | 任意随机矩阵谱、optimization、expressivity 或泛化稳定 |
| C | tied $E$ 的两路 gradient、affine target identity、条件 moments | 共享 parameter 必须合并 VJP；所声明概率合同数值正确 | Tying/Mixup/Dropout 必然改善任务表现、校准或鲁棒性 |

## 四、结果

先看图回答：A 的误差为何不是步长越小越好？B 为什么把 plain、未缩放 residual 与 scaled residual 画在同一 log 账本？C 漏掉哪条共享参数路径时误差会从 $10^{-11}$ 升到约 $0.502$？

> [!figure] 实验图｜梯度对账、深度尺度与共享随机合同
> **对象与结论**：A 扫描 finite-difference step；B 比较 64 层 scalar Jacobian products并附 LN 不变量；C 对 tied gradient、target commutation、Dropout covariance 与 interaction 做独立断言。生成脚本：[[plot_neural_network_cumulative_gate.py]]；所有常数都在本页和代码中显式给出。
>
> **怎样读图**：A 先找 U-shaped error 的最低点，不把最小步长当作最佳；B 读纵轴是 $\log_{10}|J|$，不是 accuracy；C 逐卡片核对 combined/omitted path 的对照，再检查三个概率/实验设计恒等式。
>
> **图没有证明什么**：图不证明 ReLU kink 的唯一导数、矩阵深网的 dynamical isometry、这些正则在真实数据上的 benchmark 排名，也不把 deterministic script assertions 升级为 learner mastery 或部署安全。

## 六、必须完成的手工复核

### B 轨

1. 手算前三层 plain/residual products；
2. 证明 $\epsilon=0,a>0$ 时 $\operatorname{LN}(ax+b\mathbf1)=\operatorname{LN}(x)$；
3. 把 depth 改为 128 或 scale 改为 $1/L$，先预测三条 end gain，再运行到临时文件。

### C 轨

1. 手算 target $(0.29,0.05,0.61,0.05)$ 和 inverted Dropout covariance；
2. 对重复 ID 逐行写出 lookup gradient scatter-add；
3. 暂时只返回 output path，预测 numerical error，再运行验证并恢复代码。
