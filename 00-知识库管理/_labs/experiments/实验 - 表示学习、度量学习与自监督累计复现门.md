# 实验 - 表示学习、度量学习与自监督累计复现门

> [!abstract] 实验目的
> 本实验不比较哪种 SSL 方法“最好”。它用三个完全可枚举的小系统检查：表示风险是否绑定 task/head、InfoNCE 是否绑定 candidate/batch law、non-collapse 与 self-generated target 是否被错误升级为语义或迁移证书。

先看图回答：

1. 为什么同一个 $h_{\rm id}$ 对 $S,N$ 两项任务零风险，却对 XOR 的 affine risk 为 $1/4$？
2. 为什么增加 $K$ 同时改变 InfoNCE estimand 与 false-negative collision，而不只是 gradient variance？
3. 为什么 covariance rank、VICReg variance floor 与 EMA teacher 都不能证明 downstream sufficiency？

## 一、七层共同合同

下面的 **seven-layer representation audit** 是三条轨共享的最小对象账本。

| 层 | A：representation/retrieval | B：contrastive batch | C：collapse/target |
|---|---|---|---|
| source unit | $(S,N)$ object / query-gallery / source cluster | anchor source 与 candidate sources | clean object 与 teacher history |
| view/target law | task label、augmentation、relevance | positive channel、marginal negatives、$K$ | paired views、mask、teacher target |
| model | representation + affine/metric head | critic + softmax | embedding/projector/predictor |
| objective | task risk、triplet、retrieval | candidate-index cross-entropy | agreement、variance、target loss |
| selection | task weights/head/metric | $K,\tau$, sampler, checkpoint | layer, penalty weights, teacher decay |
| evaluation | oracle/finite probe、AP/Recall | population bound 与 finite batch分开 | spectrum 与 downstream risk 并列 |
| deployment | task family、gallery、shift | real negative law 与 utility | transfer task、label/compute budget |

任何轨都必须按“source → target/view → model → objective → selection → evaluation → deployment”解释。

## 二、A 轨：任务索引表示风险与 dependent views

### 2.1 population fixture

$$
S,N\overset{\rm iid}{\sim}\operatorname{Unif}\{-1,+1\},
\qquad
(Y_S,Y_N,Y_\oplus)=(S,N,SN).
$$

五个表示为 identity、invariant-$S$、nuisance-$N$、product 与 enriched。对 affine threshold，风险表是：

| representation | $Y_S$ | $Y_N$ | $Y_\oplus$ |
|---|---:|---:|---:|
| identity $(S,N)$ | 0 | 0 | 0.25 |
| invariant-$S$ | 0 | 0.5 | 0.5 |
| nuisance-$N$ | 0.5 | 0 | 0.5 |
| product $SN$ | 0.5 | 0.5 | 0 |
| enriched $(S,N,SN)$ | 0 | 0 | 0 |

canonical task weights $(0.5,0.3,0.2)$ 给 weighted risks：

$$
(0.05,0.25,0.35,0.40,0).
$$

这不是说 enriched 在所有成本下绝对优越；脚本没有计维度、样本、compute、privacy 或 shift cost。

### 2.2 metric/retrieval fixture

triplet hinge：

$$
[0.8-1.3+0.7]_+=0.2.
$$

ranking relevance $(1,0,1,0)$：

$$
\operatorname{AP}=\frac56,\qquad
\operatorname{Recall@2}=\frac12.
$$

两者也不是同一个指标：AP 使用 relevant ranks 的全部 precision，fraction Recall@2 只看 top-2 覆盖。

### 2.3 augmentation cluster dependence

对 $n$ 个 source、每个 $m$ 个 views：

$$
\operatorname{Var}(\bar Z)
=\frac{\sigma^2}{nm}[1+(m-1)\rho],
\qquad
n_{\rm eff}=\frac{nm}{1+(m-1)\rho}.
$$

canonical $(n,m,\rho)=(12,4,0.6)$ 给 nominal 48、effective $17.142857$。这解释了为什么 split/bootstrap 必须按 source unit，而不是按 crop 或 token。

## 三、B 轨：InfoNCE candidate law、gradient 与 collision

### 3.1 exact binary channel

$$
X\sim\operatorname{Bernoulli}(1/2),
\qquad P(Y=X\mid X)=q.
$$

positive candidate 来自 channel，其他 $K-1$ candidates 来自 uniform marginal。density ratio 是：

$$
r(x,y)=
\begin{cases}
2q,&y=x,\\
2(1-q),&y\ne x.
\end{cases}
$$

Bayes posterior：

$$
P(I=i\mid x,y_{1:K})
=\frac{r(x,y_i)}{\sum_jr(x,y_j)}.
$$

脚本遍历 $K\cdot2\cdot2^K$ 个 index/anchor/candidate states，而非抽样。canonical $q=0.8,K=4$：

$$
I=0.192745,\quad
L^\star=1.240493,\quad
\log4-L^\star=0.145801,\quad
\text{gap}=0.046943.
$$

### 3.2 finite batch gradient

raw similarities $(1,0.5,-0.25)$、$\tau=0.5$ 给 logits $(2,1,-0.5)$：

$$
p=(0.689672,0.253716,0.056612),
\qquad
L=0.371539.
$$

对 raw similarities：

$$
\nabla_sL
=\frac{p-e_1}{\tau}
=(-0.620656,0.507432,0.113223).
$$

gradient 总和为零；更相似的 negative 得到更大的 push，但这只是当前 declared candidate set 下的局部梯度。

### 3.3 latent-class collision

class prior $\pi$、$M$ 个 marginal negatives 下：

$$
P(\text{至少一个 same-class})
=\sum_c\pi_c[1-(1-\pi_c)^M].
$$

canonical $\pi=(0.5,0.3,0.2),M=7$ 得 $0.929444$。same class 是否真的 relevant 仍由 downstream task 决定；latent class 只是 collision audit model。

## 四、C 轨：non-collapse、VICReg 与 self-generated targets

### 4.1 covariance fixture

四个 centered vectors：

$$
(3,1,0),(-3,-1,0),(3,-1,0),(-3,1,0)
$$

产生

$$
C=\operatorname{diag}(9,1,0).
$$

三种数字分别为：

$$
r_{\rm stable}=10/9=1.111111,
$$

$$
r_{\rm PR}=100/82=1.219512,
$$

$$
r_{\rm eff}=\exp[-0.9\log0.9-0.1\log0.1]=1.384145.
$$

algebraic rank 是 2，但谱集中说明有效几何远未达到二维均匀。

### 4.2 VICReg fixture

两 views 相同，故 spectral 与 constant representations 的 agreement 都为 0。取 $\gamma=1,\varepsilon=0$，variance penalty 对维平均并把两 views 相加：

$$
v_{\rm spectral}=2/3,\qquad v_{\rm constant}=2.
$$

variance floor 能惩罚 constant，却不能排除“高维 nuisance”。

### 4.3 EMA 与 masked Bayes target

$$
\xi_{t+1}=\tau\xi_t+(1-\tau)\theta_{t+1}.
$$

canonical $\tau=0.75,\xi_0=0,\theta=(1,3,-1,2)$ 给最终

$$
\xi_4=0.83984375.
$$

若 conditional correct-class probability 是 0.8：

$$
R_{\log}^\star=h(0.8)=0.500402,
\qquad
R_{\rm square}^\star=0.8(0.2)=0.16.
$$

两个风险来自不同 action/loss；teacher target 仍是 student history 的函数，不是独立 ground truth。

## 七、非法合同与覆盖保护

下列输入必须失败且不得改写 canonical SVG：

1. task weights 长度不是 3；
2. task weights 或 class prior 不归一；
3. view correlation 超出 $[0,1]$；
4. match probability 不在 $(0.5,1)$；
5. candidates 小于 2；
6. temperature 非正；
7. negatives 非正；
8. EMA decay 不在 $(0,1)$；
9. similarities 少于 positive + one negative；
10. 非 canonical 参数不给 `--output`；
11. 非 canonical 参数把 output 指向 canonical path。

保护的不是用户界面，而是“哪个 artifact 能作为 canonical evidence”的语义。

## 八、三类陈述必须分开

| 陈述 | 本实验能否支持 | 还缺什么 |
|---|---|---|
| 固定 finite fixture 的数值正确 | 能，exact enumeration | 独立审计仍需不导入生成函数复算 |
| InfoNCE lower bound theorem | 脚本只校验实例 | 正式证明、support 与 candidate assumptions |
| 某真实 encoder 对部署任务更好 | 不能 | registered task/protocol、locked test、uncertainty、shift |
| 非坍缩机制在训练中稳定 | 不能 | dynamics analysis 与多 seed intervention |
| 表示恢复真实语义因素 | 不能 | identifiability assumptions 与 semantic interventions |

## 十、48 小时与 14 天迁移

### 10.1 48 小时

至少同时改变一项 source/view dependence 与一项 contrastive/target mechanism，例如：

- 将 iid negatives 改为 class-conditional hard negatives；
- 将 flip-invariance 改为 equivariant readout；
- 将 EMA target 改为 fixed latent tokenizer；
- 将 view correlation 或 source cluster size 改变。

先预测 MI/bound、collision、effective sample size、collapse penalty或 downstream risk 的方向，再运行新 output。

### 10.2 14 天

迁移到陌生 RAG、speech、multimodal、time-series 或 masked-prediction pipeline，重新声明七层合同。若只更换参数但仍复述本页 binary channel 与 covariance fixture，不算迁移。

## 十一、最小结论

> [!summary]
> 表示学习的证据链不是“pretext loss 下降 → embedding 不坍缩 → probe 上升 → 普遍迁移”。正确链条是：声明 source/view/target law，区分表示与 head，明确 batch/objective，分别测 non-collapse 与 task sufficiency，在 nested protocol 中评估有限标签/compute 的 selected procedure，最后只对注册的 deployment task 与 shift 作结论。
