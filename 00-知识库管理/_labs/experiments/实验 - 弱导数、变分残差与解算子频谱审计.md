# 实验 - 弱导数、变分残差与解算子频谱审计

> [!abstract] 研究问题
> 怎样让 GEO-08 的四个关键机制可计算、可失败：$|x|$ 的二阶导数不是普通函数，而是质量为 $2$ 的 delta；conforming 线性有限元在 $H^1/L^2$ norms 中分别按一阶/二阶收敛；逐单元 strong residual 与 Galerkin weak residual 可以得出完全不同的数值；只学会低 Fourier modes 的 Poisson 解算子在训练子空间误差为零，却对首个未见模态产生 100% relative error。本实验严格区分 distribution limit、discretization convergence、residual topology 和 operator OOD。

先看图回答：distributional derivative、匹配 norm 的 FEM 收敛、strong/weak residual 与解算子的未见模态误差，为什么是四种不能互相替代的验收？

**怎样读图。** A 峰值发散与总质量趋于 2 必须一起读；B 的二阶/一阶分别绑定 $L^2/H^1$；C 中 strong residual 不降与 Galerkin residual 近零并不矛盾，因为它们作用于不同 test spaces；D 的训练模态零误差不控制首个未见模态。

**适用边界（图没有证明什么）。** 一维解析 Poisson、conforming P1 FEM 和硬谱截断是机制校准；图不证明一般 Sobolev embedding、非线性 PDE 的适定性、neural operator 泛化或 mesh-independent 误差界。

> [!question] 本实验的判别问题
> 怎样选择与对象匹配的 topology、norm 和 test space，避免把点态尖峰、离散代数残差或训练子空间拟合误报成连续算子正确？

## 1. 预注册假设与判断门

### H1：奇性在分布极限中保存质量

对

$$
u_\varepsilon(x)=\sqrt{x^2+\varepsilon^2},
\qquad
u_\varepsilon''(x)=\frac{\varepsilon^2}{(x^2+\varepsilon^2)^{3/2}},
$$

取 $\varepsilon\in\{0.4,0.2,0.1,0.05,0.025,0.0125\}$。理论上 peak $u_\varepsilon''(0)=1/\varepsilon$，而

$$
\int_{-1}^1u_\varepsilon''(x)dx
=\frac{2}{\sqrt{1+\varepsilon^2}}\to2.
$$

判断门：最小 $\varepsilon$ 的 mass 与 2 相差低于 $2\times10^{-4}$；$\max|\varepsilon\,u_\varepsilon''(0)-1|<10^{-12}$。另以 $\varphi=(1-x^2)^4$ 数值核对

$$
\int|x|\varphi'+\int\operatorname{sign}(x)\varphi=0
$$

到 $10^{-12}$。

### H2：P1 FEM 在匹配 norms 中给预期阶数

求解

$$
-u''=\pi^2\sin(\pi x),\quad u(0)=u(1)=0,
$$

精确解为 $u=\sin(\pi x)$。Uniform mesh elements

$$
N\in\{8,16,32,64,128\}.
$$

用 8-point Gauss quadrature assembly/load/error integration。判断门：log–log fitted $L^2$ slope在 $[1.95,2.05]$；$H^1$ seminorm slope在 $[0.95,1.05]$。

### H3：Strong residual 与 weak balance 不能混成一个 metric

P1 solution $u_h$ 在每个 open element 内 $u_h''=0$，所以 interior strong residual $-u_h''-f=-f$，其 $L^2$ norm固定为 $\pi^2/\sqrt2$。另一方面，assembled Galerkin system满足

$$
KU=F,
$$

故 coefficient-space relative residual应接近 machine precision。判断门：normalized interior strong residual恒为 1；$\|KU-F\|_2/\|F\|_2<10^{-11}$。这不是说 weak continuum residual为零，只是说 residual annihilates $V_h$。

### H4：低模态 operator fit 对首个 OOD 模态可完全失败

Dirichlet Poisson solution operator 对 sine mode $e_k$ 的 gain 为

$$
\sigma_k=\frac1{(\pi k)^2}.
$$

定义 $G_8e_k=Ge_k$ for $k\le8$，$G_8e_k=0$ for $k>8$。判断门：训练模态 relative error为 0；每个未保留单模态 relative error为 1；operator norm tail为

$$
\|G-G_8\|_{L^2\to L^2}=\frac1{(9\pi)^2}.
$$

这条轨道是 neural-operator spectral bias/OOD 的可控替身，不声称等价于训练一个 FNO。

## 4. 逐轨解释

### 4.1 轨道 A：峰值发散不等于质量发散

$u_\varepsilon''(0)=1/\varepsilon$ 越来越高，support尺度却按 $\varepsilon$ 收缩，总质量趋近 2。若只看 pointwise limit，除 $0$ 外它趋于 0，容易错误地得到“极限导数为零”；distribution limit通过与 tests 积分保存了 $2\delta_0$。这正是弱导数语言比逐点语言更稳健的例子。

### 4.2 轨道 B：误差阶来自空间、插值与正则性共同作用

拟合斜率 $1.999$ 与 $0.999$ 对应 P1 FEM 在 smooth exact solution 上的 $L^2$ 二阶、energy 一阶 convergence。它不是“任何区域、任何解都自动有这个阶”：角点奇性、非 uniform mesh、低阶 quadrature 或非 conforming discretization 都可能改变结果。

### 4.3 轨道 C：选择 residual topology 就是在选择问题

Interior strong residual始终等于 $-f$，因为 P1 basis的 elementwise二阶导数为零；discrete weak residual却由线性系统精确消失。这不是矛盾：前者忽略 node slope jumps的 distribution contribution，后者检查 $H_0^1$ test space中的 integration-by-parts balance。标准 FEM a posteriori estimator会同时用 element residual 和 interface flux jumps，而不是只报告其中一个。

### 4.4 轨道 D：绝对平滑会掩盖相对 OOD 失败

Poisson inverse强烈衰减 high modes。Mode 64 的真实 output norm只有 $2.47\times10^{-5}$，输出零看起来 absolute error很小；但它遗漏了全部真实 signal，relative error仍是 100%。因此 operator benchmark必须同时报告 absolute/relative norms，并按 input spectrum分层。

## 5. 对神经 PDE 方法的直接含义

1. ReLU trial function可有合法 $H^1$ energy，却不适合无审计地计算 classical second-order strong residual；
2. Weak/variational losses通过 integration by parts降低 derivative order，但 finite test space仍有盲区；
3. PINN point residual、FEM Galerkin residual和 $H^{-1}$ residual norm不是可互换的数字；
4. FNO/DeepONet在训练频谱或 sensors覆盖的子空间表现好，不证明它们恢复了 continuum solution operator；
5. Elliptic smoothing使 high-frequency absolute errors变小，可能让 aggregate $L^2$ metric掩盖 structured relative failure。

## 6. 失败注入与预期

| 改动 | 预期现象 | 暴露的合同 |
|---|---|---|
| 只在 $x\ne0$ 看 $u_\varepsilon''$ pointwise limit | 错判为 0 | distribution testing不可删 |
| FEM error只算 nodal values | P1 与 exact nodal interpolation可能显得异常好 | 必须用 continuum norm/quadrature |
| Strong residual只取 element interiors | 永远得到 $-f$ | 漏掉 slope-jump distributions |
| Weak tests只用极少全局 modes | 可漏局部误差 | test-space coverage |
| Operator metric只报 absolute $L^2$ | 高频失败看似很小 | relative/spectral stratification |
| 用训练模态测试 truncation | 得出零 error | OOD support audit缺失 |

## 7. 结论边界

本实验支持：

- 指定 smooth approximation 的 delta concentration；
- 指定一维 smooth Poisson problem上的 P1 FEM convergence；
- algebraic Galerkin residual与 element-interior strong residual的分离；
- 精确定义的 spectral truncation operator的 train/OOD差异。

本实验不支持：

- 用 finite grid证明 distribution theorem；
- 把一维 smooth rate推广到任意 domain/coefficient；
- 声称 weak residual总优于 strong residual；
- 声称所有 FNO/DeepONet都等价于 spectral truncation；
- 从本实验推断任何 neural training algorithm的优化或统计泛化。
