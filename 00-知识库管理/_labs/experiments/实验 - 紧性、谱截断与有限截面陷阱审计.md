# 实验 - 紧性、谱截断与有限截面陷阱审计

> [!abstract] 研究问题
> 怎样用同一组可复现实验区分“compact 因而可被低秩逼近”“nonnormal operator 的 eigenvalues 不控制 amplification”以及“finite-section matrix 的 spectrum 不自动逼近 continuum spectrum”？本实验不训练模型，而是先建立进入 Kernel PCA、spectral normalization 与 neural operator 前必须通过的 operator-level sanity checks。

先看图判断：compact low-rank tail、nonnormal amplification 与 finite-section spectral pollution，怎样分别留下 operator-norm、singular-value 和 eigenvalue 证据？

![[00-知识库管理/_assets/plots/functional-analysis/plot-compact-operator-spectrum-v2.svg|880]]

> [!figure] 实验图｜紧性尾界、奇异系统与有限截面陷阱

**怎样读图。** A 用 operator-norm tail 判断 compact approximation；B/C 强调 eigenvalues 不控制 nonnormal norm，有限截面的零谱也不等于 continuum spectrum；D 只把核离散作为 positive compact prototype，rank-99% 是设置相关诊断。

**适用边界（图没有证明什么）。** 对角、Volterra、shift 与单个 Gaussian kernel discretization 不证明任意 neural operator 紧、任意有限截面谱收敛，或观测到快速 eigenvalue decay 就有分布外泛化。

> [!question] 本实验的判别问题
> 面对一个有限矩阵的漂亮谱图，怎样判定它反映的是 continuum operator 的紧性与奇异系统，还是离散化、非正规性或截面选择制造的假象？

## 1. 预注册假设与判断标准

### H1：Compact diagonal 与 identity 有不同 rank–error 极限

对 $De_n=e_n/n$，coordinate rank-$N$ truncation满足 exact

$$
\|D-D_N\|=\frac1{N+1}.
$$

在 $N=4,\ldots,256$ 上，log–log fitted order应在 $[0.95,1.05]$。Infinite-dimensional identity 的同类 truncation error恒为 $1$。

### H2：Volterra 的 eigenvalues 与 singular values分裂

用 strictly lower triangular rectangle-rule matrix

$$
(V_N)_{ij}=\frac1N\mathbf1_{j<i}
$$

近似 $(Vf)(x)=\int_0^xf(t)dt$。因为 $V_N$ nilpotent，全部 eigenvalues应 exact为 $0$；top singular value应逼近

$$
s_1(V)=\frac2\pi,
$$

相对误差阈值设为 $0.5\%$。

### H3：Shift finite-section spectrum丢失

$N\times N$ right-shift matrix满足 $S_N^N=0$，故 eigenvalue radius为 $0$；但 $\|S_N\|_2=1$。本实验将这两条曲线并列，不把 finite eigenvalues解释成 infinite shift spectrum。

### H4：Weighted Gaussian kernel给 positive compact prototype

在 $[0,1]$ midpoint grid上，用

$$
k(x,y)=\exp\left(-\frac{(x-y)^2}{2\ell^2}\right),
\qquad \ell=0.12,
$$

构造 $A_{ij}=k(x_i,x_j)/N$。检查：

- Eigenvalues除 $10^{-12}$ 级 roundoff外 nonnegative；
- 报告 top eigenvalue、Hilbert–Schmidt energy 99% rank和 rank-10 operator tail；
- 不预注册“所有 Gaussian discretizations都有 rank 6”这一错误外推。

## 5. 逐轨解释

### 5.1 轨道 A：tail趋零才是 compactness 的计算影子

$D_N$ 的 error是 exact operator-norm tail，而不是对少量 vectors抽样得到的 empirical error。Identity即使乘上极小 scalar $\varepsilon$，tail仍恒为 $\varepsilon$，不会随 rank趋零；这进一步说明 small norm与 compactness不同。

Observed order略低于 $1$ 是因为拟合横轴用 $N$、exact law用 $N+1$；这不是数值不稳定。若改拟合 $N+1$，斜率 exact为 $-1$。

### 5.2 轨道 B：zero eigen spectrum不等于 zero operator

$V_N$ strictly triangular使 eigenvalues全零，但 SVD检测到 $O(1)$ amplification。它复现 Volterra operator“$\sigma(V)=\{0\}$ 但 $\|V\|=2/\pi$”的结构影子。这里不能用 eigenvalue magnitude决定 Lipschitz constant或 low-rank quality。

### 5.3 轨道 C：finite-section eigenvalues没有 set convergence保证

每个 $S_N$ 的 spectrum都只有 $0$，而 infinite right shift的 spectrum是 closed unit disk。即使 $S_N$ 对每个 finite-support vector最终与 $S$ 一致，也没有 operator-norm convergence，更没有由此自动得到 spectral set convergence。

### 5.4 轨道 D：核谱衰减依赖 kernel、measure与 metric

Weighted symmetric matrix对应 midpoint quadrature下的 $L^2$ geometry。99% rank使用 $\sum_j\lambda_j^2$，不是 $\sum_j\lambda_j$；若改 lengthscale、domain、measure、energy definition或 finite sample，rank都会变化。最小负值约 $7.4\times10^{-17}$，与 double precision roundoff一致，不应写成 kernel不正定。

## 6. 结论边界

本实验支持：

1. Compact diagonal prototype 的 finite-rank norm error趋零；
2. Eigenvalues不足以描述 nonnormal Volterra amplification；
3. Strong/pointwise-looking finite sections不足以保证 spectrum convergence；
4. 带权 kernel matrix可审计 continuum integral operator 的某个 discretization。

本实验不支持：

- 任意 compact operator都有 $1/N$ singular decay；
- 任意 integral/neural operator都 compact或 self-adjoint；
- Gaussian kernel的有效 rank普遍等于 $6$；
- Matrix eigensolver residual控制 continuum error；
- Low-rank spectral approximation自动保留下游 AI task performance。
