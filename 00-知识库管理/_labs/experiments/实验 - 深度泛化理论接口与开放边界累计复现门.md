# 实验 - 深度泛化理论接口与开放边界累计复现门

> [!abstract] 实验目的
> 用三个小到可以独立复算的 fixture，把“现象—算法选解—不变容量—训练 regime—population 边界”拆开。实验不模拟真实大模型，也不声称三条轨道共同组成统一泛化定律；它检验的是你能否阻止证据越级。

## 一、九层可靠复现账本

每次运行必须保存：

1. **object**：predictor、loss、train/test target；
2. **data law**：Gaussian calibration、固定训练矩阵或单点粒子 fixture；
3. **algorithm**：min-norm/GD selection、rescaling、kernel flow 或 particle Euler；
4. **parameterization**：哪些变换保持 function；
5. **certificate/proxy**：risk、sharpness、path quantity、norm complexity、kernel/feature drift；
6. **regime**：finite fixture、fixed-kernel limit 或 moving-feature diagnostic；
7. **quantifier**：解析期望、确定性有限计算或只是一阶数值诊断；
8. **intervention**：canonical 与 scorer nonce blind 参数；
9. **boundary**：每个输出明确列出不能推出的 population/deployment 命题。

## 二、A 轨：Interpolation、Risk 与 Algorithm Selection

### 2.1 Double-Descent Calibration

程序在 $p<n-1$ 使用

$$
R_<(p)=\sigma^2\frac p{n-p-1},
$$

在 $p>n+1$ 使用

$$
R_>(p)=\|\beta^*\|^2\left(1-\frac np\right)
+\sigma^2\frac n{p-n-1}.
$$

这是 isotropic Gaussian min-norm 线性模型的期望风险校准，不是任意 architecture 的经验拟合器。脚本主动拒绝 $p\in\{n-1,n,n+1\}$，因为这些点的有限期望公式不可用。

### 2.2 同一训练 Fit 的多个解

对 canonical $2\times3$ 矩阵，程序从 $X^\top(XX^\top)^{-1}y$ 重算 min-norm 解，再由两行 cross product 得单位 null vector。它同时输出：

- min-norm 参数；
- 沿 null direction 平移后的范数；
- 两者共同的训练残差；
- 在该 null test direction 上的预测 gap。

这把“插值”“算法选解”和“样本外行为”变成三个不同数字。

## 三、B 轨：Parameterization 与 Capacity

### 3.1 Sharpness 反例

在 $L(a,b)=\frac12(ab-1)^2$ 的 global minima 上，$ab=1$ 而 Hessian 非零 eigenvalue 为 $a^2+b^2$。程序比较 $(1,1)$ 与 $(c,c^{-1})$：function product/path quantity 恒为 1，raw sharpness 却变成 $c^2+c^{-2}$。

### 3.2 Norm-Based Skeleton

程序计算

$$
\mathcal C=\prod_\ell s_\ell
\sqrt{\sum_\ell(f_\ell/s_\ell)^2},
$$

其中 $s_\ell=\|W_\ell\|_2$、$f_\ell=\|W_\ell\|_F$，并显示 $\mathcal C/(\gamma\sqrt n)$。然后对前两层做 reciprocal rescaling，独立重算 spectral product 与 ratios。该值只是 norm-bound skeleton 的主尺度；缺少输入半径、置信项和具体定理常数时，不得当作风险上界。

## 四、C 轨：Kernel Modes 与 Moving Features

### 4.1 固定核的可解动力学

对

$$
K=\begin{pmatrix}1&\rho\\\rho&1\end{pmatrix},
$$

程序用 eigenvalues $1+\rho$、$1-\rho$ 分解 $r_t=e^{-Kt}r_0$，输出 final residual 与 slow-mode energy fraction。这里 $K$ 被合同固定，因而是明确的 lazy/kernel fixture。

### 4.2 有限粒子的一步表示漂移

另一个 fixture 使用 $f=\frac1m\sum_ja_jw_j$，对单点平方损失做一步 Euler gradient flow，输出 prediction、feature second moment 与 empirical tangent scalar 的前后值。`feature-moving` 只表示相对漂移超过预设的 0.1 诊断阈值；它不是 mean-field convergence theorem，更不是 population-generalization guarantee。

- 新 interpolation window 两侧哪个离散点达到峰，tail 是否继续下降；
- null shift 从 2 降至 1.5 后，training residual 与 test gap 各怎样变；
- $c$ 从 4 增至 8 后 sharpness 与 invariant complexity 各怎样变；

- 更小 particle step 是否仍足以触发 `feature-moving`。

## 七、输入与覆盖保护

以下情况必须非零退出：

1. sample size 小于 4，dimensions 非严格递增、重复、非正或少于五点；
2. dimensions 触及 $n-1,n,n+1$ 的有限期望奇异窗；
3. noise variance 或 signal norm squared 为负；
4. design 不是 $2\times3$、responses 长度不为 2 或 design 不满行秩；
5. rescale、margin、certificate sample size 非正；
6. layer norm 列表长度不等、少于两层、spectral 非正或 Frobenius 小于 spectral；
7. $\rho\notin(-1,1)$、kernel time 为负或 residual 不是非零二向量；
8. 粒子列表长度不等/少于两个或 step 非正；
9. 任一非 canonical 参数未指定 `--output`；
10. 非 canonical 运行试图覆盖 canonical SVG。

这些 guard 保护理论对象本身，不只是避免程序崩溃。

## 九、48 小时与 14 天迁移

48 小时后从不同机制中选一项：

- 把 isotropic curve 换成显式 covariance spectrum，重新分解 bias/variance；
- 把 Euclidean GD 换成 preconditioned flow，推导所选 geometry；
- 构造另一个保持 function 的 network rescaling，审计 proxy；
- 把固定 $2\times2$ kernel 换成三个 eigenmodes，预言 early stopping；
- 用多个 particle steps 比较 feature drift 与 loss，不把相关性当因果。

14 天后选一篇新论文或陌生博客声明，提交完整 claim card：原始命题、对象合同、证明/实验支持、invariance test、regime、竞争解释、最小反例、可复现干预和开放 bridge。
