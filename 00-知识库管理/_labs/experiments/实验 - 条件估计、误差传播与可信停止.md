# 实验 - 条件估计、误差传播与可信停止

> [!question] 本实验的判别问题
> 局部增益的微小偏离、条件数的黑箱估计和 residual-only 早停，怎样在同一实验中分别被校准而不互相替代？

## 设计

| 面板 | 自变量 | 因变量 | 不变量 |
|---|---|---|---|
| A | 深度 $L$、局部增益 $g$ | $|\partial y_L/\partial y_0|=g^L$ | 标量线性链 |
| B | Hilbert 阶数 $n$ | 显式 $\kappa_1$ 与 Hager–Higham 估计 | 同一精度/求解器 |
| C | 迭代步 $k$ | 残差、前向误差、$\kappa r$ | $A=\operatorname{diag}(1,10^{-6})$ |

## 结果

先用图回答：**深度连乘、条件估计和停止准则分别需要读取哪一个量，为什么单看局部增益或残差都不足以判定可靠性？**

![[00-知识库管理/_assets/plots/error-propagation/plot-condition-estimation-stopping-v2.svg|880]]

> [!figure] 实验图｜敏感度必须进入传播、估计与停止合同
> A 显示常增益链的指数累积；B 对 Hilbert $n=2,\ldots,9$ 比较显式 $\kappa_1$ 与 Hager–Higham 风格估计；C 把误差完全放入 $A=\operatorname{diag}(1,10^{-6})$ 的弱方向，展示残差先过阈值而前向误差仍不可忽略。生成脚本：[[plot_condition_estimation_stopping.py]]；仅标准库、无随机数，并对三条机制分别设断言。

**怎样读图。** A 比较 $g=0.85,1,1.15$ 在 30 层后的纵向分离；B 不把曲线重合作为普遍精确性，而只读作该小样本的校准；C 在绿色阈值线处读取蓝色 residual 与红色 forward error 的数量级差，再用 $\kappa r$ 解释弱方向放大。

**适用边界（图没有证明什么）。** 标量常增益链忽略 Jacobian 方向旋转，Hilbert 矩阵是结构化压力测试，对角系统则是教学反例；图不证明估计器总是精确，也不规定生产系统唯一正确的停止阈值。

| 观测 | 结果 |
|---|---:|
| $g=0.85,L=30$ | $7.631\times10^{-3}$ |
| $g=1.15,L=30$ | $6.621\times10^1$ |
| 两者比 | $8.677\times10^3$ |
| Hilbert $n=9$ 的 $\kappa_1$ | $1.100\times10^{12}$ |
| 本例中估计/显式比 | $1.000$ |
| 残差首次达 $10^{-8}$ | $k=44$ |
| 当时前向误差 | $6.857\times10^{-3}$ |

本次 Hilbert 小样本中估计与显式参考重合；这是样本结果，不应外推为估计器总是精确。面板 C 直接显示 residual-only 阈值在弱方向上早停。

## 结论边界

- Hilbert 矩阵同时有特殊结构与极端条件数，不代表所有实际矩阵；
- 面板 A 是常增益标量模型，深网络 Jacobian 方向会旋转；
- 面板 C 的阈值是教学反例，生产停止需后向误差、条件估计和任务容差。
