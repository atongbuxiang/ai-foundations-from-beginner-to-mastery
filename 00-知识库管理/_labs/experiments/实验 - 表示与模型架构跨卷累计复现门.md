# 实验 - 表示与模型架构跨卷累计复现门

> [!abstract] 目的
> A 轨用图重标号检查结构等变与读出不变；B 轨把 causal full forward、增量 KV cache 与 RoPE 相对位移放进同一精确对象；C 轨把局部 Attention、GQA cache 与 MoE All-to-All/尾负载分账。三轨只验收低维确定性恒等式，不替代训练、质量或真实集群 benchmark。

## 评分者随机干预

在看代码前随机指定一项：

1. A：把 sum readout 改为“取第一个节点”，预测不变性为何失败；
2. B：让 cache position offset 错一位，预测 full/cache 首个分歧 token；
3. C：把 load 从 $[10,2,2,2]$ 改为 $[4,4,4,4]$，保持总 assignment，预测平均与尾部怎样变；
4. C：把 $k=2$ 改为 4，预测 MoE payload，说明为何不能据此预测 quality。

学习者必须先冻结方向预测，再改副本运行，不覆盖基准 artifact。
