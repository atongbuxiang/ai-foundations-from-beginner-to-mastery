## 二、25 分钟卷级口试

每题 5 分钟，不看笔记：

1. 给出一个完整 representation contract，并解释为什么 encoder 不是 predictor、embedding 没有脱离 task 的绝对质量；
2. 从 candidate-index experiment 推出 InfoNCE 的 Bayes score 是 density ratio，并说明 $\log K-L_{\rm NCE}$ 为什么只是下界；
3. 解释 batch size 为什么可能改变 contrastive population objective，而不只是 gradient variance；
4. 区分 complete、dimensional、spectral、semantic collapse 与 coordinate non-identifiability；
5. 比较 linear probe、kNN、partial/full fine-tuning 的 estimand，并给出避免 layer/checkpoint/test reuse 的 nested protocol。

口试通过要求：至少 4/5 能同时说明对象、随机性、优化量、输出身份和不能推出；只会罗列 SSL 方法名最高记 attempted。

## 三、240 分钟闭卷（100 分）

### A 部分：对象与协议（20 分）

### 第 1 题：七层表示学习账本（5 分）

为一个图文或多模态预训练系统逐层填写：

1. source unit 与依赖/去重单位；
2. clean object、view/corruption/pairing law 与 target generator；
3. encoder、projection/prediction head 与 normalization；
4. loss、negative set、stop-gradient、teacher update 与 optimizer；
5. checkpoint/layer/head/hyperparameter selection 时间线；
6. zero-shot、retrieval、probe、fine-tune 的 downstream protocol；
7. deployment task、shift、utility 与 uncertainty。

每层给出一个若省略便会改变 estimand 或证书的具体例子。

### 第 2 题：五种“表示相同”（5 分）

分别定义并比较：信息等价、oracle-head 风险等价、linear-probe 等价、pairwise-geometry 等价、坐标相同。讨论 invertible nonlinear map、invertible linear map、orthogonal map 与 coordinate permutation 分别保留哪些层。为什么 neuron-to-neuron 对齐不是默认可辨识结论？

### 第 3 题：自监督 target-generation contract（5 分）

对 masked token、masked pixel、latent target、EMA teacher distribution 与 cross-modal pair，逐项写出谁看见什么、target 空间、损失、target 是否更新、主要泄漏/坍缩模式。证明 log loss 的 population optimum 是 conditional distribution，square loss 的 optimum 是 conditional mean。

### 第 4 题：迁移评价时间线（5 分）

团队在十个下游测试集上反复挑 checkpoint、layer、pooling、normalization、probe regularization、fine-tuning schedule 与最好 seed，然后报告每个测试集最高分：

1. 画真实信息流并指出自适应复用；
2. 给出 inner selection—locked outer test 的修复；
3. 区分 oracle linear risk、finite-label trained-probe risk 与 fine-tuning algorithm risk；
4. 说明 paired split/seed、label-budget curve 与 task-level aggregation各控制什么。

### B 部分：三轨精确计算（30 分）

### 第 5 题：任务索引的表示风险（8 分）

令 $S,N\in\{-1,+1\}$ 独立均匀，三项任务为

$$Y_S=S,\qquad Y_N=N,\qquad Y_\oplus=SN.$$

表示候选为

$$
h_{\rm id}=(S,N),\quad h_S=S,\quad h_N=N,\quad h_\oplus=SN,
\quad h_+=(S,N,SN).
$$

head class 为带 bias 的 affine threshold，loss 为 0–1。任务权重为 $(0.5,0.3,0.2)$。

1. 求五个表示在三个任务上的 oracle affine risk；
2. 解释为何 $h_{\rm id}$ 完整保留输入但 XOR risk 为 $1/4$；
3. 计算 task-family weighted risk 并按固定顺序打破平局；
4. augmentation $a(S,N)=(S,-N)$ 若被强制 invariant，对哪些任务合法？证明错误 invariance 与 task sufficiency 不相容。

### 第 6 题：度量、检索与增强依赖（7 分）

1. triplet squared distances 为 $d(a,p)^2=0.8,d(a,n)^2=1.3$，margin $m=0.7$，计算 hinge loss；
2. 一个 query 的 ranking relevance 是 $(1,0,1,0)$，计算 AP 与 fraction Recall@2；
3. 有 $n=12$ 个 source units，每个生成 $m=4$ 个 views，同一 source 内统计量方差为 $\sigma^2$、相关系数 $\rho=0.6$。推导 view mean 方差与 effective independent sample size；
4. 说明为何按 48 个 iid views bootstrap 会低估不确定性。

### 第 7 题：精确 InfoNCE candidate experiment（8 分）

令 $X\sim\operatorname{Bernoulli}(1/2)$，positive channel 满足

$$P(Y=X\mid X)=q=0.8,$$

negative 来自 $p_Y=\operatorname{Bernoulli}(1/2)$，candidate 数 $K=4$，positive index 均匀。

1. 推出 match/mismatch density ratio 与 Bayes index posterior；
2. 计算 $I(X;Y)=\log2-h(0.8)$；
3. 按 candidate tuple 的 match 数枚举 $H(I\mid X,Y_{1:K})$，得到 Bayes InfoNCE loss；
4. 计算 $\log K-L^*_{\rm NCE}$ 及未闭合 gap；
5. 说明 critic 不充分、有限 $K$、训练误差、有限估计分别位于哪一层。

### 第 8 题：Batch gradient 与 false negatives（7 分）

一个 anchor 的 raw similarities 为 $(1,0.5,-0.25)$，第一项为 positive，temperature $\tau=0.5$。

1. 计算 logits、softmax probabilities、loss 与对 raw similarities 的梯度；
2. latent-class prior 为 $(0.5,0.3,0.2)$，有 7 个 iid marginal negatives。计算随机 anchor 至少遇到一个 same-class negative 的概率；
3. 解释增加 negatives 为何会同时改变 candidate task、MI ceiling、collision 与梯度，而非仅降低方差。

### C 部分：推导、反例与边界（30 分）

### 第 9 题：不变性、等变性与充分性（8 分）

1. 定义 task-relative sufficiency $Y\perp X\mid h(X)$；
2. 证明若 $h(gx)=h(x)$ 但 $P(Y\mid gx)\ne P(Y\mid x)$，则 $h$ 不充分；
3. 证明有限群平均 predictor invariant；
4. 区分 encoder equivariance 与 invariant readout；
5. 给出“增强保标签但改变 deployment support”的反例或条件。

### 第 10 题：InfoNCE 定理与五层 gap（8 分）

从 candidate-index cross-entropy 与 KL/log-sum 结构证明

$$I(X;Y)\ge \log K-L_{\rm NCE}(s).$$

再写出 true MI、unrestricted-$K$ optimum、critic-class optimum、trained critic 与 finite estimate 五层账本。逐项指出何时不能把 bound 上升解释为“语义更多”。

### 第 11 题：坍缩证书与可辨识边界（7 分）

四个 centered representations 为

$$
(3,1,0),\ (-3,-1,0),\ (3,-1,0),\ (-3,1,0),
$$

covariance 用 $1/B$。

1. 计算 covariance spectrum、stable rank、participation ratio 与 entropy effective rank；
2. 取 VICReg $\gamma=1,\varepsilon=0$，两 views 相同，计算此表示与 constant representation 的 invariance/variance penalty（variance 对维平均、两 views 相加）；
3. 构造高秩但与目标独立的 nuisance representation；
4. 说明 non-collapse、sufficiency、finite-label accessibility 与 shift robustness 之间为何没有自动蕴含。

### 第 12 题：Teacher dynamics 与 probe inference（7 分）

1. 对 $\xi_{t+1}=0.75\xi_t+0.25\theta_{t+1}$，$\xi_0=0$，student sequence $(1,3,-1,2)$，计算最终 teacher；
2. 若 binary masked target 在 visible context 下正确类别概率为 $0.8$，计算最优 conditional log risk 与 square risk；
3. 解释 stop-gradient 保持 forward value 却改变 vector field；
4. 给出 linear probe 高/低与 fine-tuning 高/低四象限的至少一种合法解释，且不得把解释写成必然因果结论。

### D 部分：证据审计与 AI 迁移（20 分）

### 第 13 题：审计一篇自监督论文（10 分）

论文声称：“更大的 batch 带来更低 InfoNCE loss、更高 covariance rank 和更好的 linear probe，因此模型恢复了真实语义且将普遍迁移。”逐句审计：

1. 至少列出八个缺失合同或混杂；
2. 给出每条 claim 的最小合法 estimand；
3. 设计 negative/view/batch、collapse、probe 与 selection 四类消融；
4. 区分 theorem、finite exact computation、simulation、benchmark 与 mechanistic hypothesis；
5. 写出在证据成立后仍不能推出的结论。

### 第 14 题：陌生 AI pipeline 迁移（10 分）

从 RAG embedding、多语种句向量、语音 SSL、视觉 MAE 或多模态对齐中任选一个，设计可注册 pipeline：

1. task family 与 deployment shift；
2. source/pair/view/target law；
3. pretext 与 downstream estimands；
4. negative/collapse/teacher 诊断；
5. head-capacity 与 label-budget ladder；
6. nested selection、locked test 与 paired uncertainty；
7. 一个会推翻“表示更好”结论的 intervention；
8. 48 小时换机制和 14 天陌生任务复测。
