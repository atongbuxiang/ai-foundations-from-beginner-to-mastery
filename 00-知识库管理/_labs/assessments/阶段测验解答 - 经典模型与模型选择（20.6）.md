## 0. 评分总则

经典模型最常见的错误不是少记一个公式，而是把相邻层替换掉：

- 用 optimization convergence 代替 population consistency；
- 用 parameter uniqueness 代替 predictive identifiability；
- 用最小 validation score 代替 selected procedure 的 unbiased risk；
- 用 KRR/GP mean equality 代替 uncertainty equality；
- 用 clustering distortion 代替 latent semantic recovery；
- 用 AIC/BIC arithmetic 代替其 asymptotic theorem hypotheses。

评分先看 estimand、predictor、sample split 和 probability statement，再看计算。公式正确但对象错，不得主要步骤分。

## 1. 口试参考要点

### 口试 1：七类 estimand

- regression function 是 $f^*(x)=\mathbb E[Y\mid X=x]$，平方损失下在所有可测函数中最优；
- best linear predictor 是 $L^2(P_X)$ 中对 linear span 的投影，错设时可不同于 $f^*$；
- logistic 的 population 直接目标是条件概率在 log-loss/KL 意义下的 projection；
- SVM 直接目标是 regularized hinge risk 或 separable class 中的最大几何间隔，不是概率；
- PCA 识别 covariance 的主 invariant subspace；重复谱时 basis 不可辨识；
- K-Means 识别 center set 的 quantization-risk minimizer，只定义到排列；
- mixture MLE 识别的是 observed density parameter 的等价类；latent label 语义不是 likelihood 自动提供的。

### 口试 2：ridge spectral risk

若 $X^TX=V\operatorname{diag}(s_j^2)V^T$，ridge filter 为

$$
g_j(\lambda)=\frac{s_j^2}{s_j^2+\lambda}.
$$

在 test covariance 为 $I$ 的坐标中，

$$
\operatorname{Bias}_j^2=(1-g_j)^2\beta_j^2
=\left(\frac\lambda{s_j^2+\lambda}\right)^2\beta_j^2,
$$

$$
\operatorname{Var}_j
=\frac{\sigma^2s_j^2}{(s_j^2+\lambda)^2},
\qquad
df(\lambda)=\sum_jg_j(\lambda).
$$

小 $s_j$ 方向在 OLS 中贡献 $\sigma^2/s_j^2$，正则化以 bias 换 variance。

### 口试 3：同一标签，不同学习对象

logistic 最小化 log loss，直接给 score-to-probability model；SVM 最小化 norm/hinge 的 margin objective；tree 贪心优化 partition impurity；AdaBoost 做 exponential-loss coordinate descent 并重加权错例。只有 logistic 在模型正确和训练协议合法时直接以概率为目标，仍需 calibration/shift 验收。

### 口试 4：EM 单调性边界

$$
\log p_\theta(x)=\mathcal F(q,\theta)
+\mathrm{KL}(q\|p_\theta(z\mid x)).
$$

E-step 令 $q$ 等于旧参数 posterior，使下界贴住旧 likelihood；M-step 提高同一个 lower bound；新 likelihood 不低于新 lower bound。因此 exact EM observed likelihood 单调不降。它不保证 global optimum、parameter convergence、finite MLE、identifiability 或 latent semantics。

### 口试 5：选择协议

所有从数据学出的 preprocessing、representation、candidate family、metric、seed 与 stopping 都进入 inner selection。outer fold 只评估完整 selected procedure；最终 full-data refit 是另一个 predictor。反复看 outer/test 后改 pipeline 会使其也变成 selection data。可用预注册候选、nested CV、独立 certificate/test、simultaneous correction 和完整 search transcript 修复。

## 2. A 部分：对象、算法与选择合同（20 分）

### 第 1 题解答：十层经典模型账本（5 分）

| 层 | 合格内容 | 一个典型失配 |
|---|---|---|
| sampling unit | i.i.d. row、group、user、time block 或 trajectory | 同一用户的窗口跨 train/test |
| target/deployment | $P_{XY}$、时间窗、cost 与 shift class | 用随机 CV 估计未来时间段 |
| estimand | conditional mean/probability、margin boundary、subspace、center set、density quotient | 把 K-Means center 当真实类别 |
| model/class | linear/RKHS/tree/mixture family 与 approximation error | 把最佳线性投影称为真实机制 |
| objective | loss、penalty、constraint 和 scaling | KRR 的 $\lambda$ 与 GP noise ratio 缩放不一致 |
| algorithm | initialization、tie-break、seed、stopping、precision | 把 Lloyd local fixed point 写成 global K-Means optimum |
| data timeline | preprocessing、train、inner validation、outer evaluation、test | 在全数据上先做 PCA 再 CV |
| output identity | selected procedure、refit model、Gibbs/ensemble/probability | 用 outer score认证另一个手调后的 refit |
| error ledger | approximation、estimation、optimization、numerical、selection、shift | QR 稳定后声称统计错设消失 |
| evidence | theorem、finite identity、simulation、benchmark | 一次 EM 曲线证明所有初始化全局收敛 |

账本的作用是阻止“算法名字”替代数学对象。例如 Random Forest 不是一个唯一 predictor，直到 bootstrap、feature sampling、tree growth、aggregation、seed law 和 deployment probability rule 都固定。

### 第 2 题解答：四种收敛与三种相同（5 分）

1. objective convergence：$L(\theta_t)\to L_\infty$；平坦 valley 中参数可不收敛；
2. parameter convergence：在声明的 metric/quotient 中 $\theta_t\to\theta_\infty$；不自动说明 prediction 好；
3. predictor/distribution convergence：$f_{\theta_t}$ 在点态、$L^2$、uniform 或 distribution metric 中收敛；参数可因 symmetry 不收敛却 predictor 相同；
4. population consistency：随 sample size 增长，所选 predictor 的 population risk/target 收敛到 class 或 Bayes optimum；它还需要 sampling、capacity、optimization 与 identifiability 条件。

KRR 与 GP posterior mean 相同需要同一 kernel、data、mean function，以及 regularization/noise scaling 对齐。它不推出 posterior covariance、credible interval 或 prior sample-path interpretation相同。

mixture 的 permutation-related 参数给相同 observed density，应在 quotient $\Theta/S_K$ 上谈 identifiability。它不说明 component label 有外部语义。

两个不可辨识参数若给相同 deployed predictor，prediction target 可能 identifiable；但 parameter inference、causal interpretation、Fisher inverse 和 intervention response仍可能无定义或不同。

### 第 3 题解答：模型选择时间线（5 分）

题中实际信息流是：

$$
D\to\text{global scaler/PCA/rank}
\to\text{CV searches}
\to\text{human feedback creates candidates}
\to\text{minimum CV}
\to\text{full-data refit}.
$$

global preprocessing 已让 validation fold 影响 representation；rank、metric、loss、depth、kernel、seed 和新增候选形成 adaptive transcript；反复查看同一 CV 后，固定 $M$ 候选的简单 $\log M$ 账本也不再描述真实 search space。

三种修复：

- **fixed-candidate simultaneous control：** 抽样前冻结 $M$ 个完整 pipelines，在共同 event 或 union-corrected holdout 上选择；
- **nested CV：** 每个 outer training 内重新 fit scaler/PCA 并做 inner selection，outer test 只评估一次完整 procedure；
- **independent holdout：** exploration 可自适应，但冻结 pipeline 后只在未接触 certificate/test 上评估；若继续修改，需新数据或支付 reusable/adaptive analysis 成本。

outer CV 估计的是“在约 $n(1-1/K)$ 个样本上执行内层选择与训练”的 procedure。full-data refit 使用更大训练集和可能不同随机路径，是另一个随机 predictor；outer estimate常可作为 procedure-level approximation，但不是其 exact conditional risk identity。

### 第 4 题解答：预测者与损失身份（5 分）

| 模型 | empirical objective | population estimand | 输出/评价 | 非法解释 |
|---|---|---|---|---|
| logistic | negative log likelihood + optional penalty | conditional probability 的 model KL projection | score/probability；log loss、calibration、decision utility | convex ⇒ finite MLE / causal odds |
| SVM | norm + hinge/slack | margin/hinge-risk optimum | signed score/class；hinge、margin、task cost | margin = calibrated probability |
| KRR | squared loss + RKHS norm | regularized regression function | deterministic mean predictor | 与 GP mean 相同 ⇒ credible coverage相同 |
| GP | marginal likelihood/posterior conditioning | declared stochastic-process posterior | posterior predictive distribution | prior便利 ⇒真实函数由该 GP 生成 |
| tree | greedy partition gain + pruning criterion | piecewise action under partition class | leaf mean/class probability | impurity下降 ⇒ population risk下降 |
| PCA | maximize empirical projected variance | population principal subspace | projector/subspace；angle/reconstruction | high variance = task-relevant semantics |
| K-Means | empirical squared quantization loss | center-set minimizer modulo permutation | centers/assignments；distortion/utility | cluster = true class |
| mixture EM | coordinate ascent on observed likelihood lower bound | density/KL projection modulo symmetries | density/posterior responsibilities | likelihood上升 ⇒ causal latent class recovered |

## 3. B 部分：三轨精确计算（28 分）

### 第 5 题解答：谱 ridge（7 分）

对每个坐标，

$$
B_j^2(\lambda)=\left(\frac\lambda{s_j^2+\lambda}\right)^2\beta_j^2,
\qquad
V_j(\lambda)=\frac{\sigma^2s_j^2}{(s_j^2+\lambda)^2}.
$$

汇总如下：

| $\lambda$ | squared bias | variance | expected excess | effective df |
|---:|---:|---:|---:|---:|
| 0 | 0.000000 | 4.265625 | 4.265625 | 3.000000 |
| 0.25 | 0.128237 | 0.335148 | 0.463385 | 1.984615 |
| 1 | 0.305190 | 0.090182 | **0.395372** | 1.500000 |
| 4 | 0.604715 | 0.020947 | 0.625662 | 1.015385 |

$\lambda=1$ 在给定 grid 上 expected excess 最小。OLS 第三方向的 variance 是

$$
\frac{\sigma^2}{s_3^2}=\frac{0.25}{0.0625}=4,
$$

单独就占总 variance 的绝大部分；另两项是 $0.015625$ 与 $0.25$。

QR/SVD 能避免显式 normal equation、暴露小 singular values 并稳定计算选定的 estimator；它不能改变小 singular direction 的 sampling information，也不能修复 heteroskedasticity、misspecification、selection bias 或 deployment shift。截断/SVD regularization 若改变 estimator，才会改变统计 bias—variance。

### 第 6 题解答：验证选择与 KRR–GP（7 分）

冻结训练 realization 后，

$$
z=(0.875,1.3,-1.6).
$$

四个 candidate coefficient predictors 是

$$
\begin{aligned}
a_0&=(0.875,1.3,-1.6),\\
a_{0.25}&=(0.861538,1.04,-0.32),\\
a_1&=(0.823529,0.65,-0.094118),\\
a_4&=(0.7,0.26,-0.024615).
\end{aligned}
$$

它们的 fresh-response risks（坐标平均后加 $\sigma^2$）分别是

$$
(1.671875,\ 0.448390533,\ 0.349264706,\ 0.437299408).
$$

八个验证 sign vectors 的选择结果为：

| $\xi$ | selected $\lambda$ | minimum validation risk |
|---|---:|---:|
| $(-,-,-)$ | 4 | 0.015761 |
| $(-,-,+)$ | 4 | 0.298838 |
| $(-,+,-)$ | 0.25 | 0.082237 |
| $(-,+,+)$ | 1 | 0.505147 |
| $(+,-,-)$ | 1 | 0.193382 |
| $(+,-,+)$ | 4 | 0.498838 |
| $(+,+,-)$ | 0.25 | 0.174544 |
| $(+,+,+)$ | 1 | 0.622794 |

因此选择频率为

$$
(0,\ 0.25,\ 0.375,\ 0.375).
$$

加权真实风险、报告的 minimum validation risk 与 optimism 为

$$
\mathbb E R(a_{\widehat\lambda})=0.407059176,
$$

$$
\mathbb E\min_\lambda\widehat R_{val}(a_\lambda)=0.298942660,
$$

$$
\text{optimism}=0.108116516.
$$

即使每个 candidate 的 validation score 都无偏，minimum 也不无偏。

KRR 在 Gram eigenvalue $\kappa_j$ 上的 smoother filter 是 $\kappa_j/(\kappa_j+c)$。若 objective 写成 $n^{-1}\|y-f\|^2+\lambda\|f\|_\mathcal H^2$，则 $c=n\lambda$；若无 $1/n$，则 $c=\lambda$。零均值 GP、prior covariance $K$、observation noise $\sigma_n^2I$ 的 posterior mean filter 是 $\kappa_j/(\kappa_j+\sigma_n^2)$。所以需令相同 $K$ 且 $c=\sigma_n^2$ 才相同。

mean equality 只是一阶点估计恒等式。GP posterior covariance 还依赖 prior/noise stochastic contract；credible coverage 是 posterior probability，而 frequentist coverage 对重复样本取概率，需要模型正确、超参数处理与可能的 Bernstein–von Mises/coverage 条件。

### 第 7 题解答：边界、树与集成（7 分）

把标签写成 $y'=2y-1$。离边界最近的异类点为 $-2$ 与 $-1$。support constraints 同时取等号：

$$
-(-2w+b)=1,\qquad -w+b=1.
$$

解得

$$
w=2,\qquad b=3,\qquad \gamma=1/|w|=0.5.
$$

support vectors 是 $x=-2,-1$。六个 signed functional margins 是

$$
(3,1,1,5,7,9).
$$

沿 $c(w,b)$ 的平均 logistic loss 为

$$
L(c)=\frac16\sum_i\log(1+e^{-c m_i}).
$$

数值为

$$
L(1)=0.113810157,\qquad L(4)=0.006051000.
$$

当 $c\to\infty$，$L(c)\downarrow0$，但任意 finite $c$ 都大于 0，故无正则 separable logistic MLE 没有 finite minimizer。

父节点 class-1 比例为 $4/6$，Gini 为 $2(2/3)(1/3)=4/9$。阈值 $-1.5$ 把两类完全分开，children impurity 为 0，故最佳 gain 是

$$

$$

$$
t=-4:4096,\qquad t=-2.5:11529,\qquad t=-1.5:31031.
$$

在 query $-2.25$，前两个 thresholds 输出 1，所以

$$
p_B=\frac{4096+11529}{6^6}

### 第 8 题解答：PCA、K-Means、EM 与选择（7 分）

数据已中心化。使用 $1/n$ covariance：

$$
\widehat\Sigma=
\begin{bmatrix}
14/3&2\\2&1
\end{bmatrix}.
$$

trace 为 $17/3$，determinant 为 $2/3$，所以

$$
\lambda_{1,2}=\frac{17\pm\sqrt{265}}6
=(5.546470099,\ 0.120196567),
$$

$$
\text{eigengap}=\frac{\sqrt{265}}3=5.426273532.
$$

可取 top unit eigenvector

$$
u_1=(0.915348193,\ 0.402663241)^T,
$$

$$
4/6=2/3.
$$

对 symmetric mixture，右 component responsibility 是

$$
r_i=\frac1{1+e^{-2\mu x_i}}.
$$

$\mu_0=1$ 时按 $x=-3,-2,-1,1,2,3$ 得

$$

$$
\mu_1=\frac{\sum_i r_ix_i}{\sum_i r_i}=1.891604526.

## 4. C 部分：主链推导与证明接缝（32 分）

### 第 9 题解答：平方损失到 ridge spectral risk（8 分）

固定 $x_0$，令 $f^*(x_0)=\mathbb E[Y\mid X=x_0]$，fresh response 写成

$$
Y=f^*(x_0)+\varepsilon,qquad
\mathbb E[\varepsilon\mid x_0]=0.
$$

训练样本/seed 产生 $\widehat f_S(x_0)$。加减 $\bar f(x_0)=\mathbb E_S\widehat f_S(x_0)$：

$$
Y-\widehat f
=\varepsilon+[f^*-\bar f]+[\bar f-\widehat f].
$$

平方取联合期望。$\varepsilon$ 对 fresh response 条件中心化；$\widehat f-\bar f$ 对训练随机性中心化；中间 bias 项固定，所以交叉项都为 0：

$$
\mathbb E(Y-\widehat f)^2
=\operatorname{Var}(Y\mid x_0)
+[\bar f(x_0)-f^*(x_0)]^2
+\operatorname{Var}_S(\widehat f_S(x_0)).
$$

再对 $X_0\sim P_X$ 积分才是 Random-X risk。若 class 受限，还可把 $f^*$ 到 $f_\mathcal H^*$ 的 approximation 与 estimator 到 class optimum 的 estimation 分开；算法未解完是 optimization；浮点/近似 kernel/linear solve 是 numerical。它们不自动正交相加，必须声明使用的 inequality 或 projection。

固定设计 ridge：令 $X=U\operatorname{diag}(s_j)V^T$。在 $V$ 坐标中

$$
\widehat\beta_{\lambda,j}
=\frac{s_j^2}{s_j^2+\lambda}\beta_j
+\frac{s_j}{s_j^2+\lambda}u_j^T\varepsilon.
$$

均值给 shrinkage bias，noise variance 给第 5 题公式。

“复杂度越大，bias 必降、variance 必升”不是分解本身的定理。反例：若所有候选 procedures 输出同一 predictor，两者都不变；若增加无关但强制为零的 feature，风险不变；interpolating regime 中 variance/total risk 可出现 double descent；bagging 增加成员数可降 variance 而不改变单成员 class complexity。U 形曲线需要额外 nested-class/estimator/noise 条件。

### 第 10 题解答：proper loss、margin 与 kernel（8 分）

若 $Y\mid X=x\sim\mathrm{Bernoulli}(\eta)$，预测 $q\in(0,1)$，conditional log risk 为

$$
L(q;\eta)=-\eta\log q-(1-\eta)\log(1-q).
$$

加减 $-\eta\log\eta-(1-\eta)\log(1-\eta)$：

$$
L(q;\eta)=H_b(\eta)+\eta\log\frac\eta q
+(1-\eta)\log\frac{1-\eta}{1-q}
=H_b(\eta)+\operatorname{kl}(\eta\|q).
$$

KL 非负且只在 $q=\eta$ 为 0，所以 log loss strictly proper。若 log-odds linear class不能表示 $\eta(x)$，population logistic target 是该 class 中的 expected KL projection。classification calibration说明小 surrogate regret 可控制适当的 0—1 regret，不表示 finite sample probability一定校准。

hard-margin primal：

$$
\min_{w,b}\frac12\|w\|^2
\quad\text{s.t.}\quad y_i(w^Tx_i+b)\ge1.
$$

Lagrangian

$$
\mathcal L=\frac12\|w\|^2
-\sum_i\alpha_i[y_i(w^Tx_i+b)-1],\qquad \alpha_i\ge0.
$$

stationarity 给 $w=\sum_i\alpha_iy_ix_i$ 与 $\sum_i\alpha_iy_i=0$；代回得 dual

$$
\max_{\alpha\ge0,\ \alpha^Ty=0}
\mathbf1^T\alpha-\frac12\alpha^TYKY\alpha.
$$

complementary slackness：$\alpha_i[y_if(x_i)-1]=0$；$\alpha_i>0$ 的点位于 margin boundary。functional margin 会随 $(w,b)$ 缩放，geometric margin $y_if(x_i)/\|w\|$ 不变；normalization 把尺度固定。

RKHS objective

$$
\min_{f\in\mathcal H_K}
\sum_i\ell(f(x_i),y_i)+\lambda\|f\|_K^2
$$

的 minimizer 位于 sample span：$f=\sum_i\alpha_iK(x_i,\cdot)$。正交分量不改变 training evaluations却增加 norm。平方损失下得到 finite Gram system，具体是 $(K+\lambda I)\alpha=y$ 或 $(K+n\lambda I)\alpha=y$，取决于 empirical loss scaling。

kernel trick 只让 inner products/restrictions可计算并定义 geometry；margin generalization还需 norm/radius/capacity 与 sampling 条件；GP probability interpretation另需 stochastic-process prior、likelihood/noise 与 conditioning contract。

### 第 11 题解答：树、剪枝、bagging 与 boosting（8 分）

固定 regression leaf $R$ 的 squared loss：

$$
Q(c)=\sum_{i\in R}(y_i-c)^2,qquad
Q'(c)=2|R|c-2\sum_{i\in R}y_i,
$$

所以 $c=\bar y_R$。classification node impurity可用

$$
G(R)=1-\sum_kp_{Rk}^2
$$

或 entropy；split gain 是 parent impurity 减 children size-weighted impurity。

greedy split 只在当前 leaf 和候选 splits 中最大化一步 gain。未来可用 splits 与全树结构相互依赖，因此不保证 global empirical optimum；更不保证 population risk，后者还需 capacity/pruning/validation 与 sampling。

cost-complexity pruning：

$$
R_\alpha(T)=R(T)+\alpha|T|.
$$

把 internal subtree $T_t$ collapse 成 leaf $t$ 的 weakest-link ratio 是

$$
g(t)=\frac{R(t)-R(T_t)}{|T_t|-1}.
$$

依次 prune 最小 $g(t)$ 产生 nested subtree path；$\alpha$ 或 subtree 必须在 validation/inner CV 中选，outer/test 评价整个 pruning procedure。

对 $B$ 个等方差 $v$、pairwise covariance $\rho v$ 的成员，

$$
\operatorname{Var}\left(\frac1B\sum_bT_b\right)
=\frac1{B^2}[Bv+B(B-1)\rho v]
=v\left(\rho+\frac{1-\rho}{B}\right).
$$

$B\to\infty$ 后留下 $\rho v$；decorrelation 与单成员 strength 均重要。

AdaBoost 在当前 weights 下最小化

$$
Z_t(\alpha)=\sum_iD_t(i)e^{-\alpha y_ih_t(x_i)}
=(1-\varepsilon_t)e^{-\alpha}+\varepsilon_te^\alpha.
$$

令导数为 0：

$$
\alpha_t=\frac12\log\frac{1-\varepsilon_t}{\varepsilon_t},
\qquad
Z_t=2\sqrt{\varepsilon_t(1-\varepsilon_t)}.
$$

更新 $D_{t+1}(i)\propto D_t(i)e^{-\alpha_ty_ih_t(x_i)}$。训练错误 indicator 满足 $\mathbf1\{y_iF_T(x_i)\le0\}\le e^{-y_iF_T(x_i)}$，从而接到 $\prod_tZ_t$。这不是 test-risk theorem。

Random Forest 的 feature subsampling改变每棵树可见的候选与成员相关性，常在 strength 与 correlation 间折中；它可能增加单树 bias，也不保证对所有分布改善。

### 第 12 题解答：子空间、量化与潜变量（8 分）

对 centered random vector和 rank-$r$ projector $P_U$：

$$
\mathbb E\|X-P_UX\|^2
=\mathbb E\|X\|^2-\mathbb E\|P_UX\|^2
=\operatorname{tr}(\Sigma)-\operatorname{tr}(U^T\Sigma U).
$$

所以最小重构误差等价于最大投影方差；Rayleigh–Ritz/Ky Fan 选 top-$r$ eigen-subspace。样本 covariance 为 $n^{-1}X_c^TX_c$，故 top right singular vectors相同。

若 population eigengap $\gamma=\lambda_r-\lambda_{r+1}>0$，Davis–Kahan 型接口给

$$
\|\sin\Theta(\widehat U_r,U_r)\|_{op}
\lesssim\frac{\|\widehat\Sigma-\Sigma\|_{op}}\gamma
$$

（常数和局部条件依版本而异）。gap 为 0 时 individual basis不可辨识；若整组重复 eigenvalues与外部谱分离，只能识别对应 invariant subspace。

K-Means 固定 assignments $C_j$ 后，

$$
\sum_{i\in C_j}\|x_i-c_j\|^2
=\sum_{i\in C_j}\|x_i-\bar x_j\|^2+|C_j|\|c_j-\bar x_j\|^2,
$$

故 center 是 mean。assignment step 和 center step各自不升 objective，所以 Lloyd monotone；但非凸性只给 local fixed point。population consistency还需 empirical-process control、近似/global optimization、population optimum uniqueness modulo permutation 和稳定 separation等条件。

EM identity来自任意 $q(z)$：

$$
\log p_\theta(x)
=\mathbb E_q\log\frac{p_\theta(x,z)}{q(z)}
+\mathrm{KL}(q\|p_\theta(z\mid x)).
$$

E-step 用旧 posterior令 gap 0；M-step提高固定 $q$ 下 ELBO；新 likelihood ≥ 新 ELBO ≥ 旧 ELBO = 旧 likelihood。

四类失败必须分开：label switching 是 quotient symmetry；variance collapse 是 likelihood 无有限最大值的 singularity；misspecified MLE 收敛到 $\arg\min_\theta\mathrm{KL}(P_0\|P_\theta)$；错设下 asymptotic covariance一般是 $H^{-1}JH^{-1}$，不是自动 $H^{-1}$。它们分别影响身份、存在性、目标和推断。

## 5. D 部分：审计、反例与 AI 迁移（20 分）

### 第 13 题解答：十条声明（10 分）

1. **错误。** 分解是恒等式，不给随“复杂度”变化的单调性。需定义 nested procedures并证明两项变化；double descent或恒定 estimator是反例。
2. **错误。** inner minimum用于选择且乐观；outer scores才估计 selected procedure。还要考虑 fold dependence与 full-data refit差异。
3. **错误。** BLUE只在 linear unbiased estimators、固定设计和 Gauss–Markov条件内比较 covariance。ridge有 bias却可因降 variance而 prediction risk更小；第5题就是反例。
4. **错误。** convex保证任何局部最小是全局最小，不保证 minimizer存在或 unique。separation使 infimum沿无穷射线达到。
5. **错误。** margin是几何/分类 confidence proxy，不是 proper probability。需另做 Platt/isotonic/calibration并用独立数据验收。
6. **错误。** mean correspondence需 scaling条件；posterior covariance、prior解释和 coverage合同仍不同。
7. **错误。** greedy training impurity下降是经验一步性质；fully grown tree可高 variance并过拟合。需 pruning/capacity与独立评价。
8. **错误。** 若相关性 $\rho>0$，limit variance为 $\rho v$；系统偏差也不随 $B$ 消失。
9. **错误。** EM只保证声明模型和 exact steps下 observed likelihood不降；local optimum、label switching、collapse、错设和语义都仍存在。
10. **错误。** AIC优化特定 regular asymptotic predictive-KL目标，不证明 parameter identifiability、model truth或causality；singular models中普通 penalty也可能失效。

### 第 14 题解答：embedding pipeline 协议（10 分）

一份合格协议应包含：

#### 14.1 三类 estimand

- supervised：声明条件概率、cost-sensitive action或 bounded task loss；linear probe只估计 frozen representation上的 class optimum；
- unsupervised：PCA projector和 K-Means center set modulo rotation/sign/permutation；
- latent：GMM observed density与responsibilities modulo label permutation，不把 component命名预设成“用户类型”。

#### 14.2 sampling 与 shift

以用户/组织/时间段为 sampling group；同一用户全部样本只进一个 outer fold。冻结公开 foundation model版本和预训练数据 provenance。部署目标写明地区、时间、语言与产品策略；另设 temporal/OOD test。

#### 14.3 nested pipeline

每个 outer-training split内部重新计算 normalization、选择 embedding layer/pooling、fit PCA、选择 rank/metric、训练全部 candidates、校准 probability。inner CV选择完整 pipeline。outer test只执行被冻结的 selected pipeline一次。所有 outer 结束后，用预注册 rule确定最终配置并在全 train+validation refit；untouched test只开一次。

#### 14.4 predictor与决策

明确最后部署是 logistic probability、SVM score、KRR mean、forest vote/probability或 calibrated wrapper。阈值由 cost/constraint决定，不用 accuracy 自动替代 calibration。若 posterior/ensemble sampling与 deterministic mean不同，分别评价。

#### 14.5 quotient与语义

PCA按 projector/principal angles评价，不比 eigenvector sign；K-Means/GMM按 permutation-invariant distance/ARI/NMI评价。所谓“用户类型”需要外部标签、稳定性、下游 intervention/utility和人工语义审查；仅低 distortion/高 likelihood不通过。

#### 14.6 误差总账

分别报告 representation/model approximation、finite-sample estimation、optimizer/local minimum与seed、linear algebra/approximate kernel numerical error、hyperparameter/search selection、calibration、deployment shift。不得用一个 overall benchmark遮蔽来源。

#### 14.7 theorem candidates与 falsifiers

- ridge/KRR stability或effective-dimension risk theorem：核/feature class、bounded/sub-Gaussian noise、regularization与sampling需验证；heavy-tail/group dependence是 failure witness；
- PCA covariance concentration + Davis–Kahan：需要operator-norm covariance control与eigengap；gap接近0或representation随同一数据自适应选择会失败；
- finite-candidate holdout theorem：候选需在holdout前冻结；adaptive human/agent transcript是 failure witness。

#### 14.8 实验与来源边界

negative controls包括随机标签、打乱group、随机embedding layer、permutation labels、single-cluster data、重复谱、污染test。多seed报告分布而非最佳seed。theorem由教材/原论文提供条件性结论；finite script只校准fixture；博客用于发现问题和原始来源；benchmark只支持其sampling frame，不证明universal superiority。
