# 阶段测验 - 经典模型与模型选择（20.6）

> [!abstract] 这卷真正考什么
> 不是背十二种算法的 API，而是面对一个建模流程时，能依次说清 **estimand—model/class—loss—regularizer—algorithm—selection protocol—refit predictor—deployment risk**。同一个数据集上的 logistic、SVM、tree、PCA、K-Means 与 mixture model 可能优化完全不同的总体对象；训练目标下降、参数可辨识、预测有效与选择后证书必须分开。

## 一、答案与输出隔离协议

1. 生成唯一 `attempt_id`，记录开始/结束时间、题卷版本和原稿 SHA-256；
2. 先完成 **25 分钟卷级口试**，再完成 **240 分钟闭卷**，不得查看详解、canonical SVG、脚本或 stdout；
3. 闭卷后封存第 5—8 题解析结果、三轨方向预测，以及“哪个数不能比较”的判断；
4. 评分者再公布 `scorer nonce`，指定主轨、至少跨两轨的盲参数和一条非法合同；
5. 非 canonical 参数必须写入新的 `--output`，保存 command、stdout、SVG、SHA-256、运行前预测和差异解释；
6. 只有上述证据冻结后，才可打开[[阶段测验解答 - 经典模型与模型选择（20.6）]]与 canonical 结果；
7. 48 小时做换数据机制复测，14 天后迁移到陌生 AI model-selection pipeline。

## 二、25 分钟卷级口试

不看笔记，每题 5 分钟：

1. 从 estimand 开始，区分总体回归函数、最佳线性投影、类别概率、最大间隔边界、主子空间、量化中心集和 mixture density；
2. 口头推导固定设计 ridge 在奇异向量方向上的 bias、variance 与 effective degrees of freedom；
3. 用同一份二分类数据比较 logistic、hard-margin SVM、decision tree 和 AdaBoost 各自优化什么，以及谁直接输出概率；
4. 用 ELBO/KL 恒等式解释 EM 单调性，并说出它不保证全局最优、有限 MLE、参数可辨识或语义恢复中的哪几项；
5. 审计“我们试了很多 preprocessing、模型、seed 和指标，报告验证分数最低者”的完整选择成本与 nested protocol。

口试通过要求：至少 4/5 能同时说明对象、优化量、随机性、选择时间线和不能推出；只会列算法特点最高记 attempted。

## 三、240 分钟闭卷（100 分）

### A 部分：对象、算法与选择合同（20 分）

### 第 1 题：十层经典模型账本（5 分）

为一个完整建模问题填写十层账本：

1. observation/response 与 sampling unit；
2. target distribution 与 deployment shift；
3. estimand / equivalence class；
4. model/class 与 misspecification；
5. loss/regularizer；
6. optimization algorithm、initialization、tie-break 与 stopping；
7. train/validation/certificate/test 时间线；
8. selected procedure、full-data refit 与最终 predictor；
9. statistical、optimization、numerical、selection 与 shift error；
10. theorem、finite computation、simulation 与 benchmark 的证据边界。

每层给一个来自 LT-41—52 的具体失配例子。

### 第 2 题：四种“收敛”和三种“相同”（5 分）

分别定义并比较：

1. objective value convergence；
2. parameter convergence；
3. predictor/distribution convergence；
4. population-risk consistency。

再解释下列“相同”各需什么条件：KRR 与 GP posterior mean 相同；两个 mixture 参数只差 label permutation；两个不可辨识参数给相同预测。每项指出不能推出的下一层结论。

### 第 3 题：模型选择时间线（5 分）

一个团队在全部数据上先标准化、做 PCA、选择 rank，再用 10-fold CV 搜索 loss、regularization、tree depth、kernel 和 seed；反复查看 CV 后新增候选，最后在全数据 refit，并把最小 CV score 当作部署风险。

1. 画出实际信息流并标出全部泄漏/自适应点；
2. 给出 fixed-candidate simultaneous control、nested CV、独立 holdout 三种合法修复；
3. 说明 outer-CV 评估的是 selected procedure，为什么不自动等于 full-data refit predictor 的 exact risk。

### 第 4 题：预测者与损失身份（5 分）

对下列对象各写：直接优化的 empirical objective、population estimand、输出身份、自然评价指标、一个常见非法解释：

1. logistic regression；
2. hard-margin/soft-margin SVM；
3. KRR 与 GP；
4. regression/classification tree；
5. PCA 与 K-Means；
6. finite Gaussian mixture 的 EM。

### B 部分：三轨精确计算（28 分）

### 第 5 题：谱 ridge 的 bias—variance 账本（7 分）

固定设计在线性模型的奇异坐标中取

$$
s=(4,1,0.25),\quad \beta=(1,0.8,0.4),\quad \sigma=0.5,
$$

并采用 objective 对应的 filter $s_j^2/(s_j^2+\lambda)$。对 $\lambda\in\{0,0.25,1,4\}$：

1. 推出并计算 test covariance 为 $I$ 时的 squared bias、variance 与 expected excess prediction risk；
2. 计算 effective degrees of freedom；
3. 找到 expected risk 最小的 $\lambda$；
4. 解释 OLS risk 巨大的具体谱方向，以及 QR/SVD 能与不能修复什么。

### 第 6 题：验证选择、KRR 与 GP 的接口（7 分）

沿用第 5 题。冻结训练 sufficient statistics

$$
z_j=\beta_j+\sigma e_j/s_j,\qquad e=(-1,1,-1),
$$

候选预测为 $a_{\lambda,j}=s_j^2z_j/(s_j^2+\lambda)$。独立验证 response 为 $Y_j^{\rm val}=\beta_j+0.5\xi_j$，$\xi_j\in\{-1,1\}$ 等概率独立。

1. 枚举 $2^3$ 个验证 response，给出四个 $\lambda$ 的选择频率；
2. 计算 selected predictor 的 expected fresh-response risk、reported minimum validation risk 与 selection optimism；
3. 把同一 spectral filter 写成 KRR smoother 与 GP posterior mean，说明对应所需的 kernel/noise/regularization scaling；
4. 解释 mean 相同为什么不推出 GP credible interval 有 frequentist coverage。

### 第 7 题：边界、树与集成的统一小样本（7 分）

取

$$
x=(-3,-2,-1,1,2,3),\qquad y=(0,0,1,1,1,1).
$$

1. 求 hard-margin SVM 在 $y_i'(wx_i+b)\ge1$ normalization 下的 $w,b$、support vectors 与 geometric margin；
2. 沿 $(w,b)=c(2,3)$ 计算 $c=1,4$ 的 empirical logistic loss，并说明 finite MLE 是否存在；
3. 在 thresholds $(-4,-2.5,-1.5,0,1.5,2.5,4)$ 中计算最佳 Gini split；
4. 对所有 $6^6$ 个 size-6 bootstrap sequences 以 empirical error、threshold index 依次 tie-break，计算 query $x=-2.25$ 的 bagged class-1 probability；
5. 取 $B=25,\rho=0.2$，计算 independent 与 correlated ensemble variance；
6. 对固定 stump $h_0(x)=\mathbf1\{x\ge0\}$ 做一轮 AdaBoost，计算 $\varepsilon,\alpha,Z$ 与更新后最大样本权重。

### 第 8 题：PCA—K-Means—EM—选择准则（7 分）

取二维点

$$
(-3,-1),(-2,-1),(-1,-1),(1,1),(2,1),(3,1),
$$

并在 EM 中使用其第一坐标。令 two-component Gaussian mixture 等权、单位方差、对称均值 $(-\mu,\mu)$。

1. 计算 empirical covariance 的两个 eigenvalues、eigengap 与 top eigenvector；
2. 对左右三点的 $K=2$ partition 计算 centers 与平均 distortion，并给出 label-swap 等价类；
3. 从 $\mu_0=1$ 计算 E-step responsibilities 与一次 M-step；迭代到 fixed point，验证 observed log likelihood 不下降；
4. 对自由均值/方差的 single Gaussian 与上述一参数对称 mixture 计算 AIC/BIC arithmetic；
5. 说明为何这次算术比较不证明 full Gaussian-mixture 的 regular BIC theorem，也不证明两簇有真实语义。

### C 部分：主链推导与证明接缝（32 分）

### 第 9 题：平方损失分解到 ridge spectral risk（8 分）

1. 在固定测试点 $x_0$，从 fresh response、训练样本与算法随机性出发，完整推导 noise + squared bias + variance；
2. 积分到 Random-X，并区分 approximation、estimation、optimization 与 numerical error；
3. 对固定设计 ridge 推出每个奇异方向的 shrinkage、bias、variance；
4. 证明“bias—variance trade-off 是普遍 U 形定理”为假，给出一个 monotone 或 double-descent failure witness。

### 第 10 题：proper loss、margin、kernel 三条接口（8 分）

1. 证明 Bernoulli conditional log risk 等于 $H_b(\eta)+\operatorname{kl}(\eta\|q)$；
2. 由此说明 logistic population target、classification calibration 和 misspecification 下 KL projection；
3. 从 hard-margin primal 写 Lagrangian、dual 与 KKT support-vector 条件，并解释 functional/geometric margin 的缩放；
4. 用 representer theorem 把 RKHS-regularized objective 化为 finite Gram system；
5. 分开核技巧的计算/表示作用、margin generalization 与 GP probability interpretation。

### 第 11 题：partition、pruning、bagging 与 boosting（8 分）

1. 推导 regression squared-error leaf action 是样本均值，并写 classification Gini/entropy split gain；
2. 说明 greedy split 下降只保证当前 empirical objective，不保证 global tree 或 population optimum；
3. 从 cost-complexity pruning 写出 weakest-link ratio 与 validation selection 时间线；
4. 推导等方差、等相关成员平均的 variance
   $$v\left(\rho+\frac{1-\rho}{B}\right);$$
5. 从 exponential loss 推出 AdaBoost 的 $\alpha_t$、normalizer 与训练错误上界接口；
6. 解释 Random Forest 的 feature subsampling 为什么改变 strength–correlation，而不是“自动消除 bias”。

### 第 12 题：子空间、量化与潜变量主链（8 分）

1. 证明 PCA 最大投影方差、最小正交重构误差与 centered-data SVD 等价；
2. 写出 covariance perturbation / eigengap 到 principal-angle risk 的接口，并处理重复谱；
3. 证明固定 K-Means assignment 下 center 是均值，说明 Lloyd monotonicity、local fixed point 与 population consistency的缺口；
4. 从 $\log p_\theta(x)=\mathcal F(q,\theta)+\mathrm{KL}(q\|p_\theta(z\mid x))$ 推出 exact EM monotonicity；
5. 区分 label switching、variance collapse、misspecified KL projection 与 sandwich covariance 四类问题。

### D 部分：审计、反例与 AI 迁移（20 分）

### 第 13 题：十条声明审计（10 分）

逐条判断正确/错误/条件不足，给最小修复或反例：

1. bias—variance 分解证明模型越复杂 bias 必降、variance 必升；
2. nested CV 的 inner 最低分是 selected procedure 的无偏部署风险；
3. OLS 是 BLUE，所以比 ridge 的 prediction risk 总小；
4. logistic objective convex，所以 separable data 一定有 finite unique MLE；
5. SVM margin 大，所以输出就是 calibrated probability；
6. KRR 与 GP mean 相同，所以二者的不确定性解释也相同；
7. 每个 greedy split 都降低 impurity，所以 fully grown tree 的 population risk 单调下降；
8. 增加 ensemble members 总能把 variance 降到 0；
9. EM likelihood 单调上升，所以恢复了真实 latent classes；
10. AIC 最小的模型参数就是可辨识且因果正确的真实机制。

### 第 14 题：为 embedding-based AI pipeline 建立选择与部署合同（10 分）

情境：团队从公开 foundation model 提取 embeddings，搜索 layer、pooling、PCA rank、metric、linear/logistic/SVM/KRR/tree/forest/boost、class weights、seed 与 calibration method；又用 K-Means/GMM 发现“用户类型”，最后 full-data refit 并部署。

写出一份可证伪研究协议：

1. supervised、unsupervised 与 latent estimands；
2. sampling/group/time/shift unit；
3. preprocessing 与 representation 必须进入哪一层 split；
4. inner selection、outer evaluation、final refit 与 untouched test；
5. predictor identity、probability/calibration 与 decision cost；
6. identifiability/quotient 与 semantic validation；
7. statistical/optimization/numerical/selection/shift error ledger；
8. 至少两个 theorem candidates 及不可验证条件；
9. negative controls、multiple seeds 和 failure state；
10. theorem、博客、finite experiment 与 benchmark 的来源边界。

## 四、三轨参数化模型族

| 轨道 | canonical 对象 | 允许盲参 | 运行前必须预测 |
|---|---|---|---|
| A spectral/selection | diagonal fixed-design ridge + exact validation signs | $s,\beta,\sigma,\lambda$ grid、training signs | bias/variance、最佳 $\lambda$、df、selection frequency/optimism |
| B boundary/ensemble | six-point classification + all bootstraps + one boost round | query、ensemble $B$、member correlation $\rho$ | margin、bag probability、independent/correlated variance |
| C latent/geometry | symmetric 2D points + constrained mixture EM | EM initial mean、tolerance/iterations | PCA gap、K-Means quotient、EM direction/likelihood与选择边界 |

`scorer nonce` 的 SHA-256 首字节模 3 指定主轨；第二字节指定至少横跨两轨的参数变化；第三字节从“维度不匹配 / 非正 singular value / 重复或负 $\lambda$ / 非法 $\rho$ / EM 不收敛 / 非 canonical 覆盖 canonical”中指定非法合同。评分者须在预测冻结后才公布 nonce。
