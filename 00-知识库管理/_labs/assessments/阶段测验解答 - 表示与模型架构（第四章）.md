# 阶段测验解答 - 表示与模型架构（第四章）

## Q1

取 $(w*x)[n]=\sum_rw[r]x[n-r]$。对平移 $(T_ax)[n]=x[n-a]$，代入得 $w*(T_ax)=T_a(w*x)$。stride-2 是先等变卷积再只保留偶数格；令 $x=[1,0,0,\dots]$、identity kernel，平移一格后非零从被采样格移到未采样格，输出不只是平移。理论感受野由路径可达性决定，有效感受野描述实际梯度/贡献分布；anti-aliasing 控制采样前高频；任务不变性还需 pooling/data/目标。Weight sharing 不证明旋转、尺度不变或实际泛化。

## Q2

$$h_t=\sum_{j=1}^tA^{t-j}Bx_j,\qquad y_t=\sum_{j=1}^tCA^{t-j}Bx_j,$$
故 kernel $K_r=CA^rB$。$\partial h_T/\partial h_t=A^{T-t}$；谱半径控制渐近，但非正规 $A$ 可有大暂态，范数/条件性也要检查。Recurrence 深度 $T$；关联 scan 对仿射状态更新可给对数并行深度；固定 LTI kernel 可 FFT convolution。若 $A_t,B_t$ 依输入，kernel 不再只依 lag，但仿射变换的结合组合仍可能 scan。

## Q3

若归一化邻接相容地变为 $\hat A'=P\hat AP^T$，则
$$\sigma(\hat A'PXW)=\sigma(P\hat AXW)=P\sigma(\hat AXW).$$
Sum 会把不同多重集在总和相同处碰撞，mean 还丢 multiplicity，max 丢非最大元素。相同初始颜色的 regular graphs（如某些同度非同构图）可使 1-WL/标准 MPNN 始终同色。Over-smoothing 是表示趋同，可查 pairwise distance/Dirichlet energy；over-squashing 是指数增长远程信息压入固定维 bottleneck，可查远端 Jacobian、图曲率/割与 rewiring 响应。

## Q4

$S=QK^T/\sqrt{d_k}$ 为 $T_q\times T_k$，mask 同形或可广播；逐行对未遮蔽项做 max-shift softmax，$P$ 同形，$O=PV$ 为 $T_q\times d_v$。若 K/V 同乘 permutation $\Pi$，score 列与 V 行同步重排，$P\Pi^T\Pi V=PV$；self-attention 同时重排 Q/K/V 为节点/token 等变。Softmax 是逐元素指数加行归一的非线性，可把低秩 logits 变成满秩权重。全遮蔽行应显式返回零/跳过并避免 $-\infty-(-\infty)$；此行不是普通概率分布，必须单独定义。

## Q5

Pre-Norm 两子层可写 $u=x+\mathrm{Attn}(N_1x)$、$y=u+\mathrm{FFN}(N_2u)$；单子层 Jacobian 为 $I+J_FJ_N$。因 causal row $t$ 只依 $j\le t$，cache 保存过去由同一状态/位置生成的 K/V，新增 query 对相同集合算同一 softmax，逐步归纳得到等价。错 offset、跨样本 cache 污染、train dropout、低精度归约顺序与错误 packing mask 会破坏。Encoder 是双向 self relation；decoder 是 causal target self relation；encoder–decoder 另有 target query 到 source K/V 的 cross relation，目标也分别不同。

## Q6

无位置 full attention 对同步 token permutation 等变，若读出也不变，就无法区分只差顺序的输入。对同一正交旋转表示 $R(m+n)=R(m)R(n)$，$R(m)^TR(n)=R(-m)R(n)=R(n-m)$；需共享生成元/频率、正交与正确 pairing。绝对插值重映射 position ids；RoPE scaling 改角频率；relative bias 改 logits 的距离函数；local window 改 relation graph。评测应交叉 prompt length 与目标绝对/相对位置，含固定内容/干扰、PPL、检索、组合任务、TTFT/ITL/cache、短长质量和失败/OOM，而非只验证 shape 可运行。

## Q7

Sparse 改 relation edges；low-rank 压 sequence axis/模型；kernel linearization 改或近似 similarity 并用结合律；Flash 改 dense exact attention 的 IO schedule。Prefill pairwise 主项 $2Bn^2d$，naive score $Bh n^2$ 标量；decode K/V payload 为 $2LBTh_{kv}d_hs$ bytes。Flash 遍历全部 dense pairs，算术仍二次，但分块 online softmax 不把全 score 写 HBM，因此实数模型 exact 与 IO 降低并存。Serving 对照须固定 checkpoint/uptraining、质量、batch/context/output、dtype/quant、硬件/kernel、cache bytes、TP layout，分别报 TTFT、ITL、throughput 与峰值显存。

## Q8

合同含 logits、activation、Top-k/tie、selected Re-Norm、capacity/drop、combine 与 backward。$Tk/E=16/4=4$，$C=4$；负载 $[6,4,3,3]$ drop 2，处理 14，总槽 16，利用率 $87.5\%$。$f_i=T^{-1}\sum_tA_{ti}$，$P_i=T^{-1}\sum_tp_{ti}$，典型 $L_{bal}=\lambda E\sum_if_iP_i$；hard $f$ 常 stop-grad，soft $P$ 提供 proxy 梯度。Loss-free 用在线 bias 改 selection；assignment dual 在明确全局容量优化中是 shadow price，在线反馈未必精确求解它。Payload $2rTkds=2(.75)(8)(2)(1024)(2)=49{,}152$ bytes。

## Q9

合格答案应给多方案 Pareto：local attention 有显式局部 relation/成熟 kernel，但远程路径需层数或 global tokens；SSM 压历史为 state、训练可 scan/conv、decode 固定状态，但容量与选择性需验；GQA/MLA 保留 full attention relation并压 cache，仍有长历史读/算术；MoE 扩参数容量而引入路由和 All-to-All。两轨至少为等训练 FLOPs/tokens 的质量轨与等硬件/cache/latency 的 serving 轨，并扫长度、batch、远程任务和系统拓扑。

## Q10

评分按合同完整性：先固定输入/输出/shape 与 baseline；把恒等式/定理假设单列；说明是否改 relation、kernel、state、cache 或路由；分别记 parameters、MAC、activation、HBM、network 和 latency；给 fp64 reference 与 dtype/seed；做 matched-budget 训练、消融和 profiler；预注册负结果与外推边界。最后将 shape/账本标 I、条件证明标 T、测量标 E、机制解释标 H、跨规模未知标 O。只给 benchmark 或复杂度口号不得超过 4 分。
