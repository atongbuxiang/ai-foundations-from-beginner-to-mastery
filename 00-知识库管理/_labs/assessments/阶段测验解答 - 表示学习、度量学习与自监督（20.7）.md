> [!abstract] 总解题原则
> 每道题先写“正在估计什么”，再写随机实验、函数类、算法和选择时间线，最后才算数值。表示学习最常见的错误不是少背一个方法，而是把 **pretext objective、representation geometry、downstream accessibility 与 deployment utility** 当成同一个标量。

## 第 1 题解答：七层表示学习账本（5 分）

一份合格账本至少包含：

| 层 | 必须声明 | 省略后的典型错误 |
|---|---|---|
| source unit | 用户、文档、图像、患者、视频，而非 crop/token | 把同一对象的 views 当作 iid 样本 |
| view/target law | crop、mask、pairing、negative、teacher、跨模态对齐 | augmentation 或 batch 改了训练分布却仍称“同一目标” |
| model | encoder、projection/predictor、normalization、冻结位置 | projection head 健康被误当 backbone 健康 |
| optimization | loss、temperature、stop-gradient、EMA、optimizer、顺序 | 相同 forward loss 被误当相同算法 |
| selection | checkpoint、layer、head、seed、metric 与数据访问历史 | 反复查看 test 后的最高分被当无偏风险 |
| downstream protocol | kNN、linear probe、partial/full tune、label/compute budget | 不同适应能力的结果直接排名 |
| deployment | task family、shift、utility、subgroup、uncertainty | 在单一 benchmark 上的分数被外推为普遍迁移 |

例如，同一 source image 的两次 crop 共用潜在对象；若把 2,048 views 当作 2,048 个独立 source units，置信区间会虚假变窄。又如，BYOL 的 stop-gradient 不改变当前 forward scalar，却改变 target branch 是否接受梯度，所以它属于算法定义。

## 第 2 题解答：五种“表示相同”（5 分）

从弱到强不能简单排成一条线，必须声明允许的变换群与 head class：

1. **信息等价：** 两表示可互相由可测双射恢复；一般 invertible nonlinear map 可保持此层。
2. **oracle-head 风险等价：** 对给定 task 与足够闭合的 head class，两个表示达到相同最优风险。它弱于坐标相同，也依赖 task。
3. **linear-probe 等价：** 若 $z'=Az$ 且 $A$ 可逆，affine head 可吸收 $A^{-1}$，oracle affine risk 不变；一般 nonlinear bijection 不保线性可读性。
4. **pairwise-geometry 等价：** orthogonal map 保内积和 Euclidean distance；一般可逆线性 map 只在相应 Mahalanobis metric 变换后保几何。
5. **坐标相同：** 逐坐标值相同，是最强且通常没有理论必要的要求。

coordinate permutation 与 sign flip 常同时保持线性风险及正交几何，却改变“第几个 neuron”。只要 objective 与 downstream interface 对这些变换不敏感，单 neuron 语义便不可辨识；跨 seed 应比较 function、subspace、允许对齐后的 geometry 或 risk，而非默认 neuron-to-neuron identity。

## 第 3 题解答：自监督 target-generation contract（5 分）

| target | student 可见 | target 来源 | 常用损失 | 主要边界 |
|---|---|---|---|---|
| masked token | 未遮蔽 context + mask pattern | clean token | cross-entropy | tokenization、mask leakage、conditional ambiguity |
| masked pixel/patch | visible patches | raw pixel/patch | square/robust loss | low-level shortcut、mask law、perceptual mismatch |
| latent target | corrupted view | fixed/learned tokenizer 或 encoder latent | square/cosine/CE | target bias、codebook collapse |
| EMA distribution | student view | history-averaged teacher | CE/KL | confirmation bias、lag、centering/sharpening |
| cross-modal pair | one modality | paired other modality | contrastive/generative | pairing noise、identity leakage、false negatives |

对 log loss，固定 context $v$，真实 conditional law 为 $p(\cdot\mid v)$，预测为 $q$：

$$
\mathbb E[-\log q(T\mid v)\mid V=v]
=H(p(\cdot\mid v))+
\operatorname{KL}(p(\cdot\mid v)\Vert q(\cdot\mid v)).
$$

KL 非负，故最优是 $q=p(\cdot\mid v)$，最小值为 conditional entropy。

对 square loss 与任意 action $a(v)$：

$$
\mathbb E[(T-a)^2\mid V]
=\operatorname{Var}(T\mid V)+
\bigl(a-\mathbb E[T\mid V]\bigr)^2.
$$

所以最优是 conditional mean。两结论都不保证 latent 是“语义真值”；它们只刻画声明 target law 下的 Bayes action。

## 第 4 题解答：迁移评价时间线（5 分）

实际信息流是：

$$
\text{pretrain checkpoints/layers}
\to
\text{pooling/normalization/head/schedule/seed search}
\to
\text{反复读取下游 test}
\to
\text{按 test 最大值选择并报告}.
$$

此时 test 已参与 selection，不再是 locked final evidence。合法修复是：

1. 对每个 outer training split，在 inner train/validation 内完成 checkpoint、layer、head 与 schedule 选择；
2. 冻结 selected procedure；
3. 在 outer test 上只评一次；
4. 最终部署 refit 的风险若不同于 outer procedure estimand，应单独声明近似与额外假设。

三种风险必须分开：

$$
R_{\rm lin}^\star(h)
=\inf_{g\in\mathcal G_{\rm lin}}R(g\circ h)
$$

是 population oracle accessibility；

$$
\mathbb E_{S_n,\xi}R(\widehat g_{S_n,\xi}\circ h)
$$

是有限标签、指定训练程序的 probe risk；

$$
\mathbb E R(f_{\mathcal A_{\rm FT}(\theta_0,S_n,C,\xi)})
$$

是 initialization、optimizer 与 compute budget 共同定义的 fine-tuning algorithm risk。

paired split/seed 降低比较差值的噪声；label-budget curve 显示低样本与大样本区的排序；task-level aggregation控制任务抽样与权重。三者都不能修复已经发生的 test 自适应复用。

## 第 5 题解答：任务索引的表示风险（8 分）

四个输入点等概率。oracle affine 0–1 risks 为：

| representation | $Y_S$ | $Y_N$ | $Y_\oplus$ | weighted risk |
|---|---:|---:|---:|---:|
| $h_{\rm id}=(S,N)$ | 0 | 0 | $1/4$ | $0.05$ |
| $h_S=S$ | 0 | $1/2$ | $1/2$ | $0.25$ |
| $h_N=N$ | $1/2$ | 0 | $1/2$ | $0.35$ |
| $h_\oplus=SN$ | $1/2$ | $1/2$ | 0 | $0.40$ |
| $h_+=(S,N,SN)$ | 0 | 0 | 0 | $0$ |

$h_{\rm id}$ 完整保留 $X$，但 XOR 的正负点交替位于正方形四角，不能被一条 affine hyperplane 完全分开。带 bias 的直线可以单独切出一个角，故最佳错误一个点，即 $1/4$。这说明信息存在不等于在给定 head class 下线性可读。

任务权重 $(0.5,0.3,0.2)$ 给：

$$
(0.05,\ 0.25,\ 0.35,\ 0.40,\ 0).
$$

最优是 enriched representation；但这不是无代价的“绝对最好”，因为维度、估计误差、compute、privacy 与 shift 尚未计入。

变换 $a(S,N)=(S,-N)$ 对 $Y_S$ 保持 conditional law，却翻转 $Y_N$，也改变 $Y_\oplus=SN$。若 encoder 强制

$$h(S,N)=h(S,-N),$$

同一个表示值对应两种不同的 $P(Y_N\mid X)$ 或 $P(Y_\oplus\mid X)$。若仍假设 $Y\perp X\mid h(X)$，conditional law 必须只由 $h(X)$ 决定，产生矛盾。因此该 invariance 对 $Y_S$ 合法，对另两项任务破坏充分性。

## 第 6 题解答：度量、检索与增强依赖（7 分）

triplet hinge：

$$
[0.8-1.3+0.7]_+=0.2.
$$

relevance $(1,0,1,0)$ 有两个 relevant items：

$$
\operatorname{AP}
=\frac12\left(1+\frac23\right)
=\frac56
\approx0.833333,
$$

$$
\operatorname{Recall@2}
=\frac{1}{2}=0.5.
$$

令 $Z_{ij}$ 方差为 $\sigma^2$，不同 source 独立，同 source 内 pairwise correlation 为 $\rho$。则

$$
\operatorname{Var}(\bar Z)
=\frac{\sigma^2}{nm}\bigl[1+(m-1)\rho\bigr].
$$

把它写成 $\sigma^2/n_{\rm eff}$：

$$
n_{\rm eff}
=\frac{nm}{1+(m-1)\rho}
=\frac{48}{1+3(0.6)}
=17.142857.
$$

nominal views 是 48，但独立信息只相当于约 17.14 个单位。按 view-level iid bootstrap 会拆开同一 source 的相关 views，遗漏 cluster covariance；应按 source unit 做 cluster split/bootstrap，或显式拟合相关结构。

## 第 7 题解答：精确 InfoNCE candidate experiment（8 分）

由于 marginal $p_Y(y)=1/2$：

$$
r(x,y)=\frac{p(y\mid x)}{p_Y(y)}
=
\begin{cases}
1.6,&y=x,\\
0.4,&y\ne x.
\end{cases}
$$

因此

$$
P(I=i\mid x,y_{1:4})
=\frac{r(x,y_i)}{\sum_{j=1}^4r(x,y_j)}.
$$

binary symmetric channel 的 mutual information：

$$
I(X;Y)=\log2-h(0.8)
=0.1927447570\ {\rm nats}.
$$

精确枚举可压缩为 $M\sim\operatorname{Binomial}(3,1/2)$，其中 $M$ 是三个 negatives 中与 anchor 匹配的数量。

若 true positive 匹配，概率 $0.8$，其 posterior denominator 为 $2.8+1.2M$，loss 为

$$
\log\frac{2.8+1.2M}{1.6}.
$$

若 true positive 不匹配，概率 $0.2$，denominator 为 $1.6+1.2M$，loss 为

$$
\log\frac{1.6+1.2M}{0.4}.
$$

于是

$$
L_{\rm NCE}^\star
=
\sum_{m=0}^3\binom3m2^{-3}
\left[
0.8\log\frac{2.8+1.2m}{1.6}
+0.2\log\frac{1.6+1.2m}{0.4}
\right]
=1.2404929695.
$$

因此

$$
\log4-L^\star_{\rm NCE}
=0.1458013916,
$$

未闭合 gap 为

$$
0.1927447570-0.1458013916
=0.0469433654.
$$

五层账本是：

$$
I
\ge B_K^\star
\ge B_{K,\mathcal S}
\ge B_K(\widehat\theta),
$$

而 finite estimate $\widehat B$ 还围绕 trained-critic population bound 波动。有限 $K$ 造成 $I-B_K^\star$；critic restriction 造成 $B_K^\star-B_{K,\mathcal S}$；optimization 造成 class optimum 与 trained critic 的差；finite data 再产生 estimation/selection error。

## 第 8 题解答：Batch gradient 与 false negatives（7 分）

除以 $\tau=0.5$ 后：

$$u=(2,1,-0.5).$$

softmax probabilities：

$$
p=(0.6896720861,\ 0.2537161816,\ 0.0566117322).
$$

loss：

$$
\ell=-\log p_1=0.3715390319.
$$

对 raw similarity $s_j$：

$$
\frac{\partial\ell}{\partial s_j}
=\frac{p_j-\mathbf1\{j=1\}}{\tau},
$$

故

$$
\nabla_s\ell
=(-0.6206558278,\ 0.5074323633,\ 0.1132234645).
$$

随机 anchor class 为 $c$ 时，7 个 marginal negatives 至少一个 same-class 的概率是 $1-(1-\pi_c)^7$。再对 anchor class 平均：

$$
\sum_c\pi_c[1-(1-\pi_c)^7]
=0.92944442.
$$

增加 negatives 会改变：index-classification 的 candidate 数、$\log K$ ceiling、denominator law、hard/false-negative 命中概率、softmax 权重和梯度方向。因而它通常不是同一个 fixed single-example objective 的低方差估计。

## 第 9 题解答：不变性、等变性与充分性（8 分）

task-relative sufficiency 是

$$Y\perp X\mid H,\qquad H=h(X),$$

等价于 $P(Y\mid X)=P(Y\mid H)$（regular conditional law 存在时）。

若 $h(gx)=h(x)=h_0$，充分性要求

$$
P(Y\mid X=x)=P(Y\mid H=h_0)
=P(Y\mid X=gx),
$$

与题设 conditional laws 不同矛盾。因此错误 invariance 造成的信息商掉无法由更强 head 恢复。

有限群 $G$ 上

$$
\bar f(x)=\frac1{|G|}\sum_{g\in G}f(gx).
$$

对任意 $h\in G$：

$$
\bar f(hx)
=\frac1{|G|}\sum_{g\in G}f(ghx)
=\frac1{|G|}\sum_{g'\in G}f(g'x)
=\bar f(x),
$$

其中用到 $g\mapsto gh$ 是群上的双射。

equivariance 要求 $h(gx)=\rho(g)h(x)$，表示保留变换并按已知 action 移动；invariant readout 再满足 $p(\rho(g)z)=p(z)$。这允许早期 feature 保留位置/姿态，最终任务头决定是否商掉。

“训练样本标签看似不变”不足以保证 deployment validity。例如 crop 在训练图像中不改变类别，却在医疗部署中系统裁掉病灶；observed training labels 保持，但 conditional law/support 已变。需要声明 transformation kernel、target task 与部署分布上的 conditional/risk preservation。

## 第 10 题解答：InfoNCE 定理与五层 gap（8 分）

candidate experiment 中 $I$ 均匀，因此 $H(I)=\log K$。任意 critic 定义 index predictor $q_s$，cross-entropy 分解为：

$$
L_{\rm NCE}(s)
=H(I\mid X,Y_{1:K})
+\mathbb E\operatorname{KL}(P(I\mid X,Y_{1:K})\Vert q_s).
$$

所以

$$
\log K-L_{\rm NCE}(s)
\le I(I;X,Y_{1:K}).
$$

再由 candidate construction 的 KL chain rule 或 log-sum inequality：

$$
I(I;X,Y_{1:K})\le I(X;Y).
$$

组合得

$$
I(X;Y)\ge\log K-L_{\rm NCE}(s).
$$

五层为：

| 层 | 对象 | 主要缺口 |
|---|---|---|
| 1 | true $I(X;Y)$ | target 本身是否与任务相关 |
| 2 | unrestricted finite-$K$ bound | candidate bottleneck、$\log K$ ceiling |
| 3 | critic-class optimum | score family/normalization restriction |
| 4 | trained critic | optimization、regularization、finite training sample |
| 5 | finite reported estimate | evaluation noise、自适应选择与依赖 |

bound 上升可能来自更大的 $K$、更容易的 identity shortcut、更强 critic 或 test contamination；MI 本身也可能主要编码 nuisance。没有 task-relative intervention 与 downstream evidence，不能推出“语义更多”。

## 第 11 题解答：坍缩证书与可辨识边界（7 分）

四个点均值为零，population-batch covariance：

$$
C=\frac14Z^\top Z=\operatorname{diag}(9,1,0).
$$

eigenvalues 为 $(9,1,0)$。因此

$$
r_{\rm stable}=\frac{\operatorname{tr}C}{\|C\|_{\rm op}}
=\frac{10}{9}=1.111111,
$$

$$
r_{\rm PR}
=\frac{(\sum\lambda_j)^2}{\sum\lambda_j^2}
=\frac{100}{82}
=1.219512.
$$

归一化谱为 $(0.9,0.1)$，entropy effective rank：

$$
r_{\rm eff}
=\exp[-0.9\log0.9-0.1\log0.1]
=1.384145.
$$

两 views 完全相同，所以 invariance term 均为 0。std 是 $(3,1,0)$，$\gamma=1$ 时单 view variance penalty 为

$$
\frac13([1-3]_++[1-1]_++[1-0]_+)=\frac13.
$$

两 views 相加为 $2/3=0.666667$。constant representation 每维 std 为 0，单 view penalty 为 1，两 views为 2。variance floor 排除了 coordinate-wise constant，却没有证明任务充分。

反例：令目标 $Y=S$，表示 $H=(N_1,\ldots,N_d)$，其中 $N_j$ 独立、高方差且与 $S$ 独立。$H$ 可有 full-rank covariance、良好 spectrum 和容易的 instance discrimination，但任何 head 的最佳 0–1 risk 仍为 base rate $1/2$。

所以

$$
\text{non-collapse}
\not\Rightarrow\text{sufficiency}
\not\Rightarrow\text{finite-label accessibility}
\not\Rightarrow\text{shift robustness}.
$$

此外，orthogonal rotation/permutation 可能保持所有常用几何与 risk，坐标语义仍不可辨识。

## 第 12 题解答：Teacher dynamics 与 probe inference（7 分）

逐步更新：

$$
\xi_1=0.25,\quad
\xi_2=0.75(0.25)+0.25(3)=0.9375,
$$

$$
\xi_3=0.75(0.9375)+0.25(-1)=0.453125,
$$

$$
\xi_4=0.75(0.453125)+0.25(2)=0.83984375.
$$

binary conditional probability为 $0.8/0.2$。最优 log risk：

$$
h(0.8)
=-0.8\log0.8-0.2\log0.2
=0.5004024235.
$$

若 target 是 $0/1$，最优 square action 是 conditional mean，最小 risk 是 conditional variance：

$$
0.8(1-0.8)=0.16.
$$

stop-gradient 在 forward 是 identity，所以当前 scalar value 可相同；其 Jacobian 被定义为零，target branch 不接收该路径梯度，因而整个 vector field、fixed point 稳定性与 trajectory 都可能改变。

四象限的合法假说例子：

| linear probe | fine-tune | 可检验解释之一 |
|---|---|---|
| 高 | 高 | label 已线性可读且初始化也易适配 |
| 高 | 低 | aggressive tuning、domain mismatch 或遗忘破坏已有 feature |
| 低 | 高 | 信息非线性可读或主要提供 optimization initialization |
| 低 | 低 | 错误 invariance、任务缺失、严重 shift 或协议不合适 |

这些只是待 intervention 验证的解释，不是从两个分数逻辑推出的机制。

## 第 13 题解答：审计一篇自监督论文（10 分）

至少应追问：

1. batch 增大是否同步改变 negatives、devices、BN 与 learning-rate schedule；
2. positive/negative joint law 是否固定，是否有 false-negative correction；
3. source-unit 去重与跨 batch identity leakage；
4. InfoNCE 是 population、training 还是 selected validation loss；
5. covariance 在 backbone 还是 projection head、哪个 layer、如何 center/normalize；
6. $B<d$、mixed precision、epsilon 与 distributed covariance 的影响；
7. linear head、regularization、label budget 与 optimization 是否固定；
8. checkpoint/layer/seed 是否在 test 上选择；
9. task family 与 deployment shift 是否预注册；
10. compute、data exposure 与 parameter count 是否对齐。

最小合法 estimands：

- “更低 InfoNCE”只能指声明 candidate law 和 critic 下的 objective；
- “更高 rank”只能指声明 batch/layer/normalization 的 empirical spectrum；
- “更好 probe”只能指给定 task、head、label budget 与训练程序的有限样本 risk；
- “普遍迁移”需要 task distribution、shift family 与 aggregation，不由前三者推出。

最小消融矩阵：

1. 固定 candidate law，仅改变 optimizer batch accumulation；再固定 nominal batch，改变 negatives；
2. 报 complete/dimensional/spectral 与 nuisance-collapse 多种诊断，分别检查 backbone/projector；
3. 做 kNN—linear—MLP—partial/full tune 和完整 label-budget curve；
4. 全部 selection 留在 inner validation，outer test locked，报告 paired differences。

证据类型必须分层：InfoNCE inequality 是 theorem；本卷二元枚举是 finite exact computation；synthetic sweep 是 simulation；真实数据分数是 benchmark；“uniformity 促进语义”是 mechanistic hypothesis。即使结果全成立，也不能自动推出因果语义、所有任务充分、OOD 鲁棒、公平、校准或隐私安全。

## 第 14 题解答：陌生 AI pipeline 迁移（10 分）

以 RAG embedding 为例：

1. **task family：** 事实检索、长尾实体、时效问答、跨语种查询；shift 包括新语料时间段与新领域。
2. **source/pair law：** source unit 是文档/作者而非 chunk；positive 来自 query—supporting passage；hard negative 从同主题非支持段落采样，并标记可能相关的 false negatives。
3. **pretext estimand：** 声明 candidate retrieval cross-entropy；downstream estimand 是 query + gallery protocol 下的 Recall@K、MRR、answer utility 与 latency。
4. **诊断：** 改 negative sampler、batch K 与 temperature；检查 embedding spectrum、duplicate shortcut、语言/领域 subgroup；若用 teacher，审计更新与 pseudo-label confidence。
5. **capacity ladder：** BM25/base rate、frozen cosine、kNN、linear reranker、shallow cross-encoder、limited/full tune；在多档 query-label budget 下比较。
6. **selection：** time/group split；inner validation 选 checkpoint/index/head；最终未来时间窗 locked；相同 query split 做 paired bootstrap，按 source cluster 重采样。
7. **falsification：** 保持预训练 loss 与 covariance 几乎不变，交换 entity names 或移除 supporting spans；若 retrieval utility 崩溃，便推翻“语义充分”的强解释。
8. **延迟证据：** 48 小时改用跨语种 negative/pair law；14 天迁移到未见领域并重建合同，不复用 final test 调参。

评分重点不是选了 RAG，而是每个 claim 都能对应一个 estimand、一个可复现实验和一个会使结论失败的 intervention。
