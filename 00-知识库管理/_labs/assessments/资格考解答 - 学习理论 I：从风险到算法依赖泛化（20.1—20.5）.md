# 资格考解答 - 学习理论 I：从风险到算法依赖泛化（20.1—20.5）

> 本页是评分者材料，不是第一次作答时的提示。必须先冻结口试、两场闭卷、解析预测、时间戳与 hash，再执行 scorer nonce 指定的 blind run。读懂本页只说明答案可读，不代表通过 `LT-QUAL-01`，更不能替代五卷 `retained` 证据。

## 0. 评分总则：先审对象，再看公式

同一个公式只有在 predictor、loss、sample、randomness、event 与 statement type 全部匹配时才得主要步骤分。评分按以下优先级进行：

1. **对象正确：** Bayes rule、class optimum、ERM、Gibbs predictor 与 posterior mean 不得互换；
2. **量词正确：** fixed-$h$、uniform-over-$\mathcal H$、expectation 与 high probability 不得互换；
3. **数据时间线正确：** prior、class、bound route 和 selection rule 何时确定必须可审计；
4. **证明接缝正确：** concentration、union/symmetrization、algorithm dependence 与 closure 每一步都说明随机对象；
5. **数值正确：** 算术错误只扣第一次；若后续对象、方向与推理一致，可给过程分；
6. **证据边界正确：** finite enumeration、simulation 和一个 benchmark 都不能证明 universal theorem。

## 1. 口试参考要点

### 口试 1：从决策问题到 excess risk

给定 observation $X$、action space $\mathcal A$、loss $\ell(a,Y)$ 和联合分布 $P_{XY}$，一个 predictor $h:\mathcal X\to\mathcal A$ 的 population risk 是

$$
R(h)=\mathbb E_{(X,Y)\sim P}\ell(h(X),Y).
$$

Bayes rule $h^*$ 在所有可测规则中最小化 $R$，Bayes risk 是 $R^*=R(h^*)$。给定假设类 $\mathcal H$，class optimum $h_{\mathcal H}^*$ 最小化 $R$；两者之差

$$
R(h_{\mathcal H}^*)-R^*
$$

是 approximation error。训练样本 $S=(Z_1,\ldots,Z_m)$ 上的 empirical risk 是 $\widehat R_S(h)=m^{-1}\sum_i\ell(h,Z_i)$；ERM 是经验风险的最小化者。generalization gap 是 $R(A(S))-\widehat R_S(A(S))$，excess risk 是 $R(A(S))-R^*$。前者不是后者；要从 uniform deviation 闭合到 excess risk，还要插入 empirical optimality 和 class approximation。

### 口试 2：三种容量语言

- finite class 对 $h\in\mathcal H$ 做 union，复杂度是 $\log|\mathcal H|$；
- VC/growth 只数一个 finite sample 上可能出现的 restrictions，复杂度是 $\log\Pi_{\mathcal H}(n)$，再由 Sauer–Shelah 用 VC dimension 控制；
- Rademacher 先对 class 做 sample-dependent supremum，再对随机符号取期望；它测量给定样本上函数值与随机符号对齐的能力。

数据依赖的复杂度不等于允许先看同一数据、任意设计 representation/class，再把它当成固定 class。

### 口试 3：finite-class 主链

对每个固定 $h$，Hoeffding 给 tail；对有限 $\mathcal H$ union 得共同事件；在共同事件中 ERM 与 $h_{\mathcal H}^*$ 同时受控；最后用 ERM 的 empirical optimality 闭合。少了共同事件，就不能把 fixed-$h$ 结论应用到依赖 $S$ 的 $\widehat h$。

### 口试 4：同一个 ghost replacement 的两条去向

symmetrization 把 population expectation 换成 independent ghost sample，随后引入 Rademacher signs，最后由 class complexity 控制 supremum。stability 也用 replaced sample $S^{i\leftarrow Z_i'}$，但它不对整个 class 取 supremum，而是直接比较算法在相邻样本上的两个输出。入口都是 exchangeability；closure 分别是“类不能拟合随机符号”和“算法输出对替换不敏感”。

### 口试 5：三种“短描述”

- compression：用少量训练点和 side message 重构一个通常为 deterministic 的 hypothesis；给 frequentist high-probability risk certificate；
- PAC-Bayes：用 $\mathrm{KL}(Q\|P)$ 衡量 posterior 相对独立 prior 的描述成本；典型结论控制 Gibbs risk；
- information：用 $I(S;W)$ 衡量整个 randomized learning channel 泄露样本的信息；基本结论是 expected gap。

三者的 predictor、概率类型和前提不同，不能因为都出现“比特/信息”就直接互换。

### 口试 6：比较五个 bound 前的合同

至少核对：同一 loss range、同一 target distribution、同一 deployed predictor、同一 sample/certificate split、同一 event、同一 one/two-sided direction、同一 risk quantity、同一 randomness conditioning、同一 class/prior timeline、同一 confidence budget。若要事后取 minimum，必须预注册路线、在共同事件上 union，或用独立 validation/certificate sample 选择。

## 2. A 区：对象路由与量词合同（15 分）

### 第 1 题解答：七个声明的最小路由（7 分）

| 声明 | 首要工具 | 合法性所缺条件 | 结论类型 |
|---|---|---|---|
| 固定部署模型的验证损失 | fixed-$h$ concentration | predictor 在验证集前冻结；i.i.d.；bounded/sub-Gaussian loss | fixed predictor, high probability |
| 从 $N$ 个候选中选 ERM | finite union | 候选集合在样本前固定或选择成本已支付；bounded loss | uniform class, high probability |
| 无限二分类族的有限 labeling | VC/growth | restriction 作用在明确的 finite sample；finite VC 才能用 Sauer–Shelah | uniform class, combinatorial |
| norm-bounded scores 经 surrogate | Rademacher + contraction | score class、norm radius、sample、loss Lipschitz 常数与 range 已声明 | uniform class, expected 或 high probability |
| replace-one 后 loss 几乎不变 | stability | adjacency、seed coupling、所有 test point 与 loss range明确 | expected gap；另加条件才有 tail |
| 随机 posterior 接近 prior | PAC-Bayes | prior 在 certificate sample 前独立确定；$Q\ll P$；Gibbs predictor | posterior-uniform, high probability |
| 输出泄露少量样本信息 | information | 定义 joint law $P_{SW}$、product reference、fixed-$w$ sub-Gaussian loss | expected gap |

关键不是给每句话贴标签，而是知道工具的输出是什么。例如 PAC-Bayes-kl 通常不直接控制 posterior mean；information radius 通常不是“以 $1-\delta$ 概率成立”的部署风险上界。

### 第 2 题解答：阈值问题的十二层账本（8 分）

| 层 | 本题合同 |
|---|---|
| 任务 | $X\sim\mathrm{Unif}\{0,\ldots,d-1\}$，$Y=h_{t_*}(X)$，0—1 loss，目标是 population classification risk |
| 决策 | Bayes rule 是 $h_{t_*}$，Bayes risk 为 0；$h_{t_*}\in\mathcal H$，故 class risk 也为 0；algorithm 输出 lexicographic ERM $h_{A(S)}$ |
| 采样 | $S\sim P^m$ i.i.d.；exact track 还引入 independent $Z_i'$；certificate track 使用另一份 balanced deterministic design 作数值校准 |
| 容量 | $|\mathcal H|=d+1$；在有序点集上的 restrictions 是单次 0→1 跳变；VC dimension 为 1，domain 上 growth 为 $d+1$ |
| 经验过程 | fixed threshold concentration、对 thresholds 的 uniform event，或 ghost/symmetrization；不得把 output 当 fixed-$h$ |
| 算法 | tie-breaking 选择最小 $t$；replace-one 必须沿同一 tie-break；compression encoder/decoder 也必须固定 |
| 分布 | PAC-Bayes 的 prior $P$ 与 posterior $Q$ 是 threshold index 上的分布；information 的 channel 是 $S\mapsto T=A(S)$ |
| 预测者身份 | ERM 是 deterministic threshold；Gibbs 每次从 $Q$ 抽 threshold；posterior mean score 不是二者之一 |
| 概率 | exact track 给 expected gap；finite/compression/PAC-Bayes 给 high-probability certificate；两者不是同一 event |
| 选择 | 五条 route 若事后取最小值需共同 $\delta$、预注册或独立选择数据 |
| 证书质量 | 一个证书可合法却空洞；可计算却不解释机制；tight 与 universal 也不是同义词 |
| AI 迁移 | threshold index 类比 model/checkpoint；tie-break 类比 optimizer/seed；$Q$ 类比 randomized weights；必须重新验证真实神经网络的 theorem hypotheses |

tie-breaking 不是实现细节。没有它，$A(S)$ 不是单值函数，output channel、mutual information、replace-one stability 和 compression decoder 都未定义。small-sample 枚举与 large-sample certificate 的 sample、statement type 和 predictor 不同，所以不能把它们放进一个未经校准的 minimum。

## 3. B 区：统一有限模型的精确计算（20 分）

### 第 3 题解答：全部样本上的 ERM、ghost 与信息（10 分）

#### 3.1 输出由最大负类点决定

真实阈值为 3，所以 $0,1,2$ 是负类，$3,4$ 是正类。一个 threshold $t$ 与样本一致，当且仅当

$$
\max\{x_i:x_i<3\}<t\le \min\{x_i:x_i\ge3\},
$$

其中空集合要单独处理。正类最小值至少为 3，因此 lexicographic 最小一致 threshold 只看最大的负类点 $M_-$：

$$
T=A(S)=
\begin{cases}
0,&\text{样本中没有负类点},\\
M_-+1,&\text{否则}.
\end{cases}
$$

因此 $T\in\{0,1,2,3\}$，不会输出 4 或 5。

#### 3.2 输出分布

六次独立抽样且每点概率 $1/5$：

$$
\begin{aligned}
\Pr(T=0)&=(2/5)^6=0.004096,\\
\Pr(T=1)&=(3/5)^6-(2/5)^6=0.042560,\\
\Pr(T=2)&=(4/5)^6-(3/5)^6=0.215488,\\
\Pr(T=3)&=1-(4/5)^6=0.737856,\\
\Pr(T=4)&=\Pr(T=5)=0.
\end{aligned}
$$

例如 $T=2$ 等价于最大负类点为 1：所有样本点都落在 $\{0,1,3,4\}$，且至少一次取到 1。因此其概率是 $(4/5)^6-(3/5)^6$；直接按最大负类点写事件，可以避免把点值与 threshold index 错位。

#### 3.3 empirical risk、population risk 与 gap

算法总选一个 consistent threshold，故

$$
\widehat R_S(T)=0\quad\text{对每个 }S,qquad
\mathbb E\widehat R_S(T)=0.
$$

均匀 domain 上，两个阈值之间恰有 $|t-3|$ 个点预测不同，所以

$$
R(h_t)=\frac{|t-3|}{5}.
$$

于是

$$
\begin{aligned}
\mathbb ER(T)
&=\frac35(0.004096)+\frac25(0.042560)+\frac15(0.215488)\\
&=0.0625792.
\end{aligned}
$$

expected signed generalization gap 也是 $0.0625792$，六位小数为 **0.062579**。

#### 3.4 ghost replacement identity

令 $S^{i\leftarrow Z_i'}$ 把 $Z_i$ 换成独立同分布的 $Z_i'$。exchangeability 给

$$
\mathbb E\ell(A(S),Z_i')
=\mathbb E\ell(A(S^{i\leftarrow Z_i'}),Z_i).
$$

左边对 $Z_i'$ 条件期望就是 $\mathbb ER(A(S))$；而 $m^{-1}\sum_i\mathbb E\ell(A(S),Z_i)=\mathbb E\widehat R_S(A(S))$。所以

$$
\mathbb E[R(A(S))-\widehat R_S(A(S))]
=\frac1m\sum_{i=1}^m\mathbb E\!left[
\ell(A(S^{i\leftarrow Z_i'}),Z_i)-\ell(A(S),Z_i)
\right].
$$

这一步只用 i.i.d./exchangeability，没有用 stability。代入刚算出的 risk 得 ghost replacement expectation **0.0625792**。

#### 3.5 output information

$T$ 是 $S$ 的 deterministic function，所以 $H(T\mid S)=0$，从而

$$
I(S;T)=H(T)=-\sum_t p_t\log p_t=0.7119287491\ \text{nat}.
$$

对 $[0,1]$ loss 可取 $\sigma=1/2$ 的 Hoeffding sub-Gaussian proxy，信息半径为

$$
\sqrt{\frac{2(1/2)^2I(S;T)}m}
=\sqrt{\frac{I(S;T)}{2m}}
=0.2435721572.
$$

它合法但比真实 expected gap $0.0625792$ 松；它不是 high-probability risk certificate。

#### 3.6 direct uniform stability 的反例

取

$$
S=(3,3,3,3,3,3),qquad
S'=(2,3,3,3,3,3).
$$

$S$ 没有负类点，故 $A(S)=0$；$S'$ 的最大负类点是 2，故 $A(S')=3$。测试点 $x=0$ 的真标签是 0：$h_0(0)=1$ 错，$h_3(0)=0$ 对，loss difference 为 1。0—1 loss 的差不可能超过 1，因此 direct uniform stability 恰为

$$
\beta_m=1.
$$

这说明平均泛化可以很好而 worst-case replace-one stability 完全空洞。

### 第 4 题解答：五本证书账（10 分）

#### 4.1 六个 threshold 与 Gibbs risk

对 $t=0,\ldots,5$，均匀 domain 上的 true risks 也是 balanced sample 上的 empirical risks：

$$
(0.6,\ 0.4,\ 0.2,\ 0,\ 0.2,\ 0.4).
$$

因此随机抽 $t\sim Q$ 的 Gibbs risk 为

$$
\widehat R(Q)=R(Q)
=0.02(0.6)+0.03(0.4)+0.10(0.2)+0.70(0)+0.10(0.2)+0.05(0.4)
=0.084.
$$

#### 4.2 finite-union certificate

对六个 fixed thresholds 使用 two-sided Hoeffding 并 union：以概率至少 $1-\delta$，同时对所有 $t$，

$$
|R(h_t)-\widehat R(h_t)|
\le \sqrt{\frac{\log(2|\mathcal H|/\delta)}{2m_c}}
=\sqrt{\frac{\log(240)}{400}}
=0.1170538223.
$$

共同事件上对任意 posterior $Q$ 取加权平均仍成立，因此 Gibbs 上界为

$$
R(Q)\le0.084+0.1170538223=\boxed{0.2010538223}.
$$

这里允许 $Q$ data-dependent，是因为原事件已经对全部 thresholds 同时成立；不是把 fixed-$h$ bound 直接套给 $Q(S)$。

#### 4.3 compression certificate

若 fixed decoder 用一个样本点和一个 side bit 重构 consistent classifier，则 $k=1$、$|\mathcal Q|=2$。对 risk 至少为 $\varepsilon$ 的某个重构器，其未被剩余 $m_c-k$ 个点击中的概率至多 $(1-\varepsilon)^{m_c-k}$。再 union over messages 可取

$$
R(\widehat h)
\le\frac{\log m_c+\log2+\log(1/\delta)}{m_c-1}
=\frac{\log200+\log2+\log20}{199}
=\boxed{0.0451617931}.
$$

它控制由该 fixed compression scheme 重构的 consistent deterministic classifier，不控制上面的 Gibbs $Q$。因此不能因为 0.045 小于 0.201 就宣称 Gibbs risk 更小。

#### 4.4 PAC-Bayes-kl certificate

先算

$$
\mathrm{KL}(Q\|P)=\sum_{t=0}^5Q_t\log\frac{Q_t}{1/6}
=0.7483461792.
$$

采用

$$
\operatorname{kl}(\widehat R(Q)\|R(Q))
\le\frac{\mathrm{KL}(Q\|P)+\log((m_c+1)/\delta)}{m_c},
$$

右侧 budget 为

$$
c=\frac{0.7483461792+\log(201/0.05)}{200}
=0.0452369168.
$$

求最大的 $r\in[0.084,1]$ 使 $\operatorname{kl}(0.084\|r)\le c$，得到

$$
R(Q)\le\operatorname{kl}^{-1}_+(0.084,c)
=\boxed{0.1916574890}.
$$

#### 4.5 五路线共同选择预算

若五条 high-probability route 均预注册并用等权 union，总失败概率 $0.05$ 要给每条 $0.01$。PAC-Bayes budget 变为

$$
c_{\rm joint}
=\frac{0.7483461792+\log(201/0.01)}{200}
=0.0532841064,
$$

相应 endpoint 是

$$
\boxed{0.2029084707}.
$$

#### 4.6 可比性总账

| 数值 | predictor | sample / randomness | statement type | 能否与 Gibbs PAC-Bayes 直接比 |
|---:|---|---|---|---|
| 0.201054 | 任意 $Q$ 的 Gibbs | certificate sample；共同 finite event | high probability | 可以，若同一 loss/sample/confidence |
| 0.045162 | compression decoder 的 deterministic ERM | consistent sample；fixed code | high probability | 不可以，predictor 不同 |
| 0.191657 | Gibbs $Q$ | independent prior；posterior randomization | high probability | 基准自身 |
| 0.202908 | Gibbs $Q$ | 五路线共同预算 | high probability | 可以，但置信预算不同 |
| 0.243572 | small-sample lexicographic ERM 的 gap radius | $m=6$ output channel | expectation | 不可以，sample/predictor/type 都不同 |

## 4. C 区：三条跨卷证明主链（30 分）

### 第 5 题解答：finite → VC/growth → Rademacher（10 分）

#### 5.1 fixed-$h$ 到 finite-class uniform event

若 $\ell(h,Z)\in[0,1]$，对固定且与 $S$ 独立的 $h$，Hoeffding 给

$$
\Pr_S\{|R(h)-\widehat R_S(h)|>\varepsilon\}
\le2e^{-2m\varepsilon^2}.
$$

对有限且在抽样前固定的 $\mathcal H$ union：

$$
\Pr_S\left\{\sup_{h\in\mathcal H}|R(h)-\widehat R_S(h)|>\varepsilon\right\}
\le2|\mathcal H|e^{-2m\varepsilon^2}.
$$

令右侧等于 $\delta$，得到

$$
\sup_h|R(h)-\widehat R_S(h)|
\le\sqrt{\frac{\log(2|\mathcal H|/\delta)}{2m}}
$$

以概率至少 $1-\delta$ 成立。若 $\widehat h$ 是 ERM，则在该共同事件内

$$
R(\widehat h)-R(h_{\mathcal H}^*)
\le [R(\widehat h)-\widehat R(\widehat h)]
+[\widehat R(h_{\mathcal H}^*)-R(h_{\mathcal H}^*)]
\le2\varepsilon.
$$

中间的 $\widehat R(\widehat h)-\widehat R(h_{\mathcal H}^*)\le0$ 被 empirical optimality 消掉。

#### 5.2 从无限函数到 finite restrictions

binary class 在 $n$ 个点 $x_{1:n}$ 上的 restriction set 是

$$
\mathcal H|_{x_{1:n}}
=\{(h(x_1),\ldots,h(x_n)):h\in\mathcal H\},
$$

growth function 为

$$
\Pi_{\mathcal H}(n)=\sup_{x_{1:n}}|\mathcal H|_{x_{1:n}}|.
$$

在 ghost-sample proof 中所有经验差只依赖 $2m$ 个点上的 labeling，因此即使 $\mathcal H$ 无限，真正 union 的候选至多是 $\Pi_{\mathcal H}(2m)$。

若 $\operatorname{VC}(\mathcal H)=v<\infty$，Sauer–Shelah 给

$$
\Pi_{\mathcal H}(n)\le\sum_{j=0}^v\binom nj
\le (en/v)^v\quad(n\ge v).
$$

代回 symmetrized tail 可得量级

$$
\sup_h|R(h)-\widehat R(h)|
=O\!\left(\sqrt{\frac{v\log(m/v)+\log(1/\delta)}m}\right).
$$

常数随采用的 symmetrization/tail lemma 变化；答题关键是 $2m$ restriction、随机对象和 supremum 位置正确。

#### 5.3 ghost 到 empirical Rademacher

令 $\mathcal F=\{z\mapsto\ell(h,z):h\in\mathcal H\}$，$S'$ 独立同分布。则

$$
\begin{aligned}
\mathbb E_S\sup_{f\in\mathcal F}(R(f)-\widehat R_S(f))
&\le\mathbb E_{S,S'}\sup_f(\widehat R_{S'}(f)-\widehat R_S(f))\\
&=\mathbb E_{S,S',\sigma}\sup_f\frac1m\sum_{i=1}^m
\sigma_i(f(Z_i')-f(Z_i))\\
&\le2\,\mathbb E_S\widehat{\mathfrak R}_S(\mathcal F),
\end{aligned}
$$

其中

$$
\widehat{\mathfrak R}_S(\mathcal F)
=\mathbb E_\sigma\sup_{f\in\mathcal F}\frac1m\sum_i\sigma_i f(Z_i).
$$

第一步是 Jensen/ghost，第二步用交换对称性引入 Rademacher signs，最后一步把 ghost 与 original 两项分别上界。再对 bounded-difference function 做 concentration，可把 expected uniform gap 升为 high probability。

若 $\phi_i$ 都是 $L$-Lipschitz，且适当中心化如 $\phi_i(0)=0$，contraction lemma 给

$$
\widehat{\mathfrak R}_S(\phi\circ\mathcal G)
\le L\widehat{\mathfrak R}_S(\mathcal G)
$$

（具体版本可能带常数 2）。这就是从 score class 到 Lipschitz surrogate loss class 的接口。

finite bound 在小而明确的候选集上可能最好；VC 忽略参数化细节但覆盖无限 binary class；Rademacher 会利用当前 sample、norm 与 margin，可能更细。可如果 class/representation 在看过同一 $S$ 后自由设计，条件于所选 class 的 theorem 一般不再自动成立，必须把选择纳入总 class、使用条件复杂度定理或 sample split。

### 第 6 题解答：stability 与 information（10 分）

#### 6.1 replace-one stability proof

设 $S^{i\leftarrow Z_i'}$ 替换第 $i$ 个点。ghost identity 已给出

$$
\mathbb E\operatorname{gen}(A,S)
=\frac1m\sum_i\mathbb E[
\ell(A(S^{i\leftarrow Z_i'}),Z_i)-\ell(A(S),Z_i)].
$$

若算法 direct replace-one uniformly stable：对所有相邻 $S,S'$ 和所有 $z$，

$$
|\ell(A(S),z)-\ell(A(S'),z)|\le\beta_m,
$$

则逐项绝对值至多 $\beta_m$，所以

$$
|\mathbb E\operatorname{gen}(A,S)|\le\beta_m.
$$

随机算法时必须说明用同一 seed coupling，或 stability 定义是否已对 algorithm randomness 取期望；二者不是自动等价。

#### 6.2 information proof

令 $W$ 为学习输出，joint law 是 $P_{SW}$；构造 product reference $P_S\otimes P_W$，其中 $W$ 保持相同 marginal 但与 $S$ 独立。记

$$
G(S,W)=R(W)-\widehat R_S(W).
$$

在 product law 下，条件于 fixed $W=w$，$G(S,w)$ 均值为 0，且若单点 loss 是 $\sigma$-sub-Gaussian，则样本均值之差是 $\sigma/\sqrt m$-sub-Gaussian：

$$
\log\mathbb E_{P_SP_W}e^{\lambda G}
\le\frac{\lambda^2\sigma^2}{2m}.
$$

Donsker–Varadhan variational inequality 对 joint 相对 product 给

$$
\lambda\mathbb E_{P_{SW}}G
\le \mathrm{KL}(P_{SW}\|P_SP_W)
+\log\mathbb E_{P_SP_W}e^{\lambda G}.
$$

第一项正是 $I(S;W)$，故

$$
\mathbb E G\le\frac{I(S;W)}\lambda+\frac{\lambda\sigma^2}{2m}.
$$

取 $\lambda=\sqrt{2mI(S;W)/\sigma^2}$ 得

$$
\mathbb E G\le\sqrt{\frac{2\sigma^2I(S;W)}m}.
$$

对 $-G$ 重复一次，得到绝对值版本。这里 product law 用来恢复“fixed predictor 对 fresh sample”的 concentration，joint law 则描述训练依赖；KL 正是从 product 移回 joint 的代价。

本题阈值 ERM 同时有 $\beta_m=1$ 和有限 $I(S;T)=0.711929$，毫不矛盾：stability 是所有相邻样本、所有测试点上的 worst case；MI 是输入分布加权的平均 channel dependence。有限 MI 不推出小的 worst-case stability；worst-case stability 小也不自动给 output entropy 或 MI 的精确值。

### 第 7 题解答：compression 与 PAC-Bayes（10 分）

#### 7.1 exact compression proof

固定 encoder 从 $m$ 个训练例中选 $k$ 个 index，并输出 $q\in\mathcal Q$；fixed decoder 据此重构 $h$。若重构器 true risk $R(h)>\varepsilon$，而它又与其余 $m-k$ 个独立训练点全部一致，则概率至多

$$
(1-\varepsilon)^{m-k}.
$$

可能的 index subset 有 $\binom mk$ 个，side messages 有 $|\mathcal Q|$ 个。union 得 failure probability

$$
|\mathcal Q|\binom mk(1-\varepsilon)^{m-k}
\le |\mathcal Q|\binom mk e^{-(m-k)\varepsilon}.
$$

令其不超过 $\delta$：

$$
R(h)\le
\frac{\log\binom mk+\log|\mathcal Q|+\log(1/\delta)}{m-k}.
$$

proof 依赖 fixed scheme、exact consistency 和未压缩点没有被 encoder 当作自由信息渠道。

#### 7.2 PAC-Bayes-kl proof spine

对 fixed $h$ 的 Bernoulli loss，binomial method 给一个指数矩上界，例如

$$
\mathbb E_S\exp\{m\operatorname{kl}(\widehat R_S(h)\|R(h))\}\le m+1.
$$

先对 $h\sim P$ 积分，再由 Markov，以概率至少 $1-\delta$ 有

$$
\mathbb E_{h\sim P}e^{m\operatorname{kl}(\widehat R(h)\|R(h))}
\le\frac{m+1}{\delta}.
$$

在这个只依赖 $S$ 的共同事件上，对任意 $Q\ll P$ 使用 Donsker–Varadhan：

$$
\mathbb E_Q f(h)
\le\mathrm{KL}(Q\|P)+\log\mathbb E_Pe^{f(h)}.
$$

取 $f(h)=m\operatorname{kl}(\widehat R(h)\|R(h))$，再用 Bernoulli KL 的 joint convexity：

$$
m\operatorname{kl}(\widehat R(Q)\|R(Q))
\le\mathbb E_Qm\operatorname{kl}(\widehat R(h)\|R(h)),
$$

从而得到

$$
\operatorname{kl}(\widehat R(Q)\|R(Q))
\le\frac{\mathrm{KL}(Q\|P)+\log((m+1)/\delta)}m.
$$

#### 7.3 相同解释与不可混同处

$\log\binom mk+\log|\mathcal Q|$ 是离散 codebook 中选一条 message 的 worst-case 长度；$\mathrm{KL}(Q\|P)$ 是 posterior 相对 reference code 的平均额外描述成本。两者都体现“数据不能低成本地从大量互不相关的 predictor 中随意挑一个”。

但 compression 常控制一个由训练点子集重构的 deterministic、realizable predictor；PAC-Bayes 控制 randomized Gibbs predictor，允许非零 empirical risk。PAC-Bayes 需要 prior timeline 和 $Q\ll P$；compression 需要 fixed encoder/decoder、sample subset 语义和 consistency。一个十参数网络仍可能需要全部样本的高精度实数统计，参数少不等于 sample compression。反之，若 $Q=P$ 则 KL 为 0，但当 $\widehat R(Q)$ 接近 1/2 或 $m$ 很小时，PAC-Bayes endpoint 仍可能接近 1，合法却空洞。

## 5. D 区：证书审计与反例（20 分）

### 第 8 题解答：五条声明（10 分）

1. **错误。** empirical risk 0 只表示训练点未发现错误。若 class 大或算法记忆样本，population risk 可很大。修复：加 realizability/compression/capacity/stability 等合法 generalization 条件和置信度。
2. **错误。** VC dimension 是 class-level combinatorial capacity；uniform stability 是 algorithm-level adjacency 性质。本题 threshold class VC=1，但 lexicographic ERM 的 direct stability 是 1，正是反例。
3. **条件不足。** empirical Rademacher complexity 对预先给定或由合法条件定理覆盖的 class 有效。若 representation class 用同一数据自由设计，要把 meta-class/selection 纳入 supremum、支付信息/union 成本或另用 split。
4. **错误。** “公开”不等于与 certificate sample 独立。若公开预训练数据包含、推断或由 certificate 样本选择，prior timeline 被破坏。修复：数据 provenance 审计、独立 holdout、data-dependent prior theorem 或支付相应成本。
5. **错误。** $I(S;W)\le\log|\mathcal W|$ 只给一个可能巨大的上界；量化大模型的 codebook 仍指数巨大，而且 expected-gap radius 可能超过 loss range。修复：实际 channel-level MI 上界、足够大的 $m$、正确 sub-Gaussian proxy，并明确只控制 expected gap。

### 第 9 题解答：五个 bound 的选择协议（10 分）

比较前至少填写：

1. target distribution / shift assumption；
2. loss、range 或 tail proxy；
3. deterministic/Gibbs/MAP/mean/ensemble predictor；
4. train、certificate、validation、test 的身份；
5. sample size 与 dependence；
6. algorithm/data randomness 及 conditioning；
7. expected signed gap、absolute gap、tail、risk 或 excess risk；
8. one-sided/two-sided 与 confidence $\delta$；
9. class/prior/route 的确定时间；
10. hyperparameter/checkpoint/seed/bound route selection budget。

VC 与 Rademacher 通常控制一个 class 的 uniform gap/risk；SGD stability 常给训练算法的 expected gap；PAC-Bayes 通常给 Gibbs risk 的 high-probability bound；information 的经典形式是 randomized output 的 expected gap。故五个裸数很可能不在同一坐标系，不能推出 deterministic deployment risk $\le0.05$。

三种合法协议是：

- **预注册：** 看到 certificate data 前指定唯一 primary theorem、predictor 和超参数；其他只作 secondary analysis；
- **共同事件：** 给各路线 failure weight $\delta_j$，满足 $\sum_j\delta_j\le\delta$，只在 intersection event 中取合法 bound 的 minimum；
- **sample split：** 在 train/selection split 上选模型和 bound，在未使用的 certificate split 上只评估被冻结的目标；最后 test 仍只作一次外部验证。

若 information theorem 只有 expected signed gap，最多声明

$$
|\mathbb E[R(W)-\widehat R_S(W)]|\le0.05,
$$

不能声明“当前已部署模型以高概率 risk 不超过 0.05”，也不能把 0.05 直接加到某次 observed training loss 后当 deployment certificate。

四种评价：legal 检查 theorem hypotheses；nonvacuous 检查上界是否低于 loss trivial range；tight 与 independent estimate/known exact value 比较 slack；explanatory 需要干预机制变量时 gap 按预测变化。对应义务可以是合同审计、数值 endpoint、exact finite calibration、replace-one/prior/complexity controlled intervention。

## 6. E 区：陌生 AI 研究合同（15 分）

### 第 10 题解答：instruction-tuned 模型协议（15 分）

一份可得满分的方案可以如下组织。

#### 6.1 对象与量词

- observation unit 是完整 prompt/context，response 是 token sequence；先定义去重规则，避免同一对话跨 split；
- target distribution 是明确来源、时间窗、语言和安全策略下的 deployment prompt law，而不是笼统“互联网”；
- primary loss 可以是截断到 $[0,1]$ 的 sequence loss 或预注册 task failure indicator；token-average loss 是另一个对象；
- algorithm 包括 public checkpoint、LoRA parameterization、optimizer、data order、seed、early stopping 和所有搜索规则；
- deployed predictor 若是 deterministic posterior mean，就不能直接把 Gibbs theorem 当作其证书；资源预算包括数据、搜索次数、compute 和 precision。

#### 6.2 theorem 候选及 failure witness

**候选 A：PAC-Bayes-kl。** Hypotheses：certificate examples i.i.d./exchangeable；prior 在 certificate data 前确定且 provenance 可审计；posterior 对 prior absolute continuous；bounded loss；最终预测者为 Gibbs。Conclusion：以 $1-\delta$ 概率同时对 posterior 成立的 Gibbs-risk endpoint。Proof interface：fixed-weight binomial moment → prior integration → Markov → DV → joint convexity。不可验证点可能是 prompt i.i.d. 和 prior contamination。failure witness：prior 或 posterior variance 是看过同一 certificate loss 后选择，却没有支付搜索成本；或者部署 mean 而实验只抽 Gibbs。

**候选 B：algorithmic stability。** Hypotheses：完整 fine-tuning algorithm 在 replace-one dataset 下采用明确 seed coupling，测试 loss change 至多 $\beta_m$，并满足所需 tail 条件。Conclusion：首先是 expected gap；更强 theorem 才给 high probability。Proof interface：ghost replacement + adjacency bound。不可验证点是 nonconvex training 的全局 worst-case guarantee。failure witness：替换一例引发 checkpoint/early-stopping 分支跳变，某测试点 loss 差接近 1。

**候选 C：norm/Rademacher。** 若选用，必须把 base model、LoRA rank/class、norm constraint、Lipschitz surrogate 和 representation 的数据依赖写入 class。failure witness 是 rank/norm/representation 用同一 certificate sample 大规模搜索，但 bound 只覆盖最后一个 class。

information 可以作为第四候选，但要给整个 learning channel 的真实 MI 上界；gradient-noise proxy 或参数 entropy 不是自动等于 $I(S;W)$。

#### 6.3 数据治理与选择

建立 public pretraining provenance 清单和 near-duplicate scan；private instruction data 只训练；selection split 搜索 rank、optimizer、step size、checkpoint、temperature、posterior variance；冻结模型、posterior、primary bound route 后才打开 certificate split；test split 只做一次外部效度检查。若多路线同报，预先分配 $\delta_j$ 或报告未校正的 exploratory 状态，不得悄悄挑最小。

#### 6.4 预测者身份桥

对 $W\sim Q$ 每次重采样并预测是 Gibbs；固定最大 posterior density 是 MAP；$\mathbb E_QW$ 后前向是 posterior-mean weights；平均多个网络的 predictive probabilities 是 ensemble。非线性网络中

$$
f_{\mathbb E W}(x)\ne\mathbb E_Wf_W(x)
$$

通常成立。因此若 theorem 只控制 Gibbs，部署 mean 需要额外 deterministic bridge、直接重新认证或改为真正部署 Gibbs/ensemble。

#### 6.5 误差总账

总风险相对 Bayes 的差至少分成：class/LoRA approximation；finite-data estimation/generalization；optimizer 未达经验最优的 optimization；mixed precision、quantization、sampling 的 numerical/implementation；deployment prompt、policy 和 adversarial shift。bound 只关闭其中一项时，不得声称“解释全部泛化”。

#### 6.6 实验与反事实

- replace-one、group deletion 与 label/noise intervention，多 seed 测 output/loss distribution，而不把平均敏感度冒充 worst-case theorem；
- 在冻结 certificate 前定义 prior families，报告 $\mathrm{KL}(Q\|P)$、empirical Gibbs risk 和 inverse-kl endpoint；
- 用 compression/noise 或可证明 channel 估计做 information proxy，同时明确 proxy-to-MI 缺口；
- 扫 rank/norm/margin 时同时保存 search count 与 joint confidence；
- negative controls：随机标签、污染 prior、随机 posterior、打乱 prompt grouping、部署 mean 对 Gibbs 的差异。

#### 6.7 证据与来源边界

theorem 在 hypotheses 成立时给全称/概率结论；finite enumeration 只验证 finite fixture 并可发现实现错误；simulation 给选定生成机制下的经验分布；benchmark 只支撑其 sampling frame；博客适合定位直觉、术语和原始论文，不能代替原 theorem 的条件与证明。每条核心结论应回链教材/论文的一手来源，并记录版本、页码/定理号和访问日期。
