# 阶段测验 - 校准、不确定性与分布偏移（20.8）

> [!abstract] 这卷真正考什么
> 不考“列举 uncertainty/OOD 方法”，而考能否把 **joint law—predictive object—identifying assumption—certificate—selection—decision utility—shift set** 分账。accuracy、proper score、calibration、predictive spread、marginal coverage、importance-weighted target risk、domain discrepancy、OOD ranking 与 worst-group risk不是同一个目标。

## 二、25 分钟卷级口试

每题 5 分钟：

1. 区分 calibration、proper score、accuracy 与 cost-sensitive decision，并各给一个排序反例；
2. 推导 total variance 与 classification predictive-entropy decomposition，说明 aleatoric/epistemic 对信息集和模型合同的依赖；
3. 口述 split conformal 的 $m+1$ rank proof、量词与 exchangeability 边界；
4. 区分 covariate、label、concept 与 support shift，说明仅有 unlabeled target 时哪些量通常不可识别；
5. 解释 domain-adaptation bound 中 source risk、$\mathcal H\Delta\mathcal H$ discrepancy 与 joint ideal error，为什么 OOD AUROC 不能证明鲁棒或因果。

通过要求：至少 4/5 同时说清对象、假设、量词、选择时间线与不能推出。

## 三、240 分钟闭卷（100 分）

### A 部分：对象与协议（20 分）

### 第 1 题：八层可靠性账本（5 分）

为医疗分类器或 LLM 风险路由系统填写：

1. source/target joint law 与 sampling unit；
2. predictive object（probability、distribution、set、interval、score/action）；
3. information set 与 uncertainty decomposition；
4. calibration/coverage/shift 的 identifying assumptions；
5. theorem、finite computation、simulation 与 benchmark certificate；
6. calibration/threshold/model/shift selection 时间线；
7. cost/reject/coverage/latency 等 decision utility；
8. declared shift/attack/group set 与 deployment monitoring。

每层给一个省略后会改变结论的例子。

### 第 2 题：七种“可靠”（5 分）

分别定义或说明：classification accuracy、probability calibration、strictly proper risk、predictive interval coverage、selective risk、OOD ranking、worst-group robustness。构造至少两个“一项好、另一项坏”的反例。

### 第 3 题：不确定性合同（5 分）

写出 hierarchical predictive model 的 aleatoric/epistemic 总方差分解；分类中写出 predictive entropy、expected conditional entropy 与 mutual information。说明“不可约”“epistemic”“OOD”为什么都相对于信息集、模型族、posterior/ensemble construction 与 shift set。

### 第 4 题：选择与部署时间线（5 分）

团队在 validation/test 上反复选择 temperature、ensemble size、conformal score、coverage level、OOD score、threshold 与 domain-adaptation checkpoint：

1. 画出污染路径；
2. 给出 inner selection—locked calibration—locked outer test 协议；
3. 说明 conformal calibration set、probability calibration set 与 threshold-validation set 能否随意复用；
4. 区分 procedure-level risk 与最终 full-data refit predictor 的风险。

### B 部分：三轨精确计算（30 分）

### 第 5 题：Calibration 与 proper scores（8 分）

四个等质量 reliability bins 的预测概率与真实事件率为

$$
p=(0.1,0.4,0.7,0.9),\qquad
q=(0.2,0.4,0.6,0.8),
$$

每 bin 有 5 个样本且事件数与 $q$ 一致。

1. 计算 threshold $0.5$ accuracy 与 population-bin ECE；
2. 计算 Brier risk 与 log loss；
3. 计算 uncertainty、resolution、reliability 并核对 Brier 分解；
4. 说明 ECE 为零为何仍不等于 sharp、accurate 或 utility-optimal。

### 第 6 题：Posterior predictive 与 ensemble variance（7 分）

两 component predictive Gaussians 权重 $(0.4,0.6)$、均值 $(-1,2)$、conditional variances $(0.5,1.5)$。

1. 计算 mixture predictive mean；
2. 用总方差分解计算 within/aleatoric、between/epistemic 与 total variance；
3. 解释 mixture 为什么一般不是单 Gaussian；
4. 分类时说明 probability averaging 与 logit averaging为何不同，并指出 deep ensemble spread 不能自动解释为 exact Bayesian epistemic uncertainty。

### 第 7 题：Split conformal 的有限秩（8 分）

calibration nonconformity scores 已排序：

$$
(0.1,0.2,0.25,0.4,0.55,0.7,0.9),
$$

$m=7,\alpha=0.25$，点预测为 $3.2$。

1. 计算 $k=\lceil(m+1)(1-\alpha)\rceil$ 与 $\widehat q$；
2. 写出 absolute-residual interval；
3. 无 ties 且 exchangeable 时枚举新样本 rank，计算有限 rank coverage；
4. 明确 marginal coverage 的概率对谁取、不能推出哪些 conditional/group/shift guarantees；
5. 说明 calibration set 自适应复用会破坏什么。

### 第 8 题：Covariate shift、权重尾与 clipping（7 分）

在 $X\in\{a,b,c\}$ 上：

$$
p_s=(0.5,0.4,0.1),\quad
p_t=(0.2,0.3,0.5),\quad
\ell=(0.1,0.3,0.8).
$$

1. 计算 source risk、importance weights 与 target/weighted risk；
2. 对 source sample size $n=100$，用 $n/E_s[w^2]$ 计算 population-design ESS；
3. 将 weights clip 到 2，计算 unnormalized clipped risk 与 self-normalized risk；
4. 说明 overlap、ratio estimation、weighted selection 与 concept shift 各自怎样使公式或有限样本证书失效。

### C 部分：推导、反例与边界（30 分）

### 第 9 题：Shift taxonomy 与可识别性（8 分）

从 joint factorizations

$$p(x,y)=p(x)p(y\mid x)=p(y)p(x\mid y)$$

定义 covariate、label 与 concept shift。证明 covariate-shift target-risk identity；推导 label-shift confusion-matrix equation。给出 support violation 和“仅看 unlabeled target 无法区分 label/concept shift”的反例。

### 第 10 题：Domain adaptation bound 的三本账（8 分）

$X=\{0,1,2\}$：

$$
p_s=(0.6,0.3,0.1),\qquad p_t=(0.2,0.3,0.5).
$$

假设类为四个 threshold $h_j(x)=\mathbf1\{x\ge j\}$，$j=0,1,2,3$。source truth 为 $h_1$，target truth 为 $h_2$。

1. 精确计算 $d_{\mathcal H\Delta\mathcal H}(P_s,P_t)$；
2. 对 source ERM $h_1$ 计算 source/target risk；
3. 计算 $\lambda=\min_h[R_s(h)+R_t(h)]$；
4. 核对 $R_t(h)\le R_s(h)+d/2+\lambda$；
5. 构造 discrepancy 小但 $\lambda$ 大、或 invariant representation 无用的反例。

### 第 11 题：OOD、阈值与 group robustness（7 分）

高分表示 ID。ID scores 为 $(0.9,0.8,0.6)$，OOD scores 为 $(0.7,0.4,0.2)$，threshold 为 $0.65$。

1. 枚举 9 个 ID–OOD pairs，计算 AUROC；
2. 计算 ID acceptance 与 OOD false acceptance；
3. group weights $(0.7,0.2,0.1)$、risks $(0.1,0.2,0.5)$，计算 average 与 worst-group risk；
4. 说明高 AUROC、低平均风险、对 synthetic corruption 稳健分别为何不能推出 natural-shift、adversarial、worst-group 或 causal robustness。

### 第 12 题：三条定理的量词审计（7 分）

分别为下列结论写完整量词、假设与失败模式：

1. strictly proper log/Brier score 的 population optimum；
2. split-conformal finite-sample marginal coverage；
3. covariate-shift importance identity 或 domain-adaptation bound。

每条必须指出“定理结论之外最近的一步”为什么不能自动成立，并给一个 counterexample。

### D 部分：证据审计与 AI 迁移（20 分）

### 第 13 题：审计一篇可靠性论文（10 分）

论文声称：“模型 ECE 更低、ensemble entropy 更高、conformal 达到 90% coverage、OOD AUROC 更高，因此模型在未知环境中更安全且更接近因果机制。”

1. 至少列十个缺失合同或混杂；
2. 为四种指标各写最小合法 estimand；
3. 设计 calibration、uncertainty、coverage、shift/OOD 四类 intervention；
4. 区分 theorem、finite computation、simulation、benchmark 与 causal hypothesis；
5. 写出仍不可推出的部署结论。

### 第 14 题：陌生高风险 AI pipeline（10 分）

从医疗 triage、自动驾驶感知、LLM 拒答、金融风控或 RAG 路由任选一个，设计预注册协议：

1. source/target/group/shift set；
2. predictive object 与 cost/reject action；
3. proper score、calibration 与 uncertainty diagnostics；
4. conformal/coverage 对象与 exchangeability audit；
5. importance/adaptation assumptions 与 overlap；
6. OOD score、threshold 和 paired utility；
7. nested selection、locked test、monitoring 与 recalibration trigger；
8. 一个会推翻“更安全/更因果”的 intervention；
9. 48 小时换机制与 14 天陌生系统迁移。
