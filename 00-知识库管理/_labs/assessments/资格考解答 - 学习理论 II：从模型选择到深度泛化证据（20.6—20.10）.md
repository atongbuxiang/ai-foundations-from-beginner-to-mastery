## 第 1 题解答：七条声明的最小路由（7 分）

| 声明 | 首要入口与最小修复 | statement type | 不能推出 |
|---|---|---|---|
| source winner = target winner | shift/importance weighting；需 $p\ll q$、共同 conditional law 或明确 correction | target-risk identity/estimate | 未校正 source 排名保持 |
| covariance 满秩 = 可迁移 | task-indexed representation risk；需 target task/alignment、sample 与 decoder class | proxy + downstream experiment | 满秩本身给低风险 |
| ECE 降 = 所有 utility 升 | calibration/proper scoring；需决策成本、threshold 与 conditional utility | empirical calibration statement | 任意成本矩阵下 Bayes action 改善 |
| no-regret = population risk 小 | online-to-batch；需 iid next example、past measurability、random iterate/Jensen | sequence comparator 或转换后 risk | drift/last iterate/绝对风险小 |
| IPS 无偏 = exploration 可为零 | OPE/overlap；需 $\pi>0\Rightarrow\mu>0$ 与二阶矩控制 | expectation identity | 低方差、finite-sample safety |
| flat checkpoint = 好 predictor | parameterization invariance；先对同 function 做 rescaling pressure test | parameter-space proxy | function-space 或 population ordering |
| NTK fit = 解释泛化 | kernel regime + sample-to-population bridge | training dynamics | finite-width feature learning/test risk |

“首要入口”不是排他工具。例如 target model selection 还需要 selection budget，OPE 上线还需要 safety 与 feedback-loop 分析。

## 第 2 题解答：十三层统一账本（8 分）

| 层 | 本服务必须冻结的对象 |
|---|---|
| task | context $X$、binary $Y$、模型 action $A$、Brier/utility |
| data | source $q$、target $p$、online history、context/group sampling unit |
| representation | 每个 encoder、pretext/view law、spectrum proxy、target decoder/task |
| model | 三个 probability predictors $s_j(x)$ 与训练 objective |
| algorithm | 初始化、optimizer、stopping、min-norm/null component |
| selection | source validation winner、target-weighted winner、checkpoint 搜索预算 |
| probability | $s_j(x)$ 是概率 score；classification action 还需 threshold/cost |
| shift | $p/q$、conditional invariance、support、worst group |
| protocol | replay 中先见 full loss；上线只见 chosen action outcome |
| comparator | best fixed expert、target routing policy、Bayes policy 分开 |
| mechanism | implicit bias、norm/path、raw sharpness 的 symmetry |
| regime/evidence | finite width、NTK、mean-field；theorem/proxy/experiment |
| deployment | target utility、calibration/coverage、monitor/rollback |

最常见对象偷换是：把 source-selected deterministic model 换成 target stochastic policy；把 probability predictor 换成 threshold action；把 full-information regret 换成 bandit value；把一个 parameterization 的 sharpness 换成函数性质。

## 第 3 题解答：Source、Target 与表示（12 分）

对模型 $j$，Brier risk 是

$$
R_q(j)=\sum_xq_x(s_j(x)-y_x)^2,
\qquad
R_p(j)=\sum_xp_x(s_j(x)-y_x)^2.
$$

逐项得到：

| 模型 | source Brier | target Brier | target singleton-bin gap | effective rank |
|---|---:|---:|---:|---:|
| $M_0$ | 0.069250 | 0.127000 | 0.340000 | 1.275000 |
| $M_1$ | 0.091250 | 0.057500 | 0.200000 | 1.750000 |
| $M_2$ | 0.141250 | 0.121250 | 0.265000 | 1.020000 |

所以 source winner 是 $M_0$，target winner 是 $M_1$。三个模型按 threshold $1/2$ 时，$M_0,M_1$ 的四个分类都正确；accuracy 无法区分它们的概率质量。

Density ratios 为

$$
w=p/q=(0.25,2/3,1.5,4).
$$

二阶矩

$$
\mathbb E_q[w^2]
=\sum_x\frac{p_x^2}{q_x}
=0.025+0.133333+0.45+1.6
=2.208333,
$$

故 population ESS fraction 为

$$
\frac{(\mathbb E_q[w])^2}{\mathbb E_q[w^2]}
=\frac1{2.208333}=0.452830.
$$

例如 $M_1$ 的 weighted source risk 是

$$
\sum_xq_xw_x(s_1(x)-y_x)^2
=\sum_xp_x(s_1(x)-y_x)^2=0.0575.
$$

Effective rank 使用 $r_{\rm eff}=\operatorname{tr}\Sigma/\lambda_{\max}$：分别为 $5.1/4=1.275$、$3.5/2=1.75$、$3.06/3=1.02$。它只检查谱是否集中；$M_1$ 在此 fixture 中同时 target risk 最小并不证明 effective rank 对 transfer 有单调因果关系。

## 第 4 题解答：Online Routing 与 OPE（13 分）

Hedge 逐轮账本为：

| $t$ | context | 轮前 $p_t$ | 三模型 loss | mixture loss |
|---:|---:|---|---|---:|
| 1 | 0 | (.333333,.333333,.333333) | (.010000,.062500,.002500) | .025000 |
| 2 | 3 | (.337281,.323408,.339311) | (.202500,.010000,.002500) | .072382 |
| 3 | 1 | (.303114,.339037,.357849) | (.090000,.202500,.360000) | .224761 |
| 4 | 2 | (.336307,.343788,.319905) | (.090000,.022500,.160000) | .089188 |
| 5 | 3 | (.335752,.362264,.301984) | (.202500,.010000,.002500) | .072367 |
| 6 | 3 | (.301742,.379773,.318485) | (.202500,.010000,.002500) | .065697 |
| 7 | 1 | (.269777,.396072,.334152) | (.090000,.202500,.360000) | .224779 |
| 8 | 2 | (.299420,.401757,.298822) | (.090000,.022500,.160000) | .083799 |

算法 loss 为 $0.857972$；三个 fixed experts 累计 loss 为 $(0.9775,0.5425,1.05)$，故 regret $0.315472$。最终分布为 $(0.297629,0.421512,0.280858)$。

Target-policy true risk 是

$$
V_p(\pi)=\sum_xp_x\sum_a\pi(a|x)\ell_a(x)=0.073375.
$$

六个 observed joint-ratio（context ratio 与 action propensity ratio 的乘积）及 contribution 为：

| $(x,a)$ | ratio | loss | ratio $\times$ loss |
|---|---:|---:|---:|
| (0,0) | .035714 | .010000 | .000357 |
| (3,1) | 6.400000 | .010000 | .064000 |
| (1,0) | .111111 | .090000 | .010000 |
| (2,1) | 3.000000 | .022500 | .067500 |
| (3,2) | 1.333333 | .002500 | .003333 |
| (0,1) | .875000 | .062500 | .054688 |

Observed IPS mean 为 $0.033313$，它不必等于 true risk。全 support 上最大 joint ratio 为 $6.4$；realized weight ESS

$$
\frac{(\sum_iw_i)^2}{\sum_iw_i^2}=2.631218
$$

而 nominal sample size 是 6。无偏性由

$$
\begin{aligned}
\mathbb E_{q,\mu}
\left[\frac{p(X)\pi(A|X)}{q(X)\mu(A|X)}\ell_A(X)\right]
&=\sum_{x,a}q_x\mu(a|x)
\frac{p_x\pi(a|x)}{q_x\mu(a|x)}\ell_a(x)\\
&=V_p(\pi)
\end{aligned}
$$

得到。它是重复采样下的 expectation identity；单次 observed IPS 可偏离很大。

## 第 5 题解答：Source Selection 到 Target Risk（10 分）

若 $p\ll q$ 且 conditional outcome law 不变，则

$$
R_p(f)
=\int\ell(f(x),y)p(x,y)d(x,y)
=\mathbb E_q\left[\frac{p(X)}{q(X)}\ell(f(X),Y)\right].
$$

若存在区域 $B$ 满足 $q(B)=0,p(B)>0$，构造两个世界在 source support 上完全相同，却令 $B$ 上 label 全为 0 或全为 1；source data law 相同，target risk 不同，故不可识别。

对 $J$ 个预注册候选，可在独立 validation set 上用 union bound 建立所有 $j$ 的共同偏差事件，再在事件内选择；或用 train 训练、validation 选模、untouched target test 只评价一次。若同一 target validation 被用于学习 density ratio、调 representation、选 checkpoint，再报最优值，就必须处理联合依赖或再分样本。

估计 $\widehat w$ 引入 ratio estimation error、极端权重/截断 bias、与 predictor/validation 共用数据的依赖，以及 conditional shift misspecification。有效样本量下降是 variance 警告，不是完整 confidence theorem。

对 binary $Y$，先定义 forecast-conditioned truth

$$
\eta_S(s)=P(Y=1\mid S=s),\qquad \pi=P(Y=1).
$$

由条件期望的正交性，Brier risk 有 Murphy 分解：

$$
\begin{aligned}
\mathbb E(S-Y)^2
&=\underbrace{\mathbb E\bigl(S-\eta_S(S)\bigr)^2}_{\text{reliability / calibration error}}
+\underbrace{\mathbb E\bigl[\eta_S(S)(1-\eta_S(S))\bigr]}_{\text{within-bin uncertainty}}\\
&=\underbrace{\mathbb E\bigl(S-\eta_S(S)\bigr)^2}_{\text{reliability}}
-\underbrace{\operatorname{Var}(\eta_S(S))}_{\text{resolution}}
+\underbrace{\pi(1-\pi)}_{\text{uncertainty}}.
\end{aligned}
$$

这里 reliability 越小越好，resolution 越大越好，uncertainty 只由总体 base rate 决定。若直接条件在完整 $X$ 上，则另有 $\mathbb E[(S-\eta(X))^2]+\mathbb E[\eta(X)(1-\eta(X))]$；它不能代替上面的 forecast-bin calibration 分解。Accuracy 只看 threshold 后是否跨过决策边界，因而丢掉概率质量。Non-collapse 只排除 representation 的一种退化，还需 target task 与表示方向 alignment、decoder class、selection 和 finite-sample control 才能谈 transfer。

## 第 6 题解答：Regret、Conversion 与 OPE（10 分）

令 $W_t=\sum_i\exp(-\eta L_{t-1,i})$。对 $[0,1]$ loss，Hoeffding lemma 给

$$
\log\frac{W_{t+1}}{W_t}
\le-\eta\langle p_t,\ell_t\rangle+\frac{\eta^2}{8}.
$$

求和并用 $W_{T+1}\ge\exp(-\eta L_{T,i})$，得

$$
\sum_t\langle p_t,\ell_t\rangle-min_iL_{T,i}
\le\frac{\log N}{\eta}+\frac{\eta T}{8}.
$$

Full information 在 action 后揭示整个 loss vector；bandit 只揭示 chosen action；若环境看到当轮 realized action 后才定 loss，标准 Hedge adversary contract 已被破坏。

若 $h_t$ 只依赖 $Z_{<t}$ 且 $Z_t$ iid，则

$$
\mathbb E[\ell(h_t,Z_t)|Z_{<t}]=R(h_t).
$$

独立均匀 $I$ 给 $\mathbb ER(h_I)=T^{-1}\sum_t\mathbb ER(h_t)$。这不自动给 last iterate。

令单条 importance-weighted loss 为

$$
Z=\frac{p(X)\pi(A\mid X)}{q(X)\mu(A\mid X)}\ell_A(X).
$$

它的二阶矩是

$$
\mathbb E_{q,\mu}Z^2
=\sum_{x,a}\frac{p_x^2\pi(a|x)^2}{q_x\mu(a|x)}\ell_a(x)^2,
$$

显示小 $q_x\mu(a|x)$ 会放大 variance；$n$ 条独立日志的样本均值 $\widehat V=n^{-1}\sum_iZ_i$ 才是本题 estimator。Regret 比 best fixed expert 的 realized sequence；OPE 评价 target contextual policy；random iterate 是另一个 randomized predictor；last checkpoint 又是另一个对象。Drift 破坏共同 law，delay 改 filtration，零 overlap 破坏识别，action 改未来 state 时需 policy-regret/RL occupancy 而非单步 OPE。

## 第 7 题解答：Interpolation、Capacity 与 Regime（10 分）

满行秩 $X$ 的所有解为

$$
\beta=X^\dagger y+v,\qquad v\in\ker X.
$$

$X^\dagger y$ 在 row space，$v$ 在其正交补，故它唯一最小化 Euclidean norm。零初始化 GD 的每个增量都在 row space，若收敛到插值解就选择该 min-norm 点；非零初始化会保留 null component。

对 $L(a,b)=\frac12(ab-1)^2$，在 $ab=1$ 上

$$
H=\begin{pmatrix}b^2&1\\1&a^2\end{pmatrix}
$$

秩为 1，非零 eigenvalue 为 $a^2+b^2$。$(a,b)=(c,c^{-1})$ 保持同一 ReLU function，却使 sharpness $c^2+c^{-2}$ 任意大。Norm/margin skeleton 用层 spectral product 与 Frobenius/spectral ratios 抵消相邻层 reciprocal scaling；但 nonvacuous 仅表示小于平凡界，explanatory 还需抓住现实误差机制。

平方损失 gradient flow 给 $\dot r_t=-K_tr_t$；固定 $K_t\approx K_0$ 时

$$
r_t=e^{-K_0t}r_0
=\sum_ie^{-\lambda_it}\langle u_i,r_0\rangle u_i.
$$

Mean-field 把粒子 empirical measure 推向 continuity PDE，允许 feature distribution 做 $O(1)$ 演化。Width、step、time 与 sample-size 极限不能任意交换。无论 fixed kernel 还是 moving feature，要得到 population risk 都还需 data law、target alignment、noise、regularization/stopping 与 finite-sample operator control。

## 第 8 题解答：八条声明审计（8 分）

1. **错误。** 第 3 题就是 source 排名翻转；需无 shift 或合法 target correction。
2. **错误。** 满秩/高 effective rank 只排除谱坍缩；target 可依赖弱方向或无关因素。
3. **条件不足。** Brier 更低是平均 proper-score 改善；任意成本矩阵还依赖 conditional/local ordering 与 action rule。
4. **错误。** Regret 依赖 loss sequence/comparator；OPE variance 依赖 logging overlap。
5. **错误。** Importance ratio 可使单次估计超过 1；只有 expectation 回到 target risk。
6. **错误。** Null-space 平移保持 train fit，却改变 null test direction prediction。
7. **错误。** ReLU reciprocal rescaling 保持 function 而任意改变 raw sharpness。
8. **错误。** 两个极限都缺 finite-sample population/deployment bridge；且现实训练未必处于对应 regime。

每个反例只否定过强量词，不否定工具在其合同内的价值。

## 第 9 题解答：七个“最好”的选择协议（7 分）

比较前至少核对：同一 predictor/checkpoint、同一 target population、同一 sample 与复用次数、同一 loss/utility direction、同一 probability event/confidence、同一 deterministic/Gibbs identity、同一 group aggregation、同一 deployment horizon。

Source risk、target risk、ECE、worst-group risk、regret、capacity bound 与 sharpness 并不控制同一 estimand；它们不能取 minimum。合法方案包括：

- 预注册一个 primary metric 与 tie-break，其他为 diagnostics；
- 对同一 estimand 的多个 high-probability certificates 建共同事件并支付 union/selection budget；
- nested split：训练、选模/调参、最终 target test 隔离，test 只打开一次。

反复查看 target labels 会使 checkpoint 和报告本身适应 evaluation set，产生 winner's curse。尤其不能从七个数取最小后声称“部署风险不超过该最小值”。

## 第 10 题解答：陌生系统研究—部署合同（15 分）

以实时模型路由为例，合格答案应包含：请求 context 到达；路由器基于过去 filtration 选模型；模型生成回答；只观察 chosen model 的延迟反馈；日志记录 propensity、版本和 eligibility；独立 safety channel 决定 rollback。

Source law 是历史离线 benchmark，target law 是计划服务人群，online law 还受路由 action 影响。Encoder vector、probability-of-success predictor、route action 和用户 utility 必须分开。离线证书可用 nested validation，可靠性用 group calibration/coverage，shift/OPE 用 joint ratio 与 overlap，在线用预注册 fixed/switching comparator。

竞争机制至少包括真实 task-aligned representation learning、只记忆 source shortcut、以及 normalization/parameterization 造成的 proxy 变化。应用 function-space prediction/Jacobian 与 invariant norm 压力测试；记录 kernel/feature drift 只用于 regime diagnosis。

上线门示例：target OPE 上置信界优于基线且最大 ratio/ESS 达标；关键 group coverage 不下降；canary regret 和 safety violation 均在阈值内。任一 overlap、delay 或 group alarm 触发停止/rollback。即使全部通过，也不能推出未观测 action 的长期反事实完全识别、未来任意 shift 下安全、或某个 sharpness/NTK 机制是唯一因果解释。
