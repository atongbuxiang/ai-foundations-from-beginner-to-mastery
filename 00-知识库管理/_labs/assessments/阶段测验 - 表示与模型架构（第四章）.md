# 阶段测验 - 表示与模型架构（第四章）

> [!abstract] 测验目的
> 本卷不考模型名词背诵，而考你能否从输入结构、信息流、shape、对称性、复杂度、训练/推理接口与证据等级重建陌生架构。八卷各有一道主问题，最后两题检查跨架构选择与研究审计。

## 协议与门槛

- 240 分钟闭卷，可用基础计算器；
- 每个性能结论必须注明训练/prefill/decode、硬件与质量协议；
- `exact`、`linear`、`equivariant`、`stable`、`low-rank` 未写对象和条件不得分；
- 总分 100，80 分通过；Q2、Q4、Q8 三道结构主推导均不得低于 6/10；
- 另须通过[[实验 - 表示与模型架构跨卷累计复现门]]；
- 当前仅有题卷不算真实学习通过。

## Q1 CNN：局部性、等变与采样（10 分）

对一维信号 $x[n]$ 与 kernel $w[r]$：

1. 写出 stride-1 convolution/cross-correlation，并证明整数平移等变；（3）
2. 说明 stride-2 为何一般不对单像素平移等变，给最小反例；（3）
3. 区分理论感受野、有效感受野、anti-aliasing 与任务不变性；（2）
4. 写出一条不能从 weight sharing 推出的结论。（2）

## Q2 RNN/SSM：状态、卷积与并行（10 分）

给线性离散 SSM：$h_t=Ah_{t-1}+Bx_t, y_t=Ch_t$，$h_0=0$。

1. 展开 $h_t,y_t$，得到 causal convolution kernel；（3）
2. 写出 $\partial h_T/\partial h_t$，用谱/非正规性解释梯度风险；（2）
3. 区分 sequential recurrence、parallel scan 与 FFT convolution 的前提和成本；（3）
4. 说明 input-dependent $A_t,B_t$ 为什么破坏固定卷积，却不必破坏 scan。（2）

## Q3 GNN：重标号、聚合与表达边界（10 分）

1. 用 $A'=PAP^T,X'=PX$ 证明一层 $H'=\sigma(\hat AH W)$ 的节点等变；（3）
2. 说明 sum/mean/max 聚合各可能发生的多重集碰撞；（2）
3. 给出标准 MPNN 无法区分的一类 1-WL 反例思路；（2）
4. 区分 over-smoothing 与 over-squashing，并各给一个诊断。（3）

## Q4 Attention：对象、mask、rank 与几何（10 分）

令 $Q\in\mathbb R^{T_q\times d_k},K\in\mathbb R^{T_k\times d_k},V\in\mathbb R^{T_k\times d_v}$。

1. 写 scaled attention 全部 shape 与 stable masked softmax；（3）
2. 证明对同时重排 K/V 行的不变性；说明 self-attention 同时重排全序列时是哪种性质；（2）
3. 解释 $\operatorname{rank}(QK^T)\le d_k$ 为何不推出 softmax weight 低秩；（2）
4. 构造全遮蔽行的安全语义，并说明概率解释的边界。（3）

## Q5 Transformer：组合、因果与缓存（10 分）

1. 写 Pre-Norm decoder block 的两子层前向式与局部 Jacobian 主结构；（3）
2. 证明正确 KV cache 的逐步 decode 与 full causal forward 在实数代数中逐 token 等价；（3）
3. 列出 packing、position offset、dropout、dtype 会破坏对齐的方式；（2）
4. 区分 encoder-only、decoder-only、encoder–decoder 的 relation、QKV 来源与目标。（2）

## Q6 位置编码：表示、外推与评测（10 分）

1. 证明无位置 full self-attention 的置换等变性为何产生顺序辨识缺口；（2）
2. 从 $R(m)^TR(n)=R(n-m)$ 推导 RoPE 相对位移，并写所需条件；（3）
3. 区分绝对插值、RoPE 频率缩放、相对 bias 与局部窗口改变的对象；（2）
4. 设计 length×target-position 的外推评测，防止只测输入可接受。（3）

## Q7 高效 Attention：四条优化路线（10 分）

1. 分别说明 sparse、sequence low-rank、kernel linearization、FlashAttention 改变什么；（4）
2. 写 prefill pairwise MAC、score storage 与 decode KV payload 主项；（2）
3. 解释 FlashAttention 的 exact 与 quadratic arithmetic 如何同时成立；（2）
4. 比较 MHA/GQA/MQA/MLA 时写出公平 serving 协议。（2）

## Q8 MoE：路由、容量、均衡与通信（10 分）

设 $T=8,E=4,k=2,d=1024,s=2$ bytes，负载 $[6,4,3,3]$，$\alpha=1$。

1. 写完整路由合同；（2）
2. 算 capacity、drop 数与 padded utilization；（2）
3. 定义 $f_i,P_i$ 与典型 aux loss，说明 gradient proxy；（2）
4. 解释 loss-free bias 与 assignment dual 的联系和差别；（2）
5. 若 remote fraction 为 $.75$，算 dispatch+combine 逻辑 payload。（2）

## Q9 跨架构选择：长序列系统（10 分）

面对 128k context 的语言任务，在 local attention、S4/Mamba、GQA/MLA、稀疏 MoE 中选择组合。写一份决策表，至少覆盖：relation/记忆对象、训练并行、prefill、decode cache、通信、质量风险、长度外推、kernel maturity 与两条公平实验轨道。不得只给最终模型名。

## Q10 研究审计：一条“更高效、更可解释”的主张（10 分）

任选本章一个架构主张，写成可证伪研究合同：对象/shape、理论假设、模型函数变化、成本账本、数值误差、训练与系统实验、消融、失败结果、I/T/E/H/O 标签和不能推出项。
