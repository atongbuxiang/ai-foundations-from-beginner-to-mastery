## 四、A 区：对象、形状、状态与证据合同（20 分）

### 第 1 题：八个断言（4 分）

判断正误。错误时给最小修正；每项 0.5 分。

1. 只要网络层数增加，函数表达类必严格增大，训练和泛化也必改善。
2. 多个仿射层之间若没有非线性，整体仍是一个仿射映射。
3. ReLU 在 0 不可微，所以使用任意固定 subgradient convention 都会让训练算法不合法。
4. Xavier/He 初始化保持某个平均二阶矩，就自动保证所有 singular values 接近 1。
5. LayerNorm 不依赖 batch statistics，因此 train/eval 路径通常没有 BatchNorm 式 running-buffer 切换。
6. Residual block 的 Jacobian 是 $I+J_F$，但这不保证其最小 singular value远离 0。
7. Embedding lookup 与 one-hot 乘矩阵在前向上等价；当 ID 重复时，反向对同一 row 的贡献相加。
8. Label Smoothing 降低 maximum probability，就已经证明 calibration 与 epistemic uncertainty 都改善。

### 第 2 题：四份 Shape / Parameter / State 合同（6 分）

对输入 $X\in\mathbb R^{B\times d}$，逐项写输出形状、可学习参数、非参数状态、训练—推理差异和一个首要失败测试；每项 1.5 分。

1. Linear$(d,m)$，允许 bias；
2. BatchNorm1d$(m)$；
3. LayerNorm$(m)$；
4. Dropout$(p)$。

### 第 3 题：共享、Mask 与 Train/Eval（5 分）

回答以下问题，每项 1 分。

1. 一个 parameter 被计算图两条支路使用时，reverse-mode 为什么必须累加两条 cotangent？
2. tied input/output embedding 的总梯度包含哪两条路径？
3. padding row 设为零与 padding row 冻结不更新有什么区别？
4. BatchNorm 的 `running_mean` 是 parameter、optimizer state 还是 module buffer？
5. DropPath 在 sample-wise、token-wise 和 batch-wise 共享 mask 时，直接改变了哪个概率合同？

### 第 4 题：五级证据与六本账（5 分）

1. 写出 exact、local、mechanism、benchmark、deployment 五级证据各自至少一个必要条件；（2.5 分）
2. 写出 objective、optimization、generalization、calibration/uncertainty、robustness/shift、system 六本账各一个可观察量；（1.5 分）
3. 为什么“训练 loss 更低”和“某 benchmark accuracy 更高”都不能单独证明某个正则化机制或部署安全？（1 分）

## 五、B 区：手算、构造与数值解释（30 分）

### 第 5 题：两层 MLP 的完整 Forward / Reverse（8 分）

采用 column-vector convention：

$$
x=\begin{bmatrix}1\\-2\end{bmatrix},\quad
W_1=\begin{bmatrix}1&-1\\1/2&1/2\end{bmatrix},\quad
b_1=\begin{bmatrix}0\\1\end{bmatrix},
$$

$$
W_2=
\begin{bmatrix}
1&0\\
-1&2\\
1/2&-1
\end{bmatrix},\quad
b_2=\begin{bmatrix}0\\1/2\\-1/2\end{bmatrix}.
$$

定义 $a=W_1x+b_1$、$h=\operatorname{ReLU}(a)$、$z=W_2h+b_2$，target 为第三类，loss 为 fused softmax cross-entropy。

1. 计算 $a,h,z$ 与所有形状；（1.5 分）
2. 用 max-shift 计算 $p$ 与 loss；（1.5 分）
3. 计算 $\bar z=p-e_3$、$\nabla_{W_2}L$、$\nabla_{b_2}L$；（2 分）
4. 继续计算 $\bar h,\bar a,\nabla_{W_1}L,\nabla_{b_1}L,\nabla_xL$；（2 分）
5. 写出 central-difference gradient check，并说明本例为什么要同时检查 ReLU activation pattern。（1 分）

### 第 6 题：初始化、归一化与残差尺度（8 分）

1. 设 $x_i$ iid、均值 0、二阶矩 $q$，$w_i$ iid、均值 0、方差 $\sigma_w^2$，且相互独立。推导 $a=\sum_{i=1}^n w_ix_i$ 的二阶矩；对对称 $a$ 推导 ReLU 后二阶矩，并得到 fan-in He scale。（3 分）
2. 对 $x=(1,2,3)$，LayerNorm 使用 feature 轴总体方差、$\epsilon=0$、无 affine。计算 mean、variance 与输出；验证 $\operatorname{LN}(2x+5\mathbf1)=\operatorname{LN}(x)$。说明负尺度时怎样变化。（2 分）
3. 标量 residual chain 为

$$
h_{l+1}=(1+\alpha w_l)h_l,
\quad h_0=2,
\quad (w_0,w_1,w_2)=(0.2,-0.1,0.3),
\quad \alpha=0.5.
$$

计算 $h_3$ 与 $\partial h_3/\partial h_0$；说明该三层数值为什么不能证明任意深度稳定。（3 分）

### 第 7 题：Embedding、Sparse Gradient 与 Tied Softmax（7 分）

词表大小 4、维度 2，embedding matrix 为

$$
E=
\begin{bmatrix}
1&0\\
0&2\\
1&1\\
0&0
\end{bmatrix}.
$$

1. IDs 为 $(3,2,3)$。写出 lookup output 及形状；（1 分）
2. 对应 upstream rows 为 $(1,0)$、$(0.5,-1)$、$(-1,2)$。计算 scatter-add 后的 $\nabla_E$；（2 分）
3. 使用同一 $E$ 作为 output matrix，hidden $h=(2,-1)$，logits $z=Eh$，target 为 class 3。计算稳定 softmax、NLL 和 output-path $\nabla_E L$；（2.5 分）
4. 若 $h$ 本身也由 $E$ 的 lookup 路径产生，为什么 output-path gradient 不是总梯度？写出总梯度结构，不必继续数值展开。（1.5 分）

### 第 8 题：Dropout、目标变换与 Interaction（7 分）

1. 对 $x=(2,-1)$ 逐坐标 independent inverted Dropout，keep probability $q=0.75$。计算条件均值与 covariance matrix；（2 分）
2. $K=4$、inclusive uniform Label Smoothing、$\epsilon=0.2$、true class 为 2。计算 target 与最优 true-vs-wrong logit margin；（1.5 分）
3. 先以 $\lambda=0.3$ 混合 $e_1,e_3$，再做同一 smoothing。算出 target，并用一行代数说明与先 smooth 两端再 mix 相同。（2 分）
4. 风险表为 $Y_{00}=0.30,Y_{10}=0.26,Y_{01}=0.27,Y_{11}=0.20$。计算 difference-in-differences，并限定结论。（1.5 分）

## 六、C 区：推导、证明与统一结构（25 分）

### 第 9 题：从计算图统一推出 Affine—Softmax 反向（8 分）

设 mini-batch $X\in\mathbb R^{B\times d}$、$W\in\mathbb R^{d\times K}$、$b\in\mathbb R^K$，$Z=XW+\mathbf1b^\mathsf T$，每行 target $T_i\in\Delta^{K-1}$，loss 为 batch mean cross-entropy。

1. 从 log-sum-exp 形式推导 $\bar Z=(P-T)/B$；（2.5 分）
2. 用 differential/trace 或 index notation 推导 $\nabla_WL=X^\mathsf T\bar Z$、$\nabla_bL=\bar Z^\mathsf T\mathbf1$、$\nabla_XL=\bar ZW^\mathsf T$，逐项核对形状；（3 分）
3. 若 $W$ 还在另一支路中使用，证明总 $\nabla_W$ 是两条 VJP 之和；（1 分）
4. 说明 fused log-softmax 为什么比先 softmax 再 log 数值稳定，以及 probability target 合法性应由谁检查。（1.5 分）

### 第 10 题：尺度传播、LayerNorm VJP 与 Residual Bound（8 分）

1. 重新推导 fan-in ReLU 的 forward second-moment 条件，并说明它没有控制哪些相关性、有限宽误差与 Jacobian singular-value 对象；（2 分）
2. 对单样本 $x\in\mathbb R^m$，记 $\mu=m^{-1}\sum_i x_i$、$r=x-\mu\mathbf1$、$s=\sqrt{m^{-1}\|r\|^2+\epsilon}$、$\widehat x=r/s$，$y=\gamma\odot\widehat x+\beta$。从 differential 推导

$$
\bar x=\frac1s\left[g-\operatorname{mean}(g)\mathbf1-\widehat x\operatorname{mean}(g\odot\widehat x)\right],
\quad g=\bar y\odot\gamma,
$$

并写出 $\bar\gamma,\bar\beta$；（3.5 分）
3. 对 $F(x)=x+\alpha G(x)$，证明 $\operatorname{Lip}(F)\le1+|\alpha|\operatorname{Lip}(G)$；说明为什么这个上界合法但可能很松，且多层乘积仍可能爆炸。（2.5 分）

### 第 11 题：随机正则化的统一推导（9 分）

1. 对 $\widetilde x=(b/q)x$、$b\sim\operatorname{Bernoulli}(q)$ 推导条件均值、方差；再给出一个非线性反例说明 $E[f(\widetilde x)]\ne f(E\widetilde x)$。（2 分）
2. 推导 inclusive Label Smoothing 的 population optimum $(1-\epsilon)\eta+\epsilon u$，并证明 fixed-prior smoothing 与 Mixup target map 可交换；指出完整 pipeline 不可由此判为可交换。（2 分）
3. 推导普通 SGD 下 loss-side $L_2$ 与 multiplicative decay 的条件等价；用 diagonal preconditioner 写出与 decoupled decay 的断点。（2 分）
4. 写出包含 augmentation、pairing、Dropout/DropPath、target transform、Jacobian/consistency penalty 的统一 stochastic objective 与 optimizer update；为其中两种正则设计一个完整 $2\times2$ estimand，并声明 fixed-policy、retuned-policy 或 matched-budget。（3 分）

## 七、D 区：反例、实现失败与纠错（15 分）

### 第 12 题：四个最小反例（8 分）

每题 2 分：给出明确构造，算出关键量，并指出否定了哪个错误推论。

1. 堆叠任意多个 affine layers 仍不能表示 XOR；
2. 两个同结构 hidden units 全部零初始化后保持同梯度，无法自发打破置换对称；
3. 平均方差保持不推出 dynamical isometry；构造一个二阶矩平均为 1、但 singular values 很不均匀的线性层；
4. 在有限 training points 上 input gradient 为 0，不推出 global Lipschitz constant 小或 adversarially robust。

### 第 13 题：一次训练流水线事故审计（7 分）

某团队报告：

1. 用 microbatch size 2 做 gradient accumulation，却让 BatchNorm 每个 microbatch 都更新 running statistics，并宣称等价于 batch size 64；
2. validation 时忘记切换 `eval`，Dropout 与 DropPath 仍随机；
3. `padding_idx` 的 embedding 初始为 0，但 optimizer 和 tied output gradient 仍可更新该 row；
4. 对 100 万词表使用 sampled softmax，却把 loss 直接命名为 exact full-softmax NLL；
5. AMP 下先显式 softmax，再取 log，并把出现的 `-inf` clamp 后忽略；
6. 最终只报告 single-seed accuracy best checkpoint，未记录 tuning trials、compute 或 calibration/robustness。

逐条指出对象或语义错误；为前五项各给一个最小 property/numerical test，并把第六项改写成可审计的证据协议。最后写出即使修复全部问题仍不能推出的一条因果或部署结论。

## 八、E 区：陌生模型迁移（10 分）

### 第 14 题：审计一个带共享输出和随机残差的 Block（10 分）

给定 batch hidden state $X\in\mathbb R^{B\times d}$，考虑

$$
U=X+\frac{b}{q}\odot\alpha\left[
\operatorname{GELU}\!\left(\operatorname{LN}(XW_1)\right)W_2
\right],
$$

其中 $W_1\in\mathbb R^{d\times m}$、$W_2\in\mathbb R^{m\times d}$；当前 $B\times d$ 对象中 $b$ 可按 sample 或整个 batch 采样，若推广到 $B\times T\times d$ sequence 才另有 token-wise 采样。输出 logits 使用与输入 embedding 共享的 $E\in\mathbb R^{V\times d}$：$Z=UE^\mathsf T$。训练可同时使用 Mixup、Label Smoothing、weight decay 和 R-Drop。

写一份可以直接交给实现者和实验者的合同，至少包含：

1. 所有张量形状、广播轴、参数与 module/optimizer state；（1.5 分）
2. train/eval forward、stable loss 与 padding/large-vocabulary 处理；（1.5 分）
3. reverse-mode 的 identity/branch/tied-parameter 梯度路径；（1.5 分）
4. initialization、LayerNorm、residual scale、DropPath mean/covariance 的尺度账本；（1.5 分）
5. Mixup/Label Smoothing/R-Drop/decay 的 objective 与 update 分账；（1.5 分）
6. 至少六个 property/numerical/system tests；（1.5 分）
7. 一个 factorial ablation、六本账和五级证据边界；（1 分）
