# 解答 - 激活函数的角色、选择准则与函数性质

## A

### NN-CHO-A01
两层为 $f_1(x)=W_1x+b_1$、$f_2(h)=W_2h+b_2$，则 $(f_2\circ f_1)(x)=W_2W_1x+(W_2b_1+b_2)$，仍是 affine。归纳地，若前 $k$ 层为 $A_kx+c_k$，再复合 $W_{k+1}(A_kx+c_k)+b_{k+1}$ 得 $W_{k+1}A_kx+(W_{k+1}c_k+b_{k+1})$，故任意有限层仍可折叠。

### NN-CHO-A02
hidden activation 通常逐元改变中间表示；gate 用一支信号乘另一支 value；output link 把 score 映到 likelihood parameter 的支持集；softmax 跨类别轴耦合并归一化；hard decision 如 threshold/argmax 输出部署动作且通常不进入可微训练主链。它们可能都叫“activation”，但定义域、耦合轴和梯度职责不同。

### NN-CHO-A03
可比较：非仿射性、值域/有界性、导数分布与 Lipschitz、smoothness/kink、单调性、对称性/输出中心、正齐次性、moment map、数值实现/低精度、参数与 FLOP 成本、输出语义、任务证据。至少不能用“平滑”替代“梯度条件性”，也不能用“训练快”替代“表示能力”。

## B

### NN-CHO-B01
$dL=h,dh=h\phi'(z)dz$，而 $dz=x,dw+db+w,dx$，故 $dL/dw=h\phi'(z)x$、$dL/db=h\phi'(z)$、$dL/dx=h\phi'(z)w$。给定数值得 $z=1$：ReLU 的 $(h,\phi')=(1,1)$，三者为 $(2,1,3)$；sigmoid 约 $(0.731059,0.196612)$，共同系数 $h\phi'\approx0.143735$，故约 $(0.28747,0.143735,0.431205)$；tanh 约 $(0.761594,0.419974)$，共同系数约 $0.31985$，故约 $(0.63970,0.31985,0.95955)$。

### NN-CHO-B02
若 $h_\ell=\phi(W_\ell h_{\ell-1})$，$W_\ell:[d_\ell,d_{\ell-1}]$，$D_\ell=\operatorname{diag}\phi'(z_\ell):[d_\ell,d_\ell]$，则 $\partial h_L/\partial h_0=D_LW_L\cdots D_1W_1:[d_L,d_0]$。最右侧先作用。反向 seed $u:[d_L]$ 依次乘 $W_L^TD_L,ldots,W_1^TD_1$，最终与 $h_0$ 同形。

### NN-CHO-B03
无界实回归用 linear output；Bernoulli 二分类用 logit 加 fused binary cross-entropy，展示时 sigmoid；三分类用三 logits 加 softmax cross-entropy；正 scale 可用 softplus 或 exp，并匹配 likelihood。hidden activation 只决定内部函数组合和训练动力学，不由输出支持集唯一确定；同一 likelihood 可配 ReLU、tanh、GELU 等不同 backbone。

## C

### NN-CHO-C01
$h_i=\phi(z_i)$ 给 $\partial h_i/\partial z_j=\phi'(z_i)\delta_{ij}$，所以 $J=\operatorname{diag}\phi'(z)$。于是 $Jv=\phi'(z)\odot v$、$J^Tu=\phi'(z)\odot u$。softmax 的 $p_i$ 依赖所有 $z_j$，$\partial p_i/\partial z_j=p_i(\delta_{ij}-p_j)$ 含非零 off-diagonal，因此不能逐元乘 slope 处理。

### NN-CHO-C02
取 $\phi(x)=x$，则 $|\phi'|=1$；每层标量权重 $w=2$，深度 $L$ 的 Jacobian 是 $2^L$，爆炸。反向例取局部 $\phi'(z)=2$，但每层权重 $w=0.1$，每层总 gain 为 $0.2$，深度乘积 $0.2^L$ 收缩。局部 activation slope 只是一层 Jacobian 的一个因子。

### NN-CHO-C03
若 $Z\overset{d}{=}-Z$、$\phi(-z)=-\phi(z)$ 且 $\mathbb E|\phi(Z)|<\infty$，则 $\mathbb E\phi(Z)=\mathbb E\phi(-Z)=-\mathbb E\phi(Z)$，故为 0。反命题失败：常数零函数对任意非对称分布均有零均值；无条件版本失败：取 odd $\phi(x)=x$、$Z\equiv1$，输出均值为 1。

## D

### NN-CHO-D01
UAT 是“对给定 compact domain、target、norm 和容差，存在某个有限网络逼近”的存在性结论。它不给所需宽度、样本复杂度、optimizer 达到该参数的保证，也不比较有限预算下不同 activation 的 conditioning、kernel cost 或泛化。因此最多说明函数类不因表达不足被立即排除，不能推出训练/部署最优。

### NN-CHO-D02
sigmoid 是 $C^\infty$，但在大 $|z|$ 处导数指数趋 0；多层乘积可严重消失。ReLU 在 0 不可微，但几乎处处有导数，AD 在 kink 选定 convention 后能执行 SGD；实际 batch 精确落在所有 kink 的概率/频率需另审计。smoothness 与一阶训练可行性不是同一性质。

### NN-CHO-D03
固定其余超参数能回答“在这一个共同、未重调协议下替换函数的效果”，并揭示 plug-in robustness。它不能回答各函数在 activation-aware initialization、最佳 learning rate、normalization 或 compute-matched setting 下的最佳性能。若不同函数适宜尺度不同，固定协议会系统性偏向某一方；报告应明确 fixed-protocol 与 retuned-protocol 两条轨道。

## E

### NN-CHO-E01
固定 48 层 residual topology 与数据；做 matched-parameter/FLOP versions；分别跑共同初始化与 activation-aware 初始化、PreNorm/无 norm、固定 LR/独立调参；至少 5 seeds。记录 loss、validation、wall-clock、memory、finite rate、每层 $E[h]$、$E[h^2]$、derivative quantiles、gradient norm、dead/saturated rate 和 residual-branch/skip gain。预注册主指标和预算，报告均值、置信区间及 failed runs，不以 best seed 排名。

### NN-CHO-E02
hidden ReLU 是中间 representation map，训练/推理都参与 backbone；binary output 应保存 raw logit，训练用 fused logits NLL，展示 probability 时 sigmoid；deployment threshold 把 probability/logit 变成 action，阈值由 cost/calibration policy 选择，通常不参与梯度。三者分别属于 architecture、likelihood link 和 decision rule。

### NN-CHO-E03
数学门：定义、导数、kink convention、Lipschitz/smoothness 与支持集；数值门：reference FP64、极端输入、NaN/Inf、relative/absolute error、forward/backward/double-backward、dtype 与 accumulation；系统门：kernel fusion、吞吐、memory traffic、determinism、shape/layout、编译器 fallback。最后在 matched budget 上做 end-to-end seeds，并把 kernel 速度与模型质量分开报告。
