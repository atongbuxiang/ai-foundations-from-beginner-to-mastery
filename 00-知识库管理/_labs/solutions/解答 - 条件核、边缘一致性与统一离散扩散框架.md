# 解答 - 条件核、边缘一致性与统一离散扩散框架
## A. 识别与复述
### GEN47-A01
测度形式：对任意可测集合 $A$，$q_{t-1}(A|x_0)=\int r_t(A|x_t,x_0)q_t(dx_t|x_0)$。有共同 density 时：$q_{t-1}(x_{t-1}|x_0)=\int r_t(x_{t-1}|x_t,x_0)q_t(x_t|x_0)dx_t$。
### GEN47-A02
Teacher kernel 在训练构造中可条件于 $(x_t,x_0,t)$；部署时真实 $x_0$ 不可见，模型只能使用 $(x_t,t)$ 及允许的外部 condition $c$。部署目标是对 $q(x_0|x_t)$ 混合后的 reverse，而非照抄带 $x_0$ 的 component kernel。
### GEN47-A03
合法只要求积分得到目标 marginal；信息有效要求 kernel 对 $x_t$ 的变化作有用响应；可学还取决于去掉 $x_0$ 后 target 的复杂度、模型容量、损失识别的统计量与数值成本。任一道门均不蕴含下一道。
## B. 手算与建模
### GEN47-B01
$Rq_t=(0.8/2+0.7/2,0.2/2+0.3/2)^T=(0.75,0.25)^T$。每列元素非负且列和为 1，因此也是合法 column-stochastic kernel。
### GEN47-B02
要求 $(a+b)/2=3/4$，故 $a+b=3/2$。概率约束 $0\le a,b\le1$ 给 $a\in[1/2,1]$、$b=3/2-a$。例如 $(a,b)=(0.8,0.7)$ 与 $(0.75,0.75)$；后者两列相同，不使用当前状态。
### GEN47-B03
输出为 $0.6(0.2,0.8)^T+0.4(0.2,0.8)^T=(0.2,0.8)^T$。两列相同，conditional law 与当前 state 无关，因此没有利用 $x_t$，但若目标正是该分布仍合法。
## C. 推导与证明
### GEN47-C01
代入得 $\int q_{t-1}(A|x_0)q_t(dx_t|x_0)=q_{t-1}(A|x_0)\int q_t(dx_t|x_0)=q_{t-1}(A|x_0)$。只用了 $q_t$ 总质量为 1。
### GEN47-C02
按 $x_0$ 条件分解联合分布：$q(x_{t-1},x_0|x_t)=r_t(x_{t-1}|x_t,x_0)q(x_0|x_t)$。对 $x_0$ 积分即得边缘 $q(x_{t-1}|x_t)$。这也显示部署 reverse 通常是许多 component kernels 的 mixture。
### GEN47-C03
Markov kernel $K$ 对 TV 非扩张：$\|\mu K-\nu K\|_{TV}=\sup_{\|f\|_\infty\le1}|\mu(Kf)-\nu(Kf)|/2\le\|\mu-\nu\|_{TV}$，因 $\|Kf\|_\infty\le1$。但完整链还含每一步 kernel approximation $\hat K_t-K_t$ 在不同输入分布下的误差；需逐步 telescoping、uniform/on-policy bound 与可能的 contraction coefficient。
## D. 边界、反例与纠错
### GEN47-D01
取 $r_t(\cdot|x_t,x_0)=q_{t-1}(\cdot|x_0)$。它对所有 $x_t$ 相同，却由 C01 必满足一致性，因此一致性不能推出利用 $x_t$。
### GEN47-D02
平方损失只识别 $E[Y|x]$。例如 $Y|x$ 可为 $N(0,1)$ 或等概率取 $\{-1,1\}$；两者 conditional mean 都为 0，但 density、tails 和采样 law 不同。完整 kernel 还需 variance、高阶结构或完整离散概率。
### GEN47-D03
MSE 是 target-space 的点预测误差，最终 distribution metric 可能是 TV/KL/Wasserstein，并受 kernel sensitivity、on-policy state shift 与相关误差影响；量纲也不一致。只有给出将每步估计误差转换为 kernel metric 的定理，再用 composition/contraction，才可得求和式界。
## E. AI 迁移
### GEN47-E01
状态空间可取 token 序列加 `[MASK]`；声明 $q_t(x_t|x_0)$ 的独立 masking rate、从 $t$ 到 $t-1$ 的 teacher unmask/remask kernel及一致性；target 可为被 mask token 的 categorical law；部署模型只见 $x_t,t,c$；terminal prior 是全 mask 或指定简单 mask law。还需说明 absorbing/非 absorbing 与长度处理。
### GEN47-E02
对 column-stochastic matrices 检查非负、每列和 1，并计算 residual $\|R_tq_t-q_{t-1}\|_1$；随机生成多个 $x_0/t$ case，报告最大 residual、坏列、负值和 shape mismatch。失败时区分 kernel 非归一化、marginal convention 行列颠倒、索引错位与浮点 tolerance。
### GEN47-E03
可复用状态/条件对象、marginal consistency、teacher-to-deployment mixture、terminal prior 与评估接口。Gaussian noise 的线性 Gaussian posterior、epsilon/score 参数化不能直接用于 blur/deletion；blur 要处理频谱/不可逆 null space，deletion 要处理变维状态、missingness 与离散组合，因此后验、loss 和 architecture 必须重做。
