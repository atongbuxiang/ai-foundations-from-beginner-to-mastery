# 解答 - 光滑流形、切空间与余切空间

> [!important] 判断顺序
> 以下解答始终按“space/topology → chart/smooth structure → tangent/cotangent object → local rank → global map → sample/algorithm”作答。Local Jacobian 结论不能跳过 injectivity 和 topology 直接升级成 global embedding；finite-sample 现象也不能跳过统计假设升级成 population manifold theorem。

## A. 定义、对象与层级

### GEO-MAN-A01

完整类型表如下。

| 对象 | 最小条件 | 典型例子 | 典型失败 |
|---|---|---|---|
| $d$-topological manifold | Hausdorff、second-countable、每点邻域 homeomorphic to $\mathbb R^d$ open set | $S^d,T^2,\mathbb R^d$ | crossing 在交点不 locally Euclidean |
| chart $(U,\varphi)$ | $U\subset M$ open，$\varphi:U\to\varphi(U)\subset\mathbb R^d$ homeomorphism，image open | stereographic chart | angle 在整个 circle 上不一一连续可逆 |
| smooth atlas | charts cover $M$，overlap transitions 是 $C^\infty$ diffeomorphisms | sphere stereographic atlas | transitions 只有 continuous 而不 smooth |
| maximal atlas | 所有与给定 atlas smoothly compatible 的 charts | 一个 smooth structure 的完整代表 | 不是“取更多训练 patches” |
| manifold with boundary | 局部模型允许 $\mathbb H^d$ | $[0,1]$、closed disk | 当作无边界 manifold 会在端点失败 |
| immersed submanifold | 来自 immersion 的局部 image 结构 | figure-eight regular parametrization | image 自交处不一定 embedded |
| embedded submanifold | subset topology正确，inclusion 是 embedding | sphere、regular level set | 两条相交直线 |

三个维数必须分开：

- intrinsic dimension $d=\dim T_pM$；
- ambient dimension $D$ 是一次 embedding $M\subset\mathbb R^D$ 的外部维数；
- latent dimension $k$ 是模型选的 code space 维数，可能等于、低于或高于 $d$。

Hausdorff 使不同点可分离并保证 limits 正常唯一；second-countable 提供可数 basis，使 atlas、paracompactness 等全局技术可管理；locally Euclidean 提供局部拓扑坐标；smooth transitions 使微分不依赖 chart。

分类：

1. $\mathbb R^d$ 是 abstract/embedded $d$-manifold，并有 global chart。
2. $S^1$ 是 compact embedded 1-manifold，需要多 charts。
3. $[0,1]$ 是 1-manifold with boundary，不是无边界 1-manifold。
4. 两相交直线在交点不是 1-manifold。
5. finite set 配 discrete topology 是 0-manifold；这不代表潜在生成分布维数为0。
6. Torus 是 compact 2-manifold，可 embedded in $\mathbb R^3$。
7. Figure-eight regular parametrization可给 immersed circle/line，但 self-intersecting image 不是 embedded 1-submanifold。

### GEO-MAN-A02

| 对象 | 类型 | Coordinate representation |
|---|---|---|
| $v\in T_pM$ | curve velocity class / derivation | $d$ components $v^i$ |
| $\alpha\in T_p^*M$ | linear map $T_pM\to\mathbb R$ | $d$ components $\alpha_i$ |
| $dF_p$ | $T_pM\to T_{F(p)}N$ linear | $m\times d$ Jacobian |
| $df_p$ | $T_pM\to\mathbb R$ | row/covector components $\partial_i f$ |
| $TM$ | disjoint union $\bigsqcup_pT_pM$ | local $\varphi(U)\times\mathbb R^d$ |
| $T^*M$ | disjoint union $\bigsqcup_pT_p^*M$ | local $\varphi(U)\times(\mathbb R^d)^*$ |
| vector field | section $X:M\to TM$ | $X^i(x)\partial_i$ |
| 1-form | section $\omega:M\to T^*M$ | $\omega_i(x)dx^i$ |

Pushforward $dF_p$ sends tangent forward；cotangent pullback

$$
F_p^*:T_{F(p)}^*N\to T_p^*M,
\qquad
F_p^*\beta=\beta\circ dF_p
$$

sends covectors backward。

命题判断：

1. **错误。** $T_pM,T_qM$ 是不同 fibers。它们同维、非典范 isomorphic；未给 connection/transport 时没有 canonical identification。
2. **错误。** $df_p\in T_p^*M$。需 metric $g_p$ 才能由 $g_p(\operatorname{grad}f,v)=df_p(v)$ 得 gradient。
3. **错误。** Jacobian matrix 随 source/target bases 改变；intrinsic linear map与 rank 不变。
4. **正确。** Components 反向变换，pairing保持 scalar。
5. **错误。** $df$ 是 exact 1-form；一般 1-form未必 exact。Circle 上的 global closed/nonexact examples需 exterior calculus 才完整表述。

### GEO-MAN-A03

| 概念 | Local differential | Global requirement | 不能推出 |
|---|---|---|---|
| immersion | injective，rank $d$ | 无 | injectivity、embedded image |
| submersion | surjective，rank $m$ | 无 | one-to-one |
| local diffeomorphism | $d=m$、isomorphism | 每点局部逆 | global inverse |
| embedding | immersion | homeomorphism onto image | metric preservation |
| diffeomorphism | differential isomorphism | smooth bijection + smooth inverse | isometry |
| isometry | differential preserves metric | 通常要求 map/metric 条件 | 若只 local isometry，不自动 global bijection |

Decoder 声明阶梯的缺口：

1. Sampled full rank只说明 tested points 的 numerical singular values超过阈值；缺 continuous-region coverage、precision 与 rank stability。
2. 若在 open region everywhere full rank，得到 immersion；仍缺 global injectivity和 proper/topological behavior。
3. 要称 embedding，还需 one-to-one、inverse 对 image continuous，排除 self-intersection/escaping sequence。
4. 即使 decoder image是 embedded manifold，它仍是 model manifold；要称 population model需说明真实 distribution 到该 image 的 approximation、noise、sampling与 reference measure。

## B. Charts、切空间与 Jacobian 手算

### GEO-MAN-B01

从 $t=u_N=x/(1-y)$ 联立 $x^2+y^2=1$，解得

$$
u_N^{-1}(t)
=\left(\frac{2t}{1+t^2},\frac{t^2-1}{1+t^2}\right).
$$

同理

$$
u_S^{-1}(s)
=\left(\frac{2s}{1+s^2},\frac{1-s^2}{1+s^2}\right).
$$

在同时避开南北点的 overlap，代入可得

$$
s=u_S(u_N^{-1}(t))=\frac1t,
\qquad t\ne0.
$$

其 derivative 为

$$
\frac{ds}{dt}=-\frac1{t^2}.
$$

对 $p=(1,0)$，$t=s=1$。若 $[v]_t=a$，则

$$
[v]_s=\frac{ds}{dt}a=-a.
$$

若 $\alpha=b,dt$，则用 $dt/ds=-1/s^2$，在 $s=1$：

$$
\alpha=-b,ds.
$$

Pairing 检查：

$$
\alpha(v)=ba=(-b)(-a).
$$

Angle $\theta$ 若取 $[0,2\pi)$，domain不是 Euclidean open set且 inverse 在接缝不连续；若取 $\mathbb R$，map周期性非 injective。因此只能在删掉一点/选定 branch 后作为 local chart。

### GEO-MAN-B02

**1. Sphere。** 设 $F(x)=\|x\|^2$，则 $DF(p)v=2p^\top v$。对

$$
p=\frac13(1,2,2),
$$

$$
T_pS^2
=\{v\in\mathbb R^3:v_1+2v_2+2v_3=0\}.
$$

可取 basis $( -2,1,0)^\top,(-2,0,1)^\top$。

**2. Paraboloid。**

$$
J_g(u,v)=
\begin{bmatrix}1&0\\0&1\\2u&2v\end{bmatrix}.
$$

在 $(1,-1)$，点是 $(1,-1,2)$，tangent basis为

$$
(1,0,2)^\top,
\qquad
(0,1,-2)^\top.
$$

**3. Matrix sphere。** 对 $c(W)=\frac12\|W\|_F^2$，

$$
dc_W[Z]=\langle W,Z\rangle_F,
$$

所以

$$
T_WM=\{Z:\langle W,Z\rangle_F=0\}.
$$

**4. Stiefel。** 对 curve $Y(t)$ 满足 $Y(t)^\top Y(t)=I$，求导：

$$
Y^\top Z+Z^\top Y=0,
\qquad Z=Y'(0).
$$

因此

$$
T_Y\mathrm{St}(n,r)
=\{Z:Y^\top Z+Z^\top Y=0\}.
$$

**5. Dimension。** Ambient有 $nr$ 自由度。Constraint $Y^\top Y-I=0$ 取值于 symmetric $r\times r$ matrices，其独立维数是

$$
\frac{r(r+1)}2,
$$

不是 $r^2$；off-diagonal equations重复。故

$$
\dim\mathrm{St}(n,r)
=nr-\frac{r(r+1)}2.
$$

### GEO-MAN-B03

$$
J_g=
\begin{bmatrix}
1&0\\0&1\\2u&2v
\end{bmatrix}
\in\mathbb R^{3\times2},
\qquad
J_E=
\begin{bmatrix}
1&0&0\\0&1&0
\end{bmatrix}
\in\mathbb R^{2\times3}.
$$

$J_g$ full column rank，$J_E$ full row rank。令 $w=(u,v)^\top$，

$$
J_g^\top J_g=I_2+4ww^\top.
$$

其 eigenvalues 是 $1$ 与 $1+4\|w\|^2$，故

$$
\sigma_{\min}(J_g)=1,
\qquad
\sigma_{\max}(J_g)=\sqrt{1+4(u^2+v^2)}.
$$

直接有 $E(g(u,v))=(u,v)$，且

$$
J_EJ_g=I_2.
$$

而

$$
P=J_gJ_E
=\begin{bmatrix}
1&0&0\\
0&1&0\\
2u&2v&0
\end{bmatrix}.
$$

由 $J_EJ_g=I$，

$$
P^2=J_g(J_EJ_g)J_E=P.
$$

但除 $u=v=0$ 外 $P\ne P^\top$，所以不是 Euclidean orthogonal projector；它沿 encoder kernel方向做 oblique projection。

真正 orthogonal projector是

$$
P_\perp
=J_g(J_g^\top J_g)^{-1}J_g^\top.
$$

利用 Sherman–Morrison，

$$
(I+4ww^\top)^{-1}
=I-\frac{4ww^\top}{1+4\|w\|^2}.
$$

代入即可得到 symmetric idempotent matrix。$E(x,y,z)=(x,y)$ 选择沿 vertical coordinate fibers投影，不是沿 surface normal投影；因此 left inverse不决定 orthogonality。

对

$$
\tilde g(u,v)=(u^2,v,u^2+v^2),
$$

$$
J_{\tilde g}
=\begin{bmatrix}
2u&0\\0&1\\2u&2v
\end{bmatrix}.
$$

当 $u=0$ 第一列为零，rank降为1；当 $u\ne0$ 两列线性独立，rank为2。Collapse locus 是整条 $u=0$。

## C. 定理、等价定义与证明链

### GEO-MAN-C01

取 source charts $x,\tilde x$ 与 target charts $y,\tilde y$。若

$$
\widehat F_{y\leftarrow x}=y\circ F\circ x^{-1}
$$

smooth，则

$$
\widehat F_{\tilde y\leftarrow\tilde x}
=(\tilde y\circ y^{-1})
\circ\widehat F_{y\leftarrow x}
\circ(x\circ\tilde x^{-1}).
$$

两侧 transition maps由 atlas compatibility smooth，所以新 coordinate representative smooth。反向交换两组 charts 同理，故 definition chart-independent。

对上式求 derivative：

$$
[dF_p]_{\tilde y\leftarrow\tilde x}
=D(\tilde y\circ y^{-1})_{y(F(p))}
[dF_p]_{y\leftarrow x}
D(x\circ\tilde x^{-1})_{\tilde x(p)}.
$$

这就是题中公式。左右 transition Jacobians 均 invertible。

**Curve proof of chain rule。** 对 $v=[\gamma]$，

$$
d(G\circ F)_p(v)
=[G\circ F\circ\gamma]
=dG_{F(p)}([F\circ\gamma])
=dG_{F(p)}(dF_pv).
$$

**Derivation proof。** 对 $h\in C^\infty(P)$，

$$
\begin{aligned}
(d(G\circ F)_pv)[h]
&=v[h\circ G\circ F]\\
&=(dF_pv)[h\circ G]\\
&=(dG_{F(p)}(dF_pv))[h].
\end{aligned}
$$

两 derivations对所有 test functions作用相同，故相等。

Rank在换 charts 后变为

$$
\operatorname{rank}(A J B),
$$

其中 $A,B$ invertible。Invertible left/right multiplication不改变 image dimension，故 $\operatorname{rank}dF_p$ intrinsic。

### GEO-MAN-C02

在 $x\in M$，$DF(x)$ rank $k$。某个 $k\times k$ minor invertible。将 ambient coordinates重排为 $(u,w)\in\mathbb R^{D-k}\times\mathbb R^k$，使

$$
D_wF(x)
$$

invertible。Implicit function theorem给 neighborhoods与 smooth $h$，使附近 solutions恰为

$$
w=h(u).
$$

所以 local parametrization

$$
u\mapsto(u,h(u))
$$

有 $D-k$ coordinates，证明 $M$ 是 $D-k$ dimensional embedded submanifold。

对任意 tangent curve $\gamma(t)\subset M$，

$$
F(\gamma(t))=c
$$

求导得 $DF(x)\gamma'(0)=0$，故

$$
T_xM\subseteq\ker DF(x).
$$

Rank-nullity给

$$
\dim\ker DF(x)=D-k=\dim T_xM,
$$

所以两个 subspaces相等。也可由 graph parametrization直接构造 kernel vector对应的 curve。

将 $F=(c_1,\ldots,c_k)$，则

$$
DF(x)v=(dc_1|_x(v),\ldots,dc_k|_x(v)).
$$

每个 $dc_i$ annihilate $T_xM$。它们因 $DF$ full row rank而线性独立；annihilator dimension为

$$
D-(D-k)=k,
$$

故它们构成 basis。

在 Euclidean inner product 下，Riesz identification把 $dc_i$ 对应为 $\nabla c_i$，于是

$$
N_xM=\operatorname{span}\{\nabla c_1(x),\ldots,\nabla c_k(x)\}.
$$

这是 ambient metric提供的 identification，不是 cotangent definition本身。

删除 regular-value condition，取 $F(x,y)=x^2-y^2$。在原点 $DF=0$，没有 invertible $1\times1$ minor，IFT graph step失败；kernel是整个 $\mathbb R^2$，却无法成为 crossing 的一维 tangent，dimension argument也失效。

### GEO-MAN-C03

给 through-$p$ curve $\gamma$，定义

$$
v_\gamma[f]
=\frac d{dt}f(\gamma(t))\bigg|_0.
$$

一元 derivative线性；product rule给

$$
v_\gamma[fg]
=f(p)v_\gamma[g]+g(p)v_\gamma[f].
$$

所以它是 derivation。

若 $\gamma_1,\gamma_2$ 在 chart $x$ 中 velocity同为 $a$，则

$$
v_{\gamma_j}[f]
=D(f\circ x^{-1})(x(p))a,
$$

两者相同。换 chart 时 transition chain rule同时乘 invertible Jacobian，因此 equivalence intrinsic。

反过来给 derivation $v$。在 local coordinates令

$$
v^i=v[x^i].
$$

对任意 $f$，Hadamard/Taylor 一阶分解写成

$$
f(q)-f(p)
=\sum_i(x^i(q)-x^i(p))g_i(q),
$$

其中 $g_i(p)=\partial_i(f\circ x^{-1})(x(p))$。应用 $v$；由 $v$ 消去常数和 Leibniz rule，得到

$$
v[f]
=\sum_i v^i\partial_i(f\circ x^{-1})(x(p)).
$$

故 $v$ 由 components唯一决定。

取 coordinate straight curve

$$
\gamma(t)=x^{-1}(x(p)+t(v^1,\ldots,v^d))
$$

（对足够小 $t$），其 velocity恰为这些 components，因此产生 $v$。Curve classes与 derivations双射，且 $T_pM\cong\mathbb R^d$，所以 dimension $d$。

设 $y=y(x)$。Vector components由

$$
[v]_y=J_{y\leftarrow x}[v]_x
$$

变换。要求 scalar pairing不变：

$$
[\alpha]_y^\top J_{y\leftarrow x}[v]_x
=[\alpha]_x^\top[v]_x
$$

对所有 $v$ 成立，所以

$$
[\alpha]_y=J_{y\leftarrow x}^{-\top}[\alpha]_x.
$$

于是

$$
[\alpha]_y^\top[v]_y
=[\alpha]_x^\top J^{-1}J[v]_x
=[\alpha]_x^\top[v]_x.
$$

$df_p$ 是特殊 covector，因此 $df_p(v)$ 同样 coordinate invariant。

## D. 反例、条件删除与错误研究声明

### GEO-MAN-D01

**1. Crossing $xy=0$。** 原点任意足够小 neighborhood删去原点有四个 components；open interval删一点只有两个。故原点不 locally Euclidean dimension 1。其余点各有 line neighborhood。可视作四条 1-dimensional strata粘在 0-dimensional singular stratum。

**2. $[0,1]$。** Interior points像 open interval，端点只像 half-interval。它是 manifold with boundary，boundary为 $\{0,1\}$；不是无边界 1-manifold。

**3. Double cone $z^2=x^2+y^2$。** Apex删去后局部分成 upper/lower两个 components，而 punctured open disk in $\mathbb R^2$ connected，故 apex不 locally Euclidean 2D。可视为 two conical sheets带 singular stratum。

**4. Two tangent spheres。** Tangency point删去后，足够小 neighborhood分成来自两个 spheres 的两个 components；punctured 2-disk connected。不是 2-manifold，可视为 union/stratified object。

**5. Line with two origins。** 每个点 locally像 $\mathbb R$，通常也 second-countable，但两个 origins 的任意 neighborhoods相交，不能 Hausdorff。因此不是本课程定义下的 manifold。

**6. Uncountable discrete space。** 每点 singleton像 $\mathbb R^0$，且 Hausdorff。若有 countable basis，每个 singleton必须由 basis elements union表示，而 singleton open迫使每点至少有一个 distinct basis element；这与 uncountable矛盾。故非 second-countable 0-manifold。

### GEO-MAN-D02

**1. Immersion not embedding。**

$$
f(t)=(\sin t,\sin2t).
$$

Derivative

$$
f'(t)=(\cos t,2\cos2t)
$$

不可能两项同时为零，所以是 immersion。可是 $f(0)=f(\pi)=(0,0)$，非 injective，image有 self-intersection，故不是 embedding。

**2. Local not global diffeomorphism。**

$$
q:\mathbb R\to S^1,
\qquad q(t)=(\cos t,\sin t).
$$

$q'(t)\ne0$，source/target均一维，所以 everywhere local diffeomorphism；但 $q(t+2\pi)=q(t)$，不是 global one-to-one。这也是 covering map。

**3. Finite memorization。** Population set取 $M=[-1,1]$，training set仅 $\{0,1\}$。令

$$
E(x)=x^2,
\qquad
g(z)=\sqrt z
$$

在 $z\in[0,1]$。训练点 reconstruction exact，但负半轴被映成正半轴：$g(E(x))=|x|$，encoder还把 $x,-x$ 粘合。Finite zero loss完全不能推出 population homeomorphism。

同理，在1000个 samples上 $J_g$ full rank只排除这些测试点的 rank collapse；连续区域中间仍可 collapse，远处可 self-intersect，map可 periodic，多点可逃向同一 limit。Global embedding需要全域 rank、injectivity与 topology/properness等证明。

### GEO-MAN-D03

**1. Local PCA 两大特征值。** 证据不足。它表明选定 metric/radius/sample下 covariance近似 rank 2；noise、anisotropic density、two crossing lines或薄椭球都可产生类似谱。修正版：“在 radius $r$ 与该样本上观察到二维 local linearity”。诊断：radius/sample/noise sweep、eigengap、projector bootstrap、boundary标记。

**2. Decoder $\sigma_{\min}>0$。** 若只 sampled则更弱；即使 everywhere immersion，也不保证 global injectivity或 latent segment image位于 high-density data region。诊断：collision search、coverage、held-out density、path rank与condition sweep。

**3. Small reconstruction。** 不给 injectivity、inverse continuity或 topology。Finite memorization是反例。诊断：off-sample round trip、latent/data cycles、collision、transition、topology-aware tests；仍需 population assumptions。

**4. Tangent flat。** 每个 tangent space本来是 vector space；curvature描述 tangent spaces随位置及 metric/connection的变化，不由单个 tangent plane的平直性决定。Sphere反例。

**5. $df$ vs gradient。** $df\in T_p^*M$，gradient属于 $T_pM$。Row/column只是 coordinate matrix表现；identification需要 metric，换 metric gradient会改变而 $df$ 不变。

**6. Finite data is 0-manifold。** 裸 finite topology确实 discrete，但 intrinsic-dimension estimators研究带 metric scale的 sample与潜在 population model。修正版必须声明 estimator、radius、noise与 sampling assumptions。

六本账为：

| 账本 | 对象 | 典型诊断 |
|---|---|---|
| population | $P$、support/manifold hypothesis | model assumptions、theorem |
| sample | $x_1,\ldots,x_n$ | bootstrap、coverage |
| scale | radius/$k$NN/metric | multiscale sweep |
| network | $E,g$ as functions | rank、collision、cycles |
| computation | autodiff/SVD/precision | FD spot check、tolerance |
| theorem | local/global hypotheses | assumption checklist |

## E. AI 综合建模与研究设计

### GEO-MAN-E01

以 circle 为例，可用两个 charts $c\in\{N,S\}$。Encoder输出 routing weights与 local coordinates：

$$
E(x)=\bigl(\pi_N(x),\pi_S(x),z_N(x),z_S(x)\bigr),
$$

其中 $x\in\mathbb R^2$，$z_c\in\mathbb R$，$\pi_c\in[0,1]$ 且和为1。Decoders

$$
g_c:U_c\subset\mathbb R\to\mathbb R^2
$$

各自只负责避开一个 pole 的区域。

Coverage可由 soft partition $\pi_N+\pi_S=1$ 与每个 data point至少一项超过阈值保证；overlap定义为两 routing weights都非小量的区域。Transition networks

$$
\tau_{SN}:z_N\mapsto z_S,
\qquad
\tau_{NS}:z_S\mapsto z_N
$$

在理想 stereographic case互为 $z\mapsto1/z$。训练/验收包括：

$$
\|g_c(z_c)-x\|,
\quad
\|\tau_{dc}(z_c)-z_d\|,
\quad
\|\tau_{cd}(\tau_{dc}(z_c))-z_c\|,
$$

以及 triple-overlap时的

$$
\tau_{ac}\approx\tau_{ab}\circ\tau_{bc}.
$$

再报告 $J_{g_c}$ minimum singular value、transition derivative、chart usage entropy与 uncovered mass。

防 collapse：每 chart设最小/最大使用率或 coverage regularizer；防 duplicate coverage：允许 overlap但惩罚远离规定 overlap 的冗余；防 uncovered：对每点强制至少一 chart有低 reconstruction；routing应在 overlap平滑而非 hard discontinuous。

Single interval latent若要表示 circle，只能 cut一个 seam、重复 endpoints、使用 periodic quotient或产生 distortion。Torus需要至少处理两个周期方向，单 Euclidean rectangle若不 glue opposite boundaries仍不是 torus。

实验应在 train/held-out均匀与非均匀 samples、多 seeds、missing arc下报告。它能支持“learned local models与 tested transitions表现得像 atlas”，不能证明 chart maps在 population open sets上是 exact homeomorphisms，也不能证明 atlas covers unseen support。

### GEO-MAN-E02

一个合格 benchmark 可选 paraboloid

$$
g(u,v)=(u,v,\kappa(u^2+v^2))
$$

或 circle。Paraboloid ground-truth tangent basis由

$$
J_g(u,v)=
\begin{bmatrix}
1&0\\0&1\\2\kappa u&2\kappa v
\end{bmatrix}

### GEO-MAN-E03

合同可写为：

| 项 | 声明 |
|---|---|
| latent/base | $Z\subseteq\mathbb R^d$，base density相对 $d$-Lebesgue |
| geometric object | embedded $M\subseteq\mathbb R^D$，$d<D$，可能需 atlas $\{g_c\}$ |
| map | $g_c:Z_c\to M_c$ full-rank immersion；若 one-to-one 且 topology正确才称 embedding |
| manifold density | 相对 intrinsic volume；local factor $\sqrt{\det(J_g^\top J_g)}$ |
| ambient law | 若 exactly on $M$，相对 $D$-Lebesgue singular，无普通 ambient density |
| noisy observation | $x=g(z)+\epsilon$ 产生 full-dimensional convolution density，已改变对象 |
| overlaps | partition-of-unity/chart responsibility，避免 double count，并检验 transition density consistency |
| failures | rank collapse、self-intersection、uncovered chart、boundary、topology mismatch |

若使用 flow $h:Z\to Z$，它可在 latent chart内做 diffeomorphism；decoder再把 latent送到 manifold。若直接用 ambient $D$-dimensional normalizing flow，则生成 full-dimensional law，除非引入 singular limit或 projection。Sampling、intrinsic density evaluation、noisy ambient likelihood和 training surrogate必须分别报告。

Circle/torus等非单 chart topology可用 structured latent（periodic/quotient）、multiple charts或更高维 embedding。Augmented variables若最终 projection，会改变 injectivity与 density ledger，不能简单称同一个 diffeomorphic flow。

审稿意见示例：

> 文稿从 ambient likelihood 改善直接推断模型恢复了真实低维流形及其 topology，结论超出证据。若模型相对 $D$ 维 Lebesgue 测度有普通 density，它与严格 $d<D$ 的 manifold-supported law 属于不同测度对象。请明确 intrinsic/ambient dimensions、reference measure、observation noise与 decoder rank，并报告 self-intersection、chart coverage和 tangent/subspace diagnostics。Held-out likelihood只能评价指定 noisy density model，不能单独证明 support smoothness、homeomorphism或正确 topology。

## 结课检查

完成本题组后，应能独立写出以下三条：

1. A chart 是 open manifold neighborhood 到 Euclidean open set 的 homeomorphism；smoothness来自 overlap transitions。
2. Tangent vector向前 push、covector向后 pull；$df$ 在没有 metric时不是 gradient。
3. Decoder Jacobian/local PCA给 local first-order evidence；global embedding和 population manifold仍需额外条件。
