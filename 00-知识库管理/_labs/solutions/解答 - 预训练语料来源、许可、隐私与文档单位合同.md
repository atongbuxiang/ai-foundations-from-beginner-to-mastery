# 解答 - 预训练语料来源、许可、隐私与文档单位合同

## A. 识别与复述

### LM17-A01
Asset 是来源系统中的作品/记录；capture 是某时刻抓到的 bytes 与协议 metadata；parsed document 是 parser 的有损派生；selected example 是治理/质量/去重后的保留对象；token sequence 由 tokenizer/边界生成；loss event 是 shift/mask 后真正计分的位置。它们有不同 id、单位和删除范围。

### LM17-A02
访问/robots 管抓取行为，内容许可管作品权利，隐私同意关乎数据主体与语境，用途审批还依法域/部署。任何一层为允许都不推出其余层允许；`is_open` 会丢掉证据、条件、未知和版本。

### LM17-A03
WARC 可保存 record id、URI、date、request/response、payload digest、metadata 与 derivation/duplicate relation。它不证明正文抽取正确、作者身份、内容许可、训练授权、无 PII 或 parser 无损。

## B. 手算与构造

### LM17-B01
例如 `E0(raw URI+bytes hash h0) --A1(crawl config c1)→ E1(WARC id w1/hash h1) --A2(parser commit p2)→ E2(text hash h2) --A3(tokenizer hash t3)→ E3(shard hash h3,offset)`. 每个 activity 还关联 time、agent、container 和 config；最终 offset 必须能逆向定位 parent record。

### LM17-B02
方案一以 thread 为 document：保留对话上下文，但多作者权利/删除绑定一个大单位，长 thread 每次抽样权重低。方案二以 post 为 document：每作者/删除粒度清楚，但引用文本可能跨 posts 重复，丢上下文，thread 有 5 倍 document-uniform 抽样机会。可折中保存 thread parent 与 post offsets。

### LM17-B03
未归一保留质量：$w_1=.7(.5)(.8)(.5)=.14$，$w_2=.3(.9)(.5)(.5)=.0675$；总 `.2075`。最终比例约 $U_1=.14/.2075=0.6747$，$U_2=0.3253$。原始 70/30 被多个 selection mechanism 改为约 67.5/32.5。

## C. 推导与证明

### LM17-C01
联合权重为 $P_U(u)P(capture\mid u)P(parse=d\mid u,capture)P(keep\mid d)$；对所有可能 d 归一化，即 $Q(d)=w(d)/\sum_{d'}w(d')$。若过程确定，概率退化为 0/1 indicator；结论仍是条件选择分布。

### LM17-C02
若 asset A 被切成 10 documents、B 切成 1，document-uniform 抽样使 A 获得 $10/11$、B $1/11$，即使 asset-uniform 原本各 $1/2$。所以 segmentation $K(u)$ 进入 inclusion weight；换段落规则就换经验分布。

### LM17-C03
Tokenization/normalization/parse 常多对一：不同 HTML 模板可抽出同正文，不同 Unicode/whitespace 可规范化为同 tokens，tokenizer 还不保存 HTTP metadata。一个 shard 的 token sequence有多个可能 raw ancestors；无 parent map/hash 不能唯一逆演。

## D. 边界、反例与纠错

### LM17-D01
Common Crawl 对其服务的访问条件与 crawled content 的第三方权利分层；页面可含不同作者、license、数据库条款与法域。能访问 archive 不是每个 asset 的统一内容许可。真实判断需最新来源证据和合格审查。

### LM17-D02
公开页可能含电话号码、地址、未成年人信息、被他人转载的私密材料或可重识别组合；公开语境也不等于预期大规模训练与生成复现。应做 purpose/threat-model 下的隐私评估与删除机制。

### LM17-D03
完整原文能帮助追溯，却扩大敏感数据保存面、访问风险和保留期限。可用受控 raw vault、分级权限、hash/删除 key、最小 metadata与保留期平衡；provenance 不是无限收集授权。

## E. AI 迁移

### LM17-E01
至少含 source/capture IDs、raw digest、time、parser/normalization、document parent+offset、LID/rights/privacy evidence、所有 transforms/reason、dedup cluster、tokenizer+counts、shard offset、agent/approval/expiry、删除 key。敏感字段须分级访问。

### LM17-E02
按来源/语言/长度/权利状态分层随机抽 20 个 final samples，逆向核对每条 edge/hash与正文；失败分 schema missing、hash mismatch、source unavailable、rights unknown。阻断相关 shard发布，扩样估计失效率，修复后生成新 manifest，不覆盖旧版。

### LM17-E03
URL 数不说明成功抓取/解析/document unit/长度；顶层 Apache 可能只覆盖代码/metadata，未列 ancestor content licenses、privacy/PII、法域、用途、时间、transform、去重和删除。无法由该卡判断可复现或适用，必须降级为 provenance unknown。
