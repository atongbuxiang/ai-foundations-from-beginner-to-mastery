# 解答 - 深度泛化证据地图与开放问题
## A
### LT-DGM-A01
现象是可复现 observation；机制说明生成它的过程；风险定理在明确假设/概率量词下控制未知样本；数值证书把界算到特定模型；部署结论还处理 shift、反馈和外部效度。前一层不能自动升级为后一层。
### LT-DGM-A02
它直接反驳“architecture 本身因容量不足而不能记忆”“零训练误差足以保证泛化”等粗解释，并显示常用 optimizer 可找到 memorizing solution；它没有反驳训练后 norm、margin、stability、data structure 或 algorithm-dependent theory。
### LT-DGM-A03
核心五项可写为：数学/统计正确性、数值 nonvacuity、趋势/区分预测、等价参数化不变性、controlled-intervention 价值。另应检查 post-selection 与 deployment 外部效度。
## B
### LT-DGM-B01
若 risk 平凡上界为 1，$0.83<1$，所以 technically nonvacuous；但它比真实 $0.03$ 松很多，也未证明正确趋势或机制，不能据此称为充分解释。
### LT-DGM-B02
选择最大相关性本身利用了全部数据，产生 multiple-comparisons/winner's-curse；固定单指标的 p-value 未对选择事件校正。应预注册、数据拆分或做 family-wise/FDR/selection-aware correction，再在独立 sweep 复验。
### LT-DGM-B03
training loss 下降：优化现象；kernel drift 小：regime/机制诊断证据；PAC-Bayes bound 0.4：若假设/计算正确，是数值风险证书；OOD accuracy 下降：部署/shift 现象，显示 ID bridge 断裂。
## C
### LT-DGM-C01
先由 optimizer/init/parameterization 的 dynamics theorem确定 selected solution；再证明该解有小 norm、大 margin、适合的数据谱或表示；最后以容量、稳定性、PAC-Bayes、kernel/统计 theorem 接到 risk。第一箭头可因有限时间/优化器变化失败，第二可因指标坐标伪影或错误数据对齐失败，第三可因 bound vacuous、采样/shift 假设失败。
### LT-DGM-C02
反例通常针对特定 function/output class、two-sided supremum、algorithm-independent或某种 algorithm-dependent restriction，以及特定数据构造。它不量化否定局部化、one-sided、stability、compression、PAC-Bayes、information 或其他 data-dependent方法；结论应是该路线不是完整解释，而非逻辑上的全称不可能。
### LT-DGM-C03
nonvacuous 只表示比 trivial bound 小；它可能随 width/noise 呈错误趋势。趋势正确可能来自 confound，不说明干预该 proxy 会改变 risk。干预有效也可能仅在一个 setting，不提供 universal high-probability bound。因此三者需分别验证。
## D
### LT-DGM-D01
“平坦”需定义且过 raw parameterization invariance；还需证明 SGD 确实选中、指标不是坐标伪影、与 function/data complexity 相连，并给 risk bridge或干预。否则只有隐式选择叙述。
### LT-DGM-D02
训练拟合只说明 kernel Gram 在训练集上可表达 labels。feature learning 对 target alignment、sample efficiency、transfer、robustness 和 shift 可能关键；应比较 fixed-kernel 与 representation-changing models 的受控预测。
### LT-DGM-D03
ID split 只估计同一 sampling law 下风险。covariate/concept shift、feedback、rare subgroups、adversarial inputs 与 contamination 会改变 estimand；需要 shift assumptions、monitoring、subgroup/temporal/external validation，不能从 ID accuracy 推出部署安全。
## E
### LT-DGM-E01
竞争机制例：小奇异值 noise amplification 预测 ridge/谱截断会压低阈值峰；min-norm谱尾吸噪预测保持 trace 时提高 tail effective rank 会改善峰后风险；feature learning预测冻结 features/NTK scaling 会削弱第二次下降或迁移收益。实验需锁 sample、optimizer、compute 与 selection protocol。
### LT-DGM-E02
先在 training sweeps 建 proxy，独立 validation sweep确认趋势并做重缩放 stress test；再构造近似保持训练 loss/architecture的数据或正则干预，只改变 proxy；预注册方向和 effect size，在多个数据分布/seed复验，同时测中介变量并报告失败条件。
### LT-DGM-E03
claim card：data unit/law/shift；network/parameterization；init/optimizer/compute；loss/risk；现象；竞争机制；准确 theorem/量词；certificate与估计误差；invariance/nonvacuity/trend/intervention；极限顺序；适用域。反证账本列 prediction、操作化、阈值、结果、是否反驳、替代解释和措辞降级。
