# 解答 - 全量微调、冻结表示与灾难性遗忘

## A. 识别与复述

### LM28-A01
Trainable count 数开放更新的坐标；parameter drift 数权重空间位移；functional drift 在 probe inputs 上比 logits/distributions/representations；capability change 在任务/系统指标上比行为。四者相关但无一般单调等价。

### LM28-A02
Full tuning 允许几乎所有坐标移动；partial freezing 只开放指定层/模块；frozen probe 固定表示，仅学习 head，测试该表示对特定 readout 的可用性。它们限制可达函数族、状态存储和优化，不直接保证质量/保留。

### LM28-A03
Loss 越低越好时，$\Delta_{old}=R_{old}(\theta_1)-R_{old}(\theta_0)$；正值为遗忘。$\Delta_{new}=R_{new}(\theta_1)-R_{new}(\theta_0)$；负值为改善。指标方向必须声明。

## B. 手算与构造

### LM28-B01
$\Delta_{old}=1.35-1.0=+0.35$，旧域退化；$\Delta_{new}=1.2-2.0=-0.8$，新域改善。应联合报告 trade-off，不能只报 -0.8。

### LM28-B02
2M/100M=2%，8M/100M=8%。比例不能推出 frozen base storage、activations、temporary buffers、forward FLOPs、optimizer dtype、communication、peak reserved 或 wall time；两方案 target layers 也可能不同。

### LM28-B03
令大量样本在 base classifier 上 margin 都为 $\varepsilon>0$，例如 logit $f(x)=b=\varepsilon$。只把 bias 改为 $b'=-\varepsilon$，参数变化 $2\varepsilon$ 可任意小，却使全部预测从正翻负。这说明低-margin slice 对小更新敏感。

## C. 推导与证明

### LM28-C01
分 $\theta=(\theta_F,\theta_T)$：$\theta_{F,t+1}=\theta_{F,t}$，$\theta_{T,t+1}=\theta_{T,t}-\eta_t\nabla_{\theta_T}\mathcal L_t(\theta_F,\theta_T)$。若 optimizer 有 momentum/state，也只为 $T$ 更新但 forward 仍用两者。

### LM28-C02
参数有 scale/permutation 对称性，大距离可同函数；probe 低-margin/high-Jacobian 处小距离可大 KL。Functional KL 还依 $P_X$。没有对 Jacobian、参数化和输入分布的 Lipschitz/identifiability 条件，无法单调推出。

### LM28-C03
可写 $\min_\theta R_{new}(\theta)+\lambda R_{old}(\theta)+\gamma\Omega(\theta,\theta_0)$。Replay 用旧样本估 $R_{old}$；parameter/function regularizer 实现 $\Omega$。$\lambda,\gamma$ 定义 stability–plasticity 权衡和预算。

## D. 边界、反例与纠错

### LM28-D01
最后 1% 参数可能直接控制全部 logits，低-margin 样本可大量翻转；LoRA/adapter 也能改关键路径。Trainable share 是坐标/状态指标，遗忘是旧数据上的功能差，必须测。

### LM28-D02
多 checkpoints 中按最小新域 validation 选 winner，会对新域过拟合选择，并条件化旧域报告于该事件；其他 checkpoints 的较佳 trade-off 被隐藏。应画全路径 Pareto、独立 final test 或预注册 stopping。

### LM28-D03
冻结省 gradients/optimizer states，但仍需 base storage、完整 forward、部分 activations、I/O 与 kernel；训练时间可能受 frozen forward/communication/underutilization 主导。只有同硬件 end-to-end profile 能给比例。

## E. AI 迁移

### LM28-E01
固定 base/data/order/template/targets/FLOPs，训练 full、多个 freeze sets、PEFT，多 seed；每 checkpoint 测 new gain、old retention、安全/calibration，画 Pareto；并报 peak memory、throughput、parameter/function drift 和 search budget。

### LM28-E02
参数层：layerwise norm/cosine、trainable set；函数层：固定 probe logits KL、representation CKA、calibration；能力层：paired new/old/safety/OOD metrics + CI。全部绑定 checkpoint、template、sampler、eval version。

### LM28-E03
绝对低分可能是 base 本来就低，不能算 forgetting。至少需同样本/协议的 base score、差值、CI、checkpoint path 和旧任务定义；否则只能说 tuned model 在该测试上表现为某值。
