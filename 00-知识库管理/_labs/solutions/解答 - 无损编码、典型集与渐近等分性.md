# 解答 - 无损编码、典型集与渐近等分性

> [!warning] 使用边界
> Entropy 是指定 source law 下的 asymptotic benchmark，不是任意 compressor 对任意单文件的承诺。每次比较都要写明 alphabet/tokenizer、log base、block length、error criterion、model cost 和 source assumptions。

## A. 识别与复述

### INFO-CODE-A01

四类概念：

- nonsingular：不同 source symbols 有不同 codewords；
- uniquely decodable：任何有限 source-symbol sequence 的 concatenated bit string 只有一种解析；
- instantaneous/prefix：没有任何 codeword 是另一个 codeword 的 prefix，读到 codeword 末端即可解码；
- fixed-length：每个 symbol 的 codeword 长度相同。

关系是

$$
\text{fixed-length}\Longrightarrow\text{prefix}
\Longrightarrow\text{uniquely decodable}
\Longrightarrow\text{nonsingular}.
$$

逆命题一般不成立：

- ${0,01}$ uniquely decodable 但不是 prefix；
- ${0,00}$ nonsingular 但不是 uniquely decodable，因为 `00` 可解为一个或两个 symbol；
- lengths $(1,2,2)$ 的 prefix code 如 ${0,10,11}$ 不是 fixed-length。

nonsingular 只保证单个 codeword 可区分。连续发送时没有显式分隔符，跨 codeword boundary 可能产生另一种解析，所以 decoder 需要 unique decodability；prefix 是便于即时解析的更强设计。

### INFO-CODE-A02

对 binary lengths $\ell_i$：

- Kraft inequality：若存在 binary prefix code，则 $\sum_i2^{-\ell_i}\le1$；反之，任意满足此式的整数 lengths 都存在 prefix code；
- McMillan inequality：任意 uniquely decodable code 也必须满足同一 inequality；但给 lengths 构造时 Kraft converse 直接给 prefix code；
- Shannon lengths $\ell_i=\lceil-\log_2p_i\rceil$ 满足 Kraft，并给

$$
H_2(P)\le L<H_2(P)+1;
$$

- Huffman algorithm 在已知 finite alphabet probabilities、binary symbol-by-symbol prefix code 类中最小化平均 length。

Huffman optimality 不自动包含 unknown-source universal coding、block coding、model description、delay constraint、unequal letter cost 或 lossy coding。

### INFO-CODE-A03

iid finite alphabet AEP：

$$
-\frac1n\log_2p(X^n)
=\frac1n\sum_{i=1}^n[-\log_2p(X_i)]
\xrightarrow{P}H_2(X).
$$

weakly typical set 具有：probability 趋于 1；其中每个 sequence probability 约 $2^{-nH}$；cardinality 约 $2^{nH}$。

fixed-length source coding：对任意 $R>H(X)$ 存在 rate $R$ 的 block code 使 block error 趋于 0；任意 $R<H(X)$ 的 code 成功概率趋于 0（相应 error 趋于 1）。

stationary process 的 entropy rate 是

$$
\bar H(X)=\lim_{n\to\infty}\frac1nH(X^n)
=\lim_{n\to\infty}H(X_n\mid X^{n-1}),
$$

在适当条件下存在。iid AEP 只需对 self-information 用 LLN；Shannon–McMillan–Breiman 将 sample-path surprise-rate convergence 推到 stationary ergodic sources，需要 stationarity/ergodicity/integrability 等条件，不能只写“序列很长”。

## B. 手算与构造

### INFO-CODE-B01

Huffman 合并：$0.1+0.2=0.3$，再把新 $0.3$ 与原 $0.3$ 合为 $0.6$，最后与 $0.4$ 合并。一组 code 是

$$
a:0,\qquad b:10,\qquad c:110,\qquad d:111,
$$

对应 lengths $(1,2,3,3)$。平均码长：

$$
L=0.4(1)+0.3(2)+0.2(3)+0.1(3)=1.9\text{ bits}.
$$

entropy：

$$
H_2(P)=-\sum_ip_i\log_2p_i\approx1.846439\text{ bits}.
$$

故

$$
1.846439\le1.9<2.846439.
$$

Kraft sum：

$$
2^{-1}+2^{-2}+2^{-3}+2^{-3}=1,
$$

树是 complete。交换左右 branch 会得到同样最优的另一组 codewords。

### INFO-CODE-B02

任一含两个 1、六个 0 的具体 sequence probability 为

$$
p(x^8)=0.25^2 0.75^6\approx0.0111236572.
$$

每符号 surprise：

$$
-\frac18\log_2p(x^8)\approx0.811278\text{ bits}.
$$

这恰等于 $H_2(0.25)\approx0.811278$，因为该 type 的 empirical fraction 正好等于 $p$。type size 是

$$
\binom82=28,
$$

总 probability 为

$$
28(0.25^2 0.75^6)\approx0.311462.
$$

本题的 surprise 恰好等于 entropy 是参数与 type 对齐造成的 exact identity，不代表 $2^{8H}$ 是整数、type probability 接近 1，或所有 $n=8$ typical approximations 都成为等号。

### INFO-CODE-B03

由 ceiling 性质，

$$
-\log_2p(x^n)\le\ell(x^n)<-\log_2p(x^n)+1.
$$

对 $P_{X^n}$ 取 expectation：

$$
H_2(X^n)\le E\ell(X^n)<H_2(X^n)+1.
$$

iid 时 $H(X^n)=nH(X)$，除以 $n$ 得

$$
H(X)\le\frac1nE\ell(X^n)<H(X)+\frac1n.
$$

$n=100$ 时整数 rounding 引起的每符号 redundancy 严格小于 $0.01$ bit，所以 average rate 在

$$
1.846\le E\ell/100<1.856
$$

bits/symbol。这里未计 header/model/block framing cost。

## C. 推导与证明

### INFO-CODE-C01

令

$$
K=\sum_i2^{-\ell_i}\le1,
\qquad q_i=\frac{2^{-\ell_i}}K.
$$

$q$ 是 probability distribution。KL 非负给

$$
0\le D_2(P\|Q)=\sum_ip_i\log_2\frac{p_i}{q_i}.
$$

而

$$
-\log_2q_i=\ell_i+\log_2K.
$$

故

$$
\begin{aligned}
0
&\le-H_2(P)+\sum_ip_i\ell_i+\log_2K\\
&=-H_2(P)+L+\log_2K.
\end{aligned}
$$

于是

$$
L\ge H_2(P)-\log_2K\ge H_2(P),
$$

因为 $K\le1$。理想 length $-\log_2p_i$ 通常不是整数，也未必能直接作为 binary tree depth；取 ceiling 才给合法 Kraft lengths，代价是小于一 bit 的 rounding redundancy。

### INFO-CODE-C02

iid 时

$$
-\frac1n\log_2p(X^n)
=\frac1n\sum_{i=1}^n[-\log_2p(X_i)].
$$

右侧是 iid integrable random variables 的 sample mean，期望为 $H_2(X)$。weak law 给：对任意 $\varepsilon>0$，

$$
P(X^n\in A_\varepsilon^{(n)})\to1.
$$

若 $x^n\in A_\varepsilon^{(n)}$，定义直接给

$$
2^{-n(H+\varepsilon)}<p(x^n)<2^{-n(H-\varepsilon)}.
$$

对充分大 $n$，令 typical probability 至少 $1-\delta$。用每个 typical sequence 的最大 probability：

$$
1-\delta
\le\sum_{x^n\in A}p(x^n)
\le |A|2^{-n(H-\varepsilon)},
$$

所以

$$
|A|\ge(1-\delta)2^{n(H-\varepsilon)}.
$$

用每个 typical sequence 的最小 probability和总概率不超过 1：

$$
1\ge |A|2^{-n(H+\varepsilon)},
$$

故

$$
|A|\le2^{n(H+\varepsilon)}.
$$

下界含 $1-\delta$，因为 typical set 只覆盖至少这么多 mass，不保证 finite $n$ 时覆盖全部 mass。

### INFO-CODE-C03

**Achievability.** 取 $R>H$，选 $\varepsilon>0$ 使 $H+\varepsilon<R$。由 cardinality upper bound，充分大 $n$ 时

$$
|A_\varepsilon^{(n)}|\le2^{n(H+\varepsilon)}<2^{nR}.
$$

给每个 typical sequence 分配不同 index；atypical sequences 映到 error/default。block error 至多

$$
P(X^n\notin A_\varepsilon^{(n)})\to0.
$$

**Converse.** 任意 rate $R$ code 最多能对某成功集 $S_n$ 中 $2^{nR}$ 个 sequences 无误重建。取 $\varepsilon>0$ 使 $R<H-\varepsilon$：

$$
\begin{aligned}
P(X^n\in S_n)
&\le P(X^n\notin A_\varepsilon^{(n)})
+P(X^n\in S_n\cap A_\varepsilon^{(n)})\\
&\le P(A^c)+|S_n|2^{-n(H-\varepsilon)}\\
&\le P(A^c)+2^{-n(H-\varepsilon-R)}\to0.
\end{aligned}
$$

所以 error 趋于 1。定理是 $n\to\infty$ 的 block-error statement；$R>H$ 不承诺 finite $n$ 零错误，且 $R=H$ 的边界需要更细分析。

## D. 边界、反例与纠错

### INFO-CODE-D01

公平 coin 下所有 $2^n$ 个 sequences probability 都是 $2^{-n}$，per-symbol surprise 都恰为 $1=H$；“top probability”发生大规模 tie。

若 $p(1)=0.01$，全零 sequence 是唯一最可能 sequence，probability $0.99^n$，但 per-symbol surprise 为

$$
-\log_20.99\approx0.014500,
$$

而

$$
H_2(0.01)\approx0.080793.
$$

差不会随 $n$ 消失，所以对足够小 $\varepsilon$，全零序列不在 weakly typical set，尽管它单点最可能。typical set 由 surprise rate 接近 entropy 定义；type 众数讨论 empirical count；top set 按个体 probability 排序。三者不可互换。

### INFO-CODE-D02

matched cost：

$$
H_2(P)=h_2(0.8)\approx0.721928\text{ bits/symbol}.
$$

用 $Q$ 编码的 cross-entropy：

$$
H_2(P,Q)
=-0.8\log_20.6-0.2\log_20.4
\approx0.853958.
$$

excess cost：

$$
D_2(P\|Q)=H_2(P,Q)-H_2(P)\approx0.132030.
$$

若 $Q$ 从数据学得，完整 compressor 还应处理：model/parameter description 或 shared pretrained-model assumption、vocabulary/alphabet、training corpus 是否随码传送、finite precision、header/framing、termination、arithmetic coder rounding、escape/unknown symbols 和 compute/memory constraints。只报 test cross-entropy 是 data cost proxy，不一定是端到端 file size。

### INFO-CODE-D03

记整个 component choice 为 $C$。给定 $C=0$，entropy rate 为 $0$；给定 $C=1$，rate 为 $1$ bit/symbol。初始 $C$ 只贡献至多一 bit，因此

$$
\bar H(X)=\lim_n\frac1nH(X^n)=\frac12(0)+\frac12(1)=\frac12\text{ bit/symbol}.
$$

但 sample-path surprise rate 不收敛到同一常数：

- 在 $C=0$ component，$X^n=0^n$，而 marginal $P(0^n)=\tfrac12+\tfrac12 2^{-n}$，故 rate 趋于 $0$；
- 在 $C=1$ component，almost surely 最终不是特殊全零 path；典型 sequence 的 marginal probability 为 $\tfrac12 2^{-n}$，rate 趋于 $1$。

极限是 component-dependent random variable，不是统一的 $1/2$。source stationary 但不 ergodic；这说明 entropy-rate expectation 可存在，却不足以推出单一 AEP concentration。对自然语言等序列，不能仅因“stationary-looking”就套 iid typical-set 结论。

## E. AI 迁移

### INFO-CODE-E01

byte model：

$$
\frac{0.9}{\ln2}\approx1.29843\text{ bits/byte}.
$$

token model：

$$
\frac{1.7}{\ln2}\approx2.45251\text{ bits/token},
$$

再除以 $3.2$ bytes/token：

$$
\approx0.76641\text{ bits/byte}.
$$

在相同原始 held-out bytes、normalization 与 likelihood coverage 下，token model 的 ideal data cost 较低。实际 arithmetic-coded file 还需验证 probability normalization/precision、deterministic tokenizer、BOS/EOS、unknown/byte fallback、stream framing、final interval、coder rounding、model/vocabulary delivery 和是否能 bit-exact decode。若模型训练或 tokenizer 信息需随文件发送，也要计入总长。

### INFO-CODE-E02

perplexity $=2^{\text{bits/token}}$ 或 $e^{\text{nats/token}}$，token unit 不同便不可横比。tokenizer 可通过合并更多 bytes 降低 tokens/file，同时 token perplexity 可能升降。

公平 benchmark：

1. 固定同一 raw byte corpus 与 train/validation/test split；
2. 固定 Unicode normalization、whitespace 和 metadata policy；
3. 各 tokenizer 必须 losslessly cover 同一 bytes，明确 unknown/fallback；
4. 计算 total held-out NLL，再除以 raw byte count，报告 bits/byte；
5. 单列 vocabulary/tokenizer/model parameter storage 或明确双方预共享；
6. 用同一精度 arithmetic/range coder 实际 round trip；
7. 报 header、termination、small-file overhead、speed 和 memory；
8. 防止 tokenizer/model 在 test corpus 上选择。

这样比较的才是同一 source data 上的 ideal 与 realized compression cost。

### INFO-CODE-E03

top-$M$ set 解的是“给定 cardinality 最大化 covered probability”问题；weakly typical set解的是“self-information rate 接近 entropy”问题。二者有限 $n$ 时一般不同，最可能 sequence 甚至可在 typical set 外。

即使 $M\approx2^{nH}$：

- estimated $H$ 有误差且 $2^{nH}$ 只是 exponential-order statement；
- top set coverage 取决于 distribution 的 probability ranking，不由 cardinality 单独保证；
- typical set 内 sequence 只是 exponential scale 上近似等概率，不是完全均匀；
- 从 top set uniform sampling 会重加权 source，按原概率截断采样也改变 normalization；
- 生成只保留 top mass 可能系统性丢掉 rare modes，形成 mode collapse；
- source coding theorem 的 decoder codebook 与 generative sampling objective 不是一回事。

正确报告应写“top-$M$ truncation”，测量 retained probability mass、renormalization bias、diversity与 downstream quality；若声称 typicality，要直接检查 surprise-rate band 和 finite-$n$ coverage。

## 完成标准

你应能从 `Kraft → 平均码长下界 → block coding → AEP → source coding threshold` 独立重建主线，并在任何语言模型压缩比较中统一为同一原始数据单位，同时单列模型与 coder overhead。
