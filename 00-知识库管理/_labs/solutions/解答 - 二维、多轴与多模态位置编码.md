# 解答 - 二维、多轴与多模态位置编码

## A. 识别与复述

### ARCH-AXIS-A01
文本至少是 sequence index；图像是 row/column，另可带 scale；视频是 time/row/column；图文混排还需全局 sequence、modality/segment 与模态内部坐标。特殊 token 的坐标必须显式定义，而非默认为 0。

### ARCH-AXIS-A02
轴分块让每轴使用互不相交通道；轴相加把各轴向量加到同一空间；拼接后投影先保留各轴再学习混合；多轴旋转让不同轴的相位作用于指定 Q/K 通道。它们的维度、可辨识性与相对内积结构不同。

### ARCH-AXIS-A03
展平次序定义 $s=f(r,c)$，从而一维距离和邻接先验依赖 width 与遍历规则。跨行尾首在 1D 中相邻，而上下邻居相差 $W$；分辨率改变还会改变同一几何关系的一维差。

## B. 手算与建模

### ARCH-AXIS-B01
Row-major：$0\leftrightarrow(0,0),1\leftrightarrow(0,1),2\leftrightarrow(0,2),3\leftrightarrow(1,0),4\leftrightarrow(1,1),5\leftrightarrow(1,2)$。例如 $1\to2$ 与 $2\to3$ 的一维差都为 1，但二维位移分别是 $(0,1)$ 与 $(1,-2)$。

### ARCH-AXIS-B02
每轴 4 维，对应 2 个二维旋转块；三轴共 12 维、6 个块。若实现要求每轴偶数 rotary dimension，此分配合法。

### ARCH-AXIS-B03
全局 sequence 为 $0\ldots10$。Segment 可为 text0=0、image=1、text1=2；四个 patch 的 row/col 为 $(0,0),(0,1),(1,0),(1,1)$。文本 row/col 用 sentinel $-1$ 并配 valid mask，不能未经处理拿 $-1$ 查表；文本内部可另用 local text index。

## C. 推导与证明

### ARCH-AXIS-C01
令 $R_{r,c}=\operatorname{diag}(R^r_r,R^c_c)$，两轴块不相交且各自为表示。则
$$R_{r_1,c_1}^TR_{r_2,c_2}=\operatorname{diag}(R^r_{r_2-r_1},R^c_{c_2-c_1}),$$
所以变换后的内积分解为行、列两块贡献，只依 $(\Delta r,\Delta c)$。

### ARCH-AXIS-C02
$\Delta s=W\Delta r+\Delta c$ 是从整数对到整数的单个方程。对给定 $\Delta s$，$(\Delta r+k,\Delta c-kW)$ 都给同值；即使限制在图像边界，也常有多个可行解。因此没有 width/范围等附加信息不能唯一逆变换。

### ARCH-AXIS-C03
直接整数坐标让相邻 patch 的坐标差仍为 1，但同一归一化图像位置在新网格的整数约翻倍；归一化坐标 $r/(H-1),c/(W-1)$ 保持边界和相对画布位置，却使相邻间距减半。前者保局部格点尺度，后者保全局归一化几何，任务需决定。

## D. 边界、反例与纠错

### ARCH-AXIS-D01
行列相对编码最多给离散轴平移结构；旋转图像会交换/混合轴，缩放会改变坐标差，普通 2D RoPE 不满足相应群作用。几何等变性需专门的变换表示、数据与架构证明。

### ARCH-AXIS-D02
若 $d=10$ 分给时间 8 维、行列各 1 维，行列无法各形成完整 sin/cos 或旋转对；即便补成 2+2，时间拥有更多频率尺度，空间轴可能在大网格快速混叠。通道预算直接限制每轴的频率分辨率。

### ARCH-AXIS-D03
全局 ID 只说明 token 在混排序列中的先后；两个相邻 image patch 和两个相邻文字 token 得到相同一维差，却有不同语义。音频 frame 与视频 frame 也可能采样率不同，需要物理/归一化时间或对齐规则。

## E. AI 迁移

### ARCH-AXIS-E01
Transpose 后交换 row/column IDs，并在轴参数共享时检查输出相应变换；crop 比较全局与局部坐标两种合同；resize 检查整数/归一化坐标；padding 添加极端值并验证 mask。再测 row-major/column-major round-trip 与特殊 token。

### ARCH-AXIS-E02
训练点 $(T_0,H_0,W_0)$；测试 $T\in\{T_0,2T_0,4T_0\}$ 与空间 token 数 $S\in\{S_0,4S_0}$ 的网格。固定总样本/计算时另报告 token 增长成本，按目标时间和空间位置分层测任务，并含只需局部信息的负对照。

### ARCH-AXIS-E03
Schema 应含每种 token 的 coordinate tuple、单位/范围/归一化、各轴通道与频率、组合规则、sentinel+valid mask、CLS/SEP 坐标、packed sample 隔离、crop/resize、prefill/decode offset、版本号及跨模态时间对齐。任何缺项都可能造成隐式坐标冲突。
