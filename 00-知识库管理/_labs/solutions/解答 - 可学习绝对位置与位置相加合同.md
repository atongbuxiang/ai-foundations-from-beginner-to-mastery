# 解答 - 可学习绝对位置与位置相加合同

## A. 识别与复述

### ARCH-ABS-A01
若 token IDs 为 $x\in\{0,\ldots,V-1\}^{B\times T}$，位置 IDs 为 $r\in\{0,\ldots,L_{max}-1\}^{B\times T}$，则
$$X_0=E[x]+\alpha P[r],\quad E\in\mathbb R^{V\times d},\ P\in\mathbb R^{L_{max}\times d},$$
输出 shape 是 $B\times T\times d$。相加需要 batch、token 和 feature 轴可广播兼容，并需记录尺度 $\alpha$。

### ARCH-ABS-A02
它们都决定语义坐标：padding 是否消耗 ID，packing 是否在样本边界重启，crop 使用局部还是全局坐标，cache 新 token 从哪个 offset 开始。任一训练/推理不一致都在不改变 shape 的情况下改变模型输入。

### ARCH-ABS-A03
能接收长张量只是接口不报错；位置参数有定义是所有 position ID 都可映射；能利用远程信息还要求训练学到相应行为并在目标位置/任务上验证。三者依次更强，不能逆向推断。

## B. 手算与建模

### ARCH-ABS-B01
$\|e\|=5,\|p\|=1$，$e+p=(3.6,4.8)$，范数为 $6$。这里二者同向所以放大；若反向可缩小，若正交则为 $\sqrt{26}$。shape 只允许相加，norm 与夹角决定实际扰动。

### ARCH-ABS-B02
约定一：两者均用 $[0,1,2,0,0,0]$ 和 $[0,1,2,3,4,0]$，padding 位置靠 mask 隔离，且 padding embedding/position 不得影响 pooling。约定二：完整 arange $[0,1,2,3,4,5]$，同样严格 mask padding。两者都可合法，但训练与推理、left/right padding 及 pooling 必须一致。

### ARCH-ABS-B03
原参数为 $512\cdot768=393{,}216$。扩到 2048 新增 $(2048-512)\cdot768=1{,}179{,}648$ 个参数；fp16 新增 $2{,}359{,}296$ bytes，约 $2.25$ MiB。存储很小不代表新增行已训练。

## C. 推导与证明

### ARCH-ABS-C01
对任意常向量 $c\in\mathbb R^d$，令 $E'[x]=E[x]+c,P'[i]=P[i]-c$，则 $E'[x]+P'[i]=E[x]+P[i]$。所以下游仅观察和时不能唯一识别两张表的共同平移；weight decay、初始化或额外使用方式可选择一种参数化，但数据本身没有消除该自由度。

### ARCH-ABS-C02
常用 align-corners 坐标可写 $u=i(L_0-1)/(L_1-1)$。令 $a=\lfloor u\rfloor,b=\min(a+1,L_0-1),\lambda=u-a$，则 $P'_i=(1-\lambda)P_a+\lambda P_b$。不同库的 align-corners/half-pixel 定义不同，必须记录。

### ARCH-ABS-C03
若 cache 已含 $t$ 行，新 token 的绝对 IDs 从 $t$ 开始，即 $t,t+1,\ldots$。全量计算中该 token 使用 $P_t$；若缓存路径用 $P_{t-1}$，输入已变为 $E[x_t]+P_{t-1}$，后续 Q/K/V 一般不同，除非位置表恰好相同或网络偶然消除差异。因此等价性不是 shape 自动保证的。

## D. 边界、反例与纠错

### ARCH-ABS-D01
参数行存在只说明函数有定义。若训练样本从未让第 2048 行获得有效梯度，它仍近似初始化；即使训练过，模型也可能依赖短程特征。必须报告训练位置分布、目标在不同位置的质量和远程依赖任务。

### ARCH-ABS-D02
把短样本 A、B 拼成一行，不 reset 时 B 的起点 ID 与 A 长度相关，模型可利用该统计；reset 后若 attention mask 仍全可见，B token 可读取 A 的 values，形成跨样本泄露。正确 packing 同时定义 position IDs、block-diagonal attention 和 loss mask。

### ARCH-ABS-D03
拉平索引 $s=rW+c$；一维相邻既可能是同一行左右邻居，也可能跨行尾首。任意一维插值把这些关系当同质，尤其在宽高变化时会混合错误方向。应先恢复 $H\times W\times d$ 网格并沿两轴插值，再按约定展平。

## E. AI 迁移

### ARCH-ABS-E01
测试矩阵覆盖 left/right/no padding、单样本与 block packing、局部/全局 crop、full/cached decode、恰好边界与越界。断言 position IDs、mask、有效输出与全量/缓存等价；越界必须显式报错或走版本化 resize，不能静默 wrap/clamp。

### ARCH-ABS-E02
分别测试：同 token 数而图像分辨率改变；序列长度超训练范围；二者同时改变。比较 no resize、1D、恢复网格的 2D 插值及短微调；报告邻接保持、短长度回归、长位置质量和运行成本，避免把“可运行”当适配成功。

### ARCH-ABS-E03
输入至少含有效长度、padding side、segment boundaries、cache length、crop/global offset、max position；输出为 position IDs 与 validity mask。不变量包括有效 token 坐标与 full forward 一致、packed 样本互不影响、越界策略显式、特殊 token 规则稳定、同一 schema/version 在训练与 serving 共用。
