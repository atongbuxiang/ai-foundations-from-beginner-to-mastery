# 解答 - 激活、分支、广播与梯度累加
## A
### NN-SEM-A01
$dH=\phi'(Z)\odot dZ$。对 upstream $G=\bar H$，$dL=\langle G,dH\rangle=\langle G\odot\phi'(Z),dZ\rangle$，故 $\bar Z=G\odot\phi'(Z)$。这是 elementwise diagonal Jacobian 的 VJP。
### NN-SEM-A02
graph accumulation 是一次 backward 中同一 value 的多路径贡献求和；microbatch accumulation 是多次 backward 后才做一次 optimizer step；optimizer moving averages 是 Adam 等跨 steps 保存的算法状态。它们的时间尺度、scale 和语义不同。
### NN-SEM-A03
broadcast 把一个分量复制到多个 positions，其 transpose 必须把这些 positions 的 cotangents 求和；gather 把 source entries 复制/选择到 outputs，其 transpose 将 output cotangents scatter 回 source，重复 index 必须 add。两者都由 $\langle u,Av\rangle=\langle A^*u,v\rangle$ 决定。
## B
### NN-SEM-B01
forward：$\operatorname{ReLU}(x)=(0,2)$，$bx=(-3,6)$，$h=(-3,8)$，$L=5$。从 $\bar h=(1,1)$，ReLU 支路对 $x$ 给 $(0,1)$，product 支路给 $(3,3)$，故 $\bar x=(3,4)$。$\bar b=\sum_i\bar h_ix_i=-1+2=1$。
### NN-SEM-B02
$\bar X=G:[B,T,D]$。$b$ 仅在 batch 轴 0 和 feature 轴 2 被复制，所以 $\bar b_{0t0}=\sum_{i=1}^B\sum_{d=1}^DG_{itd}$，shape 为 `[1,T,1]`。time 轴保留，不能也约掉。
### NN-SEM-B03
$y=(x_2,x_2,x_1)$。第一、二个 outputs 都回到 $x_2$，第三个回到 $x_1$，因而 $\bar x=(c,a+b,0)$。如果用 scatter assignment，$x_2$ 只会保留 $a$ 或 $b$ 之一。
## C
### NN-SEM-C01
$dy=dx+DF(x)[dx]$。配对得 $dL=\langle\bar y,dx\rangle+\langle\bar y,DF(x)[dx]\rangle=\langle\bar y+DF(x)^*\bar y,dx\rangle$，故 $\bar x=\bar y+J_F(x)^T\bar y$。第一项是 identity branch，第二项是 residual branch。
### NN-SEM-C02
$B(db)_{itj}=db_j$。因此 $\langle G,B(db)\rangle=\sum_{itj}G_{itj}db_j=\sum_j(\sum_{it}G_{itj})db_j$。与 $\langle B^*G,db\rangle$ 比较系数，得 $(B^*G)_j=\sum_{it}G_{itj}$。
### NN-SEM-C03
设第 $r$ 个 microbatch 有 $N_r$ 个 valid examples，$g_r=N_r^{-1}\sum_{i\in r}\nabla\ell_i$。全局 mean gradient 是 $(\sum_rN_r)^{-1}\sum_r\sum_{i\in r}\nabla\ell_i=\sum_r\frac{N_r}{\sum_sN_s}g_r$。简单平均 $g_r$ 只在所有 $N_r$ 相等时正确。
## D
### NN-SEM-D01
ReLU 在 0 的左差商极限是 0，右差商极限是 1，两者不同，故 classical derivative 不存在。框架必须选一个 backward convention 才能执行，返回 0 是规则选择，不是可微性证明。
### NN-SEM-D02
若把 $G:[B,T,D]$ 对 $B,T,D$ 全求和，只得 scalar，而原 $b$ 是 `[1,T,1]`，已不同形；若再把 scalar 广播成 `[1,T,1]`，则错误混合了不同 time positions 的贡献。正确只在原 shape 为 1 且 forward 扩展的轴求和。
### NN-SEM-D03
例如 `v=x.view(...)`、`y=v**2`，然后在 backward 前执行 `x.zero_()`。$v$ 与 $x$ 共享 storage，平方 VJP 需原始 $v$ 计算 $2v\bar y$；被原地覆盖后会错返 0。version counter 应拒绝这种 backward，或 functionalization 把写操作变成新 value。
## E
### NN-SEM-E01
为每个 lookup position 记录 token ID 和 upstream row cotangent，按 token ID 做 scatter-add；测试用重复 token 且给各位置不同 cotangent，检查该 row 等于所有出现位置之和，未出现 rows 为 0；再对照 dense one-hot matmul gradient。
### NN-SEM-E02
设 $a=\sigma(g)$、$q=F(x;\theta)$。给 $\bar y$，$\bar x=\bar y+J_F(x)^T(a\odot\bar y)$；$\bar g=(\bar y\odot q)\odot a(1-a)$，若 $g$ 被广播还要 sum-to-shape；$\bar\theta$ 是 $F$ 对 parameter 的 VJP，seed 为 $a\odot\bar y$。
### NN-SEM-E03
检查 bias 原 shape 与 sum axes；保存或可回放 dropout mask/RNG counter；kink 两侧做差分，在 0 只验 convention；对 fused JVP/VJP 做 dot test；复制 batch 测 sum/mean scale；与未融合 reference 在 FP64 对照，再测各 dtype 和并行确定性。
