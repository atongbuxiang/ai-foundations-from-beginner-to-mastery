# 解答 - 池化、下采样、混叠与不变性边界

## A. 识别与复述

### ARCH-SAMP-A01
Filtering 是线性/非线性局部变换，summary 把窗口变成少量统计量，decimation 改变采样格只保留部分位置。一个 API 可组合三者，但理论审计应拆开。

### ARCH-SAMP-A02
Aliasing 是高于新采样率可分辨范围的频率折叠到低频，使不同原信号产生相同样本。映射已多对一，后续网络仅凭样本不能唯一判断原信号，除非借助额外先验。

### ARCH-SAMP-A03
局部稳定是小扰动下数值变化小；等变是 $f(Tx)=Sf(x)$；分类不变是输出决策不变。它们分别是连续性、群关系与任务读出性质。

## B. 手算与建模

### ARCH-SAMP-B01
Stride 1：max $[4,4,3]$，average $[2.5,3,2.5]$。Stride 2：max $[4,3]$，average $[2.5,2.5]$。

### ARCH-SAMP-B02
$x[2m]=1$，所以下采样后是常数 1，即被误认为零频/DC；原信号是离散 Nyquist 频率的交替序列。

### ARCH-SAMP-B03
Zero-same 相关得到 $[0,1/4,1/2,1/4,0]$（对称核翻转无差）；取 indices 0,2,4 得 $[0,1/2,0]$。

## C. 推导与证明

### ARCH-SAMP-C01
对任意 $h\in G$，$r(T_hx)=\sum_g f(T_gT_hx)=\sum_gf(T_{gh}x)$。右乘 $h$ 是 $G$ 的双射，令 $u=gh$，和仍遍历全部 $G$，故等于 $r(x)$。

### ARCH-SAMP-C02
同宽 kernel/channel 下 MACs 正比 $HW$。两轴各减半，新面积 $(H/2)(W/2)=HW/4$，所以约为 $1/4$；边界取整和 channel 改变另算。

### ARCH-SAMP-C03
长度 $K$ box filter 的频率响应是 Dirichlet/sinc-like，主瓣外有 side lobes 且过渡带有限，因此不能完全消除截止频率外成分。残余高频仍可 alias，并可能带 ringing/频率选择偏差。

## D. 边界、反例与纠错

### ARCH-SAMP-D01
$x=[4,1,0,0]$，window2 stride2 得 $[4,0]$；右移一格为 $[0,4,1,0]$，得 $[4,1]$，不是原输出的纯平移。

### ARCH-SAMP-D02
Blur 删除高频，可能损伤小目标、纹理、精确边界；filter 与 feature spectrum 可能错配；增加 IO/latency；论文效果依任务、架构和训练。应把 consistency 与 accuracy/latency 分开验证。

### ARCH-SAMP-D03
平移使内容进入/离开有限画布，zero extension 产生新的人工边缘；输出差异混合了 sampling sensitivity 与边界内容改变。应报告 circular 或 interior crop 对照，并说明真实部署是否确有 crop 边界。

## E. AI 迁移

### ARCH-SAMP-E01
控制参数/训练 schedule/seed/augment；只改变 blur 位置和 filter；报告整数/subpixel shift consistency、accuracy、calibration、latency、FLOPs/bytes；分架构和分辨率；含 no-blur、average、不同 filter size 对照及边界处理。

### ARCH-SAMP-E02
Classification 通常最终希望对目标位置有较强不变性，可更激进下采样；segmentation 要逐像素定位，过早不变/低分辨率会损伤边界，需要高分辨率分支、skip 或 decoder。两者都需 anti-alias，但 optimum 不同。

### ARCH-SAMP-E03
Kernel/stride 16 patch embedding 直接把 16×16 patch 压成一个 token，是强 decimation/局部投影。可能丢细纹理和 patch-boundary 稳定性。对照可含更小 patch、overlap stem、低通预滤、同 token/FLOP 条件，并测 shift consistency 与小目标任务。
