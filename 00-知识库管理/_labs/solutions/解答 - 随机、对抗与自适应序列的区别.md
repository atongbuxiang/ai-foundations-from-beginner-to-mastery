# 解答 - 随机、对抗与自适应序列的区别

## A

### LT-ADV-A01
令 $\mathcal F_{t-1}$ 包含过去 observations、actions、losses 与已公开随机性。learner distribution $p_t$ 必须是 $\mathcal F_{t-1}$-measurable，fresh coin $U_t$ 条件于 $\mathcal F_{t-1}$ 独立并生成 $I_t$。non-anticipating environment 的当前 $\ell_t$ 可依赖 $\mathcal F_{t-1}$，但不能依赖尚未揭示的 $U_t/I_t$。

### LT-ADV-A02
iid 是同分布且相互独立；一般 stochastic process 可依赖历史并非同分布；random permutation 是固定有限总体的无放回随机顺序，观测彼此依赖；oblivious sequence 在 learner 随机种子实现前已固定，甚至可以完全非随机。

### LT-ADV-A03
non-anticipating adaptive adversary 可根据 $\mathcal F_{t-1}$ 选 $\ell_t$，但看不到当前 fresh coin/action；current-action-aware adversary 在 $I_t$ 后定 $\ell_t$。后者可专门惩罚当轮 action，破坏许多 martingale 与 regret 证明。

## B

### LT-ADV-B01
每轮令被选 action loss 为 $1$，其余为 $0$，learner loss 恰为 $T$。全部 $N$ 个固定 actions 的累计 losses 之和为 $T$，故最小者至多 $T/N$。因此
$$R_T\ge T-T/N=T(1-1/N).$$

### LT-ADV-B02
若 $I_t\sim p_t$ 使用条件于 $\mathcal F_{t-1}$ 的 fresh randomness，而且 $p_t$、$\ell_t$ 在采样前已确定，则
$$E[\ell_{t,I_t}\mid\mathcal F_{t-1},\ell_t]=\sum_i p_{t,i}\ell_{t,i}.$$
若 $\ell_t$ 看见 $I_t$ 后才设置，这个条件期望等式一般不成立。

### LT-ADV-B03
独立时 simultaneous probability 是 $0.95^{10}\approx0.5987$。只知道每步 marginal coverage 0.95 并不能相乘；完全正相关时可仍为 0.95，恶意依赖时联合 coverage 还可能更低。序列结论必须显式处理 dependence。

## C

### LT-ADV-C01
有限总体有两个值 $a,b$，随机无放回观察。若首个是 $a$，第二个必为 $b$；故 $P(X_2=b\mid X_1=a)=1$，而 $P(X_2=b)=1/2$。条件概率不等于边缘概率，因而不独立。

### LT-ADV-C02
两 actions，令 $\ell_t$ 根据过去累计采样次数：对过去被选较多的 action 在下一轮给 loss 0，另一个给 1。loss sequence 是 learner 过去随机 actions 的函数；完整序列上的 best fixed action 因而也依赖这些随机数。expected regret 中 expectation 必须同时覆盖这条诱导 loss path。

### LT-ADV-C03
external regret 把实际发生的 $\ell_{1:T}$ 固定，再代入另一个 comparator action；policy regret 则比较“若从前采用另一 policy，environment 状态和以后 losses 会怎样”。当 action 影响环境，两个反事实的 loss sequence 不同，前者不能替代后者。

## D

### LT-ADV-D01
mixture bound 控制 $\sum_t\langle p_t,\ell_t\rangle$，realized loss 是 $\sum_t\ell_{t,I_t}$。两者之差需构造成 martingale difference，再用 Azuma/Freedman 加入 $O(\sqrt{T\log(1/\delta)})$ 或 variance-sensitive 项。没有这一步，就不能宣称 $1-\delta$ realized guarantee。

### LT-ADV-D02
令 $\mathcal F_{t-1}$ 包含模型先前回答、red-team 已见 transcript 与攻击策略；第 $t$ 个 prompt 可由这些历史自适应生成，但在模型当前 fresh decoding coin 前固定。若攻击者读取当前 token 再即时续写，则要把 token 级交互写进 protocol。独立 unit 常是完整 attack session，而不是 token 或 prompt 片段。

### LT-ADV-D03
Azuma/Freedman 要求相对于 filtration 的 martingale difference，并分别需要 bounded increments、或可控 conditional variance 与增量上界。若 environment 看当前 sampled action 后定 loss，$E[\ell_{t,I_t}-\langle p_t,\ell_t\rangle\mid\mathcal F_{t-1}]$ 不再必为零，martingale 条件断裂。

## E

### LT-ADV-E01
market 可先用 non-anticipating adaptive process：价格响应过去订单，但 theorem 不许看尚未下出的随机订单；recommender 应考虑 action-dependent user state，static regret 外还需 policy/MDP 模型；security red team 通常是 adaptive adversary，必须按其可见 transcript 和响应时点建 filtration。

### LT-ADV-E02
iid Rademacher complexity 在一份固定 sample 上随机翻 signs；sequential Rademacher complexity 用一棵 observation tree，每个下一节点可依赖过去 signs。它表达“环境沿 learner/history 分支自适应选择后续输入”的容量，因此适合非 iid sequential uniform convergence/minimax regret。

### LT-ADV-E03
claim card 应画出 $\mathcal F_{t-1}\subset\mathcal F_t$；标出 learner distribution 和 fresh coins；当前 context/loss 在何时 measurable；feedback 延迟；adversary 能看哪些 actions/coins；comparator 是否受 learner 影响；最后写 expectation 对谁取或 high-probability 的 $\delta$ 与条件。
