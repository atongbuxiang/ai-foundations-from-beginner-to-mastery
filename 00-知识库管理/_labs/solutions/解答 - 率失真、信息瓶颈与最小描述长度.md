# 解答 - 率失真、信息瓶颈与最小描述长度

> [!warning] 使用边界
> 每个 rate 都必须带上 source、distortion、log base、denominator 和 coding/estimation protocol。相似的 Lagrangian 只能提示结构联系，不能让 Shannon theorem、VIB surrogate 与 MDL code 自动共享结论。

## A. 识别与复述

### INFO-RDMDL-A01

设 $X^n\sim p_X^{\otimes n}$。完整 code 为：

$$
f_n:\mathcal X^n\to\{1,\ldots,M_n\},
\qquad
g_n:\{1,\ldots,M_n\}\to\widehat{\mathcal X}^n.
$$

message 为 $M=f_n(X^n)$，重构为 $\widehat X^n=g_n(M)$，rate 满足

$$
R_n=\frac1n\log_2M_n.
$$

给 single-letter distortion $d:\mathcal X\times\widehat{\mathcal X}\to[0,\infty)$，block distortion 为

$$
d_n(x^n,\widehat x^n)
=\frac1n\sum_{i=1}^nd(x_i,\widehat x_i).
$$

expected criterion 是 $E[d_n]\le D$；excess criterion 是 $P(d_n>D)\le\varepsilon$。还需说明 alphabets、source memory/ergodicity、fixed/variable length 与 asymptotic sequence。

test channel $p(\widehat x\mid x)$ 是 single-letter information optimization variable。它定义一个理想 joint law，并用于 random-coding theorem；实际 block encoder/decoder 是可执行 maps。large block deterministic code 可在 empirical joint behavior 上逼近 test channel，但两者不是同一对象。

### INFO-RDMDL-A02

$$
R(D)=\inf_{p(\widehat x\mid x):Ed\le D}I(X;\widehat X).
$$

零速率阈值：

$$
D_0=\min_{\widehat x}E[d(X,\widehat x)].
$$

当 $D\ge D_0$，$R(D)=0$。$R(D)$ 随 $D$ 单调不增，且因 time sharing convex。若 discrete reproduction 含 $X$、零失真只允许 $\widehat X=X$，则 $R(0)=H(X)$；continuous zero-MSE 通常需 infinite rate。

IB 固定 $p(x,y)$，选 $p(z\mid x)$：

$$
\min I(X;Z)-\beta I(Z;Y).
$$

$I(X;Z)$ 是输入到表示的 rate/complexity；$I(Z;Y)$ 是 task relevance。DPI 给 relevance ceiling $I(Z;Y)\le I(X;Y)$。

### INFO-RDMDL-A03

| 对象 | 层级 | 是否直接是实际 bits |
|---|---|---|
| $I(X;\widehat X)$ | population joint law 的依赖率 | 只在 coding theorem/protocol 下成为 asymptotic rate limit |
| $I(X;Z)$ | representation joint law | 同上；continuous deterministic 时可 infinite |
| $E[-\log_2q(\widehat Z)]$ | entropy model cross-entropy | ideal latent code expectation；含 mismatch，不含全部 overhead |
| bitstream length | 实际 coder output | 是；仍要声明 header、padding 与 denominator |
| parameter count | coordinate count | 不是 bits；缺 precision/code/distribution |
| MDL total length | model/protocol + data 的合法 code | 是 coding criterion，但依 code family/protocol |

bytes 只能与 bytes/bits 在相同 raw data、decoder side information 和 file protocol 下比较。MI 用 bits 表示仍是 population quantity，不是把一个 sample 文件直接写出的长度。

## B. 手算与构造

### INFO-RDMDL-B01

对 $0\le D\le1/2$：

$$
R(D)=1-h_2(D).
$$

因此：

| $D$ | $h_2(D)$ | $R(D)$ bits/symbol |
|---:|---:|---:|
| 0 | 0 | 1 |
| 0.1 | 0.468996 | 0.531004 |
| 0.25 | 0.811278 | 0.188722 |
| 0.5 | 1 | 0 |

binary entropy derivative：

$$
h_2'(D)=\log_2\frac{1-D}{D}.
$$

故

$$
R'(0.1)=-\log_29\approx-3.169925,
$$

$$
\beta=-R'(0.1)\approx3.169925
$$

bits per unit Hamming distortion。取

$$
\widehat X=X\oplus E,
\qquad E\sim\operatorname{Ber}(0.1)
$$

independent，便有 $P(\widehat X\ne X)=0.1$，$\widehat X$ 仍 fair，

$$
I(X;\widehat X)=1-h_2(0.1).
$$

### INFO-RDMDL-B02

$$
R(D)=\frac12\log_2\frac4D,
\qquad0<D<4,
$$

且 $D\ge4$ 时为零。因此：

| $D$ | $R(D)$ bits/symbol |
|---:|---:|
| 4 | 0 |
| 1 | 1 |
| 0.25 | 2 |

$D=1$ 时取 backward channel

$$
X=\widehat X+N,
$$

其中

$$
\widehat X\sim N(0,3),
\qquad N\sim N(0,1),
\qquad\widehat X\perp N.
$$

则 $X\sim N(0,4)$，MSE 为 $E[N^2]=1$，且

$$
I(X;\widehat X)
=h(X)-h(X\mid\widehat X)
=\frac12\log_2\frac41
=1.
$$

### INFO-RDMDL-B03

$H(Y)=H(N)=1$，$H(X)=2$ bits。令

$$
a=1-h_2(0.1)\approx0.531004.
$$

| encoder | $I(X;Z)$ | $I(Z;Y)$ | $I(X;Z)-2I(Z;Y)$ |
|---|---:|---:|---:|
| $Z=X=(Y,N)$ | 2 | 1 | 0 |
| $Z=Y$ | 1 | 1 | -1 |
| $Z=Y\oplus E$ | $a$ | $a$ | $-a\approx-0.531004$ |
| constant | 0 | 0 | 0 |

$Z=X$ 比 $Z=Y$ 多 1 bit input rate，却没有增加 relevance；这 1 bit 只记住 nuisance $N$。constant 是过度压缩。对给定 $\beta=2$，四个候选中 $Z=Y$ objective 最小。

## C. 推导与证明

### INFO-RDMDL-C01

**Convexity。** 令两个 schemes/test channels 产生 $(D_1,R_1)$ 与 $(D_2,R_2)$。用 independent selector $Q$ 以概率 $\alpha$ 选第一个 scheme，并让两端知道 $Q$。平均 distortion

$$
D_\alpha=\alpha D_1+(1-\alpha)D_2,
$$

平均 rate 不超过

$$
R_\alpha=\alpha R_1+(1-\alpha)R_2.
$$

故

$$
R(D_\alpha)\le R_\alpha.
$$

**Converse。** 因 $|\mathcal M|\le2^{nR}$：

$$
nR\ge\log_2|\mathcal M|\ge H(M).
$$

deterministic encoder 给 $H(M)=I(X^n;M)$。Markov chain $X^n-M-\widehat X^n$ 和 DPI 给

$$
I(X^n;M)\ge I(X^n;\widehat X^n).
$$

iid source 下：

$$
\begin{aligned}
I(X^n;\widehat X^n)
&=\sum_iH(X_i)-H(X^n\mid\widehat X^n)\\
&\ge\sum_iH(X_i)-\sum_iH(X_i\mid\widehat X_i)\\
&=\sum_iI(X_i;\widehat X_i).
\end{aligned}
$$

第二行用 conditional entropy chain rule 与 conditioning reduces entropy。令 $D_i=E[d(X_i,\widehat X_i)]$。按 $R(D_i)$ 的 infimum 定义：

$$
I(X_i;\widehat X_i)\ge R(D_i).
$$

再用 convexity/Jensen：

$$
\frac1n\sum_iR(D_i)
\ge R\left(\frac1n\sum_iD_i\right).
$$

若平均 distortion $\bar D\le D$，monotonicity 给 $R(\bar D)\ge R(D)$。合并：

$$
nR\ge nR(D).
$$

若 encoder stochastic，需把 shared/private randomness 纳入 protocol；不能直接使用 $H(M)=I(X^n;M)$，但仍可用适当 Markov/conditioning 版本建立 converse。

### INFO-RDMDL-C02

由 chain rule：

$$
I(X,Z;Y)=I(Z;Y)+I(X;Y\mid Z).
$$

另一方面

$$
I(X,Z;Y)=I(X;Y)+I(Z;Y\mid X).
$$

$Y-X-Z$ 给 $I(Z;Y\mid X)=0$，所以

$$
I(X;Y)-I(Z;Y)=I(X;Y\mid Z).
$$

conditional MI 的 expected-KL form 与 Markov property 给

$$
\begin{aligned}
I(X;Y\mid Z)
&=E_{x,z}D(p(y\mid x,z)\|p(y\mid z))\\
&=E_{x,z}D(p(y\mid x)\|p(y\mid z)).
\end{aligned}
$$

定义 $d_{IB}(x,z)$ 为最后的 KL。IB objective

$$
I(X;Z)-\beta I(Z;Y)
$$

与

$$
I(X;Z)+\beta E[d_{IB}(X,Z)]
$$

只差固定常数 $-\beta I(X;Y)$。

对 $p(z\mid x)$ 做 constrained variation，加入每个 $x$ 的 normalization multiplier；在 induced $p(z),p(y\mid z)$ 与 encoder 自洽的 stationary point，Euler equation 可整理为

$$
\log p(z\mid x)
=\log p(z)-\beta d_{IB}(x,z)-\log Z_\beta(x).
$$

故

$$
p(z\mid x)
=\frac{p(z)e^{-\beta d_{IB}(x,z)}}
{\sum_{z'}p(z')e^{-\beta d_{IB}(x,z')}}.
$$

还必须同时更新 induced $p(z)$ 和 $p(y\mid z)$；单独满足一个 proportional form 不是 global-optimum certificate。

### INFO-RDMDL-C03

令 $q(z)=\int p(x)q(z\mid x)dx$。展开：

$$
\begin{aligned}
E_XD(q(z\mid X)\|r(z))
&=E_{x,z}\log\frac{q(z\mid x)}{r(z)}\\
&=E_{x,z}\log\frac{q(z\mid x)}{q(z)}
+E_z\log\frac{q(z)}{r(z)}\\
&=I_q(X;Z)+D(q(z)\|r(z)).
\end{aligned}
$$

所以 rate upper-bound gap 是 aggregate-prior KL。

对 predictor $s(y\mid z)$：

$$
\begin{aligned}
I(Z;Y)
&=H(Y)+E\log p(y\mid z)\\
&=H(Y)+E\log s(y\mid z)
+E_zD(p(y\mid z)\|s(y\mid z)).
\end{aligned}
$$

故 relevance lower-bound gap 是 expected predictor conditional KL。

VAE 定义

$$
D=E_{x,z}[-\log p_\theta(x\mid z)],
\qquad
R=E_xD(q_\phi(z\mid x)\|p(z)).
$$

则

$$
\begin{aligned}
-E_x\mathcal L(x)
&=E[-\log p_\theta(x\mid z)]
+E_xD(q_\phi(z\mid x)\|p(z))\\
&=D+R.
\end{aligned}
$$

ideal bits-back 中先用 posterior code 从 auxiliary bits decode $z$，再按 $p(x\mid z)$ 编 $x$、按 $p(z)$ 编 $z$，receiver 最后按 $q(z\mid x)$ 重编码并恢复 auxiliary bits。净长：

$$
-\log p(x\mid z)-\log p(z)+\log q(z\mid x),
$$

expectation 正是 negative ELBO。finite precision、初始 bits 与 coder availability 决定实际 overhead。

## D. 边界、反例与纠错

### INFO-RDMDL-D01

例：二分类图像中，类别由一个很小但关键的标记决定。重构 A 平滑掉标记，却保留大面积背景，pixel MSE 很小；重构 B 在背景有轻微全局色偏，MSE 较大，却保留标记并让 classifier/human 正确识别。

Shannon theorem 没有失败：它只保证相对于预先给定的 pixel-MSE distortion，达到 $D$ 所需的最小 asymptotic rate。失败的是 distortion specification——它没有编码 semantic/task cost。

修复可包括：

1. 预注册 task-aware distortion，如 classifier loss，但要冻结/验证 classifier；
2. 同时报 MSE、perceptual feature distance、task risk 与 human preference；
3. 使用 vector-valued/multi-constraint RD，不用一个加权数隐藏 trade-off；
4. 在 distribution shift/subgroup 上复测 distortion–risk relation。

### INFO-RDMDL-D02

若 $Z=f(X)$ deterministic injective，给定 $Z$ 可精确恢复 $X$，formal conditional uncertainty消失；更严格地，joint $P_{XZ}$ 集中在 graph

$$
\{(x,z):z=f(x)\},
$$

该集合相对于通常 product measure $P_XP_Z$ 为 singular。于是

$$
I(X;Z)=D(P_{XZ}\|P_XP_Z)=+\infty
$$

在典型 continuous setting 成立。

若把 finite dataset 当作 $n$ 个等概率 atoms，injective code 最多显示 $\log n$ bits；改变 bin width 会改变 collisions，加入 Gaussian noise 会使 conditional density overlap 并产生另一有限 MI。故 estimator curve 同时反映 measurement protocol。

可复核定义例如：

$$
Z=f_\theta(X)+\varepsilon,
\qquad\varepsilon\sim N(0,\sigma^2I),
$$

固定 $\sigma$、data law、estimator 与 sample split；或令 $Z=Q_\Delta(f_\theta(X))$，固定 quantizer step $\Delta$ 与 finite alphabet。报告对 $\sigma/\Delta$ 的 sensitivity，而不是宣称一个协议无关 MI。

### INFO-RDMDL-D03

该说法把某些 regular parametric model 的 BIC/Laplace asymptotic 误当成 MDL 定义。

- two-part：要选 parameter quantization precision；不同 coordinates 下 naive grid length 改变；
- Bayesian mixture：

$$
-\log\int p_\theta(D)\pi(\theta)d\theta
$$

依 prior $\pi$，singular/nonregular model 不满足普通 Laplace expansion；
- NML：regret normalizer

$$
\sum_{y^n}p_{\widehat\theta(y^n)}(y^n)
$$

可能 infinite，plain NML 不存在；
- prequential：length 依 initial code、data ordering、update schedule、optimizer 与 randomness。

$k\log n/2$ 可在 fixed-dimensional、identifiable、regular interior model、nondegenerate Fisher information 与适当 prior/code 条件下成为 leading complexity term。mixture、deep network、boundary、gauge symmetry、overparameterization 和 interpolation 会破坏这些条件。

## E. AI 迁移

### INFO-RDMDL-E01

完整 audit：

1. 固定 raw image distribution、bit depth、color space、crop 与 train/test split；
2. encoder output、quantizer 与 rounding/noise surrogate 全写明；
3. entropy model/hyperprior 的 factorization、CDF precision 和 mismatch NLL；
4. 使用真实 range/arithmetic coder，输出可被 independent decoder读取；
5. bits 包含 main latents、hyperlatents、header、shape、model ID、termination 与 padding；
6. 若 weights 不共享，计 decoder/model codelength；
7. rate 统一为 total bits/raw pixels，另报 wall-clock/memory；
8. distortion 至少包括 MSE/PSNR、perceptual metric、downstream/human metric；
9. 扫相同 $\lambda$ 或 target-bpp grid，画 confidence band，不只挑一个点；
10. 区分 Shannon lower bound、baseline codec 与 empirical achievable points；
11. held-out、不同设备/图像 subgroup、OOD/shift 复测；
12. multiple seeds、codec version、hash、actual files 与 decode equality test。

训练 entropy NLL、estimated bpp 和 actual file bpp 应三列并报；它们不一致正是需要解释的 evidence。

### INFO-RDMDL-E02

实验设计：构造/选择能标注 nuisance 的数据 $(X,Y,N)$，encoder 为

$$
q_\phi(z\mid x)=N(\mu_\phi(x),\operatorname{diag}\sigma_\phi^2(x)),
$$

固定 prior $r=N(0,I)$，扫描 $\beta$ 与 injected noise。

每个点报告：

- held-out $E KL(q(z\mid x)\|r)$（rate upper bound）；
- sampled aggregate $q(z)$ 到 $r$ 的 density-ratio/MMD proxy，并明确它不是 exact gap；
- task NLL、accuracy、Brier/ECE 和 $I(Z;Y)$ lower-bound value；
- nuisance probe accuracy 与 task probe accuracy；
- latent ablation/permutation、active units；
- in-domain、nuisance shift、label shift、OOD；
- deterministic baseline 只报 task risk，不假装其 MI finite；
- multiple seeds、estimator/sample/bandwidth sensitivity。

可证伪声明预先写为：“在相同 in-domain task NLL 容差内，存在中等 rate 区间，使 nuisance-shift risk 显著低于无 bottleneck baseline；rate 继续下降会损害 relevance。”若不出现 U-shaped/rate threshold，或 improvement 只在一个 estimator/seed，便不支持强结论。

### INFO-RDMDL-E03

设双方预共享 base model hash 与 tokenizer version。三种 adaptation 的 total code 可组织为：

$$
L_{total}
=L(\text{method/config})
+L(\text{update or prompt})
+L_{preq}(Y\mid X,\text{adapted predictor}).
$$

- full FT：编码全部 quantized weight delta 或最终 weights；
- LoRA：编码 ranks、target modules、factor values、scales 与 precision；
- prompt：编码 text/template/examples、ordering 与 decoding config；
- prequential labels：固定 blocks、initial uniform code、每轮 training budget/seed 和 calibration；
- base model若不共享，三者都加其完整 code；tokenizer/normalizer同理；
- parameter entropy coding需给 distribution/CDF 与 decoder；不能只用 nonzero count；
- report actual compressed bytes 和 predictive data bits。

GPU hours、latency、energy、peak memory 不能普遍无损换算成 Shannon bits，应作为 parallel resource vector 报告。deployment accuracy、calibration、safety、shift 与 privacy 也不能被短 code 替代。MDL 只在固定 coding protocol 下比较 statistical compression。

## 完成标准

你应能不看答案写出 $R(D)$ 的完整 optimization、convexity 和 converse；能从 Markov chain 推出 IB predictive KL；能指出 VIB 两个 gap、VAE rate gap 与 bits-back 条件；并能为任意“压缩/最小描述”AI 论文区分 theorem、bound、estimator、training objective、actual code 和 deployment risk。
