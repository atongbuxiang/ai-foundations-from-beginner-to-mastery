# 解答 - 激活函数的数值稳定、尺度与经验选择

## A

### NN-EVA-A01
数学门检查定义域、值域、连续/可微、极限、导数与反例；浮点门检查溢出、下溢、消去、dtype 与 reference；传播门检查 activation/derivative moments、Jacobian spectrum、初始化、归一化和残差；系统门检查参数、MAC、bytes、fusion、通信与 latency；统计门检查数据切分、调参预算、seeds、不确定性、选择偏差与 claim boundary。五门任何一门失败，结论都要相应收窄。

### NN-EVA-A02
$E[H]$ 是均值，$E[H^2]$ 是二阶矩，$\operatorname{Var}(H)=E[H^2]-E[H]^2$；只有均值为 0 时后二者相等。$E[\phi'(Z)^2]$ 是局部导数增益的二阶矩，参与 backward variance/Jacobian 分析，既不是 activation variance，也不能脱离 weight scale 与相关性单独决定梯度稳定。

### NN-EVA-A03
plug-in 固定其余配置，回答直接替换是否稳健；retuned 给每个候选相同搜索预算，回答调好后能达到什么；matched-parameter 调整宽度使模型大小相当；matched-latency 以目标硬件实测调整 shape/实现使时延相当。它们的 estimand 不同，应并列报告而非互相替代。

## B

### NN-EVA-B01
sigmoid 可按 $x\ge0$ 用 $1/(1+e^{-x})$、$x<0$ 用 $e^x/(1+e^x)$；Softplus 用 $\max(x,0)+\log1p(e^{-|x|})$；log-sigmoid 用 $-\operatorname{softplus}(-x)$；ELU 负侧用 $\alpha\operatorname{expm1}(x)$。这些重写限制 exponent 的危险符号，并用专用 primitive 保留近零小量。

### NN-EVA-B02
预先定义成功与失败；五个 seed 的主指标对成功 runs 报均值、标准差/置信区间，同时单独报告 $n_{success}/5$ 与每个失败原因，不能静默删掉 NaN。若失败本身代表算法不稳，应把成功率作为共同主结果，必要时用预注册 penalty/survival estimand；绝不能只报 best seed。样本只有五个时区间很宽，应展示原始点。

### NN-EVA-B03
忽略 bias，每 token 标准 FFN 参数和 MAC 均约 $2dh$；gated FFN 约 $3dh_g$，另有 $h_g$ 次逐元 activation/multiply。若元素占 $s$ bytes，标准中间逻辑量约 $sh$；gated forward 有 $V,G,H$ 三个宽 $h_g$ 对象，未融合上界约 $3sh_g$，但 peak/saved bytes 依 fusion 与 checkpoint 而变。参数匹配 $h_g\approx2h/3$ 后仍须按实际 kernel 量内存与延迟。

## C

### NN-EVA-C01
实数中 $\log(1+e^x)=x+\log(1+e^{-x})$（$x\ge0$），但朴素左式在有限精度会先计算 $e^x$：大 $x$ 溢出；大负 $x$ 时 $e^x$ 太小，$1+e^x$ 舍入为 1。稳定式使用 $\max+log1p(e^{-|x|})$，中间量均有限并保留小尾项。因此 algebraic identity 不约束中间舍入与异常值。

### NN-EVA-C02
设候选真实 validation performance 为 $\mu_j$，观测为 $\hat\mu_j=\mu_j+\varepsilon_j$。即使 $E\varepsilon_j=0$，选择 $j^*=\arg\max_j\hat\mu_j$ 后通常有
$$E[\hat\mu_{j^*}-\mu_{j^*}]>0,$$
因为最大化同时偏好真实表现和正噪声；候选越多、噪声越大，optimism 越强。独立 test 或 nested selection 估计的是选择流程的泛化，而不是把被最大化的 validation 值当无偏真值。

### NN-EVA-C03
取线性区内 $\phi(z)=z$，$W=\operatorname{diag}(M,M^{-1})$，输入 covariance 取 $\operatorname{diag}(M^{-2},M^2)$，则输出 covariance 可为 $I$，activation moments 看似完全稳定；但层 Jacobian 就是 $W$，奇异值为 $M,M^{-1}$、condition number 为 $M^2$，可任意差。只盯逐坐标二阶矩会漏掉方向性梯度谱。

## D

### NN-EVA-D01
0.2% 可能小于 seed variation、数据采样误差或测量非确定性，也可能来自额外参数、不同调参预算或从许多候选中挑最大值。需要预注册主指标、matched budget、多 seed 区间、失败率和独立 test；若区间高度重叠，合理结论是“当前协议未分辨出有意义差异”，而不是宣布普遍优越。

### NN-EVA-D02
best seed 是对训练随机性的事后最大化，系统性高估典型性能并隐藏崩溃概率。审计应索取全部 seed、选择规则、总尝试次数、均值/中位数/区间、失败 run 与 code/config；若只有 best seed，只能把表格视为存在性结果——“至少一次达到过”——不能估计期望部署表现。

### NN-EVA-D03
原论文能支持其明确数据、模型和协议内的主张；官方实现/文档支持当前 API、公式 flag 与 kernel 语义；博客适合推导、解释和提出假说，但二手经验需回查原始证据；leaderboard 受提交选择、隐藏调参和不可比预算影响，只能提供线索。证据等级不等于作者地位，而取决于它是否直接测量当前命题且可复核。

## E

### NN-EVA-E01
预注册表至少包含：候选及精确公式/版本；architecture、初始化和 normalization；数据 split 与污染检查；plug-in/retuned/matched-budget 轨道；搜索空间与总预算；seeds；主次指标、最小有意义差异；失败/early-stop 规则；参数/MAC/bytes/latency/energy；统计汇总与多重选择处理；test 解封时点；代码、环境与 claim template。

### NN-EVA-E02
先在两类 GPU 上以 FP32 reference 验证 FP32/BF16/FP16 的 forward/VJP/gradgrad、极端输入、layout、fusion 和 determinism；记录 error quantiles、NaN/Inf、吞吐和 bytes。再在同一模型做 precision×hardware×activation factorial run，保持 token 与预算轨道一致，报告 loss scale、overflow、收敛、质量、时延与能耗。kernel 正确不推出模型等价，模型收敛也不能掩盖错误 kernel。

### NN-EVA-E03
先定义最小有意义质量差 $\delta$ 与 latency/energy 容差。若多 seed 区间不能排除 $[-\delta,\delta]$ 内的等效区，优先选择数值更稳、实现更简单、融合覆盖更好且运维风险更低者；若成本差也不显著，保留已有默认。bounded claim 写成：“在模型、数据、预算、硬件和置信区间所列范围内，未检测到超过 $\delta$ 的质量差，因此依据系统成本选 A。”
