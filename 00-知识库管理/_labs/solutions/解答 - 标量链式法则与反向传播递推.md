# 解答 - 标量链式法则与反向传播递推
## A
### NN-BP-A01
对标量损失 $L$，节点 $v$ 的 adjoint 记为 $\bar v=\partial L/\partial v$，向量时是与 $v$ 同形的 cotangent。输出对自身的 derivative 给出 seed $\bar L=1$。reverse topological order 是 forward 拓扑序的逆向，使节点在处理时已收到所有 children 贡献。
### NN-BP-A02
backpropagation 是多层网络中使用局部 VJP 的反向累积；reverse-mode AD 是对一般可微程序的更广算法框架；gradient descent 是拿已计算的 gradient 更新参数的 optimization rule。前两者计算 derivative，后者改变 parameters。
### NN-BP-A03
若 $v$ 进入 children $c_1,…,c_k$，则 $L$ 对 $v$ 的一阶变化包含每条路径，有 $\bar v=\sum_i(\partial c_i/\partial v)^T\bar c_i$。覆盖只保留最后到达的一条边，结果依赖调度且缺项；`+=` 才实现线性叠加。
## B
### NN-BP-B01
forward：$x=2,y=3,a=6,b=5,c=11,L=60.5$。reverse 从 $\bar L=1$ 开始；$L=c^2/2$ 给 $\bar c=11$；$c=a+b$ 给 $\bar a=11,\bar b=11$。$a=xy$ 向 $x,y$ 贡献 $33,22$；$b=x+y$ 又各贡献 $11$。最终 $\bar x=33+11=44$、$\bar y=22+11=33$。
### NN-BP-B02
在 $x=1$，$u=1,v=e,z=e,L=\log(1+e)$。有 $\bar z=1/(1+e)$，因 $z=uv$，$\bar u=e/(1+e)$、$\bar v=1/(1+e)$。通过 $u=x^2$ 的贡献是 $2x\bar u=2e/(1+e)$；通过 $v=e^x$ 的贡献是 $e^x\bar v=e/(1+e)$。故 $dL/dx=3e/(1+e)$。
### NN-BP-B03
给 seed $u=(3,-2)$ 等价于对 $s=3y_1-2y_2=3x^2-2\sin x$ 求导。因此 VJP $J_y(x)^Tu=6x-2\cos x$。它是一个与 scalar input 同形的数，不是二维 output gradient。
## C
### NN-BP-C01
把 $L$ 视为通过每个 child $c$ 依赖 $v$。总微分中，$dc=D_vc[dv]+其他输入项$；而 $dL=\sum_c\langle\bar c,dc\rangle$。只收集 $dv$ 项得 $dL|_{dv}=\langle\sum_cD_vc^*[\bar c],dv\rangle$。由 gradient/adjoint 的唯一性，$\bar v=\sum_cD_vc^*[\bar c]=\sum_c(\partial c/\partial v)^T\bar c$。
### NN-BP-C02
递推中每次把子节点 adjoint 替换为其 children 之和，最终得到从 $v$ 到 $L$ 每条路径上 local Jacobian-transpose products 的和。显式路径数可随层数指数增长；reverse dynamic programming 只计算每个节点的 $\bar v$ 一次，共享所有路径的重叠后缀。
### NN-BP-C03
若 $L=F(f_1(W),…,f_T(W))$，总微分中 $dW$ 通过每个 call site 出现，配对后系数必为 $\bar W=\sum_t\bar W^{(t)}$。若 $L=T^{-1}\sum_t\ell_t$，每个 $\bar W^{(t)}$ 已含 $1/T$；共享参数要求求和，不要求再额外平均。
## D
### NN-BP-D01
每条 reverse edge 施加的是 $J^Tu$，即 Jacobian transpose 对 cotangent 的乘法。它对矩形、秩亏 Jacobian 均定义良好，不解 $Jx=b$也不恢复输入。“转置”与“求逆”是两个不同操作。
### NN-BP-D02
令 $L=x^2+x$。图中 $x$ fan-out 到 square 和 identity-add 两支，局部规则分别给 $2x$ 和 $1$，真梯度是 $2x+1$。如果 backward 先写入 $2x$ 后又用 $1$ 覆盖，则回传得 1；局部导数都对，错在缺少 accumulation。
### NN-BP-D03
`stop_gradient(v)` 的 forward 是 identity，但人为定义 VJP 为 0；truncated BPTT 则删去跨越截断边界的路径。两者都保留当次 forward value，却改了“使用哪个程序求导”的合同，所得可是 surrogate/truncated gradient。
## E
### NN-BP-E01
为每个 call site 记录时间/token ID、局部输入、upstream cotangent 和本地 $\bar W^{(t)}$；统计 norm、sign/cosine 与累加前后值。用 untied clone 作小规模对照，检验 shared `.grad` 精确等于 clones gradients 之和，同时标注 loss reduction scale。
### NN-BP-E02
在各层记录 $\|\bar h_l\|$、$\|\bar z_l\|$、局部 JVP/VJP norm ratio 和 activation saturation rate，并以 log scale 随 depth 绘制。再用随机 power iteration 估计关键 block Jacobian 谱范数，对照 residual connection、normalization、initialization 与 dtype，区分局部放大/收缩和数值 underflow。
### NN-BP-E03
框架只能对已编程的 primitives 和指定 conventions 返回导数，无法自动验证损失是否表达任务、数据是否泄漏或 surrogate 是否合理。四层合同是：数学层检查可微性/推导；实现层用 hand case、finite difference、dot test；数值层检查 dtype/scale/stability；建模层用因果、数据与评估对照验证目标。
