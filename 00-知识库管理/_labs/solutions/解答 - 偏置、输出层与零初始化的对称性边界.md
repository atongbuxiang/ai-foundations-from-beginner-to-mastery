# 解答 - 偏置、输出层与零初始化的对称性边界

## A

### NN-ZERO-A01
对 $f(x)=\sum_jv_j\phi(w_j^Tx+b_j)$，unit bundle 是 incoming $w_j$、bias $b_j$ 与 outgoing coefficient/column $v_j$ 的联合对象。只让 $w_1=w_2$，但 $v_1\ne v_2$，反向到两个 incoming rows 的 multiplier 不同，下一步即可分离；所以 symmetry 判据必须比较被 unit permutation 一起搬动的全部参数与 optimizer state。

### NN-ZERO-A02
交换两个 units 不改变网络函数与 loss。若两 bundles 相同，交换后参数点仍是自身；gradient 的 equivariance 迫使两 bundle gradients 相同。SGD 使用同一 learning rate，故两参数的差从 0 更新为 $0-\eta(0)=0$。对每一步归纳即得对称子空间不变。

### NN-ZERO-A03
Hidden weights 全零/完整 bundle 相同通常危险，会 collapse 或阻断梯度。Hidden bias 通常可为零，只要 random weights 已区分 units。单层 linear/logistic 可从零离开，只需初始 loss gradient 非零。Zero output head 通常自身可学，但 step 0 上游 gradient 为零。Residual branch last layer 可零，因为 identity skip 传递主路径；branch earlier layers 通常延迟一步学习。

## B

### NN-ZERO-B01
$$\nabla_{W_2}L=\delta_2h^T,
\qquad \nabla_{W_1}L=((W_2^T\delta_2)\odot\phi'(W_1x+b_1))x^T.$$
全零且 $\phi=\tanh$ 时 $h=0$，所以 $\nabla W_2=0$；又 $W_2=0$，所以 $\nabla W_1=0$。输出 bias gradient $\delta_2$ 可非零，但仅学习常数输出不能恢复 hidden representation。

### NN-ZERO-B02
零 logits 给 $p=(1/2,1/2)^T$。样本和 loss 的
$$\nabla_wL=X^T(p-y)=I^T(-1/2,1/2)^T=(-1/2,1/2)^T,$$
$$\nabla_bL=\mathbf1^T(p-y)=0.$$
因此 weights 第一步就离开零；这里没有多个可置换 hidden units 的 collapse。

### NN-ZERO-B03
预测 $\hat y=w^Th=0$，residual 为 $-3$。于是
$$\nabla_wL=(\hat y-y)h=-3(2,-1)^T=(-6,3)^T,$$
$$\nabla_hL=(\hat y-y)w=0.$$
Head 第一步学习而 encoder 第一步冻结，精确展示 zero-head 的 staged gradient。

## C

### NN-ZERO-C01
令 permutation group element $P$ 作用于参数，且 $L(P\theta)=L(\theta)$。链式法则给
$$\nabla L(P\theta)=P\nabla L(\theta)$$
（在正交 permutation 表示下）。若 $P\theta=\theta$，则 $P\nabla L(\theta)=\nabla L(\theta)$，gradient 位于 fixed-point subspace 的 tangent space。Gradient flow $\dot\theta=-\nabla L$ 与 SGD 因而不离开该子空间。

### NN-ZERO-C02
Sigmoid 全零时 $h_j=1/2$，所以 output weights 可以收到 gradient；但所有 hidden coordinates 相同，若完整 bundles 与 optimizer states 对称，所有对应 output columns 同步更新，传回的 incoming gradients也相同。网络可能从全零移动，却仍停留在“一个 hidden feature 的多份复制”子空间；非零梯度不等于 symmetry 已破。

### NN-ZERO-C03
令 upstream gradient 为 $g=\partial L/\partial y$、$a=\phi(W_1x)$。在 $W_2=0$ 时
$$\nabla_{W_2}L=ga^T,$$
通常非零；
$$\nabla_{W_1}L=((W_2^Tg)\odot\phi'(W_1x))x^T=0.$$
同时
$$\frac{\partial y}{\partial x}=I+W_2D_\phi W_1=I.$$
所以主路径 gradient 不断，末层先学，branch earlier layer 延后。

## D

### NN-ZERO-D01
取标量输入 $x=1$、identity activation、两个 units $w_1=w_2=1$，但 $v_1=1,v_2=2$。对任意非零 output adjoint $\delta$，
$$\frac{\partial L}{\partial w_1}=\delta v_1x=\delta,
\qquad \frac{\partial L}{\partial w_2}=\delta v_2x=2\delta.$$
所以下一步 incoming weights 分离。Incoming rows 相同并不足以形成完整对称 bundle。

### NN-ZERO-D02
Mini-batch sampling 对两个精确相同 units 提供的是同一 batch 与同一计算图；它改变两者共同的 gradient，但不制造 unit-specific difference。若 dropout masks 独立或 kernel 非确定性，可能出现扰动，但这已增加显式/隐式 unit-specific randomness，并非 SGD sampling 本身的保证，也不应作为可复现 symmetry-breaking 方案。

### NN-ZERO-D03
串行全零网络中每层 backward 都乘下一层 zero weight，主路径没有 identity term，梯度链被切断。Residual block 的 total Jacobian 是 $I+J_F$；即使 $J_F=0$，$I$ 仍把 activation 与 gradient 传到后续 blocks。结构不同，所以 zero-last-layer 的局部安全性不能推广为每层全零。

## E

### NN-ZERO-E01
建立两-unit MLP，固定 deterministic data order/optimizer。四组为：完整全零、相同常数 bundle、incoming 相同/outgoing 独立、全部随机。每步记录 bundle distance、gradient distance、activation difference 与 effective feature rank。相同 bundle 组应保持机器精度内零差；若不保持，检查 dropout mask、non-deterministic kernel、optimizer state 与参数共享。

### NN-ZERO-E02
两组只改变 head：exact zero 与 matched small random；固定 encoder、data、loss reduction、optimizer、warmup、seed pairs。记录 step 0/1/2 的 head/encoder gradient、update norm、optimizer moments、early loss 与 feature drift。结论区分“zero head 首步冻结 encoder”与最终性能；多 seed 比较不能只看单次 early curve。

### NN-ZERO-E03
Policy 示例：普通 hidden weights 用 fan-aware independent random init；普通 bias 为 0，但 gate bias 按目标 open/closed prior 另设；padding embedding row 固定为 0 并屏蔽 gradient；classifier head 可 small random，若 zero 则记录 encoder 首步冻结；residual branch last layer 可 zero，但保留 identity skip、其余 branch weights 用 depth-aware scale。每条 policy 都绑定计算图与第一步 gradient，不用统一口诀。
