# 解答 - 深度分离、线性区域与表达效率
## A
### NN-DEP-A01
depth 是串行 nonlinear transforms 数；width 是最大并行 units；size 常指总 units/parameters；nonzero parameters 排除固定零；distinct values 在 weight tying 时小于参数槽位；executed units 按一次 forward 实际调用计。论文必须声明采用哪一种。
### NN-DEP-A02
固定 pattern 后每个 ReLU 是固定 diagonal mask $D_l$，于是层为 $D_l(W_lh+b_l)$；有限个 affine maps 复合仍 affine。
### NN-DEP-A03
region count 是单函数分片；VC 是函数类标记能力；Lipschitz 是敏感性；generalization 是算法—数据风险。它们不构成单调蕴含链。
## B
### NN-DEP-B01
$x\le0$ 为 0；$0\le x\le1/2$ 为 $2x$；$1/2<x\le1$ 为 $2-2x$；$x>1$ 为 0。
### NN-DEP-B02
$T(k/8)=(0,1/4,1/2,3/4,1,3/4,1/2,1/4,0)$；再作用 $T$ 得 $(0,1/2,1,1/2,0,1/2,1,1/2,0)$，共有 4 个单调线性 pieces。
### NN-DEP-B03
至多 12 breakpoints、13 intervals。$w_j=0$、threshold 在 domain 外、多个 threshold 重合或 outgoing coefficient 为零都会减少有效数。
## C
### NN-DEP-C01
每项 $\operatorname{ReLU}(w_jx+b_j)$ 在 $w_j\ne0$ 时只有一个 kink $-b_j/w_j$；和函数的 kink 集包含于这些点的 union，故不超过 $m$。
### NN-DEP-C02
$T$ 在每个半区单调映满 $[0,1]$。若 $T^{\circ L}$ 有 $2^L$ 个各自映满区间的单调 pieces，再复合 $T$ 会把每个 piece 在值 $1/2$ 处分成两段，得到 $2^{L+1}$。
### NN-DEP-C03
形式是存在目标族 $f_k$ 与小 deep representation；对所有受限 shallow networks，若 size 低于某指数阈值，则指定分布/norm 下误差有正下界。存在量词不能交换成“对所有 $f$”。
## D
### NN-DEP-D01
每层取正区间上的 identity $h\mapsto\operatorname{ReLU}(h)$，并保证输入非负；增加任意层仍是 identity，region 数为 1。
### NN-DEP-D02
最大值只说明某参数存在；训练可能不可达、数据只落在少数区域、过多敏感边界可能伤害鲁棒性。测试风险还依样本与算法。
### NN-DEP-D03
深网 critical path 更长、需更多 activation/cache 或 recomputation；浅宽网可能参数/通信大但并行好。相同参数数不固定 FLOPs、latency 或 memory。
## E
### NN-DEP-E01
按目标 dependency tree 放局部二元 modules，自底向上复合并在重复子函数处共享参数；再与同参数浅网比较 approximation curve。
### NN-DEP-E02
报告 executed depth $L$、每步 units/FLOPs 与总 FLOPs；parameter slots（tied 后一份）；distinct values。untied 网络三者随 $L$ 增，tied 网络后两者可固定而执行成本增长。
### NN-DEP-E03
比较 teacher/student function error、难例/高频 slices、linear regions 或 task probes；独立训练与 distillation optimization；latency、memory、throughput、calibration 和 shift。不能只看参数数。
