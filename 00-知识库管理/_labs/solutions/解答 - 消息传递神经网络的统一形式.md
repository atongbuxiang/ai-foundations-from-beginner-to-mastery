# 解答 - 消息传递神经网络的统一形式

## A. 识别与复述

### ARCH-MPNN-A01
$m_{j\to i}^{(l)}=M_l(h_i^{(l)},h_j^{(l)},e_{ji})$；$m_i^{(l)}=\operatorname{AGG}_l\{m_{j\to i}^{(l)}:j\in\mathcal N(i)\}$；$h_i^{(l+1)}=U_l(h_i^{(l)},m_i^{(l)})$。Graph task 还需 invariant readout。

### ARCH-MPNN-A02
邻居没有语义顺序，但同值邻居可出现多次。多重集既忽略枚举顺序又保留 multiplicity，正好匹配图邻域。普通 set 会错误去重，sequence 会错误引入顺序。

### ARCH-MPNN-A03
同步更新用整层旧 $H^{(l)}$ 生成所有 $H^{(l+1)}$，与节点遍历无关。原地异步更新让后访问节点读取部分新状态，定义依遍历顺序，属于另一种动力系统。

## B. 手算与建模

### ARCH-MPNN-B01
邻居和为 $(m_1,m_2,m_3)=(2,1+4,2)=(2,5,2)$。加旧状态得 $h'=(3,7,6)$。无 self-loop 已由 update 的 $h_i$ 项保留中心。

### ARCH-MPNN-B02
以 $(3,7,6)$ 同步计算邻居和 $(7,9,7)$，更新得 $(10,16,13)$。节点 1 的第二层消息来自节点 2 的第一层状态，而该状态已含节点 3，所以第二层首次受 3 影响。

### ARCH-MPNN-B03
$m_{1\to2}=2\cdot3=6$，$m_{3\to2}=-1\cdot5=-5$，sum 得 $h_2'=1$。若反向边未显式加入，节点 1、3 不从 2 接收消息。

## C. 推导与证明

### ARCH-MPNN-C01
重标号建立边和邻居的一一对应。共享 $M$ 使对应边消息相同；invariant AGG 使对应节点聚合相同；共享 $U$ 使输出只是换行，故一层等变。初始 $PX$ 等变；假设第 $l$ 层等变，一层论证推出 $l+1$ 层，归纳完成。

### ARCH-MPNN-C02
$K=0$ 时只依自身。假设 $l$ 层每节点只依其 $l$-hop；下一层 $i$ 只读取一跳邻居 $j$ 的 $l$-hop 信息，其并集包含于 $i$ 的 $(l+1)$-hop。归纳得至多 $K$-hop。

### ARCH-MPNN-C03
根为 1 个，第 1 层最多 $s$，第 2 层 $s^2$，至第 $K$ 层 $s^K$；总数 $1+s+\cdots+s^K=(s^{K+1}-1)/(s-1)=O(s^K)$。真实图的重复节点、degree 截断和子图去重会降低数量。

## D. 边界、反例与纠错

### ARCH-MPNN-D01
令 AGG 把“第一个邻居减第二个邻居”。邻居特征 $(1,3)$ 输出 $-2$，反序输出 2；重标号改变 edge-list 枚举即可改变预测，所以不等变。

### ARCH-MPNN-D02
三层只给结构可见性上限。Sampling 可能漏节点；mean/max 可碰撞；gate 可置零；ReLU 可截断；长路径 Jacobian 可很小。故存在路径不等于信息实际进入或可被 decoder 恢复。

### ARCH-MPNN-D03
两节点双向边，初态 $(1,2)$，规则 $h_i\leftarrow h_i+h_j$。顺序 1 后 2 得 $(3,5)$；顺序 2 后 1 得 $(4,3)$。同步本应得 $(3,3)$。

## E. AI 迁移

### ARCH-MPNN-E01
用小图手算/dense reference 验 forward；随机 $P$ 验等变；有限差分验 node/edge parameter gradient；用只有单向边的图确认不可逆向传播；覆盖 self-loop、重复边、孤立点、空 edge list、batch 与 float64/32 tolerance。

### ARCH-MPNN-E02
固定 encoder 宽深、optimizer/data/split，扫 fan-out 与 full；同一推理策略或同时报告 sampled/full inference；测 quality、variance over sampling seeds、coverage、throughput、peak memory；按 degree 分层并记录 sampled node/edge counts。

### ARCH-MPNN-E03
设 batch 共 $n$ 原子、$m$ 键、宽度 $d$、edge width $e$、层数 $K$。记录 node tensor $n\times d$、directed edge index $2\times m'$、edge tensor $m'\times e$；每层 message 约 $O(m'd)$、projection 约 $O(nd^2)$，激活约 $O(Knd)$ 加 edge intermediates；图以 disjoint union batching，readout 按 graph id 分组。
