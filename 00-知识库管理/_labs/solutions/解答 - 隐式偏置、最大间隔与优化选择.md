# 解答 - 隐式偏置、最大间隔与优化选择
## A
### LT-IB-A01
explicit regularization 显式优化 $\widehat L+\lambda\Omega$；implicit bias 是未写该 penalty 时，特定 dynamics 仍在多训练最优解中选择结构化极限/方向。后者必须随 optimizer、init、loss、step 和 parameterization 声明。
### LT-IB-A02
$\{w:Xw=y\}=X^\dagger y+\ker X$；$X^\dagger y\in\operatorname{row}(X)$，且 $\operatorname{row}(X)=\ker(X)^\perp$。任意解唯一分为 row-space min-norm 部分与训练不可见 null 部分。
### LT-IB-A03
严格可分 logistic 下，empirical loss→0、training error 最终为0、$\|w_t\|\to\infty$；在 theorem 条件下 normalized direction $w_t/\|w_t\|$ 趋 hard-margin SVM direction。raw parameter 不收敛到有限点。
## B
### LT-IB-B01
零初始化保持 $w_1=w_2$，与 $w_1+w_2=1$ 交于 $(1/2,1/2)$。$(1,-1)$ 是 null component，gradient 不改变它，故极限 $(1/2,1/2)+(1,-1)=(3/2,-1/2)$。
### LT-IB-B02
最小 norm 等式解为 $A^T(AA^T)^{-1}1$，$A=(1,2)$，故 $(1,2)/5=(0.2,0.4)$。
### LT-IB-B03
主项 norm 为 $\Theta(\log t)$，余项 $O(\log\log t)$，归一化后方向误差典型为 $O(\log\log t/\log t)$。
## C
### LT-IB-C01
$\nabla L=X^T(Xw-y)$ 总在 row space；从0开始所有 iterates在 row space。合适步长使 residual趋0，则极限属于插值集合；row space 与该 affine 集合唯一交点是 $X^\dagger y$，故结论。
### LT-IB-C02
对 $v\in\ker X$，$v^T\nabla L=(Xv)^T(Xw-y)=0$。每次 update没有 null-space 分量，所以 $P_{\ker X}w_{t+1}=P_{\ker X}w_t=P_{\ker X}w_0$。
### LT-IB-C03
logistic gradient 是 $-\sum_i y_ix_i/(1+e^{y_iw^Tx_i})$；大 margin 时权重约 $e^{-m_i}$。最小 normalized margin点衰减最慢并主导长期梯度；其正组合与 hard-margin KKT 中 support vectors/dual coefficients对应，方向被推向最大化最小 margin 的解。
## D
### LT-IB-D01
需 homogeneous linear predictor或特定 homogeneous network、strict separability、logistic/exponential-tail loss、GD而非任意SGD、步长范围、初始化、是否有 bias、direction而非parameter convergence，以及 finite/asymptotic量词。Adam、noise、nonseparable data均需新 theorem。
### LT-IB-D02
更新 $-A\nabla L$ 相当于在 $A^{-1}$ metric 最陡下降，约束解偏向 min $w^TA^{-1}w$。coordinate rescaling改变 Euclidean gradient和 $A$，故同一 function class可选不同解。
### LT-IB-D03
它依赖矩阵 measurement structure、factorization、small initialization、step/gradient-flow与部分 commutativity/RIP 条件；更深 factorization甚至可能不能由单一norm刻画。一般非线性深网有symmetry、feature learning和非唯一function representation。
## E
### LT-IB-E01
匹配 data/order/compute/train loss，记录 LoRA factor initialization/scale与 full update；比较输出 logits、margins、function distance、effective rank和shift risk，而非只比parameter norm；做factor-rescaling controls检验 measure invariance，并用多 seeds 估计 selected-function distribution。
### LT-IB-E02
第一段证明 dynamics invariant/limit；第二段把 limit表征为 min norm/max margin/其他 function class；第三段在明确 $P$ 下用 margin、spectrum、stability或bound控制risk。每段分别给 assumptions、counterexample与实验可观测量。
### LT-IB-E03
claim card：training loss及tail；separable/noise；optimizer/preconditioner/randomness；initialization；step/time；parameterization/symmetry；limit是parameter/direction/function；finite rate；selected solution表征；population-risk bridge。
