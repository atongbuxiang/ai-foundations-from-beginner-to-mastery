# 解答 - 自编码器、重构与生成缺口

## A. 识别与复述

### GEN09-A01
AE 最小化 $\mathbb E_{\widehat P_n}d(X,g(f(X)))$；生成先声明 $Z\sim\nu$，输出分布为 $Q=g_\#\nu$，即 $Q(A)=\nu(g^{-1}(A))$。前者只量化训练数据及其编码点，后者量化 $\nu$ 几乎所有 latent 输入，故前者不蕴含 $Q\approx P_*$。

### GEN09-A02
至少补：latent prior $p(z)$、observation model $p_\theta(x\mid z)$、joint $p_\theta(x,z)$、evidence/训练目标、posterior 推断或其近似、祖先采样和部署输出协议。若要严格评价，还应补样本空间、参考测度与指标。

### GEN09-A03
若 $p_\theta(x\mid z)=N(m_\theta(z),\tau^2I)$，decoder 均值只是 $m_\theta(z)$；模型抽样还需加 observation noise；再把 $z\sim p(z)$ 积分后才得到输出边缘。始终输出均值会诱导另一分布，通常更集中。

## B. 手算与建模

### GEN09-B01
概率为
$$
2[\Phi(3.1)-\Phi(2.9)]\approx
2(0.2)\varphi(3)\approx0.00177.
$$
所以约 $99.82\%$ 的 prior 样本落在这两个小训练区之外。近似只用局部密度；精确值可由 Gaussian CDF 求。

### GEN09-B02
$f'=h\circ f=3(2x+1)=6x+3$；$h^{-1}(u)=u/3$，故
$$
g'=g\circ h^{-1},\qquad g'(u)=\frac{u/3-1}{2}=\frac{u-3}{6}.
$$
于是 $g'(f'(x))=(6x+3-3)/6=x$，与原重构完全相同。

### GEN09-B03
令 $f(-1)=-1,f(1)=1$，$g(-1)=-1,g(1)=1$，对其余 $z$ 令 $g(z)=10^6$。训练误差为零；但 $U[-2,2]$ 抽到恰好 $\{-1,1\}$ 的概率为零，所以几乎必然输出坏值。

## C. 推导与证明

### GEN09-C01
对任意 $x$，
$$
g'(f'(x))=(g\circ h^{-1})(h\circ f(x))
=g((h^{-1}\circ h)(f(x)))=g(f(x)).
$$
故任意逐样本 distortion 相同，经验或总体重构期望也相同。

### GEN09-C02
有限 code 集 $S$ 在绝对连续 $\nu$ 下满足 $\nu(S)=0$。重构约束只规定 $g$ 在 $S$ 的取值；任取两个在 $S$ 上一致、在 $S^c$ 上任意不同的 decoder，其训练重构相同，但因 $\nu(S^c)=1$，生成分布可以完全不同。

### GEN09-C03
确定性条件可写 $p_\theta(dx\mid z)=\delta_{g_\theta(z)}(dx)$，边缘为 $g_{\theta\#}p(z)$。若 $z\in\mathbb R^m,x\in\mathbb R^d,m<d$ 且 $g$ 足够规则，其像通常落在低维集合上，对 $d$ 维 Lebesgue 测度奇异。加入 full-dimensional observation noise 可展宽为普通 density。

## D. 边界、反例与纠错

### GEN09-D01
线性插值只测试一条选定路径；连续 decoder 能让像素平滑，即使路径穿过极低概率区。还存在可逆坐标扭曲保持重构却改变直线。要声称“真实流形”，至少需定义 manifold/metric、density 与独立 geodesic 或 neighborhood 证据。

### GEN09-D02
对任意有限样本 $x_1,\ldots,x_n\in\mathbb R^D$，分配不同标量 $z_i=i$，用高容量网络插值使 $f(x_i)=i,g(i)=x_i$。latent 仅一维仍可零误差记忆有限集；维数小不是信息容量的充分限制。

### GEN09-D03
加噪只定义某个 stochastic encoder。VAE 还需生成 prior、likelihood、joint、变分 posterior 的角色和 ELBO。若 loss 仍是任意重构距离，噪声分布也未与 posterior density/entropy 对齐，就没有 variational evidence bound。

## E. AI 迁移

### GEN09-E01
四组应分别报告：held-out reconstruction（相同 encoder path）；prior samples（从声明 prior 采）；interpolation（多对样本、路径密度/端点匹配）；coverage（独立 feature 下 precision/recall 或 mode count）。固定 preprocess、decoder sampling/mean、seed 和样本预算。

### GEN09-E02
若只有 waveform→codes→waveform、rate 和重构感知分数，它是 codec。称生成模型还需 code prior、条件 waveform likelihood/decoder 随机合同、训练目标、从 prior 的完整采样、覆盖与 likelihood/分布评价；外部语言模型生成 codes 也要单列。

### GEN09-E03
冻结 encoder/decoder，比较标准 prior、拟合 aggregate posterior 的 density、经验 code bootstrap 与局部扰动。若后两者好而标准 prior 坏，主因是 mismatch；若所有离开训练点的局部扰动都坏，decoder 外推是主因。用相同 latent 样本保存 decoder 输入和输出，避免采样器混淆。
