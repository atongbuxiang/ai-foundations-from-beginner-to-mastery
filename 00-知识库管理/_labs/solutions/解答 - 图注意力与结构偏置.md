# 解答 - 图注意力与结构偏置

## A. 识别与复述

### ARCH-GAT-A01
$z_i=Wh_i$；$e_{ij}=\mathrm{LeakyReLU}(a^\top[z_i\Vert z_j])$；$\alpha_{ij}=\exp e_{ij}/\sum_{k\in N(i)}\exp e_{ik}$；$h_i'=\sigma(\sum_{j\in N(i)}\alpha_{ij}z_j)$。需声明边方向与 self-loop。

### ARCH-GAT-A02
$e_{ij}$ 是未归一化兼容分数；$\alpha_{ij}$ 是对同一接收节点邻域归一化后的相对系数；message/value 是被加权传输的内容，如 $Wh_j$ 或含 edge feature 的变换。高 score 不等于 value 大。

### ARCH-GAT-A03
共同：内容依赖 score、softmax、value aggregation、可多头。不同：GAT 默认 sparse graph mask；无天然序列位置；成本按 $|E|$；edge direction/degree/isolated node 改变归一化域。Dense Transformer 默认全 token 对可见并常含显式位置编码。

## B. 手算与建模

### ARCH-GAT-B01
指数为 $(1,2,3)$，总和 6，所以权重 $(1/6,1/3,1/2)$。

### ARCH-GAT-B02
输出 $1/6\cdot1+1/3\cdot4+1/2\cdot(-2)=1/6+4/3-1=1/2$。

### ARCH-GAT-B03
Concatenation 为 $(1,2,3,0)$，维数 4；average 为 $((1+3)/2,(2+0)/2)=(2,1)$，维数 2。

## C. 推导与证明

### ARCH-GAT-C01
重标号把每条边与目标邻域一一重排。共享 $W,a$ 使对应 $e$ 相同；每个目标的 score 多重集相同，softmax 只重排系数；加权 sum 顺序不变，故对应节点输出相同并换到新行，即等变。

### ARCH-GAT-C02
$\mathrm{softmax}(e_j+c)=e^{e_j+c}/\sum_ke^{e_k+c}=e^c e^{e_j}/(e^c\sum_ke^{e_k})=\mathrm{softmax}(e_j)$。

### ARCH-GAT-C03
Projection $O(ndKd_h)$（若每头独立）；edge score 与 aggregation $O(|E|Kd_h)$；attention logits/weights 激活约 $O(|E|K)$，node outputs $O(nKd_h)$。若总 output width 固定为 $Kd_h=d'$, 应按该约束重写比较。

## D. 边界、反例与纠错

### ARCH-GAT-D01
两个邻居权重 $(0.9,0.1)$，value $(0,10)$。贡献为 $(0,1)$；权重最大的邻居贡献为零。向量情形还需看方向与下游 Jacobian。

### ARCH-GAT-D02
Vanilla GAT 的 mask 只含 $N(i)$；一层 $h_i'$ 不依非邻居。需多层、global edges/token 或 dense attention 才扩大可见性，且多层仍有传播瓶颈。

### ARCH-GAT-D03
输出取决于 weight × value、后续层与 residual；可替代的参数化可能给相同预测却不同 heatmap；相关不等于删除该边的因果效应。需 intervention/counterfactual/stability 等独立验证。

## E. AI 迁移

### ARCH-GAT-E01
构造一个 source 连向两个 target、另一个 target 有三入边的非对称图；手算每个 target 的 softmax 和为 1，source 分组则故意失败；检查 edge reversal、self-loop、isolated target、batch，确保输出与 reference 一致。

### ARCH-GAT-E02
固定 split/features/depth/total width/parameter 或给两种 matched budget；相同 tuning seeds/steps。报告 accuracy、calibration、参数、edge operations、peak memory、train/inference latency；扫 degree/batch，使用优化稀疏实现并报告版本。

### ARCH-GAT-E03
四组：structure-only fixed weights；node-content score；再加 edge bias 只影响 logits；edge transform 只影响 value；二者同时。对齐参数，测质量、edge perturbation robustness、attention entropy 和 counterfactual contribution，以定位收益来源。
