# 解答 - 自回归模型的表达、成本、失效模式与证据地图

## A. 识别与复述

### GEN08-A01
Chain rule 允许把真实 joint 写为真实 conditionals；它没有说一个固定参数共享网络能表示每个 conditional，也未给参数量、深度、receptive field、sample complexity 或优化算法。将存在性变成有限架构保证还需 universal approximation 与复杂度定理。

### GEN08-A02
分布/support：稀有 mode 消失；conditional family：连续输出被平均；排序/架构：远程依赖失败；train–rollout：错误前缀无法恢复；decoding：重复/过长/覆盖降；system：cache/mask 泄漏。评价协议还可产生“只看 cherry-picked 样本”的假象，通常单列为第七审计层亦可。

### GEN08-A03
NLL 衡量测试数据的平均 log score；precision/quality 看生成样本是否可信；recall/coverage 看数据模式是否被覆盖；conditional consistency 看输出是否满足给定条件；latency 看程序时间成本。任何一项都不能替代其他四项。

## B. 手算与建模

### GEN08-B01
无 cache 累计 pairs

$$
\sum_{t=1}^Tt^2=\frac{T(T+1)(2T+1)}6=O(T^3).
$$

有 cache 每步仅新 query 对 $t$ keys：

$$
\sum_{t=1}^Tt=\frac{T(T+1)}2=O(T^2).
$$

这只是 attention pair 主项；FFN、projection、kernel I/O 另计。

### GEN08-B02
Token perplexity 分别为 $e^{1.8}\approx6.05$ 与 $e^{1.75}\approx5.75$。长度 100 的平均 sequence log score 相差约 5 nat，但自由生成质量还依误差落在哪些 token、decoder、校准、prefix shift 与 sequence metric，不能由 PPL 比率直接换算。

### GEN08-B03
第一系统生成的大部分样本可信，但只覆盖少数模式，适合高 precision/低 diversity 场景；第二系统质量稍低但覆盖更均衡。是否偏好取决于任务损失，且指标 estimator/feature space 也需审计；不能以单一“更好”隐藏 Pareto trade-off。

## C. 推导与证明

### GEN08-C01
对 joint $P(x_{1:T})$，在其正概率前缀上定义

$$
p_t(x_t|x_{<t})=\frac{P(x_{1:t})}{P(x_{<t})},
$$

零概率前缀任取 normalized conditional。Chain rule 使乘积在 joint support 上等于 $P$，support 外路径会在某步获得零质量。因此存在 exact AR 表示。证明用了一张可能指数大的条件表，没有给紧凑神经表示或高效采样硬件保证。

### GEN08-C02
有 prompt 长度 $P$、新增 $S$ tokens，若每步无 cache 重算整前缀，pairs 为

$$
\sum_{s=1}^S(P+s)^2
=SP^2+PS(S+1)+\frac{S(S+1)(2S+1)}6.
$$

Cache 后增量 decode 为

$$
\sum_{s=1}^S(P+s)=SP+\frac{S(S+1)}2.
$$

共同 prefill 的 $P^2$ 可另加一次；不同 attention variants 会改变常数或窗口。

### GEN08-C03
观测重复至少有：raw model 把循环赋高概率；top-$p$ 删除 EOS；cache/position bug。干预分别是原样 sampling 与 raw-logit probe、扫截断并记录 EOS mask、full-vs-cache/reset test。相关日志如“循环时 entropy 低”可由三者共同造成；只有改变一个机制并观察反事实输出，才更接近因果区分。

## D. 边界、反例与纠错

### GEN08-D01
设模型准确给 100 个模式各 0.01，held-out NLL 达到真实最优。部署 top-$p=0.5$ 在固定 tie-break 下只保留前 50 个并归一化，输出覆盖立刻减半。模型 likelihood 无问题，失败来自 $Q_{\theta,\phi}$。

### GEN08-D02
真实数据为两类清晰图像 A/B 各半。生成器只输出 A 类内部的高质量、多样样本。人工查看每张都清晰，precision 近 1；但 B 类从不出现，recall 仅覆盖一半。样本画廊无法证明 mode coverage。

### GEN08-D03
给完整真实序列时，causal mask 允许 Transformer 同时计算所有位置的 conditional logits；每行不读未来即可满足统计因果。采样时未来 token 未知才需要逐步决定。训练执行图和生成依赖图不同，所以采样串行不推出训练 token loop 串行。

## E. AI 迁移

### GEN08-E01
共同列：样本单位、token/像素/latent 长度；exact/bound NLL 及归约；参数/训练 compute；condition family；采样 rounds、cache/NFE、latency；quality/coverage。文本再报 tokenizer/EOS；raw pixel 报 bit depth/dequantization 与 $HWC$；VQ 图像报 tokenizer reconstruction/codebook usage 和二阶段误差。不能只按“AR”合并成本。

### GEN08-E02
5861 的 chain factorization 是 `I`，beam 效果是 `E`；7259 的 prefix mismatch 是 `I`，具体对策改善是 `E/H`；7500 的 top-$p$ 定义与 stopping 问题是 `I`，通用最佳参数是未成立 `E`；8062 的 IS/rejection 公式是 `I/T`（由概率来源证明），文本效率是 `E`；10197 的 MSE–Gaussian 解释是 `I`，加噪与“生成促进理解”为 `H/O`。补证分别用原论文、正式推导、受控实验和反例。

### GEN08-E03
选择同数据/分辨率/tokenizer（或明确两阶段代价），匹配参数、训练 FLOPs/数据量；分别调优但公开预算。报 held-out NLL/ELBO 口径、precision/recall/FID 与人评、条件准确、采样 NFE/串行 rounds、wall-clock/energy/memory；多质量—成本 Pareto 点而非单点。跨文本/图像或不同硬件时限定结论；若任一族在同预算稳定支配才支持局部“优于”，仍不支持普遍淘汰。
