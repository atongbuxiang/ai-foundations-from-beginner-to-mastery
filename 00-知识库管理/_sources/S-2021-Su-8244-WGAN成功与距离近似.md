# WGAN 成功与 Wasserstein 近似的边界

> [!abstract] 来源定位
> 文章讨论一个重要反例性视角：实际 WGAN critic、Lipschitz regularization 和交替优化未必精确逼近 population $W_1$，训练成功也不能反向证明“准确估计 Wasserstein 距离”是唯一机制。课程采用这一问题意识，而不把评论性结论升级为所有 WGAN 的普遍因果解释。

## 核心断言与课程判断

| ID | 断言 | 类型 | 条件/边界 | 当前判断 |
|---|---|---|---|---|
| C1 | $W_1$ 的 Kantorovich–Rubinstein dual 使用全体 1-Lipschitz functions | 经典定理 | Polish/metric space 与 finite first moment 等条件 | 已核验 |
| C2 | neural critic、spectral normalization 或 sampled gradient penalty 只近似该函数类 | 工程事实 | architecture 与 enforcement scheme 相关 | 成立 |
| C3 | GAN 效果好不证明估计的 population $W_1$ 更准 | 逻辑边界 | 还涉及 regularization 与 game dynamics | 成立 |
| C4 | Wasserstein geometry 与 WGAN 成功完全无关 | 因果主张 | 证据不足以作普遍否定 | 不采用 |

## 课程采用的四层分解

1. population metric：$W_1(P,Q)$；
2. empirical metric：$W_1(\widehat P_n,\widehat Q_m)$；
3. restricted critic optimum；
4. alternating optimizer 实际达到的 train objective。

四层不同。只有同时控制 function approximation、sampling、optimization 和 generalization，才能把第四层解释成第一层的可靠估计。
