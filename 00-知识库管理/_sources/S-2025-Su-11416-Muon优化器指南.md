# Muon优化器指南

> [!abstract] 来源定位
> 文章汇总 Muon 的使用对象、超参数、缩放和实践注意事项。它适合建立中文操作地图，但软件 transition、默认值和分布式行为以访问日的官方源码为最高实现依据。

## 采用内容

- 二维 hidden-weight 与 embedding、bias、norm、output head 的参数组边界；
- momentum、orthogonalization、shape scaling 与 learning rate 的组合顺序；
- 从 AdamW 迁移时需要重新审计状态、学习率、weight decay 与失败预算；
- 训练吞吐、通信和额外矩阵乘不能由单个 microbenchmark 代替。

## 不越界结论

1. “指南推荐”不是跨模型最优超参数定理；
2. 旧实现中的 sum-style momentum 与当前 PyTorch EMA-style buffer 不可混用 checkpoint；
3. 公开 loss curve 只证明对应配方下的观测，不证明 matrix geometry 是唯一因果机制；
4. 是否采用 Muon 应由质量、tokens/FLOP、wall-clock、显存、通信尾延迟和失败运行共同决定。
