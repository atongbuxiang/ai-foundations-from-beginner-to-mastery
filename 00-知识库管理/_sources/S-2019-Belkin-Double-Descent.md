# Reconciling Modern ML and Bias–Variance
> [!abstract] 来源定位
> 系统提出/展示统一的 double-descent performance curve，把 interpolation threshold 后的风险下降接到经典 U 型曲线。本库调用现象与实验框架，不把经验普遍性当作所有模型 theorem。
## 本库调用
1. interpolation threshold；
2. model-wise double descent；
3. classical/modern curve relation；
4. min-norm/simple interpolant intuition；
5. phenomenon–mechanism 分层。
