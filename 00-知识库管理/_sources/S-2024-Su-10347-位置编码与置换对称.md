# Decoder-only的LLM为什么需要位置编码？

> [!abstract] 来源定位
> 文章从 attention 对 token permutation 的结构出发，讨论 causal decoder是否仍需要显式位置编码。课程采用其问题设置，补上完整 sequence map 的 equivariance、固定 query 对 key–value pair重排的 invariance、causal mask的关系结构与 empirical performance之间的类型区分。

## 课程重建的核心等式

无 position-dependent term与asymmetric mask时，对 permutation matrix $P$：

$$
Q(PX)=PQ(X),\quad K(PX)=PK(X),\quad V(PX)=PV(X),
$$

$$
Q'K'^\top=P(QK^\top)P^\top,
$$

row-softmax满足 conjugation law，因此

$$
\operatorname{Attn}(PX)=P\operatorname{Attn}(X).
$$

完整 sequence output是 permutation-equivariant；若固定一个 query而只同步重排 key–value pairs，则该 query output invariant；symmetric pooling以后才得到 set-level invariance。

## 核心断言与课程判断

| ID | 断言 | 条件/边界 | 当前判断 |
|---|---|---|---|
| C1 | 无位置双向 attention 对同步 token permutation有结构对称 | 无 position/mask不对称项；shared projections | 修正术语后采用 |
| C2 | Attention汇聚对 key–value pair reorder不敏感 | query固定、keys与values同步重排 | 已核验 |
| C3 | Causal mask自身包含order信息 | mask定义了有向可见关系 | 已核验 |
| C4 | 因此 decoder-only完全不需要位置编码 | expressivity、optimization、length generalization与task依赖 | 不无条件采用 |
| C5 | 加position encoding只是“破坏置换不变性” | 更准确是修改group/action与relative structure | 补严后采用 |

## 课程补严

- 区分 equivariant sequence map与 invariant readout；
- 把 mask看作domain relation的一部分，只有保持mask的permutations才可能是symmetry；
- absolute、relative bias、RoPE分别指定不同position transformation law；
- algebraic symmetry、可表达性、可学习性与 empirical benchmark分层；
- padding mask、batching与KV cache implementation也进入end-to-end audit。
