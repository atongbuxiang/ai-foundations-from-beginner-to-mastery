# Data Statements for NLP

> [!abstract] 来源定位
> 论文提出为语言数据记录说话者/作者、语言变体、收集语境和标注等信息，以约束系统性偏差和外推范围。课程将其扩展为大规模预训练 data card 的“谁的语言、何时、在何种语境、经何种选择进入”账本。

无法获得人口学信息不应被填成“未知即均衡”；应显式记录 missingness、代理变量风险与不允许作出的群体结论。
