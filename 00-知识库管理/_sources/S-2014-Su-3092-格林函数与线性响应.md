# 力的无穷分解与格林函数法

> [!abstract] 来源定位
> 本文从物理响应与线性叠加的角度解释 Green function 方法。这里将它作为“线性 PDE 的输入函数如何映到输出函数”的中文直觉桥，连接 inverse differential operator、integral kernel 与 neural operator；它不承担 Sobolev、trace、Lax–Milgram 或神经算子通用逼近定理的正式证据。

## 结构摘要

文章利用线性系统可叠加的结构，把复杂外力看成许多局部激励的组合；若已知单位点激励产生的响应，就能通过积分组合恢复一般输入的响应。这个“局部响应核”就是 Green function 方法的核心直觉。

```mermaid
flowchart LR
    F["一般 forcing"] --> D["分解为局部激励"]
    D --> G["Green response"]
    G --> I["积分叠加"]
    I --> U["solution field"]
```

## 值得保留的推导或方法

将输入写成 point responses 的连续叠加：

$$
u(x)=\int G(x,y)f(y)\,dy.
$$

它在概念上同时连接：

1. differential operator 的 inverse；
2. integral operator 的 kernel；
3. 一族输入函数到输出函数的 solution operator；
4. neural operator 中可学习的 integral kernel layer。

## 限制与保留意见

- Green function 是否存在、是否唯一以及属于哪个 function/distribution space，依赖算子、边界条件和区域；
- 点源常是 distribution，不能只用 classical function 语言处理；
- 非线性 PDE 一般不能直接使用线性叠加；
- 原文不是 Sobolev space、弱解或神经算子的正式数学来源；这些结论以教材与原始论文为准。
