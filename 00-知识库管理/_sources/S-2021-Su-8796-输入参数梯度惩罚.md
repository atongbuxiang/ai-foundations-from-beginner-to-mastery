# 苏剑林：输入梯度与参数梯度惩罚的条件性联系

> [!abstract] 来源定位
> 文章在特定分层网络与范数条件下比较输入梯度和某层参数梯度，给出一个带 activation、weight 与中间 Jacobian 比例的不等式。它提醒两类 penalty 可有结构联系；比例项本身会随表示尺度变化，不能把二者视作同一正则器。

## 证据边界

- 输入梯度属于 function sensitivity；参数梯度属于当前参数化与 loss 的 optimization geometry；
- 重参数化、normalization、hidden scale 和 weight norm 会改变不等式中的系数；
- 单向 bound 不给等价，也不说明两种 penalty 的最优 strength 可互换；
- 博客承担问题入口，正式矩阵范数、chain rule 与统计结论由课程其他节点补证。
