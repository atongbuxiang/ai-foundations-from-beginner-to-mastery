# VQ 编码表加线性变换（SimVQ）

> [!abstract] 来源定位
> 文章解释 SimVQ 的关键：把有效 codebook 参数化为 $E=QW$，函数表达能力未必增加，但梯度下降动力学改变，未命中的 code 也可通过共享 $W$ 联动更新。

## 核心判断

- $QW$ 在推理时可合并成一个矩阵，因此“多一层”不自动扩大表示族；
- 在训练时，$W$ 的梯度汇总被选 code 的信号，使整张 codebook 发生耦合更新；
- 原论文与博客复现实验显示收敛/利用率改善，但仍是协议依赖经验；
- 仅训练 $W$、固定随机 $Q$ 是抑制共同坍缩的一种选择，不是代数必然；
- EMA 更新版 VQ 若改用 SimVQ，优化器合同也随之改变，不能只插入矩阵而不记录更新规则。
