# L2正则没有想象那么好？可能是“权重尺度偏移”惹的祸

> [!abstract] 来源定位
> 文章讨论深度网络中正齐次结构带来的 layer rescaling freedom：函数可保持不变，参数 L2 却随层间尺度分配改变。课程借此限制“L2 就是自然复杂度”与“weight decay 就是固定 Gaussian prior”的无条件说法；不把经验现象外推成对所有 architecture 的普遍否定。

## 核心结构

对两层正齐次网络的一类变换可示意为

$$
W_1\mapsto cW_1,\qquad
W_2\mapsto c^{-1}W_2,\qquad c>0.
$$

当 activation 满足正齐次性时，网络函数可保持不变，但

$$
\|cW_1\|_F^2+\|c^{-1}W_2\|_F^2
$$

一般随 $c$ 改变。因此 parameter norm 不仅度量函数，还选择同一函数的参数代表和 layer balance。

## 核心断言与课程判断

| ID | 断言 | 条件/边界 | 当前判断 |
|---|---|---|---|
| C1 | 正齐次网络存在层间 rescaling symmetry | architecture/activation 满足对应齐次性 | 已核验 |
| C2 | 相同函数可具有不同 parameter L2 | 沿 symmetry orbit | 已核验 |
| C3 | L2 会同时影响 function fitting 与尺度代表选择 | optimizer、normalization、parameter mask 共同作用 | 有条件采用 |
| C4 | L2 一般都无效 | architecture/task 依赖，经验结论不能普遍化 | 不采用 |
| C5 | L2 与 Gaussian prior 完全等价 | 还需 reduction、坐标、optimizer 与 proper prior | 仅作形式条件对应 |

## 课程补严

- 区分 loss L2 与 decoupled weight decay；
- 核对 mean/sum reduction 造成的 $n$-scaling；
- MAP density mode 本身依参数坐标，非线性变换还需 Jacobian；
- parameter Gaussian prior 是一个合法建模选择，但不因此成为 function-space invariant prior；
- symmetry 可导致 Fisher/Hessian 零方向，inverse curvature 的 uncertainty 解释也需相同审计。
