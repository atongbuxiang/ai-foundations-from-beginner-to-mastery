# 路径积分系列：2.随机游走模型

> [!abstract] 来源定位
> 文章从离散随机游走出发，用生成函数/Fourier思路连接概率分布与扩散型PDE，并强调随机游走是Brownian/扩散的重要离散入口。它适合建立“每步波动—扩散缩放—连续极限”的中文直觉；Brownian process definition、Donsker function-space convergence、连续版本与quadratic variation由正式概率教材和课程补严。

## 课程补严

若 $\xi_k$ 独立、均值0、方差1，则

$$
W_t^{(n)}
=\frac1{\sqrt n}
\sum_{k=1}^{\lfloor nt\rfloor}\xi_k
$$

具有正确的variance scaling。但“趋向Brownian”需要四层证据：

| 层 | 必须说明 |
|---|---|
| 单时刻 | CLT与 $\mathcal N(0,t)$ |
| FDD | 多时刻联合收敛 |
| tightness | path law不逃逸 |
| topology | $C([0,T])$ 或 $D([0,T])$ 中的weak convergence |

## 断言审计

| 断言 | 课程判断 |
|---|---|
| 随机游走提供Brownian/扩散直觉 | 采用 |
| 空间尺度应与时间平方根匹配 | 采用并量纲化 |
| 随机游走可模拟扩散PDE | 作为数值/概率接口，需误差与边界条件 |
| 任意随机游走都等价Brownian | 不采用；需要中心化、方差、缩放与invariance-principle条件 |
| 单时刻Gaussian极限决定过程 | 不成立；还需FDD与tightness |
