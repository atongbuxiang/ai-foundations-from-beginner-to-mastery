# MuP 之上 3：特殊参数组

> [!abstract] 来源定位
> 文章沿用三类稳定性指标，为 embedding、LM head、bias/RMSNorm 等非普通 hidden matrix 参数推导专门的初始化与最速更新方向。课程用它反驳“二维参数都套同一矩阵规则”，并与 Tensor Programs V 和 `microsoft/mup` 实现逐项对照。

## 采用内容

- embedding 的活跃行、LM head 的列与 dense hidden matrix 的输入输出几何不同；
- vocabulary size、model width 和 batch/token support 是不同尺度轴；
- normalization scale 和 bias 是向量参数，不应仅因存储为 tensor 就进入矩阵 optimizer；
- weight tying 使输入与输出角色共享一个参数，必须先决定联合参数化和梯度合成。

## 边界

博客给出的更新方向依赖其 RMS/谱范数和 loss 表达约定。课程不把某个 optimizer 推荐升级为所有词表、数据稀疏度和并行布局下的最优结论。
