# 生成扩散模型漫谈（四）：DDIM = 高观点 DDPM

> [!abstract] 来源定位
> 文章突出“训练只看各时刻 $q(x_t\mid x_0)$ 边缘，因此可换 joint path 与抽取时间子序列”的观点，是 GEN-46 的中文入口。课程把 same marginal、same denoising objective、different joint process 和 finite skip sampler 四件事分开。

## 边界

- DDIM 构造非 Markov forward joint，但保留与 DDPM 相同的 $q(x_t\mid x_0)$；
- $\eta=0$ 给确定性 sampler（给定初始 noise 与 conditioner），不等于无数值误差或 exact data inversion；
- 使用时间子序列减少 network evaluations，是既定模型/solver 的经验折中；
- 论文的 10–50× wall-time 结果属于当时设置，不外推为所有现代实现。
