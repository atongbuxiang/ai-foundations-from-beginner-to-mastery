# Data Provenance Initiative

> [!abstract] 来源定位
> 项目审计大量文本数据集的来源、creator、license 和 attribution lineage，并报告 metadata 遗漏/误分类。课程用它说明聚合数据集的顶层 license 字段不能代表所有 ancestor assets；许可与来源必须沿 derivation graph 传播并保留不确定性。

审计标签仍会随网页、法域解释与数据版本变化；本卡不替代逐项目法律审批。
