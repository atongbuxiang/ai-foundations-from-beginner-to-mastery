# 训练集、验证集和测试集的意义

> [!abstract] 来源定位
> 文章清楚区分训练集拟合、验证集调参与测试集最终评价，适合建立中文直觉。课程在此基础上补充 group/time split、预处理泄漏、验证集属于学习算法、自适应复用的选择偏差与 finite-test uncertainty；不把固定比例或“集合不相交”当成统计独立性的充分条件。

## 元数据与纳入

- 页面：[科学空间原文](https://spaces.ac.cn/archives/4638)；
- 当前调用者：[[训练集、验证集、测试集与自适应复用]]；
- 证据角色：三种数据角色的中文问题入口；
- 不承担：adaptive data analysis 的正式定理、任意数据上的 split 合法性或固定 `8:1:1` 比例规则。

## 核心结构

| 数据角色 | 直接用途 | 一旦被使用后属于什么 |
|---|---|---|
| training set | 拟合参数/表示 | 基础 learner 的输入 |
| validation set | 选超参数、checkpoint、threshold、pipeline | meta-learner 的输入 |
| test set | pipeline 冻结后的最终估计 | 若反馈到开发过程，也会成为算法输入 |

文章强调三者功能不同。课程把这一点写成组合算法：

$$
\widehat h
=A_{\rm meta}(S_{\rm train},S_{\rm val},U),
$$

只有在 $\widehat h$ 不依赖最终测试集 $T$ 且 $T$ 来自目标分布时，$R_T(\widehat h)$ 才是条件无偏的最终风险估计。

## 断言账本

| ID | 断言 | 条件/边界 | 课程判断 |
|---|---|---|---|
| C1 | train/validation/test 应承担不同角色 | pipeline 与 target protocol 明确 | 采用 |
| C2 | 三者文件不相交即可视为独立 | 还需独立 sampling unit、无 group/time/duplicate leakage | 不充分 |
| C3 | validation 只用于调参，不参与训练 | 从最终算法看，它参与 model selection | 术语上补严 |
| C4 | 测试集只应作最终评价 | “最终”指不把结果反馈给 pipeline | 采用并形式化 |
| C5 | 常见划分比例具有普遍最优性 | 依样本量、调参复杂度、shift 与成本而变 | 不采用 |

## 课程补严

1. validation choice、early stopping、prompt/pipeline editing 都属于 learner 的一部分；
2. 数据不重叠不等于随机变量独立，同一患者/用户/模板仍会泄漏；
3. 多次查看 test/leaderboard 并据此修改模型，会让输出依赖 test；
4. 一次 test score 仍有采样误差，应报告区间或成对差异；
5. random split 只适用于与部署抽样合同相符的 exchangeable/i.i.d. 单位；时间预测与分组数据需要相应 split；
6. cross-validation 主要复用训练/验证角色，不能把最终外部测试集一起卷入选择。
