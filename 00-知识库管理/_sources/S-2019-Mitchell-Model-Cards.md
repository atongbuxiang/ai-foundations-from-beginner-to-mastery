# Model Cards

> [!abstract] 来源定位
> 论文提出随模型发布用途、限制、性能切片与伦理考虑等文档。课程把 Model Card 视为证据索引，而非营销摘要或安全认证；每个主张应回链可复现 artifact。

语言模型系统还需 Data Card、System Card、版本合同、在线 SLO 与 incident 记录，单张 Model Card 不足以覆盖系统。
