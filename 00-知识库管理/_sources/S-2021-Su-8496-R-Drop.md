# 苏剑林：R-Drop 的双前向一致性入口

> [!abstract] 来源定位
> 文章以中文拆解同一样本两次 Dropout forward、双 task CE 与双向 KL 的训练结构，并讨论其与一致性/对抗正则的联系。它承担应用直觉和实现入口；SOTA、普适性与机制归因回查原论文并由本库的 factorial audit 限定。

## 边界

- KL 的两个方向、是否除以 2、temperature 与 padding mask 会改变实际目标；
- 两个 forward 必须使用合同所需的独立 masks，同时避免 BatchNorm state 混入；
- improvement 不能单独识别“减少 train/eval inconsistency”这一机制；
- 与 Dropout、Label Smoothing 或 Mixup 联用时必须把 target entropy 与 consistency strength 分账。
