# Size-Independent Sample Complexity of Neural Networks
> [!abstract] 来源定位
> 研究深网 Rademacher complexity 在层 norm 约束下可不显式依赖网络 size 的条件与 depth dependence。本库调用“参数数不是唯一容量尺度”和 norm-product bound 的比较边界；不把 size-independent 理解成无条件 width/depth independent。
## 本库调用
1. norm-constrained Rademacher bounds；
2. parameter count 与 sample complexity 分离；
3. width/depth dependence 的准确措辞；
4. 多种 layer norm 假设的比较。
