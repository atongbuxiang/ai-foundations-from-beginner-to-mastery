# 生成扩散模型漫谈（十六）：W 距离 ≤ 得分匹配

> [!abstract] 来源定位
> 文章研读 Kwon、Fan 与 Lee 关于 score error 控制生成分布 Wasserstein 距离的结果，并尝试从 SDE coupling 解释它。它最重要的课程价值不只是结论，而是作者明确保留证明缺口、展示朴素控制项可能失败：这正是区分“有方向感的推导”与“已证定理”的范例。

## 元数据与纳入

- 原始页面：[https://spaces.ac.cn/archives/9467](https://spaces.ac.cn/archives/9467)；发布日期：2023-02-14；
- 纳入：score MSE 与 $W_2$ 误差的研究问题、同步 coupling/Grönwall 路线、假设敏感性；
- 不纳入：把标题写成无常数、无终端项、无正则条件的普遍不等式；
- 本卷调用：GEN-52 的评价边界、GEN-56 的 theorem/proof-gap 证据地图。

## 课程判定

原论文给的是在适当 regularity、时间权重和过程条件下的上界，通常还包含常数与 terminal mismatch。博客给出部分 SDE 路线，同时指出某个想当然的中间界并不成立。因此正文只引用原论文中的精确 theorem；博客用于解释动机与记录失败尝试。

> [!warning] 禁止的缩写
> 不写“score loss 小，所以 Wasserstein 必然小”。必须同时给出使用哪种 score loss、在哪条 forward/reverse process 上积分、常数依赖什么、端点误差是否为零，以及结论针对 exact sampler 还是 finite-step sampler。
