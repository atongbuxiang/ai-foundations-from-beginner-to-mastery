# “熵”不起：最大熵模型（三）

> [!abstract] 来源定位
> 文章把 maximum conditional entropy 用于监督分类，由 empirical feature expectations 推出 conditional log-linear/softmax model。课程采用“特征约束—条件分布—配分函数”的桥梁，并补齐条件熵的 reference distribution、primal–dual/MLE 等价、不可分数据、正则化和神经网络扩展边界。

## 核心断言与课程判断

| ID | 断言 | 类型 | 条件/边界 | 当前判断 |
|---|---|---|---|---|
| C1 | 固定 empirical $\tilde p(x)$，最大化 $H(Y\mid X)$ 并匹配 feature moments 得 log-linear conditional model | 经典结论 | finite label、可行约束、normalizer 有限 | 已核验 |
| C2 | 每个 feature 对应一个 Lagrange multiplier/weight | 对偶解释 | 冗余 feature 会导致参数不唯一 | 有条件成立 |
| C3 | 最大熵模型与最大似然训练相连 | primal–dual 等价 | 同一 feature family、经验 measure 与 regularity | 已核验并补条件 |
| C4 | 提取足够 feature 后 maximum entropy 是“最佳利用” | 建模主张 | feature misspecification 与部署 shift 仍存在 | 只作条件性表述 |

## 课程采用的 conditional form

$$
p_\theta(y\mid x)
=\frac{\exp\{\theta^\top f(x,y)\}}
{\sum_{y'}\exp\{\theta^\top f(x,y')\}}.
$$

dual gradient 是 model feature expectation 减 empirical feature expectation；这正是 conditional log-likelihood 的一阶条件。binary logistic regression、multiclass softmax 和线性链 CRF 都是这一结构的实例，但深层 representation 使整体参数优化不再是简单 convex maximum-entropy problem。

## 限制与保留意见

- $p(x)$ 是固定 empirical/reference measure，不是同时估计 joint 的无条件声明；
- regularization 相当于 prior、penalty 或 softened constraints，不是原 hard-constraint primal 的字面同一问题；
- feature redundancy、complete separation 和 boundary moments 会影响参数存在/唯一性；
- neural softmax output 具有 conditional exponential form，不代表整个 deep-network training 是 convex MaxEnt；
- conditional entropy 大不等于 classifier 更准，约束决定保留的 predictive information。
