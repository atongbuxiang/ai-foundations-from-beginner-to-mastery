# 长度外推技术复盘：可输入、低 PPL 与可利用分离

> [!abstract] 来源定位
> 文章回顾位置插值、缩放及 ReRoPE 等路线，强调比较不同上下文长度时应固定被评分 target 区间，并警告通过局部化获得好 PPL 可能牺牲远程依赖。

## 评测接口

若比较 4K、8K、16K context，可让它们读取不同长度前缀，却只在相同末端 4K targets 上计 loss；否则 target 集变化会混淆 context value 与样本难度。

## 边界

固定 target loss 仍不证明长程利用；还要在多个 evidence positions、依赖跨度及非局部任务上测干预收益。任何“支持 N 长度”都需拆为输入接受、数值稳定、局部语言建模、检索和推理。
