# ISO 28500:2017：WARC 文件格式

> [!abstract] 来源定位
> WARC 规定如何把抓取响应、请求/控制信息、metadata、digest、duplicate 与 transformation relation 保存为可追溯记录。课程用它区分 raw capture、HTTP payload、extracted text 与训练 document；格式可追溯性不等于内容许可或训练授权。

## 课程调用

WARC record id、target URI、date、payload digest、record type 和 derivation link 应在抽取后保留映射；WET/plain text 不是原网页的无损替代。规范定义容器，不保证 parser、语言标签、版权状态或隐私安全。
