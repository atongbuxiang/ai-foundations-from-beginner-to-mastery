# 随机位置训练与位置鲁棒性

> [!abstract] 来源定位
> 文章从“测试位置训练未覆盖”出发，讨论从大区间随机抽取递增 position IDs，以及连续位置的随机尺度训练；并借非局部形式语言任务提醒语言模型 PPL 可能偏向局部方法。

## 合同

长度为 $N$ 的样本不再总用 $0,\dots,N-1$，而从更大位置域采样保持顺序的 IDs。这样训练覆盖更多绝对/相对间隔，但 token 数仍为 $N$。

## 边界

位置覆盖增加不等于内容依赖跨度增加；采样分布、连续/离散编码、训练目标与测试任务决定效果。博客实验与 CHE 讨论属于 E/H，不是任意架构的外推定理。
