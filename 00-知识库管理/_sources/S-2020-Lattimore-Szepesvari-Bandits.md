# Bandit Algorithms
> [!abstract] 来源定位
> stochastic/adversarial/contextual bandit、regret、concentration、lower bound 与 algorithm design 的权威专著。本库用其统一不同 bandit regimes，不混用 gap-dependent 与 adversarial guarantees。
## 本库调用
1. stochastic pseudo-regret；
2. UCB 与 confidence；
3. adversarial estimator；
4. contextual policy comparison；
5. best-arm identification boundary。
