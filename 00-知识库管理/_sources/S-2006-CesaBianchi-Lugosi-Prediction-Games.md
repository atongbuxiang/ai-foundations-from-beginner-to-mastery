# Prediction, Learning, and Games
> [!abstract] 来源定位
> 在线预测、专家建议、随机化、regret 与 adversarial protocols 的标准专著。本库调用精确时序和 potential proofs；不同 feedback/adversary setting 不混用。
## 本库调用
1. learner–environment sequential contract；
2. external regret 与 hindsight comparator；
3. exponential weights/Hedge；
4. expected/high-probability randomization；
5. stochastic、oblivious 与 adaptive regimes 分层。
