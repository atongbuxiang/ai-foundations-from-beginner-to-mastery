# Aleatoric and Epistemic Uncertainty in Machine Learning

> [!abstract] 来源定位
> 系统梳理数据随机性、知识不足、模型空间与预测不确定性的概念。本库用它建立对象层 taxonomy；同时保留关键边界：分解依赖模型、信息状态与表达语言，并非观测数据中天然带标签的两个真值字段。

## 本库调用

1. aleatoric uncertainty 与 irreducible randomness 的条件化含义；
2. epistemic uncertainty 与可通过信息增加而缩减的知识不足；
3. model、parameter、distributional 与 approximation uncertainty 的层级；
4. classification 与 regression 中不同度量不可随意互换；
5. 任何不确定性数值都必须声明预测对象和知识状态。
