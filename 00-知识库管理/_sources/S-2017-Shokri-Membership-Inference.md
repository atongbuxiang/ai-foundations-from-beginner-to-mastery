# Membership Inference 基础

> [!abstract] 来源定位
> 论文形式化攻击者判断某条记录是否参与训练的问题，并用 shadow models 等机制构造攻击。课程把成员事件、攻击者先验、可见输出、邻接关系和评估分布全部写进合同。

平均攻击准确率可能被类别先验掩盖；敏感场景还需看低假阳率区域、置信区间与对照攻击。
