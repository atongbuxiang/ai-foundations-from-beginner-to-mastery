# Reinforcement Learning: An Introduction
> [!abstract] 来源定位
> multi-armed bandit、MDP、return、value、temporal-difference 与 policy learning 的标准教材。本库本节点只调用 bandit-to-RL object boundary；完整 RL 理论留给强化学习卷。
## 本库调用
1. bandit exploration；
2. state/action/reward/transition；
3. discounted return；
4. credit assignment；
5. horizon-1 bandit 与 stateful MDP 分界。
