# Telgarsky 2016：Benefits of Depth
> [!abstract] 来源定位
> 以 oscillatory constructions 和 semi-algebraic gates 证明特定深网—浅网指数 size separation 的原始论文。本库保留目标族、depth、size、gate class 与 approximation error 的完整量词，不把存在性 separation 泛化为所有任务或可训练性结论。
