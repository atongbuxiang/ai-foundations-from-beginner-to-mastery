# ML Test Score

> [!abstract] 来源定位
> 论文以数据、模型、基础设施和监控测试组织生产就绪度。课程将其作为测试清单来源，并为语言模型补上 tokenizer/template、retrieval/tool trace、judge 漂移和安全切片。

分数是改进路线图，不是跨组织可直接比较的成熟度认证。
