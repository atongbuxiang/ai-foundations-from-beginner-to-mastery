# 重温SSM（三）：HiPPO的高效计算（S4）

> [!abstract] 来源定位
> 文章围绕 S4 中 HiPPO 矩阵的“对角矩阵＋低秩矩阵”结构，解释如何将长卷积核计算约化为 Cauchy 型结构化计算。课程采用它讲清代数路线，不把博客中的简化叙述替代 S4 论文的完整算法与实验条件。

## 课程采用的路线

1. 由连续 SSM 离散化并写出长度 $L$ 的 impulse response；
2. 用 generating function / resolvent 统一看核系数；
3. 通过 NPLR/DPLR 结构和 Woodbury 类恒等式减少一般稠密计算；
4. 分离数学运算数、数值条件与 GPU 实际吞吐。
