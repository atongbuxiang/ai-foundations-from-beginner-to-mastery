# 科学空间：动态 Expert 数与预算反馈

> [!abstract] 来源定位
> 文章质疑“每个 token 恰好激活同样数量 Expert”，用 threshold routing 和 bias 自由度同时追求平均预算与 Expert 均衡。

## Claim audit

- “难 token 应获更多计算”是设计假说，难度定义与因果收益仍需受控实验；
- 动态激活把固定 token cost 改为分布，必须报告均值、尾部、设备负载和 latency；
- Top-p、空 Expert、预测 k 等替代路线的比较限定作者搜集的协议与观点。
