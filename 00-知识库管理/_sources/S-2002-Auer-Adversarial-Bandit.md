# The Nonstochastic Multiarmed Bandit Problem
> [!abstract] 来源定位
> adversarial multi-armed bandit 与 EXP3 的经典原始来源。本库调用 exploration、importance-weighted loss estimate 与 best-fixed-arm regret；adversary 可见性必须沿原 theorem 声明。
## 本库调用
1. nonstochastic bandit protocol；
2. EXP3；
3. partial-information regret；
4. exploration–estimation tradeoff；
5. lower-bound/setting boundary。
