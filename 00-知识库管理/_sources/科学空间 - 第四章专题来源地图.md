# 科学空间 - 第四章专题来源地图

> [!abstract] 使用结论
> 科学空间在 Attention、Transformer、位置编码、长度外推、线性 Attention、SSM 与 MoE 上有高密度的中文推导和新问题追踪，适合作为第四章的“理解主线”。它不是唯一证据源：架构定义、历史优先权、理论保证、规模化效果和系统最优性仍由原论文、教材、官方实现与复现实验共同承担。

## 一、断言分级

| 标记 | 含义 | 写入正文时的措辞 |
|---|---|---|
| `I` | exact identity / 可独立复算的代数恒等式 | “可由……直接推出”，附推导 |
| `T` | theorem / 有明确假设的理论结果 | 写全假设、量词和结论，回查原论文 |
| `E` | empirical / 特定模型、数据与协议的实验 | “在该设置下观察到”，保留配置 |
| `H` | hypothesis / 解释、猜测或设计直觉 | “一种解释是”“尚待更大规模验证” |
| `O` | open / 作者明确保留的开放问题 | 不收敛成单一结论 |

- 2025—2026 新文章视为会继续演化的当代来源，正文写明访问日期与版本边界。

## 十、执行顺序

1. 先为每卷建立原论文骨架，再调用本地图中的博客解释；
2. 每篇 source card 只保存主问题、关键公式、claim table、课程补严和调用节点；
3. 每节点至少包含一个“科学空间怎样帮助理解 / 哪里不能直接采信”的框；
4. 分卷收官时检查来源是否偏科：CNN/GNN 不得因科学空间覆盖少而缩水；
5. 第四章静态收官后再执行前三章的五个高价值回填，不做无边界扩张。
