# 科学空间 - 第七章语言模型专题来源地图

> [!abstract] 使用结论
> 科学空间对第七章最有价值的覆盖集中在中文分词与 tokenizer、语言模型目标、解码、暴露偏差、LoRA、上下文学习和检索增强。课程把这些文章用作“问题从哪里来、公式怎样直观重建、哪些前沿假说值得验证”的入口；历史优先权、一般定理、模型/数据性能、软件语义和安全结论分别回到原论文、教材、官方实现与独立复现。

## 一、来源等级与逐篇合同

| 等级 | 典型来源 | 在正文中的职责 |
|---|---|---|
| P0 | Unicode 标准、RFC、框架/模型官方规格、数据卡 | 定义字符、序列化、API、版本和可执行合同 |
| P1 | 原始论文、作者技术报告、公开实验记录 | 原创算法、定理、实验与局限 |
| P2 | 教材、综述、课程讲义 | 统一记号、背景、证明与跨工作比较 |
| P3 | 科学空间等高质量技术博客 | 中文推导桥梁、问题地图、实现洞见与待验证假说 |
| P4 | 二手教程、产品页面、社区帖子 | 仅作线索或现象样本，不单独支撑核心结论 |

每篇博客进入正式节点前必须回答：

1. 文章的对象是文本、分段、概率目标、生成算法、参数更新还是系统行为？
2. 核心式是恒等式 `I`、条件定理 `T`、近似 `A`、实验 `E`、解释假说 `H` 还是开放问题 `O`？
3. 使用了哪些独立性、平稳性、有限词表、teacher forcing、top-k 候选或模型规模假设？
4. 原论文、教材、官方实现分别补足哪个证据层？
5. 能否以小词表、有限序列或标准库实验复算；反例和失效边界是什么？

## 四、预训练数据（LM-17—24）

科学空间对许可、数据治理、MinHash/LSH、benchmark contamination 和大型数据 provenance 的系统覆盖较弱。本卷不为了博客比例而削减核心内容，主线以数据集论文、数据卡、许可文本和官方管线为 P0/P1：

| 主线 | 一级来源队列 | 最小复现 |
|---|---|---|
| 文档解析与质量过滤 | Common Crawl/WARC 规范、C4、Gopher、RefinedWeb 数据报告 | 固定网页集合记录每个过滤器的增删与群体切片 |
| 去重 | Broder MinHash/LSH、公开大模型数据去重报告 | 小 shingle 集枚举 Jaccard，与 MinHash/LSH recall 比较 |
| 污染 | benchmark contamination / decontamination 原始协议 | exact、n-gram、semantic 三种 overlap 的假阳/假阴样例 |
| 数据混合 | multilingual/domain sampling 原论文与公开配方 | 文档概率、token 概率、batch quota 三种口径互译 |
| Packing | 框架 data collator 与模型 attention/loss 实现 | 断言跨文档 attention、position id 和 loss mask |

科学空间文章如果用于解释“有效 token”或数据尺度，只能作为补充假说，并与第六章 Scaling Law 的数据质量账交叉链接。
