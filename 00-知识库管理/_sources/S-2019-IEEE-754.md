# IEEE 754-2019

> [!abstract] 来源定位
> 这是浮点格式、运算、异常条件与默认处理的规范来源。知识节点中的“IEEE 要求什么”只以该标准公开入口和官方实现文档为依据；Goldberg/Higham 承担教学解释与误差分析。

## 公开元数据

- 名称：`IEEE Standard for Floating-Point Arithmetic`。
- 状态：Active Standard。
- 发布：2019-07-22。
- 替代：IEEE 754-2008。
- 范围：二进制与十进制浮点的 interchange/arithmetic formats、运算方法、异常与默认处理。

## 在本库中的职责

| 规范对象 | 本章用途 |
|---|---|
| 格式 | binary16/32/64 字段与特殊编码的标准背景 |
| 舍入 | round-to-nearest ties-to-even 与有向舍入 |
| 运算 | 基本操作与 FMA 的结果语义 |
| 特殊值 | signed zero、Infinity、NaN |
| 异常 | overflow、underflow、inexact、invalid 等语义边界 |

## 使用纪律

- “符合 IEEE 754”不代表不同括号或不同算法逐比特相同；
- 标准规定操作语义，不替应用选择稳定公式；
- BF16、TF32、FP8 等实现格式/模式不可不加说明地混入 IEEE 基本格式表；
- 当前设备是否 flush-to-zero、是否启用 FMA contraction，需回到厂商文档。
