# VQ-VAE 的简明介绍：量子化自编码器

> [!abstract] 来源定位
> 文章用 encoder—nearest code—decoder 主线解释 VQ-VAE，逐项拆开 STE、codebook loss、commitment loss 与第二阶段 prior。课程采用其中文推导，但把“VQ-VAE 名称中的 VAE”与标准连续潜变量 ELBO 明确分开。

## 核心断言与核验

| 断言 | 类型 | 课程判断 |
|---|---|---|
| $z_q=z+\operatorname{sg}(q-z)$ 前向等于 $q$、反向对 $z$ 为恒等映射 | 实现恒等式 | 已核验 |
| $\|\operatorname{sg}z-q\|^2$ 更新 codebook，$\|z-\operatorname{sg}q\|^2$ 约束 encoder | 优化合同 | 已核验；权重与 EMA 版本须记录 |
| 仅靠 autoencoder 不产生新样本，生成还需学习离散 code prior | 模型分解 | 已核验 |
| 博客个人实验生成效果不佳 | 单次实验观察 | 不外推为方法结论 |

## 课程补严

- hard nearest-neighbor 的真实导数几乎处处为零/边界不可导；STE 是代理梯度，不是链式法则算出的导数。
- codebook index、embedding vector 和 prior token 是三个对象；不能把整数 ID 当作有序数值。
- 两阶段系统必须分别报告 tokenizer distortion 与 prior modeling error。
