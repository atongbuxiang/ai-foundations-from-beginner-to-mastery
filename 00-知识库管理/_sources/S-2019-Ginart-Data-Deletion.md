# 机器学习中的 Data Deletion

> [!abstract] 来源定位
> 论文从模型维护与删除请求出发研究高效数据删除。课程用它区分删除原始样本、更新索引、重新训练、近似 unlearning 与可验证删除；数据库删除成功不推出模型影响消失。

算法保证依模型族与状态保存方式，不能直接外推现代大语言模型。
