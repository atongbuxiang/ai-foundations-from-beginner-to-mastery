# Online Learning via Sequential Complexities
> [!abstract] 来源定位
> 用 sequential Rademacher complexity/trees 描述 adaptive online games。本库调用其历史依赖与量词边界；基础节点只建立入口，不伪装完成全部 minimax theory。
## 本库调用
1. adversary tree 而非 iid sample；
2. history-dependent choices；
3. minimax value；
4. sequential complexity；
5. adaptive vs oblivious distinction。
