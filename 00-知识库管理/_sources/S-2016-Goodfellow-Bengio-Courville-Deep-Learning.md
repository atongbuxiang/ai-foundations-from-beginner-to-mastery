# Goodfellow–Bengio–Courville：Deep Learning
> [!abstract] 来源定位
> 神经网络基础、正则化、优化、卷积、序列模型与深度学习研究方法的正式教材骨架。本库重点调用第 6 章 deep feedforward networks、第 7 章 regularization 与第 8 章 optimization；具体历史优先回原论文，2016 年后的模块另以新论文补齐。
## 本库调用
1. feedforward network 作为函数复合；
2. affine layer、hidden unit、output unit 与 loss 的分层；
3. XOR、representation learning 与 architecture design；
4. backprop/computational graph 主线；
5. regularization 与 optimization 的经典边界。
