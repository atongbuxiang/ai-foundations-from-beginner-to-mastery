# 科学空间 - 第六章训练与优化专题来源地图

> [!abstract] 使用结论
> 科学空间在第六章最强的覆盖不是分布式系统或经典收敛理论，而是优化动力学、学习率—Batch Size、Adam/Muon 的尺度、μP 与矩阵最速下降。课程以这些文章提出问题、翻译记号和训练前沿判断；标准优化教材、原论文、框架源码与独立数值实验分别承担一般定理、原创断言、实现合同和复现证据。

## 一、纳入与证据合同

每篇博客进入正文前必须完成五项分账：

1. **对象**：文章讨论的是 loss、gradient estimator、optimizer state、parameter norm、feature update 还是 system throughput；
2. **地位**：公式是恒等式 `I`、条件定理 `T`、近似 `A`、实验 `E`、解释假说 `H` 还是开放问题 `O`；
3. **假设**：尤其记录 quadratic/Taylor、stationary gradient、mean-field、Gaussian/isotropic、infinite width、small step、full rank 与独立性；
4. **补严**：原论文/教材补什么，标准库 toy experiment 能否复算，规模性能是否需要公开训练记录；
5. **边界**：不把单个模型、单一训练长度或作者的机制解释升级为跨架构定理。

## 十一、逐节点调用合同

每个正式节点至少设置一个“科学空间研读框”，但只有确有对应文章时才强制直接引用。研读框必须包含：

1. 文章从哪个训练现象切入；
2. 博客记号与课程张量/shape/step convention 的映射；
3. 可独立复算的恒等式或 toy simulation；
4. mean-field、各向同性、stationarity、small-step 等假设；
5. 原论文/教材/框架源码分别补哪一层；
6. 文章中的保留意见、失败实验与开放问题。

不得为了“多和科学空间结合”而机械引用。分布式训练等站内薄弱内容必须由站外一级来源补齐。
