# 生成扩散模型漫谈（十四）：构建 ODE 的一般步骤（上）

> [!abstract] 来源定位
> 文章把 $d$ 维密度演化视作 $d+1$ 维时空中的无散场，并借 Green function 构造运输速度。它清楚暴露了一个关键事实：给定 $p_t$ 后，满足连续性方程的速度通常不唯一。

## 元数据与纳入

- 原始页面：[https://spaces.ac.cn/archives/9370](https://spaces.ac.cn/archives/9370)；发布日期：2022-12-15；
- 纳入：$\partial_tp+\nabla\cdot(pv)=0$、时空守恒场、Green-function 构造、PFGM/Gaussian diffusion 作为实例；
- 不纳入：把形式积分自动升级为全空间可积、无边界项、唯一且全局适定的向量场；
- 本卷调用：GEN-53 的“路径—速度—密度”三层对象，GEN-54 的速度非唯一性。

## 课程补严

若 $v$ 运输 $p_t$，且另一个场 $w$ 满足

$$\nabla\cdot(p_tw)=0,$$

则 $v+w$ 也运输同一个 $p_t$。因此“指定概率路径”只约束密度通量的散度；coupling、conditional path 或额外最优性原则才进一步选择速度。

使用 Green function 还须声明：定义域、边界条件、源项总质量、奇点处理、可积性与解的函数空间。正文将博客的构造视作推导桥，不当作无需假设的存在唯一性定理。
