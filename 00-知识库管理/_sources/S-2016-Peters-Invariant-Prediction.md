# Causal Inference by Using Invariant Prediction

> [!abstract] 来源定位
> 在结构方程与环境干预假设下，用条件分布跨环境不变性识别因果父集并给置信集合。本库调用其“invariance 需要环境与干预语义”原则；不把一般 domain-invariant features 直接称为 causal。

## 本库调用

1. environments 与 intervention target 假设；
2. causal mechanism 的条件不变性；
3. accepted invariant sets 的交集与 error control；
4. faithfulness/coverage/linear-model 等条件边界；
5. prediction robustness 与 causal identification 是不同结论。
