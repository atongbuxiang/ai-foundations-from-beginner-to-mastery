# 初探 MuP

> [!abstract] 来源定位
> 文章以更直接的量级计算重排 μP 的 forward、backward、loss increment 与 feature-update 条件，并讨论初始化和学习率怎样随宽度迁移。它承担中文推导入口；原创 maximal-update 定义与迁移证据回查 Tensor Programs IV/V。

## 采用与补严

- 每个量级结论都绑定矩阵方向、fan-in/fan-out、坐标相关性、loss reduction 与 optimizer；
- standard、NTK、mean-field 与 μP 不能只比较“初始化方差”，还要比较 forward multiplier、学习率和训练时标；
- bias、normalization、residual、embedding/readout 和 attention 不机械套 hidden matrix 规则；
- 博文自述未完整覆盖的特殊参数组与深度问题由 TRN-46—48 单独处理。

## 不越界结论

文章中的 $O(1)$ 或 $\Theta(1)$ 量级推导不是有限宽误差界；“超参数迁移”也必须通过多宽度曲线、随机种子和目标规模确认，不能由代数表直接宣告成功。
