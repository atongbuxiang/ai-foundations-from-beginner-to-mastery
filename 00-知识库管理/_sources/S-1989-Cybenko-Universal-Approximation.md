# Cybenko 1989：Sigmoidal Universal Approximation
> [!abstract] 来源定位
> 单隐藏层 continuous sigmoidal ridge functions 在 $C([0,1]^d)$ 的 uniform norm 下稠密的经典原始论文。本库调用其精确量词、compact/uniform 合同与 Hahn–Banach—Riesz—measure 证明骨架，不把它外推为 ReLU 训练或高维效率保证。
