# 科学空间 - 第五章生成模型专题来源地图

> [!abstract] 使用结论
> 科学空间的生成模型文章不是零散补充，而是第五章重要的中文理解主线：VAE 系列负责 latent-variable intuition，能量视角系列连接 GAN—EBM—Langevin，细水长 flow 系列连接 Jacobian—可逆性—exact likelihood，31 篇“生成扩散模型漫谈”从 DDPM 一直追到 MeanFlow/JiT。课程将这些文章嵌入每卷，但所有方法定义、定理、历史优先权和性能主张仍回查原论文、教材、官方实现与复现实验。

## 一、检索范围与版本边界

- 站点：科学空间 / Scientific Spaces，作者苏剑林；
- 主题边界：只纳入与生成建模、密度估计、隐变量、能量/score、采样、流、扩散、离散编码、控制和评价直接相关的文章；
- 访问与复核日期：**2026-08-25**；
- 扩散系列：站内归档和页面检索到“生成扩散模型漫谈（三十一）”，尚未把未出现的（三十二）以后当作既成来源；
- 最新补充：2025 年 TARFLOW、DDCM、MeanFlow、JiT，2025 年 DiVeQ，2026 年 FD Loss；
- 版权：不镜像网页正文或批量下载原图，只保存独立摘要、必要短公式、地址、claim audit 和课程调用记录。

## 二、断言分级与来源职责

| 标记 | 含义 | 写入正文时的处理 |
|---|---|---|
| `I` | exact identity / 可独立复算的恒等式 | 在课程记号下完整重推，做特例与 shape 检查 |
| `T` | theorem / 有明确假设的定理 | 回查原论文或正式教材，写全假设、量词和结论 |
| `E` | empirical / 指定模型、数据和协议的实验 | 保留配置、预算、指标、方差和版本，不外推 |
| `H` | hypothesis / 解释、类比或机制猜测 | 使用“一个解释是”，并给出竞争解释和验证方案 |
| `O` | open / 开放问题 | 保留不确定性，不为了笔记完整而强行下结论 |

科学空间主要承担 `I` 的中文推导入口、`E/H/O` 的研究问题入口和不同模型间的概念桥。A 级原论文承担方法定义与直接证据；正式教材承担概率、变分、最优传输、SDE/PDE 和数值分析的证明义务。
