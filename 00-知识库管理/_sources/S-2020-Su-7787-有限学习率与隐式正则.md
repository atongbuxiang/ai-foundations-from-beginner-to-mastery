# 从动力学角度看优化算法（五）：为什么学习率不宜过小？

> [!abstract] 来源定位
> 文章讨论 finite learning rate 相对 infinitesimal gradient flow 可能产生的隐式梯度正则与泛化效应。课程采用“离散步长会改变动力学和隐式偏置”这一问题入口；稳定区、收敛率、近似阶数以及“泛化改善”能否外推，必须由正式优化教材、原始论文和受控实验补严。

## 问题结构摘要

1. 区分“太大导致不稳定”与“太小导致计算慢/离散效应消失”；
2. 把 finite-step gradient update 与 continuous gradient flow 对照；
3. 引入有限步长可能对应额外 gradient penalty 的分析；
4. 讨论这种隐式项与模型泛化的潜在联系；
5. 强调存在适中学习率区间，而非只追求无限小步长。

|---|---|---|---|---|

## 课程补严

对 $L$-smooth deterministic objective，gradient descent

$$
x_{k+1}=x_k-\eta\nabla f(x_k)
$$

满足

$$
f(x_{k+1})
\le f(x_k)-\eta\left(1-\frac{L\eta}{2}\right)
\|\nabla f(x_k)\|^2.
$$

因此 $0<\eta<2/L$ 是相应全局/区域 smoothness 假设下的下降区间。这个结论只关于当前 objective，不说明 validation/generalization。

gradient flow

$$
\dot x=-\nabla f(x)
$$

与 finite-step Euler update 的差异包括 stability region、离散误差、eigenmode oscillation、batch-noise interaction 与 finite-precision floor。所谓 implicit regularization 必须说明比较的连续/离散系统、近似阶数与保留时间尺度。

## 限制与保留意见

- “适中”不是常数，随 loss reduction、batch、width、normalization、optimizer 和 scheduler 改变；
- global $L$ 常未知，local Hessian estimate 也不自动给整条 trajectory 的安全阈值；
- implicit penalty 的近似等价不等于两个训练程序在有限时间严格相同；
- generalization improvement 不能由 training-objective descent theorem 推出；
- 大学习率若触发 clipping、overflow、NaN 或 batch-statistics 改变，已不是原始 exact-gradient model；
- 单 seed accuracy improvement 不足以区分 optimization、regularization 与 selection effect。

## 最小验证协议

1. 在已知 spectrum 的 quadratic 上验证 $\eta L$ stability map；
2. 固定 model/data order/seed/batch/precision，扫描 normalized learning rate；
3. 同时报 train objective、full-gradient probe、update norm、clipping rate 与 curvature estimate；
4. 独立报告 validation loss、calibration、shift 与多 seed uncertainty；
5. 用 gradient-flow/high-accuracy small-step baseline 区分 discretization effect；
6. 改变 batch 和 parameterization，检查所谓 implicit regularization 是否保持。
