# S-2008 Absil–Mahony–Sepulchre - Matrix Manifolds

## 核心贡献

- 系统区分 embedded manifold、tangent space、Riemannian metric、gradient、retraction 与 vector transport；
- 提供 Stiefel/Grassmann 等矩阵流形的标准优化框架；
- 说明一阶 tangent step 与保持可行的 retraction 是不同操作。

## 采用边界

承担成熟流形术语与算法条件；科学空间的谱范数最速方向和 2026 解析式作为额外 norm choice/前沿推导，不能反向改写标准 Riemannian 定义。
