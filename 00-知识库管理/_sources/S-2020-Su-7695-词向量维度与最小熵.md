# 最小熵原理（六）：词向量的维度应该怎么选择？

> [!abstract] 来源定位
> 文章尝试从 Skip-Gram joint model 的 entropy 和向量内积的集中尺度，估计 vocabulary size $N$ 所需 embedding dimension 的数量级，并给出约 $n>8.33\log N$ 的经验公式。课程采用它作为“representation capacity 应如何付费”的研究问题入口，不把该经验估计当作 rate–distortion、MDL、JL lemma 或泛化理论的严格结论。

## 课程补严

dimension $d$、Shannon rate $I(X;Z)$、parameter codelength 与 effective rank 是四个不同对象：

- $d$ 只给 ambient coordinate count；
- $I(X;Z)$ 依 joint distribution、noise 与 precision；
- MDL 要编码 model/parameters/data，并指定 code；
- effective rank 描述 spectrum concentration，不等于可传 bits。

因此验证一个 dimension rule 至少要画：

$$
d\longmapsto
\{L_{model},L_{data\mid model},\text{held-out risk},\text{calibration},\text{shift risk}\}.
$$

若没有实际 coding protocol 和 distortion/task target，就不能称为计算了 $R(D)$ 或 MDL optimum。
