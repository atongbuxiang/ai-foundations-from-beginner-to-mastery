# 插值、双下降与经典偏差方差边界

> [!abstract] 本章主问题
> 模型容量越过“刚好能拟合训练集”的 interpolation threshold 后，测试风险为何有时再次下降？双下降不是推翻 bias–variance，而是提醒我们：风险曲线属于“数据分布 + 算法 + 参数化 + 正则化 + 容量路径”的联合对象，参数数目本身不是完整复杂度。

## 一、学习目标

完成本章后，应能：

1. 定义 interpolation 与 interpolation threshold；
2. 区分经典 U 型曲线和 model-wise double descent；
3. 区分 model-wise、sample-wise 与 epoch-wise 现象；
4. 在 Gaussian 线性模型中推导阈值两侧风险项；
5. 解释 $p\approx n$ 时 inverse Gram matrix 为什么不稳定；
6. 说明 min-norm rule 是过参数化曲线的一部分；
7. 解释 ridge、early stopping 与 noise 如何改变峰；
8. 区分 parameter count 与 effective complexity；
9. 识别双下降实验中的选择/缩放混杂；
10. 把现象证据与机制 theorem 分开。

## 二、什么叫插值

给样本 $(x_i,y_i)_{i=1}^n$ 和 loss $\ell$。若训练算法输出 $\widehat f$ 满足

$$
\widehat R_n(\widehat f)=\frac1n\sum_{i=1}^n\ell(\widehat f(x_i),y_i)=0,
$$

称它插值训练数据。平方损失中等价于 $\widehat f(x_i)=y_i$；分类 0–1 error 为零不等于 cross-entropy 为零，因为后者通常只在 logits 发散时趋零。

## 三、Interpolation Threshold

沿某条模型族/训练流程增加容量 $c$，第一次能把训练 loss 压到零的区域称 interpolation threshold。在线性回归的朴素坐标中常在参数数 $p\approx n$，但深网中 threshold 还受：

- architecture 与参数共享；
- optimizer 能否找到插值解；
- label noise 与 augmentation；
- training time；
- explicit regularization；
- effective rank 与 feature geometry。

所以“参数数 = 样本数”只是特定线性模型的示意，不是通用定义。

## 四、经典 U 型曲线没有错在哪里

经典偏差—方差讨论通常固定 estimator family 和 regularization path，随着复杂度增大：approximation bias 下降，estimation variance 上升，于是测试风险先降后升。

双下降把路径继续延伸到插值区之后：刚能插值时 estimator 对噪声极敏感，风险出现峰；更强过参数化后，特定 algorithm 可能在大量插值解中选择 norm 更小/更平滑的解，风险再次下降。

它不是说 bias–variance identity 失效；identity 仍成立，变化的是 bias 与 variance 对容量的函数形状。

## 五、可精确计算的 Gaussian 线性模型

令

$$
x\sim\mathcal N(0,I_p),\qquad y=x^\top\beta^*+\varepsilon,\qquad E\varepsilon=0,\quad \operatorname{Var}(\varepsilon)=\sigma^2.
$$

训练矩阵 $X\in\mathbb R^{n\times p}$。测试 excess prediction risk 在此 isotropic 约定下是

$$
E_x[(x^\top(\widehat\beta-\beta^*))^2]
=E\|\widehat\beta-\beta^*\|^2.
$$

以下公式还对 $X$ 与训练噪声取期望。

## 六、阈值左侧：$p<n-1$ 的 OLS

当 $X$ full column rank，

$$
\widehat\beta=(X^\top X)^{-1}X^\top y
=\beta^*+(X^\top X)^{-1}X^\top\varepsilon.
$$

它条件无偏。Wishart inverse 的期望给

$$
\boxed{
E\|\widehat\beta-\beta^*\|^2
=\sigma^2\frac{p}{n-p-1}.
}
$$

当 $p\uparrow n-1$，分母趋零，variance 爆炸。

## 七、阈值右侧：$p>n+1$ 的 Min-Norm Interpolator

当 $p>n$ 且 $X$ full row rank，最小欧氏范数插值解为

$$
\widehat\beta=X^\top(XX^\top)^{-1}y=X^\dagger y.
$$

令 $P_X=X^\top(XX^\top)^{-1}X$ 为 row-space projector：

$$
\widehat\beta-\beta^*
=-(I-P_X)\beta^*+X^\top(XX^\top)^{-1}\varepsilon.
$$

前项是未被数据 row space 观察到的 signal bias，后项是插值 noise 的 variance。

在 isotropic Gaussian 下：

$$
\boxed{
E\|\widehat\beta-\beta^*\|^2
=\left(1-\frac np\right)\|\beta^*\|^2
+\sigma^2\frac{n}{p-n-1}.
}
$$

这条公式把“第二次下降”拆成可检查的两项。

## 八、为什么阈值附近会峰值

两侧都出现 inverse Gram matrix：

$$
(X^\top X)^{-1}\quad\text{或}\quad(XX^\top)^{-1}.
$$

当最小非零奇异值 $\sigma_{\min}(X)$ 很小时，noise coefficient 含 $1/\sigma_{min}(X)$，刚好插值时最不稳定。进一步增加 $p$ 可让 row vectors 在高维更接近正交，使 $XX^\top$ 条件性改善，noise variance 项下降。

## 九、第二次下降不是必然趋零

在上式中若 $p/n\to c>1$，noise 项约为 $\sigma^2/(c-1)$，不自动趋零；signal bias 也依赖 $\beta^*$ 如何随维数扩展。若 $p\gg n$，noise 项可小，但 isotropic null-space bias 接近 $\|\beta^*\|^2$。

因此“更多参数总会更好”是错的。需要 covariance spectrum、signal alignment 和 algorithmic selection 共同决定。

## 十、三类 Double Descent

| 类型 | 横轴 | 需要固定什么 |
|---|---|---|
| model-wise | width/depth/features/parameters | data、train budget、regularization |
| sample-wise | sample size | architecture、optimizer、epoch rule |
| epoch-wise | training time | model、data order、schedule |

当增加样本反而把系统推近 interpolation threshold，sample-wise 曲线可局部变坏；这不等于“数据有害”，而是路径上其他对象未同步。

## 十一、Regularization 如何改变曲线

ridge estimator

$$
\widehat\beta_\lambda=(X^\top X+\lambda I)^{-1}X^\top y
$$

把 $1/s_j$ spectral filter 改为 $s_j/(s_j^2+\lambda)$，截断小奇异值放大，因此可平滑/消除 interpolation peak。early stopping、data augmentation、label smoothing 也改变 effective estimator，不能把有无这些机制的曲线混在一起。

## 十二、实验设计最小合同

画双下降图至少要报告：

1. 横轴到底是参数、width、effective rank 还是 FLOPs；
2. 每点是否真正训练到相同 stopping criterion；
3. train 0–1 error 与 train loss 是否都为零；
4. label noise 和 data augmentation；
5. optimizer、schedule、weight decay；
6. 多 seeds 与 uncertainty；
7. test set 是否因多点搜索被重复适配；
8. 峰是否与最小奇异值/conditioning 同步。

## 十四、AI 接口

- LLM scaling：参数/数据/compute 同时变化，不是纯 model-wise path；
- fine-tuning：checkpoint、epoch 与 adapter rank 可产生不同 interpolation paths；
- noisy preference data：阈值附近可能放大 annotator noise；
- retrieval/linear probe：feature effective rank 比 raw parameter count 更接近线性公式；
- model selection：大量宽度/epoch 搜索会适配 validation/test。

## 十五、常见错误

1. 把 interpolation 定义成 0–1 error 为零却忽略训练 loss；
2. 只用参数数定位所有 threshold；
3. 说双下降推翻 bias–variance identity；
4. 不声明 min-norm/optimizer 选了哪个插值解；
5. 把 $p\gg n$ 自动等同 risk→0；
6. 混合 regularized 与 unregularized curves；
7. 只画一 seed；
8. 从曲线相关性宣称机制因果。

## 十六、最小记忆与掌握标准

> [!summary]
> - interpolation 是训练目标精确拟合；
> - threshold 是沿指定容量/训练路径第一次可插值的区域；
> - 峰常来自小奇异值导致的 noise amplification；
> - 过参数化侧风险由 signal bias + noise variance 共同决定；
> - min-norm、regularization、optimizer 和数据谱都是曲线对象；
> - 双下降是 regime-dependent phenomenon，不是普遍单调律。

能定义现象（A）、手算线性风险（B）、推导 projector 分解（C）、审计曲线混杂（D），并为现代 AI scaling 实验建立可比较路径（E）。
