# 深度泛化证据地图与开放问题

> [!abstract] 本章主问题
> 深网泛化没有一条已经完结的单因素定律。严谨的答案应是一张带量词和适用域的证据地图：现象告诉我们要解释什么，优化理论告诉我们算法选了什么，容量/稳定性/PAC-Bayes 给出风险控制，数据与表示机制说明为何条件可能满足，部署评估再检验分布变化后的有效性。

## 一、学习目标

完成本章后，应能：

1. 区分 phenomenon、mechanism、theorem、certificate 与 hypothesis；
2. 把 LT-77—83 放进同一因果/证明链；
3. 解释随机标签实验支持什么、不支持什么；
4. 正确陈述 uniform-convergence limitation 的范围；
5. 评价泛化指标的正确性、非空性、趋势、不变性与干预价值；
6. 为一个深网理论 claim 写全对象合同；
7. 识别 in-distribution risk 与 OOD/deployment risk 的断点；
8. 区分 correlation benchmark 与 causal intervention；
9. 提出可证伪而非只可叙述的研究假设；
10. 构建从理论到实验再回到理论的研究流程。

## 二、五级证据词典

| 等级 | 问题 | 合格产物 |
|---|---|---|
| 现象 | 发生了什么？ | 可复现曲线、受控数据与 protocol |
| 选解机制 | 算法为什么到这个解？ | dynamics theorem/干预证据 |
| 风险保证 | 这个解为何对未知样本有效？ | 带概率量词的 generalization bound |
| 数值证书 | 界在这个模型上有多大？ | nonvacuous、selection-corrected 数值 |
| 部署机制 | 环境改变后是否仍有效？ | shift/causal assumptions 与外部验证 |

一项工作可以在某一级很强、在下一等级保持开放。例如 NTK 可精确解释训练 dynamics，却未自动给目标分布上的小风险。

## 四、随机标签实验究竟证明了什么

大型网络能把随机 labels 训练到近零误差，说明：

1. architecture 的 worst-case finite-sample expressivity 很强；
2. 常用 optimizer 并不总阻止 memorization；
3. 仅用参数个数或“训练误差为零”无法区分真实标签与随机标签的泛化。

它没有证明：

- 真实标签训练过程与随机标签完全相同；
- norm、margin、stability、compression 或 PAC-Bayes 都不可能解释泛化；
- memorization 与 generalization 互斥；
- 真实数据没有 exploitable structure。

更有力的实验应同时追踪训练时间、margin、feature evolution、augmentation、样本难度与 per-example memorization。

## 五、Uniform Convergence 的限制要精确陈述

uniform convergence 控制

$$
\sup_{h\in\mathcal H}|R(h)-\widehat R_S(h)|.
$$

对过大的、algorithm-independent 类，这个 supremum 可能被训练算法永远不会选到的坏函数主导。Nagarajan–Kolter 构造/实验表明：在特定过参数化线性/神经设置中，即使把类限制到 GD 可能输出的良好 test classifiers，某类 two-sided uniform-convergence 解释仍可 vacuous，并可能随样本量呈反直觉趋势。

严谨结论是“这些 uniform-convergence 路线可能不足以给完整解释”，不是“任何一致收敛、局部化、one-sided bound 或 data-dependent 方法都不可能工作”。反例的量词范围必须保留。

## 六、Nonvacuous 与 Explanatory 不是同义词

若分类错误率界小于 1，它是 nonvacuous；但一个理论要成为解释，还应问：

1. **正确性**：假设和概率量词是否真的满足？
2. **非空性**：数值是否优于 trivial bound？
3. **趋势性**：是否随样本、宽度、label noise、augmentation 呈正确方向？
4. **不变性**：等价 predictor 是否给相近度量？
5. **区分力**：能否区分随机标签与真实标签、好与坏超参？
6. **干预价值**：主动改变该量是否稳定改变 risk？

PAC-Bayes 可对大网络给 nonvacuous stochastic-predictor certificate，这是重要可行性证据；但 posterior construction、prior independence、deterministic deployment bridge 与 trend/causality 仍需单独分析。

## 七、从相关性到机制的阶梯

设复杂度指标 $C(\theta,S)$ 与 generalization gap 在超参数 sweep 中相关。至少有四种解释：

- $C$ 真正参与 risk mechanism；
- $C$ 与另一个原因共同变化；
- test/validation 信息泄漏到指标选择；
- parameterization artifact 同时随超参变化。

证据升级次序可以是：

$$
\text{held-out correlation}
\to\text{invariance stress test}
\to\text{controlled intervention}
\to\text{distribution replication}
\to\text{theorem under matched assumptions}.
$$

在多个指标中 post-hoc 选择相关性最强者，还必须控制 multiple comparisons。

## 八、完整的深网泛化对象合同

任何 claim 至少写清：

1. 数据单位与 $P$：i.i.d.、grouped、sequence 还是 adaptive；
2. architecture 与 parameterization；
3. initialization、optimizer、learning rate、batch 与 stopping；
4. augmentation/preprocessing 是否属于 algorithm；
5. loss、target risk 与 evaluation metric；
6. theorem 控制 deterministic 还是 stochastic predictor；
7. 概率对 sample、seed、posterior 哪些随机性取；
8. finite/infinite-width、finite/asymptotic sample 与极限顺序；
9. 计算/估计误差；
10. 适用域：ID、covariate shift、label shift、concept shift 或 adversarial。

没有对象合同的“SGD 偏好平坦解所以泛化”不是可检验命题。

## 九、开放问题地图

### 9.1 数据与表示

- 自然数据的 compositionality、invariance、long-tail 怎样进入可证风险率？
- augmentation 为什么在某些任务提供正确不变性，在另一些任务破坏 label sufficiency？
- pretraining 如何改变 downstream spectrum、margin 与 sample complexity？

### 9.2 优化与有限宽 Feature Learning

- 实际宽深网络何时在 lazy、rich、catapult 等 regimes 间切换？
- Adam、momentum、normalization、weight decay 的联合 implicit bias 是什么？
- 如何构造 parameterization-invariant 且可计算的 dynamics/complexity 描述？

### 9.3 规模、数据与计算

- scaling law 的幂律在哪些分布/compute 范围成立，何时发生 phase transition？
- interpolation 与 in-context learning/overparameterized sequence prediction 怎样连接？
- finite compute 与 asymptotic selected solution 的差距如何进入风险界？

### 9.4 Shift、反馈与部署

- ID generalization 为什么不能预测 spurious shift、OOD、adversarial risk？
- 模型部署后影响采样分布时，静态 PAC 对象怎样替换为 sequential/adaptive 对象？
- adaptive benchmark、agent-generated data 与 contamination 怎样保持有效评估？

## 十、研究工作流：一条可复现闭环

1. **锁对象**：写 data/algorithm/risk/limit contract；
2. **锁现象**：用受控 protocol 复现，不先命名机制；
3. **生成竞争假设**：至少包含 capacity、selection、data/feature 三类；
4. **导出可区分预测**：每个假设写一个会失败的条件；
5. **做干预**：保持其余因素不变地改变 spectrum、margin、kernel drift 等；
6. **匹配 theorem**：逐项核对假设而非只引用标题；
7. **算 certificate**：报告单位、置信度、近似误差与 nonvacuity；
8. **外部分布复验**：区分 ID 与 deployment 结论；
9. **维护反证账本**：记录失败 prediction；
10. **降级措辞**：证据只到 correlation 就不写成 mechanism。

## 十二、给初学者的最终判断框架

遇到“某理论解释了深度学习泛化”，依次问：

1. 它解释的是 training、ID test 还是 shift？
2. 是 theorem、数值界、相关性还是机制假说？
3. data、algorithm、loss 与 limit 写全了吗？
4. 它控制 architecture class，还是训练算法实际输出？
5. 指标对等价 parameterization 是否稳定？
6. 数值 nonvacuous 吗？趋势对吗？
7. 有反事实干预吗？
8. 哪个 observable 结果会推翻它？

能回答这八问，才算进入现代泛化理论，而不是收集术语。

## 十三、常见错误

1. 寻找唯一“真正原因”；
2. 把训练收敛 theorem 当 risk theorem；
3. 把 nonvacuous 当 causal explanation；
4. 把一个 uniform-convergence 反例泛化到全部学习理论；
5. 忽略随机标签与真实数据结构不同；
6. 用 test set 选择泛化指标；
7. 把 infinite-width 极限直接贴到 finite model；
8. 用 ID accuracy 代表 deployment reliability。

## 十四、最小记忆与掌握标准

> [!summary]
> - 深网泛化解释是一条证据链，不是一个 proxy；
> - 现象、选解、风险界、数值证书与部署结论必须分层；
> - 随机标签反驳粗糙容量解释，不反驳所有数据/算法依赖理论；
> - nonvacuity、趋势、不变性、区分力、干预价值是五类不同验收；
> - 任何强 claim 都要附适用域与可证伪预测。

能给证据定级（A）、对 claim 做五项验收（B）、重建 LT-77—83 拼图（C）、识别量词过度外推（D），并写可执行的研究 proposal/claim card（E）。
