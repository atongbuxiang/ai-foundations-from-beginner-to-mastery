# 70.7 静态完成与质量审计

> [!abstract] 结论
> 70.7 已形成从 raw logits 到在线 request trace 的闭环：8 个核心节点、8 张差异化节点图、120 题/120 解答、19 张被调用来源卡、1 个 9/9 标准库实验、3 份 CSV、3 张实验图、分卷 MOC 与累计门均已落库。这里的“通过”只指静态材料和复现资产通过，不代表学习者已个人掌握，也不代表真实 GPU 服务达到任何性能承诺。

## 一、范围与边界

本卷覆盖：

1. logits、稳定 softmax、temperature、entropy、categorical sampling 与 RNG；
2. greedy、beam、sequence score、length penalty、completed queue 与 search/model/metric error；
3. top-$k$、top-$p$、locally typical、min-$p$ 的 support 与证据边界；
4. EOS hazard、stop/max/parser/cancel、重复惩罚与退化循环；
5. grammar/prefix closure、token-byte mask、schema 与安全分层；
6. prefill/decode、KV bytes、MHA/GQA/MQA、分页内存与 continuous batching；
7. speculative acceptance、residual、TV、multi-token waterfall 与成本；
8. model/decoder/server 分层，TTFT/TBT/goodput、随机性和 Pareto 证据。

不重复展开 70.5 的 test-time reasoning、70.6 的检索管线、40.7 的完整 attention 算法谱系；70.8 才系统讲 benchmark、contamination、calibration 与 judge，70.9 统一软件版本/安全/部署证据。

## 八、仍不由静态验收保证

静态通过不能证明学习者已能在新模型上独立调试 decoder，也不能把 toy 时间线外推到 vLLM、TensorRT-LLM 或其他引擎。个人掌握需通过累计门；生产主张还需真实 checkpoint、grammar/tokenizer、硬件、并发到达、长度分布、多 seed 质量、失败/OOM、TTFT/TBT tail 与 SLO goodput。
