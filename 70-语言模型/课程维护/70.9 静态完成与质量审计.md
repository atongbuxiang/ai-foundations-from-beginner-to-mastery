# 70.9 静态完成与质量审计

> [!abstract] 结论
> 70.9 已形成从训练数据隐私到线上治理的闭环：8 个核心节点、8 张差异化节点图、120 题/120 解答、38 张已核验来源卡、1 个 9/9 标准库实验、3 份 CSV、3 张实验图、分卷 MOC 与累计研究门均已落库。这里的“通过”仅指静态材料和复现资产通过，不代表学习者个人掌握，也不代表任何真实模型、API、组织或产品满足隐私、安全或合规承诺。

## 一、范围与边界

本卷覆盖：

1. inclusion、memorization、逐字复现、extractability、harm，合成 canary、rank/exposure 与预算化抽取；
2. membership 假设检验、低 FPR 尾部、似然比、重训参照、认证/经验 unlearning 与删除 lineage；
3. direct/indirect prompt injection、Tool-RAG 数据流、trust boundary 与模型外 reference monitor；
4. jailbreak 攻击预算、toxicity/bias 测量、harm/benign 双分母、红队覆盖与适应性；
5. abstain/refuse/safe-complete/escalate、correctness/safety 双 score、risk–coverage 与群体 over-refusal；
6. model/API/tokenizer/template/retriever/tool/judge bundle、内容指纹与 R0—R3 复现；
7. 五层 SLI/SLO、dataset/system/measurement shift、反馈选择、canary rollout 与 incident；
8. Model/Data/System Cards、研究预注册、PROV、Govern–Map–Measure–Manage 与 claim ledger。

不收录真实秘密、个人数据、可复用注入/越权载荷、在线目标步骤或凭据；实验只用合成字符串、抽象动作与离线算术。标准与厂商报告用于术语、过程和案例，不被写成独立安全认证。

真实测试必须另行获得授权，采用合成/脱敏数据、隔离沙箱、最小权限、停止规则与受限存储。本卷不授权对任何外部系统、账户或数据实施测试。
