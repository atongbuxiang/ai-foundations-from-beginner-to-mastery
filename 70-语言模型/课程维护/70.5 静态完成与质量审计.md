## 三、实验关键 oracle

| 检查 | 数值 |
|---|---|
| Prompt bytes | trailing space 使 23→24 bytes |
| Order | 24 permutations；score -9…9 |
| Label map | positive A→B |
| Theory | posterior .9/.1；OLS=GD=2 |
| Induction | clean B；corrupt X |
| Faithfulness | answer flip；trace invariant |
| Sampling | majority A；pass@3=.9；regret 1 |
| Search | depth 3 binary tree = 15 |
| Long context | $\tau=.8$ 时 $T_{eff}=16K$ |

## 五、尚未证明

- 任意 prompt 改写都产生显著变化，或存在普适最佳模板；
- 真实 LLM 的 ICL 唯一实现 Bayesian、OLS、GD 或 induction circuit；
- 可见 CoT 完整呈现内部因果过程；
- 多数一致、verifier 高分或 pass-at-k 等于正确 top-1；
- 更多 token/FLOPs/search 对每道题单调有益；
- Lost-in-the-Middle 由单一位置机制造成；
- synthetic long-context 成绩等于现实文档理解。
