# 70.4 指令适配与参数高效微调 最小实验与复现说明

> [!abstract] 实验结论
> Python 标准库脚本通过 9 项确定性检查：训练/推理 template 前缀、SFT shift/mask/global denominator、指令 draw/target/selection 份额、小参数变化的大量功能翻转、LoRA 首步梯度与 merge、QLoRA 分项内存、PEFT 参数量、soup/task arithmetic/TIES，以及置换对称导致的平均失败。

## 一、问题与通过条件

| ID | 问题 | 通过条件 |
|---|---|---|
| H1 | 训练回答前缀与推理 generation prefix 是否完全相同？ | 8 个 token exact equality |
| H2 | SFT 是否只 shift 一次并按全局 target 规约？ | labels/mask exact；global 7/3，设备均值 2.5 |
| H3 | Task 50/50 是否等于 target/selected share？ | targets 20/80；selected A/B 为 6/7、1/7 |
| H4 | 很小参数变化能否造成大功能变化？ | bias 变化 .002，100/100 低 margin 样本翻转 |
| H5 | LoRA 零因子梯度与 merge 是否逐项正确？ | B=0 时 grad A=0、grad B≠0；输出 [2,5] 相等 |
| H6 | 4-bit 是否等于总显存？ | 分项账合计 2.62GB，而 codes 仅 0.5GB |
| H7 | 三类 PEFT 参数是否按接口公式计算？ | prompt 500、prefix KV 4000、adapter 1600 |
| H8 | Soup、task vectors 与 TIES 是否给不同结果？ | soup [1.5,1.5]；task sum [2,2]；TIES .7/-.65 |
| H9 | 功能等价的置换模型可否直接平均？ | 两 ingredient 输出 6，参数平均输出 0 |
