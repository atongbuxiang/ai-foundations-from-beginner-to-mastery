# 70.8 评估校准与幻觉 最小实验与复现说明

> [!abstract] 实验目标
> 用 Python 标准库把本卷九组易混对象变成确定性 oracle：macro/micro 与 cluster 分母、EM/F1/BLEU/ROUGE、pass@$k$、Brier/ECE/risk–coverage、事实与引用分母、judge 交换、污染行为探针、prompt 方差和 oracle/决策门。它只验证定义、数值与数据合同，不冒充真实模型 benchmark。

## 一、运行

在知识库根目录执行：

~~~bash
python3 00-知识库管理/_labs/code/experiment_language_evaluation_v1.py
~~~

成功输出：

~~~text
{"status": "passed", "checks": "9/9", ...}
~~~

产物目录：

~~~text
00-知识库管理/_labs/experiments/lm70.8-evaluation-v1/
~~~

其中包含 results.json、metric_trace.csv、robustness_trace.csv、decision_trace.csv 与三张实验 SVG。脚本不访问网络、模型 API 或 GPU，也不依赖随机数；prompt bootstrap 使用 27 个有放回三元组的精确枚举。

## 三、实验图

**读图问题**：为什么同一批计数会得到不同 macro/micro 分数，文本匹配指标与 calibration 又为何不能被压成一个“综合正确率”？

> [!figure] 实验图 1　分母、词面指标与可靠性图
> **数据来源**：柱长、词面指标与 reliability 点全部由 experiment_language_evaluation_v1.py 中的教学数组计算，并与 results.json、metric_trace.csv 同源。

**怎样读图**：先比较 task/example 与 user/request 两组不同分母；再核对 token F1、BLEU BP、ROUGE-L 只描述各自匹配单位；最后看 reliability 点是否落在对角线及其 bin 样本量，并回到 Brier/ECE 数值。

**图没有证明什么**：这些小数组不证明任何真实模型的质量、事实性或校准水平；把不同指标并排也不等于它们可以线性合成，真实区间必须按独立 item/user cluster 估计。

**读图问题**：item×prompt 的不均匀表现怎样体现稳健性，而 canonical-order 相对置换下降为何只能作为污染诊断、不能单独定罪？

> **数据来源**：热图读取 robustness_trace.csv 的 20 个 cell；右侧 $.80/.62$ 来自固定计数，未调用任何模型或训练数据检测器。

**怎样读图**：逐 item 横看四个 prompt，区分稳定难题与 prompt 交互；再比较 canonical/permuted 的配对差，并把位置偏差、格式敏感和 parser 变化保留为替代解释。

**图没有证明什么**：教学热图不能估计真实 prompt 总体，18 个百分点下降也不是训练 exposure、memorization 或 exploitation 的充分证据；真实审计还需要数据谱系、重叠检测与新题对照。

**读图问题**：两个 oracle gap 分别定位什么当前管线差异，为什么质量显著提高仍可能因为延迟非劣门和高风险 slice 而不能发布？

![[00-知识库管理/_labs/experiments/lm70.8-evaluation-v1/plot-language-eval-decision-v1.svg|850]]

**怎样读图**：从真实端到端到 gold retriever、gold tool 读取相邻 gap，而不是把三条横条当可加模块贡献；再检查三个 slice 的不同分母，最后逐项判断 superiority 与 non-inferiority，任一硬门失败则 all gates 失败。

**图没有证明什么**：Oracle gap 不保证实际工程能达到，也不提供优化成本；教学 CI 和 slice 不代表任何产品，不能据此作真实上线、安全或性能承诺。

## 四、手算复核

### 1. 分母

$$
\operatorname{Macro}=\frac{20/25+3/15}{2}=.5,\qquad
\operatorname{Micro}=\frac{20+3}{25+15}=.575.
$$

用户甲 4 请求中 3 成功、用户乙 1 请求失败：

$$
\operatorname{RequestAvg}=3/5=.6,\qquad
\operatorname{UserAvg}=\frac{3/4+0}{2}=.375.
$$

### 2. Pass@$k$ 与 calibration

$$
\widehat{\mathrm{pass@}2}
=1-\frac{\binom72}{\binom{10}2}
=\frac{24}{45}.
$$

$$
\operatorname{Brier}=\frac{.04+.49+.04}{3}=.19,\qquad
\operatorname{ECE}=.4|.20-.25|+.6|.65-.80|=.11.
$$

### 3. 事实分母与决策

$$
\operatorname{FactualPrecision}=6/8,\quad
\operatorname{CitationPrecision}=4/5,\quad
\operatorname{ClaimCoverage}=6/10.
$$

质量差的 95% CI 下界 $+.4>0$，superiority 通过；延迟差的 CI 上界 $27>20$ ms，non-inferiority 失败，因此不能用质量门补偿延迟门。

## 五、故意破坏

逐项修改并观察对应 check 失败：

1. 把 task-macro 写成合并事件的 micro；
2. token overlap 不按多重集合裁剪，或 BLEU 短句惩罚符号写反；
3. pass@$k$ 把“全失败”组合数漏取补；
4. ECE 忽略 bin 权重，或 risk 分母仍用全部样本；
5. citation precision 与 claim coverage 互换分母；
6. AB/BA 不映射回候选身份，或静默删除 ties；
7. 把 canonical drop 的解释写成污染证明；
8. sample standard deviation 与题面 population standard deviation混用；
9. 只按 CI 点估计判断 non-inferiority，或用质量平均补偿硬 SLO。

若修改后仍 9/9，说明断言没有覆盖相应实现。

## 六、外推边界

本实验没有真实 prompts、outputs、references、sources、judge、人标、模型、检索库或在线用户。它能保证课程中的小算例和数据契约可回归，不能证明某 benchmark 构念有效、某模型校准、某回答真实、某 judge 公平或某产品可上线。真实扩展必须冻结 manifest，保留 per-unit raw outputs/traces/failures，按独立 cluster 做配对区间，并用未参与选择的人类/可执行 oracle 与真实 SLO 验证。
