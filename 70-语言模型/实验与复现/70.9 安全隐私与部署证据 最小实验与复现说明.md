# 70.9 安全隐私与部署证据 最小实验与复现说明

> [!abstract] 实验目标
> 用 Python 标准库把本卷九组关键定义变成确定性 oracle：canary exposure、低 FPR membership、删除参照距离、模型外工具授权、攻击预算、拒答双分母/risk–coverage、版本指纹、drift/反馈/incident gate 与证据卡有效链接。实验只用合成字符串、抽象提案和离线算术，不接触真实秘密、用户、攻击目标、模型、API 或凭据。

## 一、运行

在知识库根目录执行：

~~~bash
python3 00-知识库管理/_labs/code/experiment_language_safety_deployment_v1.py
~~~

成功输出：

~~~text
{"status": "passed", "checks": "9/9", ...}
~~~

产物目录：

~~~text
00-知识库管理/_labs/experiments/lm70.9-safety-deployment-v1/
~~~

其中有 results.json、privacy_trace.csv、security_trace.csv、deployment_trace.csv 和三张实验 SVG。脚本不访问网络，不使用随机采样；所有小数由固定数组、精确公式或 canonical JSON 哈希得到。

## 二、九个断言

| check | 数学/系统 oracle |
|---|---|
| canary_exposure_rank | $|\mathcal R|=1024$、rank $=8$，exposure $=10-3=7$ bits |
| membership_low_fpr | 100 个 non-members、10 个 members，固定阈值下 FPR $.01$、TPR $.20$ |
| certified_removal_distance | 四个合成 probe 上 unlearned 与 retrain 的平均绝对差 $.05$；明确不是通用认证 |
| capability_boundary_and_tool_auth | 1 个合法读取提案通过；4 个身份/schema/scope/confirmation 失败提案 4/4 被阻断 |
| adaptive_attack_budget | iid 基线 $1-(1-.03)^{20}\approx.4562$，同时保留 benign utility $.92$ |
| refusal_confusion_risk_coverage | unsafe answer $.12$、over-refusal $.18$；coverage $.25/.5/1$ 的 risk $.5/.25/.5$ |
| version_hash_contract | canonical serialization 对字段顺序稳定；template 变化使 bundle hash 改变 |
| drift_feedback_incident | TV $.1$、PSI $.04055$；被选择反馈 $.90$ 与随机审计总体 $.78$ 不同；延迟硬门失败 |
| evidence_card_completeness | 20 个字段中 16 个有链接、2 个失效：表面 $.80$，有效链接 $.70$ |

## 四、手算复核

### 1. Exposure 与 Membership

$$
\operatorname{exposure}
=\log_2(1024)-\log_2(8)=10-3=7.
$$

在 100 个 non-members 中 1 个超过阈值，在 10 个 members 中 2 个超过：

$$
\operatorname{FPR}=1/100=.01,\qquad
\operatorname{TPR}=2/10=.20.
$$

### 2. 攻击预算与拒答

$$
\Pr(\text{20 次内至少成功一次})
=1-(1-.03)^{20}\approx.4562.
$$

$$
\operatorname{unsafe}=12/100=.12,\qquad
\operatorname{overrefusal}=18/100=.18.
$$

### 3. Drift 与证据

$$
\operatorname{TV}
=\frac12(|.5-.4|+|.3-.35|+|.2-.25|)=.1.
$$

$$
\operatorname{PSI}
=(.5-.6)\log(.5/.6)+(.5-.4)\log(.5/.4)
\approx.04055.
$$

20 个必填字段，16 个链接中 2 个失效：

$$
\text{surface}=16/20=.8,\qquad
\text{valid}=(16-2)/20=.7.
$$

## 五、故意破坏

1. 把 exposure 的 rank 写成概率，观察 canary check 失败；
2. 把 membership 的分母互换，或只报 AUC；
3. 用原模型而非 retrain 作删除参照；
4. 删除 scope/confirmation predicate，让一个越权提案通过；
5. 把多次攻击成功概率写成 $20p$；
6. 只保留 harmful 分母，使全拒绝看似完美；
7. 不 canonicalize manifest，让字段顺序改变 hash；
8. 将 parser failure 从 SLI 分母静默剔除或把反馈子集当总体；
9. 把失效链接仍记为完整。

若修改后仍 9/9，说明对应断言没有保护该契约。

## 六、外推边界

本实验没有真实训练数据、个人记录、攻击文本、模型输出、用户、政策、工具、API、线上流量或事故。它能保证本卷的小算例、字段与决策逻辑可回归，不能证明某模型未记忆、某 unlearning 有保证、某 agent 抗注入、某拒答政策合适、某 API 可复现或某产品可上线。真实扩展必须经过授权，使用合成/脱敏数据和沙箱，冻结 threat model、预算、版本、分母、人工锚点、SLO 与停止规则。
