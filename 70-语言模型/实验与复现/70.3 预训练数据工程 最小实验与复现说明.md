# 70.3 预训练数据工程 最小实验与复现说明

> [!abstract] 实验结论
> Python 标准库脚本通过 9 项确定性检查：过滤后的选择分布、MinHash 枚举恒等式、LSH 候选概率、阈值图非传递、污染检测的 Bayes 基率、mixture 三份额、packing 边界合同、curriculum 更新不交换，以及 provenance/effective-target 账本。它把本卷最容易被口号掩盖的对象变成可手算 oracle。

## 一、问题与通过条件

| ID | 问题 | 通过条件 |
|---|---|---|
| H1 | 两群体保留率不同，selected distribution 是否改变？ | A 从 60% 变 78.95%，B 从 40% 变 21.05% |
| H2 | 枚举所有随机排列时，MinHash equality 是否等于 Jaccard？ | 6 个排列中 2 个相等，概率 $1/3=J$ |
| H3 | LSH 的 $b=10,r=4,s=.8$ 候选概率是多少？ | $1-(1-.8^4)^{10}=0.994846\ldots$ |
| H4 | pair threshold 是否具有传递性？ | A–B、B–C 通过，A–C 失败，但 connected component 合并三者 |
| H5 | 高 recall detector 阳性是否近似必为污染？ | $\pi=.02,r=.9,f=.01$ 时后验约 64.75% |
| H6 | 50/50 document share 是否等于 token/target share？ | token 20/80，effective target 1/3、2/3 |
| H7 | FFD packing 是否同时满足装箱、relation 与 boundary loss？ | 两满箱；精确 $5\times5$ block relation；mask 为 1,0,1,1 |
| H8 | 相同 A/B exposure count、不同顺序是否同终点？ | AB=-.12，BA=-.08 |
| H9 | positions、effective targets 与 manifest hash 是否可分账？ | $T_{eff}=4$，mean NLL=1.5；canonical hash 与键顺序无关 |

## 四、实验图 1：过滤器是分布算子

先看图回答：为什么“只删低质量”仍必须报告每群体的 source、retention 与 selected share？

![[00-知识库管理/_assets/plots/language-models/plot-language-pretraining-selection-v1.svg|900]]

> [!figure] 图 EXP-LM-703-01　来源比例、群体保留率与过滤后比例的三账
> 蓝/橙分别为 A/B。图把 $P(g)$、$P(S=1\mid g)$ 与 $P(g\mid S=1)$ 分列，避免把 classifier decision 当客观噪声标签。来源：标准库脚本按 Bayes 归一化直接生成。

**怎样读图**：先乘 source share 与 retention 得 kept mass，再跨群体归一；总体 57% retention 不包含方向信息。

**图没有证明什么**：toy 两群体不证明真实过滤器有相同偏差，也不证明所有 selection 都有害；真实结论需要分层 gold labels 与不确定性。

## 五、实验图 2：检索、验证、聚类与暴露不能合并

先看图回答：99.48% 的 LSH candidate probability、一个 verified pair 和 64.75% contamination posterior 分别回答什么问题？

![[00-知识库管理/_assets/plots/language-models/plot-language-pretraining-similarity-contamination-v1.svg|900]]

> [!figure] 图 EXP-LM-703-02　LSH S 曲线、非传递阈值图与污染 detector 后验
> 左侧是候选召回概率而非相似度真值；中间给 connected-component chaining 反例；右侧固定 recall/FPR，显示后验依赖 base rate。来源：标准库有限计算。

**怎样读图**：依次标注 candidate、exact similarity、cluster policy、exposure label 与 causal performance effect，禁止跨层升级。

**图没有证明什么**：理想 band 独立不保证具体 hash 实现达到该召回；文本 overlap 也不自动证明模型 memorized 或利用了样本。

## 六、实验图 3：训练运行需要四本账

先看图回答：同一 run 中哪四种“相同”最容易被误写——相同 sampler、相同物理 batch、相同累计数据量、相同 token 数？

![[00-知识库管理/_assets/plots/language-models/plot-language-pretraining-training-contracts-v1.svg|900]]

> [!figure] 图 EXP-LM-703-03　Mixture、packing、curriculum 与 provenance 的联合账本
> 左上区分 document/token/target share；右上给 block-causal relation；左下展示 AB/BA 不交换；右下区分 raw、parsed、filtered、unique、draw 与 targets。
> **数据来源：**本图由本卷确定性实验脚本生成，并与同目录 results/CSV 或脚本内固定数组同源；未特别标注的结构只承担教学排版。

**怎样读图**：每个面板先问“对象和 denominator 是什么”，再判断份额、等价或效率；draw/unique 大于 1 是 exposure，不是 retention。

**图没有证明什么**：100% toy utilization 不保证真实 wall time；两步非交换不证明某 curriculum 更优；hash equality 不证明许可、语义或隐私正确。

## 八、可复现边界

本实验验证 toy 定义与反例，不证明真实网页 parser、LID、dedup、distributed dataloader 或模型 kernel 正确。接入真实管线后还要固定 normalization/shingle/hash、candidate verification、cluster representative、cutoff、sampling unit、tokenizer、position IDs、loss reduction、worker seed 和 manifest schema；并在语言、来源、长度、权利状态与 benchmark 切片上报告错误。
