# 70.6 检索增强与外部记忆 最小实验与复现说明

> [!abstract] 实验目标
> 用 Python 标准库把本卷最容易混淆的九组对象变成可执行 oracle：潜文档边缘化、chunk/距离合同、BM25、RRF、ANN 保真、对比梯度、引用指标、多跳状态和 R×G×A 联合评估。它不下载模型、不需要向量库，也不把 toy 结果冒充生产质量。

## 一、运行

在知识库根目录执行：

~~~bash
python3 00-知识库管理/_labs/code/experiment_language_rag_audit_v1.py
~~~

成功输出：

~~~text
{"passed": 9, "total": 9, ...}
~~~

产物目录包含：

- results.json；
- corpus_index.csv：chunk span、coverage、ACL 与版本；
- ranking_trace.csv：逐 query 的 R/G/A 与首个相关排名；
- 三张实验 SVG。

## 二、九个断言

| check | 数学/系统 oracle |
|---|---|
| latent_marginal_and_topk | 完整边缘概率 $0.64$；top-2 权重 $0.625,0.375$ |
| chunk_coverage_and_distance | $N=1000,L=256,O=64$ 得 5 chunks；gold 被覆盖；单位向量平方距离 $0.4$ |
| bm25_saturation | 词频分数严格递增且低于极限 $k_1+1=2.5$ |
| rrf_fusion | A $(1,10)$ 得 $0.03068$；B $(3,3)$ 得 $0.03175$ |
| ann_exact_preservation | exact/ANN top-5 交集 3，ANN recall $0.6$；候选保留 gold 但重排丢失 |
| contrastive_gradient | logits $(2,1,0)$ 的 loss $0.407606$，三个梯度和为 0 |
| citation_correctness_completeness | completeness $2/3$，correctness $3/4$ |
| iterative_multihop_state | 两次检索形成 A→B→C，预算单调不增且只在双证据后回答 |
| evaluation_joint_and_metrics | 四样本联合率 $0.25$，MRR $0.45833$，$DCG(3,2,0)=8.89279$ |

## 四、手算复核

### 1. 潜文档

$$
0.5(0.8)+0.3(0.2)+0.2(0.9)=0.64.
$$

截断第三项后，保留质量 $0.8$，所以 $0.5/0.8=0.625$、$0.3/0.8=0.375$。

### 2. 对比梯度

$$
p=\operatorname{softmax}(2,1,0)\approx(0.66524,0.24473,0.09003),
$$

$$
\nabla_sL=p-(1,0,0).
$$

梯度和为 0；若改错 positive index，断言应立即失败。

### 3. MRR 与联合率

四题首相关排名为 $1,2,\infty,3$：

$$
MRR=(1+1/2+0+1/3)/4=0.45833.
$$

只有 q1 同时满足 $R=G=A=1$，联合率为 $1/4$。

## 五、故意破坏

依次尝试：

1. 把 top-2 权重除以 1 而非 $0.8$；
2. 将 overlap 当步长；
3. 删除 BM25 分母中的 $f$；
4. 把 RRF rank 从 1 改为 0 起算；
5. 用 task recall 替换 exact-overlap；
6. 忘记 positive 梯度的减一；
7. 交换 correctness/completeness 分母；
8. 允许预算增加或无证据直接 answer；
9. 把 $P(R)P(G)P(A)$ 当联合率。

每项都应改变相应断言或结果。若代码仍全部通过，说明测试没有覆盖实现。

## 六、外推边界

本实验没有真实 tokenizer、embedding、ANN 图、LLM、NLI judge 或网络延迟。它验证定义和账本，不验证某个产品、模型或语料的质量。真实扩展需固定 corpus/chunker/encoder/index，加入 exact search、人工 relevance 与 claim-support 标注，并保留同样九层 oracle。
