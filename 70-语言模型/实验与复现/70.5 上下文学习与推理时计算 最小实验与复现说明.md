# 70.5 上下文学习与推理时计算 最小实验与复现说明

> [!abstract] 实验结论
> Python 标准库脚本通过 9 项确定性检查：prompt bytes/IDs 与完整 label score、24 种顺序反例、标签置换合同、Bayesian/OLS/GD oracle、induction counterfactual、faithfulness bias intervention、多样本 coverage/selection、搜索树预算，以及阈值有效上下文。

## 一、问题与通过条件

| ID | 问题 | 通过条件 |
|---|---|---|
| H1 | 尾随空格与完整多 token scorer 是否改变对象？ | byte IDs 不同；fox score > panda |
| H2 | 同 demonstrations 不同顺序能否改变预测？ | 24 permutations；正负预测均出现 |
| H3 | 标签置换是否被作为临时映射记录？ | positive 从 A 变 B，映射对象不同 |
| H4 | 三种 ICL toy oracle 是否可复算？ | posterior .9/.1；OLS=GD=2 |
| H5 | induction 是否依 earlier A 后的 token？ | clean→B；counterfactual→X |
| H6 | 答案可否随隐藏 cue 变而 trace 不变？ | A→B；可见 trace 相同且不提 cue |
| H7 | coverage、聚合与选择是否分账？ | majority A；pass@3=.9；regret=1 |
| H8 | 搜索规模与成本是否独立记录？ | binary depth 3 = 15；五项成本账 |
| H9 | 声明长度是否等于阈值有效长度？ | $\tau=.8$ 时 $T_{eff}=16K$ |
