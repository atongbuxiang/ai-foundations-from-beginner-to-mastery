# 70.2 语言模型目标 最小实验与复现说明

> [!abstract] 实验结论
> Python 标准库脚本通过 9 项确定性检查：有限自回归树概率守恒、CLM shift/relation/loss 对齐、全局 numerator/denominator、MLM mask-set 账本、MLM 条件不自动构成 joint、T5 sentinel 无损重建、Prefix LM 矩阵、mixture sample/token share 分离，以及跨 tokenizer PPL 反例。所有检查都是有限 oracle，不依赖深度学习框架或随机训练。

## 一、问题与可证伪预期

| ID | 问题 | 通过条件 |
|---|---|---|
| H1 | 局部条件相乘后，有限 EOS 树叶概率是否守恒？ | 叶和 1；token NLL 和等于 path NLL |
| H2 | `[BOS,a,b,EOS]` 是否只 shift 一次并配下三角 relation？ | pairs、矩阵与 3 个 targets exact equality |
| H3 | 多设备平均是否先规约 $N,D$？ | global token mean 1.36；与错误 1.60 分叉 |
| H4 | BERT 80/10/10 中 `[MASK]` 数是否等于 targets？ | 1200 可见 mask，1500 loss targets |
| H5 | 任意 MLM 条件表是否自动定义 joint？ | 两方向 odds ratio 不同；PLL weights 和为 1.18 而非 1 |
| H6 | 两个 T5 spans 是否可由 sentinel pair 无损恢复？ | restored exact clean；长度公式一致 |
| H7 | $P=2,S=3$ 的 Prefix LM relation 是否逐格正确？ | 与预注册 $5\times5$ 矩阵 exact equality |
| H8 | 各 50% 样本是否意味着等 target share？ | R/X sample 50/50，target 20/80 |
| H9 | 相同字符串概率的跨 tokenizer PPL 是否可分叉？ | 2/6 tokens 得 PPL 1000/10，BPB 同为 1.6610 |

## 六、实验图 3：错误 denominator 改变 estimand

先看图回答：为什么同一组设备 loss 和同一字符串概率，各自能产生两个看似合理却含义不同的均值？

![[00-知识库管理/_assets/plots/language-models/plot-language-objectives-denominators-v1.svg|900]]

> [!figure] 图 EXP-LM-702-03　分布式 reduction 与跨 tokenizer PPL 反例
> 左侧比较先全局汇总 token 与设备等权；右侧固定完整字符串概率，只改变 token count，PPL 从 1000 变 10，而共同 raw-byte BPB 不变。
> **数据来源：**本图由本卷确定性实验脚本生成，并与同目录 results/CSV 或脚本内固定数组同源；未特别标注的结构只承担教学排版。

**怎样读图**：先找到 numerator/完整事件概率，再查 denominator 的单位；不要先比较最终标量颜色或大小。

**图没有证明什么**：BPB 只有在模型对同一 raw byte string 定义可比概率时成立；随机/非可逆 tokenizer 还需处理潜在分段求和。

## 八、可复现边界

脚本证明的是 toy contract 的计算与反例，不证明大型神经模型已正确实现这些合同。接入 PyTorch/JAX 后仍需测试 mask polarity、broadcast、padding/packing、内部 shift、低精度 softmax、分布式规约和增量缓存。MLM 二元条件反例证明“条件表不自动兼容”，不证明任何具体 BERT checkpoint 必然具有该不兼容程度。
