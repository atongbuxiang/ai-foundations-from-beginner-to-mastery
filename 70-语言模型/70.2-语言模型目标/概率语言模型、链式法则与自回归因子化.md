# 概率语言模型、链式法则与自回归因子化

## 零、本页在课程中的位置

- **承接**：[[语言模型的文本对象、文档边界与序列样本空间]]已经说明，只有先固定 Unicode、tokenizer、文档边界和特殊 token，我们才知道“一个序列”究竟是什么。
- **中心问题**：怎样用一系列“给定前缀，下一个 token 是什么”的局部概率，定义一条完整序列的联合概率？
- **去向**：下一节[[Causal LM 的 Shift、Attention Mask 与 Token Loss]]会把这里的概率因子变成实际训练张量中的输入、标签、mask 和逐 token loss。

> [!tip] 第一次阅读抓住三件事
> 先理解概率链式法则，再手算一条含 EOS 的序列概率，最后理解为什么最大似然会变成逐 token 负对数似然。Proper scoring、无界长度归一化和暴露偏移可以在第二遍细读。

> [!abstract] 一句话结论
> 概率语言模型是在已经锁定的序列样本空间上给每条有限序列分配概率。自回归语言模型用概率链式法则把联合分布精确写成一串 next-token 条件分布；这不是“假设 token 彼此独立”，而是选择一种可训练、可采样的联合分布坐标系。

## 一、先问：模型究竟给什么对象分配概率

先看一个不带一般符号的问题。假设词表只有 `A`、`B` 和 `EOS`。模型首先回答“开头出现 `A` 的概率是多少”，看到 `A` 后再回答“下一个出现 `B` 的概率是多少”，看到 `AB` 后回答“现在结束的概率是多少”。我们想知道：

> 完整序列 `A B EOS` 的概率，能否只用这三个局部回答算出来？

答案是可以相乘，但“为什么可以相乘”来自条件概率定义，不是语言模型额外假设。为了准确写出这件事，先固定对象和符号。

设 tokenizer 与文档切分合同已经固定，词表为有限集合 $\mathcal V$，并含终止符 $\langle\mathrm{eos}\rangle$。一条完成的序列可写为

$$
x=(x_1,\ldots,x_{\tau-1},\langle\mathrm{eos}\rangle),\qquad x_t\in\mathcal V.
$$

语言模型是样本空间 $\Omega$ 上的概率分布 $p_\theta:\Omega\to[0,1]$，满足

$$
\sum_{x\in\Omega}p_\theta(x)=1.
$$

这里的 $\Omega$ 不是抽象的“所有文字”：它由 Unicode 规范化、tokenizer、特殊 token、最大长度、文档边界和 EOS 规则共同决定。只改 tokenizer，随机变量就变了；因此两套模型的 token 概率并不天然处在同一坐标系。

### 1.1 符号账本

| 符号 | 类型 | 含义 |
|---|---|---|
| $\mathcal V$ | 有限集合 | tokenizer 的词表，包含普通 token 和 EOS |
| $X_t$ | 随机变量 | 第 $t$ 个位置将出现的 token |
| $x_t$ | $\mathcal V$ 中的元素 | 一条具体序列在第 $t$ 个位置的取值 |
| $x_{<t}$ | token 序列 | 前缀 $(x_1,\ldots,x_{t-1})$ |
| $\tau$ | 正整数随机量或具体长度 | EOS 出现的位置 |
| $\Omega$ | 可数样本空间 | 当前文本合同允许的全部完整序列 |
| $p_\theta$ | 概率分布 | 参数为 $\theta$ 的语言模型 |

公式 $p_\theta(x_t\mid x_{<t})$ 的读法是：“在前 $t-1$ 个 token 已经等于 $x_{<t}$ 的条件下，第 $t$ 个 token 等于 $x_t$ 的概率。”竖线右边是已知条件，不是另一个需要相乘的事件。

现在对象已经固定，下一步才讨论怎样把联合事件拆成条件事件。

## 二、链式法则怎样出现

由条件概率定义

$$
p(a,b)=p(a)\,p(b\mid a),
$$

其中真正的起点是

$$
p(b\mid a)=\frac{p(a,b)}{p(a)},\qquad p(a)>0.
$$

把两边乘以 $p(a)$，就得到上一式。对三个 token，不要直接跳到乘积；分两步展开：

$$
\begin{aligned}
p(x_1,x_2,x_3)
&=p(x_1,x_2)\,p(x_3\mid x_1,x_2)
&&\text{把前两个 token 视为一个联合事件},\\
&=p(x_1)\,p(x_2\mid x_1)\,p(x_3\mid x_1,x_2)
&&\text{再展开 }p(x_1,x_2).
\end{aligned}
$$

每一步只使用一次二变量条件概率定义。对 $T$ 个 token 重复同一操作，得到固定长度序列的恒等式

$$
p(x_{1:T})
=p(x_1)\prod_{t=2}^{T}p(x_t\mid x_{<t})
=\prod_{t=1}^{T}p(x_t\mid x_{<t}),
$$

其中 $x_{<1}$ 是空前缀。对有限可变长度序列，更准确地写成

$$
p_\theta(x)
=\left[\prod_{t=1}^{\tau-1}p_\theta(x_t\mid x_{<t})\right]
p_\theta(\langle\mathrm{eos}\rangle\mid x_{<\tau}).
$$

EOS 因子既决定“内容以后出现什么”，也决定“何时结束”。若训练从不计 EOS，却在生成时依靠 EOS 停止，训练的概率对象与部署程序便不完全一致。

### 2.1 怎样读这条乘积公式

- 第 $t$ 个因子只回答一步预测问题；
- 条件 $x_{<t}$ 保留了此前全部 token，因此没有删除依赖；
- 乘积把一条路径上各步的条件概率合成为叶节点概率；
- 任意一个因子接近 0，整条序列概率都会被显著压低；
- 取对数以后，乘积会变成求和，这正是训练损失能够逐 token 累加的原因。

### 2.2 三项检查

1. **数值范围**：每个因子在 $[0,1]$，所以乘积也在 $[0,1]$。
2. **固定长度归一化**：若每个前缀上的 next-token 分布和为 1，则深度为 $T$ 的概率树所有叶子之和为 1。
3. **独立特例**：若恰好有 $p(x_t\mid x_{<t})=p(x_t)$，公式才退化为独立乘积 $\prod_t p(x_t)$。

> [!important] 因子化不是独立性假设
> 若假设独立，右侧应为 $\prod_t p(x_t)$；自回归因子却是 $p(x_t\mid x_{<t})$，可以依赖整个前缀。链式法则对任何联合分布都成立，限制来自我们怎样参数化这些条件分布，而不是来自恒等式本身。

## 三、一个完整手算

令词表为 $\{A,B,\mathrm{eos}\}$，模型给出：

| 前缀 | $p(A\mid\cdot)$ | $p(B\mid\cdot)$ | $p(\mathrm{eos}\mid\cdot)$ |
|---|---:|---:|---:|
| 空 | 0.5 | 0.3 | 0.2 |
| $A$ | 0.1 | 0.6 | 0.3 |
| $AB$ | 0.2 | 0.1 | 0.7 |

则完整序列 $AB\mathrm{eos}$ 的概率为

$$
p(AB\mathrm{eos})=0.5\times0.6\times0.7=0.21,
$$

自然对数负似然为

$$
-\log p(AB\mathrm{eos})
=-\log0.5-\log0.6-\log0.7\approx1.561.
$$

三项之和对应三个局部预测错误的累积。若 $p(\mathrm{eos}\mid AB)$ 从 $0.7$ 降至 $0.07$，内容 token 不变，整条序列 NLL 仍增加 $\log 10$；这说明长度模型不是附属品。

再做两个快速检查：概率 $0.21$ 小于路径上最小的单步概率 $0.5$，符合多个 $[0,1]$ 因子相乘的结果；NLL $1.561$ 为正，也符合 $-\log p\ge 0$。这两个检查不能证明模型正确，却能及时发现符号或计算错误。

## 四、最大似然为什么变成 token 交叉熵

给定独立抽样的训练序列 $x^{(1)},\ldots,x^{(N)}$，最大化数据似然

$$
\prod_{n=1}^{N}p_\theta(x^{(n)})
$$

等价于最小化总负对数似然

$$
\mathcal L_{\mathrm{sum}}(\theta)
=-\sum_{n=1}^{N}\sum_{t=1}^{T_n}
\log p_\theta(x_t^{(n)}\mid x_{<t}^{(n)}).
$$

这个变换包含三步：

$$
\begin{aligned}
\arg\max_\theta \prod_{n=1}^{N}p_\theta(x^{(n)})
&=\arg\max_\theta \sum_{n=1}^{N}\log p_\theta(x^{(n)})
&&\text{对数严格递增，不改变最优点},\\
&=\arg\max_\theta \sum_{n=1}^{N}\sum_{t=1}^{T_n}
\log p_\theta(x_t^{(n)}\mid x_{<t}^{(n)})
&&\text{代入链式因子化},\\
&=\arg\min_\theta \mathcal L_{\mathrm{sum}}(\theta)
&&\text{整体乘以 }-1\text{，最大化变最小化}.
\end{aligned}
$$

总和、按序列平均和按有效 token 平均通常拥有不同的数值尺度。只有把分母、mask 和优化器学习率合同写清楚，代码中的“cross entropy”才与这里的概率目标对应。

若真实条件分布为 $q(\cdot\mid h)$，某个上下文 $h$ 上的总体风险是

$$
\mathbb E_{Y\sim q(\cdot\mid h)}[-\log p_\theta(Y\mid h)]
=H(q)+D_{\mathrm{KL}}(q\|p_\theta).
$$

这条分解也可以逐项验证。假设当 $q(v)>0$ 时都有 $p_\theta(v)>0$，则

$$
\begin{aligned}
-\sum_{v\in\mathcal V}q(v)\log p_\theta(v)
&=-\sum_v q(v)\log q(v)
  +\sum_v q(v)\log\frac{q(v)}{p_\theta(v)}\\
&=H(q)+D_{\mathrm{KL}}(q\|p_\theta).
\end{aligned}
$$

第一行只是加上再减去 $\sum_v q(v)\log q(v)$；第二行识别出熵和 KL 散度。因为 $D_{\mathrm{KL}}(q\|p_\theta)\ge0$，总体 log loss 在 $p_\theta=q$ 时达到最小值。

$H(q)$ 与参数无关，因此无限数据和充分模型容量下，期望 log loss 在 $p_\theta=q$ 处最小。这是对数评分作为严格 proper scoring rule 的核心理由；它不表示有限样本、受限模型或特定优化器一定找到真实分布。

## 五、教师强制、生成与暴露偏移

到这里我们只说明了目标分布怎样分解，还没有说明训练和生成会访问哪些前缀。二者正是在这里出现差别。

训练时第 $t$ 项通常条件于真实前缀 $x_{<t}$，称为 teacher forcing。生成时前缀来自模型自己的历史采样：

$$
\hat x_t\sim p_\theta(\cdot\mid \hat x_{<t}).
$$

二者的条件分布形式相同，但所访问的前缀分布不同。训练数据附近很小的局部误差可能把采样轨迹带到罕见前缀，再累积新的误差。这种 distribution shift 不能靠“链式法则正确”自动消失，也不能只凭单步 NLL 判断长程生成质量。

## 六、归一化需要什么条件

固定长度概率树的归一化可以逐层求和得到；可变长度模型还多一个“是否最终停止”的问题。

若每个前缀上的条件分布都满足

$$
\sum_{v\in\mathcal V}p_\theta(v\mid h)=1,
$$

那么固定深度树上所有叶子概率之和为 1。对无界长度还需确保模型以概率 1 最终停止；否则可能存在“永不发 EOS”的概率质量。工程中常用最大长度强制截断，这会定义一个不同的生成程序，必须记录截断是模型事件、评测规则还是服务安全阀。

## 八、常见概念错误

1. **把 logit 当概率**：logit 需经 softmax 才归一化；温度或截断采样会改变部署分布。
2. **漏掉第一项或 EOS**：BOS 是条件上下文，是否作为预测目标必须单独声明。
3. **把 token 平均当序列似然**：平均 NLL 便于尺度比较，但完整序列概率对应总和。
4. **把模型族当目标**：RNN、CNN、Transformer 都可参数化同一因子化；“decoder-only”仍需写清 mask 和 targets。
5. **把训练分布当世界分布**：MLE 拟合的是数据管线诱导的经验分布，重复、筛选与采样权重都会进入目标。

## 九、AI 对象映射

| 数学对象 | 训练或推理中的对象 | 需要记录的合同 |
|---|---|---|
| $x_{<t}$ | 输入前缀 token IDs | tokenizer、BOS、文档拼接和 position IDs |
| $p_\theta(\cdot\mid x_{<t})$ | logits 经 softmax 得到的词表分布 | checkpoint、logit dtype、mask 和 vocabulary |
| $x_t$ | 第 $t$ 个监督标签或采样 token | shift、ignore index、loss mask 或 sampler |
| $\sum_t-\log p_\theta(x_t\mid x_{<t})$ | 序列 NLL | sum/mean 分母、padding 和有效 token 数 |
| EOS 因子 | 终止概率与生成长度 | EOS ID、停止规则、最大长度和截断语义 |

这些映射说明：链式法则是概率恒等式，但一个训练程序是否真的优化了所声明的序列概率，还取决于 tokenizer、shift、mask、reduction 和 EOS 合同。
