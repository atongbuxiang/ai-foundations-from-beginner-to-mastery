# 70.5 上下文学习与推理时计算 累计测验与研究审计门

> [!abstract] 验收目标
> 本门检查能否把 prompt、demonstrations、机制主张、reasoning paths、selector/search 和 context length 写成可复查对象。“会推理”“长上下文”“更多计算”均不得替代协议与证据。

## 一、进入条件

- 120 题中 A/B 至少 90% 独立完成；
- C/D/E 每层至少各 8 题能在新 prompt/任务/预算上完成；
- 已运行[[70.5 上下文学习与推理时计算 最小实验与复现说明]]；
- 能闭卷写 posterior predictive、OLS/ridge、一步 GD、pass-at-k 与完整树节点数。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜Prompt 条件事件（7 分）

给两份 rendered prompts 与 tokenizer 表：写 IDs、multi-token label score、parser，计算翻转率并指出选择偏差。

### Q2｜ICL 因子设计（7 分）

给 demonstrations：构造 correct/random/permuted/format-only，枚举顺序统计并设计 selector split。

### Q3｜ICL 理论（9 分）

手算 latent posterior、ridge/OLS 与一步 GD；区分行为、表示、机制等价，写 toy theorem 量词。

### Q4｜Induction 回路（7 分）

从 QK/OV 解释 $AB\ldots A\to B$，写 direct logit，设计 clean/corrupt/patch 与 matched ablation。

### Q5｜CoT 与 Faithfulness（7 分）

给 reasoning trace 和 bias cue：分 outcome/local/executable/causal，写三个干预与 token 对照。

### Q6｜多样本估计（8 分）

给 $n,c,k$ 和候选答案：算 majority、pass-at-k、coverage、chosen success、regret 与相关性边界。

### Q7｜Search 与预算（8 分）

给 branching/depth/step scores：算树节点、trajectory score，写七元搜索合同与成本向量。

### Q8｜长上下文（7 分）

给 length × position × task 矩阵：算 $T_{eff}$，指出声明窗口、位置效应与 synthetic 外推边界。

## 三、开卷复现部分（40 分）

### R1｜标准库重跑（10 分）

从空目录运行脚本，核对 9 checks、2 CSV、3 SVG，逐项手算 oracle。

### R2｜故意破坏合同（10 分）

依次删尾随空格、固定排列、破坏 label swap、改噪声、改 earlier-next token、让 trace 提 cue、换错误公式、漏 verifier cost、只看 end position；说明哪个断言先失败。

### R3｜真实小模型协议（10 分）

固定一个开源小模型，运行 prompt/order/label、重复 token、CoT sampling 与 length-position toy；保存实际 IDs/logprobs/candidates/成本。不得以大模型下载或付费 API 作为通过前提。

### R4｜研究预注册（10 分）

比较 direct、few-shot、CoT、self-consistency、Best-of-N 与 search：固定 policy，定义 token/FLOPs/latency、selector、faithfulness 与 long-context 矩阵，写不能识别的机制。

## 四、等级与通过线

| 等级 | 可观察能力 |
|---|---|
| 未通过 | 把可见 prompt、attention 图、agreement 或窗口上限当结论 |
| L1 | 会复述名词，但 scorer/估计量/预算仍混写 |
| L2 | 独立手算 posterior、OLS/GD、pass-at-k、树与 $T_{eff}$ |
| L3 | 做因子、干预、selector 与预算匹配实验 |
| L4 | 区分行为—表示—机制、coverage—selection 与 synthetic—现实外推 |

通过线：总分至少 80/100，且 Q1、Q3、Q5、Q6、Q7、R2 任一不得低于 50%。
