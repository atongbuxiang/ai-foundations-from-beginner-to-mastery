# 70.2 语言模型目标 累计测验与研究审计门

> [!abstract] 验收目标
> 本门不检查能否背出 GPT/BERT/T5 名称，而检查能否为任意 batch 从 clean object 开始，重建 sampler、input/target shift、query–key relation、loss mask、numerator/denominator，并判断一个能力主张的证据身份。

## 一、进入条件

- 8 份节点题库共 120 题，A/B 层至少 90% 标为 `independent`；
- C/D/E 每层至少各有 8 题能在新序列、新 mask 和新分母上独立完成；
- 已运行[[70.2 语言模型目标 最小实验与复现说明]]，能解释 9 checks 与 3 张实验图；
- 能不看笔记写出 CLM、MLM、span seq2seq 与 prefix LM 的概率对象。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜链式概率与 EOS（7 分）

给一棵深度 3 概率树：列出全部终止序列，验证叶概率和，计算一条序列的 NLL，并指出无界长度几乎必停还需什么条件。

### Q2｜CLM 四张量（8 分）

给含 BOS/EOS、两条变长样本和 padding 的 batch：写 inputs、labels、relation、loss mask、$N,D$；指出内部 shift 的 API 风险。

### Q3｜Packing 与分布式分母（7 分）

画两文档 block-causal relation；给三设备不同有效 token 数，比较局部均值再平均与全局 token mean。

### Q4｜MLM corruption 与 PLL（8 分）

给 mask rate 与三分支 recipe：写 $q_M,q_C$、期望计数与总体风险；构造逐位置 PLL，并解释为何不自动是 joint log-likelihood。

### Q5｜T5 span 可逆构造（8 分）

给长度 12 序列与三个 spans：构造 source、target、decoder shift；重建 clean 并核对 source/target 长度公式。

### Q6｜Prefix / UniLM 矩阵（7 分）

$P=3,S=4$ 时逐格写 relation；标出 prompt 与 suffix loss 区域，比较单栈与 encoder–decoder 信息路径。

### Q7｜Mixture 贡献账（8 分）

给 R/S/X 的 sample probability、target length、FLOP 和梯度范数：计算前三类 share，写总体风险并分析梯度冲突证据。

### Q8｜指标与证据（7 分）

审计“模型 A 的 PPL 更低，所以其 tokenizer、事实性与理解能力全面更强”；构造跨 tokenizer 反例，并给 claim 加 `I/T/A/E/H/O` 标签。

## 三、开卷复现部分（40 分）

### R1｜从空目录复现（10 分）

运行标准库脚本，核对 9 checks、3 CSV、3 SVG；手算概率树、Prefix 矩阵和 PPL/BPB，与输出逐项对齐。

### R2｜故意破坏合同（10 分）

依次注入 double shift、转置 prefix relation、把设备 mean 等权、重复 sentinel。每项先写预期失败，再定位第一个被破坏的不变量。

### R3｜真实框架审计（10 分）

任选一个开源 CLM/MLM/T5 checkpoint，用 3 条 toy samples 保存 tokenizer/config hash，打印 input IDs、labels、attention relation、loss mask、numerator、denominator；完成未来不变性或重建测试。

### R4｜研究预注册（10 分）

设计 CLM/MLM/span objective 比较：固定 raw data 与 tokenizer，分别按 target token 和 FLOPs 匹配，写主要 estimand、多个 seed、服务指标、下游任务与不能识别的反事实。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 用模型名代替目标，或把 attention mask/loss mask、PPL/PPPL 混写 |
| L1 | 能复述三类目标，但手算 shift、sentinel 或 denominator 仍错位 |
| L2 | 独立重建概率对象、sampler、relation、loss 与指标 |
| L3 | 以 oracle/反例审计框架实现并做预算匹配实验 |
| L4 | 分解多目标梯度与模型能力证据，提出可证伪反事实 |

通过线：总分至少 80/100，且 Q2、Q4、Q5、Q7、R2 任一不得低于该题 50%。
