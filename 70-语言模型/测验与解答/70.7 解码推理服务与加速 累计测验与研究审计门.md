# 70.7 解码推理服务与加速 累计测验与研究审计门

> [!abstract] 验收目标
> 本门检查能否从 raw logits 重建实际 rollout kernel，并把单请求生成映射到 prefill/decode/KV/scheduler 时间线。任何“质量更好”“完全精确”“更快”都必须注明对象层、算法前提、统计证据和服务负载。

## 一、进入条件

- 120 题中 A/B 至少 90% 独立完成；
- C/D/E 每层至少各 8 题能迁移到新 decoder/engine；
- 已运行[[70.7 解码推理服务与加速 最小实验与复现说明]]；
- 能闭卷写 temperature odds、top-$p$、EOS survival、grammar mask、KV bytes、speculative residual、TTFT/TBT/goodput。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜Logits 与 sampling（7 分）

手算稳定 softmax、temperature odds、entropy 方向与 inverse CDF；区分 raw、processed 与 sampled kernel。

### Q2｜Search 与 sequence score（7 分）

给小搜索树执行 greedy/beam，维护 active/completed，比较 raw 与 length-normalized score 并识别 unsafe early stop。

### Q3｜Truncation（7 分）

手算 top-$k$、top-$p$、typical、min-$p$ support、removed mass 和新概率；分析 processor 顺序。

### Q4｜停止与退化（7 分）

由 hazard 算 survival/finish event，处理跨-token stop，区分训练、概率、解码与服务根因。

### Q5｜Grammar 与 schema（8 分）

给自动机、token bytes 与概率，算 live state、valid set、$Z$；区分语法、语义、权限，并设计 dead-end 合同。

### Q6｜KV 与调度（8 分）

按 MHA/GQA/MQA 结构算 KV bytes/blocks，画 prefill/decode iteration，计算 TTFT/TBT 并识别 head-of-line。

### Q7｜Speculative（8 分）

手算 accept/reject/residual/TV，证明质量守恒，解释多 token 首拒绝与 exactness 边界。

### Q8｜联合证据（8 分）

给 request trace 与多配置表，算 latency/goodput/Pareto，区分分布、统计、字节复现，写可证伪实验合同。

## 三、开卷复现部分（40 分）

### R1｜标准库重跑（10 分）

从空产物目录运行脚本，核对 9 checks、3 CSV 与 3 SVG，并逐项用手算复核。

### R2｜故意破坏合同（10 分）

按实验说明破坏 softmax、序列分、support 边界、survival、grammar 归一化、KV head/block、residual、TTFT 起点与 Pareto；说明哪个断言首先失败。

### R3｜真实小服务（10 分）

选择公开小模型或本地 toy decoder，实现至少两种 sampler、stop、结构约束与 KV trace；回放不少于 100 请求的长度/arrival 分布，保存 token/finish/timing。不得把付费 API 作为通过前提。

### R4｜研究预注册（10 分）

比较两套 decoder/serving 配置：冻结 model 与 workload，预注册质量非劣界、TTFT/TBT SLO、goodput、显存、失败、seed/CI、warmup 与排除规则。

## 四、等级与通过线

| 等级 | 可观察能力 |
|---|---|
| 未通过 | 把 temperature、beam、KV、throughput 当几个孤立参数 |
| L1 | 会调用 API，但说不清 processor 顺序、finish reason 与指标起点 |
| L2 | 能手算核心公式并重建 token/request trace |
| L3 | 能证明 speculative 精确性，审计 grammar/KV/scheduler 边界 |
| L4 | 能在质量、tail、goodput、显存与成本约束下做预注册和因果诊断 |

通过线：总分至少 80/100，且 Q1、Q3、Q5、Q6、Q7、Q8、R2 任一不得低于 50%。
