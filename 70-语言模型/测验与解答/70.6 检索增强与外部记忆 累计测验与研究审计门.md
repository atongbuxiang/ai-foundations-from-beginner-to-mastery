# 70.6 检索增强与外部记忆 累计测验与研究审计门

> [!abstract] 验收目标
> 本门检查能否把 RAG 从“向量库 + prompt”还原为可推导、可复现、可归因的知识系统。任何最终正确率都不能替代 corpus、chunk、retrieval、ANN、rerank、context、generation 与 citation 的分层证据。

## 一、进入条件

- 120 题中 A/B 至少 90% 独立完成；
- C/D/E 每层至少各 8 题能迁移到新语料；
- 已运行[[70.6 检索增强与外部记忆 最小实验与复现说明]]；
- 能闭卷写潜文档边缘化、BM25、InfoNCE 梯度、RRF、Recall/MRR/nDCG 与 citation 两分母。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜潜变量与记忆（7 分）

给文档权重与条件答案概率，算完整/截断边缘概率，区分 sequence/token/concat，并标 $A_C,A_R,A_X,A_Y$。

### Q2｜数据与索引合同（7 分）

给文件、span、窗口与 ACL，算 chunk 数/coverage，写 doc→chunk→vector→citation 的正反向血缘。

### Q3｜检索与融合（8 分）

手算 BM25、dense dot、RRF；用 union oracle 区分互补覆盖和融合排序。

### Q4｜ANN 与重排（8 分）

给 exact/ANN/candidate/rerank 列表，算 ANN recall 与 task recall，证明候选上界并列延迟账。

### Q5｜Retriever 训练（8 分）

手算 softmax loss/gradient，比较三类 negatives，识别 false negative 与 index lag。

### Q6｜Context 与引用（8 分）

做预算选择，区分 relevance/support/factuality/attribution/faithfulness，算 citation correctness/completeness。

### Q7｜多跳与工具（7 分）

把两跳问题写成状态机、证据图和工具 schema；定义 stop、loop 与 oracle first-hop。

### Q8｜评估地图（7 分）

算 Recall/MRR/nDCG 与 RGA joint，选择 oracle 干预并写成本匹配与 paired bootstrap。

## 三、开卷复现部分（40 分）

### R1｜标准库重跑（10 分）

从空产物目录运行脚本，核对 9 checks、2 CSV、3 SVG，并逐项手算 oracle。

### R2｜故意破坏合同（10 分）

按实验说明破坏归一化、chunk 步长、RRF、ANN 分母、梯度、citation 分母、预算和联合事件，说明哪项断言首先失败。

### R3｜真实小语料系统（10 分）

自建至少 50 文档、20 queries 的可公开小语料；实现 lexical 与 dense/exact/ANN 至少两路，保存 span/ACL/version、候选 IDs、gold 与引用。不得把付费 API 作为通过前提。

### R4｜研究预注册（10 分）

比较两套 RAG：冻结 corpus/chunk、定义 relevance/support、设 K/latency/token 预算，预注册 oracle、切片、人工审计和最早失败层。

## 四、等级与通过线

| 等级 | 可观察能力 |
|---|---|
| 未通过 | 用“RAG 幻觉”概括所有失败 |
| L1 | 会搭流程，但分母、版本与 gold 单位混写 |
| L2 | 能手算核心公式并重建全链路 IDs |
| L3 | 能做 exact/ANN、gold-context、冲突与负样本审计 |
| L4 | 能在成本约束下做联合评估、因果干预和根因优先级 |

通过线：总分至少 80/100，且 Q2、Q4、Q5、Q6、Q8、R2 任一不得低于 50%。
