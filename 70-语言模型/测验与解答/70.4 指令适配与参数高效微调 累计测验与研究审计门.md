# 70.4 指令适配与参数高效微调 累计测验与研究审计门

> [!abstract] 验收目标
> 本门检查能否从 messages 编译到 loss，从 trainable set 推到内存/函数，再从多个 checkpoints 重建合并。参数百分比、4-bit、rank 和平均 benchmark 均不得替代实际对象。

## 一、进入条件

- 120 题中 A/B 至少 90% 独立完成；
- C/D/E 每层至少各 8 题能在新 shape/序列/config 上完成；
- 已运行[[70.4 指令适配与参数高效微调 最小实验与复现说明]]；
- 能不看笔记写出 SFT $N/D$、LoRA 两因子梯度和 TIES 三步。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜消息编译合同（7 分）

给 system/user/tool 多轮 messages 与模板规则：编译 text/IDs，标 train/infer 边界，构造 escaping 与 duplicate-special 反例。

### Q2｜SFT 四张量（8 分）

给两段多轮 packed conversations：写 inputs、labels、relation、response mask、$N,D$；比较 per-token/turn/conversation 与分布式 reduction。

### Q3｜指令数据分布（7 分）

给 task/template/conversation/length/retention：算 task、conversation、target 与 selected shares；设计 unseen-task split 和 synthetic feedback 审计。

### Q4｜Full/Freeze 与遗忘（7 分）

写 trainable-set 更新；由 base/tuned 新旧 risk 算 trade-off；构造小参数大功能变化，指出 checkpoint selection bias。

### Q5｜LoRA（9 分）

给 $m,n,r,A,B,s,G,x$：算参数量、rank、$\Delta W x$、$\nabla_A,\nabla_B$、首步和 merge；讨论因子尺度不唯一。

### Q6｜QLoRA 总账（7 分）

给 codes/metadata/adapter/activation/temp 与 dtypes：算 bytes，区分 storage/compute/optimizer，说明 runtime adapter 与 merge-requantize。

### Q7｜PEFT 接口（7 分）

给 $d,L,p,r$：算 prompt/prefix/adapter 状态；在 block 图标 LoRA/IA3；比较 context、KV、extra FLOPs、merge 与 mixed-task serving。

### Q8｜合并与证据（8 分）

给共同 base 与三个 checkpoints：算 soup/task vectors/TIES，构造 permutation 反例，写逐任务/OOD/安全矩阵。

## 三、开卷复现部分（40 分）

### R1｜标准库重跑（10 分）

从空目录运行脚本，核对 9 checks、3 CSV、3 SVG；手算全部关键 oracle。

### R2｜故意破坏合同（10 分）

依次注入 duplicate BOS、double shift、B=A=0、漏 quant metadata、错 base task vector、hidden permutation；说明哪个断言最先失败。

### R3｜真实框架微型实验（10 分）

选一个开源小模型，固定 repository revision；打印 template IDs、labels/mask、LoRA target/grad、allocated/peak；验证 merged/unmerged logits。不得下载或训练大模型作为通过前提。

### R4｜研究预注册（10 分）

比较 full、LoRA、QLoRA 与另一 PEFT：固定 data/template/targets/FLOPs/search；定义 new/old/OOD/safety、内存/延迟、selection 与不能识别的反事实。

## 四、等级与通过线

| 等级 | 可观察能力 |
|---|---|
| 未通过 | 把模型名、rank、4-bit 或参数比例当完整方法 |
| L1 | 能复述方法名，但 shift/shape/bytes/坐标仍错 |
| L2 | 独立手算序列、梯度、内存、PEFT 与合并 |
| L3 | 用框架 oracle、profile 与预算匹配完成对照 |
| L4 | 识别 selection、功能干扰、OOD/安全和外推边界 |

通过线：总分至少 80/100，且 Q2、Q5、Q6、Q8、R2 任一不得低于 50%。
