# 70.3 预训练数据工程 累计测验与研究审计门

> [!abstract] 验收目标
> 本门不检查是否会背数据集名称，而检查能否把一个训练 target 追溯到 source asset，并在每个 transform 上重建选择分布、相似度对象、边界、抽样单位、路径、版本和证据限度。

## 一、进入条件

- 8 份节点题库共 120 题，A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题可在新对象上独立完成；
- 已运行[[70.3 预训练数据工程 最小实验与复现说明]]并解释 9 checks、3 CSV 与 3 图；
- 能不看笔记区分 asset/capture/document/token/target，candidate/pair/cluster，unique/draw/effective token。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜来源、单位与治理（7 分）

给论坛 thread/post、WARC record 与 token shard：设计 IDs/parent edges；区分 access、content rights、privacy 与 use approval；说明删一位作者时受影响单位。

### Q2｜解析、过滤与选择分布（8 分）

给三群体 source share、parser success、LID 与 filter retention：逐级计算 selected distribution；构造 stage order 不交换例；写 macro/worst-group error。

### Q3｜去重与聚类（8 分）

手算 shingle Jaccard/containment，证明 MinHash 恒等式；由 $b,r,s$ 算候选概率；构造 threshold chaining，并比较三种 representative policy。

### Q4｜污染与时间（7 分）

给 detector recall/FPR/base rate，算阳性后验和校正 prevalence；画 pretrain/SFT/RAG 三阶段 cutoff；说明 overlap、memorization 与 causal advantage 的断点。

### Q5｜Mixture 四份额（8 分）

给 domain sizes、temperature、平均长度、loss fraction、每 token FLOPs 与 gradient norm：计算 document/token/target/compute share，并写目标 risk 与 importance weights。

### Q6｜Packing 四合同（8 分）

对三文档做 FFD packing，写 query–key relation、position IDs、labels 与 loss mask；推导 global $N/D$，说明 packed/unpacked 等价的充分条件。

### Q7｜Curriculum 与持续预训练（7 分）

展开两次非交换梯度更新；为 DAPT/TAPT/replay 固定总预算，画新域—旧域 Pareto 轨迹；指出 checkpoint selection bias。

### Q8｜版本与有效 token（7 分）

给 raw→parse→filter→dedup→draw→pack 计数：命名每个 ratio，计算 $T_{eff}$ 与 mean NLL；设计 content-addressed manifest 和一次删除影响遍历。

## 三、开卷复现部分（40 分）

### R1｜从空目录复现（10 分）

运行标准库脚本，核对 9 checks、3 CSV、3 SVG；手算 selection、MinHash、Bayes、mixture、relation、AB/BA 与 $T_{eff}$。

### R2｜故意破坏合同（10 分）

依次注入 normalization 变化、漏 LSH verification、跨文档 attention、boundary target、manifest 内容变更但沿用旧 hash。每项先写预期失败，再定位第一个失效不变量。

### R3｜真实小管线（10 分）

选 30—100 个可合法使用的公开文档，保存 capture/rights evidence；执行 parse/filter/dedup/tokenize/pack，输出 keep/reject reason、cluster map、三份额、边界测试和 lineage DAG。不要求训练大模型。

### R4｜研究预注册（10 分）

设计两套数据配方比较：固定 tokenizer、unique/effective targets、FLOPs、模型/optimizer 与 evaluation cutoff；预注册主要 estimand、切片、detectors、多个 seeds、mixture search compute、失败处理与不可识别反事实。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 用“清洗后 1T tokens”代替对象、分布、版本和分母 |
| L1 | 能列 pipeline，但 candidate/pair/cluster 或 unique/draw/target 仍混淆 |
| L2 | 能独立手算选择、去重、污染、mixture、packing 与路径 |
| L3 | 能以 oracle/反例测试实现，并做预算与时间截止匹配 |
| L4 | 能建立 provenance/删除影响图，审计因果主张与群体外推 |

通过线：总分至少 80/100，且 Q2、Q3、Q5、Q6、R2 任一不得低于该题 50%。
