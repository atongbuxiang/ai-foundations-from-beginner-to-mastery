# 70.5 上下文学习与推理时计算 MOC

> [!abstract] 卷终目标
> 把 prompt 写成精确条件事件，把 demonstrations 拆成内容、映射、格式、选择和顺序；区分 ICL 的行为、理论与机制证据；再把可见推理、多样本、搜索、verifier 和长上下文统一放入预算与因果审计。最终能判断“模型会推理”究竟由什么实验支持。

## 一、课程主线

本卷固定部署权重，追踪行为怎样随上下文和推理算法变化：

~~~mermaid
flowchart LR
    Q["task + query"] --> P["template + exact token prefix"]
    D["demonstrations"] --> P
    P --> I["ICL behavior"]
    I --> M["Bayes / estimator / optimizer / circuit hypotheses"]
    I --> R["visible reasoning paths"]
    R --> S["sampling / search / verifier"]
    C["long context + evidence position"] --> I
    S --> E["answer + evidence + cost audit"]
~~~

## 三、五本贯穿账

| 账本 | 必须记录 | 不允许的替代 |
|---|---|---|
| 条件账 | bytes、template、IDs、label scorer、parser | 只贴可见 prompt |
| 示例账 | pool、selector、内容、标签、顺序、位置、$K/T$ | 只写 few-shot 数 |
| 机制账 | 行为、表示、干预、构造、模型族与量词 | 用 attention 图当证明 |
| 推理账 | path、canonicalizer、verifier、search、stop | 用“多想”概括算法 |
| 预算证据账 | token/FLOPs/calls/latency/memory、CI、失败 | 只报最佳准确率 |

## 五、卷终能力

通过本卷意味着能：

1. 从 bytes/IDs 计算多 token label 分数并设计 prompt sensitivity；
2. 分离 instruction、format、label space、mapping、selection 与 order；
3. 推导 latent-task posterior、OLS/ridge 与一步 GD；
4. 从 QK/OV 解释 induction circuit，并区分相关/因果/构造；
5. 分离答案正确、步骤有效、可执行与 faithfulness；
6. 手算 self-consistency、pass-at-k、coverage 与 selection regret；
7. 把 test-time scaling 写成搜索七元组与多维成本向量；
8. 用 length × position × task × distractor 定义有效上下文。
