# 无损编码、典型集与渐近等分性

> [!abstract] 本章主问题
> 对有限 alphabet 上的 iid source，sample surprise 满足大数定律：$-\frac1n\log_2p(X^n)\to H_2(X)$。因此几乎全部 probability mass 集中在约 $2^{nH}$ 个、每个 probability 约 $2^{-nH}$ 的 typical sequences 上。rate $R>H$ 时可枚举 typical set 实现 vanishing-error fixed-length compression；$R<H$ 时任何至多 $2^{nR}$ 个 codewords 覆盖的 probability mass 都趋于零。单符号 variable-length prefix code 有 $H\le L<H+1$，Huffman 在给定 symbol probabilities 下最优；block/arithmetic/universal coding 则把 integer overhead 和 model mismatch 进一步摊薄。

## 学习目标

完成本节后，你应当能够：

1. 区分 nonsingular、uniquely decodable、prefix-free 和 fixed-length codes；
2. 陈述 Kraft–McMillan inequality 与平均码长 bounds；
3. 手工执行 Huffman algorithm，并解释其 exchange/induction 最优性；
4. 从 LLN 证明 iid AEP；
5. 定义 weak typical set 并证明 probability、单点 probability 与 cardinality bounds；
6. 证明 fixed-length almost-lossless source coding 的 achievability 与 converse；
7. 区分“most probable sequence”与“typical set 承担大部分 mass”；
8. 解释 arithmetic coding、entropy rate、Shannon–McMillan–Breiman 与 universal coding 的角色；
9. 把 LM NLL/perplexity 转为 compression rate，同时审计 tokenizer、EOS、model cost 和 distribution shift；
10. 区分 lossless source coding、lossy rate–distortion 与 channel coding。

> 3. Huffman algorithm 为什么在给定单符号概率下最优，它与 Shannon code 的存在性界有何不同？

> 5. typical set 的 probability、单点 probability 与 cardinality 三条性质怎样共同成立？
> 6. 为什么 $R>H$ 可实现 vanishing-error almost-lossless compression，而 $R<H$ 不可能？
> 7. language-model NLL 作为码率时为什么必须加入 tokenizer、EOS、model/protocol cost 与 distribution shift 审计？

## 零、四类 code 不要混

设 source alphabet $\mathcal X$，binary code $c:\mathcal X\to\{0,1\}^*$。

### 0.1 Nonsingular

不同 source symbols 有不同 codewords。单独看到一个完整 codeword 时可区分，但 concatenation 可能歧义。

例如

$$
a\mapsto0,\quad b\mapsto01
$$

是 nonsingular；若没有外部分隔，bit string `01` 可被读为 $b$ 或 $a$ 后跟未知 continuation。

### 0.2 Uniquely decodable

任意有限 source sequence 的 concatenated bit string 都有唯一解析。它允许某个 codeword 是另一个前缀，只要全局仍无歧义，但检测和证明更难。

### 0.3 Prefix-free

没有 codeword 是另一个 codeword 的前缀。它自动 uniquely decodable，并可即时 decoding。Huffman code 属于此类。

### 0.4 Fixed-length block code

把 $n$ 个 source symbols 映射到固定 $m$ bits；rate 为 $R=m/n$ bits/source-symbol。若 codebook 不够覆盖所有 source sequences，允许小 error/overflow event，称 almost lossless。

## 一、Kraft–McMillan 与平均长度

### 1.1 Kraft inequality

二进制 prefix lengths 满足

$$
\sum_x2^{-\ell(x)}\le1.
$$

反过来，任何满足该式的 positive integer lengths 都可构造 prefix code。

### 1.2 McMillan inequality

更广的 uniquely decodable codes 也满足同一 inequality。证明可考察 $n$ 个 codewords concatenation 的长度 generating sum：

$$
\left(\sum_x2^{-\ell(x)}\right)^n
=\sum_{x^n}2^{-\sum_i\ell(x_i)}.
$$

unique decodability 控制每个总长度上的 distinct bit strings 数量；取 $n$ 次根再令 $n\to\infty$ 得 sum 不超过 $1$。

### 1.3 Entropy lower bound

令

$$
K=\sum_x2^{-\ell(x)}\le1,
\qquad
q(x)=\frac{2^{-\ell(x)}}K.
$$

则

$$
L=E_P\ell(X)
=H_2(P)+D_2(P\|Q)-\log_2K
\ge H_2(P).
$$

### 1.4 Shannon code

取

$$
\ell(x)=\lceil-\log_2p(x)\rceil
$$

满足 Kraft，并给

$$
H_2(P)\le L<H_2(P)+1.
$$

这是一条 existence/constructive upper bound，但不保证单 symbol prefix code 最短；Huffman 会给 exact optimum。

## 二、Huffman coding

### 2.1 Algorithm

反复执行：

1. 选当前 probability 最小的两个 nodes；
2. 合并为 parent，probability 为两者之和；
3. 对缩小后的 alphabet 重复；
4. 从 root 回溯，在两条 branches 标 $0/1$。

### 2.2 手算例子

设

$$
p=(0.4,0.3,0.2,0.1).
$$

合并 $0.1+0.2=0.3$；现在 $(0.4,0.3,0.3)$，合并两个 $0.3$ 得 $0.6$；再与 $0.4$ 合并。一个 Huffman length set 为

$$
(1,2,3,3).
$$

平均长度

$$
L=0.4(1)+0.3(2)+0.2(3)+0.1(3)=1.9\text{ bits},
$$

而 $H_2(P)\approx1.846$。

### 2.3 为什么 greedy 合法

最优 prefix tree 可调整为：

- probability 最小的两个 symbols 位于最大 depth；
- 它们是 siblings。

理由是 exchange argument：若低 probability symbol 比高 probability symbol 更浅，交换两者不会增加、且通常减少 expected length。最深 leaves 可成 sibling，否则局部重接不增 cost。

把这两个 siblings 合成 probability $p_i+p_j$ 的 super-symbol，原问题的 expected length 等于缩小问题的 expected length 加 $p_i+p_j$。于是 optimal substructure + induction 证明 Huffman greedy 最优。

### 2.4 Huffman 的边界

- 对已知 single-symbol distribution、binary prefix codes 最优；
- 不一定达到 entropy，因为 lengths 为 integers；
- distribution 估错会有 mismatch redundancy；
- alphabet/树的存储成本通常未计入 $L$；
- sequence dependence 未用到时，会浪费 conditional structure。

## 三、从单 symbol 到 block

对 iid $X_1,\ldots,X_n$，

$$
p(x^n)=\prod_{i=1}^np(x_i),
$$

$$
-\log_2p(x^n)=\sum_i-\log_2p(x_i),
$$

$$
H(X^n)=nH(X).
$$

把 $x^n$ 当 super-symbol 做 Shannon code：

$$
nH(X)\le L_n<nH(X)+1.
$$

每 source symbol：

$$
H(X)\le L_n/n<H(X)+1/n.
$$

整数 overhead 消失，但 block alphabet 大小为 $|\mathcal X|^n$，直接 codebook 不可扩展。AEP 解释哪些 blocks 真正需要重点编码。

## 四、AEP：sample surprise 的大数定律

令 $X_i$ iid，finite alphabet，$H_2(X)<\infty$。定义 information random variables

$$
Z_i=-\log_2p(X_i).
$$

它们 iid 且

$$
E[Z_i]=H_2(X).
$$

又因

$$
-\frac1n\log_2p(X^n)
=\frac1n\sum_{i=1}^nZ_i,
$$

由 weak LLN：

$$
\boxed{
-\frac1n\log_2p(X^n)
\xrightarrow{P}H_2(X).
}
$$

等价地，对任意 $\varepsilon>0$：

$$
P\left(
2^{-n(H+\varepsilon)}
\le p(X^n)
\le2^{-n(H-\varepsilon)}
\right)\to1.
$$

这叫 asymptotic equipartition property：高概率 sequence 并非完全等概率，而是在指数尺度上接近 $2^{-nH}$。

## 五、weak typical set

定义

$$
\mathcal T_\varepsilon^{(n)}
=\left\{x^n:
\left|-\frac1n\log_2p(x^n)-H(X)\right|
\le\varepsilon
\right\}.
$$

### 5.1 高 probability

AEP 直接给

$$
P(X^n\in\mathcal T_\varepsilon^{(n)})\to1.
$$

### 5.2 每个 typical sequence 的 probability

若 $x^n\in\mathcal T$：

$$
2^{-n(H+\varepsilon)}
\le p(x^n)
\le2^{-n(H-\varepsilon)}.
$$

### 5.3 Cardinality upper bound

因为 total probability 不超过 $1$，且每个 typical sequence 至少有 $2^{-n(H+\varepsilon)}$：

$$
|\mathcal T_\varepsilon^{(n)}|
2^{-n(H+\varepsilon)}\le1,
$$

故

$$
\boxed{|\mathcal T_\varepsilon^{(n)}|\le2^{n(H+\varepsilon)}.}
$$

### 5.4 Cardinality lower bound

对足够大 $n$，令 typical probability 至少 $1-\delta$。每个 typical sequence 至多有 $2^{-n(H-\varepsilon)}$，所以

$$
1-\delta
\le|\mathcal T|2^{-n(H-\varepsilon)},
$$

即

$$
\boxed{|\mathcal T_\varepsilon^{(n)}|\ge(1-\delta)2^{n(H-\varepsilon)}.}
$$

所以“约 $2^{nH}$ 个”是 exponential-order statement。

## 六、most probable 不等于 typical

令 Bernoulli$(p)$ 且 $p<1/2$。全零 sequence 的 probability

$$
(1-p)^n
$$

通常是单个最高，但其 empirical one-frequency 为 $0$，离 typical frequency $p$ 很远。随着 $n$ 增大，全零事件 probability 仍趋于 $0$。

typical set 包含约 $np$ 个 ones 的巨大数量 sequences；每个单独不一定最高，但 combinatorial multiplicity 让它们承担几乎全部 probability mass。

> [!warning] “典型”不是“看起来最普通”
> typicality 是相对于指定 source distribution、block length 和 tolerance 的 probability statement，不是人类语义判断，也不是找单个 mode。

## 七、fixed-length almost-lossless source coding theorem

对 iid finite-alphabet source，entropy $H=H_2(X)$ 是 vanishing-error fixed-length compression 的临界 rate。

### 7.1 Achievability：$R>H$

选 $\varepsilon>0$ 使 $H+\varepsilon<R$。对足够大 $n$：

$$
|\mathcal T_\varepsilon^{(n)}|
\le2^{n(H+\varepsilon)}<2^{nR}.
$$

给每个 typical sequence 一个 distinct $nR$-bit index；atypical sequences 输出 error/overflow symbol。decoding error：

$$
P_e\le P(X^n\notin\mathcal T_\varepsilon^{(n)})\to0.
$$

所以任意 $R>H$ 可实现 vanishing error。

### 7.2 Converse：$R<H$

任意 $nR$-bit code 最多无错区分 $2^{nR}$ 个 source sequences，记 correct set $\mathcal C_n$。选 $\varepsilon>0$ 使 $R<H-\varepsilon$：

$$
\begin{aligned}
P(X^n\in\mathcal C_n)
&\le P(X^n\notin\mathcal T_\varepsilon^{(n)})
+P(X^n\in\mathcal C_n\cap\mathcal T)\\
&\le o(1)+|\mathcal C_n|2^{-n(H-\varepsilon)}\\
&\le o(1)+2^{-n(H-\varepsilon-R)}\to0.
\end{aligned}
$$

因此 error probability 趋于 $1$。在 iid finite setting，低于 entropy 不只是“有一点误差”，而是 asymptotically 几乎总失败。

### 7.3 与 variable-length theorem 的区别

- variable-length zero-error：平均 length 受 $H$ 控制；
- fixed-length almost-lossless：固定 rate，允许 rare block error；
- AEP 直接支撑后者；
- 具体 finite-$n$ redundancy/error 需要 finite-blocklength analysis，不能只写 $n\to\infty$。

## 八、arithmetic coding：不枚举巨型 block alphabet

arithmetic/range coding 按 sequence probability 逐步缩小 $[0,1)$ interval；最终 interval width 约为 $q(x^n)$，选择其中一个 binary fraction，code length 约

$$
-\log_2q(x^n)+O(1).
$$

优势：

- 能利用 autoregressive conditional probabilities；
- overhead 以 sequence 为单位而非每 token；
- 不需要显式构造 $|\mathcal X|^n$ 个 block codewords。

边界：finite precision、renormalization、termination、model table transmission 和 malformed-stream security 都是工程协议；概率模型越好只保证期望 code length 越短，不保证实现吞吐/延迟最好。

## 九、mismatched 与 universal coding

若真实 source 为 $P$，编码器使用 $Q$：

$$
E_P[-\log_2q(X)]
=H_2(P)+D_2(P\|Q).
$$

KL 是每 symbol asymptotic model mismatch cost。

现实中 $P$ 未知。universal code 要同时学习/适应 source 与编码数据；total description 通常包含：

$$
L_{total}
=L(model)+L(data\mid model)+L(protocol).
$$

只报告 data NLL 而忽略 model parameters、tokenizer/codebook 和 side information，不是完整 MDL。Lempel–Ziv、Krichevsky–Trofimov 和 Bayesian/prequential codes 是不同 universal 路线，正式展开留 INFO-10。

## 十、stationary sources 与 entropy rate

对 dependent sequence，不能写 $H(X^n)=nH(X_1)$。定义 entropy rate

$$
\mathcal H
=\lim_{n\to\infty}\frac1nH(X_{1:n}),
$$

若极限存在。stationary process 还常有

$$
\mathcal H
=\lim_{n\to\infty}H(X_n\mid X_{1:n-1}).
$$

Shannon–McMillan–Breiman theorem 在 stationary ergodic 等条件下把 AEP 扩展为

$$
-\frac1n\log p(X_{1:n})\to\mathcal H
$$

（具体收敛方式和 regularity 依 theorem version）。非 stationary、non-ergodic mixture 或 heavy-memory source 不能机械使用 iid proof。

## 十一、AI 与语言模型接口

### 11.1 LM 是概率模型，也是潜在 compressor

autoregressive LM 给

$$
q_\theta(x_{1:T})
=\prod_tq_\theta(x_t\mid x_{<t}).
$$

配合 arithmetic coding，可得到接近

$$
-\log_2q_\theta(x_{1:T})
$$

bits 的 data code。held-out bits per token/byte 是 prediction quality 的 operational measure。

### 11.2 不能忽略 tokenizer

per-token rate 随 tokenizer 变化。跨模型应至少同时报告：

- same raw corpus；
- bytes/characters denominator；
- EOS、normalization 和 unknown/byte fallback；
- 是否传输 tokenizer/codebook；
- model parameter cost 是否计入。

[[S-2018-Su-5476-最小熵原理词库构建]]中的 per-character information 正好说明归约单位会改变词库选择目标。

### 11.3 训练集压缩不代表泛化

大模型可 memorise data。真正 evidence 应来自 independent held-out/prequential coding；若 test contamination、重复网页或 prompt leakage 存在，短码长可能只是记忆。

### 11.4 Typical sampling 不是 source-coding typical set 的自动实现

生成中的 “typical decoding”、top-$p$、temperature 是 decoding heuristics。它们修改 sampling distribution，不能仅凭名称视为从 Shannon typical set uniform sampling；必须写具体 score 和 normalization。

## 十二、lossless、lossy 与 channel coding

| 问题 | 输入/输出 | 允许什么误差 | 核心极限 |
|---|---|---|---|
| lossless source coding | source sequence → bits → exact sequence | zero 或 vanishing block error | entropy / entropy rate |
| lossy source coding | source → reconstruction | distortion $D$ | rate–distortion $R(D)$ |
| channel coding | message → noisy channel → message | decoding error | channel capacity |

把 JPEG/embedding 压缩称作“达到 entropy”通常不完整，因为它们允许 distortion；这属于[[率失真、信息瓶颈与最小描述长度]]。

## 十三、常见错误与纠正

| 错误说法 | 问题 | 纠正 |
|---|---|---|
| “Huffman 总达到 entropy” | integer lengths 带冗余 | 只有 dyadic probabilities 可精确达到 |
| “prefix 是唯一可译码的必要条件” | prefix 只是易用充分条件 | 所有 UD code 满足 McMillan |
| “AEP 表示所有 sequences 等概率” | 只对 high-mass typical set 的指数尺度 | atypical/finite-$n$ 仍存在差异 |
| “最高概率 sequence 就代表典型集” | mode 可 atypical，mass 在大量 sequences | 区分 point probability 与 set mass |
| “rate 低于 H 还能靠更聪明算法无损压缩” | 违反 iid asymptotic converse | 改变 source model、允许 distortion 或付 error |
| “PPL 直接等于压缩率” | 底数、tokenizer、协议和 model cost 未写 | 转 bits/byte 并给完整 coding setup |
| “训练 NLL 低表示 universal compression 好” | overfit/contamination/model cost | 用 held-out/prequential total length |

## 十四、推导与实现审计清单

1. code 是 prefix、UD、fixed-length 还是有外部分隔？
2. source 是 iid、stationary ergodic 还是任意 dependent？
3. log base、rate denominator 和 block error 定义是什么？
4. Kraft/McMillan applicability 与 codebook 是否明确？
5. Huffman probabilities 是真实、估计还是部署 distribution？
6. typicality 的 $n,\varepsilon$ 和 convergence statement 是否写清？
7. most-probable 与 high-total-mass set 是否混淆？
8. theorem 是 asymptotic 还是有 finite-blocklength certificate？
9. arithmetic coder 的 termination/precision/model transmission 是否计入？
10. tokenizer、EOS、bytes/characters 和 model cost 是否统一？
11. held-out data 是否独立且无 contamination？
12. 问题是否其实允许 distortion，应转 rate–distortion？

## 十五、你现在应能独立重建的主链

单 symbol：

$$
\text{Kraft–McMillan}
\Longrightarrow
H_2(X)\le L<H_2(X)+1.
$$

iid block：

$$
-\frac1n\log_2p(X^n)
=\frac1n\sum_i[-\log_2p(X_i)]
\xrightarrow{P}H_2(X).
$$

因此

$$
P(X^n\in\mathcal T_\varepsilon^{(n)})\to1,
\qquad
|\mathcal T_\varepsilon^{(n)}|\doteq2^{nH}.
$$

枚举 typical set 得 $R>H$ 的 achievability；任意 $2^{nR}$ codebook 与 typical point-probability bound 给 $R<H$ 的 converse。至此 INFO-01—06 已形成“信息量—依赖—信息流—编码极限”的第一条完整信息论主链。
