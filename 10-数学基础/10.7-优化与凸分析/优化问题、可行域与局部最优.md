# 优化问题、可行域与局部最优

> [!abstract] 本章主问题
> 优化不是“调用一个 optimizer”，而是先定义一个五元契约：变量、目标、domain、约束和解概念。`loss 下降`、`梯度很小`、`约束近似满足`和`population risk 良好`是四类不同证据；只有问题和证书写全，算法输出才有可解释含义。

## 学习目标

完成本章后，你应当能够：

1. 把自然语言任务写成标准优化形式；
2. 区分 decision variable、data、hyperparameter、randomness 与 state；
3. 区分 effective domain、constraint set 与 feasible set；
4. 定义 feasible/infeasible、bounded/unbounded、infimum/minimum 与 argmin；
5. 解释最优值存在与最优解被取得是两件事；
6. 严格定义 global/local/strict/isolated local minimizer；
7. 区分 stationary point、local minimizer、saddle 与 constrained boundary solution；
8. 使用 Weierstrass theorem 和 coercivity 给出存在性证书；
9. 区分 objective gap、solution distance、stationarity residual 与 feasibility residual；
10. 解释为什么它们之间的换算需要 convexity、strong convexity 或 error bound；
11. 判断 reformulation、relaxation、regularization、penalty 和 surrogate 是否保持原解；
12. 把 empirical、population、approximation 与 optimization error 分层；
13. 为监督学习、鲁棒训练、稀疏学习、VAE 与 bilevel learning 写 problem contract；
14. 审计“训练收敛”“找到最优”“模型更好”等过强表述；
15. 为后续凸集、KKT、对偶与算法章节建立统一符号。

> [!question] 初学者读完必须能回答
> 1. decision variable、data、hyperparameter、randomness 与 algorithm state 为什么必须分开？
> 2. effective domain、constraint set 与 feasible set 各由什么决定？
> 3. infimum、minimum、argmin、unbounded 与 infeasible 分别描述什么状态？
> 4. global/local/strict/isolated minimizer 与 stationary/saddle/boundary solution 有何区别？
> 5. compactness、lower semicontinuity、coercivity 与 Weierstrass 怎样给出存在性证书？
> 6. objective gap、solution distance、stationarity residual 与 feasibility residual 何时可以换算？
> 7. optimization、approximation、estimation/generalization 与 deployment error 为什么不能互相替代？

## 零、先看一个会“训练成功却回答错问题”的例子

假设二分类模型输出 $p_\theta(y=1\mid x)$，团队写下

$$
\min_\theta
\frac1n\sum_{i=1}^n
-\log p_\theta(y_i\mid x_i).
$$

optimizer 把训练 NLL 降到接近 0。能否宣布“问题已解决”？不能，因为至少还有以下未写对象：

1. $\theta$ 是全部权重，还是只训练 LoRA/最后一层？
2. data preprocessing、class weights、augmentation 和 random seed 是否固定？
3. 是否有 norm、latency、fairness 或 memory constraint？
4. target 是 training NLL、validation NLL、calibration 还是部署 utility？
5. 若数据可分，logistic loss 的 infimum 可能是 0，但有限参数处没有 minimizer；
6. 小训练 NLL 不说明 population risk 小；
7. 梯度小可能来自 saturation、数值下溢或不良尺度；
8. 不同参数可因 permutation/scaling symmetry 表示同一个函数。

优化理论的第一课不是更聪明的更新式，而是拒绝用一个模糊动词“优化”掩盖这些对象。

先用下图回答一个视觉问题：**完整优化契约、最优值的存在状态和模型落地误差为什么必须分成三层？**

**怎样读图。** A 从变量一路核对到解概念，并把数据与随机性视为 problem instance 的组成；B 同时检查最优值是否有限、是否被可行点取得；C 只在各自层内解释证据，不从训练 loss 或梯度残差直接跳到 population/deployment 结论。

**适用边界（图没有证明什么）。** 五项契约是建模清单，不自动保证问题 well-posed、可解或算法收敛；三条曲线只是状态示意；objective gap 与参数距离的换算需要 strong convexity/error bound 等结构，多参数对称也会让参数距离失去函数层意义。

## 一、标准形式：变量、目标和约束

有限维 minimization problem 的常见标准形式是

$$
\begin{aligned}
\underset{x\in\mathbb R^n}{\operatorname{minimize}}
&\quad f_0(x)\\
\text{subject to}
&\quad f_i(x)\le0,
\quad i=1,\ldots,m,\\
&\quad h_j(x)=0,
\quad j=1,\ldots,p.
\end{aligned}
$$

这里：

- $x$：decision variable；
- $f_0$：objective/cost；
- $f_i$：inequality constraint functions；
- $h_j$：equality constraint functions；
- 数据、超参数和阈值被视为固定 problem instance 的一部分。

最大化 $u(x)$ 可写为最小化 $-u(x)$。这只是符号转换；若论文同时使用 reward、loss 和 energy，必须明确符号，不能靠语境猜。

### 1.1 标量变量、向量变量与函数变量

变量未必只是一个向量：

| 问题 | decision variable | 所在空间 |
|---|---|---|
| linear regression | $w,b$ | $\mathbb R^d\times\mathbb R$ |
| matrix factorization | $U,V$ | $\mathbb R^{m\times r}\times\mathbb R^{n\times r}$ |
| covariance estimation | $\Sigma$ | symmetric/PSD matrices |
| optimal control | trajectory $u(t)$ | function space |
| distributionally robust learning | probability law $Q$ | space of measures |

变量的空间决定合法方向、度量、compactness 和 derivative 类型。把矩阵变量 flatten 成向量在代数上可行，但可能隐藏 symmetry、rank、PSD 或 manifold constraint。

### 1.2 哪些东西不是 decision variable

给定训练 run 中，以下对象可能固定，也可能被纳入外层优化：

- dataset $D$；
- regularization coefficient $\lambda$；
- architecture $a$；
- optimizer schedule $s$；
- random seed $\omega$；
- data ordering；
- threshold/decision rule。

若 validation 上挑 $\lambda$，完整过程其实是 bilevel/model-selection problem：

$$
\lambda^*
\in\arg\min_{\lambda\in\Lambda}
L_{val}(\theta^*(\lambda),\lambda),
$$

其中

$$
\theta^*(\lambda)
\in\arg\min_\theta L_{train}(\theta,\lambda).
$$

把只写内层训练目标的报告称为“完整优化问题”会漏掉 selection bias 和 inner-solve error。

## 二、domain 先于 constraint

函数的 effective domain 定义为

$$
\operatorname{dom}f
=\{x:f(x)<+\infty\}
$$

（对 extended-real minimization）。普通实值函数也有自然 domain，例如：

$$
\operatorname{dom}(-\log x)=(0,\infty),
$$

$$
\operatorname{dom}(X\mapsto-\log\det X)=\mathbb S_{++}^n.
$$

标准问题共同 domain 可写为

$$
\mathcal D
=\bigcap_{i=0}^m\operatorname{dom}f_i
\cap\bigcap_{j=1}^p\operatorname{dom}h_j.
$$

如果在 $x=0$ 处写 $-\log x\le 3$，不是“约束违反 3 个单位”，而是 objective/constraint 根本未定义。

### 2.1 extended-value 语言

集合 $C$ 的 indicator function 定义为

$$
\delta_C(x)=
\begin{cases}
0,&x\in C,\\
+\infty,&x\notin C.
\end{cases}
$$

于是约束问题

$$
\min_{x\in C}f(x)
$$

可写成无显式约束的 extended-value problem

$$
\min_x f(x)+\delta_C(x).
$$

这是后续 convex analysis 与 proximal method 的统一语言；$+\infty$ 是禁止选择某点的数学编码，不是实际浮点程序应计算的数。

## 三、可行集与 problem status

feasible set 是

$$
\mathcal F
=\left\{x\in\mathcal D:
f_i(x)\le0\ \forall i,
h_j(x)=0\ \forall j
\right\}.
$$

- $x\in\mathcal F$：feasible point；
- $\mathcal F=\varnothing$：infeasible problem；
- $\mathcal F\ne\varnothing$：feasible problem。

### 3.1 feasibility 不是 objective quality

一个点可以完全可行但 objective 很差，也可以 objective 很低但违反关键约束。应分开报告

$$
r_{ineq}(x)
=\left\|[f(x)]_+\right\|,
\qquad
r_{eq}(x)=\|h(x)\|,
$$

其中 $[a]_+=\max(a,0)$ 逐分量作用。不同约束单位差异很大时，还要说明 normalization 与 tolerance。

### 3.2 hard constraint 与 penalty 不等价

原问题

$$
\min_x f(x)
\quad\text{s.t.}\quad c(x)=0
$$

被改写为

$$
\min_x f(x)+\rho\|c(x)\|^2
$$

时，有限 $\rho$ 通常只鼓励接近可行，不保证 $c(x)=0$。例如

$$
\min_x (x-1)^2
\quad\text{s.t.}\quad x=0
$$

的解是 $x^*=0$；quadratic penalty 解满足

$$
2(x-1)+2\rho x=0
\Longrightarrow
x_\rho=\frac1{1+\rho}\ne0
$$

对每个有限 $\rho$ 都不可行。penalty limit、exact penalty 与 augmented Lagrangian 需要额外理论。

## 四、最优值、infimum 与 optimizer

定义 optimal value

$$
p^*=\inf_{x\in\mathcal F}f_0(x).
$$

若存在 $x^*\in\mathcal F$ 使

$$
f_0(x^*)=p^*,
$$

则称 $x^*$ 为 global minimizer/optimal solution，解集为

$$
\mathcal X^*
=\operatorname*{argmin}_{x\in\mathcal F}f_0(x).
$$

### 4.1 infimum 可以不被取得

考虑

$$
\min_{x>0}x.
$$

有

$$
p^*=0,
$$

但任何 feasible $x$ 都满足 $x>0$，所以

$$
\mathcal X^*=\varnothing.
$$

这是 feasible、bounded below、optimal value finite，但 minimum unattained。

### 4.2 unbounded below

考虑

$$
\min_{x\in\mathbb R}-x.
$$

对任意 $M$ 都可取 $x>M$ 使 $-x<-M$，故

$$
p^*=-\infty.
$$

这叫 unbounded below，不是“optimizer 数值发散”自动证明的结论；数值发散也可能来自步长、overflow 或代码错误。

### 4.3 infeasible 与 unbounded 要分开

在 extended convention 下常记：

$$
\inf\varnothing=+\infty.
$$

所以：

| 状态 | $\mathcal F$ | $p^*$ | optimizer |
|---|---|---:|---|
| infeasible | empty | $+\infty$（约定） | 无 |
| feasible, unattained | nonempty | finite | 无 |
| attained | nonempty | finite | 至少一个 |
| unbounded below | nonempty | $-\infty$ | 无有限最优点 |

求解器的 `infeasible_or_unbounded` 状态表示当前证书不足以区分二者，不能在报告中任选一个。

## 五、global、local、strict 与 isolated

### 5.1 global minimizer

$x^*\in\mathcal F$ 是 global minimizer，当且仅当

$$
f_0(x^*)\le f_0(x),
\qquad\forall x\in\mathcal F.
$$

量词覆盖整个可行集。

### 5.2 local minimizer

$x^*$ 是 local minimizer，若存在 $r>0$，使

$$
f_0(x^*)\le f_0(x),
\qquad
\forall x\in\mathcal F\cap B(x^*,r).
$$

邻域必须与 feasible set 相交；边界点的不可行方向不能拿来否定 constrained local optimum。

### 5.3 strict local minimizer

若对所有

$$
x\in(\mathcal F\cap B(x^*,r))\setminus\{x^*\}
$$

都有

$$
f_0(x^*)<f_0(x),
$$

则为 strict local minimizer。

### 5.4 isolated minimizer

若某邻域内没有其他 minimizer，则 $x^*$ 是 isolated local minimizer。strict local minimizer 在常见定义下是 isolated 的；但一个 isolated local minimizer 未必能给 uniform quadratic growth。

### 5.5 plateau 上的非严格解

函数

$$
f(x)=0,
\qquad x\in[-1,1]
$$

在整个 feasible set 上每点都是 global minimizer，没有一个是 strict/isolated。解集可以是 continuum，而非单个“真参数”。

## 六、stationary point 只是候选

对 unconstrained differentiable $f:\mathbb R^n\to\mathbb R$，若 $x^*$ 是 interior local minimizer，则 Fermat necessary condition 给

$$
\nabla f(x^*)=0.
$$

满足该式的点叫 first-order stationary point。

### 6.1 stationary 不充分

一维三个例子：

| 函数 | $x=0$ | 类型 |
|---|---|---|
| $f(x)=x^2$ | $f'(0)=0$ | strict global minimum |
| $f(x)=-x^2$ | $f'(0)=0$ | strict global maximum |
| $f(x)=x^3$ | $f'(0)=0$ | neither min nor max |

二维

$$
f(x,y)=x^2-y^2
$$

在原点梯度为零，但沿 $x$ 轴上升、沿 $y$ 轴下降，是 saddle point。

### 6.2 局部最优未必梯度为零

约束问题

$$
\min_{x\ge0}x
$$

的唯一 global minimizer 是 $x^*=0$，但

$$
f'(0)=1\ne0.
$$

原因是下降方向 $-1$ 不可行。正确 necessary condition 要涉及 feasible-direction/tangent cone 与 normal cone，后续[[投影、约束与可行方向]]和 KKT 会系统建立。

### 6.3 nonsmooth minimum 也未必 ordinary gradient 为零

$$
f(x)=|x|
$$

在 0 处取得唯一 global minimum，但 ordinary derivative 不存在。后续使用 subdifferential condition

$$
0\in\partial f(0).
$$

所以“检查 gradient norm”只适用于相应 smooth unconstrained 或经过正确 generalized-gradient 处理的问题。

## 七、存在性：什么时候 infimum 真能落在一点上

### 7.1 Weierstrass theorem

> [!theorem] 连续函数在非空 compact 集上取得极值
> 若 $\mathcal F\subset\mathbb R^n$ 非空且 compact，$f_0$ 在 $\mathcal F$ 上连续，则存在 $x^*\in\mathcal F$ 使 $f_0(x^*)=\min_{x\in\mathcal F}f_0(x)$。

证明骨架：取 minimizing sequence $x_k$ 使 $f(x_k)\downarrow p^*$；compactness 给收敛子列 $x_{k_j}\to x^*\in\mathcal F$；连续性给

$$
f(x^*)=\lim_jf(x_{k_j})=p^*.
$$

三个条件分别阻止：没有点、序列逃向无穷或边界、极限处函数值跳变。

### 7.2 closed 不等于 compact

$\mathbb R^n$ 是 closed 但不 bounded。函数 $e^{-x}$ 在 $\mathbb R$ 上连续且 bounded below，infimum 0 却不取得。有限维中 compact 等价于 closed and bounded。

### 7.3 coercivity 替代显式有界性

若

$$
\|x\|\to\infty
\Longrightarrow
f_0(x)\to+\infty,
$$

称 $f_0$ coercive。若 $f_0$ lower semicontinuous、$\mathcal F$ 非空 closed，并且在 $\mathcal F$ 上 coercive，则其低 sublevel set

$$
\{x\in\mathcal F:f_0(x)\le\alpha\}
$$

可被限制在 compact 区域，从而存在 minimizer。

$\ell_2$ regularization 常通过

$$
f(\theta)=L(\theta)+\lambda\|\theta\|_2^2
$$

提供 coercive growth，但前提是 $L$ 不以更快速度趋向 $-\infty$，且 parameterization 没有不可控非欧氏方向。

### 7.4 existence 不等于 uniqueness

Weierstrass 只给“至少一个”。唯一性通常要 strict convexity、identifiability 或问题特定结构。深网中的 neuron permutation、ReLU scaling、matrix factorization gauge 常产生多组等价参数。

## 八、近似解需要四类 residual

真实算法通常返回 $\widehat x$，不是 exact $x^*$。至少区分：

### 8.1 objective gap

$$
f_0(\widehat x)-p^*.
$$

问题：$p^*$ 常未知；非唯一/平坦问题中小 gap 不保证参数靠近某一点。

### 8.2 distance to solution set

$$
\operatorname{dist}(\widehat x,\mathcal X^*)
=\inf_{x^*\in\mathcal X^*}\|\widehat x-x^*\|.
$$

若 parameterization 有 symmetry，距离应先 quotient/alignment，否则功能等价模型可能参数距离很大。

### 8.3 stationarity residual

smooth unconstrained 时常用

$$
\|\nabla f(\widehat x)\|.
$$

constrained/nonsmooth 时需 projected-gradient、gradient mapping、KKT residual 或 subgradient distance；不能统一用 raw gradient norm。

### 8.4 feasibility residual

$$
r_{feas}(\widehat x)
=\max\left{
\max_i[f_i(\widehat x)]_+,
\max_j|h_j(\widehat x)|
\right}.
$$

### 8.5 四者不能无条件互换

对

$$
f_\varepsilon(x)=\varepsilon x^2,
$$

$x=1$ 的 solution distance 是 1，但 objective gap 是 $\varepsilon$、gradient norm 是 $2\varepsilon$，可任意小。只有 strong convexity/error bound 等额外结构才给

$$
f(x)-f^*\ge\frac\mu2\operatorname{dist}(x,\mathcal X^*)^2.
$$

这也是为什么不能用一个固定 gradient threshold 跨模型、尺度和 parameterization 比较“收敛程度”。

## 九、等价变换、reformulation 与 relaxation

### 9.1 严格单调变换保持 argmin

若 $\phi$ 严格递增，则

$$
\operatorname*{argmin}_{x\in\mathcal F}f(x)
=\operatorname*{argmin}_{x\in\mathcal F}\phi(f(x)).
$$

但数值几何不同。例如最小化 $f>0$ 与 $\log f$ 有相同 exact minimizers，却有

$$
\nabla\log f=\frac{\nabla f}{f},
$$

所以 gradient trajectory、conditioning 与 stopping threshold 都改变。

### 9.2 正缩放保持解但改变容差

$$
\arg\min f=\arg\min af+b,
\qquad a>0.
$$

然而 gradient norm 乘以 $a$，固定 learning rate 与固定 tolerance 不再可比。

### 9.3 一一重参数化保持函数解但不保持局部算法

若 $x=\psi(u)$ 为 bijection，则 exact global solutions 对应；但 Euclidean gradient 受 Jacobian 影响：

$$
\nabla_u(f\circ\psi)(u)
=J_\psi(u)^T\nabla_x f(x).
$$

有限步 gradient descent 不是一般 coordinate invariant。自然梯度/mirror geometry 正是对此问题的结构化回答。

### 9.4 relaxation 扩大可行集

整数问题

$$
\min_{x\in\{0,1\}^n}c^Tx
$$

relax 为 $x\in[0,1]^n$ 后，feasible set 变大，所以 minimization optimal value 给 lower bound：

$$
p^*_{relax}\le p^*_{original}.
$$

relaxed optimum 若非整数，不是原问题 feasible solution；需要 rounding 与 integrality-gap 分析。

### 9.5 surrogate 改目标

用 cross-entropy 替代 0–1 loss、用 differentiable perceptual proxy 替代 human preference，属于 surrogate optimization。需要单独证明 calibration/consistency 或做 empirical validation；“surrogate 降低”不自动等于原 metric 改善。

## 十、经验目标、总体目标与三类误差

令 population risk

$$
R(\theta)=E_{Z\sim P}[\ell(\theta;Z)],
$$

empirical risk

$$
\widehat R_n(\theta)
=\frac1n\sum_{i=1}^n\ell(\theta;Z_i).
$$

若模型类为 $\Theta$，算法输出 $\widehat\theta$，可用一个典型分解理解：

$$
R(\widehat\theta)-R^*_{all}
=\underbrace{R(\theta_\Theta^*)-R^*_{all}}_{\text{approximation/model gap}}
+\underbrace{R(\widehat\theta)-R(\theta_\Theta^*)}_{\text{estimation + optimization interaction}}.
$$

更细地，empirical optimization gap 是

$$
\widehat R_n(\widehat\theta)
-\inf_{\theta\in\Theta}\widehat R_n(\theta),
$$

generalization gap 是

$$
R(\theta)-\widehat R_n(\theta).
$$

它们的随机性与控制工具不同。把训练更久降低 empirical objective，可能改善 optimization gap，也可能放大 overfitting；early stopping 同时是算法截断与 implicit regularization hypothesis。

## 十一、常见 AI 问题怎样写成合同

### 11.1 正则化监督学习

$$
\min_{\theta\in\Theta}
\frac1n\sum_{i=1}^n\ell(f_\theta(x_i),y_i)
+\lambda\Omega(\theta).
$$

必须记录：loss reduction、sample weighting、regularizer、trainable parameter subset、data split 与 log base。weight decay 的实现是否等价于 objective 中的 $\ell_2$ penalty 依 optimizer 而定。

### 11.2 鲁棒/对抗训练

$$
\min_\theta
E_{(X,Y)}
\left[
\max_{\delta\in\Delta(X)}
\ell(f_\theta(X+\delta),Y)
\right].
$$

这是 min–max problem。有限步 PGD 只得到 inner maximization 的候选，外层实际优化的是 attack-dependent surrogate；应报告 inner residual/attack strength，而非只写理论 max。

### 11.3 公平/资源约束

$$
\min_\theta \widehat R_n(\theta)
\quad\text{s.t.}\quad
|\widehat g_k(\theta)|\le\varepsilon_k,
\quad
C(\theta)\le B.
$$

$\widehat g_k$ 的 sampling uncertainty、subgroup support 与 deployment shift 不能被 feasibility tolerance 替代。若 constraints 互相冲突，问题可能 infeasible。

### 11.4 VAE/VI

$$
\max_{\theta,\phi}
\frac1n\sum_i\operatorname{ELBO}(x_i;\theta,\phi).
$$

这是对 evidence 的 variational lower-bound empirical optimization；ELBO optimization gap、variational family gap、amortization gap 和 model misspecification 必须分开。

### 11.5 bilevel/meta-learning

$$
\min_\lambda F(\theta^*(\lambda),\lambda),
\qquad
\theta^*(\lambda)\in\arg\min_\theta G(\theta,\lambda).
$$

若 inner argmin 非唯一，$\theta^*(\lambda)$ 是 set-valued；有限 inner iterations 定义的是另一个 algorithm-dependent outer objective。implicit gradient 还需 inner stationarity 和 Hessian/linear-solve 条件。

## 十二、停止准则是 theorem 的一部分

只看 loss plateau 可能混入：

- learning rate 太小；
- stochastic noise floor；
- finite precision；
- objective scaling；
- validation metric 延迟；
- infeasible constraint；
- saddle/flat direction。

一个可审计停止报告至少包括：

1. objective 与归约方式；
2. feasibility residual；
3. 适合问题结构的 stationarity/KKT residual；
4. iterate/update norm；
5. gradient estimator variance 或 batch sensitivity；
6. evaluation/validation trajectory；
7. numerical residual 与 precision；
8. budget termination 与 convergence termination 的区分。

## 十三、常见错误与纠正

| 错误说法 | 缺失对象 | 纠正 |
|---|---|---|
| loss 有下界，所以一定有最优解 | compactness/coercivity/closedness | 有 infimum 不等于 attained |
| 梯度为 0，所以找到 minimum | 二阶/凸性/邻域 | stationary 只是候选 |
| 梯度不为 0，所以不是最优 | constraint/nonsmoothness | 边界或 cusp 可最优 |
| 参数不再变化，所以收敛 | scale/precision/step | 报 residual 与 objective gap 证据 |
| 加 penalty 与 hard constraint 等价 | finite penalty/exactness | 检查 feasibility 与 exact-penalty 条件 |
| 训练目标降低，所以部署指标改善 | surrogate/generalization/shift | 分开验证原 metric 与 population |
| 更换参数化只是实现细节 | geometry | exact 解可对应，轨迹和 implicit bias 会变 |
| 最优参数应唯一 | symmetry/identifiability | 报 solution set/function equivalence |
| solver failed 说明问题 infeasible | numerical/algorithm status | 需要 infeasibility certificate |
| 多跑几个 seed 就证明 global optimum | search space/certificate | seed sensitivity 是诊断，不是全局证书 |

## 十四、problem contract 模板

```text
Problem instance：数据、预处理、模型类、固定超参数、seed/order
Decision variables：形状、空间、trainable subset
Objective：公式、log base、sum/mean、weights、expectation law
Domain：使所有函数有定义的集合
Constraints：hard/soft、单位、容差、估计不确定性
Solution concept：global/local/stationary/saddle/approximate
Existence/uniqueness：使用的条件或明确未知
Algorithm：oracle、初始化、步长、batch、precision
Stopping：objective/feasibility/stationarity/numerical residual
Statistical target：population estimand、split、shift
Deployment metrics：calibration、latency、safety、subgroups
Cannot conclude：不由当前证据支持的全局/因果/泛化声明
```

## 十五、本节回顾

你应能独立重建：

$$
\mathcal F
=\{x\in\mathcal D:f_i(x)\le0,\ h_j(x)=0\},
$$

$$
p^*=\inf_{x\in\mathcal F}f_0(x),
\qquad
\mathcal X^*=\arg\min_{x\in\mathcal F}f_0(x),
$$

并始终记住：

$$
\text{small loss}
\not\Rightarrow
\text{global optimum}
\not\Rightarrow
\text{small population risk}
\not\Rightarrow
\text{good deployment decision}.
$$
