# 60.5 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背诵 cosine、warmup 或 clipping 配方为通过标准，而检查能否从实际更新尺度出发，追踪时域、状态、估计器和输出选择，最后设计预算匹配、能识别交互且有证据边界的训练实验。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能在新数字上独立完成；
- 已从空输出目录运行 [[实验 - 训练控制器、调度时域与证据账审计]]；
- 能不看图注解释 11 张图各自“证明了什么/没有证明什么”；
- 能为任意训练配置写出 reduction → direction → scale → state → output 的完整合同。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜Learning rate 与实际更新（8 分）

从 descent lemma 推导一般方向 $u$ 的充分下降区间；证明 $u\mapsto cu,\eta\mapsto\eta/c$ 的轨迹不变性；最后比较 absolute、relative、angular 与 feature step 的信息和失效边界。

### Q2｜Warmup 的多机制假说（7 分）

对时变一维曲率写逐步稳定条件；手算 Adam 前两步偏差修正；建立曲率、state、relative update、noise、numeric、architecture 六行机制矩阵，并为每行给一个反证干预。

### Q3｜Schedule 端点、面积与时钟（8 分）

手算 constant、linear、cosine 的连续面积和平方面积；证明 inverse-sqrt 两种累计量的阶；构造离散 endpoint off-by-one，并写 success-update/token 两种时钟的差异。

### Q4｜Horizon、Branch 与 Schedule-Free（7 分）

证明 $T$ 与 $2T$ full-horizon cosine 在历史内不同；为 resume、restart、branch 写 state transition；展开一个在线平均递推并说明 train/eval point 为什么属于算法定义。

### Q5｜Clipping estimator（8 分）

证明 global clipping 是 Euclidean projection；手算期望方向反转和 clip/average 不交换反例；比较 global、layerwise、AGC，并写 distributed order contract。

### Q6｜Weight RMS 与尺度不变性（8 分）

展开 AdamW 的时变历史核和 $q,r,c$ 递推；在明示假设下导出 RMS 的 $\sqrt{\eta/\lambda}$ 阶；证明尺度不变函数的梯度正交，并比较 SGD/normalized direction 的角 LR。

### Q7｜EMA、SWA 与平均对象（7 分）

展开 EMA 权重、half-life 与初始化残余；用 Taylor 解释 parameter/prediction average 差异；构造隐藏单元置换反例，并说明 BN state 与 teacher feedback 边界。

### Q8｜联合消融与证据（7 分）

由四 cell 计算主效应与交互；推导 paired-difference 方差；建立 controller→mediator→outcome 证据链，并写训练、调参、选择、评估四本预算账。

## 三、开卷复现部分（40 分）

### R1｜无缓存确定性复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 27 项 checks、1 JSON、10 CSV 与 3 SVG；
- 手算任取一个 schedule area、一个 clipping row、一个 $q_t$ row；
- 记录 Python 版本、命令、退出码、三个 SHA-256、14/14 byte comparison 与渲染目检。

### R2｜改变时域与裁剪分布（10 分）

把离散点数改成 37 与 1000，审计端点/面积；把 two-point clipping 分布改成对称、重尾和零均值非对称三类。运行前预注册期望符号与 non-commutativity，运行后区分 estimator bias 和稳定性。

### R3｜改变 LR/WD 与平均时钟（10 分）

对 $\eta$、$\lambda$ 分别做上/下阶跃并加入 $c_t\ne0$，比较 exact recurrence 与 instantaneous equilibrium；把 EMA 从每 step 改成每 50 step，按物理 step 匹配 half-life，再测试 nonlinear prediction gap。

### R4｜小模型联合控制实验（10 分）

在小型 Transformer/MLP 上做 LR×warmup 和 clip×WD 因子实验；固定 data/seeds，总搜索 compute 对称。报告 actual/relative/feature step、moments、clip/overflow、RMS、last/EMA、失败分母、四本预算账与限定作用域的 claim。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 只比较 raw LR，或把 warmup/clipping/EMA 的相关性写成唯一机制 |
| L1 | 会写曲线公式，但不能处理 endpoint、clock、state 与平均对象 |
| L2 | 能手算下降界、schedule、偏差、RMS 和记忆核，并给反例 |
| L3 | 能复现实验、改变时域/分布/state，用中介量定位失败层 |
| L4 | 能在真实框架做 factorial/paired/compute-matched 审计，形成可回滚的证据结论 |

通过线：总分至少 80/100，且 Q1、Q4、Q5、Q6、Q8、R4 均不得低于该题 50%。本卷静态状态为 verified 时，也只说明课程材料通过审计，不代表学习者已经通过。
