# 第六章训练与优化累计测验与研究总审计门

> [!abstract] 这道门测什么
> 分卷题库检查局部知识，本门检查你能否把九卷合成一条完整推理链：**目标与 batch → 状态与优化几何 → 控制器与尺度 → 有限精度/并行执行 → telemetry 与因果证据**。它分为闭卷重建、跨卷案例和真实研究三层；看到文件或运行合成脚本都不算个人通过。

## 一、先锁定考试合同

### 1.1 三层必须分开

| 层 | 证据 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| A：闭卷重建 | 18 题手写答案、推导和数值 | 对象、公式、边界是否进入长期记忆 | 能否独立运行真实训练研究 |
| B：跨卷案例 | 4 份设计答卷、可执行检查式 | 能否联立数值、系统和统计约束 | 某个模型上的经验结论是否成立 |
| C：真实研究 | 原始 run、manifest、失败记录、统计与复现 | 能否生产范围受控、可复查的训练证据 | 超出 treatment、模型、数据和预算的普遍结论 |

只有 A、B、C 都通过，才可把个人状态记为“第六章掌握通过”。课程文件的 `verified` 只代表静态教材通过机器与人工审计。

### 1.2 考试条件

- A 层 150 分钟，闭卷，不运行代码；允许空白纸和普通计算器；
- B 层 180 分钟，可查本库，但不得看 [[第六章训练与优化累计测验校准解答]]；
- C 层不限定日历时间，必须使用至少一个真实 autodiff/framework 训练程序；合成标准库实验只能作为 oracle，不能替代真实 run；
- 所有公式必须声明 loss reduction、时钟、参数组、dtype、预算和比较单位；只给结论不给对象合同，最多得该小题一半分；
- 若更改题目假设，必须先明确写出改动，再分别回答原题和修改后的问题。

## 二、A 层：九卷闭卷重建（90 分）

每题 5 分。卷内最低要求为每两题合计至少 6/10；总分至少 72/90。定义/对象 1 分，推导或手算 2 分，边界 1 分，可执行检查 1 分。

### A01　训练步与多时钟（60.1）

一个 rank 每次处理 8 个样本，4 ranks 做 data parallel，每个 optimizer update 累积 3 个 microsteps；loss 在本 rank 内取 mean，all-reduce 后又取 world mean。第 11 次 update attempt 因 overflow 跳过参数和 optimizer state 写回，但数据已经消费。

1. 写出正常 update 的 global effective batch；
2. 写出第 11 次 attempt 后 microstep、attempt、optimizer-step、sample 四个时钟各自怎样变化；
3. 说明 scheduler 按 attempt 或按成功 optimizer-step 推进会造成什么不同。

### A02　有限总体 batch covariance（60.1）

训练集有 $N=1000$ 个样本，单样本梯度的有限总体 covariance 记为 $S$。无放回均匀抽取 $B=100$ 个样本并取平均。

1. 写出 batch mean covariance（注明有限总体修正）；
2. 与有放回的 $S/B$ 比较；
3. 解释为什么这个恒等式仍不能单独预测 deep-network generalization。

### A03　Momentum 翻译与二次稳定性（60.1）

对 $f(x)=\tfrac12\lambda x^2$，采用 Heavy-ball

$$
x_{t+1}=x_t-\eta\lambda x_t+\beta(x_t-x_{t-1}).
$$

1. 写出 characteristic polynomial；
2. 对 $\lambda=4,\eta=0.2,\beta=0.9$ 计算根的模并判断稳定/振荡；
3. 说明它与“PyTorch momentum buffer”比较前必须固定哪条状态翻译。

### A04　Adam 偏差修正、epsilon 与实际步（60.2）

设 $g_1=2$，$m_0=v_0=0$，$\beta_1=0.9,\beta_2=0.99,\eta=10^{-3}$。

1. 计算 $m_1,v_1,\hat m_1,\hat v_1$；
2. 分别计算 $\epsilon=10^{-8}$ 放在根号外，以及 $\epsilon=10^{-4}$ 放在根号内的第一步 direction；
3. 说明当梯度整体乘正常数时，哪一部分会破坏理想尺度不变性。

### A05　L2、coupled decay 与 AdamW（60.2）

令参数 $\theta=(1,2)$、task gradient $g=(1,1)$、diagonal preconditioner $P=\operatorname{diag}(1,0.1)$、$\eta=0.01,\lambda=0.1$。

1. 写出 coupled L2 的一步位移；
2. 写出 decoupled AdamW-style 位移；
3. 指出两者何时才会退化为同一方向。

### A06　Hessian、GGN、Fisher 与 empirical Fisher（60.3）

以标量模型 $z=f_\theta(x)=\theta^2$、平方损失 $\ell(z,y)=\tfrac12(z-y)^2$ 为例。

1. 推导 Hessian 分解为 GGN 项与 model-second-derivative 项；
2. 在 $\theta=0,y=1$ 处计算二者与 Hessian；
3. 解释为什么样本梯度 outer product 既不自动等于 GGN，也不自动等于 model Fisher。

### A07　Trust region、damping 与 HVP（60.3）

给定局部模型 $m(p)=g^Tp+\tfrac12p^THp$，$H=\operatorname{diag}(-1,4)$、$g=(1,1)$。

1. 为什么裸 Newton 方程的解不是可靠下降证书？
2. 写出 $(H+\lambda I)p=-g$ 并给出使矩阵正定的 $\lambda$ 条件；
3. 若 $H$ 不能显式形成，说明 HVP+CG 能解决什么、负曲率时还缺什么机制。

### A08　对偶范数与 matrix sign（60.4）

设矩阵梯度 $G=U\Sigma V^T$。

1. 从 $\min_{\|\Delta\|_2\le \rho}\langle G,\Delta\rangle$ 推导最优值和一个最优方向；
2. 写出谱范数与核范数的对偶关系；
3. 若 $G$ rank-deficient，说明 null space 上的非唯一性与 canonical polar factor 的选择。

### A09　Newton–Schulz、形状缩放与 Muon 合同（60.4）

1. 写出一个用于逼近 polar/matrix-sign 的 Newton–Schulz 迭代及其缩放前提；
2. 对 $m\times n$ 方向满足非零奇异值约为 1，写出 Frobenius RMS 随形状的数量级；
3. 解释为何 Muon 的矩阵参数组、bias/norm/embedding fallback、动量位置和 shape factor 必须作为同一版本合同记录。

### A10　学习率、warmup、schedule 与 clipping（60.5）

一个 1000-step run 使用 100-step linear warmup 到 $\eta_{\max}=10^{-3}$，再做 cosine decay 到 0。

1. 写出分段 schedule；
2. 计算连续近似下 learning-rate area；
3. 说明把 horizon 改成 2000 而保持公式中的绝对 step 不变，为何不是“只训练更久”；
4. 全局 norm clipping 放在 accumulation 前后为何通常不等价？

### A11　EMA、SWA 与预测平均（60.5）

1. 写出 bias-corrected parameter EMA；
2. 给出 $\beta=0.999$ 的有效记忆长度数量级；
3. 构造一个非线性模型，说明 $f_{\bar\theta}(x)\ne \frac1K\sum_k f_{\theta_k}(x)$；
4. checkpoint averaging 前必须对齐哪些 state/buffer？

### A12　参数化、μP 与跨宽度迁移（60.6）

1. 区分 standard、NTK、mean-field 与 μP 想保持的极限对象；
2. 为什么只要求 activation variance 为 $O(1)$ 不足以保证 feature update 非退化？
3. 写出一次 μTransfer 必须锁定的 base shape、width multiplier、parameter role 与 optimizer-group 信息；
4. 为什么 embedding、readout、bias/norm 和 attention QKV 不能机械套同一个 hidden-matrix 规则？

### A13　Compute-optimal scaling 推导（60.7）

给定 excess loss

$$
L(N,D)-E=A N^{-\alpha}+B D^{-\beta},\qquad C=kND.
$$

1. 消去 $D$，求一阶条件；
2. 推出 $N_*(C)$ 与 $D_*(C)$ 的指数；
3. 当 $\alpha=\beta$ 时给出两个指数；
4. 指出连续最优点到实际模型配置之间还缺哪些离散/系统约束。

### A14　有效 token、过训练与部署目标（60.7）

两个数据集都有 $10^{11}$ seen tokens：A 含大量重复，B 的去重率更高但单 token 处理成本更高。

1. 为什么 seen token 不能直接当 effective token？
2. 设计至少两个可估计重复/混合价值的对照；
3. 写出包含训练成本与未来推理量的总目标，说明 Chinchilla-style 训练最优为何未必是部署最优。

### A15　dtype、loss scaling 与随机舍入（60.8）

1. 分别说明 exponent bits、significand bits、accumulation dtype 控制什么；
2. 写出 dynamic loss scaling 中 scale、unscale、nonfinite check、clip、step 的正确顺序；
3. 解释单次 stochastic rounding 无偏为何不能自动推出长期参数轨迹无偏；
4. master weight 解决的对象是什么，不能解决什么？

### A16　并行语义、内存和通信（60.8）

8 ranks、local microbatch 4、accumulation 8，loss 本地取 mean，梯度 all-reduce 后取 average。

1. 正常 global effective batch 是多少？
2. 若最后一个 microstep 各 rank 有效样本数不等，简单 rank mean 为什么有偏？
3. 写出 ZeRO/FSDP 对 parameter、gradient、optimizer state 的分片对象；
4. 用 latency $\alpha$、bandwidth $\beta$ 与消息量 $M$ 写出 ring all-reduce 的数量级，并解释 overlap 为什么受关键路径限制。

### A17　Telemetry 与 first-bad-event（60.9）

某 run 在 step 920 出现 loss spike；activation max 每 100 steps 记一次，gradient norm 每 10 steps，optimizer update 每步，系统事件按 wall time 记录。

1. 设计统一事件键；
2. 说明“最早看到异常的曲线”为什么不必是根因；
3. 给出寻找 first bad event 的二分 replay/检查点流程；
4. 写出至少三个机器不变量。

### A18　Factorial、paired seeds 与 checkpoint selection（60.9）

优化器 $O\in\{0,1\}$ 与 schedule $S\in\{0,1\}$ 的四个 cell 均值为 $10,11,12,17$（顺序为 $00,10,01,11$，越大越好）。

1. 计算 $O$ 在 $S=0$、$S=1$ 时的 simple effect 与 difference-in-differences；
2. 解释只比较 $00$ 与 $11$ 会误归因什么；
3. 说明为何同一 seed/data order 的 paired difference 通常比非配对比较方差更小；
4. best checkpoint、调参预算、测试集只开一次分别怎样进入协议。

## 三、B 层：跨卷综合案例（100 分）

每题 25 分，合计至少 75 分，且任一题不得低于 15 分。答案必须包含：对象表、公式、可执行不变量、失败/反例、证据边界。

### B01　从配置到真实一步：mixed-precision DDP 审计

给出一个 BF16 Transformer、8-way DDP、gradient accumulation、AdamW、global clipping、cosine schedule、dynamic loss scaling 的配置。你需要画出一次 update attempt 的有序状态机，并回答：

1. data cursor、RNG、autocast、backward、all-reduce、unscale、nonfinite check、clip、Adam moments、decay、parameter write、scheduler 各在何时发生；
2. overflow、uneven batch、resume、gradient-as-bucket-view 分别会破坏哪条朴素等价性；
3. 最小 telemetry 如何同时追踪 token/microstep/attempt/update/scheduler/wall 六个时钟；
4. 给出一个两 microbatch 的手算 oracle，验证 accumulation 与一次大 batch 在你声明的条件下相等。

### B02　AdamW、Shampoo 与 Muon 的 compute-matched 比较

设计一个不借 optimizer 名称偷换结论的比较：

1. 明确每种方法的 parameter grouping、state、precondition/orthogonalization interval、fallback 与实现版本；
2. 对齐训练 tokens、model/data、schedule search、有效 batch、precision、wall time 与总调参 compute；
3. 同时报告 task loss、UWR、update RMS、谱异常、state memory、communication 和失败率；
4. 规定 checkpoint selection 与多 seed paired analysis；
5. 写出什么结果只支持“此预算下较优”，什么额外证据才支持几何机制解释。

### B03　μTransfer × Scaling Law × 低精度 scale-up

你要从 width 256 的 base model 迁移到 width 4096，并决定参数量、数据量和 dtype。

1. 写出 base shape 与 target shape 的 role-aware 映射；
2. 设计至少 4 个宽度的 coordinate check，并给出稳定/失败的 slope 判据；
3. 用 held-out scale 检查 scaling family，而不是用全部尺度选模型再报告同一尺度；
4. 把 theoretical FLOPs、achieved throughput、memory、communication、energy 与 inference demand 分账；
5. 说明 BF16/FP8 改变后为什么不能继续声称“只改了宽度”。

### B04　一次训练改进如何升级为因果证据

观察到“新数据清洗 + 新 optimizer + WSD”相对旧 baseline 提升 1.2 点。设计完整归因协议：

1. 画 DAG，列出 treatment、outcome、pre-treatment covariates、mediators、selection 与可能的 common causes；
2. 设计 $2^3$ factorial 或有原则的 fractional factorial，并声明 interaction；
3. 用 paired seeds、预先锁定 checkpoint rule、compute matching 与 confidence interval；
4. 定义 sequential monitoring 边界，不许每看到一次 $p<0.05$ 就停；
5. 写出最终 claim ledger：哪些是 identity、approximation、toy result、scoped experiment、hypothesis；
6. 给出至少一个 null/negative result 仍值得保留的情形。

## 四、C 层：真实训练研究包（通过/不通过）

### C01　最低实验规模

完成一个你能实际负担的训练问题。小模型/小数据可以，伪造“大模型代表性”不可以。至少包括：

- 一个 baseline 与一个 treatment；
- 一个 $2\times2$ factorial（可把 treatment 作为其中一因子）；
- 至少 5 个 paired seeds，或给出功效/成本说明解释为什么更少；
- 至少一次故意制造并定位的失败（overflow、错误 reduction、resume drift、data corruption 等）；
- 一个完全锁定的 validation selection rule 与只在最终开启的 test；
- compute、tokens、wall time、peak memory、失败/重试和调参预算总账。

### C02　必须提交的 artifact

```text
research-package/
├── README.md                 # 问题、范围、复现命令
├── preregistration.md        # treatment/unit/outcome/budget/selection/analysis
├── environment.md            # commit、依赖、硬件、determinism level
├── configs/                  # baseline、factorial cells、seed manifests
├── raw/                      # 不覆盖的原始 telemetry/metrics/events
├── derived/                  # 从 raw 生成的表格和图
├── failures/                 # first-bad-event 与 incident timeline
├── analysis.md               # paired effect、interaction、interval、sensitivity
├── claim-ledger.md            # claim → evidence → scope → falsifier
└── reproduce.sh 或等价入口   # 从空目录重建 derived，不改 raw
```

不要求目录名逐字相同，但信息不能缺失。若数据/模型不能公开，提交 hash、schema、生成过程、访问条件与最小可公开 surrogate；“保密”不能成为省略对象合同的理由。

### C03　八个硬门

任一项失败则 C 层不通过：

1. **目标门**：population/empirical objective、metric numerator/denominator 与 regularizer 清楚；
2. **执行门**：batch/reduction/accumulation/world-size/dtype/update clocks 可重建；
3. **状态门**：optimizer、scheduler、scaler、RNG、data cursor 与 resume 可回放；
4. **预算门**：训练与调参 compute、tokens、wall time、memory 和失败 run 不隐去；
5. **选择门**：validation/checkpoint/early-stop 预先固定，test 不参与调参；
6. **统计门**：保留 paired raw values、interaction、interval；序贯查看有显式规则；
7. **事故门**：至少一个真实失败有 first-bad-event、竞争解释、修复和防复发检查；
8. **范围门**：结论不超出模型、数据、硬件、实现、预算和观测时窗。

## 五、评分与掌握状态

| 状态 | A 层 | B 层 | C 层 | 可写入的个人结论 |
|---|---:|---:|---|---|
| not attempted | 无 | 无 | 无 | 只有静态教材可用 |
| foundation | ≥72/90 且卷内无短板 | 未过 | 未过 | 能重建主要对象与公式 |
| integrated | 通过 | ≥75/100 且单题≥15 | 未过 | 能做跨卷设计与审计 |
| research-ready | 通过 | 通过 | 8/8 硬门通过 | 能生产范围受控的训练证据 |
| distinction | 通过且 ≥84 | ≥90 | 通过，并由另一环境独立复现关键结论 | 具备本章高阶研究出口 |

### 5.1 失败后的回修规则

- 某卷 A 两题低于 6/10：回到该卷 MOC，随机抽取 15 道题重新闭卷；
- B 题低于 15：先写“对象遗漏表”，再重做，不允许只修数字；
- C 的 selection/test 泄漏：旧 test 立即降级为 validation，新建未见数据后重跑最终门；
- C 的 committed raw data 被覆盖：本次研究包不通过，必须从不可变日志或新 run 重建；
- 外部复现失败：保留失败结果，缩小 claim；不得只换 seed 直到成功。

## 六、阅卷与校准

- 客观手算与关键推导见 [[第六章训练与优化累计测验校准解答]]；
- 开放题按“对象合同 25% + 数学/算法 25% + 可执行验证 20% + 反例/失败 15% + 证据边界 15%”评分；
- 阅卷者必须把“算错”“对象没定义”“近似越级”“预算不公平”“选择泄漏”“因果越级”分开记录；
- 一次高分不能永久免检。软件实现、硬件、模型与研究问题变化时，C 层证据必须重新绑定新范围。

> [!success] 总出口
> 真正通过不是能背出 AdamW 或 Muon，而是面对陌生训练系统时，能独立完成：**定义对象 → 推导更新 → 核对有限精度与并行执行 → 设计公平实验 → 定位失败 → 写出受证据约束的结论**。
