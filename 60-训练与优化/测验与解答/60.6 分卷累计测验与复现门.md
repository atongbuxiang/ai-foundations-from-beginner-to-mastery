# 60.6 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背出 μP 表格为通过标准，而检查能否先声明尺度对象与极限路径，再从随机/相干聚合推导参数组规则，用 coordinate、spectral、curve 与 failure telemetry 分层验收，最后给出不泄漏 target 信息、预算诚实的 scale-up 结论。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能在新 shape、新 optimizer 与新 head/depth path 上独立完成；
- 已从空输出目录运行 [[实验 - μP 坐标、谱条件与尺度迁移审计]]；
- 能不看图注解释 11 张图各自“证明了什么/没有证明什么”；
- 能为任意参数组写出 shape、forward aggregation、init、raw direction、actual update、feature/logit update 和 limit path 七栏合同。

## 二、闭卷部分（150 分钟，60 分）

### Q1｜尺度对象与极限路径（7 分）

给定 width、depth、head count、head dimension、FFN aspect、vocab 与 sequence length，写完整 scale contract；区分 coordinate RMS、vector norm、entry RMS、Frobenius、data-weighted gain 与 spectral norm；构造“固定 head 数”和“固定 head dimension”两个同样增大 $d_{model}$、却需要不同解释的路径。

### Q2｜Standard、NTK 与 Mean-field（7 分）

对
$$
f_n(x)=n^{-a}\sum_{i=1}^na_i\phi(w_i^\top x)
$$
分别从随机初始化和训练后相干更新推导输出量级；给出 lazy 与 feature-learning 的判据；说明同样的初始 $O(1)$ 输出为何不决定训练 regime。

### Q3｜Maximal Update 与指数账（9 分）

对三层 MLP 从前向、loss gradient、backprop、SGD/Adam-like direction 到 feature update 完成逐层 exponent ledger；分别处理 input、hidden、readout；指出随机和 $\sqrt n$ 与相干和 $n$ 在哪一步切换，并解释 maximal 为什么既要求不爆炸也要求不消失。

### Q4｜Tensor Programs 与 Coord Check（7 分）

说明 covariance recursion、gradient independence 入口、fixed depth/fixed ratio/fixed step 的作用；给一组多宽度 observations 估计 log–log slope；设计 forward-only、step-1 和 later-step 三阶段检查，处理 readout zero-init 瞬态与有限宽修正。

### Q5｜μTransfer 与选择稳定性（7 分）

从 base/delta/target shapes 写 infshape oracle；证明 uniform curve approximation 加 isolated optimum 可导出 argmin 稳定；构造平谷使 argmin drift 大而 regret 小；计算 transfer regret 与 near-optimal overlap，并说明没有 target sweep 时哪些量不可识别。

### Q6｜特殊参数组（7 分）

对 embedding lookup、tied readout、Q/K/V/O、bias/norm 与 LoRA A/B，分别写 forward 聚合、梯度结构和主要 scale axes；推导 readout 对齐和、tied 总梯度及 $\Delta(AB)$；说明 $1/\sqrt{d_h}$ 与 $1/d_h$ 分别控制什么阶段。

### Q7｜谱条件与 Width–Depth（8 分）

从输入输出坐标合同推导 $\lVert W\rVert_2$ 的 shape ratio 上界并说明 $\Theta$ 下界所需条件；证明谱范数约束下的 matrix-sign 最速方向；用 rank-one/Hadamard 反例拆分 RMS 与谱；推导同向/正交残差下 $1/L$ 与 $1/\sqrt L$ 的边界。

### Q8｜Scale-up 证据与预算（8 分）

写 Shape、Coordinate、Spectral/Depth、Training Safety、Transfer 五道 gate；给一张 failure observation→hypothesis→intervention 表；设计 proxy-to-target 锁定协议、失败分母和
$$
C_{train}+C_{tune}+C_{select}+C_{eval}+C_{confirm}
$$
五本账；把一个 E2 结果改写成不越级到 E4 的 claim。

## 三、开卷复现部分（40 分）

### R1｜无缓存确定性复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 29 项 checks、1 JSON、10 CSV 与 3 SVG；
- 手算一行 coherent sum、一条 coord slope、一个 spectral gap、一个 target regret 与一个 depth accumulation；
- 记录 Python 版本、命令、退出码、三个 SHA-256、14/14 byte comparison 与渲染目检。

### R2｜改变相关性、有限宽与 Attention 阶段（10 分）

把独立/同向二分改成相关系数 $\rho_n$ 的连续族；给 stable coord signal 加 $c n^{-1/2}$ 修正；令 q/k 的训练对齐强度从 0 逐步到 1。运行前预注册各 log slope 与 crossover width，运行后区分 asymptotic exponent、finite-width constant 和 correlation regime。

### R3｜改变迁移曲线与 Gate 顺序（10 分）

把单峰二次曲线改成宽平谷、多峰与 seed-noisy 三类；比较 optimum drift、rank correlation、near-optimal overlap 与 transfer regret。再让 coordinate pass、spectral fail，验证 target confirm 停止且保留预算仍入账；不得删除失败配置。

### R4｜真实小模型 Scale-up（10 分）

在最小 MLP 或 Transformer 上做至少三个 widths、两个 depths 与两种 head paths 的分阶段实验。固定数据、token clock、optimizer semantics 和 seeds；逐组记录 actual init/LR/forward multiplier、activation/feature/logit、parameter/update RMS 与 spectrum、loss/失败、curve/selection 和五本预算账。先锁定 proxy recipe，再运行 target confirm。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 背规则表但不声明 orientation/scale path，或以一次 target loss 代替迁移证据 |
| L1 | 能做 fan-in 随机和，却混淆训练相干和、特殊参数组与 optimizer direction |
| L2 | 能完成指数账、infshape、coord/spectral/curve 手算并给反例 |
| L3 | 能复现实验、改变相关性/曲线/gate，用中介遥测定位失败层 |
| L4 | 能在真实框架预注册 scale-up、锁定选择、保留失败分母与预算，并写有限作用域 claim |

通过线：总分至少 80/100，且 Q3、Q5、Q7、Q8、R4 均不得低于该题 50%。本卷静态状态为 verified 时，也只说明课程材料通过审计，不代表学习者已经通过。
