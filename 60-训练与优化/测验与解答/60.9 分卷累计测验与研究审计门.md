# 60.9 分卷累计测验与研究审计门

> [!abstract] 验收目标
> 本门不以“会看 loss 曲线”“跑了三个 seeds”或“消融后掉点”作为通过标准，而检查能否定义观测对象、定位 first bad event、建立因果 estimand、用 factorial/paired/sequential 设计处理交互与不确定性、隔离 checkpoint/test selection，并交付含真实失败的可审计 research ledger。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能换数据、optimizer、schedule、seed 层级和预算后独立完成；
- 从空目录复跑 [[实验 - 训练诊断、实验设计与因果证据审计]]，核对 40/40 checks 与 14/14 byte identity；
- 能不看图注解释 8 张机制图和 3 张实验图各自展示/不证明什么；
- 已完成一次真实小模型失败运行，保存 first bad、配置、batch、checkpoint、RNG、环境与修复前后反事实。

## 二、闭卷部分（180 分钟，60 分）

### Q1｜Telemetry、多时钟与六本账（7 分）

画 data→forward→backward→optimizer→system 闭环；定义 wall/micro/update/token/scheduler 五时钟；为数据、目标、梯度、更新、参数/激活、系统写最小字段和 aggregation window；构造 skipped update 使时钟分叉；说明 L0/L1/L2 与观测开销。

### Q2｜First-bad-event 与事故定位（8 分）

给正常/异常 checkpoint 区间，手算二分轮数；写 data/forward/backward/update/distributed 决策树；区分非有限与有限异常；设计 anomaly/hook/reference 使用顺序；最后用 replay-A/B、control-C、quality-D 验证候选修复。

### Q3｜UWR、谱与参数化边界（7 分）

计算 global/layer/unit/spectral UWR；构造相同 RMS、不同 stable rank 的更新；解释 LARS/LAMB/AGC 对象差异；推导 power iteration 和固定二次稳定条件；用正齐次重缩放反驳 UWR 的函数不变性。

### Q4｜DAG、混杂与归因语言（8 分）

为 data×optimizer×schedule×precision 画 DAG；定义 treatment bundle、unit、outcome、ATE/target scope；区分 confounder/mediator/collider；手算 Simpson 标准化；列 consistency/exchangeability/positivity/measurement，并把观测时间线限制为 E2。

### Q5｜Factorial Ablation 与 Alias（7 分）

由四个 cell means 推导 $\beta_0,\beta_A,\beta_B,\beta_{AB}$、effects 与 difference-in-differences；证明平衡 $2^k$ contrast 正交；解释 randomization/replication/blocking；推导一个 fractional generator 的 alias 并设计确认 runs。

### Q6｜Seed、配对、区间与序贯决策（8 分）

定义 seed hierarchy 与算法分布；推导 paired variance；计算 paired CI 和 MDE 样本量；处理重尾、task hierarchy、failure/censoring 与 multiplicity；解释 fixed-$n$ CI 的可选停止问题并写 simultaneous coverage 量词。

### Q7｜Checkpoint、泄漏与 Compute Matching（7 分）

证明 best validation 的选择乐观；写 early-stop/restore/tie-break 合同；区分 nested selection 与 locked test；列 token/FLOP/device-time/time-to-quality/total-R&D 五种预算；构造 throughput 更高却更晚达标的反例。

### Q8｜Research Ledger 与证据地图（8 分）

从 claim/estimand 到 protocol、manifest、event/trial ledger、incident、analysis、decision 画可追溯图；区分 artifact/same-code/reimplementation/statistical/external 复现；把三个结论映射 E0—E5；处理 protocol deviation，并说明账本完整为何不等于结论正确。

## 三、开卷研究部分（40 分）

### R1｜无缓存确定性复现（8 分）

- 在两个空 output/plot 目录运行标准库脚本；
- 核对 1 JSON、10 CSV、3 SVG 和 40 项 checks；
- 手算一个 clock split、二分边界、stable rank、Simpson 标准化、factorial interaction、paired variance、time-to-quality；
- 记录命令、Python 版本、退出码、三个 SVG 哈希、14/14 byte comparison 与实际渲染目检。

### R2｜真实失败与 Incident（12 分）

在可用小模型上保存一次自然发生或开发过程中真实遇到的 failure；不得为了交作业只人工写 `NaN`。冻结最后正常/首异常 checkpoint、batch/data cursor、RNG、全部 states 与环境；二分并定位 first bad；做四格反事实；提交 impact/timeline/mechanism/control gap/action items 与回归 invariant。

### R3｜Factorial + Paired Confirmatory Study（10 分）

至少做 $2^2$ 设计，因素来自 optimizer/schedule/data/precision 中两个；以 checkpoint/data seed 阻断并随机运行顺序；预注册 primary effect/interaction、margin、失败处理和 fixed/sequential rule；报告 raw pairs、cell means、区间、interaction、tuning/compute 总账与所有 null/失败。

### R4｜Selection 与外部复验（10 分）

冻结 checkpoint cadence、early-stop、locked-test 和 target-quality；在新 seeds 上比较 time-to-quality 与 fixed-budget quality；随后至少换一个 data slice、model scale、hardware/backend 或独立实现复验。输出 claim–evidence matrix，明确最高 E 等级与未解决竞争解释。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 只凭 loss/单 seed/best checkpoint 调参，失败 run 被删除，相关性直接写成根因 |
| L1 | 能列指标和画曲线，但时钟、unit、selection、预算或 failure 分母不完整 |
| L2 | 能做 first-bad、UWR/谱、factorial、paired CI 与 locked selection 的手算/设计 |
| L3 | 能执行真实失败审计和预注册 paired factorial study，保留 null/失败与 protocol deviations |
| L4 | 能在新环境复验、区分 E0—E5、组织可交接 ledger，并为开放竞争解释设计最高信息价值的下一实验 |

通过线：总分至少 80/100，且 Q2、Q4、Q6、Q7、Q8、R2、R3 均不得低于该题 50%。材料 `verified` 只表示静态课程闭环，不代表学习者已经通过。

## 六、通过后出口

通过本门后，可以把第六章前八卷的 optimizer、schedule、μP、Scaling Law 与分布式训练知识转化为真正的研究流程：先写对象和预测，再以 telemetry 发现偏离，以 first-bad 和 factorial/paired design 区分解释，以 checkpoint/compute 协议形成公平决策，最后把正反证据、失败和适用边界交给下一位研究者。
