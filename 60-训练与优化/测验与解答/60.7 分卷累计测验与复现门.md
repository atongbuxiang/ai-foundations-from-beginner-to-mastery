# 60.7 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背出 Kaplan 指数或“20 tokens/parameter”为通过标准，而检查能否把有限区间经验律建成可证伪统计模型，从 joint loss surface 推导资源最优，在 model—system—energy—deployment 多层账本中做决策，并以 held-out scales、失败分母和结构不确定性约束结论。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能在新函数族、新成本口径和新部署目标上独立完成；
- 已从空 output/plot directory 运行 [[实验 - Scaling Law、资源分配与外推证据审计]]；
- 能不看图注解释 11 张图分别“证明了什么/没有证明什么”；
- 能为任意 scaling claim 写 response、resource axes、family、range、training protocol、error model、failure policy 与 target horizon 八栏合同。

## 二、闭卷部分（150 分钟，60 分）

### Q1｜Offset、误差模型与局部斜率（7 分）

对 $L=E+Ax^{-\alpha}$ 推导 raw 与 excess log-slope；构造错误 offset 造成的斜率漂移；分别写原尺度与 log 尺度似然；解释高 $R^2$、短窗口和最优 seed 选择为何不足以支持远尺度外推。

### Q2｜Kaplan 边际律与联合曲面（7 分）

区分 $N,D,T,C$ 与 total/non-embedding/active 参数；对 $L=E+AN^{-\alpha}+BD^{-\beta}+G(N,D,T)$ 推导两个局部斜率；证明单条 $D=kN^p$ 路径的不可辨识；设计 crossed grid 与 checkpoint 维度分解 optimization gap。

### Q3｜Chinchilla 与 Compute-optimal 推导（9 分）

在 $C=\kappa ND$ 下从代入法或拉格朗日法完整推导 $N^*(C),D^*(C),L^*(C)$ 与边际平衡式；分析 tokens/parameter 比是否恒定；把连续解传播到 bootstrap 近优集合、离散 shape 和数据约束。

### Q4｜IsoFLOP 与系统资源账（7 分）

从 dense forward/backward 解释 $6ND$ 的来源和失效项；区分 model/executed/peak FLOPs、MFU/HFU、wall time、energy 与 carbon；对 dense、MoE、重算和低利用率系统做一次 compute manifest 与 time-to-quality 比较。

### Q5｜数据重复、Mixture 与有效 Token（7 分）

区分 raw/unique/seen/repeated/effective tokens；推导几何重复模型及饱和上限；在 simplex 上写 mixture 目标的一阶条件与局部 transfer matrix；构造总 loss 改善、关键域退化的反例，并设计 contamination audit。

### Q6｜过训练、推理成本与 Pareto（7 分）

区分三种 overtraining；从训练截距与单请求斜率推导 break-even 及全部符号情形；加入 prefill/decode、KV cache、延迟和内存约束；给候选集找 Pareto frontier，并解释训练期最优为何不自动是部署最优。

### Q7｜Broken Scaling 与涌现诊断（8 分）

从 smooth broken law 推导前后 local exponent；对 $M=p^m$ 推导弹性并计算有限样本零成功概率；列出至少六个竞争解释；设计 optimizer–architecture–data factorial intervention，区分函数形状、指标表象与机制转变。

### Q8｜Scale-block 实验与证据等级（8 分）

预注册 calibration/validation/held-out scale split；分解训练、测量、参数与结构不确定性；说明 hierarchical block bootstrap、failure denominator、multiplicity、prediction error 与 decision regret；把 E2、E3、E4、E5 的允许措辞严格分开。

## 三、开卷复现部分（40 分）

### R1｜无缓存确定性复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 34 项 checks、1 JSON、10 CSV 与 3 SVG；
- 手算一条 raw slope、一个 far-scale error、一个 marginal balance、一次 MFU/time 换算、一个 repeated-token 值、一个 break-even 与一个 held-out error；
- 记录 Python 版本、命令、退出码、三个 SHA-256、14/14 byte comparison 与渲染目检。

### R2｜改变函数族与可辨识设计（10 分）

给真实曲线加入 finite correction 或 smooth breakpoint；分别用短/长 calibration window 比较无 offset、offset 与 broken family。再把 diagonal $N$–$D$ 路径改为 crossed grid，计算设计秩、参数相关和 held-out error。运行前冻结选族规则，不能看 target 后换模型。

### R3｜改变资源与生命周期目标（10 分）

改变 $\alpha,\beta,\kappa$、数据上限、execution multiplier、MFU、PUE、电网强度和请求量 $Q$；比较连续 $N^*,D^*$、离散近优集、wall time、energy/carbon、break-even 与 Pareto 选择。说明每次翻转来自 loss surface、系统层还是部署偏好。

### R4｜真实小模型 Scaling Pilot（10 分）

在最小语言模型或分类网络上做至少四个 scales、三个 data budgets、每 cell 多 seed 和中间 checkpoints。冻结 tokenizer、评测、超参协议和参数/FLOP 口径；按整个 scale 切分 calibration/validation/held-out；保存失败、搜索、能耗/时间和逐域 loss；比较至少三个函数族并报告区间、覆盖与 decision regret。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 只画 log–log 直线，或背诵固定 tokens/parameter 而不写对象、范围与成本口径 |
| L1 | 能算两点指数，却忽略 floor、joint bottleneck、训练充分度和失败分母 |
| L2 | 能完成 constrained optimum、compute/data/system 账与 metric 反例 |
| L3 | 能复现实验、改变函数族/资源/目标，并做无泄漏 held-out scale audit |
| L4 | 能在真实 pilot 上预注册设计、保留结构不确定性，用 E5 decision regret 验收资源建议 |

通过线：总分至少 80/100，且 Q1、Q3、Q4、Q8、R4 均不得低于该题 50%。本卷静态状态为 verified 时，也只说明课程材料通过审计，不代表学习者已经通过。

## 六、通过后出口

通过本门后进入低精度、量化与分布式训练时，仍要继承本卷的资源合同：理论操作数、实际 kernel、通信、内存、wall time、能耗和质量不是同一目标；进入训练诊断时，还要继承 scale-block split、失败分母、函数族不确定性与证据等级。任何“扩规模有效”或“降低训练成本”的结论都必须能回到这些账本。
