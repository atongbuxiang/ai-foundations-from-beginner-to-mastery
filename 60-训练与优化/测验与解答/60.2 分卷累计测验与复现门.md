# 60.2 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背诵 Adam 公式为通过标准，而检查能否从 state transition 重建 AdaGrad/RMSProp/Adam-family，区分 exact identity、approximation 与 counterexample，并把资源优势和 benchmark 结论放入正确证据层级。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 `independent`；
- C/D/E 每层至少各有 8 题可在新数字上独立完成；
- 已独立运行 [[实验 - 自适应优化器状态、尺度与反例数值审计]]；
- 能解释三张实验图各自“证明了什么/没有证明什么”。

## 二、闭卷部分（100 分钟，60 分）

### Q1｜AdaGrad 几何与尺度（7 分）

给梯度 $(3,0),(0,4),(6,0)$：手算 diagonal accumulator 与三步方向；从 proximal 子问题推导第 3 步；再判断“全历史乘 2”与“只把第 3 步乘 2”是否等价。

### Q2｜RMSProp 时间尺度（7 分）

$\rho=.95$、$v_0=1$，之后 $g_t^2=16$：推导 $v_k$，计算半衰期、e-fold 和 $N_{eff}$，并说明三个数为何不同。

### Q3｜Adam 状态与 bias correction（8 分）

$g=(2,-1,3)$、$\beta_1=.5,\beta_2=.75$、$\epsilon=0$：完整手算 $m,v,\hat m,\hat v,u$；指出哪一步用到了二阶矩平稳假设，为什么随机比值不因此无偏。

### Q4｜Epsilon 与有限精度（7 分）

比较 root-out `eps=1e-6` 与 root-in `eps=1e-6` 的量纲和 crossover；把 root-in epsilon 重标到相同零点分母尺度；列出 representability、absorption、compute dtype 三层诊断。

### Q5｜反例与 AMSGrad（8 分）

对 $C=5$ 的三周期线性损失找最佳固定 comparator；解释 Adam denominator 遗忘路径；证明 running max 非减；严格写出反例能否定和不能否定的命题。

### Q6｜Scale、Sign 与 RMS（8 分）

从零均值 iid gradient 推导 EMA 方差与低 SNR Update RMS；给一个 current gradient 与 momentum 异号的反例；说明为何 $\beta_2$ 从近似式消失不等于无关。

### Q7｜L2、Coupled 与 AdamW（8 分）

$P=\operatorname{diag}(2,.2)$、$\theta=(1,1)$、$g=0$：比较两种 decay；推导变 LR 累计乘积；从 AR(1) 式递推推导精确 Weight RMS。

### Q8｜Lion、Adafactor 与证据门（7 分）

写 Lion 两个 beta 的更新时序；证明 Adafactor 边际重建；给一个非 rank-one 反例；用算法/资源/调参/统计四门审计“状态更少所以更好”。

## 三、开卷复现部分（40 分）

### R1｜无缓存复现（12 分）

- 从空输出目录运行标准库脚本；
- 核对 13 项 checks 与三张 SVG；
- 任取 RMSProp 第 7 步和 epsilon 曲线一点手算；
- 记录命令、Python 版本、seed、SVG hash 和目检结果。

### R2｜干预近似条件（10 分）

给 Update RMS 轨道加入 $\mu/\sigma=1$ 或 AR(1) 相关性；运行前写偏离方向的预测，运行后报告 empirical/theory residual，并指出被破坏的假设。

### R3｜重建反例（8 分）

把 $C$ 改为 3、6 两种值，先手算周期 comparator；分别改变 $\beta_2$ 或删掉投影，记录第一处分叉。不得把新轨迹仍称作原合同的“同一复现”。

### R4｜真实 optimizer 审计（10 分）

选择一个小模型，逐参数导出 shape/dtype/group/state bytes，做 AdamW 与 Lion 或 Adafactor 的一步 reference test；同时报告 peak memory、step time、quality metric 和等额调参协议。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 混淆 $v$ 与 variance、epsilon 位置或 L2/decay；只会背公式 |
| L1 | 能手算状态，但不能说明假设、单位和实现合同 |
| L2 | 能独立推导时间尺度、偏差修正、反例和 decay 差异 |
| L3 | 能复现实验、修改条件并用残差定位近似失效 |
| L4 | 能审计真实训练系统与新优化器证据，形成可证伪研究协议 |

通过线：总分至少 80/100，且 Q4、Q5、Q7、Q8、R2 均不得低于该题 50%。静态笔记与脚本为 `verified` 不代表学习者已经通过本门。
