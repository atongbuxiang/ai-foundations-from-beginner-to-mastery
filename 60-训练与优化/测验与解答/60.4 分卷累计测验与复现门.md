# 60.4 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背诵 Muon 伪代码为通过标准，而检查能否从 norm ball 与 duality map 出发，经过 exact polar target、finite-step numerical solver、versioned state machine 和 shape scale，最后形成带系统与证据边界的迁移决策。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能在新数字上独立完成；
- 已从空输出目录运行 [[实验 - Muon 矩阵几何、数值迭代与迁移边界审计]]；
- 能不看图注解释 11 张图各自“证明了什么/没有证明什么”；
- 能在纸上写出本卷固定的 $y=xW$ shape convention 并正确翻译转置版本。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜Norm duality 与最速方向（7 分）

从 support function 定义证明一般范数下单位最速值为 $-\lVert g\rVert_*$；对 $g=(3,1)$ 手算 $\ell_2,\ell_\infty,\ell_1$ 三个方向；最后说明 constrained 与 penalized oracle 何时不能只靠 LR 互译。

### Q2｜Spectral/nuclear duality 与 rank（8 分）

从 von Neumann inequality 证明 spectral/nuclear duality，手算 $G=\operatorname{diag}(4,1)$；对 rank-one $3\times2$ 矩阵构造两个非 canonical maximizers，并证明 canonical partial isometry 的 Frobenius norm 最小。

### Q3｜三种 sign 对象（6 分）

分别定义 polar/msign、classical matrix sign 与 finite-step NS output。用非正规 involution $A^2=I$ 反驳前两者等价，再列出 exact polar 唯一性与 rank 条件。

### Q4｜Muon 状态机（8 分）

按访问日源码写 parameter filter、EMA buffer、Nesterov、NS、shape adjustment、base-LR decay 和 update。手算两步 momentum，解释 None/zero、joint/block QKV 与 all-reduce order 的三个非等价。

### Q5｜Newton–Schulz 数值门（8 分）

从矩阵五次多项式推出 scalar singular map，证明经典误差递推；对 $s_0=.5$ 手算两步。然后为 flat、tiny、rank-deficient 与 BF16 情形设计四残差验收，不能只写 iteration count。

### Q6｜Shape scaling（7 分）

证明 rank-$r$ partial isometry 的 RMS 为 $\sqrt{r/(AB)}$；在 $4096\times1024$ 与转置 shape 上互译 current 三种 adjustment，并区分 parameter RMS、relative update、average output change 与 spectral worst case。

### Q7｜优化器对象与约束（8 分）

写出 Muon、Shampoo、SOAP 与 K-FAC 的 state equations；用同 current gradient/不同 history 和同 $G$/不同 $(x,\delta)$ 两例删除错误等价。再推导 Stiefel tangent projection与 polar retraction。

### Q8｜证据、系统与迁移（8 分）

将一项大规模 Muon 结果放入 L0—L4 证据阶梯；分解 tokens/FLOPs/wall-clock；为 AdamW→Muon 写 state/LR/ownership、同搜索预算、P95/peak/communication 和 rollback 合同。

## 三、开卷复现部分（40 分）

### R1｜无缓存确定性复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 21 项 checks、1 JSON、10 CSV 与 3 SVG；
- 手算任取一个 polar pairing、一个 scaling row 与一个 Stiefel residual；
- 记录 Python 版本、命令、退出码、三个 SHA-256、14/14 byte comparison 与渲染目检。

### R2｜改变 spectrum 与 solver（10 分）

把小 singular value 扫为 $10^{-1},10^{-2},10^{-4},10^{-6}$，比较 classic/Jordan 的 0—8 步 residual；加入 FP32/BF16 框架 kernel。运行前预注册误差方向，运行后同时报告 orthogonality、polar、cosine 与 dual gap。

### R3｜改变 shape 与 state（10 分）

把 global $4096^2$ matrix 改成四个 column shards，分别计算 global/local original scaling；再切换 EMA/sum 与 joint/block polar。比较 nominal/actual RMS、direction、buffer、communication 和 save/load consistency。

### R4｜小模型迁移实验（10 分）

在小型 Transformer/MLP 上做 AdamW、Muon 与关键 ablations；固定 data/seeds，总搜索 compute 对称。报告 quality-vs-token/FLOP/wall-clock、NS residual、state/peak、P50/P95、失败 runs 和可回滚 checkpoint。不得只展示最佳 loss curve。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 把 $-g$ 当无条件最速方向，或把 finite-step NS 写成 exact polar |
| L1 | 会复述公式，但不能处理 rank、shape convention、state clock 与 residual |
| L2 | 能证明 duality/RMS、手算状态机并给 non-equivalence counterexample |
| L3 | 能复现实验、改变 spectrum/shape/state，用残差定位失败层 |
| L4 | 能在真实框架和系统上做同预算审计，形成带 rollback 的证据结论 |

通过线：总分至少 80/100，且 Q2、Q4、Q5、Q8、R2 均不得低于该题 50%。本卷静态状态为 verified 时，也只说明课程材料通过审计，不代表学习者已经通过。
