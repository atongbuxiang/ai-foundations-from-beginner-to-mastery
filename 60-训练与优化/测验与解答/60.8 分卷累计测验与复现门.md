# 60.8 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背诵“BF16 不需 scaling”“ZeRO-3 除以 world size”或某通信公式为通过标准，而检查能否从数值字段、estimator、控制流、tensor shape、对象生命周期与关键路径逐层推导训练语义，并用 matched quality、重复与因果 control 约束系统结论。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 independent；
- C/D/E 每层至少各有 8 题能在新 dtype、unequal batch、新 mesh 与新 topology 上独立完成；
- 已从空 output/plot directory 运行 [[实验 - 低精度数值、分布式语义与系统证据审计]]；
- 能不看图注解释本卷 11 张图分别“展示了什么/没有证明什么”；
- 能为任一训练方案写 dtype、quantizer、reduction、process mesh、memory timeline、clock、failure 和 evidence 八类 manifest。

## 二、闭卷部分（150 分钟，60 分）

### Q1｜格式字段、Ulp 与 Kernel 合同（7 分）

由二进制浮点表示推导 binade 内格距与 unit roundoff；比较 FP32、TF32、FP16、BF16、E4M3/E5M2 的 range/precision；给一个小更新吞没例；最后为 attention block 写 storage—multiply—accumulate—reduce—update—checkpoint 六栏合同，并指出 subnormal、FTZ、scale 与 kernel 的证据边界。

### Q2｜Loss Scaling、Master 与多时钟（8 分）

从链式法则证明 loss scaling 的精确等价，计算给定 gradient range 的安全 $S$ 区间；推导 clip-before-unscale 的阈值漂移；解释 master weight 的 half-ulp 动机；画 dynamic scaler 的 finite/overflow 状态机，并决定 attempt、optimizer、scheduler、EMA 与 weight decay 时钟。

### Q3｜随机舍入与量化 Estimator（8 分）

推导 SR 两点概率、条件期望与 $\Delta^2/4$ 方差界；给出局部无偏不推出轨迹无偏的反例；手算 affine quantizer；解释 clipping/rounding、STE、error feedback 与 optimizer-state 扰动；为“8-bit training”写对象、granularity、scale、kernel 和 failure 合同。

### Q4｜Data Parallel 与全局 Batch（7 分）

从全局经验风险推导 unequal-rank sample-weighted gradient；构造 local mean×collective mean 的错误组合；在 micro-step×rank 二维账中处理 masked tokens；区分 DP degree 与总 GPU 数；推导 ring All-Reduce payload，并说明代数等价为何不等于逐比特等价。

### Q5｜TP、PP、SP/CP 与 EP（7 分）

由 $Y=XW$ 推导 column/row TP shape 与 collective；从 fill/drain 时间表推导 pipeline bubble；比较 sequence/context parallel；写 MoE dispatch/combine 与 capacity；最后把一个 hybrid job 写成 rank coordinates、groups、local shapes 和 collective DAG。

### Q6｜ZeRO/FSDP、重计算与 Offload（8 分）

从 16 B/parameter 账推导 ZeRO-1/2/3 稳态；写 $M_{peak}=\max_t\sum_jM_j(t)$ 并构造分片后 OOM 的生命周期；解释 $O(\sqrt L)$ checkpointing；计算 offload bandwidth 下界；设计 world-size-independent checkpoint/restart 合同。

### Q7｜Roofline、关键路径与 Scaling（7 分）

推导 $\min(C,BI)$ 与 ridge；把 collective 写成 latency–bandwidth 模型；从 bucket-ready DAG 计算 exposed tail；用实测单卡 baseline 计算 strong-scaling efficiency；区分 peak FLOPs、tokens/s、step time 与 time-to-quality。

### Q8｜非确定性、复现与因果证据（8 分）

给出浮点非结合反例和分布式非确定性来源树；区分 bitwise/numerical/trajectory/decision reproducibility；将 E0—E5 与允许的声明一一对应；为“低精度 collective 导致 Attention collapse”画 DAG、negative controls、mediator 时间顺序和 paired repeats。

## 三、开卷复现部分（40 分）

### R1｜无缓存确定性复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 38 项 checks、1 JSON、10 CSV 与 3 SVG；
- 手算一个 ulp、loss-scale 区间、SR 方差、affine code、global mean、ring bytes、pipeline efficiency、ZeRO bytes、ridge 和非结合反例；
- 记录 Python 版本、命令、退出码、三个 SHA-256、14/14 byte comparison 与渲染目检。

### R2｜数值与控制流干预（10 分）

至少完成两类：改变 fraction/exponent bits；移动 gradient range；加入 subnormal/FTZ；比较 RN/SR/error feedback；改变 quantizer block/scale；让 overflow 发生在不同 ranks。预注册期望，逐一审计 local estimator、global consensus、update/scheduler/EMA 时钟和 failure denominator。

### R3｜Process Mesh、Memory 与 Critical Path（10 分）

构造至少两个 DP/TP/PP/SP/EP meshes；从 shape 计算 collective bytes 与 global batch；为 FSDP gather、activation、workspace、prefetch/offload 生成 $M(t)$；把 backward-ready 与 collective 画成 DAG，比较 steady、peak、sum-of-communication 与 exposed tail。

### R4｜真实小模型 Mixed-precision Distributed Pilot（10 分）

在可用硬件上以 FP32/BF16 或 FP16 reference 与至少一个量化/分布式变体训练小模型。冻结数据、global batch、update count、checkpoint rule 与 failure policy；保存 dtype/kernel、scale/overflow、per-rank count、profiler、memory trace、多 seed learning curve、重启记录和软件硬件 manifest；分别给 bitwise/numerical/trajectory/decision 结论，不把单 step speedup 写成质量结论。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 只背 dtype/ZeRO 名称，或以总 GPU、理论 bytes、tokens/s 直接替代训练语义 |
| L1 | 能算 ulp、batch 与 payload，但没有控制流、shape、生命周期或证据边界 |
| L2 | 能完成 estimator、multi-clock、mesh、peak-memory 与 Roofline 推导 |
| L3 | 能复现实验、设计单因素干预，并以 matched learning curve 与失败分母验收 |
| L4 | 能在真实 pilot 中联合审计数值、系统、复现和因果链，对新方案给出可执行边界 |

通过线：总分至少 80/100，且 Q1、Q2、Q4、Q6、Q8、R4 均不得低于该题 50%。本卷静态状态为 verified 时，也只说明课程材料通过审计，不代表学习者已经通过。

## 六、通过后出口

通过本门后进入训练诊断与实验方法时，要把本卷的多时钟、per-rank count、dtype/kernel、memory/communication timeline、failure/restart 与复现层级变成统一 telemetry；任何异常都要先定位于表示、estimator、控制流、shape、生命周期或外部系统，再用配对比较、置信区间、checkpoint 选择和因果干预确认，而不是只看 loss 曲线猜原因。
