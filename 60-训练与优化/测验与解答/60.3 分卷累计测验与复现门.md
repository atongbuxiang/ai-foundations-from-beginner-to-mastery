# 60.3 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不以背诵 optimizer 名称为通过标准，而检查能否从 derivative object 与 expectation measure 开始，经过结构近似、数值线代和 state clocks，最后形成带边界的系统与统计结论。

## 一、进入条件

- 8 份节点习题的 A/B 层至少 90% 标为 `independent`；
- C/D/E 每层至少各有 8 题能在新数字上独立完成；
- 已从空输出目录运行 [[实验 - 曲率对象、隐式二阶步与矩阵预条件数值审计]]；
- 能不看图注解释 11 张图各自“证明了什么/没有证明什么”。

## 二、闭卷部分（120 分钟，60 分）

### Q1｜曲率对象总账（8 分）

给 $z=f_\theta(x)$ 与一般 $\ell(z,y)$，从指标链式法则推出 $H=G+R$；分别定义 true Fisher 与 empirical Fisher。最后用一句带完整量词的话说明 $F=G$ 的常见充分条件。

### Q2｜三张最小反例（7 分）

手算 $f=\theta^2$ least-squares、Gaussian mean optimum 与 per-sample gradients $(+1,-1)$ 三例；逐一说明它们删除哪条错误等号、没有否定什么。

### Q3｜Newton 与 globalization（8 分）

对 $B=\operatorname{diag}(-1,4)$、$g=(1,2)$，比较 Newton、damped 与 radius-$1$ trust-region candidate；写 KKT 条件、pred/ared/$\rho$，并区分 negative curvature、boundary hit 与 accepted step。

### Q4｜HVP、CG 与误差（8 分）

从 $\nabla L^Tv$ 推出 HVP；手算一个二维 quadratic 的 HVP 与两步 CG；证明 $e=A^{-1}r$，再说明 dropout mask 每次变化为何破坏固定 Krylov system。

### Q5｜Natural gradient（7 分）

从 KL 二阶展开推导约束自然梯度及尺度；在 Bernoulli 的 logit/probability 坐标手算同一 tangent；列出 finite step、Euclidean damping 与结构近似的三个不变性断点。

### Q6｜K-FAC（8 分）

从 $\delta a^T$ 推到 exact sample Kronecker identity，再指出 expectation factorization 的位置；证明 inverse apply 公式；展开 factored damping 的两个 cross terms并给数值反例。

### Q7｜Shampoo（7 分）

对 $2\times3\times4$ tensor 写三组 mode Gram shape、state 元素数和 $-1/(2k)$ root；为一个 diagonal block 计算正确/错误 root residual；写 amortized 与 tail cost。

### Q8｜SOAP 与证据地图（7 分）

手算一次 45° basis rotation 与逐坐标 normalization，说明 nonlinear state transport 风险；再用算法、数值、系统、调参、统计五门审计“SOAP 少 30% iteration，所以普遍快 30%”。

## 三、开卷复现部分（40 分）

### R1｜无缓存复现（10 分）

- 从空 output/plot directory 运行标准库脚本；
- 核对 16 项 checks、1 JSON、8 CSV 与 3 SVG；
- 手算任取一个 K-FAC damping mode 和一个 natural-gradient endpoint；
- 记录 Python 版本、命令、退出码、三个 SHA-256 与渲染目检结果。

### R2｜改变 conditioning（10 分）

把 CG diagonal 谱改为条件数 $10^2,10^4,10^6$，分别记录 residual 与 solution error。加入一个便宜 preconditioner；运行前写 iteration 与 error 的方向性预测，运行后用谱解释偏差。

### R3｜改变对象或测度（10 分）

改变 logistic 的 $p$ 与 observed-label 比例，分别计算 true Fisher、per-sample EF、batch-mean outer product。至少找一组数，使“增大样本”仍不能修复 label-law mismatch。

### R4｜框架/系统复现（10 分）

在小型 autodiff 模型中比较 dense Hessian 与 HVP，冻结 batch/RNG/buffers；实现一个 K-FAC 或 Shampoo 小 block，报告 residual、state/peak bytes、average/p95 time、repair 和失败计数。不得只报告 loss 曲线。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 以 shape/PSD/变量名判断对象，或把 CG/basis refresh 的退出都叫收敛 |
| L1 | 能复述公式，但不能写 expectation measure、vec convention 与 residual |
| L2 | 能手算对象、二阶步、Kronecker/root 并给最小反例 |
| L3 | 能复现实验、改变条件，用 residual 定位 statistical/structural/numerical 误差 |
| L4 | 能审计真实训练实现和性能表，形成可证伪、可复现的系统协议 |

通过线：总分至少 80/100，且 Q1、Q4、Q6、Q8、R2 均不得低于该题 50%。本卷静态状态为 `verified` 时，也只说明课程材料通过审计，不代表学习者已经通过。
