# 60.1 分卷累计测验与复现门

> [!abstract] 验收目标
> 本门不检查“能否背出 SGD 公式”，而检查能否从训练合同重建真实 update，手算稳定/噪声尺度，构造反例，并把 large-batch/implicit-bias 主张放到正确证据层级。

## 一、进入条件

- 8 份节点习题中 A/B 两层至少 90% `independent`；
- C/D/E 每层至少各有 8 题 `independent`；
- 已运行 [[实验 - SGD、Momentum 与随机优化噪声最小数值审计]] 并能解释三个 plot；
- 不能只凭解答复述，需在新数字/新 convention 上迁移。

## 二、闭卷部分（90 分钟，60 分）

### Q1｜训练状态合同（8 分）

给出一段含 DDP、AMP、accumulation、clip、momentum 和 cosine scheduler 的伪代码：

1. 写完整 $X_t$；
2. 标出 optimizer-step 的边界；
3. 指出三处顺序交换会改变算法的位置；
4. 写最小 resume checkpoint。

### Q2｜Reduction 与 covariance（8 分）

有限 gradient population $\{-2,0,4,6\}$：

1. 求 full mean 和分母 $N$ covariance；
2. 求 iid $B=2$ mean variance；
3. 求 without-replacement $B=2$ variance；
4. 把 mean-LR 0.08 翻成 sum-LR。

### Q3｜Accumulation 判定（7 分）

两个 micro-batches 的有效 token 数为 2 和 6、mean gradients 为 $-1$ 和 3。求 global gradient；然后分别加入 per-micro clipping、BatchNorm、每块一次 momentum update，判断哪条等价门被删除。

### Q4｜Momentum 字典（8 分）

给 $g=(1,-2,3),\mu=.8$：

1. 手算 buffer 与 EMA；
2. 常 $\eta=.05$ 时翻成 velocity；
3. 若第二步 LR 改为 .005，解释 naive translation 的错误；
4. 说明 bias correction 是否改变 early update。

### Q5｜Nesterov 变量映射（7 分）

从 $y_t=x_t+\mu v_t$ 出发，不看笔记推导 current-gradient-plus-buffer 形式；必须注明常参数与初始化条件。

### Q6｜Heavy-ball roots（8 分）

$\mu=.64$：

1. 求正实/复根/负实/发散的三个边界；
2. 判断 $\eta\lambda=.02,1,3.5$；
3. 解释稳定为何不等于 loss 单调。

### Q7｜SDE 尺度（7 分）

$C=\operatorname{diag}(9,1),B=9,\eta=.04$：求 gradient covariance、update covariance、$s=t\eta$ 下 diffusion coefficient；若 $H=\operatorname{diag}(3,1)$ 且与 $C$ 同基，求 OU stationary diagonal covariance。

### Q8｜证据审计（7 分）

审计声明：“batch 从 256 降到 32 后 test accuracy 提升，因此 SGD noise 找到更 flat minimum 并因而泛化更好。”把声明拆成可证伪箭头，列混杂、反例和最低补证实验。

## 三、开卷复现部分（40 分）

### R1｜脚本复现（12 分）

- 从空输出目录运行标准库实验；
- 核对 JSON 中六个 checks；
- 任选一个 batch size 手算 theory variance，与 CSV 对齐；
- 改 seed 后说明哪些量应变、哪些解析量不应变。

### R2｜故意破坏合同（10 分）

依次修改脚本：不缩放 sum-LR、改为 sequential steps、把 clip 移到每个 micro-gradient。对每个修改写“预期—观测—第一处分叉—原因”。

### R3｜稳定域迁移（8 分）

把 $\mu$ 改为 .64，重新生成 roots plot；先手算三个边界，再核对图。若图与解析不符，优先检查 normalized-step 横轴和 root polynomial。

### R4｜研究协议（10 分）

为一个小型 MLP/CNN 设计四臂 batch 实验，隔离 optimizer batch、update count 与 BN statistics；写表格预注册 LR search、budget、seeds、primary metric、telemetry 和停止规则。

## 四、评分标准

| 等级 | 要求 |
|---|---|
| 未通过 | 只能写口号；mean/sum、step/micro-step 或 covariance/diffusion 混淆 |
| L1 | 定义与手算正确，但遇到实现约定仍依赖提示 |
| L2 | 可独立推导 roots、covariance、变量映射并构造反例 |
| L3 | 可审计真实训练合同、复现数值实验并设计公平消融 |
| L4 | 可修改模型假设、解释新证据并明确哪些结论不能外推 |

通过线：总分至少 80/100，且 Q5、Q6、Q7、Q8 和 R2 不得有任何一项低于 50%。
