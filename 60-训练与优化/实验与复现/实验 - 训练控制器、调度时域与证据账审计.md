# 实验 - 训练控制器、调度时域与证据账审计

> [!abstract] 实验结论
> Python 标准库实验用 10 条轨道、27 项机器断言把 LR 标度、warmup 稳定区、schedule 端点与面积、horizon 改写、裁剪偏差与 scope、Weight RMS 记忆、参数平均、因子交互和四本预算账分开验收。27/27 断言通过；从另一空目录复跑时，1 JSON、10 CSV、3 SVG 共 14/14 个文件逐字节一致。实验以可手算反例证明：相同 raw LR 不识别 actual step，warmup 不保证 peak 安全，裁剪可反转梯度期望，当前 $\eta/\lambda$ 不能删除权重历史，单因素排序不能替代联合实验。

## 一、研究问题与预注册门

| ID | 对象 | 可证伪预期 |
|---|---|---|
| H1 | LR 标度 | $u\mapsto10u,\eta\mapsto\eta/10$ 后 $\Delta\theta$ 逐坐标相同；二次例 $\eta=.2$ 确实下降 |
| H2 | warmup | 曲率 50 下前 3 个 LR 严格落在 $(0,.04)$；第 4 步是边界、第 5 步越界 |
| H3 | schedule | linear/cosine/WSD 端点精确；linear 与 cosine 一阶面积相同而平方面积不同 |
| H4 | horizon | 对 $0<t<T$，$\eta_t(2T)>\eta_t(T)$；checkpoint 不能事后改写历史 |
| H5 | clipping estimator | $E[G]=.1>0$，但 $E[C_1(G)]=-.8<0$；clip 与 average 不交换 |
| H6 | clipping scope | global 保持两层 norm ratio 10；layerwise 改成 5；AGC 阈值随 weight norm 改变 |
| H7 | Weight RMS | 精确 $q_t$ 递推残差为 0；step 80 降 LR 后实际 $q_t$ 显著滞后于瞬时平衡 |
| H8 | averaging | 三步 EMA 为 1.522；$f_{\bar\theta}=4$ 而 prediction average 为 5 |
| H9 | factorial | 四 cell 的二阶差分为 $-0.3$；paired-seed 差的方差低于未配对方差和 |
| H10 | budget | branch lineage 去重成本 1040 GPUh，朴素重跑 2640 GPUh；四本账均存在 |

## 四、实验图 1：Schedule 形状与 Horizon 不是一回事

先看图回答：linear 与 cosine 在当前离散网格的一阶面积相同，为什么两条轨迹仍不等价；右栏的蓝红分离又说明未来 $T$ 怎样进入过去的控制输入？

![[00-知识库管理/_assets/plots/training-optimization/plot-training-control-schedule-horizon-v1.svg|900]]

> [!figure] 图 EXP-TRN-605-01　Schedule endpoint–area 与 horizon rewrite
> 左图对 101 个离散点绘制 constant、linear、cosine、inverse-sqrt 与 WSD；右图在同一 $t$ 比较 full-horizon cosine 的 $T$ 与 $2T$ 定义。来源：[[experiment_training_control_schedule_audit_v1.py]] 确定性生成；SVG SHA-256 `c35bbe25797b0b9baec9ed41a04ad7069ca9e2c908459e991794f2f3a97ade94`。

**怎样读图**：先检查首末值和连接点，再看一阶/平方面积；然后固定物理 step，比较不同 horizon 的 LR。虚线 WSD 在 stable trunk 保持历史一致，直到显式 cooldown 分支。

**图没有证明什么**：相同面积不保证相同 optimizer state、noise、weight-decay product 或泛化；WSD 也没有消除 cooldown 长度和输出选择对停止时刻的依赖。

## 五、实验图 2：裁剪偏差与 Weight RMS 记忆是两类非局部效应

先看图回答：左栏为什么不是“缩短了一点梯度”而是改变了 estimator 方向；右栏为什么 LR 已下降，实际 $q_t$ 却仍接近旧平台？

![[00-知识库管理/_assets/plots/training-optimization/plot-training-control-clipping-weight-rms-v1.svg|900]]

> [!figure] 图 EXP-TRN-605-02　Clipping expectation reversal 与 Weight-RMS lag
> 左图用两点随机分布显示阈值 1 前后期望符号反转；右图从第一阶段精确平衡出发，在 step 80 把 LR 从 $.01$ 降到 $.002$，比较实际 $q_t$ 与按当前 $\eta/\lambda$ 计算的瞬时平衡。来源：同一标准库脚本；SVG SHA-256 `de34166d1c8450b44001c80a0ec145a9b66dea629362470819d9168ef4916eb0`。

**怎样读图**：左侧把 raw 与 clipped expectation 分账；右侧橙线是带平稳假设的当期 target，蓝线由精确递推保留历史。阶跃瞬间两者相差约五倍。

**图没有证明什么**：这个反例不说明裁剪总是有害；$c_t=0,r_t=4$ 的标量递推也不等于真实 Transformer Weight RMS。它只删除“无偏”和“瞬时平衡”两类错误偷换。

## 六、实验图 3：平均对象与控制器交互

先看图回答：同一轨迹的 raw、EMA、SWA 为什么是三个输出候选；右栏哪个量明确告诉我们不能只做单因素排名？

![[00-知识库管理/_assets/plots/training-optimization/plot-training-control-averaging-factorial-v1.svg|900]]

> [!figure] 图 EXP-TRN-605-03　Averaging object 与 factorial interaction
> 左图对参数序列 $(2,4,10)$ 比较 raw、$\beta=.9$ EMA 与前缀 SWA，并标注二次模型中参数平均 4、预测平均 5 的反例；右图给出 $2\times2$ cell mean 和交互 $I=-.3$。来源：同一标准库脚本；SVG SHA-256 `8dc19876b2732ff8bbd7793e7ed6c5951284cfab27965d81e1f4fc46c3ddf12f`。

**怎样读图**：左栏先问交付 raw、EMA 还是 SWA，再区分 parameter 与 prediction average；右栏按相同 seed 比较 cell 差，并用二阶差分识别交互。

**图没有证明什么**：EMA/SWA 曲线不证明更优，$I=-.3$ 也只属于本实验的四个 cell。外推到模型、数据或更宽超参空间必须重新随机化与计账。

> 本实验刻意用标量、二维向量和确定性 cell 验收定义、顺序与反例，不是语言模型 benchmark。真实迁移还需框架级 mixed precision、per-group telemetry、distributed aggregation、真实失败删失、paired seeds、validation selection 与 wall-clock/energy 证据。
