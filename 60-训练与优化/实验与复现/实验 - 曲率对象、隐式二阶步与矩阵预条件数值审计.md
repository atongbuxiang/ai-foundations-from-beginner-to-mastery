# 实验 - 曲率对象、隐式二阶步与矩阵预条件数值审计

> [!abstract] 实验结论
> Python 标准库脚本以 6 组实验、16 项机器断言分离 exact identity、controlled counterexample、structural approximation 与 numerical certificate：Hessian 分解、sample Kronecker identity、正交旋转和自然梯度 infinitesimal tangent 在浮点容差内成立；GGN negative-curvature deletion、empirical-Fisher label mismatch、batch reduction、K-FAC moment/factored damping 与 SOAP nonlinear basis state 均给出非零反例；HVP finite difference、CG、inverse root 和 trust-region ratio 则各用独立 residual 验收。不同目录复跑的 JSON、8 CSV 与 3 SVG 逐字节相同。

## 一、研究问题与预注册门

| ID | 对象 | 可证伪预期 |
|---|---|---|
| H1 | Hessian decomposition | $H=G+R$ 误差 $<10^{-14}$；$\theta=0$ 时 $G=0,H<0$ |
| H2 | Fisher/EF/reduction | logistic 的 true Fisher 不随 observed label 改变；EF 改变；`mean_outer ≠ outer_mean` |
| H3 | Damping/trust region | quartic toy 的 pred 为正且 $\rho>0$；不同 $\lambda$ 给不同 step/model ratio |
| H4 | HVP/CG | bilinear symmetry 误差 $<10^{-14}$；finite difference 有内部最优尺度；CG 达到小 solution error |
| H5 | Natural gradient | logit/probability 的 tangent gap $<10^{-14}$；finite endpoint gap 随步长缩小 |
| H6 | K-FAC | sample Kronecker identity 精确；moment factorization 与 factored damping 保留非零 bias |
| H7 | Shampoo | 正确 inverse fourth root residual 为零；错误 exponent residual $>0.9$ |
| H8 | SOAP | 正交 round-trip/norm 精确；elementwise nonlinear update 不 rotation-equivariant |

## 三、关键数值摘要

| 轨道 | 观测 | 证据层级 |
|---|---:|---|
| 非线性 least squares，$\theta=0$ | GGN $=0$；Hessian $=-2$ | exact counterexample |
| Logistic，$p=.8,x=2$ | $H=G=F=.64$；EF 为 $.16$ 或 $2.56$ | label-measure counterexample |
| Gaussian sample optimum | $F=H=1$；EF $=0$ | label-measure counterexample |
| Batch gradients $+1,-1$ | mean outer $=1$；outer mean $=0$ | reduction counterexample |
| HVP finite difference | 最小误差 $1.18\times10^{-8}$，在 $h=10^{-8}$ | numerical diagnostic |
| $\kappa=100$ diagonal CG | 6 步后 residual $2.90\times10^{-11}$，solution error $2.90\times10^{-13}$ | linear-solve certificate |
| Natural gradient | tangent gap $=0$；$\eta=.001$ endpoint gap $7.50\times10^{-8}$ | local invariance / finite break |
| K-FAC correlated toy | factorization gap $2.25$ | structural approximation |
| Exact vs factored damping | cosine $.99972$，step-norm gap $49.93\%$ | direction near, scale not equal |
| Shampoo exponent | correct residual $0$；wrong residual $.9375$ | root certificate |
| SOAP basis | orthogonal norm gap $4.44\times10^{-16}$；nonlinear gap $.4142$ | exact rotation / nonlinear break |

## 五、实验图 2：HVP、CG 与 trust-region 是三道不同验收

先看图回答：为什么 finite-difference 最小误差不出现在最小 $h$，为什么 CG 的 residual 和 solution error 必须分两条线？

![[00-知识库管理/_assets/plots/training-optimization/plot-hvp-cg-trust-region-audit-v1.svg|900]]

> [!figure] 图 EXP-TRN-603-02　Finite-difference U 曲线、CG 误差与 quartic model ratio
> 左图扫描 $h=10^{-1},\ldots,10^{-13}$ 诊断 $L(\theta)=\sin\theta$ 的 HVP；中图对 $\operatorname{diag}(1,2,5,10,50,100)$ 运行 CG；右图在 $L(\theta)=\theta^4/4,\theta=1$ 比较五个 damping。来源：同一脚本；SVG SHA-256 `1bfb09737627ea2b0cae224f56cad4bebe7eead126a1a3bbf583d64ec72fbf82`。

**怎样读图**：左侧的 U 形来自 truncation/cancellation 权衡；中间两线回答不同误差问题；右侧 $\rho\to1$ 只说明步变小时局部二次模型更准，不自动说明训练更快。

**图没有证明什么**：六维 diagonal CG 不是大模型吞吐 benchmark；quartic 的正 $\rho$ 也不覆盖不定 Hessian、随机 batch 或 failed solve。

## 六、实验图 3：K-FAC、Shampoo、SOAP 的误差不在同一接口

先看图回答：为什么 exact sample identity 和 correct root residual 为零，却仍不能推出最终 optimizer 是 exact second-order method？

![[00-知识库管理/_assets/plots/training-optimization/plot-kfac-shampoo-soap-approximation-v1.svg|900]]

> [!figure] 图 EXP-TRN-603-03　Moment、damping、root 与 basis-state 的分层误差
> 六个柱分别记录 K-FAC expectation factorization gap、factored-damping step-norm gap、Shampoo 正确/错误 exponent residual、SOAP elementwise rotation gap 与只保存 diagonal 时丢失的 off-diagonal norm。柱共享绘图尺度但单位不同，只用于定位非零接口。来源：同一标准库脚本确定性生成；SVG SHA-256 `8dd7c2c723ccf73a6d269e54b2639ae5a6f075b584f0db5d3687ee0c5478440b`。

**怎样读图**：零值对应局部 exact algebra/numerics；非零值分别属于 statistical、structural 或 state-coordinate 层。逐层定位后，才可讨论下游 step 与 time-to-quality。

**图没有证明什么**：柱高不能用于给三种优化器排名，也不能外推到真实模型；它们的量纲、toy contract 和作用层级不同。
