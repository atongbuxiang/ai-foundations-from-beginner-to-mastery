# 实验 - 自适应优化器状态、尺度与反例数值审计

> [!abstract] 实验结论
> Python 标准库脚本以 9 条轨道、13 项机器断言区分三类结论：AdaGrad 全历史缩放、RMSProp step response、epsilon 缩放比和 Adafactor 边际属于可逐式核对的恒等关系；Adam/AMSGrad 三周期轨迹提供受控反例；Update RMS 与 Weight RMS 只在预先声明的平稳、低 SNR 或线性随机递推条件下与近似式吻合。首次运行、不同输出目录复跑、XML 校验和实际 PNG 渲染均已通过。

## 一、研究问题与预注册门

| ID | 对象 | 可证伪预期 |
|---|---|---|
| H1 | AdaGrad gradient scale | 全历史乘正数时 direction 误差 $<10^{-12}$；中途缩放必须分叉 |
| H2 | RMSProp 尺度切换 | 递推与 $b+\rho^k(a-b)$ 误差 $<10^{-12}$ |
| H3 | Adam bias correction | 常梯度矩修正精确；随机比值不冒充无偏 |
| H4 | epsilon placement | root-in/root-out 曲线不同；固定 epsilon 打破理想尺度抵消 |
| H5 | Adam counterexample | $C=4$ 三周期下 Adam 去错误端，AMSGrad 去 $-1$ |
| H6 | decay paths | diagonal coupled shrink 各向异性，AdamW 直接收缩各向同性 |
| H7 | Update RMS | 三个 $\beta_1$ 的 Monte Carlo 与 mean-field 式相对误差 $<3\%$ |
| H8 | Weight RMS | 线性递推 Monte Carlo 与精确稳态 RMS 相对误差 $<6\%$ |
| H9 | Adafactor | 行列边际精确保持；rank-one 精确、非 rank-one 可有元素误差 |

## 三、精确合同与受控反例摘要

| 轨道 | 观测 | 解释层级 |
|---|---:|---|
| AdaGrad 全历史乘 7 | direction 最大误差 $1.11\times10^{-16}$ | exact，浮点容差内 |
| AdaGrad 第 3 步才乘 10 | direction gap $0.4128$ | counterexample |
| RMSProp $1\to9,\rho=.9$ | 解析/递推最大误差 $7.11\times10^{-15}$ | exact recurrence |
| Adam 一步随机比值 | empirical ratio $0.00596$ vs $1/\sqrt5=0.4472$ | “分别无偏”不推出“比值无偏” |
| epsilon 同步乘 100 | direction ratio $4.19355$ | fixed epsilon scale break |
| 三周期 $C=4$，12,000 步 | Adam $x=0.6680$；AMSGrad $x=-0.99998$ | online-convex counterexample |
| Coupled vs AdamW | $(0.98,0.998)$ vs $(0.98,0.98)$ | diagonal anisotropy |
| Adafactor identity matrix | 边际误差 0；元素 RMS 误差 0.5 | marginals 不代表 elementwise fit |

RMSProp 三种“记忆长度”也由同一递推计算：半衰期 $6.579$ 步、e-fold $9.491$ 步、$N_{eff}=19$。它们回答不同问题，因此不能统称“精确记住 10 步”。

## 四、实验图 1：epsilon placement 不是排版差异

先看图回答：同样写 `1e-8` 时，为什么 root-in 红线的过渡点比 root-out 蓝线晚四个数量级？

![[00-知识库管理/_assets/plots/training-optimization/plot-adaptive-epsilon-response-v1.svg|900]]

> [!figure] 图 EXP-TRN-602-01　Root-out、尺度匹配 root-in 与同字面 epsilon 的响应
> 令 $m=\sqrt v$，扫描 $\log_{10}\sqrt v=-14,\ldots,2$。蓝线为 $m/(\sqrt v+10^{-8})$；绿线把 root-in epsilon 改为 $10^{-16}$ 以匹配零点分母尺度；红线直接在根内使用 $10^{-8}$。来源：同一标准库脚本确定性生成；SVG SHA-256 `50da51f8463fe7f347e6a7f0091b27c80b741853ff216e49a86aeb53e20365c9`。

**怎样读图**：先找 $\epsilon/\sqrt v\approx1$ 的 crossover，再比较曲线；绿线与蓝线只在极小/极大端相近，中间没有代数等价。

**图没有证明什么**：图不提供真实模型的最佳 epsilon，也不包含 accumulator dtype、loss scaling、underflow 或 fused-kernel 舍入。

## 五、实验图 2：反例究竟否定了什么

先看图回答：为什么一个周期中负梯度出现两次，最佳固定 comparator 仍是左端点，而 Adam 却向右移动？

![[00-知识库管理/_assets/plots/training-optimization/plot-adam-amsgrad-counterexample-v1.svg|900]]

> [!figure] 图 EXP-TRN-602-02　Reddi 风格三周期凸序列的投影轨迹
> $f_t(x)=4x$ 当 $t\equiv1\pmod3$，否则 $f_t(x)=-x$；$x\in[-1,1]$，$\beta_1=0$、$\beta_2=1/17$、$\alpha_t=0.5/t$。红线 Adam 最终到 $0.6680$，绿线 AMSGrad 到 $-0.99998$。来源：本卷标准库脚本确定性生成；SVG SHA-256 `f45ad62d3aaba73ab287bdf86d07bcb660bfb434445d551a2151eb025e737c3b`。

**怎样读图**：周期总斜率为 $4-1-1=2>0$，所以固定最优是 $-1$；Adam 的二阶 EMA 忘掉峰值，改变后两步相对位移。AMSGrad 保存 max denominator，阻断该遗忘路径。

**图没有证明什么**：它不证明 AMSGrad 在所有深网更优，也不证明 Adam 在常见任务必失败；投影、线性损失、周期和超参数都是反例合同的一部分。

## 六、实验图 3：两条 RMS 缩放律的证据边界

先看图回答：左图的圆点为何只是近似落在柱顶，右图两线为何几乎重合却仍需保留“exact/approx”标签？

![[00-知识库管理/_assets/plots/training-optimization/plot-update-weight-rms-audit-v1.svg|900]]

> [!figure] 图 EXP-TRN-602-03　低 SNR Update RMS 与线性 AdamW Weight RMS
> 左图以零均值 Gaussian gradient、$\beta_2=.999$、140,000 步检验 $\sqrt{(1-\beta_1)/(1+\beta_1)}$；三点最大相对误差 0.926%。右图固定 $\lambda=.1$，比较精确稳态式与 $\sqrt{\eta/(2\lambda)}$。独立 1,200 路、7,000 步的 Weight RMS 为 0.22296，精确值 0.22366。来源：本卷标准库脚本确定性生成；SVG SHA-256 `e2dada2e1ecb3749dc11e3b84cda98a2941108c210f5576a2eb6192536004d1a`。

**怎样读图**：左侧是带随机 denominator 的 Monte Carlo，接近 mean-field 预测不表示恒等；右侧实线保留 $-\eta\lambda^2$ 修正，虚线只取小步长首项。

**图没有证明什么**：真实网络的 update 有信号、相关噪声、非平稳 $v_t$、schedule、参数组和 decay 交叉项；Weight RMS 也受初始化与有限训练时长影响。
