# 实验 - 训练诊断、实验设计与因果证据审计

> [!abstract] 实验结论
> Python 标准库实验用 10 条互相分账的轨道和 40 项机器断言，验收多时钟、first-bad-event 二分、UWR 与谱尖峰、Simpson 混杂、$2^2$ 交互、配对降方差、有限时域序贯边界、checkpoint 选择乐观、throughput—time-to-quality 反转及 research-ledger 完整性。40/40 通过；1 JSON、10 CSV、3 SVG 共 14 个文件在两个空目录复跑逐字节一致。它是解析/有限教学 oracle，不是真实模型 benchmark，也不把 E2 时间线升级为 E3 因果实验。

## 一、研究问题与预注册门

| ID | 轨道 | 可证伪预期 |
|---|---|---|
| H1 | clock alignment | 4 attempts 消费 8 microsteps 与 7,990 tokens；一次 overflow 后只有 3 optimizer updates，attempt-scheduler 与 update-scheduler 分叉 |
| H2 | first bad event | 对 $[12000,12512]$ 的确定 replay 在不超过 10 次判定内定位 last-normal=12340、first-bad=12341 |
| H3 | UWR/spectrum | 相同 Frobenius norm 的 100×100 更新具有相同 entry RMS=.01，但 rank-one/top-spectrum 与 stable-rank 证据不同 |
| H4 | confounding | 新方法在 short/long 两组内都改善，因 composition shift 导致 crude 0.704 < 0.840；标准化后为 0.866 |
| H5 | factorial | 四格 10/14/12/22 给 $\beta_A=3.5,\beta_B=2.5,\beta_{AB}=1.5$，difference-in-differences=6 |
| H6 | pairing | 共享难度使 paired-difference variance 严格小于两个独立方差之和，并回收 covariance identity |
| H7 | sequential boundary | 预声明 20 次、值域 $[-1,1]$ 的 finite-horizon union-bound 区间比逐时 fixed-time Hoeffding 更宽且随 $t$ 收缩 |
| H8 | checkpoint selection | 三组候选各选择一次最小 validation noise，所选观测 risk 对共同 true risk 都乐观 |
| H9 | compute matching | A 吞吐 120k>100k tok/s，却因达标需 30B>20B tokens 得到 250k>200k 秒；吞吐排序与 time-to-quality 反转 |
| H10 | research ledger | claim/protocol/manifest/incident/E3 study 可字段完整，而 E4/E5 artifact 仍缺；完整度和证据等级不是同一轴 |

## 四、实验图 1：时钟分叉与 first-bad-event 是两个正交问题

先看图回答：overflow 之后为什么 attempt=2 而 update=1？已知一端正常、一端异常时，二分怎样把 512-step 区间缩为相邻边界？

![[00-知识库管理/_assets/plots/training-optimization/plot-telemetry-first-bad-audit-v1.svg|880]]

> [!figure] 图 EXP-TRN-609-01　Skipped update 的多时钟与 checkpoint 二分
> 左栏按 attempt 展示 micro/update/token 计数，并以红色标出 overflow 不推进 optimizer；右栏展示确定 replay 下区间逐轮缩小到 12340｜12341。来源：[[experiment_training_diagnostics_audit_v1.py]] 确定性生成；SHA-256 `6ff54138368a959d229c4f409015cafd40206109bcf2e67f8660c40c2e8b9e8e`。

**怎样读图**：横向比较同一 attempt 的四个 clock，确认数据消费不等于参数写回；再从二分每轮的 midpoint 颜色读出“正常端向右、异常端向左”的不变量。

**图没有证明什么**：真实训练可能无法 bitwise replay，first bad 还可能早于 telemetry 的采样点；此时需容差不变量、多次复现和更细 module instrumentation。

## 八、四条硬边界

1. 所有轨道是合成/解析教学对象，不是 GPU/LLM benchmark；
2. finite-horizon union-bound 在声明的 bounded-observation 和 $T=20$ 下成立，不可偷换为无限时域或普通训练 metric 的默认 CS；
3. first-change、Simpson 修正与完整 ledger 仍不能单独识别 causal mechanism；
4. throughput/checkpoint 反例说明协议可反转排名，不给出任何真实方法的普适排名。

## 九、继续实验

学习者至少完成两项变化并在运行前写定量预测：

- 把 overflow 改到不同 attempt，检查四个 clock/invariant；
- 移动 first-bad step，验证 $O(\log n)$ 轮数；
- 固定 RMS 改变 stable rank，比较 spectral/feature response；
- 改 group mixture 制造/消除 Simpson reversal；
- 把 interaction 设为 0 或方向翻转，重算 contrasts；
- 改 pair covariance，验证配对可能无益甚至有害；
- 改 $\alpha,T$ 比较 fixed/uniform width；
- 增加 checkpoint 数观察 selection optimism；
- 改 throughput 与 tokens-to-quality 制造排名边界；
- 故意缺一个 manifest/incident 字段，验证 completeness audit 报错但不改 E 等级。

最终还需在真实小模型上保存一次自然发生的失败 run、first-bad replay、paired factorial study、locked checkpoint selection、time-to-quality、置信区间与完整 incident ledger，才能从本实验的 E0/E1 校准进入 E3/E4 证据。
