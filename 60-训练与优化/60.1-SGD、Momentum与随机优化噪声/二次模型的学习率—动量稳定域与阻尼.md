# 二次模型的学习率—动量稳定域与阻尼

> [!abstract] 一句话结论
> 对 eigenvalue 为 $\lambda>0$ 的固定二次 mode，heavy-ball 误差满足二阶递推，其精确渐近稳定条件是 $0\le\mu<1$ 且 $0<\eta\lambda<2(1+\mu)$。区间内部还分为单调、阻尼振荡和交替振荡；这张相图是局部线性基准，不是深网全程的安全证书。

## 一、从高维二次函数降到标量 mode

考虑

$$f(\theta)=\frac12(\theta-\theta^*)^TH(\theta-\theta^*),
\qquad H=H^T\succ0.$$

Heavy-ball 写成

$$\theta_{t+1}=\theta_t-\eta H(\theta_t-\theta^*)
+\mu(\theta_t-\theta_{t-1}).$$

令误差 $e_t=\theta_t-\theta^*$，并用 $H=Q\Lambda Q^T$。在 eigenvector $q_i$ 方向上的坐标 $z_t=q_i^Te_t$ 满足

$$
\boxed{z_{t+1}=(1+\mu-\eta\lambda)z_t-\mu z_{t-1}.}
$$

所以必须对谱中每个 $\lambda$ 同时检查；只看平均 curvature 会漏掉最陡 mode。

## 二、特征根与稳定条件

尝试 $z_t=r^t$，得到 characteristic polynomial

$$p_\lambda(r)=r^2-(1+\mu-\eta\lambda)r+\mu.$$

两个根

$$r_\pm=\frac{1+\mu-\eta\lambda
\pm\sqrt{(1+\mu-\eta\lambda)^2-4\mu}}2.$$

mode 渐近收敛当且仅当 $|r_+|<1$ 且 $|r_-|<1$。对二次多项式使用 Jury 条件：

$$|\mu|<1,$$
$$1-(1+\mu-\eta\lambda)+\mu=\eta\lambda>0,$$
$$1+(1+\mu-\eta\lambda)+\mu=2(1+\mu)-\eta\lambda>0.$$

因此对 $0\le\mu<1$，

$$
\boxed{0<\eta\lambda<2(1+\mu).}
$$

若谱位于 $[m,L]$，所有 mode 稳定要求 $0<\eta<2(1+\mu)/L$。

## 三、稳定区内部的三种动力学

判别式

$$D=(1+\mu-\eta\lambda)^2-4\mu$$

决定根是实数还是共轭复数。

### 3.1 正实根：无换号收缩

当

$$0<\eta\lambda\le(1-\sqrt\mu)^2,$$

两个根非负；适当初值下误差不需换号。边界 $D=0$ 是 repeated root，可类比 critical damping。

### 3.2 复根：阻尼振荡

当

$$(1-\sqrt\mu)^2<\eta\lambda<(1+\sqrt\mu)^2,$$

根为共轭对，乘积 $r_+r_-=\mu$，所以

$$|r_\pm|=\sqrt\mu.$$

误差振荡，包络按 $(\sqrt\mu)^t$ 收缩。

### 3.3 负实根：交替换号

当

$$(1+\sqrt\mu)^2\le\eta\lambda<2(1+\mu),$$

根为负实数，轨迹强烈交替但仍可渐近稳定。达到上界时有根落到 $-1$，再增大即发散。

## 四、与 plain gradient descent 对照

令 $\mu=0$，多项式退化为 $r[r-(1-\eta\lambda)]$，有效根是 $1-\eta\lambda$。稳定条件恢复

$$0<\eta\lambda<2.$$

$0<\eta\lambda\le1$ 时不换号；$1<\eta\lambda<2$ 时交替收缩。Momentum 扩大了单个 mode 的稳定上界，却引入二阶 transient 和额外调参维度。

## 五、SPD quadratic 的经典最优常参数

对 $mI\preceq H\preceq LI$，令 $\kappa=L/m$。Polyak 的经典参数为

$$
\eta^*=\frac4{(\sqrt L+\sqrt m)^2},
\qquad
\mu^*=\left(\frac{\sqrt L-\sqrt m}{\sqrt L+\sqrt m}\right)^2.
$$

最坏 mode 的渐近收缩因子

$$\rho^*=\frac{\sqrt\kappa-1}{\sqrt\kappa+1}.$$

它展示 $\sqrt\kappa$ 级的谱改善，但前提是固定 SPD quadratic、已知谱端点和 exact gradients。对一般 smooth strongly convex 函数，heavy-ball 的全局行为更微妙；不要把 quadratic 最优参数当成通用 theorem。

## 六、两 mode 手算

取 $H=\operatorname{diag}(1,100)$，$\mu=0.9$。

- 若 $\eta=0.01$，平缓 mode 有 $\eta\lambda=0.01$，处于慢正根区；陡峭 mode 有 $1$，处于复根振荡区；
- 若 $\eta=0.04$，陡峭 mode 有 $4$，但稳定上界 $2(1+0.9)=3.8$，所以必发散。

这说明 training loss 先在某些方向下降，不能证明所有 mode 稳定。

## 七、连续阻尼类比与离散边界

二阶 ODE

$$\ddot x+\gamma\dot x+\lambda x=0$$

有欠阻尼、临界阻尼、过阻尼分类，能帮助理解振荡。但离散 heavy-ball 的区域由 $\eta\lambda$ 与 $\mu$ 决定，且单位圆而非左半平面是稳定边界。稳定 ODE 的粗 Euler 离散仍可不稳定。

## 九、Edge of Stability 与前沿边界

[[S-2021-Cohen-Edge-of-Stability]]报告 full-batch 神经网络训练中 top Hessian eigenvalue 常在 $2/\eta$ 附近甚至略高，短时间 loss 非单调、长时间仍下降。这与固定二次模型冲突的表象提醒我们：深网 Hessian 随参数移动，Taylor region 和 eigenvectors 都会变化。

[[S-2020-Su-7787-有限学习率与隐式正则]]进一步把有限步长看作动力学与隐式正则来源。当前可靠分层是：

- **定理**：固定 quadratic 的根与 Jury 稳定域；
- **局部探针**：当前 Hessian eigenvalue 和 linearization；
- **经验现象**：特定网络中的 edge-of-stability trajectory；
- **开放问题**：随机、时变、非凸训练为何可在超出静态阈值的区域长期自稳。

## 十、本节回顾

- 高维 SPD quadratic 可逐 eigenmode 化成二阶递推；
- 稳定要检查两个根都在单位圆内；
- $0<\eta\lambda<2(1+\mu)$ 是 exact quadratic condition；
- 稳定区内还可单调、复根振荡或负根交替；
- 深网的 local Hessian 只能作诊断，不能直接充当全程定理；
- 下一节 [[梯度噪声协方差、Noise Scale 与 SDE 近似]] 将把 deterministic recurrence 加上随机 forcing。
