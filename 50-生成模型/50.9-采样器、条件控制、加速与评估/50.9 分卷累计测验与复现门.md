# 50.9 分卷累计测验与复现门

> [!abstract] 通过标准
> 通过不是能背 CFG 公式或列出 FID。学习者必须在不看答案时推导 conditional score、noisy inverse likelihood、Euler/Heun 和 MeanFlow identity；能构造“自洽但错误”与“相同 FID moments、不同分布”的反例；并能把一篇少步生成论文写成预注册的质量—覆盖—成本实验。

## 一、八节点最小掌握

| 节点 | 必须能独立完成 | 常见未通过表现 |
|---|---|---|
| GEN-65 | 从 Bayes 推 conditional score，正确放入三类 sampler | 丢 $g^2/\Sigma$；把分类准确率当梯度可靠性 |
| GEN-66 | 固定 $w=0,1$ convention，做 quality–coverage sweep | 把 $w>1$ 称为更精确 conditional；忽略双 forward |
| GEN-67 | 写 $p(y\mid x_t)$ 积分并手推 Gaussian exact score | 把 $x_t$ 当 $x_0$；用 residual 代替 posterior calibration |
| GEN-68 | 分开 field/discretization/MC error，按 NFE 比 solver | 用 steps 代替 NFE；把 order 当模型质量保证 |
| GEN-69 | 区分 teacher endpoint、trajectory invariant、step map | 把全部 1-NFE 方法称为蒸馏；自洽当正确性充分条件 |
| GEN-70 | 推 average-velocity identity 与 JVP | 把 average 当端点算术平均；只写偏导不写全导数 |
| GEN-71 | 推 FID/KID，设计 P/R+人评面板 | 跨预处理比 FID；“无偏 KID”误解成零方差 |
| GEN-72 | 推 FD gradient，隔离 train/select/test evaluators | 可导即可靠；普通 accumulation 冒充 global FD gradient |

## 三、数值复现门

运行：

```bash
python3 00-知识库管理/_labs/code/experiment_guidance_solver_meanflow_evaluation_audit_v1.py \
  --fd-step 1e-5
```

必须得到 `all_assertions_passed: true`，并能解释：

1. 为什么 plug-in inverse score 是 exact score 的 6.76 倍；

## 四、口试门

### 4.1 条件与逆问题

现场推 Bayes score；再给 $y=ax_0+\eta$ 与 Gaussian diffusion，推 $y\mid x_t$。若直接写 $p(y\mid x_t)=p(y\mid x_0=x_t)$，未通过。

### 4.2 低步数对象

在白板画出 teacher two-step、consistency endpoint、Shortcut composition、MeanFlow chord，并逐一说明 target、stop-gradient、部署 map 和一个反例。

### 4.3 评价审计

给两个“FID 2.1 vs 2.3”的模型，要求在 5 分钟内追问 encoder/preprocessing/sample count/CI、P/R、conditionality、selection leakage、copy 与 cost。

## 五、最终项目门

选择 guidance、inverse solver、fast sampler 或 FD Loss 之一，提交：

1. 一页对象/符号/shape 合同；
2. 一个 oracle toy correctness test 与 finite-difference audit；
3. model/sampler/evaluator 三层误差账；
4. 质量—覆盖—条件—成本 Pareto；
5. 至少一个会否定自己机制解释的反例；
6. train/validation/test 与 evaluator 隔离；
7. 一级论文、科学空间研读入口、自己的推导/实验分层；
8. 配置、hash、seed、failure log 与可复现命令。

不要求训练大模型；要求任何结论都不越过证据。
