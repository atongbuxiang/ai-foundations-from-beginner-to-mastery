## 二、闭卷卷（210 分钟）

每节抽 A02、B02、C02、D02，再完成三道综合题。禁止查看公式表与代码。

### X1：从离散极限到反向 SDE 与 PF ODE

从 $\beta_k=\beta(t_k)h$ 无提示推出 VP SDE、闭式 $m,V$，再写 VE/sub-VP 并以方差 ODE验算。随后在两种时钟下推导 reverse drift，最后由 Fokker–Planck 推出 PF ODE。必须用一个 Gaussian 例子证明同边缘、异 conditional/path law，并分别列 model、terminal 与 solver error。

### X2：两个条件期望投影

先由 $p_t=\int p_0q_t$ 证明 marginal score 是 conditional score 的条件均值，并证明两个 MSE 相差常数；再对 $X_t=\phi_t(Z)$ 用 test function 证明 $E[\partial_t\phi_t|X_t=x]$ 运输 marginal path，推出 CFM/FM 常数差。最后说明 input-measurable weighting 与 target-dependent weighting 的边界。

### X3：Coupling、Rectification 与统一证据

构造同 endpoint marginals 的 identity/swap couplings，算出中点 target variance；说明 population OT、minibatch OT 与 Rectified Flow 的关系。推导 material acceleration 和一步 Euler endpoint error，给出 teacher straight 不推出 one-step exact 的反例。最后以表格区分 identity、theorem、continuous idealization、numerical result、controlled experiment 与 hypothesis。

门槛：总分 80%，C 类 75%，D 类 75%，三道综合题各 70%。以下任一错误直接不通过本轮：

- 忘记 $t\downarrow$ 的 $dt<0$，把两套 reverse drift 混用；
- 把 SDE/PF ODE same marginals 写成 same path law；
- 把 conditional/marginal loss 写成逐样本或数值相等；
- 把 straight conditional segments 写成 learned ODE trajectory 必直；
- 把 minibatch assignment 当 population OT；
- 把 diffusion $v=\alpha\epsilon-\sigma x_0$ 当任意时间参数下的 instantaneous velocity；
- 用 solver refinement 掩盖 model/score error。

## 三、复现门

运行 [[实验 - 连续扩散、Flow Matching 与 Rectified Flow 最小数值审计]]，完成其中至少五项改写并提交：

- VP/VE/sub-VP 的解析系数、差分 ODE residual 与 MC confidence；
- 两时钟 reverse drift 的同位移对照和故意符号失败；
- SDE/PF ODE 的 marginal moments 与 quadratic variation；
- score/CFM 两种 Pythagorean constant-gap 实验；
- identity/swap/minibatch-OT coupling 的 target variance/cost；
- Euler/Heun/RK4 的 equal-NFE 与 equal-error 对照；
- data/noise/score/velocity 的 round-trip 与 schedule-dependent 反例。

每个实验需报告 seed、样本数、step/NFE、tolerance、解析 oracle、失败 assertion 和修复输出。若使用额外库，锁版本并给 environment；标准库基准必须保留。
