# 条件核、边缘一致性与统一离散扩散框架

> [!abstract] 一句话结论
> 指定各时刻 corruption marginal $q_t(x_t|x_0)$ 后，连接 $x_t$ 与 $x_{t-1}$ 的 conditional kernel 不能任意写：对 $x_t$ 边缘化必须恢复 $q_{t-1}(x_{t-1}|x_0)$。满足一致性只保证概率结构合法，不保证 kernel 使用信息充分、易学习或生成质量好。

## 一、三个对象

对固定数据 $x_0$：

1. 当前边缘 $q_t(dx_t|x_0)$；
2. 反向/耦合 kernel $r_t(dx_{t-1}|x_t,x_0)$；
3. 目标前一边缘 $q_{t-1}(dx_{t-1}|x_0)$。

一致性要求对任意可测集合 $A$：

$$
\boxed{q_{t-1}(A|x_0)=
\int r_t(A|x_t,x_0)q_t(dx_t|x_0).}
$$

有 density 时即

$$\int r_t(x_{t-1}|x_t,x_0)q_t(x_t|x_0)dx_t
=q_{t-1}(x_{t-1}|x_0).$$

## 二、同一边缘有许多 coupling

最简单的“独立”构造

$$r_t(x_{t-1}|x_t,x_0)=q_{t-1}(x_{t-1}|x_0)$$

完全忽略 $x_t$，仍满足一致性，因为 $q_t$ 积分为 1。它证明一致性不等于信息效率：生成时若 $x_0$ 未知，必须从 $x_t$ 估计整个 $q_{t-1}$，难度可能很高。

另一端可选择高度相关甚至 deterministic coupling（若 marginals允许），使相邻状态共享信息。DDPM/DDIM 是不同 coupling 设计。

## 三、有限离散例子

令 $X_t\in\{0,1\}$ 且 $q_t=(1/2,1/2)$，目标 $q_{t-1}=(3/4,1/4)$。任取 kernel matrix（列对应当前状态）

$$R=\begin{pmatrix}0.8&0.7\\0.2&0.3\end{pmatrix}.$$

则 $Rq_t=(0.75,0.25)^T$，满足一致性。另一个两列都等于 $(0.75,0.25)^T$ 的 kernel 也满足，却完全忽略当前 state。合法 kernel 不唯一。

## 四、从 teacher kernel 到 learned reverse

训练时 $x_0$ 已知，可 sample/evaluate $r_t(x_{t-1}|x_t,x_0)$；部署模型只能用 $x_t$（及 condition $c,t$），目标是逼近对数据 posterior 混合后的 reverse：

$$q(x_{t-1}|x_t)=\int r_t(x_{t-1}|x_t,x_0)q(x_0|x_t)dx_0.$$

如果网络用平方损失预测某 target，只识别相应 conditional mean；完整 kernel 还需要 variance/离散概率或其他分布参数。

## 五、统一框架的能力与边界

前向变化可以是 Gaussian noise、blur、mask、删减、离散 transition 等，只要声明：

- 状态空间和基准测度；
- 每时刻 marginal/kernel 是否可 sample/evaluate；
- 一致性/Markov 或 non-Markov joint；
- 可训练 target 与部署 reverse kernel；
- 信息是否不可逆丢失、终端 prior 是否易采样。

形式统一不表示同一 Gaussian posterior 公式、同一 loss 或同一 architecture 适用。离散/mask diffusion 在 50.8 另建状态空间理论。

## 六、误差怎样进入 chain

即使每个 learned kernel $P_t$ 接近理想 $Q_t$，多步 composed distribution 的误差取决于 metric、kernel contraction、状态分布与误差相关性。不能只把每步 scalar MSE 相加就声称最终 distribution bound；需 total variation/KL/Wasserstein 或 coupling 的明确组合定理。

## 九、本节回顾与训练

- conditional kernel 必须与两端 marginals 一致；
- 一致 coupling 非唯一，independent kernel 是最小反例；
- teacher 看 $x_0$，部署 reverse 不看 $x_0$；
- 形式统一、统计可学、数值高效与生成质量需分别验证；
