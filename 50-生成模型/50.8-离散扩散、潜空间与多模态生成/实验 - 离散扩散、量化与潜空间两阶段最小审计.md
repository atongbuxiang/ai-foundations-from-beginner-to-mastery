# 实验 - 离散扩散、量化与潜空间两阶段最小审计

> [!abstract] 实验目标
> 不训练神经网络，只用 Python 标准库把本卷最容易写错的代数/采样接口变成可执行断言：row-stochastic matrix product、离散 Bayes posterior、absorbing posterior、CTMC reverse rate、VQ/FSQ 账本与 DDCM density weighting。它验证公式和实现方向，不验证论文级生成质量。

## 一、运行

在仓库根目录执行：

```bash
python3 00-知识库管理/_labs/code/experiment_discrete_diffusion_latent_token_audit_v1.py \
  --seed 20260825 --samples 100000
```

脚本无 NumPy/PyTorch 依赖。成功时 JSON 最后一项为：

```json
"all_assertions_passed": true
```

## 二、固定配置

| 子实验 | 配置 |
|---|---|
| categorical | 三状态对称核 diagonal=.8、off-diagonal=.1，模拟 10 万条两步路径 |
| absorbing | $\alpha=(.9,.8,.5)$ |
| CTMC | $R=[[-2,2],[1,-1]]$、$p_t=(.75,.25)$、$h=.05$ |
| VQ/FSQ | 三个二维 codes；FSQ levels $(8,8,8,5,5)$ |
| DDCM | 四个二维等模 noise codes；greedy residual 与 density mean 分开 |

## 三、已核验结果

### 3.1 Categorical marginal 与 posterior

解析边缘

$$q(x_2\mid x_0=1)=(.66,.17,.17).$$

seed 20260825 的 10 万次 Monte Carlo 得

$$\hat p=(.65950,.17015,.17035),$$

最大绝对偏差 $.00050$。给定 $x_2=2$ 的解析 posterior 为

$$
q(x_1\mid x_2=2,x_0=1)
=(8/17,8/17,1/17).
$$

### 3.2 Absorbing posterior

$$\bar\alpha_3=.36,$$

给定第三步为 mask，第二步仍 clean 的概率 $.5625$、已 mask 的概率 $.4375$；两项和严格为 1（浮点容差内）。

### 3.3 CTMC reverse rate

$$R^{rev}[2,1]=6,
\qquad R^{rev}[1,2]=1/3.$$

小步核

$$
I+.05R=\begin{bmatrix}.9&.1\\.05&.95\end{bmatrix}
$$

通过 nonnegative/row-sum assertions。

> [!warning] 本轮真实发现的实现陷阱
> 初版脚本曾把 $I+hR$ 写成“每个元素都加 $1$”，立即触发 row-sum assertion。正确实现必须用 Kronecker delta：`(1.0 if i == j else 0.0) + h * R[i][j]`。这不是排版问题，而是会把 generator 变成非法概率核的对象错误。

### 3.4 Quantization 与 DDCM

- $z=(1.4,.3)$ 最近 code 是 $(2,0)$，平方距离 $.45$；
- assignment $(.5,.25,.125,.125)$ 的 PPL 约 $3.3636$；
- FSQ 隐式 cardinality $8^3 5^2=12800$；
- DDCM residual $(2,-1)$ 的 greedy code 是 $(1,0)$；
- 对 target mean $(1,.5)$，density-weighted probabilities 约为 $(.5089,.3087,.0689,.1136)$。

## 四、脚本证明了什么

- row-vector matrix product 与 posterior 的指标方向一致；
- fixed-time closed marginal 与逐步 Monte Carlo 频率相符；
- absorbing posterior 的两条路径权重正确；
- reverse CTMC rate 的反边和 ratio 方向正确；
- VQ/FSQ/DDCM 的小例子可由独立算术复现；
- assertions 能抓到 identity matrix 的实现错误。

## 五、脚本没有证明什么

- 不证明 learned denoiser/ratio network 准确；
- 不证明 MaskGIT sampler 是 exact reverse chain；
- 不证明 FSQ/Rotation/SimVQ/DiVeQ 谁更优；
- 不训练 LDM，因此不测 representation floor 或生成质量；
- 不证明 DDCM 小 codebook 在高维图像上保持 FID/率失真；
- Monte Carlo agreement 只验证给定 toy kernel，不替代一般证明。

## 六、扩展实验

1. 扫 $K,T$ 并比较 analytic posterior 与 sampling variance；
2. 为 CTMC 加 Gillespie 与 tau-leap，画终点 weak error 随 $h$；
3. 在相同 toy dataset 比 VQ 与 FSQ 的 distortion/usage；
4. 为 DDCM 比 greedy argmax 与 density-weighted sampling 的 diversity；
5. 加一个明确非 injective encoder，数值展示 LDM representation floor。
