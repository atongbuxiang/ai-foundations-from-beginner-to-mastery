## 三、数值复现门

运行：

```bash
python3 00-知识库管理/_labs/code/experiment_discrete_diffusion_latent_token_audit_v1.py \
  --seed 20260825 --samples 100000
```

必须得到 `all_assertions_passed: true`，并能解释：

1. 为什么 categorical Monte Carlo 允许抽样误差而 posterior assertion 是解析精度；
2. 为什么 $I+hR$ 只在 diagonal 加 identity；
3. 为什么 DDCM density weights 与 greedy code 是两个 sampling rules；
4. 为什么本脚本不能比较前沿 quantizer 的生成性能。

实验记录与结果见[[实验 - 离散扩散、量化与潜空间两阶段最小审计]]。

## 四、口试题

### 4.1 对象口试

给出一句“我们把图像离散后做 diffusion”，要求在 3 分钟内追问并画出：

- 离散的是 pixel、encoder latent、token state 还是 sampler noise；
- clean/noisy state 空间；
- forward kernel；
- learned target；
- reverse sampler；
- decoder 与评价。

### 4.2 推导口试

随机给一个 $3\times3$ stochastic matrix 和 $(x_0,x_t)$，现场计算 posterior；再给一个两状态 generator 和 $p_t$，现场写 reverse rates。

### 4.3 证据口试

给“FSQ 超越 VQ”“Rotation 改善 collapse”“DDCM 小 $K$ 不降 FID”三个标题，分别说出可独立复算部分、论文实验、科学空间补充观察与不能外推的结论。

## 五、最终项目门

选择 D3PM、MaskGIT、SEDD、VQ/FSQ、LDM 或 DDCM 中一条路线，提交：

1. 一页对象合同与符号；
2. 一个可执行 toy correctness test；
3. representation/model/sampler/evaluation 四本账；
4. 至少一个会否定自己机制解释的对照；
5. 来源分层：一级论文、科学空间研读入口、自己的推导与实验；
6. 一张符合本卷图注规范的教学图。

不要求训练大模型；要求结论不越过证据。
