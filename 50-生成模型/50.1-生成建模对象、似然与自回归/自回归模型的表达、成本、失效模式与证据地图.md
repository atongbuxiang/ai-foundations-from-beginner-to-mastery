# 自回归模型的表达、成本、失效模式与证据地图

> [!abstract] 本节主问题
> 自回归模型的强项是 normalized conditionals、tractable joint likelihood 和概念简单的祖先采样；代价是顺序归纳偏置与生成串行。其失败必须按分布、条件族、训练前缀、解码器、系统实现和评价协议分账，不能把所有重复、模糊、慢或漏模式都归因于“自回归”。

## 一、表达能力：chain rule 完备不等于有限网络完备

概率 chain rule 对任意 joint 成立；如果每个条件模型能精确表示真实 conditional，则自回归乘积能表示真实 joint。这个结论有三个常被删除的条件：

1. 每个 conditional family 足够丰富；
2. 网络能从所给前缀提取必要依赖；
3. 优化和数据能识别正确参数。

所以“AR 能表示任何分布”是理论存在性陈述，不是固定深度 Transformer/PixelCNN 在有限预算下的性能保证。

## 二、成本分账

设序列长度 $T$，每步 categorical 词表 $V$。

### Density evaluation / 训练

$$
\log p_\theta(x_{1:T})=\sum_t\log p_\theta(x_t\mid x_{<t}).
$$

RNN 本身按时间递推；masked CNN/Transformer 在完整样本上可并行输出条件分布。Transformer full attention 核常为 $O(T^2d)$，但真实 wall-clock 取决于 kernel、batch 和 memory I/O。

### Sampling

生成存在 $T$ 个串行决策。KV cache 可把每步重算前缀改为复用历史 K/V，使 attention pair 累计从朴素近 $O(T^3)$ 降到 $O(T^2)$，但无法在不改变模型/算法的情况下同时决定所有未知 token。

### Memory

Cache、beam duplication、long context 和大词表 logits 都占内存。评价“AR 慢”必须报告 prompt/output length、batch、dtype、cache、hardware 和 latency 类型；不能只写大 $O$。

## 三、六类失效模式

| 层 | 典型现象 | 首先检查 |
|---|---|---|
| 分布/support | 漏掉稀有模式、无效序列 | 数据覆盖、模型 support、likelihood/recall |
| 条件分布族 | 连续 patch 平均、错误尾概率 | Gaussian/MSE、mixture、calibration |
| 排序/架构 | 长程依赖困难、局部纹理优先 | order、receptive field、position |
| train–rollout | 错误前缀恢复差 | teacher vs rollout prefix probes |
| decoding | 重复、过短/过长、低多样性 | temperature、truncation、EOS、beam objective |
| system | cache reorder/position/mask 错误 | full-vs-cache、reset、packing isolation |

一个现象可有多个竞争解释。例如重复可能来自模型把循环赋高概率、top-$p$ 删掉 EOS、beam 长度偏置、cache bug 或训练数据重复。需要干预实验而非标签归因。

## 四、likelihood 与样本证据如何同时读

| 证据 | 回答 | 不回答 |
|---|---|---|
| held-out NLL/BPD | 对测试分布的平均 log score | 人类偏好、单样本典型性 |
| unconditional samples | 某些 rollout 可见行为 | 模式覆盖、概率校准 |
| precision/quality | 样本是否落在可信区域 | 是否覆盖全部数据模式 |
| recall/coverage | 模式覆盖迹象 | 单样本细节质量 |
| conditional accuracy | 条件一致性 | 无条件分布是否正确 |
| latency/memory | 程序成本 | 概率正确性 |

高 likelihood 与高 sample quality 可以相关，也可能被预处理、低层统计和 decoder 改动解耦。结论必须限定指标与协议。

## 五、跨模态比较

### 文本

离散 token categorical likelihood 自然；困难在 tokenizer、长序列、开放生成的 tail 与 evaluation。top-$p$ 改变实际 joint，beam 对翻译等有任务依赖价值。

### 图像

raw pixels 可用 PixelRNN/CNN 的离散条件 mass，exact likelihood 但采样非常串行；VQ tokens 缩短序列却引入 tokenizer loss；连续 patches 需要 expressive conditional density，MSE-only 可能平均多峰。

### 音频与视频

采样率/时空 token 数让 serial horizon 巨大，通常靠 hierarchy、codec、blockwise/parallel prediction 或 diffusion head 转移难点。模型名称仍是 AR，不代表单步对象相同。

### 多模态

顺序决定文本/图像谁条件于谁；统一 token space 会牺牲某些连续信息。[[S-2024-Su-10197-多模态自回归]]把排序和连续 patch likelihood 提为开放问题，适合保留为研究议程而非标准答案。

## 七、经典证据与当代边界

- [[S-2016-Uria-NADE]]：normalized conditional product 与 ordering-aware density estimation；
- [[S-2016-Oord-PixelRNN]]：二维 raw-pixel AR、discrete likelihood 与历史 benchmark；
- [[S-2019-Holtzman-Nucleus-Sampling]]：特定开放文本设置的 decoding degeneration 与 nucleus evidence；
- [[S-2015-Huszar-Scheduled-Sampling批判]]：修复 prefix shift 可能破坏 proper estimation 的反例。

到 2026 年，AR、diffusion、flow 和 hybrid 方法持续互相吸收；“某家族已经淘汰另一家族”通常是依模型、数据、采样预算和指标的经验主张。课程后续会用同一七账表比较，而不靠模型名站队。

## 八、最小受控比较协议

比较两个 AR 系统时至少固定：

1. 数据 split、去重、tokenizer/dequantization；
2. 参数量、训练 tokens/steps、optimizer 与 compute；
3. teacher-forced NLL 的 mask 和归约；
4. decoding kernel、seed、样本数、长度预算；
5. quality、coverage、repetition、validity、conditional consistency；
6. prefill/decode latency、throughput、memory；
7. 多次运行或置信区间，以及失败样本选择规则。

只展示 cherry-picked 样本或只报最佳 NLL 都不足以裁决系统。

## 九、反例诊断：低 NLL 仍可能生成差

可能原因包括：

- 平均 NLL 的改善集中在频繁、容易 token，稀有关键决策仍差；
- token-level loss 小差异沿长 rollout 累积；
- decoder $Q_{\theta,\phi}$ 与评估过的 $P_\theta$ 不同；
- sequence-level metric 与 log score 不同；
- 测试数据和部署 prompt 分布不同；
- implementation cache/mask/precision bug。

诊断顺序应是先验证 full-vs-cache 和原样 sampling，再 sweep decoder，再做 prefix-conditional calibration，最后才归因架构。

## 十二、本节回顾

- AR 的概率表达来自 chain rule，有限模型能力仍受 conditional family、顺序、架构、数据和优化限制；
- training density evaluation 可并行不等于 sampling 并行；
- failure attribution 至少跨分布、训练、解码、系统与评价五层；
- Science Space 是中文问题与研究假说主线，原论文和独立推导承担定义/证据；
- 受控比较必须同时报告 likelihood、quality、coverage 和 cost。
